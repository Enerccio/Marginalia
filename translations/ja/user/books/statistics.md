# 執筆統計

Marginalia は、あなたの本に起きたことを日ごとに記録します。書いた単語数とモデルが書いた単語数、執筆していた時間、モデルに送ったトークン数、本の大きさなどです。**統計**ウィンドウでは、1冊または全部の本について、数値、グラフ、作業した日の**カレンダー**を表示し、あわせて**連続日数**と**1日の目標**も確認できます。

数値はあなただけのものです。アカウントごとに、それぞれ自分の本だけを表示します。集計はバージョン 1.6.0 から始まります。それ以前の出来事は、[パートの履歴から](#days-before-the-statistics)可能な範囲で再構成されます。

<a id="opening-the-window"></a>

## ウィンドウを開く

- **1冊の本:** 設定メニュー（ストーリーの下にある歯車）に**統計**があります。このウィンドウはその本を集計します。
- **すべての本:** 本の一覧の**管理**メニューに**統計**があります。このウィンドウはすべての本を合算し、さらに**本**と**本ごと**の2つのタブがあります。

どちらのウィンドウも同じように動作します。上部で**期間**（*今日*、*昨日*、*過去7日間*、*過去30日間*、*今月*、*全期間*、または開始日と終了日を指定する*カスタム*）と**集計対象**（**すべて**、**自分**（あなたと、あなたが依頼したモデル）、または **エージェント**（[エージェント](../agents.md)が行った作業。これは分けて集計されます））を選びます。日付はサーバーの時計に従います。

![本の統計：日別](../../images/statistics-book.png)

選択肢の下には、期間の合計があり、その下にタブが並びます。

<a id="what-is-counted"></a>

## 集計される内容

| | |
|---|---|
| **書いた単語数** | あなた自身が書いた単語数。パートに入力した文章や、ストーリーエディターなど、パートを編集するあらゆる場所で入力したテキストです。 |
| **生成した単語数** | モデルがこの本のために書いた単語数。 |
| **削除した単語数** | なくなった単語数。パートから切り取ったテキストや、削除したパートが含まれます。 |
| **作成したパート**、**削除したパート**、**編集** | 作成・削除されたパートの数と、変更したパートを保存した回数。 |
| **送信トークン数**、**生成トークン数**、**リクエスト数** | この本のためにモデルへ送られたもの（毎回のプロンプト全体）と返ってきたもの、そしてリクエストの回数。 |
| **開いている時間** | 本を画面で開いていた時間。 |
| **編集中** | パートに入力していた時間。長い休止があると計測は止まります。 |
| **生成中** | モデルがこの本のために作業していた時間。 |
| **エージェント稼働** | エージェントがこの本に対して作業していた時間。 |
| **増加** | 期間中に本がどれだけ大きくなった（または小さくなった）かを単語数で表したもの。 |

時間は実際の時計で計測されます。2冊の本を同時に開いている場合や、3つのエージェントが一緒に動いている場合、合計はその時間帯を1回だけ数えるため、各本の行を足した値が合計を上回ることがあります（ウィンドウにもそう表示されます）。単語数とトークン数は足し合わせても一致します。

本やテキストのインポート（アーカイブ、SillyTavern からのチャット）、本の複製、バックアップの復元は、何も数えません。そのテキストはここで書かれたものではないからです。エージェントの作業は（**エージェント**として）エージェント側で集計されます。エージェントは本のコピーに対して働きますが、集計は元の本に対するものです。破棄された作業や、本に統合されなかった作業も含まれます。

<a id="the-tabs"></a>

## タブ

| タブ | |
|---|---|
| **日別** | 何かが記録された日ごとの行。上記のすべての数値が、新しい順に並びます。見出しをクリックすると並べ替えできます。 |
| **単語** | 日ごとの書いた単語数、生成した単語数、削除した単語数のグラフ。長い期間は週単位または月単位にまとめられます。 |
| **時間** | 開いている時間、編集中、生成中、エージェント稼働中の時間のグラフ。 |
| **トークン** | 送信トークン数と生成トークン数のグラフ。 |
| **サイズ** | 各日の終わりの本の大きさと、各日にどれだけ増えたか。**単語**または**トークン**で表示されます。 |
| **本**（すべての本） | 本ごとの行。[ごみ箱](../trash.md)にあるものや、消えてしまったものも含みます。フォルダー、数値、時間、増加量、そして全体に占める割合が表示されます。**削除した本も表示**を選ぶと、ごみ箱にあるものと消えたものを隠せます。本をクリックすると、その本が開きます。 |
| **本ごと**（すべての本） | 本を、**グラフの基準**で選んだ数値ごとに棒グラフで表示したもの。上位10冊が表示され、残りは*その他*として1本にまとめられます。 |
| **カレンダー** | 作業した日、連続日数、目標。下記を参照してください。 |

![日ごとの時間](../../images/statistics-time.png)

本の大きさは、変更の直後に、パートが保存した単語数とトークン数から計測されます。古いパートのトークンは、そのパートが書かれた時点で数えられた値です。そのため、本のモデルを変更しても、どの数値も変わりません。

<a id="the-calendar"></a>

## カレンダー

**カレンダー**タブには、過去1年間（53週、スマートフォンでは16週）の各日の小さなマス目が表示されます。1列が1週間で、最新の日は右下の隅に枠で示されます。マス目が濃いほど、その日の作業量が多いことを意味します。ポインターを日の上に置くと、日付、書いた単語数、編集した時間、そしてその日に最後に作業した時刻が表示されます（履歴から再構成された日の後には `~` が付きます）。

![すべての本のカレンダーと、その日の目標](../../images/statistics-global-calendar.png)

**作業した日**とは、単語を書いた、パートを編集した、パートを作成した、または編集に時間を費やした日を指します。エージェントの作業、生成されただけの単語、本を開いただけの操作は数えません。カレンダーが対象とするのは*あなた自身の*執筆だからです。空のマス目より少しだけ濃いマス目は、作業はしたものの、書いた量が少なかった日です。

マス目の濃淡は、**書いた単語数**または**編集**（編集時間の分数）で切り替えられます。カレンダーには、上の**期間**の選択にかかわらず、常に直近の数週間が表示されます。

カレンダーの上部には次の項目があります。

| | |
|---|---|
| **現在の連続日数** | 今日から遡って、連続して作業した日数。まだ作業していない今日は連続を途切れさせません。その場合、連続日数は昨日から数えられます。 |
| **最長の連続日数** | 全期間を通じて最も長く続いた連続日数。 |
| **作業した日数** | 表示されているマス目のうち、作業した日の数。 |
| **目標達成の連続日数**、**目標達成の最長連続日数** | 上の連続日数と同様ですが、1日の目標に達した日について数えます（目標を設定している場合。すべての本のウィンドウで設定します）。 |

<a id="the-daily-goal"></a>

### 1日の目標

**設定**タブの一般設定で目標を設定します。

| 項目 | |
|---|---|
| **1日の目標：書く単語数** | 1日に書く単語数（すべての本の合計）。モデルが生成した単語は数えません。 |
| **1日の目標：編集時間（分）** | 1日に編集する分数（すべての本の合計）。 |

![設定の目標](../../images/settings-daily-goal.png)

目標を設定しない場合は、項目を空のままにします。両方を設定した場合、1日が**両方**に達したときに目標達成となります。**すべての本**のウィンドウには、今日どこまで進んだかが2本の棒で表示されます（*今日: 500語中310語*）。カレンダーの濃淡は目標に従い（目標に達した日が最も濃くなります）、**目標達成の連続日数**は目標に達した日を数えます。目標を設定していない場合、濃淡はカレンダー上で最も作業量の多い日を基準にします。1冊の本のウィンドウには目標がありません（すべての本にとっての目標は、1冊の本にとってはあまり意味がないためです）。そのマス目の濃淡は、その本で最も作業量の多い日を基準にします。

記録された時間がない日（下記参照）がある場合、カレンダーの濃淡が**編集**で表示されているときは、その日は作業した日としてだけ印が付けられます。

![スマートフォンでのすべての本の統計](../../images/phone-statistics.png)

<a id="days-before-the-statistics"></a>

## 統計の前の日々

バージョン 1.6.0 より前は、統計は記録されていませんでした。Marginalia は更新時に、それ以前の日々をパートの履歴から再構成しました。パートの最初のバージョンは、その時点の単語を持って作成されたパートとして扱われ、その後のバージョンは編集、消えたパートは削除として扱われます。これらの日は推定値です。日の一覧では `~` で印が付けられ、ウィンドウには再構成された日の数が表示されます。再構成された日のトークン数は下限値にすぎません。**時間**は再構成できません。誰も記録していなかったからです。ウィンドウには、いつから時間が記録されているか（*時間は…から記録されています*）が表示され、それより前の日は時間を示す欄に「-」が表示されて、時間のグラフからは除かれます。**カレンダー**では、再構成された日も、ほかの日と同じように作業した日として数えられます。
<a id="privacy-clearing-not-recording-keeping-less"></a>

## プライバシー: 消去、記録の停止、保持期間の短縮

統計からは、いつ本に取り組んだか、どれだけの時間だったかがわかります。また、すべての本の名前とフォルダーを保持しており、削除した本についても同様です。これらはあなたのものであり、どこまで残すかはあなたが決めます。

![設定の執筆統計の記録と統計の保持期間](../../images/settings-statistics-privacy.png)

- **この本の統計を消去** (本のウィンドウにあるボタン) と **すべての統計を消去** (すべての本のウィンドウ) は、確認の後に、件数、時間、サイズを完全に削除します。本は変更されません。その後の集計はゼロから始まります。
- 本の一覧で、ゴミ箱にある本や消えた本には **忘れる** があり、これはその本の統計だけを削除します。
- [設定](../account.md)の **執筆統計を記録する** をオフにすると、あなたの本についての集計が止まります。すでに記録された分は、消去するまで残ります。ウィンドウには、新たに何も数えられていないことが表示されます。管理者はすべてのユーザーについて記録をオフにすることもでき、その場合も同じ注記が表示されます。
- 設定の **統計を保持する期間 (月)** では、それより古い日の記録が、1日に1回と保存時に削除されます。空欄または0の場合はすべて保持されます。管理者はすべてのユーザーに上限を設定でき、両方のうち短いほうが使われます。本のサイズについては、上限より前の最後の値が残されるので、保持される最初の日の増加量を引き続き計算できます。

[管理者](../administration/statistics.md)は、1人のユーザーの統計、またはすべてのユーザーの統計を消去できます。

<a id="commands"></a>

## コマンド

同じ数値を読み取る[コマンド](../commands/index.md)が2つあります。`/get-book-statistics [range] [side]` は開いている本を日別に表示し、`/get-statistics [range] [by] [side]` はすべての本を日別または本別に表示します。範囲には `today`、`yesterday`、`last-7-days`、`last-30-days`、`this-month`、`all-time`、1日 (`2026-03-14`)、または2日間 (`2026-03-01..2026-03-14`) を指定できます。[エージェント](../agents.md)もこれらを使用できます。
