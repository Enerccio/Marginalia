# 권한

권한은 모든 사용자에게 주어지지 않는 작업을 특정 사용자가 할 수 있도록 합니다. 관리자는 사용자마다 권한을 하나씩 부여합니다;
권한이 없는 사용자도 Marginalia의 다른 모든 기능을 평소처럼 사용할 수 있습니다(책 쓰기, 로어북 만들기, 관리자가 [공유](../inference-providers.md#shared-providers)한 모델 사용 등).

| 권한 | 허용하는 작업 | 설정 |
|---|---|---|
| **자체 모델 만들기** | [추론 제공자](../inference-providers.md) 추가: 이 권한이 없으면 사용자는 관리자가 공유한 제공자만 사용할 수 있습니다. 이미 가진 제공자는 계속 작동하며 여전히 편집할 수 있습니다. | |
| **도움말 어시스턴트** | 매뉴얼의 내용으로 답하는 채팅인 [도움말 어시스턴트](help-assistant.md)에 질문하기. | **제한 적용**과 **인터페이스 탐색 허용**, [권한의 설정](#settings-of-a-permission) 참고. |
| **에이전트** | (실험적 기능, [에이전트](../agents.md) 참고) [에이전트](../agents.md) 탭: 에이전트 만들기, 복제하기, 책에서 실행하기. | **최대 에이전트 수**, **동시 실행 수**, **모델에 동시에 보내는 요청 수 (실행당)**, **실행당 토큰 예산**과 복사본 및 파일 할당량, [권한의 설정](#settings-of-a-permission) 참고. |
| **버전 기록** | 사용자의 책에 대해 기록이 유지하는 [파트별 최대 버전 수](../books/version-history.md#how-many-versions-are-kept). 모든 사용자는 50개를 가집니다(행이 없는 사용자도 마찬가지). 권한이 부여되지 않은 경우 해당 사용자에게는 기록이 없습니다. | **파트별 보관 버전 수**. 폴더, 책, 사용자가 올릴 수 없는 상한입니다. 빈 값이면 여기서는 제한이 없습니다. 추가한 권한은 50에서 시작합니다. |
| **알림** | 에이전트가 사용자를 필요로 하는데 열린 화면이 없을 때 서버가 URL로 보내는 [메시지](../agents.md#when-you-are-not-there). 서버는 사용자가 입력한 주소를 호출하므로 이 권한은 별도의 권한입니다. 이 권한이 없으면 사용자 설정에 해당 필드가 나타나지 않으며 아무것도 전송되지 않습니다. | **이 컴퓨터와 사설 네트워크의 주소 허용**, [권한의 설정](#settings-of-a-permission) 참고. |

관리자는 항상 모든 권한을 가지므로 권한을 부여할 필요가 없습니다(관리자의 버튼과 섹션은 권한에 따라 달라지지 않습니다). 새 사용자는 권한이 없으므로 [사용자를 추가한](users.md#adding-a-user) 직후 필요한 권한을 부여하세요.

<a id="giving-and-taking-permissions"></a>

## 권한 부여와 회수

**관리자 → 사용자**에서 사용자 행의 열쇠 버튼을 누르면 해당 사용자의 권한이 열립니다:

![사용자의 권한](../../images/permissions-dialog.png)

이 창은 사용자가 가진 권한을 보여주는 표이며, 세 개의 열이 있습니다:

| 열 | |
|---|---|
| **이름** | 권한. 설정이 있는 권한은 이름 앞에 화살표가 있습니다([권한의 설정](#settings-of-a-permission) 참고). |
| **허용됨** | 권한이 작동하는지 여부. 허용되지 않은 권한은 없는 것과 같지만 설정은 그대로 유지되므로, 잠시 끄고 나중에 다시 켤 수 있습니다. |
| 휴지통 버튼 | 권한(및 설정)을 영구히 삭제합니다. |

권한을 부여하려면 표 위의 **권한 추가**를 누르고, 사용자가 가지고 있지 않은 권한 중 하나를 고르세요. 그 권한은 허용된 상태로 표에 추가됩니다. **저장**을 누르기 전까지는 아무것도 저장되지 않습니다:

![추가할 권한 선택](../../images/permissions-add.png)

- 저장할 것이 없으면 **저장**은 비활성화됩니다.
- **종료**는 창을 닫습니다. 저장되지 않은 변경 사항이 있으면 먼저 확인을 묻으므로, 변경 사항이 실수로 버려지는 일이 없습니다.
- 삭제한 권한은 저장하기 전까지 표에 남아 있으며, 저장하면 영구히 삭제됩니다. 그 전에 되돌리려면 저장하지 않고 **종료**로 창을 닫으세요.

저장한 뒤 사용자가 로그인해 있으면 해당 사용자의 페이지가 다시 로드되므로, 권한에 따라 달라지는 버튼과 섹션이 즉시 나타나거나 사라집니다. 본인의 권한을 바꾸더라도 본인의 페이지는 다시 로드되지 않습니다.

<a id="settings-of-a-permission"></a>

## 권한의 설정

일부 권한에는 전체 설치가 아니라 사용자에게 속하는 설정이 있습니다. 그런 권한의 행은 화살표로 시작합니다. 화살표를 누르면 설정이 펼쳐지고(창이 열릴 때는 접혀 있으며, 방금 추가한 권한은 펼쳐져 있습니다), 다시 누르면 접힙니다. 접기는 긴 목록을 짧게 보이게 하는 방법일 뿐이며, 아무것도 바꾸지 않고 저장되지 않은 변경으로 세지도 않습니다.

![도움말 어시스턴트 권한의 설정](../../images/permissions-settings.png)

**도움말 어시스턴트**, **에이전트**, **알림**에 설정이 있습니다. 도움말 어시스턴트의 설정은 다음과 같습니다:

| 설정 | |
|---|---|
| **제한 적용** | 공유 모델의 경우 사용자의 질문이 다른 요청과 마찬가지로 사용자의 한도와 사용량에 포함되는지 여부. [누가 비용을 내는가](help-assistant.md#who-pays) 참고. 기본값은 꺼짐입니다. |
| **인터페이스 탐색 허용** | 사용자가 길을 보여 달라고 요청할 때, 어시스턴트가 섹션을 열고, 탭을 선택하고, 무언가를 추가하는 대화 상자를 열 수 있게 합니다. [길 안내](help-assistant.md#showing-the-way) 참고. 기본값은 꺼짐입니다. |

에이전트의 설정은 다음과 같습니다. 빈 필드는 기본값입니다:

| 설정 | |
|---|---|
| **최대 에이전트 수** | 사용자가 가질 수 있는 에이전트 수(에이전트의 복제본 포함). 비어 있으면 5개입니다. 0이면 사용자가 에이전트를 보관하고 실행할 수는 있지만 새로 만들거나 복제할 수는 없습니다. 삭제된 에이전트는 자리를 비웁니다. |
| **동시 실행 수** | 사용자의 실행 중 동시에 작업할 수 있는 수. 비어 있으면 1입니다. |
| **모델에 동시에 보내는 요청 수 (실행당)** | 하나의 실행이 동시에 처리 중일 수 있는 모델 요청 수. 에이전트와 [하위 에이전트](../agents.md#sub-agents)를 합친 값입니다. 비어 있으면 1입니다. 하위 에이전트가 모델에 요청하는 동안 에이전트는 기다리고, 그 반대도 마찬가지입니다. 더 크게 설정하면 하위 에이전트가 에이전트와 병렬로 작업할 수 있습니다(에이전트의 모델에도 자체 [요청 상한](../inference-providers.md#general-settings)이 있다면 그것도 함께 적용됩니다). |
| **실행당 토큰 예산** | 사용자의 실행 한 번이 쓸 수 있는 최대 토큰 수(보내고 생성한 토큰 모두 포함). 비어 있거나 0이면 제한이 없습니다. |
| **작업 사본** | 사용자의 실행이 동시에 유지할 수 있는 책의 작업 사본 수. 끝나지 않은 실행은 일시 정지된 경우에도 사본을 유지하며, 끝나거나 중지되거나 삭제되면 사본을 반환합니다. 비어 있거나 0이면 에이전트 수 외에는 제한이 없습니다. |
| **최대 파일 크기 (KB)** | 사용자의 에이전트가 작업 공간에 쓸 수 있는 가장 큰 파일. 비어 있으면 1024(1 MB)입니다. |
| **작업 공간 크기 (MB)** | 사용자의 에이전트 하나의 작업 공간에 있는 모든 파일이 차지할 수 있는 용량. 비어 있으면 20입니다. |
| **작업 공간의 파일 수** | 사용자의 에이전트 하나의 작업 공간이 가질 수 있는 파일 수. 폴더는 세지 않습니다. 비어 있으면 500입니다. |
| **실행의 체크포인트 (MB)** | 한 실행의 모든 [체크포인트](../agents.md#checkpoints)(작업 사본과 그 작업 공간의 복원 지점)가 차지할 수 있는 용량. 일부는 자동 체크포인트를 위해 남겨 둡니다. 비어 있으면 100입니다. |

![에이전트 권한의 설정](../../images/permissions-settings-agents.png)

알림의 설정은 다음과 같습니다:

| 설정 | |
|---|---|
| **이 컴퓨터와 사설 네트워크의 주소 허용** | 하위 권한입니다. **알림** 권한이 부여된 동안에만 체크할 수 있습니다(그렇지 않으면 회색으로 비활성화되며, 권한을 회수하면 체크도 해제됩니다). 이 설정이 없으면 인터넷상의 주소만 호출됩니다. `localhost`, 사설 네트워크(`10.x.x.x`, `172.16-31.x.x`, `192.168.x.x`), 링크 로컬 또는 공유 주소(`169.254.x.x`, 클라우드 호스트가 메타데이터 서비스를 두는 곳, `100.64-127.x.x`), IPv6의 고유 로컬 주소는 호출되지 않습니다. ntfy나 Gotify가 같은 컴퓨터나 본인의 네트워크에서 실행되는 사용자에게만 체크하세요. 기본값은 꺼짐입니다. 이름은 그 이름이 해석되는 주소로 확인하므로, 사설 주소를 가리키는 이름은 물론 찾을 수 없는 이름도 거부됩니다. |

관리자는 권한과 하위 권한이 모두 필요 없습니다. 관리자는 메시지를 받을 수 있고 로컬 주소를 사용할 수 있습니다. 완전히 신뢰하지 않는 사람들과 공유하는 서버에서는 이 하위 권한을 끄세요. 그렇지 않으면 서버가 사용자가 입력한 어떤 주소로든, 여러분의 네트워크 안에서도 요청을 보내게 됩니다.

<a id="when-permissions-were-introduced"></a>

## 권한이 도입된 시기

권한이 도입되기 전에는 **사용자가 자신의 모델을 만들 수 있음**과 도움말 어시스턴트의 **사용** 스위치(**제한 적용**, **인터페이스 탐색 허용**과 함께)가 전체 설치의 설정이었습니다. Marginalia는 업데이트 때 이것들을 권한으로 옮겼습니다. 당시 존재하던 모든 사용자는, 누구나 모델을 만들 수 있었다면(기본값) **자체 모델 만들기**를, 어시스턴트가 켜져 있었다면 같은 두 설정과 함께 **도움말 어시스턴트**를 받았습니다. 여러분이 바꾸기 전까지 이 사용자들에게는 아무것도 달라지지 않으며, 지금부터 추가하는 사용자는 권한이 없는 상태로 시작합니다.
