# 책 내보내기

내보내기는 이야기를 읽거나, 인쇄하거나, 보내거나, 다른 곳에 발행할 수 있는 파일로 바꿔 줍니다. [백업](backups.md)과 달리 내보내기 파일에는 텍스트만, 완성된 책의 형태로 담깁니다.

내보내기에는 [활성 분기](branches-and-story-tree.md)만 포함되며, 이는 이야기 편집기에 표시되는 부분과 같습니다. 다른 버전의 이야기를 내보내려면 먼저 그 분기로 전환하세요.

<a id="exporting"></a>

## 내보내기

1. 책을 열고 **이야기** 탭으로 이동합니다.
2. 하단 막대의 설정 메뉴(⚙)를 열고 **이야기 내보내기**를 선택합니다.
3. 대화상자를 작성하고 **내보내기**를 선택합니다.
4. Marginalia가 분기의 부분들을 모아 파일을 쓰며, 긴 책이라면 잠시 걸립니다. 진행 막대에 진행 상황이 표시됩니다.
5. 파일이 준비되면 다운로드를 제안하는 대화상자가 나타납니다. 저장하려면 **다운로드** 버튼을 선택합니다.

![이야기 내보내기 대화상자](../../images/export-dialog.png)

| 필드 | |
|---|---|
| **형식** | 파일 종류입니다. 아래를 참고하세요. |
| **인쇄 스타일** | 글꼴과 색상이 있는 형식(HTML, Word, PDF, EPUB)에서만 쓸 수 있습니다. 텍스트의 모양이며, *내보내기용* 스타일 중에서 고릅니다. 애플리케이션은 이 형식마다 하나씩, 즉 **HTML 페이지**, **전자책 (EPUB)**, **PDF 책**, **Word 문서**를 기본으로 제공하며, 이는 내보내기가 항상 가졌던 모양이고 형식을 고르면 자동으로 선택됩니다. 직접 스타일을 만들 수도 있습니다. [인쇄 스타일](#print-styles)을 참고하세요. [설정 → 내보내기](../account.md#exports)에서 해당 형식에 지정한 스타일이 미리 선택되어 있습니다. |
| **파일 이름** | 확장자를 뺀 다운로드 파일의 이름입니다. 확장자는 Marginalia가 붙입니다. 처음에는 책의 이름이 들어 있습니다. |
| **책 제목** | 파일 안의 제목입니다(표지 페이지와 파일 속성). 처음에는 책의 이름이 들어 있으며, 여기서 바꿔도 책의 이름이 바뀌지는 않습니다. |
| **저자** | [계정](../account.md)에 적은 전체 이름이 처음에 들어 있습니다. 비워 두면 저자가 없는 것으로 처리됩니다. |
| **시작 메시지**, **끝 메시지** | 내보낼 부분의 범위입니다. 부분은 이야기 순서대로 1부터 세며, 텍스트가 없는 부분은 세지 않습니다. **끝 메시지**를 비워 두면 끝까지 내보냅니다. |
| **표지 페이지 포함** | 파일 첫 페이지에 제목과 저자를 담은 표지를 넣습니다. |
| **저작 표시 포함** | 파일 끝에 누가 글을 썼는지 짧게 밝히는 문구를 넣습니다. 직접 쓴 단어 수와 모델이 생성한 단어 수를 단어와 백분율로 적고, 사용한 모델도 함께 표기합니다. 일부 출판사와 공모전은 이를 요구합니다. 내보낸 부분의 [버전 기록](version-history.md)을 바탕으로 계산합니다([생성된 텍스트 강조](story-editor.md#highlighting-generated-text) 참고). SillyTavern 채팅에서는 제공하지 않습니다. 문구의 형식은 [설정 → 내보내기](../account.md#exports)에서 바꿀 수 있는 템플릿입니다. |

## 형식

| 형식 | |
|---|---|
| **일반 텍스트** (`.txt`) | UTF-8 인코딩의 순수 텍스트입니다. *기울임* 같은 서식은 사라지고, 문단은 빈 줄로 구분됩니다. |
| **Markdown** (`.md`) | 이야기에 적힌 그대로의 텍스트로, Obsidian이나 Typora 같은 편집기, 정적 사이트, 저장소에서 쓰기 좋습니다. 강조, 제목, 인용, 목록, 코드 블록, 장면 구분선이 Markdown 형태로 유지됩니다. 텍스트에 있는 원시 HTML은 입력된 그대로 남으며, 보여 줄지는 Markdown 뷰어가 결정합니다. |
| **HTML** (`.html`) | 책처럼 보이는 스타일이 포함된 한 페이지짜리 문서입니다. 어떤 브라우저에서도 같은 모습으로 보입니다. 인쇄할 수 있으며 외부 파일에 의존하지 않습니다. |
| **Word 문서** (`.docx`) | Word, LibreOffice 등 비슷한 프로그램에서 열립니다. 양쪽 맞춤 텍스트이며, 제목과 저자는 파일 속성에 설정됩니다. |
| **PDF** (`.pdf`) | 라틴, 그리스, 키릴 문자를 포함하는 내장 글꼴을 쓴 A5 페이지이며, 가나, 한자, 일본어 문장부호를 위해 Noto Sans JP 일본어 글꼴이 함께 들어 있습니다. 다른 문자(중국어 전용 한자, 한국어, 아랍어)의 텍스트는 그려지지 않습니다. PDF에 해당 글꼴이 없기 때문입니다. |
| **EPUB** (`.epub`) | 전자책 리더와 독서 앱을 위한 전자책입니다. 긴 책은 독자가 빠르게 읽을 수 있도록 EPUB 안에서 여러 파일로 나뉩니다. |
| **Archive of Our Own용 HTML** (`.html`) | AO3에 올리기 위한 형식입니다. [아래](#for-other-tools)를 참고하세요. |
| **front matter가 있는 Markdown** (`.md`) | 정적 사이트 생성기용입니다. [아래](#for-other-tools)를 참고하세요. |
| **SillyTavern 채팅** (`.jsonl`) | 이야기를 채팅으로 만든 형식입니다. [아래](#for-other-tools)를 참고하세요. |
| **Obsidian 보관소** (`.zip`) | 장과 로어북을 서로 연결된 노트로 만든 형식입니다. [아래](#for-other-tools)를 참고하세요. |
| **LaTeX** (`.zip`) | 책의 LaTeX 프로젝트(`main.tex`와 이미지)입니다. [아래](#for-other-tools)를 참고하세요. |

부분의 텍스트는 Markdown입니다. 강조, 제목, 인용, 목록, 코드 블록, 장면 구분선(`---`)은 이를 표시할 수 있는 모든 형식에서 유지됩니다. 텍스트에 있는 원시 HTML은 텍스트로 표시되며, 실행되는 일은 결코 없습니다.

## 각주

각주는 부분의 텍스트에서 표시가 들어갈 자리에 `[^1]`로 적고, 별도의 줄에 `[^1]: 주석 내용`으로 적습니다(라벨은 아무 단어나 가능합니다). 모든 형식에서 각주를 지원합니다. **Markdown**은 문법을 그대로 유지하고, **HTML**, **EPUB**, **Archive of Our Own용 HTML**은 작은 위첨자 번호를 넣어 부분의 텍스트 아래에 있는 주석과 연결합니다(AO3에는 편집기가 유지하는 일반 마크업이 들어갑니다). **일반 텍스트**는 표시를 `[1]`로 쓰고, 주석은 부분의 텍스트 뒤에 `[1]`로 시작하는 줄로 적습니다. 이는 미주가 보이는 방식과 같습니다. **Word**와 **PDF**에는 실제 각주가 있습니다. 표시는 작은 위첨자 번호이고, 주석은 같은 페이지 하단에 더 작은 글씨로 놓입니다(PDF에서는 짧은 선 아래에 놓이며, 각 페이지가 주석에 필요한 공간을 확보할 때까지 페이지를 배치합니다. Word는 주석의 번호와 위치를 직접 정하므로, 문서를 편집하면 함께 따라 바뀝니다). 확장 기능도 각주를 쓸 수 있습니다. 예를 들어 Conlang Translator 확장 기능은 각 대사의 영어 번역을 각주로 씁니다.

## 이미지

부분의 [이미지](story-editor.md#images)는 지정된 위치에 배치되며(다른 위치를 고르지 않았다면 텍스트 뒤), 캡션과 함께, 지정한 너비로 들어갑니다(텍스트 폭의 백분율입니다. 너비를 지정하지 않으면 이미지는 원래 크기를 유지하되 페이지에 맞게 축소됩니다). 모든 형식이 이미지 옆에 텍스트를 배치할 수 있는 것은 아닙니다:

| 형식 | |
|---|---|
| **HTML**, **EPUB** | 내장됩니다(페이지 안에 넣거나 책의 파일로 넣습니다). 텍스트는 이미지의 왼쪽이나 오른쪽을 따라 흐르며, 가운데에 있는 이미지는 두 단 사이에 놓입니다. 좁은 화면에서는 이미지가 텍스트 위로 올라가며, 단을 지원하지 않는 리더(일부 전자책 단말기)에서는 첫 텍스트, 이미지, 나머지 텍스트가 차례로 이어서 표시됩니다. 같은 위치에 나란히 있는 이미지는 한 줄로 배열됩니다. |
| **Word 문서** | 텍스트가 감싸고 흐르는 이미지는 작은 표 안에 들어가며, Word가 이를 측면 또는 가운데에 배치하고 텍스트는 그 주위를 감쌉니다(가운데에 있으면 양쪽, 줄 단위로). 캡션은 이미지 아래에 놓입니다. 너비가 맞아 나란히 들어갈 수 있는 이미지는 표의 한 행을 이룹니다. |
| **PDF** | 텍스트는 이미지의 측면을 따라 흐르며, 캡션은 이미지 아래에 그려집니다. 가운데에 있는 이미지는 왼쪽 정렬된 두 단 사이에 놓입니다(페이지 끝에 맞지 않는 띠는 다음 페이지로 넘어갑니다). 너비가 맞아 나란히 들어갈 수 있는 이미지는 한 줄을 이룹니다. 페이지의 남은 공간보다 높은 이미지는 다음 페이지로 넘어갑니다. |
| **Markdown** | `![캡션](data:...)` 형태의 이미지로 파일 안에 내장되며, 그 아래에 기울임꼴 캡션이 붙습니다. 그래서 여전히 파일 하나로 유지됩니다. 텍스트 속 위치는 유지되지만, 너비와 텍스트 흐름은 유지되지 않습니다. 내장 이미지를 표시하지 않는 뷰어도 있으며(GitHub가 그렇습니다), 이미지가 많은 책은 줄이 매우 길어지므로, Markdown으로 내보낼 때만 부분에 이미지를 첨부하세요. |
| **일반 텍스트** | 텍스트 속 위치에 `[Image]` 또는 `[Image: 캡션]`으로 표시됩니다. |
| **Archive of Our Own용 HTML** | `[Image: 캡션]`으로 표시됩니다. AO3는 링크로 연결된 이미지만 받아들이기 때문입니다. |
| **Obsidian 보관소** | 보관소의 `Attachments` 폴더에 저장되고, 해당 장의 노트 안에 위치에 맞게 내장되며, 캡션은 기울임꼴로 표시됩니다. |
| **LaTeX** | 프로젝트의 `images` 폴더에 저장되고, 위치에 맞게 텍스트에 포함됩니다(이미지 너비에 맞는 그림이며, 텍스트 폭을 넘지 않습니다). 캡션은 그 아래에 놓입니다. 텍스트는 이미지 주위를 감싸지 않습니다. |
| **SillyTavern 채팅** | 채팅에는 텍스트만 있으므로 제외됩니다. |

## 다른 도구용 형식

이 형식들은 읽는 용도가 아니라 다른 도구가 읽도록 만들어졌습니다. *인쇄 스타일* 선택지가 없습니다.

**Archive of Our Own용 HTML.** AO3는 제목, 작가, 챕터 제목을 자체 입력란에 받으며, 자신이 모르는 것(스타일 블록, 본문을 감싸는 페이지, 링크가 아닌 이미지)은 버리므로 이 파일에는 표지 페이지가 없습니다. 붙여넣었을 때 어떻게 보일지 보려면 브라우저에서 여세요. 모든 챕터(제목으로 시작하는 부분과 다음 제목 전까지의 부분)는 제목 위에 두 개의 주석 `BEGIN chapter N`과 `END chapter N`을 갖습니다. 두 주석 사이의 내용을 AO3에서 해당 챕터의 HTML 편집기에 복사하고, 제목은 제목 입력란에 넣으세요. 텍스트는 태그 사이에 줄바꿈이 없는 깨끗한 HTML입니다. AO3는 줄바꿈 하나하나를 `<br>`로 바꾸기 때문입니다.

**front matter가 있는 Markdown.** *Markdown* 형식과 같은 Markdown이지만, 파일은 표지 페이지 대신 Jekyll, Hugo, Eleventy 같은 생성기가 읽는 YAML 블록(`title`, `author`, `lang`, 내보내기 날짜 `date`)으로 시작합니다. **표지 페이지 포함**은 이 형식에 영향을 주지 않습니다. 이 블록은 [설정 → 내보내기](../account.md#exports)에서 바꿀 수 있는 템플릿입니다(`{{title}}`, `{{author}}`, `{{language}}`, `{{exportDate}}`; 제목과 작가는 이미 큰따옴표 안에서 쓸 수 있도록 이스케이프되어 있습니다).

**SillyTavern 채팅.** SillyTavern의 채팅 가져오기가 읽는 JSON Lines 파일입니다. 캐릭터의 이름은 책 제목이고, 작성자는 당신입니다. 이야기의 각 부분은 캐릭터의 메시지(본문)가 되며, 그 부분이 지시문과 함께 작성되었다면 지시문은 당신의 메시지로서 본문 앞에 옵니다. 모델의 추론이 있는 부분이라면 그 추론은 메시지의 추론으로 보존됩니다. 표지 페이지는 적용되지 않습니다.

**Obsidian 볼트.** 책 이름의 폴더가 들어 있는 ZIP입니다. 압축을 풀고 폴더를 볼트로 여세요. 책 이름의 노트(front matter, 표지 페이지, 챕터 목록과 설정 목록)가 있고, `Chapters`에는 챕터마다 노트가 있으며(이전 챕터와 다음 챕터로의 링크 포함), `Lore/<lorebook>`에는 책의 [로어북](../lorebooks/index.md)과 그 하위 로어북에서 활성화된 항목마다 노트가 있습니다(항목의 태그는 노트의 태그가 되고, 항목의 주석은 콜아웃이 됩니다). 이미지는 `Attachments`에 있습니다. 모든 노트에서 항목 이름이 처음 언급되는 곳(세 글자 이상이고 온전한 단어이며 적힌 철자 그대로인 이름)은 그 항목 노트로 가는 링크이므로, 그래프 보기에서 어떤 항목이 어느 챕터에 나오는지 볼 수 있습니다. 제목이 있는 부분은 챕터를 시작하고, 첫 제목 앞의 부분은 *Beginning* 노트(책에 제목이 없으면 *Story* 노트)가 됩니다. front matter와 표지 페이지는 [설정 → 내보내기](../account.md#exports)에서 바꿀 수 있는 템플릿입니다.

**LaTeX.** 책 이름의 폴더가 들어 있는 ZIP입니다. `main.tex`는 `pdflatex`, `xelatex` 또는 `lualatex`로 컴파일되는 `book`이며, 각 부분의 이미지는 `images`에 있습니다. 표지 페이지는 [표지 페이지 템플릿](../account.md#exports)으로 만든 `titlepage`입니다. 이야기에서 가장 얕은 제목은 챕터가 되고, 그다음 단계는 절(section)이 되며, 이런 식으로 이어집니다. 번호는 붙지 않지만(이야기가 챕터 이름을 직접 정합니다) 목차에는 나열됩니다. 강조, 인용, 목록, 코드 블록과 장면 구분은 LaTeX에서 그에 맞는 모양이 되고, 각주는 실제 각주가 됩니다. LaTeX에 의미가 있는 문자는 글자로 적히며, 책의 언어가 흔한 언어 중 하나이면 그 언어의 하이픈 규칙(`babel`)이 선택됩니다. 일본어, 중국어 또는 한국어 텍스트가 있는 책에는 `xelatex` 또는 `lualatex`가 필요합니다(`pdflatex`는 메시지를 내고 멈춥니다). 파일은 이를 위해 `xeCJK` 또는 `luatexja`를 불러오며, `xelatex`에서는 당신의 글자가 들어 있는 글꼴을 지정하세요(바꿔야 할 줄은 바로 위 주석에 있습니다. 예: `\setCJKmainfont{Noto Serif CJK JP}`). 그렇지 않으면 `xeCJK`에 딸린 중국어 글꼴만 쓰입니다. ZIP을 [Overleaf](https://www.overleaf.com)에 올리거나 압축을 풀고 `pdflatex main.tex`를 실행하세요(목차를 위해 두 번). 인쇄 스타일은 적용되지 않습니다. 모양은 클래스의 것이며, 바꾸려면 `main.tex`의 프리앰블을 고치세요.

<a id="print-styles"></a>

## 인쇄 스타일

내보내기는 [설정 → 스타일](../account.md#styles)의 텍스트 스타일 중 **내보내기용**으로 표시된 것을 사용합니다. 스타일은 책용(이야기와 독자용)이거나 내보내기용입니다. *텍스트 스타일 변경* 메뉴와 독자 화면은 첫 번째 종류만, 내보내기 대화상자는 두 번째 종류만 보여 줍니다. 기본 제공되는 네 가지는 형식들의 모양이며, 예를 들어 종이용 책 스타일처럼 나만의 스타일을 만들려면 (책 스타일이나 책 스타일 하나를) **복제**하고 **내보내기용**을 선택하세요. 스타일은 종이를 기준으로 만들어집니다. 응용 프로그램의 테마에 따라 달라지는 색(어두운 테마의 밝은 글자)은 흰 종이에 맞는 어두운 색이 됩니다.

| 형식 | 스타일이 주는 것 |
|---|---|
| **HTML** | 사용자 지정 CSS, **드롭 캡**, 텍스트 너비와 배경을 포함한 스타일의 스타일시트 전체. 표지 페이지와 목차는 형식의 모양을 유지합니다. |
| **EPUB** | 사용자 지정 CSS를 뺀 스타일의 스타일시트(전자책 리더가 모두 이해하지는 못하며, 일부 리더는 자체 글꼴과 크기를 설정합니다). |
| **PDF** | 글꼴 모음(글꼴 스택에서 고른 내장 글꼴의 세리프, 산세리프 또는 고정폭 계열), 크기, 줄 간격, 정렬, 문단 사이 간격, 첫 줄 들여쓰기, 페이지의 **배경색**(표지 페이지를 포함한 전체 페이지), 본문, 기울임꼴, 굵은 글씨, 인용, 제목과 장면 구분의 색, 제목의 정렬과 크기, 장면 구분 기호. |
| **Word 문서** | PDF와 같지만, 내장 글꼴 대신 스타일에 지정된 글꼴을 사용합니다(컴퓨터에 그 글꼴이 없으면 Word가 자체 글꼴을 보여 줍니다). 배경은 페이지의 색입니다. Word는 화면에는 보여 주지만, 인쇄 옵션에서 *배경색과 이미지 인쇄*를 켜지 않으면 인쇄하지 않습니다. |

드롭 캡, 사용자 지정 CSS(PDF, Word, EPUB), 제목의 작은 대문자와 텍스트 너비는 PDF와 Word 파일에서 만들어지지 않습니다.

<a id="title-page-template"></a>

## 표지 페이지 템플릿

표지 페이지는 템플릿에서 만들어지며, 형식마다 하나씩 있습니다. [설정 → 내보내기](../account.md#exports)에서 바꾸세요. 템플릿은 `{{title}}`(대화상자의 책 제목)과 `{{author}}`를 쓰는 Markdown입니다. 예를 들어 `## {{title}}`과 `written by {{author}}`라는 줄입니다. 기본값은 제목을 제목 글머리로, 작가를 기울임꼴로 쓰는 것입니다.

같은 템플릿(표지 페이지, front matter, 저작 진술)은 **책 하나 또는 폴더 단위로** 바꿀 수 있습니다. 책의 *프롬프트* 탭과 폴더 창에서 **확장 기능 설정**에는 내보내기 형식마다 패널이 있고, 각 템플릿마다 입력란이 있습니다. 책 자체의 버전이 먼저 쓰이고, 없으면 그 위의 가장 가까운 폴더의 것, 없으면 *설정 → 내보내기*의 당신의 것, 없으면 기본값이 쓰입니다. 시리즈가 자체 표지 페이지를 가질 수 있는 이유입니다. 빈 입력란은 상속되며, 어디에서 왔는지 표시됩니다.
<a id="table-of-contents"></a>

## 목차

텍스트에 장(chapter)이 있으면 제목 페이지 뒤에 목차가 들어갑니다. 장이란 Markdown 제목(줄 첫머리가 `#`로 시작하는 줄, 예: `# Chapter 3: The Harbour`)이 있는 이야기의 한 부분을 말하며, 이는 이야기 사이드바에서 [Chapter Marker](../extensions/chapter-marker.md) 플러그인이 사용하는 규칙과 같습니다. 부분의 첫 번째 제목이 그 부분의 제목이 되며, 제목이 없는 부분은 바로 앞의 장에 속합니다. 제목이 하나도 없는 이야기에는 목차가 없습니다.

![내보낸 PDF의 제목 페이지와 목차](../../images/export-result.png)

PDF, Word, EPUB에서는 모든 장이 새 페이지에서 시작합니다. 제목 페이지와 목차도 각각 별도의 페이지입니다.

목차 항목은 장으로 연결되는 링크입니다.

| 형식 | |
|---|---|
| **HTML** | 페이지의 장으로 연결되는 링크입니다. |
| **PDF** | 장의 페이지 번호가 함께 표시된 클릭 가능한 항목이며, 장은 PDF 리더가 페이지 옆에 보여 주는 개요(책갈피)에도 나타납니다. |
| **EPUB** | 리더의 목차이며, 제목 페이지 뒤에 오는 책의 한 페이지이기도 합니다. |
| **Word 문서** (`.docx`) | 장의 페이지 번호가 함께 표시된 클릭 가능한 항목입니다. Word는 파일을 열 때 필드를 업데이트할지 묻는데, 페이지 번호를 채우려면 **예**를 선택하십시오(LibreOffice는 자동으로 채웁니다). Word의 목차 필드가 아니라 링크 목록입니다. |
| **Markdown** | 목차가 없습니다. 장 제목은 본문에 그대로 남으며, 대부분의 Markdown 편집기는 이 제목으로 개요를 만듭니다. |
| **일반 텍스트** | 목차가 없습니다. |

<a id="page-numbers"></a>

## 페이지 번호

PDF와 Word 파일은 제목 페이지를 제외한 모든 페이지의 바닥글에 페이지 번호가 있습니다. 번호는 파일 안에서 페이지가 놓인 위치이므로, 제목 페이지가 1페이지이고 그 뒤의 첫 페이지는 2페이지입니다. 다른 형식에는 고유한 페이지가 없습니다.

<a id="the-title-page"></a>

## 제목 페이지

**표지 페이지 포함**을 선택하면 파일 맨 앞에 책 제목과 저자가 들어간 별도의 페이지가 놓입니다. 이 페이지는 내장 템플릿(`DEFAULT_EXPORT_HEADER_TEMPLATE`)으로 만들어지며, 현재 애플리케이션에서는 편집할 수 없습니다.

<a id="good-to-know"></a>

## 알아두면 좋은 점

- 내보내기는 **내보내기**를 선택하는 순간의 분기를 그대로 찍은 스냅숏입니다. 그 이후에 생성하거나 편집한 부분은 파일에 들어가지 않습니다.
- 내보낸 파일은 다운로드 대화상자를 닫을 때까지만 보관됩니다. 나중에 필요하면 다시 내보내십시오.
- 요약, 로어북, 지시문, 모델의 추론 과정은 내보내지 않으며, 부분의 텍스트와 이미지만 내보냅니다. 이 모든 것을 저장하려면 [백업](backups.md)을 만드십시오.
