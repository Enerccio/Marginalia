# 文件夹

文件夹像磁盘上的文件夹管理文件一样整理你的书籍。一个文件夹可以放书籍和其他文件夹，层级不限，而书籍列表每次只显示一个文件夹的内容。文件夹还可以保存**设置**（语言、视角、时态、风格、模板和提示词）：其中的书籍，以及下层文件夹中的书籍，在没有各自设置的情况下，都会使用这些设置进行写作。这也是使用文件夹的主要原因：为一个系列设置一次风格，系列中的每本书都会使用它。

![带有文件夹的 Books 标签页](../../images/books-folders.png)

<a id="moving-around"></a>

## 浏览文件夹

书籍列表上方会显示当前文件夹中的子文件夹，顺序与所排序的列一致。点击文件夹的**名称**即可打开它。列表上方的按钮路径（`Books / Sci-fi / Expanse`）显示你当前所在的位置；点击其中任意一部分即可返回该位置。

复选框 **Include subfolders** 会列出当前文件夹下任意深度的所有书籍（在顶层时即为你的全部书籍），并添加一列 **Folder**，显示每本书所在的位置。当前文件夹和该复选框的状态会被记住，即使重新加载页面也是如此。

文件夹行会显示其下任意深度的书籍数量。书籍行会显示其[当前分支](branches-and-story-tree.md)的字数和 token 数。**Name** 和 **Tags** 筛选器对文件夹和书籍同样有效（文件夹也有标签，参见[为文件夹添加标签](#tagging-folders)），可作用于当前文件夹，或在勾选 *Include subfolders* 时作用于其下的所有内容。

文件夹的 **Last Modified** 跟随其中的书籍：当其中某本书，或下层文件夹中的某本书（或其某个部分）发生变化时，该文件夹也会随之更新。按此列排序，可以看到你最近在哪里写作。打开或移动书籍不算作修改。

<a id="what-the-buttons-do"></a>

### 按钮的作用

| 按钮 | |
|---|---|
| **New folder**（标题栏） | 在当前文件夹中新建一个文件夹。名称不能为空，不能超过 255 个字符，不能包含 `/`，并且同一位置不能已有同名文件夹（不区分大小写）。 |
| 文件夹的齿轮图标 | [文件夹的设置](#folder-settings)。 |
| 文件夹的铅笔图标 | 重命名该文件夹。 |
| 文件夹的垃圾桶图标 | 删除该文件夹，参见[删除文件夹](#deleting-a-folder)。 |
| **Move to folder**（书籍） | 选择要将该书籍移入的文件夹。 |
| 书籍的星标 | 将其设为[收藏](#favorites)。 |
| **Add Book**、各种导入 | 新书会放入**当前文件夹**。[克隆](managing-books.md#cloning-a-book)的书会放在原书旁边。 |

<a id="folder-settings"></a>

## 文件夹设置

点击文件夹的齿轮图标可打开其设置（**Organise** 窗口中有相同的按钮，快捷键为 `i`）：

![文件夹的设置](../../images/folder-settings.png)

- **Name**、**Description** 和 **Tags**。
- **Language**，以及书籍的 [Prompts](prompts.md) 标签页中的相同字段：主模板、视角、时态、风格和提示词。
- **Versions kept per part**：[历史记录](version-history.md#how-many-versions-are-kept)为该文件夹及其下层文件夹中的书籍保留每个部分的早期版本数量。在上述所有限制中，对某本书生效的是最严格的那一个。
- **Extension Settings**：当已加载的[扩展](../extensions/index.md)有可供书籍继承的设置时显示，参见[扩展的设置](prompts.md#settings-of-extensions)。

所有设置都是可选的。空字段表示*继承*，并会说明来源：字段中的灰色文字是它所继承的值，其下方的一行说明该值来自何处。点击 **Save** 保存文件夹。名称和描述随时可以修改，但如果该文件夹或其下层文件夹中的某本书正有智能体在运行，则拒绝修改语言或文本设置。提示信息会注明该书的名称，请先[暂停或停止其运行](../agents.md)。

<a id="where-the-settings-of-a-book-come-from"></a>

### 书籍设置的来源

对于每一项设置，书籍会使用以下列表中第一个非空的值：

1. **书籍**本身（其 *About* 和 *Prompts* 标签页）；
2. 书籍所在的**文件夹**；
3. 该文件夹的上一级文件夹，依此类推，直至顶层；
4. 你的**用户设置**（*Settings → Templates*，参见[账户与设置](../account.md)）；
5. 内置默认值。

空白文本视为未设置。这些值在需要时才会查找（生成某个部分、制作摘要、重写某个部分等时），将书籍放入文件夹时并不会把设置复制到书籍中。因此，**将书籍移到另一个文件夹会改变它的写作方式**，而修改某个文件夹的设置，会影响其下所有未设置自身值的书籍。

书籍的 [Prompts](prompts.md#inherited-settings) 标签页会显示这一来源：每个字段下方都会标明其值的来源（*Inherited from the folder "Sci-fi"*、*Inherited from your settings* 或 *Built-in default*）。

<a id="language"></a>

### 语言

书籍（[About](managing-books.md#the-about-tab) 标签页）和文件夹中的 **Language** 框可以留空，表示*继承*：书籍会采用其上方最近的、设置了语言的文件夹的语言，若都未设置则使用英语。空框会显示当前生效的语言及其来源。该框带有清除按钮，清除后即恢复继承（以前清除后会变为英语）。书籍的语言会统一用于所有显示或使用语言的地方，包括文本的连字符处理、导出，以及[批量更改语言](#mass-changes)表格。

<a id="deleting-a-folder"></a>

## 删除文件夹

点击文件夹的垃圾桶按钮时，系统会询问如何处理：

- **空文件夹**会在确认后被删除；
- **含有书籍或文件夹的文件夹**会提供 **Move its content to the folder above**（默认）或 **Delete everything in it as well**。后者会再次询问，并显示书籍和文件夹的数量，同时将书籍移入[回收站](../trash.md)，你可以从那里恢复它们。被删除的文件夹本身不会出现在回收站中。

如果内部某个文件夹与上一级文件夹中的文件夹同名，则拒绝将内容上移（名称必须唯一）：请先重命名其中一个。若文件夹中有智能体正在处理的书籍，则该文件夹不能被删除或移动，因为这会在运行过程中改变该书的设置。
<a id="organise"></a>

## 整理

**整理**（列表标题栏的 **管理** 菜单中）会打开一个分为两栏的窗口，每栏显示一个文件夹，便于在不逐个打开的情况下，在两栏之间移动和复制书籍及文件夹。窗口打开时，左栏显示你所在的文件夹，右栏显示上次显示的文件夹。

![整理窗口](../../images/organise-dialog.png)

| 按键 | |
|---|---|
| 左 / 右 / Tab | 切换到另一栏。 |
| 上 / 下 | 移动光标。 |
| Enter | 打开光标所在的文件夹。 |
| Backspace | 返回上一级。 |
| 空格或 Insert | 标记光标所在的条目；按住 Shift + 上 / 下 可在移动时进行标记。 |
| 点击复选框 | 标记或取消标记该条目；**Shift + 点击** 会标记（或清除）它与之前点击的复选框之间的所有条目。 |

窗口底部的一排按钮会对**已标记**的条目执行操作（如果没有标记任何条目，则对光标所在的条目执行操作），括号中显示其快捷键：

| 按钮 | 快捷键 | |
|---|---|---|
| **复制** | `c` | 复制到*另一栏*的文件夹中。 |
| **移动** | `m` | 移动到另一栏的文件夹中。 |
| **新建文件夹** | `n` | 在活动栏所在的文件夹中新建一个文件夹。 |
| **重命名** | `Shift+r` | 重命名光标所在的文件夹或书籍。 |
| **删除** | `Delete` | 删除该条目，与列表中的操作相同。 |
| **文件夹设置** | `i` | 光标所在文件夹的[设置](#folder-settings)。 |
| **批量更改模型/协议**、**批量更改语言**、**批量重命名**、**为书籍添加标签** | `p`、`l`、`Shift+n`、`t` | 对已标记的书籍，或对活动栏文件夹中的书籍（可选择是否包含子文件夹）执行[批量更改](#mass-changes)。批量重命名后，两栏会显示新名称。 |
| **高级搜索** | `f` | 在活动栏所在的文件夹中进行[搜索](managing-books.md#advanced-search)，可选择包含子文件夹。搜索结果中有**在文件夹中显示**，点击后会将焦点切换到该文件夹并标记该书籍。 |
| **在列表中显示文件夹** | `o` | 关闭窗口，并在书籍列表中打开活动栏所在的文件夹。 |

关闭窗口时，书籍列表会重新读取，因此你所做的新建、移动、复制、重命名或删除操作会立即显示出来（如果列表所在的文件夹已不存在，则会跳转到顶层）。

这些快捷键是 *设置* 中[键盘快捷键](../account.md#keyboard-shortcuts)的操作项：你可以在那里更改或清除它们（默认情况下没有功能键，因为 Mac 和浏览器会占用这些键）。按钮上显示的是你设置的快捷键。

<a id="copying"></a>

### 复制

书籍的**复制**即为[克隆](managing-books.md#cloning-a-book)；窗口会询问是否仅复制当前分支。文件夹的复制会生成一个新文件夹，其设置、描述和标签与原文件夹相同，并复制其中所有的书籍和文件夹。复制可能耗时较长，因此会在进度条后台运行，且无法中途停止。如果复制中途失败，则已完成的副本会被保留，每个副本都是完整的。

**移动**会立即完成，可以通过移回原处来撤销。文件夹不能移动到它自身之中，也不能移动到其下级文件夹中。

<a id="when-a-name-is-taken"></a>

### 名称冲突时

如果目标位置已存在同名文件夹，窗口会询问如何处理该文件夹，并提供**全部应用**选项，以便对其余同名文件夹采用相同的处理方式：

| 选项 | |
|---|---|
| **重命名** | 该文件夹会获得另一个名称。 |
| **跳过** | 该文件夹保留在原位（且不会被复制）。 |
| **合并** | 其中的内容会放入已存在的同名文件夹；其中的同名子文件夹会依次合并。 |

书籍不会产生冲突：它们的名称可以重复。

<a id="mass-changes"></a>

## 批量更改

列表的 **管理 → 批量更改** 菜单（以及整理窗口中的按钮）可以一次更改多本书籍。**批量更改模型/协议**为书籍设置一个模型和/或一个协议，**批量更改语言**设置语言，**批量重命名**可以为书名添加前缀或后缀、替换其中的文字或为其编号，**为书籍添加标签**和**为文件夹添加标签**可以添加或移除标签。参见[管理书籍](managing-books.md#tagging-many-books-at-once)。在列表中使用时，这些操作针对当前文件夹中的书籍，并可选择是否包含子文件夹。

<a id="favorites"></a>

## 收藏

书籍行上的星标可将其设为**收藏**。当你有收藏的书籍时，顶层会显示虚拟文件夹**收藏**（一个星标），其中包含你所有文件夹中的收藏书籍。它只是一个视图：你不能在其中新建书籍或文件夹，取消星标会将书籍从该视图中移除，但不会将其从所在文件夹中移除。收藏记录保存在你的设置中。

<a id="tagging-folders"></a>

## 为文件夹添加标签

文件夹和书籍一样可以添加标签。**管理 → 批量更改 → 为文件夹添加标签**可以一次为多个文件夹添加标签。文件夹的标签不会改变其中书籍的标签，并且它们不属于[备份](backups.md)的内容。

<a id="folders-and-other-features"></a>

## 文件夹与其他功能

- **备份。** [备份](backups.md#backups-and-folders)会记住其书籍所在的文件夹，导出的文件可以包含书籍所继承的设置。
- **代理。** [代理](../agents.md#agents-and-folders)会使用其书籍所在文件夹的设置进行写作。
- **帮助助手。** 如果你允许，[助手](../administration/help-assistant.md#your-books)可以查找你的书籍和文件夹。
- **手机。** [手机布局](../phone.md#books)以卡片形式显示相同的文件夹，并可以新建、重命名、设置和删除它们；整理和批量更改位于其标题栏的 **⋮** 菜单中。
- **阅读器。** [阅读器](publishing.md#folders-in-the-list)同样会列出文件夹，并在你离开时所在的文件夹中打开。
