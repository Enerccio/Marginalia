# ロアブックの作成

<a id="the-lorebook-editor"></a>

## ロアブックエディター

**Lorebooks** タブを開きます。エディターには一度に一つのロアブックが表示されます。上部の **Lorebook** フィールドで選択してください。
ロアブックはあなたのアカウントに属します。[共有](#sharing-a-lorebook)しない限り、他のユーザーからは見えません。

ツールバーは二段になっており、画面が狭いと複数の行に折り返されます。一段目はロアブック用（**Lorebook** から **Tag lorebooks** まで）、二段目は選択したロアブックのエントリ用（**Add Entry** から **Refresh** まで）です。

| ボタン | |
|---|---|
| **Lorebook** | 編集するロアブックを選択します。 |
| **Only root lorebooks** | 他のロアブックのサブロアブックではないロアブックだけを一覧に表示します（選択中のロアブックは一覧に残ります）。 |
| **Add Lorebook** | *New Lorebook* という名前の新しいロアブックを作成し、それを選択します。 |
| Clone（二枚の紙のアイコン） | 選択中のロアブックのコピーを作成します。名前を尋ねられ（元の名前に *(Copy)* が付いたものが初期値）、コピーが選択されます。コピーには同じエントリ（その設定、タグ、否定タグを含む）、タグ、説明、拡張機能のデータが含まれます。サブロアブックはコピーされず、コピーも同じサブロアブックを使います。元のロアブックは変更されません。 |
| **Delete Lorebook** | 選択中のロアブックを削除します（確認後）。 |
| Import（ファイルのアイコン） | **Import Marginalia Lorebook**、**Import from SillyTavern**、**Import from archive**（`.md` ファイルを含む zip）、または **Import from other user**（他のユーザーが[共有](#sharing-a-lorebook)しているロアブック）。詳しくは [インポートとエクスポート](import-export.md) を参照してください。 |
| Export（ファイルのアイコン） | サブロアブックを含めてロアブックをダウンロードします。詳しくは [インポートとエクスポート](import-export.md#exporting) を参照してください。 |
| Tags（タグのアイコン） | **Tag lorebooks**：多数のロアブックにまとめてタグを付けます。[下記](#tagging-many-at-once)を参照してください。ロアブックが本で開かれている場合は表示されません。 |
| Description（行のアイコン、一段目の最後） | **Edit description**：ロアブックの内容を書き込むウィンドウを開きます。[下記](#description)を参照してください。 |
| **Add Entry** | ロアブックにエントリを追加します。詳しくは [エントリと発動](entries.md) を参照してください。 |
| **Full-screen editor** | ロアブックのエントリをタブ付きの全画面ウィンドウで開きます。詳しくは [全画面での編集](#editing-in-full-screen) を参照してください。デスクトップのみで利用できます。 |
| **Search and replace** | ロアブックのエントリの名前、本文、コメント内の文字列を置き換えます。詳しくは [検索と置換](entries.md#search-and-replace) を参照してください。 |
| **Mass edit** | ロアブックとそのサブロアブックのすべてのエントリを一つの表で開きます。詳しくは [一括編集](#mass-edit) を参照してください。 |
| Tags（タグのアイコン、**Search and replace** の右、二段目） | **Tag entries**：選択中のロアブックの多数のエントリにまとめてタグを付けます。[下記](#tagging-many-at-once)を参照してください。 |
| **Preview activation** | 入力したテキストによるターンで、どのエントリが使われるか、またその理由を表示します。詳しくは [発動のプレビュー](entries.md#preview-activation) を参照してください。 |
| **Refresh** | エントリを再読み込みします。 |
| 検索ボックス | 入力したテキストを含むエントリだけを表示します。詳しくは [多数のエントリの検索と削除](entries.md#searching-and-deleting-many-entries) を参照してください。 |
| **Delete selected** | 一覧でエントリが選択されているときに表示されます。確認後に選択したエントリを削除します。 |

ツールバーの下には、選択中のロアブックの設定があります。

| フィールド | |
|---|---|
| **Name** | ロアブックの名前です。本に使うとき、またはサブロアブックとして選択するときに表示されます。 |
| **Sub Lorebooks** | このロアブックと一緒にエントリが取り込まれる他のロアブックです。[下記](#sub-lorebooks)を参照してください。選択したサブロアブックの名前をクリックすると、それが開きます。 |
| **Tags** | ロアブック全体のタグです。各エントリのタグとして扱われます。詳しくは [タグ](entries.md#tags) を参照してください。 |
| **Scan depth** | `0` から `5` まで：発動したエントリの内容を、他のエントリの発動条件の検索に何回かけるかを示します。詳しくは [他のエントリに取り込まれるエントリ](entries.md#entries-brought-in-by-other-entries) を参照してください。本が使うロアブックのエントリと、そのサブロアブックのエントリに適用されます。ただし、サブロアブックが独自の深度を持つ場合（次の行）はそちらが優先されます。 |
| **Scan depth as a sub lorebook** | 空欄、または `0` から `5` まで：このロアブックが本の使うロアブックのサブロアブックになっているときの、このロアブックのエントリのスキャン深度です。空欄の場合は、そのロアブックのスキャン深度になります。`0` の場合、このロアブックのエントリは他のエントリの内容によって見つけられることはありません。 |
| **Enabled** | チェックを外すと、ロアブックは何も寄与しません。エントリもサブロアブックのエントリも対象になりません。 |
| **Share with other users** | チェックすると、他のユーザーがこのロアブックを閲覧し、コピーをインポートできます。詳しくは [下記](#sharing-a-lorebook) を参照してください。新しいロアブックではオフです。 |

設定の下には、ロアブックに説明があれば、その[説明](#description)が表示されます。

エディターの残りの部分は [エントリ](entries.md) の一覧です。すべての変更は、行うと同時に保存されます。

<a id="description"></a>

### 説明

説明は、ロアブックについての数語（または数行）です。どのような世界か、何のためのものか、どの本が使っているか、などを書きます。ツールバーの一段目にある行のアイコンをクリックし、ウィンドウに書き込んで確定してください。空のテキストにすると説明は削除されます。説明があるロアブックは、設定の下に一行で表示されます。収まらない部分は省略記号で切られます。全文を読むには、マウスポインターを行の上に置いてください。説明はロアブックと一緒にコピーされ（クローン、エクスポート、インポート、バックアップ）、共有したときには、その名前の横に他のユーザーに表示されるテキストになります。

![ロアブックの説明のウィンドウ](../../images/lorebook-description.png)

<a id="sharing-a-lorebook"></a>

### ロアブックの共有

**Share with other users** にチェックを入れると、この環境の他のすべてのユーザーには、**Import from other user**（一段目のツールバーにあるインポートボタン）にそのロアブックが表示されます。名前、作成者（あなたのフルネーム、またはフルネームがない場合はログイン名）、説明も表示されます。ユーザーは行を開いてエントリ（およびサブロアブックのエントリ）を閲覧し、コピーをインポートできます。チェックを外すと、そのロアブックは相手の一覧から消えます。すでに作成されたコピーは、そのユーザーのものとして残ります。

* 共有は閲覧のみです。他のユーザーは、あなたのロアブックを変更、削除、または本で使用することはできません。ロアブックはあなたのものであり、これまでどおり見えます。
* インポートすると、**他のユーザーの新しいロアブック**が作られます。ロアブックと、その**共有されている**サブロアブック（階層の深さは問いません）が、エントリ、タグ、説明とともにコピーされ、あなたのロアブックと同じように関連付けられます。コピーは非公開（共有されていない）です。あなたがその後ロアブックに何をしても、コピーには反映されません。また、相手が変更したことも、あなたのロアブックには反映されません。
* **共有されているサブロアブックだけが表示され、コピーされます。** 共有されていないサブロアブックは、その下にあるすべてのものとともに除外されます。その下にある共有されたロアブックも含まれます。共有されていないサブロアブックを持つロアブックで **Share with other users** にチェックを入れると、それらも共有するかどうかの確認が表示されます。**Yes** を選ぶと、ロアブックとそのすべてのサブロアブック（階層の深さは問いません）を共有します。**No** を選ぶと、ロアブックだけを共有します。**Cancel** を選ぶと、何も共有せず、チェックボックスも外れたままになります。後から追加したサブロアブックは、あなたが共有するまで共有されません。
* チェックを外すと、そのロアブックだけの共有が止まります。サブロアブックは、あなたがそれらのチェックも外すまで共有されたままです（他のユーザーの一覧には、それぞれ独立して表示されます）。
* 削除されたロアブック、エージェントの作業用コピー、あなた自身のロアブックは一覧に表示されません。削除されたユーザーの分も表示されません。

設定の下には、ロアブックの有効なエントリのトークン数の見積もりが表示されます。その横の **Count with subbooks** というリンクは、ロアブックの有効なエントリと、その下にあるすべてのサブロアブック（階層の深さは問いません）の有効なエントリのトークン数を合計し、その合計を横に表示します。物語を書くときと同じく、無効なサブロアブックは、その下にあるロアブックとともに除外されます。また、複数の場所でサブロアブックになっているロアブックは一度だけ数えられます。合計は、クリックした時点の数です。エントリを変更すると表示は消えるので、もう一度クリックして数え直してください。

エージェントが作業している本のロアブックは、読み取り専用で表示されます（[エージェント](../agents.md) を参照）。**Add Entry**、**Search and replace**、**Mass edit**、**Delete Lorebook** と設定は表示されません。**Add Lorebook**、インポート、エクスポート、**Refresh** は残るので、いつでも別のロアブックを始められます。
<a id="mass-edit"></a>

## マスエディット

**マスエディット**を開くと、選択したロアブックのすべてのエントリと、その**サブロアブック**(どれだけ深くても)のすべてのエントリが、1つの表にまとめて表示されます。並び順は、エントリの**順序**によります(同じ順序のものはロアブックごとにまとめられ、その中で名前順になります)。大きなロアブックを整理するためのものです。

- エディターと同じように、エントリの *有効* チェックボックス、**エントリ名**、**順序**、**タグ**、**フィルターモード**、**フィルタリング**、**挿入モード**、**ネガティブタグ**、**発動コンテキスト**とその**パート**、パートの範囲(**開始メッセージ**と**終了メッセージ**。空欄は制限なし)、**メモ**をその場で変更できます。エントリは1行ずつ表示され、表は下方向にスクロールします(ウィンドウが狭いときは横方向にもスクロールします)。順序を変更すると、その行は新しい位置に移動します。エントリの本文は表では省略されます。全文を読んだり編集したりするには、ロアブックでエントリを開いてください。
- 行の**ロアブック**欄には、そのエントリがどのロアブックにあるかが表示されます。別のロアブック(そのロアブック自身か、そのサブロアブックのいずれか)を選ぶと、エントリをそこへ移動できます。
- 複数のエントリを移動するには、それらにチェックを入れ(ヘッダーのチェックボックスで全件にチェックが入ります)、下部の**ロアブックへ移動**を選んで**チェックしたものを移動**を押します。
- 複数のエントリを削除するには、チェックを入れて**チェックしたものを削除**を押します。確認は一度だけ行われ、エントリは[ごみ箱](../trash.md)に移動します。
- エージェントが作業中のロアブックはロックされます。そのエントリはグレーアウトされ、変更も移動もできず、そのロアブックへエントリを移動することもできません。これはロアブックごとに判定されるため、サブロアブックが別の作品で使われていてロックされている一方、そのロアブック自体はロックされていないということもあります。**更新**を押すと、ウィンドウを読み直して、ロックが解除されたかどうかを確認します。

変更後にウィンドウを閉じると、エディター内のロアブックも更新されます。

## フルスクリーンでの編集

**全画面エディター**（ツールバーの2段目）は、選択したロアブックを画面いっぱいのウィンドウで開きます。長いエントリの編集に向いています（エントリの行にある展開ボタンを押すと、そのエントリを開いた状態でウィンドウが開きます）。ブックのウィンドウの *Lorebook* タブにも同じボタンがあり、そのタブに表示されているロアブックを開きます。ウィンドウのタイトルはロアブックの名前になります。[ストーリーエディター](../books/story-editor.md)と同じように、タブの集まりとして構成されています。タブをドラッグして別のタブの横や下に配置でき、タブ間の仕切り線もドラッグできます。

![全画面ロアブックエディター：エントリの一覧と、タブで開いた2つのエントリ](../../images/lorebook-fullscreen.png)

- **Entries** タブには、エントリの一覧が表示されます。ロアブックページと同じ検索ボックス、タグとステータスのフィルター、**エントリを追加**、**一括編集**、**エントリにタグを付ける**、**発動をプレビュー**、**更新** があります（一括編集とタグの変更は、開いているタブにも反映されます）。**サブロアブックを含める** をオンにすると、[サブロアブック](#sub-lorebooks)のエントリも、それぞれのロアブックの名前付きで一覧に表示されます。この場合、**エントリを追加** は、一覧の横で選んだロアブックにエントリを追加します。そのようなエントリのタブには、所属するロアブックの名前が表示されます。このタブは閉じることができません。各行には3つのボタンがあります。
  - **開く**（ペンのアイコン。行をダブルクリックしても同じ）は、最後に使ったエントリタブでエントリを開きます。そのようなタブがない場合は、一覧の右側の列に新しいタブを開きます。
  - **新しいタブで開く**（矢印のアイコン）は、最後に使ったエントリタブの隣に、そのエントリ用のタブを追加します。
  - **削除**（ゴミ箱のアイコン）は、確認のあとエントリを削除し、そのタブを閉じます。

  1つのエントリは同時に1つのタブでしか開けません。もう一度開こうとすると、すでに開いているタブが表示されます。
- **エントリタブ** には上から順に、**名前**、**順序**、**有効** が並びます。その下には、折りたたみ可能なパネルの **設定** があり、エントリのそのほかの設定（フィルターのモードと条件、挿入モード、発動の文脈と部分、タグと除外タグ、部分の範囲、再帰の各チェックボックスと条件）が入っています。詳しくは [エントリと発動](entries.md) を参照してください。その下が、Markdownエディターによる**本文**です。各タブは、テキストだけを表示するか、テキストとプレビューを並べて表示するか、プレビューだけを表示するかを記憶しており、ウィンドウを開き直したときも同じ表示になります。**メモを表示** にチェックを入れると、本文の横にメモが表示されます。目のアイコンを押すと、このエントリの[発動プレビュー](entries.md#preview-activation)が開きます。一番下の行には、本文の推定トークン数と、テンプレートに問題がある場合はその内容が赤字で表示されます（問題があっても保存はされます）。タブを閉じるには、その **×** を押します。
- **エントリの画像。** 本文に画像を貼り付けるか、画像をドロップするか、ツールバーの画像ボタンで選択します（PNG、JPEG、GIF、WebP。10 MBまで）。画像はファイル（*Resources* タブ）に保存され、カーソルのあった位置に `![Map](resource:…)` のような行が追加されます。プレビューには画像が表示され、角かっこ内のテキストが画像の説明になります。エントリから画像を取り除くには、この行を削除します。モデルは、これらの行を除いた状態でエントリを読みます。画像そのものは、モデルの設定で *Send lore images* が有効な場合にのみ送信されます（[推論プロバイダー](../inference-providers.md)を参照）。画像はロアブックと一緒に移動します。複製、共有ロアブックのコピー、エクスポートしたロアブックファイル、ファイルを含むブックのバックアップには画像も含まれ、コピー先では画像が独自のものになります。SillyTavern形式のエクスポートとブックのエクスポートには画像は含まれません。ストーリーの *Lorebook* タブでは、エントリのテキストの下に画像が表示されます。画像は、現時点ではトークン数の推定に含まれません。
- **エントリ間の移動。** 本文、またはプレビュー内の別のエントリの名前やキーワードを Ctrl+クリック（Macでは Cmd+クリック）すると、最後に使ったタブでそのエントリが開きます。Shift も押すと新しいタブで開きます。一番下の行には、**言及元：** に続けて、本文がこのエントリの名前を含んでいるエントリも表示されます。それをクリックすると開き、Shift+クリックで新しいタブに開きます。エントリは、その名前と、フィルターの語句（各キーワード、*Text* フィルターのテキスト全体、正規表現が一致するもの）によって、大文字と小文字を区別せず単語単位で言及されたものとみなされます。これは[再帰](entries.md)がたどるものに近いものの、同じではありません。再帰は、より長い単語の中のキーワードも見つけ、*AND* フィルターではすべてのキーワードを必要とし、タグや条件も確認します。
- Markdownエディターには、ツールバーがあります（太字、斜体、取り消し線、線、見出し、引用、コード、コードブロック、表、3種類のリスト）。右側には、*編集*、*編集とプレビュー*（既定）、*プレビュー* の表示切り替えがあります。一般的なキー操作（Ctrl+B、Ctrl+I など）が使え、Tab キーはインデントではなく次の項目へ移動します。入力した内容は、入力が少し止まったときと、エディターから離れたときに保存されます。
- ヘッダーには、有効なエントリの推定トークン数、**サブブックを含めて計算** と **検索と置換** が表示されます。置換を行うと、開いているタブの内容にも反映されます。

すべての変更は行うと同時に保存されるため、**閉じる** を押しても何も失われません。ウィンドウは、ロアブックごとに最後の状態を記憶します。次に同じロアブックを開くと、同じエントリが同じタブに、同じ配置で表示されます（その後に削除されたエントリは除かれます）。ウィンドウを閉じると、ロアブックページにはエントリが再び表示されます。

**別の場所での変更。** タブでの変更は、その時点で保存されているエントリの内容に上書きされる形で保存されます。そのため、別の場所（ロアブックページ、一括編集、別のウィンドウ）で変更されたエントリの *他の* 項目は残り、タブにもその内容が表示されます。タブが表示してから別の場所で **本文** または **メモ** が変更された場合、あなたのテキストは保存された内容の上に上書きされません。一番下の行にその旨が表示され、**自分のテキストを残す**（それでも自分のテキストを保存する）と **保存済みのテキストを読み込む**（自分のテキストを破棄する）が選べます。別の場所で削除されたエントリのタブは閉じます。

ウィンドウを開いている間に保存されたことにも追従します。エージェントや別のウィンドウ（別のブラウザータブ、ストーリーのロアブックタブなど）がエントリを保存または削除すると、一覧は読み込み直され、そのエントリのタブには現在の内容が表示されます（削除されたエントリのタブは閉じます）。テキストが **自分のテキストを残す** または **保存済みのテキストを読み込む** の選択を待っているタブは、回答するまでそのままになります。入力したのと同じ秒に変更が保存された場合、変更が行き違うことがあります。その場合は、一番下の行に上記と同じ確認が表示されます。

**エージェント。** エージェントがそのロアブックを使うブックで作業している間は、このウィンドウは開けません。ウィンドウを開いたままエージェントの実行が始まった場合、次に変更を加えたとき、またはタブを切り替えたときに、ウィンドウは読み取り専用になります。バーにはエージェントの名前が表示され、直前の変更を保存できなかった場合はその旨も表示されます。実行を一時停止または停止してから **再確認** を押すと、エントリは実行が終わった状態で読み込まれ、再び編集できるようになります。

[Lore Generator](../extensions/lore-generator.md) と [Lorebook VCS](../extensions/lorebook-vcs.md) の拡張機能も、ここで使えます。魔法の杖のアイコンは一覧の各行とエントリタブの名前の行にあり、リビジョンのパネルは一覧の上に、エントリのリビジョンバーはそのタブ内にあります。

<a id="tagging-many-at-once"></a>

## 複数の項目にまとめてタグを付ける

ツールバーの2つのタグのボタンは、同じウィンドウを開きます。このウィンドウでは、複数の項目にタグを付けたり、外したりできます。**ロアブックにタグを付ける** はあなたのロアブックを、**エントリにタグを付ける** は選択したロアブックのエントリを一覧表示します。**Tag**（既存のタグを選ぶか、新しいタグを入力して Enter キーを押す）を選ぶと、一覧にはすべての項目とそのタグが表示されます。選んだタグを持つ項目が先頭に並び、タグが強調表示されます。各行の **+** と **-** のボタンは、その項目にタグを付けるか外すかを行います。複数の項目にチェックを入れ（ヘッダーのチェックボックスですべてを選択できます）、下部の **チェックした項目にタグを付ける** または **チェックした項目からタグを外す** を使うと、まとめて処理できます。エージェントが作業中の項目（実行中のエージェントがあるブックのロアブック、つまりそのすべてのエントリ）は灰色で表示され、実行を一時停止または停止するまで変更できません。このウィンドウは[ブック](../books/managing-books.md#tagging-many-books-at-once)にもタグを付けられます。エントリに付けるタグは通常のタグで、詳しくは [タグ](entries.md#tags) を参照してください。除外タグは、エントリ自体に設定します。

<a id="using-a-lorebook-in-a-book"></a>

## ブックでロアブックを使う

ブックを開き、その **Lorebook** タブで、**Lorebook** の欄からロアブックを選びます。下のエディターにそのロアブックが表示されるので、執筆しながらエントリを追加したり変更したりできます。欄を空にすると、ロアブックを使わずに執筆できます。

1つのブックが使えるロアブックは1つだけです。複数のロアブックを使いたい場合は、それらをサブロアブックとして含む新しいロアブックを作成し、そちらを使ってください。

同じロアブックを、いくつのブックでも使えます。そのロアブックへの変更は、次に生成される部分から、すべてのブックに影響します。すでに書かれた部分は、書かれたときのロア設定を保ちます。
<a id="sub-lorebooks"></a>

## サブロアブック

**サブロアブック**では、他のロアブックのエントリーをこのロアブックに取り込めます。典型的な構成は次のとおりです。

```
"Saga"（シリーズの各巻が使用）
 ├─ "World"       場所、歴史、魔法のルール
 ├─ "Characters"  主要な登場人物
 └─ "Book 2 notes"
```

- サブロアブックは、さらに自分のサブロアブックを持てます。すべての階層が取り込まれます。
- 1つのロアブックを、複数のロアブックのサブロアブックにすることができます。同じロアブックに複数回到達しても、そのエントリーは1回だけ使用されます。
- ロアブックは、直接でも他のロアブックを経由してでも、自分自身を取り込めません。このような選択は、*サブロアブックを選択できません：循環が検出されました。*と表示されて拒否されます。
- 無効なサブロアブックは、それが取り込んでいるものすべてと一緒に除外されます。

![サブロアブックを2つ持つロアブックと、それらを含む場合と含まない場合のトークン数](../../images/lorebook-sub-lorebooks.png)

取り込まれたすべてのロアブックのエントリーは、どのロアブックから来たかに関係なく1つにまとめられ、[順序](entries.md#order-and-insertion)で並べられます。

<a id="disabling-and-deleting"></a>

## 無効化と削除

しばらくロアブックを使わずに、たとえばそれがない場合に本がどう読めるかを確認したいときは、**有効**のチェックを外してください。そのロアブックを使用している本はそのまま残り、チェックを入れ直すと再び機能します。

**ロアブックを削除**を実行すると、ロアブックが一覧から削除されます。それを使用していた本はそのエントリーを受け取らなくなり、それをサブロアブックとして取り込んでいたロアブックは、それを読み飛ばします。データは、管理者が[クリーンアップ](../administration/cleanup.md)を実行するまでデータベースに残ります。それまでは[ごみ箱](../trash.md)からロアブックを復元できます。[本のバックアップ](../books/backups.md)やエクスポートされたファイルにあるコピーには影響しません。
