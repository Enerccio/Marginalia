# プロンプト検査

生成のプロンプトを、モデルに送信する前に表示し、送信してよいかを確認します。

<a id="how-it-works"></a>

## 動作の仕組み

この拡張機能は、[ストーリーエディタ](../books/story-editor.md)の設定メニュー（⚙）の **分析** グループに、**Inspect prompt before sending** という項目を追加します。これはチェックボックス項目です。選ぶと検査が有効になり、もう一度選ぶと無効になります。この設定はユーザーごとの設定で、すべての本に適用されます。

有効な間、生成（新しいパート、スワイプ、再生成）は要求を送る直前で止まり、**Send this prompt to the model?** というダイアログが開きます。表示されるテキストは、他のすべての拡張機能が変更を加えた後に、モデルが受け取る形のプロンプトです。各メッセージはそのロールごとに表示されます。`[SYSTEM]`（テンプレート、ロア、要約）、それまでのパートが `[USER]` と `[ASSISTANT]` のメッセージとして並び、最後に今回のターンの指示が続きます。一緒に送られる画像は、そのメッセージの末尾で数えられます。

![送信前のプロンプト](../../images/plugin-prompt-inspector.png)

- **送信** を選ぶと要求が送られ、生成は通常どおり続きます。
- **キャンセル** を選ぶと生成が止まります。その生成のために作成されたパートは削除されます（再生成されたパートは元のテキストに戻ります）。これは、テキストが届く前に生成が失敗した場合と同じです。

<a id="notes"></a>

## 注意点

- プロンプトは、どの生成とも同じく最初に組み立てられ、要求を送る直前の最後の手順で確認を求められます。要約が無効になっていた場合は、要約なしで続行するかという通常の質問が、プロンプトを表示する前に出ます。あなたが答えるまで、モデルへの要求は一切行われません。
- 保留されるのは、ストーリーエディタから始めた生成だけです。[エージェント](../agents.md)とコマンドはプロンプトを表示できるページがないため、確認なしで続行します。
- ダイアログは移動やサイズ変更ができ、テキストを選択してコピーできます。必ず回答が必要で、Esc キーやダイアログの外側のクリックでは閉じません。ダイアログを開いたままページを閉じた場合は *キャンセル* として扱われます。サーバーがページの消失を検知すると生成は止まり、何も送信されません（検知までに時間がかかることがあります）。
- 他のユーザーには確認は求められず、この設定はページを再読み込みしても保持されます。
