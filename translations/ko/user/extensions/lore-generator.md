# 로어 생성기

모델이 [로어북 항목](../lorebooks/entries.md)의 내용을 대신 작성하게 해 줍니다. 이미 있는 로어를 읽고 새 항목이 세계관에 맞도록 하며, 결과를 로어 항목에 가장 잘 맞는 짧고 밀도 높은 형태로 다듬어 줍니다.

!!!
로어 생성기는 [휴대폰 레이아웃](../phone.md#extensions)에서도 동작합니다. 항목 행에 마법봉 버튼이 있고, 창 위쪽에는 프롬프트가, 아래쪽에는 결과가 나타납니다.
!!!

<a id="opening-the-generator"></a>

## 생성기 열기

확장 기능을 설치하면 로어북 편집기의 모든 행에 마법봉 버튼(**Generate lore entry**)이 생깁니다. 이 버튼을 누르면 해당 항목의 생성기가 열립니다. 항목에 이미 내용이 있으면 대화상자 맨 위에 그 사실이 표시되며, 결과를 항목에 복사하면 기존 내용이 대체됩니다.

[전체 화면 편집기](../lorebooks/lorebooks.md#editing-in-full-screen)에도 마법봉이 있습니다. 항목 목록의 모든 행과, 항목 탭의 이름 행에 있는 **Generate lore entry**로 열 수 있습니다. 편집기에서 복사한 내용은 해당 항목의 탭에 바로 표시됩니다. 책(그 *Lorebook* 탭이나 이야기의 로어북 탭)에서 편집기를 열면 편집기가 그 책을 알고 있으므로, 로어북 페이지에서와 마찬가지로 모델 사용 비용을 그 책이 부담합니다.

생성기는 *Settings*의 **Default Model**과 **Default Protocol**로 시작합니다. 자세한 내용은 [계정 및 설정](../account.md)을 참고하세요. 대화상자 머리말 아래의 **Model**과 **Protocols** 목록에서는 이번 생성에만 다른 모델이나 프로토콜을 쓸 수 있습니다(선택 내용은 저장되지 않습니다). 프로토콜은 선택 사항입니다. 모델이 없으면 경고만 표시됩니다.

![로어 생성기](../../images/plugin-loregenerator.png)

<a id="what-the-model-sees"></a>

## 모델이 보는 내용

대화상자 위쪽의 두 가지 선택지가 요청에 어떤 로어를 넣을지 정합니다.

| 선택지 | |
|---|---|
| **Current Lorebook** (기본값) / **All Lore** | 항목이 속한 로어북의 항목만, [하위 로어북](../lorebooks/lorebooks.md)은 제외합니다. 또는 그 로어북의 항목과 모든 하위 로어북의 항목을 함께 씁니다. |
| **Only up to position (n)** (기본값) / **All entries** | *n*은 항목의 순서입니다. 그보다 앞에 오는 항목만 표시됩니다(순서가 더 작거나, 순서가 같고 먼저 만들어진 항목). 그래서 모델은 이미 있는 내용을 바탕으로 작성하며, 항목 이후에 쓰인 로어를 받지 않습니다. *All entries*를 고르면 모든 항목을 보여 줍니다. |

생성 중인 항목은 내용이 있든 없든 절대 포함되지 않습니다. 다른 항목이나 로어북이 활성화되어 있는지, 태그와 필터, 삽입 모드가 어떤지는 무시됩니다. 여기서 고른 것이 그대로 전송되며, 항목은 프롬프트에 삽입되는 순서대로 보내집니다. 항목의 템플릿은 평소처럼 처리됩니다.

<a id="prompts"></a>

## 프롬프트

생성 프롬프트는 모델에게 무엇을 써 달라고 요청하는 글입니다. 프롬프트 목록은 선택지 옆 상자에 같은 위쪽 줄로 나열됩니다. 선택한 프롬프트의 텍스트는 왼쪽의 텍스트 영역에 있으며, 저장하지 않고도 한 번의 생성에 대해 바꿀 수 있습니다. 대화상자의 두 부분은 끌어서 크기를 조절할 수 있는 구분선으로 나뉩니다.

| 버튼 | |
|---|---|
| **Save** | 선택한 이름으로 텍스트를 저장합니다. |
| **Save as** | 이름을 묻고, 텍스트를 새 프롬프트로 저장합니다(같은 이름이 있으면 확인 후 대체합니다). |
| **Delete** | 선택한 프롬프트를 삭제합니다. 마지막 프롬프트를 삭제하면 기본 제공 `DEFAULT` 프롬프트가 다시 나타납니다. |

기본 제공 프롬프트에는 대괄호 안의 자리표시자(주제, 포함할 세부 사항, 길이, 구조)가 있습니다. 실행하기 전에 이들을 채워 넣으세요. 프롬프트는 계정에 속하며, 마지막으로 사용한 프롬프트가 다음에 대화상자를 열 때 다시 선택되어 있습니다.

<a id="generation-and-compaction"></a>

## 생성과 압축

오른쪽에는 두 개의 탭이 있습니다.

**Generation** - **Run Generation**은 로어와 생성 프롬프트를 보냅니다. 응답은 작성되는 대로 나타나며, 모델이 추론 과정을 제공하는 경우 그 내용은 위쪽의 *Thinking Process* 섹션에 표시됩니다. **Stop**(*Run Generation* 대신 표시됨)은 생성을 중간에 끝내며, 그때까지 작성된 내용은 남습니다.

**Compaction** - 생성 결과가 있으면 사용할 수 있습니다. **Run Compaction**은 같은 로어와, 생성된 텍스트가 포함된 압축 프롬프트를 보내고, 모델은 그것을 간결한 항목으로 줄입니다. 압축 프롬프트는 *Settings → Extension Settings → Lore Generator*에서 설정합니다. 비어 있으면 기본 제공 프롬프트가 사용됩니다(산문을 걷어내고 사실만 남깁니다). 생성을 다시 실행하면 압축 결과는 버려집니다.

![생성된 항목의 압축](../../images/plugin-loregenerator-compaction.png)

모델이 작업하는 동안에는 **Stop**을 제외한 모든 컨트롤이 잠기며, 대화상자도 닫을 수 없습니다.

<a id="remembered-per-entry"></a>

### 항목별로 기억되는 설정

**Copy to Lore Entry**를 누르면 그 생성의 옵션이 항목과 함께 저장됩니다. 프롬프트 텍스트, 어떤 저장된 프롬프트에서 왔는지, 로어와 항목 선택, 체크된 이름 범주가 포함됩니다. 그 항목에 대해 생성기를 다시 열면 이 옵션들이 복원되며, 마지막으로 사용한 프롬프트와 저장된 이름 범주보다 우선합니다. 한 번도 생성 결과를 복사한 적이 없는 항목은 일반 기본값으로 열립니다. 이 옵션은 항목에 속하므로 로어북의 백업과 내보내기에도 함께 포함됩니다.

<a id="tools"></a>

### 도구

[모델용 도구](tools.md) 모음(the [Name generator](name-generator.md) 또는 [Name provider](name-provider.md)의 이름, [Place provider](place-provider.md)의 장소)이 설치되어 있으면 위쪽 줄에 **Tools** 버튼이 나타납니다. 이 버튼을 누르면 모델이 사용할 수 있는 모음을 고르는 창이 열립니다. 범주가 있는 모음은 어떤 범주를 쓸지도 고를 수 있습니다. 동작 방식은 [모델용 도구](tools.md)를 참고하세요. 무언가 체크되어 있으면 생성 중에 모델이 도구를 호출할 수 있으며(압축 중에는 아님), 각 모음의 안내문이 생성 프롬프트 끝에 추가됩니다. 이 선택은 계정과 항목에 함께 저장됩니다.

<a id="attachments"></a>

### 첨부 파일

프롬프트 아래에서 모델이 살펴볼 파일을 추가할 수 있습니다. 참고 이미지, 지도, 캐릭터 시트 등이 해당됩니다. 업로드 영역에 끌어다 놓거나, 선택하거나, Ctrl+V로 프롬프트에 붙여 넣으면 됩니다(스크린샷이나 복사한 파일은 첨부 파일이 되고, 붙여 넣은 텍스트는 평소처럼 삽입됩니다). 파일당 최대 20MB입니다. 파일은 이름, 유형, 크기와 함께 나열되며, 휴지통 버튼으로 하나씩 제거할 수 있습니다. 첨부 파일은 생성과 함께 전송되며 압축에는 보내지 않습니다. 생성이 진행되지 않을 때에만 추가하거나 삭제할 수 있습니다.

모델이 첨부 파일을 사용할 수 있는지는 모델과 [추론 제공자](../inference-providers.md)에 따라 다릅니다. 이미지는 이미지로, 오디오는 WAV 또는 MP3로만, 그 밖의 파일은 파일로 전송됩니다. 제공자가 첨부 파일을 거부하면 메시지가 표시되며, 아무것도 생성되지 않습니다.

<a id="copying-the-result"></a>

## 결과 복사

압축에 결과가 있으면 **Copy to Lore Entry**를 쓸 수 있습니다. 압축된 텍스트는 항목의 **content**가 되고, 압축 이전의 생성 텍스트는 항목의 **note**에 들어갑니다. 두 곳 모두 대체됩니다. 압축 결과가 코드 블록 하나로만 되어 있으면(기본 제공 프롬프트가 이렇게 요청합니다. 텍스트를 쉽게 복사하기 위해서입니다) 그 주위의 코드 블록은 제거됩니다. 로어북은 새로 고쳐지며, 대화상자는 열린 채로 남습니다. 닫으려면 **Exit**을 누르세요.
<a id="commands"></a>

## 명령

생성기는 대화 상자 없이도 동작하며, 명령줄과 [에이전트](../commands/index.md)를 위한 세 가지 [명령](../agents.md)으로 제공됩니다. 이 명령들은 대화 상자와 같은 두 단계를 수행하지만, 대화 상자와 마찬가지로 아무것도 저장하지 않습니다. 텍스트를 반환할 뿐이며, 그 텍스트를 항목에 넣는 일(**Copy to Lore Entry**가 하는 일)은 호출한 쪽의 몫입니다. 따라서 세 명령 모두 읽기만 합니다. 로어북과 항목은 `/list-lorebooks`와 `/list-lore-entries`에서처럼 번호로 지정하며, 모델은 기본 모델과 기본 프로토콜을 사용합니다.

| 명령 | 하는 일 |
|---|---|
| `/list-lore-templates [template]` | 저장된 생성 프롬프트 목록(이름, 길이, 텍스트 시작 부분)과 마지막으로 사용한 프롬프트를 보여 줍니다. 이름을 주면 해당 프롬프트의 전체 텍스트를 반환합니다. |
| `/generate-lore-entry [prompt [template [lorebook [entry [order [scope [limit [images [compact]]]]]]]]]` | 로어북의 로어를 바탕으로 텍스트를 생성하고, 압축(`/compact-lore-entry`와 같음)한 뒤 압축된 텍스트를 반환합니다. `compact`를 `false`로 주면 생성된 텍스트를 그대로 반환합니다. 전송되는 텍스트는 템플릿과 그 뒤에 호출자의 프롬프트가 이어진 것입니다(아래 참고). `images`를 주면 모델이 대화 상자의 첨부 파일처럼 그림도 함께 봅니다. |
| `/compact-lore-entry text [lorebook [entry [order [scope [limit]]]]]` | 같은 로어를 기준으로 텍스트를 압축하여 결과를 반환합니다. 결과를 감싸는 코드 블록은 붙이지 않습니다. |

텍스트가 대상으로 하는 항목이 모델이 보는 로어를 결정합니다. 항목의 핸들 또는 번호를 `entry`로 주고(번호로 줄 때는 항목이 들어 있는 `lorebook`도 핸들이나 번호로 함께 줍니다), 로어는 대화 상자에서와 같습니다. `limit`이 `UP_TO_POSITION`(기본값)이면 그 앞의 항목만 보이고, 항목 자신은 절대 보이지 않습니다. 아직 없는 항목에는 번호가 없으므로, 대신 받게 될 `order`(`/list-lore-entries`의 `order`, 작은 값이 먼저 옵니다)를 주면 모델은 그 순서보다 앞의 항목을 봅니다. 둘 다 주지 않으면 텍스트는 다른 모든 항목 뒤에 올 새 항목을 위해 작성됩니다. `scope`는 `CURRENT_LOREBOOK`(기본값) 또는 `ALL_LORE`이고, `limit`은 `UP_TO_POSITION` 또는 `ALL_ENTRIES`로, 대화 상자와 같습니다.

생성 결과는 프롬프트의 품질에 달려 있으므로, 명령은 항상 저장해 둔 생성 프롬프트([프롬프트](#prompts) 참고) 중 하나에서 시작합니다. `template`에 이름을 준 프롬프트를 쓰고, 이름을 주지 않으면 마지막으로 사용한 프롬프트를 씁니다. 호출자의 `prompt`는 그 뒤에 *Task for this entry* 제목 아래에 붙으며, 주제, 사실, 길이, 섹션 등 템플릿이 요구하는 내용을 여기에 적습니다. `template`을 `none`으로 주면 프롬프트만 보내는데, 이는 호출자가 프롬프트 전체를 직접 작성한 경우(예: `/list-lore-templates`로 받은 템플릿 텍스트를 고친 경우)를 위한 것입니다. 템플릿 없이 프롬프트만 주면 명령은 템플릿만 보냅니다.

`/generate-lore-entry`의 `images`는 대화 상자가 생성에 첨부하는 이미지와 같습니다. [에이전트](../agents.md)는 작업 공간에 있는 이미지 파일의 경로 목록(`/refs/map.png`처럼, 최대 8개, PNG, JPEG, GIF 또는 WebP, 크면 축소됨)을 넘기며, 이 파일들은 작업 공간 탭의 **파일 업로드**로 올려 둡니다. 명령 입력줄에서는 이미지를 지정할 방법이 없으므로 `images`는 에이전트를 위한 것입니다. 이미지를 보는 것은 기본 모델이며, 모델이 이미지를 지원하지 않으면 명령이 실패하고 그 사실을 알려 줍니다. 대화 상자에서와 같이 이미지는 생성 단계에서만 쓰이며, 압축은 텍스트만 가지고 작업합니다.

`/generate-lore-entry`의 `compact` 매개변수는 기본적으로 `true`입니다. 명령이 생성과 압축을 한 번의 호출로 처리하므로, [에이전트](../agents.md)는 명령 하나만 있으면 되고 두 번째 단계를 빠뜨릴 일이 없습니다. 긴 생성 텍스트를 받고 싶을 때(예: 검토하거나 편집하려고)는 `compact`를 `false`로 주고, 나중에 그 텍스트에 `/compact-lore-entry`를 실행하면 됩니다.

여기서 모델은 어떤 도구도 받지 않습니다. 이름이 필요한 호출자는 먼저 [이름 생성기](name-generator.md)의 `/generate-names`나 [이름 제공자](name-provider.md)의 `/pick-real-names`로 이름을 받아, 마음에 드는 이름을 프롬프트에 적어 넣습니다. 에이전트는 `/list-lore-templates`로 템플릿 텍스트를 받아 고친 뒤, 그 결과를 프롬프트로 넘길 수도 있습니다.

## 저장

프롬프트와 압축 프롬프트는 설정과 함께 저장되므로, [데이터베이스 백업](../administration/database-backups.md)에 포함됩니다. 로어북에는 아무것도 함께 저장되지 않으며, 생성된 텍스트는 복사하기 전까지만 대화 상자에 존재합니다.
