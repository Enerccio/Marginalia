# リソースファイル

[リソース](../resources.md)のファイル(ストーリーの各部分に添付された画像、アップロードされたファイル)は、各ユーザーのデータフォルダー内の`data/<login>/images`と`data/<login>/resources`に保存されています。リソースを削除したり、その内容を置き換えたりしても、変更されるのはデータベースだけです。ファイルはディスク上に残り、[クリーンアップ](cleanup.md)やその他の処理でも削除されません。**リソースファイル**では、もう使われていないファイルを見つけ、ダウンロードしたり、ディスクから削除して容量を取り戻したりできます。

<a id="cleaning-up-the-files"></a>

## ファイルのクリーンアップ

1. 管理ページの**リソースファイル**タブを開き、**ファイルをスキャン**をクリックします。読み取り中のフォルダーは進捗バーに表示されます。
   この時点では何も変更されません。
2. 表には、**どのリソースからも参照されていない**ファイルが一覧されます。パス(`<user folder>/images/<file>`)、サイズ、最終更新日時が表示されます。すべてのファイルにチェックが入っています。残したいファイルのチェックを外してください。**すべて選択**と**選択を解除**は全ファイルに作用し、先頭列のヘッダーの矢印も同じ働きをします。表の上の行には、未使用のファイルの数、合計サイズ、チェックが入っている数が表示されます。
3. 必要に応じて**ZIPでダウンロード**をクリックすると、チェックの入ったファイルを1つのアーカイブにまとめて取得できます(エントリー名はパスになります)。個別の1ファイルだけが必要な場合は、その行の矢印を使います。削除する前には、このバックアップを取っておくことをお勧めします。
4. **選択したものを削除**をクリックし、確認すると、チェックの入ったファイルがディスクから削除されます。**閉じる**をクリックすると、何も削除せずに表を空にします。

![スキャン後のリソースファイルタブ](../../images/admin-resource-files.png)

!!!warning
削除したファイルは元に戻せません。少しでも不安があれば、先にZIPでダウンロードしてください。
!!!

<a id="what-counts-as-used"></a>

## 使用中とみなされる条件

ファイルは、**どのユーザーのどのリソースでも**参照されていれば使用中とみなされます。削除済みのリソースも含まれます。[ごみ箱](../trash.md)にあるリソースは復元できるため、その画像は再び正しく表示される必要があります。そのため、削除されたリソースのファイルは、[クリーンアップ](cleanup.md)でリソースがデータベースから取り除かれた後にのみ一覧に現れます。置き換えられた内容の古いファイル(古いファイルはそのまま残ります)や、アップロードに失敗して残ったファイルも同様です。

ファイルは名前(ランダムな識別子)で照合され、すべてのユーザーのフォルダーを対象とします。削除されたユーザーの`<login>-deleted`フォルダーも含まれ、そのファイルは、クリーンアップがユーザーとそのリソースを完全に消去するまで*使用中*のままです。

データフォルダー内のフォルダーのうち、読み取られるのは`images`と`resources`だけです。それ以外(データベースのバックアップ、エージェントの作業領域など)には触れません。

スキャンの後にユーザーがアップロードしたファイルは削除されません。**選択したものを削除**を実行すると、データベースが再度読み込まれ、その時点でリソースが参照しているファイルは残されます(残ったファイル数はメッセージに表示されます)。

スキャンではデータフォルダーを読み取るため、ファイル数が多いと時間がかかることがあります。進捗バーの**停止**をクリックすると、スキャンを中止できます。
