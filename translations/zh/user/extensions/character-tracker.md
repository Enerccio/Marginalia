# 角色追踪器

侧边栏中的书籍角色列表：包含每个角色的一句简介、备注、图标和颜色，角色之间的关系，以及一张关系图。

<a id="the-characters-tab"></a>

## 角色标签页

[故事编辑器](../books/story-editor.md)的左侧边栏在*大纲*旁边新增了**角色**标签页。列表上方是一行按钮：**添加**（新建角色）、一个包含导入设定条目功能的菜单、**关系图**，以及一个对话气泡按钮，用于设置提示词（悬停可查看名称）。

对话气泡按钮会打开一个弹出面板，其中有**在提示词中**、**深度**和角色选项，与[作者注释](authors-note.md)相同；当角色被加入提示词时，该按钮显示为绿色。勾选*在提示词中*后，每次生成时都会把角色作为一条消息发送：每个角色一行，包含名称、括号中的简介以及备注，另附一份关系列表（例如 `Mara -> Tomas: employs`，双向关系则显示为 `<->`）。*深度*表示它之后的消息数量（`0` 为最末尾，即你的指令之后；`1` 为指令之前的一条），角色可选*系统*、*助手*或*用户*。该文本会占用故事所用上下文中的 token。书中没有角色时不会插入任何内容。设置随书籍一同保存。

两个按钮之间的魔杖按钮有一个菜单项**将设定条目导入为角色**，详见[下文](#importing-characters-from-the-lorebook)。

列表按名称排序。每个角色使用其专属颜色，名称下方以较小的字体显示**简介**（最多两行）。角色的按钮如下：

| 按钮 | |
|---|---|
| 折叠箭头 | 展开角色，显示其**图标**和**备注**。 |
| 铅笔 | 在对话框中打开该角色。 |
| 垃圾桶 | 在确认后删除该角色及其所有关系。 |

角色在你修改后会立即随书籍保存，因此会包含在书籍的备份中。

![角色标签页](../../images/plugin-charactertracker-tab.png)

<a id="picking-characters-for-a-turn"></a>

## 为一轮生成选择角色

[新一轮](../books/story-editor.md)表单中有**视角角色**和**在场角色**两个字段。它们仍然是自由文本，但每个字段末尾都有一个带人形图标的按钮，点击后会按名称排序列出书中的角色。在**视角角色**的列表中选择的名称会替换字段中的内容；在**在场角色**的列表中选择的名称会以逗号分隔添加到末尾，如果已存在则不重复添加。打开列表时会读取角色，因此你刚添加的角色也会出现在其中。你仍然可以输入任何名称，字段中的名称也不必是书中的角色。

<a id="the-character-dialog"></a>

## 角色对话框

**添加**（带加号的按钮，其提示文字为*添加新角色*）和铅笔按钮会打开同一个对话框：

| 字段 | |
|---|---|
| **名称** | 必填。 |
| **简介** | 关于该角色的几句话，显示在列表和关系图中。 |
| **备注** | 任何你想记住的内容。 |
| **图标** | 上传 PNG、JPEG 或 GIF 文件。图片会被缩小到最大 200 x 200 像素，并保持比例。 |
| **颜色** | 角色在列表和关系图中的背景色。 |

点击**保存**以应用这些字段。

![带有关系的角色](../../images/plugin-charactertracker-dialog.png)

如果存在未保存的更改（包括你已填写但尚未添加的关系），此时按下**取消**（或 Esc），系统会询问你是否放弃这些更改。

![取消带有未保存更改的角色时的提示](../../images/plugin-charactertracker-unsaved.png)

<a id="relationships"></a>

### 关系

打开已有角色时，对话框还会列出其关系：该角色指向他人的关系（`→`）、他人指向该角色的关系（`←`）以及单向关系（`↔`），每条关系都显示名称和简介。垃圾桶按钮可删除一条关系。

要添加关系，先搜索另一个角色，选择**方向**（*本角色 → 对方*、*对方 → 本角色*或*双向*），输入**名称**（例如 *employs*、*friends*），可选填**简介**，然后点击**添加关系**（该按钮位于这些字段上方）。关系会立即保存。新角色需要先保存，之后才能添加关系。

<a id="importing-characters-from-the-lorebook"></a>

## 从设定集导入角色

如果你的角色已经写在设定集中，可以通过魔杖菜单自动创建。**将设定条目导入为角色**会打开一个对话框，列出本书设定集及其所有子设定集中的条目，并按*顺序*排序。每个条目显示名称和一个复选框，以及一个 **i** 图标，点击后会在弹出面板中显示该条目的内容，方便在决定前快速浏览；列表标题处的复选框可全选或全部取消。点击**导入**会为每个已勾选条目的名称创建一个角色（简介、备注、图标和颜色保持空白，供你之后填写），点击**关闭**则不导入直接离开。

条目不会与你已有的角色进行比较：同一条目导入两次会创建两个角色。

![从设定集导入角色](../../images/plugin-charactertracker-import.png)

<a id="the-relationship-map"></a>

## 关系图

**关系图**以图形方式展示本书的所有关系。每个有关系的角色都是一个圆形，上面是其图标（没有图标则为方框），背景为其颜色，并显示名称和简介；每条关系是两个角色之间的一条箭头，并显示其名称和简介。箭头指向目标角色；单向关系的箭头只在一端。没有关系的角色不会出现在图中。

![关系图](../../images/plugin-charactertracker-map.png)

角色会围绕一个中心角色呈环形排列，初始中心为关系最多的那个角色：与它有关系的角色位于第一环，与这些角色有关系的位于第二环，依此类推。**双击某个角色**可将关系图围绕该角色重新排列。你也可以拖动角色、移动画布，并用鼠标滚轮缩放。

<a id="commands"></a>

## 命令

角色也可以作为[命令](../commands/index.md)使用，适用于命令行和[智能体](../agents.md)。它们作用于当前打开的书籍（对智能体而言则作用于其工作副本），打开的角色标签页会立即显示变更。角色通过其**名称**指定（不区分大小写），当两个角色同名时，也可以通过 `/list-characters` 中的**编号**（即名称的排序序号）指定。关系通过 `/list-character-relations` 中的编号指定。修改角色的命令只会处理你提供的字段；空文本会清除简介或备注。图标只能在对话框中设置。

| 命令 | 作用 |
|---|---|
| `/list-characters` | 按名称排序列出角色：简介、颜色、是否有备注、关系数量。仅读取。 |
| `/get-character character` | 显示一个角色及其备注和关系。仅读取。 |
| `/create-character name [tagline [note [color]]]` | 添加一个角色。`color` 格式为 `#rrggbb`。 |
| `/update-character character [name [tagline [note [color]]]]` | 修改一个角色。 |
| `/delete-character character` | 在确认后删除一个角色及其关系。 |
| `/list-character-relations [character]` | 列出所有关系，或某个角色的关系。仅读取。 |
| `/add-character-relation source target name [tagline [bidirectional]]` | 添加一条从 `source` 指向 `target` 的关系（*employs*）；若 `bidirectional` 为 `true`，则添加一条双向关系（两端相同，*friends*）。 |
| `/update-character-relation relationship [name [tagline]]` | 修改一条关系的名称或简介。 |
| `/delete-character-relation relationship` | 在确认后删除一条关系。 |
| `/character-tracker-map` | 以提示词所接收的文本形式输出角色及其关系。仅读取。 |

`character-tracker-map` 专为 [{%{`{{command::character-tracker-map}}`}%} 宏](../templates/macros.md#commands)设计：将其放入主模板、用户提示词或设定条目中，即可把角色放置在提示词中你想要的位置，而不是（或除了）角色标签页的自动插入。无论自动插入是否开启，它始终反映角色的当前状态。

添加和修改操作不具破坏性；只有 `delete` 类命令具有破坏性，智能体可以被设置为在执行前询问你。

<a id="phone"></a>

## 手机版

该标签页位于故事的抽屉中，与大纲并列，与[作者注释](authors-note.md)的位置相同。手机版的新一轮表单中同样提供了视角角色和在场角色的选择按钮。
