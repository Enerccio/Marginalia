# 스토리 노트

사이드바에 있는 책 전용 작은 위키입니다. 계획 중인 줄거리, 아직 쓸 준비가 되지 않은 아이디어, 마법 체계의 규칙, 악당이 정말 원하는 것 등을 페이지로 정리할 수 있습니다. 페이지는 당신의 생각을 당신의 말로 적은 것이며, 태그와 페이지 사이의 링크를 달 수 있습니다. 모든 생성 때마다 모델에 함께 보내지는 하나의 텍스트인 [작가 노트](authors-note.md)와 달리, 노트는 그 자체로는 모델에 전달되지 않습니다. [플롯 마법사](arc-outline.md#developing-the-plot-in-a-conversation)와 에이전트는 노트를 읽을 수 있으며, 허용하면 노트를 바꿀 수도 있습니다.

<a id="the-notes-tab"></a>

## 노트 탭

[스토리 편집기](../books/story-editor.md)의 왼쪽 사이드바에는 *개요* 옆에 **Notes** 탭이 생깁니다. 이 탭에는 책의 페이지가 제목 순으로 나열됩니다. 목록 위에는 **Add**(새 페이지), **tag**로 거르기(페이지에 태그가 붙으면 표시됨), 그리고 제목, 태그, 페이지 텍스트를 대상으로 하는 검색이 있습니다.

각 페이지에는 제목, 텍스트의 첫 줄, 태그가 표시됩니다. 페이지를 클릭하거나 펜 아이콘을 누르면 열립니다. 휴지통 아이콘을 누르면 확인 후 삭제됩니다. 제목 뒤에는 작은 표시가 두 가지 붙을 수 있습니다. 빗금 친 눈 모양은 페이지가 [어시스턴트에게 숨겨져](#what-assistants-can-see) 있다는 뜻이고, 마술봉 모양은 마지막 변경이 당신이 아니라 명령에서 나왔다는 뜻입니다.

![노트 탭: 어시스턴트에게 숨겨진 페이지(눈 표시)와 플롯 마법사가 내용을 추가한 페이지(마술봉 표시)](../../images/plugin-storynotes-tab.png)

<a id="a-page"></a>

## 페이지

페이지 대화상자에는 다음 항목이 있습니다.

| | |
|---|---|
| **제목** | 필수 항목이며, 책 안에서 고유해야 합니다(대소문자는 구분하지 않음). 대괄호나 세로 막대(`|`)는 쓸 수 없습니다. 다른 페이지들은 이 제목을 기준으로 링크합니다. |
| **태그** | 쉼표로 구분합니다. 목록을 거르는 데 쓰입니다. |
| **텍스트** | Markdown입니다. **Write**와 **미리 보기**로 텍스트 편집과 완성된 모습을 전환합니다. 텍스트 안의 `[[Title]]`는 그 제목의 페이지로 링크되고, `[[Title|other words]]`도 같은 페이지로 링크되지만 미리 보기에서는 *다른 말*(`[[Language barrier|how they talk]]`)로 표시됩니다. |
| **Visible to assistants** | 기본으로 켜져 있습니다. 아래 설명을 보세요. |

텍스트 아래에는 대화상자가 이 텍스트가 **링크하는** 페이지 목록을 보여 줍니다. 존재하는 페이지로의 링크는 그 페이지를 열고, 존재하지 않는 페이지로의 링크에는 **Create**가 표시되어 그 제목으로 새 페이지를 만들 수 있습니다. 그 아래에는 **이 페이지로 링크하는** 페이지들이 나열됩니다. 페이지 이름을 바꾸면 다른 페이지들에 있는 이 페이지로의 `[[links]]`가 함께 바뀝니다(링크에 표시되는 말은 그대로 남습니다).

![링크하는 페이지와 이 페이지로 링크하는 페이지가 표시된 페이지](../../images/plugin-storynotes-page.png)

**미리 보기**는 텍스트를 Markdown으로 보여 주며, 모든 `[[link]]`를 링크로 표시합니다. 링크를 클릭하면 그 페이지가 열립니다(존재하지 않는 페이지로의 링크를 클릭하면 그 제목으로 새 페이지가 시작됩니다).

![같은 페이지의 미리 보기](../../images/plugin-storynotes-preview.png)

**저장**을 누르기 전까지는 아무것도 저장되지 않습니다. 변경된 페이지를 닫으려 하면 변경 사항을 버리기 전에 확인을 요청합니다. 편집하는 동안 명령으로 페이지가 바뀌었다면, 당신의 버전이 그것을 덮어쓰기 전에 확인을 요청합니다. **Ctrl/Cmd+Enter**로도 저장할 수 있습니다. 페이지는 책과 함께 저장되므로 책의 백업과 사본에도 포함됩니다.

<a id="what-assistants-can-see"></a>

## 어시스턴트가 볼 수 있는 것

"어시스턴트"란 노트가 제공하는 명령들을 가리키며, 에이전트, 매크로, 플롯 마법사가 이를 사용합니다. **Visible to assistants**가 꺼진 페이지는 어시스턴트에게는 존재하지 않는 것과 같습니다. 목록에 나오지도, 검색되지도, 읽히거나 변경되지도 않으며, 그 페이지에만 있는 제목으로 어시스턴트가 페이지를 만들려 하면 거부됩니다. 당신만 봐야 할 내용에 대해서만 끄세요. 꺼 둔 페이지도 백업에는 그대로 남습니다.

명령어 목록입니다(명령 막대와 에이전트용이며, 제목은 페이지의 주소입니다).

| 명령 | |
|---|---|
| `/list-notes [<tag>]`, `/get-note <note>`, `/search-notes <query>` | 페이지 목록, 한 페이지의 텍스트·링크·이 페이지로 링크하는 페이지들, 그리고 검색. |
| `/create-note <title> [<content> [<tags>]]` | 페이지를 추가합니다. |
| `/append-to-note <note> <text>` | 페이지 끝에 단락을 추가합니다. |
| `/update-note <note> [<title> [<content> [<tags>]]]`, `/edit-note <note> <find> <replace> [<all>]` | 페이지를 변경하거나 텍스트의 일부를 바꿉니다. `find`는 페이지에 정확히 적힌 그대로(대소문자 구분) 있어야 하며, `all`가 `true`가 아니라면 정확히 한 번만 나와야 합니다. `all`를 쓰면 나오는 곳이 모두 바뀝니다. 이름이나 용어를 페이지 전체에서 바꿀 때 유용합니다. 응답에는 몇 군데가 바뀌었는지 나옵니다. 이 명령들은 이미 있는 텍스트를 바꾸므로 *파괴적*입니다. 확인 후 실행하도록 설정된 에이전트는 먼저 당신에게 묻습니다. |
| `/delete-note <note>` | 페이지를 삭제합니다(확인 후). |
| `/note-text <note>` | 매크로용으로 페이지의 텍스트를 가져옵니다. {%{`{{command::note-text::Magic}}`}%}는 그 텍스트를 템플릿에 넣습니다. 존재하지 않거나 숨겨진 페이지라면 비어 있습니다. |

명령으로 바뀐 페이지는 당신이 직접 저장할 때까지 마술봉 표시가 붙습니다.

<a id="with-the-plot-wizard"></a>

## 플롯 마법사와 함께

이 확장 기능이 설치되어 있으면, Arc Outline의 [플롯 마법사](arc-outline.md#developing-the-plot-in-a-conversation)에는 **Send the notes** 옵션(제목과 첫 줄, 전체 텍스트, 또는 없음)과 **Notes** 도구 그룹이 있습니다. 모델은 페이지를 검색하고 읽으며, 페이지 간 링크를 따라가고, 당신이 무언가를 보관하라고 요청하면 페이지를 추가하거나 기존 페이지에 덧붙일 수 있습니다. 또한 한 페이지의 텍스트를 바꿀 수 있습니다. *Ask me before it changes or deletes something*이 켜져 있는 동안에는 페이지 텍스트를 바꾸기 전에 먼저 묻습니다. 마법사는 페이지를 삭제할 수 없습니다. 옵션과 도구 그룹에 대한 자세한 내용은 마법사 표를 참고하세요.

![Notes 도구가 있는 플롯 마법사: 페이지를 읽고 거기에 미해결 질문을 추가한 모습](../../images/plugin-storynotes-wizard.png)

## 다른 확장 기능

이 확장 기능은 다른 확장 기능에 두 가지 텍스트 소스를 제공합니다([Side Query](side-query.md)는 플러그 버튼에서 이것들을 첨부할 수 있습니다). **Story notes (titles)**와 **Story notes (all)**입니다. 둘 다 숨겨진 페이지는 제외합니다.
