# xAI Grok

xAI の Grok モデルを、xAI 自身の API を通して [推論プロバイダー](../inference-providers.md)として追加します。

Grok は、通常の *OpenAI Compatible* プロバイダーと URL `https://api.x.ai/v1` を使っても利用できます。この拡張機能は xAI API に直接接続するため、推論を推論として表示でき、xAI が報告する正確なトークン数（推論トークンを含む）を取得でき、このサービス向けに作られたモデル一覧と接続テストを利用できます。

!!!warning ストーリーのテキストは xAI に送信されます
このプロバイダーを使う AI へのリクエストはすべて、xAI のサーバー（`api.x.ai`、または設定したプロキシ）に送信されます。これには、ストーリーを含むプロンプト、ロアブックの項目や要約、モデルの回答、エージェントやコマンドが送る画像が含まれます。xAI での取り扱いは、API に関する xAI の利用規約とプライバシーポリシーによって決まります。他のプロバイダーは、あなたが選んだサーバー（自分で運用するサーバーの場合もあります）に送信します。xAI に送信してよいと確信できないテキストには、このプロバイダーを使わないでください。他のユーザーと共有しているサーバーでは、このプロバイダーの AI を共有する管理者は、その AI を使う全員のストーリーのテキストを xAI に送信することになります。
!!!

<a id="installing"></a>

## インストール

[拡張機能の管理](../administration/extensions.md)で説明しているとおり、*Admin → Extensions* で拡張機能を読み込みます。読み込むと、推論プロバイダーのダイアログの **Type** リストに **Extension** の項目が追加され、*Per Type Settings* タブ上部の **Provider** リストに **xAI Grok** が表示されます。

<a id="adding-a-grok-provider"></a>

## Grok プロバイダーの追加

1. [xAI Console](https://console.x.ai) で API キーを取得します。
2. **Inference Providers** タブで **Add Inference Provider** をクリックし、**Name** を入力して、タイプに **Extension**、プロバイダーに **xAI Grok** を選びます。
3. *General Settings*（コンテキストサイズ、応答サイズ、[推論](#reasoning)）と、*Per Type Settings* タブのプロバイダーの設定を入力し、**Test Connection** をクリックします。

| Field | |
|---|---|
| **Api Key** | xAI Console のキーです。暗号化して保存され、再び表示されることはありません。プロバイダーを編集するときに別のキーを入力するには **Reset** をクリックします。 |
| **Model** | 使用するモデルです。例: `grok-4` や `grok-3-mini`。**Refresh** をクリックすると、キーで使えるモデルが一覧に表示されます。一覧にない名前も入力できます。 |
| **URL** | 任意です。空欄にすると xAI の API（`https://api.x.ai/v1`）を使います。リクエストをプロキシ経由で送る場合に設定します。 |
| **Timeout (seconds)** | xAI の応答を待つ時間、および書き始めた後にさらにテキストを待つ時間です。既定値は 300 です。 |
| **Retries** | xAI がレート制限（429）やサーバーエラー（5xx）を返したとき、または接続できなかったときに、リクエストを繰り返す回数です。既定値は 2 で、0 にすると再試行を行いません。 |
| **Send the reasoning effort** | *Automatic* では `grok-3-mini` のみに推論の強度を送ります。*Always* はすべてのモデルに送ります。*Never* はどのモデルにも送りません。 |

**Test Connection** は、モデルの一覧を取得し、選んだモデルに数トークン分の応答を求めます。ダイアログに入力した値（保存する前の値）を使います。

<a id="reasoning"></a>

## 推論

推論の設定は、他のプロバイダーと同様に、プロバイダーの一般設定にあるものです。推論をオンにすると、モデルが示す推論は、ストーリーの部分の推論として表示されます。強度は、それを受け付けるモデル（`grok-3-mini`）にだけ送られます。値は *low*、または medium と high の場合は *high* です。それ以外の Grok モデルは、既定のとおりに推論し、このパラメーターを受け付けません。

<a id="what-works"></a>

## 動作する機能

ストリーミング、停止、JSON スキーマ、モデルが呼び出せる関数、添付の画像（JPEG、PNG）とテキストファイル、共有 AI の制限、使用量の集計は、OpenAI 互換プロバイダーと同じように動作します。使用量は xAI が報告した値です。推論トークンは生成されたトークンとして数えます。温度、top p、[プロトコル](../protocols.md)のペナルティは、有効にしている場合に送信されます。推論モデルの中には、ペナルティを受け付けないものがあります。サポートしていないものは、xAI のサーバー側ツール（ライブ検索、コード実行）と、画像や動画の生成です。
