# 폴더

폴더는 디스크의 폴더가 파일을 정리하듯 책을 정리합니다. 폴더에는 책과 다른 폴더를 넣을 수 있고, 깊이에 제한도 없습니다. 책 목록에는 한 번에 한 폴더의 내용만 표시됩니다. 폴더에는 **설정**(언어, 시점, 시제, 문체, 템플릿과 프롬프트)도 담을 수 있습니다. 폴더 안의 책과 그 아래 폴더의 책은 자체 설정이 없는 한 이 설정을 따라 집필합니다. 폴더를 쓰는 주된 이유가 여기에 있습니다. 시리즈의 문체를 한 번 정해 두면, 그 시리즈의 모든 책이 같은 문체를 갖게 됩니다.

![폴더가 있는 Books 탭](../../images/books-folders.png)

<a id="moving-around"></a>

## 이동하기

책 목록 위에는 현재 폴더 안의 폴더들이 정렬된 열 순서대로 표시됩니다. 폴더의 **이름**을 클릭하면 그 폴더가 열립니다. 목록 위의 버튼 경로(`Books / Sci-fi / Expanse`)는 현재 위치를 보여 줍니다. 경로의 일부를 클릭하면 그 위치로 돌아갑니다.

**하위 폴더 포함** 체크박스를 선택하면 현재 폴더 아래의 모든 책이 깊이와 상관없이 표시됩니다(최상위 폴더에서는 모든 책이 표시됩니다). 이때 각 책이 속한 위치를 보여 주는 **폴더** 열이 추가됩니다. 현재 폴더와 체크박스 상태는 페이지를 다시 불러와도 기억됩니다.

폴더 행에는 그 아래에 있는 책의 수가 깊이와 상관없이 표시됩니다. 책 행에는 책의 [활성 분기](branches-and-story-tree.md)에 있는 단어 수와 토큰 수가 표시됩니다. **이름**과 **태그** 필터는 책뿐 아니라 폴더에도 적용됩니다(폴더에도 태그를 달 수 있습니다. [폴더에 태그 달기](#tagging-folders) 참고). 필터는 현재 폴더에서 동작하며, *하위 폴더 포함*을 선택하면 그 아래 폴더까지 적용됩니다.

폴더의 **마지막 수정** 시각은 그 안의 책을 따릅니다. 폴더 안의 책이나 그 아래 폴더의 책(또는 책의 파트)이 바뀌면 폴더도 함께 갱신됩니다. 이 열로 정렬하면 마지막으로 집필한 위치를 찾을 수 있습니다. 책을 열거나 옮기는 것은 수정으로 치지 않습니다.

<a id="what-the-buttons-do"></a>

### 버튼의 기능

| 버튼 | |
|---|---|
| **새 폴더** (헤더) | 현재 폴더 안에 폴더를 만듭니다. 이름은 비워 둘 수 없고, 255자를 넘을 수 없으며, `/`를 포함할 수 없습니다. 같은 위치에 있는 다른 폴더와 이름이 같아서도 안 됩니다(대소문자는 구분하지 않습니다). |
| 폴더의 톱니바퀴 | [폴더 설정](#folder-settings)을 엽니다. |
| 폴더의 연필 | 폴더 이름을 바꿉니다. |
| 폴더의 휴지통 | 폴더를 삭제합니다. [폴더 삭제](#deleting-a-folder)를 참고하세요. |
| **폴더로 이동** (책) | 책을 넣을 폴더를 고릅니다. |
| 책의 별 | 책을 [즐겨찾기](#favorites)에 추가합니다. |
| **책 추가**, 가져오기 | 새 책은 **현재 폴더**에 들어갑니다. [복제본](managing-books.md#cloning-a-book)은 원본 바로 옆에 놓입니다. |

<a id="folder-settings"></a>

## 폴더 설정

폴더의 톱니바퀴를 누르면 설정이 열립니다(**정리하기** 창에도 같은 버튼이 있으며 단축키는 `i`입니다).

![폴더 설정](../../images/folder-settings.png)

- **이름**, **설명**, **태그**.
- **언어**와 책의 [프롬프트](prompts.md) 탭과 같은 항목들: 마스터 템플릿, 시점, 시제, 문체, 프롬프트.
- **파트별 보관 버전 수**: 폴더 안의 책과 그 아래 폴더의 책에 대해 파트마다 이전 버전을 몇 개까지 [기록](version-history.md#how-many-versions-are-kept)에 남길지 정합니다. 위의 제한들이 모두 적용될 때는 책에 가장 엄격한 값이 적용됩니다.
- **확장 기능 설정**: 불러온 [확장 기능](../extensions/index.md)에 책이 상속받는 설정이 있을 때 나타납니다. [확장 기능 설정](prompts.md#settings-of-extensions)을 참고하세요.

모든 항목은 선택 사항입니다. 비어 있는 항목은 *상속*되며, 그 사실이 표시됩니다. 항목의 회색 글자는 상속받는 값이고, 그 아래 줄은 그 값이 어디서 왔는지 알려 줍니다. 폴더를 저장하려면 **저장**을 누르세요. 이름과 설명은 언제든 바꿀 수 있습니다. 하지만 언어나 텍스트 설정을 바꾸는 것은, 해당 폴더 안이나 그 아래에 있는 책에서 에이전트가 작업 중일 때는 거부됩니다. 메시지에 해당 책의 이름이 나오니, 먼저 [실행을 일시 중지하거나 멈추세요](../agents.md).

<a id="where-the-settings-of-a-book-come-from"></a>

### 책의 설정은 어디서 오는가

책은 각 설정 항목에 대해 아래 목록에서 처음으로 비어 있지 않은 값을 사용합니다.

1. 책 자체(*정보*와 *프롬프트* 탭),
2. 책이 들어 있는 **폴더**,
3. 그 위의 폴더, 그리고 최상위까지 같은 방식으로 이어지는 상위 폴더들,
4. **사용자 설정**(*Settings → Templates*, [계정 및 설정](../account.md) 참고),
5. **내장 기본값**.

빈 텍스트는 설정되지 않은 것으로 봅니다. 이 값은 필요할 때 찾아봅니다(파트를 생성하거나, 요약을 만들거나, 파트를 다시 쓸 때 등). 책을 폴더에 넣을 때 설정이 책에 복사되지는 않습니다. 따라서 **책을 다른 폴더로 옮기면 집필 방식이 바뀌고**, 폴더의 설정을 바꾸면 자체 설정이 없는 아래 책들의 집필 방식도 바뀝니다.

책의 [프롬프트](prompts.md#inherited-settings) 탭에서 이를 확인할 수 있습니다. 각 항목 아래에 값의 출처가 표시됩니다(*Inherited from the folder "Sci-fi"*, *내 설정에서 상속됨* 또는 *내장 기본값*).

<a id="language"></a>

### 언어

책의 **언어** 상자([정보](managing-books.md#the-about-tab) 탭)와 폴더의 **언어** 상자는 비워 둘 수 있으며, 이는 *상속*을 뜻합니다. 이 경우 책은 자신보다 위에 있는 가장 가까운 폴더 중 언어를 설정한 폴더의 언어를 따르고, 그런 폴더가 없으면 영어를 씁니다. 비어 있는 상자에는 어떤 언어가 쓰이는지와 그 출처가 표시됩니다. 상자에는 지우기 버튼이 있습니다. 이를 누르면 다시 상속 상태가 됩니다(예전에는 영어로 바뀌었습니다). 책의 언어를 표시하거나 사용하는 모든 곳은 폴더와 함께 정해진 언어를 씁니다. 텍스트의 하이픈 처리, 내보내기, [일괄 언어 변경](#mass-changes) 표가 여기에 해당합니다.

<a id="deleting-a-folder"></a>

## 폴더 삭제

폴더의 휴지통 버튼을 누르면 어떻게 할지 묻습니다.

- **빈 폴더**는 확인 후 삭제됩니다.
- **책이나 폴더가 들어 있는 폴더**에는 **내용을 상위 폴더로 이동**(기본값) 또는 **Delete everything in it as well**이 제시됩니다. 두 번째 항목을 고르면 책과 폴더의 개수를 보여 주며 다시 한번 묻고, 책은 [Trash](../trash.md)로 보내져 나중에 복원할 수 있습니다. 삭제한 폴더 자체는 Trash 목록에 나타나지 않습니다.

안에 있는 폴더의 이름이 상위 폴더에 이미 있는 폴더 이름과 같으면 내용을 위로 옮길 수 없습니다(이름은 고유해야 합니다). 이 경우 둘 중 하나의 이름을 먼저 바꾸세요. 에이전트가 작업 중인 책이 들어 있는 폴더는 삭제하거나 이동할 수 없습니다. 실행 중에 그 책의 설정이 바뀌기 때문입니다.
<a id="organise"></a>

## 정리하기

목록의 **관리** 메뉴에 있는 **정리하기**를 열면 두 개의 창으로 나뉜 대화상자가 나타납니다. 각 창에는 폴더가 하나씩 표시되며, 책과 폴더를 하나씩 열지 않고도 한쪽에서 다른 쪽으로 옮기거나 복사할 수 있습니다. 처음 열면 왼쪽 창은 지금 있던 폴더를, 오른쪽 창은 지난번에 보았던 폴더를 보여 줍니다.

![정리하기 창](../../images/organise-dialog.png)

| 키 | |
|---|---|
| 왼쪽 / 오른쪽 / Tab | 다른 창으로 이동합니다. |
| 위 / 아래 | 커서를 움직입니다. |
| Enter | 커서가 있는 폴더를 엽니다. |
| Backspace | 상위 폴더로 올라갑니다. |
| Space 또는 Insert | 커서가 있는 항목을 표시합니다. 이동하면서 표시하려면 Shift + 위 / 아래를 누릅니다. |
| 체크박스 클릭 | 항목을 표시하거나 표시를 해제합니다. **Shift + 클릭**을 하면 앞서 클릭한 체크박스와 지금 클릭한 체크박스 사이의 모든 항목을 표시하거나 표시를 지웁니다. |

창 아래쪽의 버튼 줄은 **표시한** 항목에 작업을 수행합니다. 표시한 항목이 없으면 커서가 있는 항목에 적용됩니다. 각 버튼의 단축키는 괄호 안에 표시됩니다.

| 버튼 | 키 | |
|---|---|---|
| **복사** | `c` | *다른* 창의 폴더로 복사합니다. |
| **이동** | `m` | 다른 창의 폴더로 옮깁니다. |
| **새 폴더** | `n` | 활성 창의 폴더에 새 폴더를 만듭니다. |
| **이름 바꾸기** | `Shift+r` | 커서가 있는 폴더나 책의 이름을 바꿉니다. |
| **삭제** | `Delete` | 목록에서와 같이 삭제합니다. |
| **폴더 설정** | `i` | 커서가 있는 폴더의 [설정](#folder-settings)을 엽니다. |
| **모델/프로토콜 일괄 변경**, **언어 일괄 변경**, **일괄 이름 변경**, **책에 태그 지정** | `p`, `l`, `Shift+n`, `t` | 표시한 책이나, 표시한 책이 없으면 활성 창 폴더의 책에 대해 [일괄 변경](#mass-changes)을 수행합니다. 대상에는 각자의 *하위 폴더 포함* 옵션이 적용됩니다. 일괄 이름 변경 후에는 두 창에 새 이름이 표시됩니다. |
| **고급 검색** | `f` | 활성 창 폴더에서 [검색](managing-books.md#advanced-search)을 수행합니다. 선택적으로 *하위 폴더 포함*을 켤 수 있습니다. 결과에는 **폴더에서 보기**가 있으며, 이를 누르면 해당 창이 그 위치로 이동하고 책이 표시됩니다. |
| **목록에서 폴더 표시** | `o` | 창을 닫고 활성 창의 폴더를 책 목록에서 엽니다. |

창을 닫으면 책 목록을 다시 읽어 들이므로, 만들거나 이동하거나 복사하거나 이름을 바꾸거나 삭제한 결과가 바로 표시됩니다. (목록이 보고 있던 폴더가 사라졌다면 최상위 폴더로 이동합니다.)

이 단축키들은 *설정*의 [키보드 단축키](../account.md#keyboard-shortcuts) 기능으로, 여기서 바꾸거나 지울 수 있습니다. 기본적으로 기능 키(F1~F12)는 지정되어 있지 않은데, Mac과 브라우저가 이 키들을 이미 사용하기 때문입니다. 버튼에는 설정한 단축키가 표시됩니다.

<a id="copying"></a>

### 복사

책을 **복사**하면 [복제](managing-books.md#cloning-a-book)가 만들어집니다. 이때 창은 현재 분기만 복사할지 물어봅니다. 폴더를 복사하면 원본의 설정, 설명, 태그를 그대로 가진 새 폴더가 만들어지고, 그 안의 모든 책과 폴더도 복사됩니다. 복사에는 시간이 걸릴 수 있으며, 진행 막대가 표시되는 동안에는 중지할 수 없습니다. 복사 도중 실패하면, 그 전까지 만들어진 복사본은 각각 완전한 상태로 남습니다.

**이동**은 즉시 실행되며, 다시 원래 위치로 옮기면 되돌릴 수 있습니다. 폴더를 자기 자신이나 그 하위 폴더 안으로 이동할 수는 없습니다.

<a id="when-a-name-is-taken"></a>

### 이름이 겹칠 때

대상 위치에 같은 이름의 폴더가 이미 있으면, 창은 그 폴더를 어떻게 할지 묻습니다. 나머지 항목에도 같은 선택을 적용하려면 **모두에 적용**을 사용합니다.

| 선택 | |
|---|---|
| **이름 바꾸기** | 폴더에 다른 이름이 붙습니다. |
| **건너뛰기** | 폴더는 원래 자리에 그대로 남고, 복사되지 않습니다. |
| **병합** | 폴더 안의 내용이 기존 폴더 안으로 들어갑니다. 안에 같은 이름의 폴더가 있으면 차례로 병합됩니다. |

책은 이름이 겹쳐도 충돌하지 않습니다. 책 이름은 중복될 수 있습니다.

<a id="mass-changes"></a>

## 일괄 변경

목록의 **관리 → 일괄 변경** 메뉴(및 정리하기의 버튼)를 사용하면 여러 책을 한 번에 바꿀 수 있습니다. **모델/프로토콜 일괄 변경**은 책들에 모델이나 프로토콜 중 하나 또는 둘 다를 지정하고, **언어 일괄 변경**은 언어를 지정합니다. **일괄 이름 변경**은 이름에 접두사나 접미사를 붙이고, 이름 안의 텍스트를 바꾸거나 번호를 매깁니다. **책에 태그 지정**과 **폴더에 태그 지정**은 태그를 추가하거나 제거합니다. 자세한 내용은 [책 관리](managing-books.md#tagging-many-books-at-once)를 참고하세요. 목록에서 실행하면 현재 폴더의 책을 대상으로 하며, 각 기능의 **하위 폴더 포함** 옵션을 따로 설정할 수 있습니다.

<a id="favorites"></a>

## 즐겨찾기

책 행의 별표를 누르면 그 책이 **즐겨찾기**에 추가됩니다. 즐겨찾기가 하나라도 있으면 최상위 화면에 가상 폴더 **즐겨찾기**(별 모양)가 나타나며, 모든 폴더에 있는 즐겨찾기 책들이 여기에 모입니다. 이것은 보기 전용 폴더입니다. 이 안에서 책이나 폴더를 만들 수 없으며, 별표를 해제하면 책이 즐겨찾기 목록에서만 빠지고 원래 폴더에는 그대로 남습니다. 즐겨찾기 정보는 설정에 저장됩니다.

<a id="tagging-folders"></a>

## 폴더에 태그 지정

폴더에도 책과 마찬가지로 태그를 붙일 수 있습니다. **관리 → 일괄 변경 → 폴더에 태그 지정**을 사용하면 여러 폴더에 한 번에 태그를 지정할 수 있습니다. 폴더의 태그를 바꿔도 그 안에 있는 책의 태그는 바뀌지 않으며, 태그는 [백업](backups.md)에도 포함되지 않습니다.

<a id="folders-and-other-features"></a>

## 폴더와 다른 기능

- **백업.** [백업](backups.md#backups-and-folders)은 책이 속한 폴더 정보를 기억하며, 내보내기 파일에는 책이 상속받는 설정을 함께 담을 수 있습니다.
- **에이전트.** [에이전트](../agents.md#agents-and-folders)는 책이 속한 폴더의 설정을 따라 글을 씁니다.
- **도움말 어시스턴트.** 허용하면 [어시스턴트](../administration/help-assistant.md#your-books)가 사용자의 책과 폴더를 조회할 수 있습니다.
- **휴대폰.** [휴대폰 레이아웃](../phone.md#books)은 같은 폴더를 카드 형태로 보여 주며, 폴더를 만들고, 이름을 바꾸고, 설정하고, 삭제할 수 있습니다. 정리하기와 일괄 변경은 헤더의 **⋮** 메뉴에 있습니다.
- **뷰어.** [뷰어](publishing.md#folders-in-the-list)도 폴더를 목록으로 보여 주며, 사용자가 마지막으로 보았던 폴더에서 열립니다.
