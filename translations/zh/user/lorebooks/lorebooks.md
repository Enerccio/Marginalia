# 创建知识书

<a id="the-lorebook-editor"></a>

## 知识书编辑器

打开 **Lorebooks** 标签页。编辑器一次只显示一本知识书；在顶部的 **Lorebook** 字段中选择要编辑的那一本。
知识书属于你的账户：其他用户看不到它们，除非你[分享](#sharing-a-lorebook)了某本。

工具栏分为两行，在窗口较窄时会换行到更多行：第一行用于知识书（从 **Lorebook** 到 **Tag lorebooks**），第二行用于所选知识书的条目（从 **Add Entry** 到 **Refresh**）。

| 按钮 | |
|---|---|
| **Lorebook** | 选择要编辑的知识书。 |
| **Only root lorebooks** | 仅列出不是其他知识书子知识书的知识书（所选知识书仍保留在列表中）。 |
| **Add Lorebook** | 创建一本名为 *New Lorebook* 的新知识书并选中它。 |
| Clone（两张纸图标） | 复制所选知识书：会要求输入名称（原名称加上 *(Copy)*），并选中副本。副本拥有相同的条目（包括其设置、标签和负面标签）、标签、描述和扩展数据。其子知识书不会被复制，副本使用的是相同的子知识书。原知识书不会被改动。 |
| **Delete Lorebook** | 删除所选知识书（需确认）。 |
| Import（文件图标） | **Import Marginalia Lorebook**、**Import from SillyTavern**、**Import from archive**（包含 `.md` 文件的 zip 压缩包）或 **Import from other user**（其他用户[分享](#sharing-a-lorebook)的知识书）。参见[导入与导出](import-export.md)。 |
| Export（文件图标） | 下载该知识书及其子知识书，参见[导入与导出](import-export.md#exporting)。 |
| Tags（标签图标） | **Tag lorebooks**：一次为多本知识书添加标签，参见[下文](#tagging-many-at-once)。在书中打开的知识书不显示此按钮。 |
| Description（横线图标，第一行最右侧） | **Edit description**：打开一个窗口，用于填写该知识书的内容简介，参见[下文](#description)。 |
| **Add Entry** | 向知识书添加条目，参见[条目与激活](entries.md)。 |
| **Full-screen editor** | 以带标签页的全屏窗口打开该知识书的条目，参见[全屏编辑](#editing-in-full-screen)。仅限桌面端。 |
| **Search and replace** | 替换该知识书条目的名称、正文和注释中的文字，参见[查找与替换](entries.md#search-and-replace)。 |
| **Mass edit** | 将该知识书及其子知识书的所有条目放在一个表格中打开，参见[批量编辑](#mass-edit)。 |
| Tags（标签图标，位于 **Search and replace** 右侧，第二行） | **Tag entries**：一次为所选知识书的多个条目添加标签，参见[下文](#tagging-many-at-once)。 |
| **Preview activation** | 输入一段文字，显示在一轮生成中会用到哪些条目以及原因，参见[预览激活](entries.md#preview-activation)。 |
| **Refresh** | 重新加载条目。 |
| 搜索框 | 仅显示包含所输入文字的条目，参见[搜索与删除大量条目](entries.md#searching-and-deleting-many-entries)。 |
| **Delete selected** | 在列表中选中条目时出现；确认后删除这些条目。 |

工具栏下方是所选知识书的设置：

| 字段 | |
|---|---|
| **Name** | 知识书的名称，在为某本书或作为子知识书选择它时显示。 |
| **Sub Lorebooks** | 其条目会与本知识书一同纳入的其他知识书，参见[下文](#sub-lorebooks)。点击已选子知识书的名称可打开它。 |
| **Tags** | 整本知识书的标签；它们会被视为其每个条目的标签，参见[标签](entries.md#tags)。 |
| **Scan depth** | `0` 至 `5`：已被使用的条目的内容会被搜索多少轮，以查找其他条目的过滤条件，参见[由其他条目引入的条目](entries.md#entries-brought-in-by-other-entries)。它对书所使用的知识书的条目及其子知识书的条目都起作用，除非某个子知识书有自己的扫描深度（下一行）。 |
| **Scan depth as a sub lorebook** | 留空，或填 `0` 至 `5`：当本知识书作为某本书所用知识书的子知识书时，其条目的扫描深度。留空表示使用该知识书的扫描深度，`0` 表示本知识书的条目永远不会被其他内容找到。 |
| **Enabled** | 取消勾选后，该知识书不提供任何内容，既不提供其条目，也不提供其子知识书的条目。 |
| **Share with other users** | 勾选后，其他用户可以查看该知识书并导入一份副本，参见[下文](#sharing-a-lorebook)。新知识书默认不勾选。 |

设置下方是该知识书的[描述](#description)（如果有的话）。

编辑器的其余部分是[条目](entries.md)列表。所有更改在你操作时即时保存。

### Description

描述是关于该知识书的几句话（或几行）：它描述的是什么世界、用途为何、由哪本书使用。点击工具栏第一行的横线图标，在窗口中写下描述后确认；若文本为空，则删除描述。有描述的知识书会在其设置下方以一行显示，放不下的部分以省略号截断；将鼠标指针停留在该行上可阅读全文。描述会随知识书一同复制（克隆、导出、导入、备份），并且当你分享该知识书时，其他用户会在知识书名称旁看到这段文字。

![知识书描述窗口](../../images/lorebook-description.png)

### Sharing a lorebook

勾选 **Share with other users**，本安装实例的每位其他用户都会在 **Import from other user**（工具栏第一行的导入按钮）中看到该知识书，并显示其名称、作者（你的全名；若未设置全名则显示登录名）以及描述。他们可以展开一行以阅读条目（以及子知识书的条目），并导入一份副本。取消勾选后，该知识书会从他们的列表中消失；他们已经制作的副本仍归他们所有。

* 分享仅限于读取。其他人不能更改、删除或在书中使用你的知识书；你的知识书仍然属于你，你看到的内容与以前一样。
* 导入会为**该其他用户**创建**新的知识书**：包括知识书本身及其**已分享的**子知识书（层级不限），连同其条目、标签和描述，并按照你的知识书的方式相互链接。副本是私有的（未分享），你之后对自己知识书的任何操作都不会影响副本，副本中的改动也不会影响你的知识书。
* **只有本身已分享的子知识书才会被显示和复制。** 未分享的子知识书连同其下方的所有内容都会被排除在外，包括位于它下方的已分享知识书。当你在一本带有未分享子知识书的知识书上勾选 **Share with other users** 时，会出现一个提问，询问是否也分享它们：**Yes** 会分享该知识书及所有子知识书（层级不限），**No** 只分享该知识书，**Cancel** 不分享任何内容并保持复选框未勾选。之后添加的子知识书在你单独分享之前不会被分享。
* 取消勾选只会停止分享该知识书；其子知识书仍保持分享状态（并会在其他人的列表中单独出现），直到你也取消勾选它们。
* 已删除的知识书、智能体的工作副本以及你自己的知识书都不会出现在列表中；已被删除的用户也不会有任何内容被列出。

在设置下方会显示该知识书已启用条目的 token 估算值。紧挨着它的 **Count with subbooks** 链接会统计该知识书及其所有子知识书（层级不限）中已启用条目的 token 总数，并在旁边显示合计值。与撰写故事时一样，被禁用的子知识书会连同其下方的知识书一并排除在外；若某知识书在多处作为子知识书出现，则只计算一次。该合计值是你点击那一刻的统计：更改某个条目后它会消失，再次点击即可重新统计。

智能体正在处理的书所使用的知识书以只读方式显示（参见[智能体](../agents.md)），不显示 **Add Entry**、**Search and replace**、**Mass edit**、**Delete Lorebook** 以及设置项；**Add Lorebook**、导入、导出和 **Refresh** 仍然保留，以便你随时开始另一本知识书。

## 批量编辑

**批量编辑**会打开一个窗口，把所选世界书**及其子世界书**（无论嵌套多深）的每个条目都列在同一张表格中，按条目的**顺序**排列（先按世界书排，顺序相同的再按名称排）。它用于整理大型世界书：

- 可以像在编辑器中一样，直接修改条目的*启用*复选框、**条目名称**、**顺序**、**标签**、**过滤模式**、**过滤**、**插入模式**、**否定标签**、**激活上下文**及其**片段**、片段范围（**起始消息**和**结束消息**，留空表示不限制）以及条目的**备注**。每个条目占一行；表格可以上下滚动，窗口较窄时也可以左右滚动。修改顺序后，该行会移动到新的位置。表格中的条目文本会被缩短显示；如需阅读或编辑全文，请在世界书中打开该条目。
- 行中的**世界书**下拉框显示条目所属的世界书。选择另一个世界书（即该世界书本身或其任一子世界书）即可将条目移动到那里。
- 要移动多个条目，请勾选它们（表头的复选框可全选），然后在底部选择**移动到世界书**，再按**移动所选**。
- 要删除多个条目，请勾选它们并按**删除所选**；系统只会询问一次，然后将它们移入[回收站](../trash.md)。
- 正在被智能体使用的世界书会被锁定：其条目显示为灰色，无法修改或移动，也无法将条目移入其中。此检查针对每个世界书单独进行，因此某个子世界书被其他书占用而锁定时，其父世界书仍可能是可用的。点击**刷新**可重新读取窗口，以查看锁定是否已解除。

修改后关闭窗口时，编辑器中的世界书会随之刷新。

## 全屏编辑

**全屏编辑器**（工具栏第二行）在一个铺满屏幕的窗口中打开所选的设定集，便于编辑较长的条目（某个条目行中的展开按钮会打开窗口并定位到该条目）；书籍窗口的*设定集*标签页也有同样的按钮，用于打开其中显示的设定集。窗口标题为设定集的名称。它与[故事编辑器](../books/story-editor.md)一样是一组标签页：拖动标签页可将其放在另一个标签页旁边或下方，拖动它们之间的分隔条可调整大小。

![全屏设定集编辑器：条目列表和两个打开的条目标签页](../../images/lorebook-fullscreen.png)

- **条目**标签页列出条目，并提供设定集页面上的搜索框以及标签和状态筛选器，还有**添加条目**、**批量编辑**、**为条目加标签**、**预览激活**和**刷新**（批量编辑和标签操作的变更也会在已打开的标签页中显示）。勾选**包含子设定集**后，它也会列出[子设定集](#sub-lorebooks)中的条目，并标明每个条目所属的设定集；此时**添加条目**会把条目添加到其旁边所选的设定集中，此类条目的标签页会标明其所属设定集。该标签页无法关闭。每一行有三个按钮：
  - **打开**（铅笔图标，双击该行也可以）在你最后使用的条目标签页中显示该条目；若没有这样的标签页，则在列表右侧的一列中打开一个新的标签页；
  - **在新标签页中打开**（箭头图标）为该条目添加一个标签页，位于你最后使用的条目标签页旁边；
  - **删除**（垃圾桶图标）在确认后删除该条目，并关闭其标签页。

  同一条目最多只在一个标签页中打开：再次打开时会显示它已有的那个标签页。
- **条目标签页**从上到下包括：**名称**、**顺序**和**启用**；**设置**面板（可折叠），其中是该条目的其余设置（筛选模式和筛选器、插入模式、激活上下文和部分、标签和负面标签、部分范围、递归复选框及条件，参见[条目与激活](entries.md)）；然后是 Markdown 编辑器中的**内容**（每个标签页会记住它显示的是文本、文本与预览，还是仅预览，重新打开窗口时同样保留）；当勾选**显示备注**时，内容旁边会出现**备注**。眼睛图标会打开该条目的[激活预览](entries.md#preview-activation)。底部一行显示内容的估计令牌数，若模板有问题则以红色显示问题所在（仍会保存）。关闭标签页请点击其**×**。
- **条目中的图片。**将图片粘贴到内容中、拖放到内容上，或使用工具栏的图片按钮选择（PNG、JPEG、GIF 或 WebP，最大 10 MB）。图片存放在你的文件中（*资源*标签页），内容中光标所在处会出现一行类似 `![地图](resource:…)` 的文本；预览会显示图片，方括号中的文字即为图片说明。删除该行即可从条目中移除图片。模型读取条目时会忽略这些行。只有当模型设置中勾选了*发送设定图片*时，图片本身才会发送（参见[推理服务商](../inference-providers.md)）。图片随设定集一起流转：副本、共享设定集的复本、导出的设定集文件以及带文件的书籍备份都会携带图片，而复本会获得自己的图片。SillyTavern 导出和书籍导出则不包含图片。故事的*设定集*标签页会在条目文本下方显示图片。目前图片不计入令牌估算。
- **在条目之间跳转。**在内容中（无论是正文还是预览）按住 Ctrl 点击（Mac 上为 Cmd+点击）另一个条目的名称或关键词，即可在你最后使用的条目标签页中打开该条目；再加上 Shift 则在新标签页中打开。底部一行还会在**提及于：**之后列出内容中提到本条目的其他条目；点击其中一个即可打开，Shift+点击则在新标签页中打开。条目通过其名称以及其筛选器中的词语被提及（每个关键词、*文本*筛选器的整段文字、正则表达式匹配的内容），按整词匹配，不区分大小写。这与[递归](entries.md)所遵循的规则相近但并不相同：递归还会匹配较长单词中的关键词，要求 *AND* 筛选器的所有关键词都出现，并检查标签和条件。
- Markdown 编辑器有一个工具栏（粗体、斜体、删除线、分隔线、标题、引用、代码、代码块、表格以及三种列表），右侧为*编辑*、*编辑与预览*（默认）和*预览*三种视图。常用快捷键可用（Ctrl+B、Ctrl+I 等）；Tab 键会移动到下一个字段而不是缩进。你输入的内容会在停止输入片刻后以及离开编辑器时保存。
- 标题栏显示已启用条目的估计令牌数，以及**包含子书籍计数**和**搜索与替换**；后者也会在已打开的标签页中替换文本。

所有更改在你做出时即被保存，因此点击**关闭**不会丢失任何内容。窗口会为每个设定集记住你的离开状态：下次以相同条目、相同标签页打开时，布局也相同（期间已删除的条目会被略去）。关闭窗口后，设定集页面会重新显示条目。

**在别处所做的更改。**标签页中的更改会以该条目当前保存的状态写入条目，因此在别处（设定集页面、批量编辑、另一个窗口）对条目*其他*字段所做的修改会保留，并且标签页会显示这些修改。如果自标签页显示以来，**内容**或**备注**在别处被修改过，你的文本不会覆盖已保存的内容：底部一行会提示这一点，并提供**保留我的文本**（仍然保存你的文本）和**加载已保存的文本**（放弃你的文本）两个选项。在别处被删除的条目会关闭其标签页。

窗口在打开期间也会跟随已保存的变化：当某个智能体或另一个窗口（另一个浏览器标签页、故事的设定集标签页）保存或删除条目时，列表会重新加载，该条目的标签页会显示其当前状态（已删除条目的标签页随之关闭）。等待**保留我的文本**或**加载已保存的文本**选择的标签页会保持原样，直到你作出选择。在你输入的同一秒内保存的更改仍可能出现交叉：此时底部一行会按上述方式询问。

**智能体。**当智能体正在处理使用该设定集的书籍时，该窗口不可用。如果窗口打开期间智能体开始运行，窗口会在你下一次更改或切换标签页时变为只读；一个提示栏会指明该智能体（并说明你最近的一次更改是否未能保存）。暂停或停止运行后，点击**重新检查**：条目会按运行留下的状态重新加载，你即可再次编辑。

[设定生成器](../extensions/lore-generator.md)和[设定集版本控制](../extensions/lorebook-vcs.md)扩展在此同样可用：魔杖图标位于列表的行中以及条目标签页的名称行中，版本面板位于列表上方，条目的版本栏位于其标签页中。

## 批量加标签

工具栏上的两个标签按钮会打开同一个窗口，用于为多个项目添加或移除标签：**为设定集加标签**列出你的设定集，**为条目加标签**列出所选设定集中的条目。选择**标签**（或输入新标签并按 Enter）；列表会显示每个项目及其标签，带有所选标签的项目排在前面，并突出显示该标签。每行的**+**和**-**按钮可为该项目添加或移除标签；勾选多个项目（表头的复选框可全选），然后使用底部的**为已勾选项添加标签**或**从已勾选项移除标签**即可一次性处理。智能体正在处理的项目（运行中书籍所使用的设定集，因而其所有条目也都一样）会变灰，在运行暂停或停止之前无法更改。该窗口同样可为[书籍](../books/managing-books.md#tagging-many-books-at-once)加标签。它为条目添加的标签是普通标签，参见[标签](entries.md#tags)；负面标签则直接设置在条目本身上。

## 在书籍中使用设定集

打开书籍及其**设定集**标签页，在**设定集**字段中选择设定集。下方的编辑器会显示该设定集，因此你在写作时即可添加和修改条目。清空该字段即可在不使用设定集的情况下写作。

一本书只使用一个设定集。若要使用多个设定集，请新建一个将它们作为子设定集包含在内的设定集，并使用这一个。

同一个设定集可被任意数量的书籍使用。对它的更改会从下一个生成的部分起影响所有这些书籍；已经写好的部分仍保留写作时所用的设定。
<a id="sub-lorebooks"></a>

## 子设定集

**子设定集**会把其他设定集的条目纳入当前设定集。典型的设置如下：

```
"Saga"（供本系列各书使用）
 ├─ "World"       地点、历史、魔法规则
 ├─ "Characters"  主要角色
 └─ "Book 2 notes"
```

- 子设定集自身也可以有子设定集，所有层级都会被纳入。
- 一个设定集可以同时是多个设定集的子设定集。若它被多次引用，其条目仍只会被使用一次。
- 设定集不能直接或通过其他设定集间接包含自身。这种选择会被拒绝，并提示 *Cannot select sub lorebook: cycle detected.*
- 被禁用的子设定集及其包含的全部内容都会被排除在外。

![一个包含两个子设定集的设定集：有这些子设定集和没有时的词元](../../images/lorebook-sub-lorebooks.png)

所有被纳入的设定集的条目会合并在一起，并按其 [顺序](entries.md#order-and-insertion) 排序，无论它们来自哪个设定集。

<a id="disabling-and-deleting"></a>

## 禁用与删除

取消勾选 **Enabled**，可暂时关闭某个设定集，例如想看看没有它时书的内容读起来怎样。使用该设定集的书会保留这一引用，重新勾选后它即恢复生效。

**Delete Lorebook** 会将该设定集从你的列表中移除。引用它的书不再获取其条目，把它作为子设定集包含的设定集也会跳过它。数据会保留在数据库中，直到管理员运行 [清理](../administration/cleanup.md)；在此之前，你可以从 [回收站](../trash.md) 恢复该设定集。[书籍备份](../books/backups.md) 和导出的文件中的副本不受影响。
