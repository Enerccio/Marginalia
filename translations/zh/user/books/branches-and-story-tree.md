# 分支与故事树

Marginalia 从不让你丢弃任何版本。你尝试过的每一种替代写法都会保留为故事的一条**分支**，你可以随时回到其中任何一条。

<a id="how-the-story-tree-works"></a>

## 故事树如何运作

每一部分都接续它前面的部分。当某一部分有多个续写时，故事就会分叉：从第一部分到任一结尾的每条路径都是一条分支。

```
#1 ─ #2 ─ #3 ─ #4 ─ #5          ← 分支 A
           └─ #4' ─ #5' ─ #6'   ← 分支 B（当前）
```

**当前分支**是[故事编辑器](story-editor.md)显示并继续写作的那一条。只有它的部分会发送给模型，其他分支不会影响故事。

获得新分支的方式有三种：

| | 发生什么 | 旧版本 |
|---|---|---|
| **换一版**（最后一部分） | 模型为最后一部分重新写一个版本。 | 作为单独的分支保留。 |
| **从此分支**（任意部分） | 故事从这一部分开始，在新分支上继续。 | 此后的部分仍留在旧分支上。 |
| **重新生成**（最后一部分） | 模型原地重新写最后一部分。 | 被替换，不会创建分支。 |

*换一版*和*重新生成*只出现在最后一部分的菜单中；*从此分支*出现在每一部分的菜单中。

<a id="trying-another-version-of-the-last-part"></a>

## 尝试最后一部分的另一版本

如果你不满意最后一部分，请在它的菜单中选择**换一版**。模型会基于相同的[回合详情](story-editor.md#turn-details)重新写这一部分，新版本成为当前分支的结尾。之前的版本会保留为它自己的分支；你可以在[分支视图](#the-branch-view)中切换回去。

如果想在再次尝试前修改应当发生的内容，请打开最后一部分的**回合详情**，编辑其中的指令。

如果不需要旧版本，就使用**重新生成**：它会覆盖这一部分。

<a id="branching-from-an-earlier-part"></a>

## 从较早的部分分支

如果想从较早的某个节点让故事朝另一个方向发展，请打开该部分的菜单，选择**从此分支**。Marginalia 会将该部分复制到一条新分支上，并使其成为当前分支的结尾，因此故事编辑器现在以这一部分结束。照常点击 **+** 继续写作即可。

此后的部分并不会丢失：它们仍留在旧分支上。

被复制部分的[摘要](summaries.md)会随之一并复制。

<a id="the-branch-view"></a>

## 分支视图

**分支视图**标签页显示整个故事树。每一部分是一张卡片，上面有日期、场景设定、在场角色和指令；将鼠标悬停在卡片上即可查看全部细节。

![故事树](../../images/story-tree.png)

- **当前分支**的各部分会高亮显示，其最后一部分带有标记。
- **点击其他分支的最后一部分**即可将该分支设为当前分支。书籍会切换到*故事*标签页并显示该分支。只有分支的末端可以被点击；若要从中间的某一部分继续，请使用[从此分支](#branching-from-an-earlier-part)。
- 没有任何分叉的长段（超过 20 个部分）会被折叠为一个区块，只显示开头的十个和结尾的十个部分。点击该区块即可显示全部部分。

<a id="searching-all-branches"></a>

### 搜索所有分支

树上方的输入框会搜索本书**所有分支**的文本，而不仅仅是当前分支。输入你要找的内容，然后按 **Enter** 或点击**搜索**；输入框会记住你最近的搜索，从列表中选择即可重复该搜索。输入框中的 **x** 用于清除搜索。

- 当某一部分的文本包含你输入的**每一个词**（顺序不限）时，该部分即为匹配项：`lighthouse key` 会找到同时包含这两个词的部分。若要查找短语，请将词语放在双引号中：`"lighthouse key"`。
- 使用 `*` 代表任意字符：`light*` 可以找到 *lighthouse* 和 *lightning*。其他字符，包括 `%`、`_` 和 `\`，都按其字面原样搜索。
- 大小写不敏感。对于带重音的字母，用小写输入的词也能找到同一个词的大写或首字母大写形式（`žluťoučký` 可以找到 *Žluťoučký* 和 *ŽLUŤOUČKÝ*）。
- 只搜索部分的正文，不搜索指令、场景设定或世界书。你已删除的部分不会被搜索。

![带有搜索结果的分支视图](../../images/story-tree-search.png)

输入框旁边的复选框**包含版本**，还会查找各部分更早的[文本版本](version-history.md#searching-the-old-text)；仅在旧版本中含有这些词的部分同样会被高亮，并会注明是哪个版本，且在**在故事中显示**旁边还有**在历史中显示**。

每一个匹配的部分都会以橙色**高亮**显示，并展示匹配处周围的文字；树上方的那一行会告诉你找到了多少个部分。原本会被折叠的长段，如果其中包含匹配项，也会自动展开。搜索结果会一直保留，直到你清除搜索或关闭书籍窗口；当你回到该标签页时，高亮会被更新。

点击高亮部分中的**在故事中显示**即可阅读它：

- 如果该部分位于当前分支上，书籍会切换到*故事*标签页并滚动到该部分。
- 如果它位于其他分支上，则该分支会先变为当前分支。该分支会在找到的部分之下、最近的分支末端处结束（若有两个末端，则取较新的那个），因此故事编辑器会显示到找到的部分为止的故事，以及其后的内容。随后书籍切换到*故事*标签页并滚动到该部分，该部分会短暂闪烁。

切换分支的效果与在树中点击某个分支末端相同：不会丢失任何内容，之前的分支保持原样，你可以从树中切换回去。

<a id="deleting-parts-and-branches"></a>

## 删除部分与分支

部分菜单中的**删除**只会移除该部分。其后的部分会向上移动，并接续其前面的部分。若要删除整条分支，请从末端开始逐个删除其中的部分。

*关于*标签页中的字数与词元数会同时显示整本书（所有分支）和当前分支的数值。
