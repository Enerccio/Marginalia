# リアル言語翻訳

物語の登場人物に**実在の言語**で話させます。たとえば日本を舞台にした物語を、あなたとモデルが英語で書き進めると、登場人物の直接話法が本物の日本語（仮名と漢字、またはローマ字）に変換され、その背後に英語が残ります。語彙集を使わない点を除けば、[Conlang Translator](conlang-translator.md) と同じ考え方と同じ画面を持つ、実在する言語向けの翻訳機能です。

!!!
物語の本文には**翻訳文**が入ります。モデルに物語を読ませるすべてのもの（次の生成、要約、ロアブックの走査、注釈、他の拡張機能）は、話した内容を翻訳する元となった**英語**を読みます。そのため、あなたは英語で物語を書き、方向づけを行います。翻訳された発話をクリックすると英語が表示されます。
!!!

!!!warning 作業中
部分・範囲・文単位の翻訳、設定、本の「タブ」、ビューア、エクスポート、[コマンド](#commands)は実装済みです。翻訳文を磨く二回目の処理、1冊の本での複数の実在言語、登場人物ごとの言語指定は未実装です。[制限事項](#limits)を参照してください。
!!!

<a id="the-idea"></a>

## 考え方

1. **言語**とは、翻訳機能に与える短い規則の集まりです。規則には、**文字体系**（仮名と漢字、仮名のみ、ローマ字）、名前に敬称を付けるかどうか、話話者と聞き手の関係から**話し方のレベル**をどう選ぶか、**名前**をどう書くか、その他守らせたいことが含まれます。言語そのものはモデルが知っているので、語彙集は要りません。言語は設定に一度保存すれば、いくつの本でも使えます。
2. **本**（またはフォルダー内の本）が言語を選びます。部分は、そのメニューから**手動で**、確定したときに**自動で**、または**範囲をまとめて**翻訳できます。
3. 部分ごとに、モデルへの要求は1回です。その要求で、直接話法のひとつひとつが分類されます（この登場人物がこの言語で話しているか、英語で話しているか、聞き手に理解されるか）。そのうえで、言語で話すとされた発話を、登場人物と関係が求める口調と話し方のレベルで翻訳します。
4. 英語は本のデータの中に、発話の*原文*として保持され、すべてのモデルが読みます。翻訳文が本来の文章です。あなたが手で変えた部分は残り、編集した部分が知らないうちに上書きされることはありません。

拡張機能は、無料で確認できることは確認します。引用された発話が部分の中にあるか、言語が本の言語と一致するか、翻訳が指定された**文字体系**になっているか（ローマ字の翻訳に漢字が含まれる、あるいは仮名のみの翻訳に漢字が含まれる場合は、そのまま残され、*報告*されます）を検査します。日本語そのものの正しさは検査できません。長い実行の前に、いくつかの部分を読んで確かめてください。

## 言語

言語は**設定 → 拡張機能の設定 → Real Language Translator**で編集します。

| ボタン | |
|---|---|
| **Add** | 新しい言語を追加します。最初は**プリセット**のどれか（仮名と漢字の日本語、仮名のみ、ローマ字、またはその他の言語）から始まり、項目が埋まります。必要に応じて変更してください。 |
| **Edit**、**Delete**、**Move up**、**Move down** | 選択中の言語に対する操作です。削除時には確認が出ます。 |
| **Duplicate** | 新しい名前を付けた独立した複製を作ります。ある言語を選んでいる本は、その言語を選んでいる他のすべての本と共有されます。一冊の本のためだけに言語を残したいときは、複製を作ってください。 |

編集画面には次の項目があります。

![設定画面の言語一覧](../../images/plugin-reallang-settings.png)

| 項目 | |
|---|---|
| **Name** | 言語の呼び名です（「小説用のローマ字の日本語」など）。 |
| **モデルが言語を呼ぶ名前** | 言語での発話に対して、モデルが答えに使う語です（「Japanese」）。空欄の場合は名前が使われます。 |
| **Script** | *Kana and kanji*（仮名と漢字）、*Kana only*（仮名のみ）、*Romaji (Latin letters)*（ローマ字）、*Another script (not checked)*（その他の文字体系・検査なし）のいずれかです。 |
| **Write the honorific suffixes of names** | san、sama、kun など、名前に付く敬称を書くかどうかです。 |
| **Also write how it is read (romaji)** | 翻訳文の読み方もモデルに書かせます。読み方はポップオーバーで英語の上に表示されます。 |
| **Politeness and speech level**、**Names of people and places**、**Other rules** | 翻訳者に与える短い文章です。日本語のプリセットは、最初の二つについて文章を用意しています（親しい対等の間柄では普通体、見知らぬ人にはです・ます体、目上の人には敬語。外国の名前はカタカナで書く）。 |

![言語の編集画面](../../images/plugin-reallang-editor.png)

一覧の下には、本やフォルダーがあなたの設定から**継承する**選択肢があります。言語、部分を単独で翻訳するかどうか、翻訳に使うモデルとプロトコルです。変更を保存するには、設定画面で**Save**を押してください。

## 本の言語を選ぶ

本のウィンドウの**Prompts**タブには、*Extension Settings*の下に拡張機能の項目があります。フォルダーのウィンドウも同じ項目を持ちます。空欄は*継承*を意味し、上位のフォルダー、次にあなたの設定が使われます。

| 項目 | |
|---|---|
| **Language of the speech** | 本を翻訳する先の言語です。空欄の場合、本は翻訳されません。 |
| **Translate a new part by itself** | 部分が確定したときに翻訳します。生成の後、本に自動注釈と再執筆があればそれらの後、そして[部分の後に続く処理](../books/story-editor.md#what-follows-a-generated-part)の一段階として翻訳されます（実行パネルに表示され、その**Stop**で停止できます）。 |
| **Model of the translation**、**Protocol of the translation** | 空欄の場合は本のモデルとプロトコルが使われ、それもなければあなたの既定値が使われます。 |
| **Readers of the published book see** | [ビューア](#what-the-reader-sees)に表示される内容です。 |

## 本の Real language タブ

物語のウィンドウには、この本の言語のための**Real language**タブがあります（章やロアブックと同じドックにあります）。**Refresh**で再読み込みできます。

![物語の Real language タブ。話者と理解度を表示](../../images/plugin-reallang-tab.png)

**Speakers（話者）。** この本でその言語を話す人を指定します（[複数の言語](#more-than-one-language-in-a-book)を持つ本では、言語ごとに*Speakers*タブがあります）。初期状態では、一覧に挙げられた登場人物を除くすべての人がその言語を話します（または、挙げられた人だけが話します）。本文の記述が、これを上書きします（「彼女は英語で言った」「衛兵は一言も理解できなかった」など）。登場人物ごとに**性別**と**声**を記入してください。話し方のレベルは、これに従います。年齢、地位、そして他者への話し方をここに書いてください（「若い士官。目上には丁寧で、友人にはぶっきらぼう」など）。それが、翻訳者に普通体と敬語のどちらを選ぶかを判断させる材料になります。話者は本に属します。

各登場人物には**理解度**も設定できます。*まったく分からない*、*少し分かる*、*だいたい分かる*、*すべて分かる*から選べます。空欄（または*すべて分かる*）にすると、モデルには何も伝えられません。言語を話さずに聞くだけの人々に使ってください（*Tomáš: まったく分からない（日本語）*、*村人たち: だいたい分かる*など。名前は単なる文字列なので、集団でも構いません）。理解度は**本全体を通じて固定**され、情報としてモデルに渡されます。登場人物がそれにどう反応するかはモデルに任されますが、指示の中で補足することもできます（「Tomáš は彼らの言うことが分からない」など）。理解度がモデルに届くのは二つの経路です。**物語のモデル**には、理解度を示す短いメッセージが届きます（Author's Note と同様にプロンプトに挿入されます。一覧の上のチェックボックスでオフにでき、数字は末尾から何件目に入れるかを示します）。また、**部分を見直すモデル**（*AI で注釈を付ける*）には、事実の一節として理解度が渡されるため、理解できない言葉に反応する登場人物を指摘できます。文章の配置を自分で決めたい場合は、挿入をオフにし、テンプレートの中で {%{`{{command::reallang-understanding}}`}%} [マクロ](../templates/macros.md#commands)を使ってください。マクロは、残す登場人物の任意の一覧を受け取ります。

**Languages（言語）。** 本のその他の言語です。**Language of the speech**の項目で指定された言語以外のものを示します。詳しくは[下記](#more-than-one-language-in-a-book)を参照してください。

**Quick translate（クイック翻訳）。** 英語の文章を書き、必要に応じて誰が誰に言うかを書き、**Translate**を押します。モデルが、言語の規則に従って翻訳します（複数の言語がある場合は、どの言語にするかを選びます）。物語には何も書き込まれません。翻訳をコピーして使ってください。

**Glossary（用語集）。** 物語の名前と特別な語を、その言語でどう書くかを定めます（[後のセクション](#the-glossary-of-names-and-special-words)）。本の言語ごとに*Glossary*タブがあります。
<a id="the-glossary-of-names-and-special-words"></a>

## 用語集の単語と特別な語

用語集がないと、翻訳はパートごとに名前の書き方を選び直します。たとえば `Saellen` がある部分では `サエレン`、次の部分ではラテン文字のまま、というように揺れ、`Tomáš` は `トマーシュ` になったり `トマシュ` になったりします。用語集はその選択を一度だけ固定します。エントリには次の項目があります。

- **単語**：物語が書くとおりの語（`Saellen`、`witch`）。エントリの見出しになり、大文字小文字は区別しません。
- **言語での書き方**：その言語での表記（`サエレン`、`魔女`）。タイトル、地名、訳さない造語の場合は *keep it as it is*（そのまま）。
- **読み**（任意。読みのある言語で使用）：たとえば `魔女` の読みは `ウィッチ`。
- **メモ**：翻訳者向けの注記（登場人物が受ける敬称、姓名の順序など）。
- **適用するかどうか**。

**3つのレベルを統合。** 言語の用語集は3つのレベルにあります。**言語**レベル（*Settings → Extension Settings* の言語エディタ内。この言語のすべての本の名前と用語）、本が置かれている**フォルダ**のレベル（シリーズは、そのシリーズの本が共有する名前を定義します。フォルダはネストできます）、そして**本**レベル（その本だけのもので、最もよく使われます）。モデルに渡されるのは両者の**和集合**です。同じ単語については**最も近いレベルが優先**されるので、本はフォルダとは別の書き方を使えます。*Real language* タブの *Glossary* タブには、すべてのエントリが出所のレベルとともに表示され、各エントリはそれが置かれている場所で変更できます。上位レベルの単語でこの本では使うべきでないものは、**この本では無効化**できます（本の中で無効になったエントリ。同じ操作で再び有効にするか、削除すると上位レベルの単語が戻ります）。本のエントリが共通のものだとわかった場合は、フォルダまたは言語へ**引き上げ**できます。フォルダと本の用語集は、本の**言語ごとに**保持されます。名前は言語ごとに書き方が異なるためです。

**翻訳での使われ方。** 用語集はリクエストの一部なので、モデルはリストどおりに単語を書きます。100エントリまでの用語集はすべてのリクエストに丸ごと含まれます（プロンプトをキャッシュするサーバーは一度だけ読み込みます）。それより大きい場合は、そのパートに関係するエントリだけを含めます。回答を受け取った後、プラグインはそれを**チェック**します。英文に用語集の単語があるのに、訳文がその単語を用語集どおりに書いていない発言は、そのまま残され**報告**されます（判断は著者に委ねられます）。用語集にない名前について、モデルが書き方を選ばなければならなかった場合は、その名前が本の用語集に**提案**として追加されます（*Status* 列には *Proposed* と表示されます）。以後モデルはその名前を使い、*Accept* で確認済みにするか、*Edit* で変更できます。どのレベルにもすでにある単語（無効化されたものも含む）は、二度と提案されません。

![本の用語集：3つのレベルのエントリと、承認を待つモデルの提案語](../../images/plugin-reallang-glossary.png)

![用語集のエントリ](../../images/plugin-reallang-glossary-entry.png)

![言語エディタの末尾にある用語集](../../images/plugin-reallang-editor-glossary.png)

用語集に関するコマンドは下の表にあります。用語集が存在する前に本が翻訳したパートは、その翻訳を保持します。用語集を使うには、もう一度翻訳してください。

<a id="extracting-the-words-by-model"></a>

## モデルによる単語の抽出

長い本の場合、用語集を手作業で書くのは時間がかかります。*Real language* タブの用語集タブの隣にある **Word extraction** タブでは、モデルに**パートの範囲**を読ませ、そこに出てくる名前と特別な語を、各言語での形とともに一覧にさせます。見つかったもののうち、用語集にまだないものは、本の用語集に**提案**として追加されます。モデルは次のリクエストから使い、*Glossary* タブで承認、編集、削除できます。物語本文は変わりません。

![Word extraction タブの実行後：モデルが見つけた用語が提案として用語集に入っている](../../images/plugin-reallang-extraction.png)

- **Language**：本に複数の言語がある場合、用語集の対象となる言語。
- **Prompt**：モデルへの指示。何を探すか、各種の語がその言語でどう書かれるかを示します。ライブラリから選ぶか、*None: only my specification*（なし：自分の指定のみ）を選びます。プラグインには日本語用のプロンプトが付属しています（実在の地名や組織は通常の日本語表記、架空の外国語の名前はカタカナ、日本語の名前は読みを付けた漢字、世界の造語は漢字とカタカナ読み、*gikun*（ぎくん））。このプロンプトは *built-in*（組み込み）と表示され、常に利用できます。
- **Specification**：*この本*のための自由記述。プロンプトの後に追加されます。除外するもの（端役など）、ある種類の語のこの本での書き方、希望する綴りを書けます。プロンプトがない場合は、これだけがモデルに伝えられます。
- **From part / To part** の後に **Extract the words**。パートは順に読まれ（1パートは遅いモデルで数分かかることがあります）、タブには *Part 3 of 12* のように表示されます。**Stop** を押すと、読み込み中のパートの後で停止します。失敗したパートは数えられ、実行は続きます。言語、モデル、またはプロンプトと指定の両方がない場合は、実行は終了します。

用語集にすでにある単語（どのレベルにあっても、無効化されたものも含む）はモデルに伝えられ、再び提案されることはありません。同じ範囲で二度目を実行すると、新しいものだけが追加されます。モデルが用語を入れた*カテゴリー*（「Fictional coined term / gikun」など）は、エントリのメモに書き込まれます。出力の形式を指定する必要はありません。プラグインは、プロンプトの内容にかかわらず、決まった形式を要求します。

**プロンプトのライブラリ。** *Settings → Extension Settings → Real Language Translator* には **Extraction prompts** の一覧があります。名前と指示を持つ自分のプロンプトを、追加、編集、削除、並べ替えできます。**Copy a built-in prompt** を押すと、組み込みプロンプトのコピーが自分の一覧に入り、変更できます。プロンプトは本ではなくあなたのものです。本は、選んだプロンプトと指定を記憶しています。

![設定にある抽出プロンプトのライブラリ](../../images/plugin-reallang-prompts.png)

## 1冊の本に複数の言語

日本語話者と韓国語話者が登場する物語では、両方が必要です。本では**最初の言語を1つ指定**します（上記の項目。フォルダや設定がこれを与えることもあります）。**Languages** タブでは、ライブラリから**他の言語**を1つずつ追加し、また取り除けます。

- **言語ごとに話者が決まります**。それぞれの言語は専用のタブで話者を設定します。最初の言語は、以前と同じく、リストに載せたキャラクター以外の全員が話します。**追加した言語は「リストされた登場人物だけが話す」状態で、誰もリストにない状態から始まります**。そのため、誰かを話者に加えるまでは何も求められません。ある登場人物の言語が別だった場合は、その人物を最初の言語の例外として載せてください。さもないと、最初の言語がその人物の発言も求められてしまいます（二つの言語が同じ発言を主張する場合、先に求められた方が保持します）。登場人物は複数の言語を話せます（両方のリストに載せます。パートの本文が、発言がどの言語かをモデルに伝えます）。
- **言語ごとに1回のリクエスト**：ある言語のルールと注記、そしてその言語の話者の発言だけです。二つの言語の発言を含むパートは、二回のリクエストを順に行います。二回目は、一回目の言語の発言が英語のままの状態でパートを読み、それらの発言は翻訳済みのまま残します。視点人物と登場人物がすべてある言語の話者の外にあるパートは、その言語については求められません（誰も名前が出ないパートは、話者がいるすべての言語について求められます）。
- **発言は自分の言語を知っています**。ある言語について **Translate dialogs (real language)** をもう一度実行すると、他の言語の発言は変わりません。**Put the English back** は、一つの言語について、またはすべての言語について実行できます。
- **メニューは、本に複数の言語がある場合にどの言語かを尋ねます**：パートのメニュー（言語のいずれか、または *All languages*）と、選択した文の右クリック（一つの言語）。
  **Translate parts** には *Language* 欄があります（既定ではすべての言語）。*the parts that are not translated*（翻訳されていないパート）は、「その言語で翻訳されていない」という意味です。
- **自動実行**では、新しいパートが、話者が現れうるすべての言語へ翻訳されます。
<a id="translating"></a>

## 翻訳

- **手動で:** 部の メニューには **翻訳** サブメニューがあります(テキスト上の右クリックにもあります)。そこには **翻訳ダイアログ（実言語）** があります(これらの項目と **部を翻訳（実言語）** は、この プラグインの言語を持つ本でのみ表示されます)。すでに翻訳された部は、**英語から** 再度翻訳されます。複数の言語を持つ本では、まず [どの言語か](#more-than-one-language-in-a-book) を尋ねられます。
- **自動で:** **新しい部を自動で翻訳** を使うと、生成された部は確定するとすぐに翻訳されます。部の*再生成*では新しい英語が生成され、古い翻訳は削除されます。
- **翻訳の後の動作。** 一つの部の翻訳(手動、選択範囲、または自動)はページを塞ぎません。翻訳は左下の [実行パネル](../books/story-editor.md#the-panel-of-the-runs) に一覧表示され、モデルの **推論** や **回答** の末尾が届くたびに表示され、**停止** ボタンがあります。その間、部には *部の発話を翻訳中...* と表示され、他の操作では翻訳できません。**停止** はリクエストをすぐに取り消し、それ以降の処理を開始しません。複数の言語がある場合、それより前に書かれた言語は翻訳済みのまま残ります。[範囲](#translating) の翻訳には専用のウィンドウがあり、物語の横で開いたままになります。
- **モデルが見落とした発話:** 翻訳で発話が英語のまま残ることがあります。部のメニューの **翻訳 → 見落とした発話を翻訳（実言語）** は、まだ英語のままの発話だけを翻訳し、翻訳済みの発話はそのまま残します。テキストを選択している場合は、右クリックの **翻訳 → 選択範囲にある見落とした発話を翻訳（実言語）** で、選択範囲に触れている発話を翻訳します。モデルには部がそのままの状態で送られ、翻訳済みの発話も含まれたまま、英語のままの発話だけを求めるため、部全体を翻訳するよりも低コストです。書き出されるのは発話だけなので、モデルが発話として認識していない文を翻訳する手段ではありません。その場合は *選択したテキストを翻訳* を使ってください。
- **自分で書いた文:** 部のテキストで文を選択し、右クリックして **翻訳 → 選択したテキストを翻訳（実言語）** を選びます。モデルは前後の物語を踏まえて翻訳します。英語は原文として保持されます。翻訳済みの発話を含む選択範囲は受け付けられません。
- **範囲:** 物語のツールメニューにある **部を翻訳（実言語）** は、物語の横で開いたままになるウィンドウを開きます。ここでは、部から部までを対象に、*未翻訳の部を翻訳*、*翻訳済みの部をもう一度翻訳*、または *英語に戻す* を **停止** とともに実行できます。

![部の範囲を翻訳するウィンドウ](../../images/plugin-reallang-range.png)

翻訳は、テキストへのあらゆる変更と同様に保存されます。部の履歴にはバージョンが追加され、部は **編集済みとしてマークされません**。英語も保持されます。**手動で変更した発話は、** 部が再翻訳されたり英語に戻されたりしても **そのまま残ります**。あなたの言葉が含まれているためです。

<a id="what-the-reader-sees"></a>

## 読者に見えるもの

翻訳された発話には **点線** が付きます。それをクリックすると、ポップオーバーに英語が表示されます。ポップオーバーには、(言語が求める場合の)読み、話者、聞き手がその内容を理解できないかどうか、そして翻訳を作成した後にあなたが翻訳を編集した場合の赤い注記が含まれます。

**ソースを編集**(ポップオーバーのボタン。自分のビューでのみ使用可能)は、物語が持つ翻訳と、モデルが読む英語を並べて表示するウィンドウを開きます。ネイティブ話者が日本語を手で修正し、英語の内容が違うものになった場合や、モデルが英語を誤解した場合に使ってください。保存すると、その発話は新しい英語を持つことになり、現在の翻訳がその英語の対応する翻訳として採用されます(赤い注記は消えます)。モデルはその位置で新しい英語を読みます。部のテキストは変更されません。`reallang-edit-source` も、コマンドラインから同じことを行います。

**ソース内の検索と置換**(*Real language* タブの上部にある矢印のボタン)は、アクティブな分岐にある翻訳済み発話の英語ソースに対して、アプリケーションの検索と置換ウィンドウを開きます(プレーンテキストまたは正規表現)。変わるのはソースだけです。翻訳そのものの語句は、本の検索と置換で置き換えます。

![発話のソースを編集するウィンドウ](../../images/plugin-reallang-source.png)

![発話の英語ソースに対する検索と置換](../../images/plugin-reallang-search-replace.png)

![ポップオーバーに英語を表示した翻訳済みの発話](../../images/plugin-reallang-story.png)

[公開された本](../books/publishing.md) は、本の設定に従って表示します。**公開された本の読者に見えるもの** の設定により、*翻訳、クリックで英語*(既定値)、*翻訳のみ*(英語は読者のブラウザに送られません)、*英語のみ* から選べます。

<a id="exporting"></a>

## 書き出し

本に翻訳された発話がある場合、[書き出し](../books/export.md) ダイアログに **翻訳された発話（実言語）** の項目が表示されます。選択肢は、*翻訳をそのまま*、*英語のみ*、*翻訳を脚注付きで英語と共に*、*英語を脚注付きで翻訳と共に* です。書き出しによって本の保存されたテキストが変更されることはありません。

![翻訳された発話を含む書き出しダイアログ](../../images/plugin-reallang-export.png)

<a id="together-with-the-conlang-translator"></a>

## Conlang Translator との併用

一冊の本に両方を含めることができます。たとえば、エルフのための創作言語と、町のための日本語です。それぞれのプラグインは独自の話者、独自の言語設定、独自の箇所を持ち、両者の箇所は互いに干渉しません。すべてのモデルが読む英語には両方が戻されています。[書き出し](../books/export.md) では両者の脚注が一つの番号体系にまとめられ、ビューアは同じページに両方の発話を描画します。**公開された本の読者に見えるもの** には両方とも同じ値を設定してください。一つのページは、最初にそこに到達したプラグインによって一度だけ描画されます。
<a id="commands"></a>

## コマンド

画面でできることはすべてコマンドとしても使えます。[コマンドライン](../commands/index.md)からも、[エージェント](../agents.md)からも使えます。言語は**名前**（大文字・小文字は区別しません）またはIDで指定します。パートは、ハンドルか、有効な分岐上の位置（最初のパートは1）で指定します。

| コマンド | |
|---|---|
| `reallang-list`、`reallang-create`、`reallang-update`、`reallang-delete` | ライブラリの操作です。`reallang-create` は `preset`（`ja-kana-kanji`、`ja-kana`、`ja-romaji`、`other`）を受け取ります。`reallang-delete` は確認を求めます。 |
| `reallang-set-book-language` | 開いている本の言語です（その**拡張機能の設定**の**話し言葉の言語**欄）。 |
| `reallang-add-book-language`、`reallang-remove-book-language` | 開いている本のほかの言語です。削除するとユーザーに確認します。 |
| `reallang-status` | 本の言語と、翻訳済みのパートを表示します。 |
| `reallang-translate-part`、`reallang-translate-range`、`reallang-translate-sentence`、`reallang-translate-text`、`reallang-revert-to-source` | 翻訳です。1つのパート（`missingOnly` は、まだ英語のままの発話だけを翻訳します。`within` で一節を引用すると、その範囲に限定できます）、範囲（`mode` は *new* または *again*）、パート内の1文、結果を返すだけの文章、そして英語への差し戻しです。任意の `language` を指定すると、本のどの言語について行うかを選べます（省略時はすべての言語。文と文章は最初の言語）。 |
| `reallang-glossary`、`reallang-glossary-set`、`reallang-glossary-remove`、`reallang-glossary-accept`、`reallang-glossary-switch`、`reallang-glossary-move` | 特定の言語での開いている本の[用語集](#the-glossary-of-names-and-special-words)です。統合されたエントリをレベルとともに読み取り、`level`（`language`、`folder` と `folder` 名、`book`）でエントリを追加・変更し、1つを削除し（確認あり）、提案を承認し、上位レベルの語を本ごとに有効・無効に切り替え、本のエントリを上位へ移動します。 |
| `reallang-extract-terms`、`reallang-extraction-set` | [用語の抽出](#extracting-the-words-by-model)です。`reallang-extraction-set` は `prompt` を選び、開いている本の `specification` を書きます（除外する内容はそのまま残ります）。`reallang-extract-terms` はパートの from から to までを読み、用語を本の用語集への提案として出します（`language` で言語を指定）。 |
| `reallang-extraction-prompts`、`reallang-extraction-prompt-set`、`reallang-extraction-prompt-remove` | 抽出プロンプトのライブラリです。組み込みのものと自分のものを一覧し、追加または変更します（組み込みのものの名前を指定すると、コピーが作られます）。1つを削除します（確認あり）。 |
| `reallang-edit-source` | 翻訳された1つの発話の英語の原文を設定します（`part`、`speech` は `reallang-list-passages` が付けた番号、`source`）。現在の翻訳は、それが対応する訳文として扱われます。古い原文は置き換えられます。 |
| `reallang-get-source`、`reallang-list-passages` | 読み取りです。モデルが読む形のパートの本文（英語）と、パートの翻訳済み発話をその読み方と英語とともに表示します。 |
| `reallang-speakers`、`reallang-set-speakers-mode`、`reallang-set-speaker`、`reallang-remove-speaker` | 開いている本でその言語を話す人です（`language` で本の言語の一つを指定します。省略時は最初の言語）。`reallang-set-speaker` では `understands`（理解のレベル）も設定できます。 |
| `reallang-set-understanding-prompt` | 理解のレベルを物語のプロンプトに自動的に挿入するかどうか、また末尾から何件のメッセージを対象にするかを設定します。 |
| `reallang-understanding` | どの登場人物がどの言語を理解しないかを、テキストとして返します。{%{`{{command::reallang-understanding::<characters>}}`}%} の[マクロ](../templates/macros.md#commands)で使われます（登場人物の指定は任意です）。 |

言語は数行の規則で、エージェントの実行用の作業コピーはありません（Conlang Translatorは語彙とともに言語をコピーします）。そのため、言語を作成または変更するエージェントは、あなたのライブラリを直ちに変更します。話者、本の設定、そして発話は本のものであり、実行時のコピーの本がそれらを保持します。

<a id="limits"></a>

## 制限事項

- **品質はモデルに依存します。** 日本語では敬語が最も難しい部分です。規則と文字に関する注記がこれを導きますが、人が読んで確認する少数のパートが、それで十分かどうかを決めます。
- **話者が、どの言語に問い合わせるかを決めます。** パートの視点と、そこに登場する人物をもとに判断されます。話者が一覧にない言語では、パートで名前が挙がっていない人物による発話を見落とすことがあります。リクエスト内では、テキストのパートが判断します。
- **自然さのために翻訳を書き直す第二のパスはありません。** 逆翻訳による確認もまだありません。
- **ふりがなはありません。** 読みは、ページ内のルビではなく、ポップオーバーの1行として表示されます。
- **別の翻訳プラグインで翻訳されたパート**は、このモデルが、その訳文を含むテキストとして読みます（英語ではありません）。そこの発話が別の言語である、ということだけが伝えられます。
- **スマートフォン**では、パネルと編集画面が使えます。物語側（メニュー、範囲のウィンドウ、物語内のクリック）は試されていません。
