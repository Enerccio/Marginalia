# スマートフォンでMarginaliaを使う

Marginaliaには、スマートフォン向けのレイアウトがあります。スマートフォンのブラウザから、パーツの執筆、編集、再生成、ロアブックの編集、モデルの管理、そして（管理者であれば）インストール全体の管理ができます。スマートフォンのレイアウトは**デスクトップ版の複製ではありません**。同じ内容が1列に配置され、いくつかのウィンドウはより簡素になり、すべての拡張機能が動作するわけではありません。このページでは、その違いを一覧にします。

スマートフォンで本を読むには、それ向けに作られた[ビューア](books/publishing.md)もあります。

<a id="when-the-phone-layout-is-used"></a>

## スマートフォンのレイアウトが使われる条件

Marginaliaは、ページを読み込んだ時点のブラウザウィンドウの幅を確認します。768ピクセルより狭いとスマートフォンのレイアウトになり、それより広いと通常の[ワークスペース](index.md#the-workspace)になります。

- 横向きのタブレットやスマートフォンは通常768ピクセルより広いため、デスクトップ版のレイアウトになります。
- レイアウトは**作業中には切り替わりません**。スマートフォンやタブレットを横に倒したり、ウィンドウのサイズを変えたりしても、**ページを再読み込みする**までレイアウトは変わりません。そのため、タブレットや横向きにしたスマートフォンで大きいデスクトップ版のレイアウトにしたいときは、向きを変えてから再読み込みします。スマートフォンのレイアウトに戻すには、元の向きに戻してからもう一度再読み込みします。
- デスクトップのブラウザで幅を狭くしたウィンドウも、スマートフォンのレイアウトになります。試してみるのに便利です。

デスクトップ版と同様に、スマートフォンのレイアウトもブラウザのメニューから（*Install app* / *Add to Home Screen*）アプリのようにホーム画面に追加できます。

<a id="the-workspace"></a>

## ワークスペース

左側のタブは**ドロワー**に置き換えられています。上部バーのメニューボタンをタップしてドロワーを開き、タブをタップして切り替えます。現在のタブは画面全体を占め、その名前が上部バーに表示されます。

![ドロワーを開いたスマートフォンのワークスペース](../images/phone-workspace-drawer.png)

ドロワーにはデスクトップ版と同じタブがあります（*Books*、*Lorebooks*、*Settings*、*Protocols*、*Inference Providers*、*Agents*（[エージェント](agents.md#on-a-phone)の利用が許可されたユーザーのみ）、*Resources*、*Trash*）。管理者には、さらに*Admin*（デスクトップ版のボタンはここではタブになります）があります。下部には**Language**セレクター、**Change Password**、**Logout**があります。拡張機能はボタンを追加できますが、スマートフォン上で拡張機能が対応している場所にのみ追加されます。[拡張機能](#extensions)を参照してください。

*Settings*タブに保存されていない変更があるときは、デスクトップ版と同じくドロワーがロックされます。先に保存するか、変更を破棄してください。

<a id="books"></a>

### 本

本の一覧は1列で表示されます。その上には、名前のフィルター、タグのフィルター、並べ替えのボタン（*Last Modified*、*Created*、*Name*。現在選ばれているものをもう一度タップすると順序が逆になります）があり、その次に**Add Book**、虫眼鏡（[高度な検索](books/managing-books.md#advanced-search)：含めるタグと除外するタグ、日付、パーツ数、テキスト）、更新ボタンが並びます。各本には次のボタンがあります。星は本をお気に入りにし、**Move to folder**は本を[フォルダ](books/folders.md)に移動し、鉛筆は本を開き、ゴミ箱は本を削除します（[ゴミ箱](trash.md)へ移動します）。

![スマートフォンの本の一覧](../images/phone-book-list.png)

デスクトップ版と同様に、一覧には一度に1つの[フォルダ](books/folders.md)が表示されます。現在いるフォルダへのパスは、戻るためのボタンとして表示されます。チェックボックス**Include subfolders**の下には、本の上にフォルダが並びます（フォルダをタップすると中に入ります。フォルダの下にある本の数が表示されます）。最上位の階層には、仮想フォルダ**Favorites**もあります。名前とタグのフィルターは現在のフォルダを検索します。*Include subfolders*をオンにすると、その下のすべてを検索します。**Add Book**とインポートは、新しい本を現在いるフォルダに追加します。現在いるフォルダは記憶されます。

![スマートフォンのフォルダ](../images/phone-folders.png)

![本の一覧のメニュー](../images/phone-books-menu.png)

フォルダは、ヘッダーの**New folder**ボタンで作成します。名前の変更、設定（説明、タグ、言語、そのフォルダ内の本で使うモデルとプロトコル）、削除は、各行の**⋮**ボタンから行えます。ヘッダーの**⋮**ボタンには、多数の本に対して操作するためのウィンドウがあります。**Organise**（フォルダの2つのペインは、スマートフォンでは上下に重ねて表示されます。キーボードのヒントはありません）、**Tag books**、**Tag folders**、そして[フォルダ](books/folders.md)の一括変更（モデルとプロトコル、言語、名前の変更）です。本の言語は、ここでフォルダから継承させることもできます。*Prompts*タブには、各値がどこから来ているかが表示されます。

<a id="lorebooks"></a>

### ロアブック

スマートフォンには、デスクトップ版の**ロアブック編集画面全体**が1列のレイアウトで用意されています。ロアブックは入力欄で選びます。その横の**⋮**ボタンを押すと、ロアブックのメニューが開きます。メニューには**Add Lorebook**、**Clone**、**Delete**、**Import**（ロアブックファイル、SillyTavernのファイル、Markdownファイルをまとめたzipアーカイブ、他のユーザーが共有したロアブック）、**Export**（ロアブックまたはSillyTavern形式）、**Tag lorebooks**、**Edit description**があります。*Enabled*チェックボックス、トークン数、**Search and replace**と**activation preview**のボタンの下にある**Settings**セクションを開くと、ロアブックの名前、サブロアブック、タグ、スキャンの深さ、*Share with other users*の設定ができます。詳しくは[ロアブック](lorebooks/index.md)を参照してください。

その下には、**Add Entry**（および、多数のエントリに対する一括編集とタグ付けのための**⋮**）、検索ボックス、エントリの一覧があります。エントリは、有効チェックボックスと名前が1行に並んで表示されます。開くとフォームが表示されます。フォームには、名前、順序、タグ、フィルタリングのモードとテキスト、挿入のモード、除外タグ、アクティベーションの文脈とその範囲、*Also search the summaries*、*Prevent recursion*、*Only through other entries*、内容、メモ、**Delete entry**があります。変更された内容は、デスクトップ版と同様にすぐに保存されます。検索ボックスの下には、一覧を絞り込むためのタグとステータスのボックスがあります。**⋮**メニューの**Select entries**を選ぶと、すべてのエントリの前にチェックボックスが表示され、チェックしたものに対して**Delete selected**が表示されます。ここにないものもあります。チェックボックス*Only root lorebooks*です。

ドロワーの*Lorebook*タブ（物語の画面）では、デスクトップ版のタブと同じように、本の設定をもとにロアを表示します。検索ボックスがあり、エントリは開くと内容が表示され、ペンのアイコンでエントリのテキストを編集できます。

本の*Lorebook*タブでも、同じエディターが使われます。本のロアブックにサブロアブックがある場合は、その下の**Shown lorebook**ボックスで、本のロアブックを変えずにタブの表示を任意のサブロアブックに切り替えられます（元に戻すこともできます）。その本を使う[エージェント](agents.md)が作業している間は、ロアブックはテキストとして表示され、中身は変更できません。

![スマートフォンのロアブック](../images/phone-lorebook.png)

![スマートフォンのロアブックのメニュー](../images/phone-lorebook-menu.png)

![ロアブックの設定](../images/phone-lorebook-settings.png)

![フォームを開いたエントリ。上にロアブックのVCSのリビジョンが表示されている](../images/phone-lorebook-entry.png)

*Enabled*チェックボックスの横のボタンを押すと、ロアブックのエントリに対する**Search and replace**が開きます。詳しくは[エントリ](lorebooks/entries.md#search-and-replace)を参照してください。

![スマートフォンでのロアブックの検索と置換](../images/phone-lorebook-search-replace.png)

<a id="settings-protocols-providers-resources-trash"></a>

### 設定、プロトコル、プロバイダー、リソース、ゴミ箱

- **Settings**はデスクトップ版と同じですが、狭い1列に配置されています。**Import Backup as New Book**は、*Discard Changes*の上にあるボタンです。
- **Protocols**と**Inference Providers**は、各項目をテキストとして一覧表示し、その横にボタンがあります（プロバイダーは項目が多いため、ボタンは項目の下に置かれます）。編集ダイアログはデスクトップ版と同じなので、スマートフォンからプロトコルを[共有](protocols.md#sharing-a-protocol)できます。一覧の上にある**Import from other user**ボタンでは、他のユーザーが共有したプロトコルをインポートできます。
- **Resources**は、ファイルを使用しているオブジェクトごとにグループ化します（矢印でグループを開きます）。各ファイルはカードとして表示されます（画像、名前、種類、サイズ、日付、そしてダウンロード、置き換え、削除のボタン）。*Delete selected*用のチェックボックスがあり、グループをチェックするとそのグループのファイルがすべて削除されます。
- **Trash**では、削除された各オブジェクトがカードとして表示されます（名前、種類、削除された日時）。ゴミ箱の説明は**i**ボタンの後ろにあります。フィルターのボタンは2行目に折り返されます。復元の方法は[ゴミ箱](trash.md)に書かれているとおりです。

![スマートフォンのリソース](../images/phone-resources.png)

![共有プロバイダーの情報ボタンを含む、スマートフォンの推論プロバイダー](../images/phone-providers.png)

![スマートフォンのゴミ箱](../images/phone-trash.png)
<a id="the-book-window"></a>

## 本の画面

本を開くと、全画面で表示されます。閉じるボタンは右上隅の **✕** です。タブ（*概要*、*プロンプト*、*ロアブック*、*ストーリー*、*ブランチ表示*、*バックアップ*）は1行に並び、横にスクロールします。機能はデスクトップと同じです（[本](books/index.md)を参照）。入力欄は1列にまとめられています。

<a id="the-story"></a>

### ストーリー

ストーリーのタブは、パートを1列に並べたものです。[ストーリーエディタ](books/story-editor.md)との違いは次のとおりです。

![スマートフォンで表示した本のストーリー](../images/phone-book-story.png)

- **アウトライン**（およびその横に追加される拡張機能のタブ。例：[著者ノート](extensions/authors-note.md)）は**ドロワー**に入っています。左上のボタンで開きます。
- **要約**ボタンと設定メニュー（⚙。*テキストのスタイルを変更*、*検索と置換*、*インポート*、*一括削除*、*ストーリーをエクスポート* を含む）は、下部ではなく上部のバーにあります。
- 新しいパートを追加する **+** ボタンは下部にあります。
- **要約**ウィンドウのメニューバー（*検索と置換*、*要約を作成...*、*すべての要約を再作成*、*要約をエクスポート*、*要約をインポート*）は独立した行に表示されます。画面が狭い場合、項目は **⋯** ボタンの中に入ります。[要約のインポート](books/summaries.md#export-and-import-of-the-summaries)は、デスクトップと同じウィンドウを画面の幅いっぱいに表示したものです。

![スマートフォンでの要約のインポート](../images/phone-summaries-import.png)

- [注釈](books/annotations.md)：**注釈**タブはアウトラインの横のドロワーにあります。下線の引かれた箇所をタップすると、そのメモが開きます。**パートに注釈を付ける**と **AI で注釈を付ける** はパートのメニューに、**選択範囲に注釈を付ける** は選択したテキストを長押ししたときのメニューにあります。
- **検索と置換**は、デスクトップと同じウィンドウを開きます。入力欄とボタンは上下に並びます。

  ![スマートフォンでのストーリーの検索と置換](../images/phone-search-replace.png)

- パートは、小さな行が1本あるだけのテキストで、その行には2つのアイコンがあります。1つ目はパートの**メニュー**（編集、再生成、スワイプ、ブランチ、履歴、プロンプトを表示、画像、要約、削除）です。2つ目は**ポップアップ**を開きます。ポップアップには、デスクトップでパートの右側の列に表示される内容（ID、モデル、プロトコル、トークン、単語数、ターンの詳細）が表示されます。
- パートのメニューの**履歴**を選ぶと、[バージョン履歴](books/version-history.md)が全画面ページで開きます。バージョンは選択中のバージョンの上にカードとして並び、操作はデスクトップと同じです。

  ![スマートフォンでのパートのバージョン履歴](../images/phone-history.png)

- **統計**は、ストーリーの設定メニュー（その本の統計）にあり、また本の一覧のヘッダーにあるボタン（すべての本）からも開けます。ウィンドウは全画面ページで、カレンダーは直近16週間を表示します（デスクトップでは1年分）。詳しくは[執筆の統計](books/statistics.md)を参照してください。

  ![スマートフォンでのすべての本の統計](../images/phone-statistics.png)

- [要約](books/summaries.md)の一覧は幅が固定され、横にスクロールします。

<a id="administration"></a>

## 管理

管理者には、ドロワーに **管理** タブがあります。[デスクトップのページ](administration/index.md)と同じタブが、横にスクロールする1行に並びます：*ユーザー*、*データベースのバックアップ*、*クリーンアップ*、*リソースファイル*、*ヘルプアシスタント*、*エージェント*、*アップデート*、*拡張機能*。一覧（ユーザー、バックアップ、拡張機能）は、テキストの下にボタンがあるカードとして表示され、ツールバーは2行目に折り返されます。拡張機能の導入（*Load Extension*）とデータベースのバックアップのアップロードは、スマートフォンのファイル選択画面を開きます。その他のユーザーにはこのタブは表示されません。

![スマートフォンでの管理タブのユーザー](../images/phone-admin-users.png)

![スマートフォンでのデータベースのバックアップ](../images/phone-admin-backups.png)

<a id="what-is-missing"></a>

## 対応していない機能

スマートフォンでもデスクトップの機能はすべて使えますが、次の点が異なります。

| スマートフォンで無い・異なるもの | 行う場所 |
|---|---|
| チェックボックス *ルートのロアブックのみ* と、ロアブックの項目を複数選んで一度に削除する操作 | デスクトップの画面。 |
| コマンドバー、キーボードショートカット、再生成したパートの差分表示、余白のメモ | デスクトップの画面。キーボードや広い画面が必要です。 |
| 列が多いウィンドウや2ペインのウィンドウ（[要約](books/summaries.md)の一覧、Beta Readers の会話、Manga Generator）は小さくなります | 使えますが、横向きの方が見やすいです。 |

この一覧にない機能は、すべてデスクトップと同じように動作します。生成、編集、再生成、スワイプ、パートのブランチ、要約とメタ要約、本のプロンプト、ブランチツリー、本のバックアップ、エクスポート、リソース、ゴミ箱、ロアブック、管理などです。

<a id="extensions"></a>

## 拡張機能

スマートフォンの画面は専用のクラスを使うため、拡張機能はそれに明示的に対応する必要があります。Marginalia に付属する拡張機能は次のとおりです。

| 拡張機能 | スマートフォンでの動作 |
|---|---|
| [Arc Outline](extensions/arc-outline.md) | 動作します。Arcs タブはアウトラインのドロワーにあります。 |
| [著者ノート](extensions/authors-note.md) | 動作します。ノートはストーリーのアウトラインのドロワーにあります。 |
| [Beta Readers](extensions/beta-readers.md) | 動作します。Beta Readers タブはアウトラインのドロワーにあります。会話の領域は狭いため、横向きの方が見やすいです。 |
| [Book Description Generator](extensions/book-description-generator.md) | 動作します。ボタンは概要タブの末尾にあります。ダイアログは結果の上にオプションを表示します。 |
| [Chapter Marker](extensions/chapter-marker.md) | 動作します。章のタイトルはアウトラインのドロワーにあります。 |
| [Character Tracker](extensions/character-tracker.md) | 動作します。Characters タブはアウトラインのドロワーにあります。 |
| [Story Notes](extensions/story-notes.md) | 動作します。Notes タブはアウトラインのドロワーにあります。ページのダイアログは画面に収まりますが、長いページは横向きの方が書きやすいです。 |
| [Conlang Translator](extensions/conlang-translator.md) | 一部動作します。*設定 → 拡張機能の設定* のパネル、エディタ、レビュー、ウィザードは動作します（語彙の一覧は横にスクロールします）。翻訳された会話をビューアーでタップすることも同様です。ストーリー側（**会話を翻訳**、**パートを翻訳（構築言語）**、ストーリーでのクリック）はスマートフォンでは試していません。詳しくは[制限](extensions/conlang-translator.md#limits)を参照してください。 |
| [Converter](extensions/sillytavern-converter.md) | 動作します。Converter タブはアウトラインのドロワーにあります。チャットの範囲は2回のタップで選びます。詳しくは[スマートフォンでの利用](extensions/sillytavern-converter.md#on-a-phone)を参照してください。 |
| [Instruction Exporter](extensions/instruction-exporter.md) | 動作します。**Export instructions** はストーリーの設定メニューにあります。 |
| [Manga Generator](extensions/manga-generator.md) | 動作します。**Manga Generator** はストーリーの設定メニューにあります。ウィンドウが大きいため、横向きの方が見やすいです。 |
| [Reviewer](extensions/reviewer.md) | 動作します。その項目はパートのメニューに、設定は *設定 → 拡張機能の設定* にあります。 |
| [Side Query](extensions/side-query.md) | 動作します。Side Query タブはアウトラインのドロワーにあります。 |
| [Lore Generator](extensions/lore-generator.md) | 動作します。魔法の杖ボタンはロアブックの各項目の行にあり、そのウィンドウはプロンプトを結果の上に表示します。 |
| [Lorebook VCS](extensions/lorebook-vcs.md) | 動作します。ロアブックのパネルは *Enabled* の行の下にあり、項目の改訂履歴はその項目のフォームの上部にあります。 |
| [Image Generator](extensions/image-generator.md) | 動作します。**Generate image** はパートのメニューにあります。 |

他の提供元の拡張機能は、スマートフォンで異なる動作をするか、何も追加されない場合があります。それらは作者が動作させた場所に表示されます。拡張機能が見当たらない場合は、デスクトップの画面で確認してください。拡張機能がスマートフォンに対応する方法は、[開発者マニュアル](../developer/plugins/extendable.md#the-phone-twins)に記載されています。

<a id="tips"></a>

## ヒント

- 長い文章をスマートフォンで書くときは、横向きの方が書きやすいです。ターンの後もスマートフォンのレイアウトのままです。ページを再読み込みするまで変わりません。
- スマートフォンにない機能が必要な場合は、スマートフォンを横に向けてページを再読み込みするか、より広いウィンドウで Marginalia を開いてください。本や設定は、どこでも同じです。
- スマートフォンから Marginalia に接続するには、[サーバー](getting-started/docker-server.md)として実行する必要があります。[デスクトップアプリ](getting-started/desktop-app.md)は、お使いのコンピュータからのみ接続を受け付けます。
