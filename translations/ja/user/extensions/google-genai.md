# Google Gemini

[推論プロバイダー](../inference-providers.md)として、Googleの Gemini モデルを追加します。OpenAI 互換のものではなく、Google 独自の API を使って接続します。

Google は OpenAI 互換のエンドポイントも提供しており、通常の *OpenAI 互換* プロバイダーで利用できます。この拡張機能は Gemini API に直接接続します（Google Gen AI SDK を使用）。そのため、互換エンドポイントではできないことが可能になります。具体的には、推論として表示される**モデルの思考の要約**、Gemini 3 の思考レベルと以前のモデルの思考予算、安全フィルター、そして Google が報告する正確なトークン数です。

!!!warning ストーリーの本文は Google に送信されます
このプロバイダーを使う AI のリクエストはすべて、Google のサーバーに送信されます。ストーリーを含むプロンプト、ロアブックの項目と要約、モデルの応答、エージェントやコマンドが送信するファイルや画像などが対象です（送信先は `generativelanguage.googleapis.com`、または設定したプロキシです）。送信されたデータが Google でどう扱われるか（保存期間、モデルの改善に使われるかどうか）は、Gemini API の利用規約とプライバシーポリシーによって決まります。これは API キーのプランによって異なります。他のプロバイダーは、あなたが選んだサーバー（自分のサーバーの場合もあります）に送信します。第三者に知られてはならないテキストには、このプロバイダーを使わないでください。他のユーザーと共有しているサーバーでは、このプロバイダーの AI を共有した管理者は、それを使うすべてのユーザーのストーリー本文を Google に送信することになります。
!!!

<a id="installing"></a>

## インストール

*管理 → 拡張機能* で拡張機能を読み込みます（[拡張機能の管理](../administration/extensions.md)を参照）。JAR ファイルは約 14 MB と大きいです。Google の SDK と、SDK だけが必要とするライブラリを含んでいるためです。Marginalia の他の部分はこれらを使いません。

読み込まれると、推論プロバイダーのダイアログの **種類** のリストに **拡張機能** という新しい項目が追加されます。また、*種類別設定* タブの上部にある **プロバイダー** のリストに **Google Gemini** が表示されます（候補が一つしかない間は自動的に選ばれます）。AI を提供する拡張機能が読み込まれていない場合、**拡張機能** は表示されません。

<a id="adding-a-gemini-provider"></a>

## Gemini プロバイダーを追加する

1. [Google AI Studio](https://aistudio.google.com/apikey) で API キーを取得します。
2. **推論プロバイダー** タブで **推論プロバイダーを追加** をクリックし、**名前** を入力し、種類に **拡張機能**、プロバイダーに **Google Gemini** を選びます。
3. *一般設定*（コンテキストのサイズ、応答のサイズ、[推論](#reasoning)）と、*種類別設定* タブでプロバイダーの設定を入力してから、**接続テスト** をクリックします。

![種類が拡張機能のプロバイダーの一般設定](../../images/plugin-googlegenai-general.png)

![Google Gemini プロバイダーの種類別設定](../../images/plugin-googlegenai.png)

プロバイダーは、他のプロバイダーと同じように一覧に表示されます。*種類* の列にはプロバイダーの名前が表示されます。

![Google Gemini プロバイダーを含む推論プロバイダーの一覧](../../images/plugin-googlegenai-list.png)

| 項目 | |
|---|---|
| **APIキー** | Google AI Studio のキーです。暗号化して保存され、再度表示されることはありません。プロバイダーを編集するときに別のキーを入力するには **リセット** をクリックします。 |
| **モデル** | 使用するモデルです（例：`gemini-2.5-flash`、`gemini-3-pro-preview`）。**更新** をクリックすると、キーで文章生成に使えるモデルの一覧が表示されます。一覧にない名前を直接入力することもできます。 |
| **URL** | 任意です。空欄の場合は Google の API（`generativelanguage.googleapis.com`）を使います。プロキシ経由でリクエストを送る場合に設定します。 |
| **タイムアウト（秒）** | Google の応答を待つ時間、および書き始めた後に続きのテキストを待つ時間です。初期値は 300 です。 |
| **再試行回数** | Google がレート制限（429）やサーバーエラー（5xx）を返した場合、または接続できない場合に、リクエストを繰り返す回数です。初期値は 2 で、0 にすると再試行をしなくなります。 |
| **安全フィルターをオフにする** | 調整可能な安全カテゴリ（嫌がらせ、憎悪表現、性的に露骨な内容、危険な内容）に対して `BLOCK_NONE` を送信します。フィクションはフィルターに引っかかることが多いです。ただし、送信内容に関係なく Google が一部のコンテンツをブロックすることがあります。 |

**接続テスト** は、モデルの一覧を取得し、選択したモデルに数トークンの生成を依頼します。このとき使われるのは、保存前のダイアログ内の値です。

<a id="reasoning"></a>

## 推論

推論の設定は、他のプロバイダーと同様に、プロバイダーの一般設定にあります。

- **推論を有効にする** がオフの場合、モデルはデフォルトの動作で思考し、その思考は表示されません。
- オンの場合、モデルは思考の要約を送信し、それがストーリー部分の推論として表示されます。**推論の強度** は、モデルがどれだけ考えるかを設定します。Gemini 3 のモデルでは思考レベル（low、medium、high）になり、以前のモデルでは 1 024、8 192、24 576 の思考トークン数の予算になります。**なし** はオフと同じです。

思考トークンは生成トークンとして数えられ、設定した応答のサイズから差し引かれます。モデルがすべてを思考に使い切ると、ストーリー部分は空で返され、応答のサイズを使い切ったというエラーが表示されます。**最大応答トークン数** を増やすか、推論の強度を下げてください。

<a id="what-works"></a>

## 使える機能

ストーリーに必要なことはすべて、OpenAI 互換のプロバイダーと同じように動作します。ストリーミング、生成の停止、要約、[モデルを呼び出す拡張機能](index.md)、モデルが呼び出せる関数（[名前ジェネレーター](name-generator.md)がいくつか提供します）、メッセージに添付した画像やファイルなどです。ユーザーが使ったトークンは、Google が報告する数値に基づいて **送信トークン数** と **生成トークン数** の列に集計されます。また、共有プロバイダーの[制限](../inference-providers.md#limits-of-shared-providers)も適用されます。

ストーリー内に表示されるトークン数（パートのサイズ、プロンプトのサイズ）は、Google が数えます（モデルの `countTokens` リクエストを使用）。テキストごとに 1 回だけ数えられ、結果は保存されます。Google に問い合わせられない場合（キーがない、ネットワークがない、エラーが発生したなど）、Marginalia は 1 分間は自分で数を推定し、その後で再び Google に問い合わせます。別の保存処理の途中で保存または編集されたテキストも推定されます。この推定値は、Google が請求する数と少し異なります。

<a id="when-the-extension-is-not-loaded"></a>

## 拡張機能が読み込まれていない場合

拡張機能を読み込み解除しても、作成したプロバイダーは一覧に残ります。その際の種類は *拡張機能: google-genai* と表示されます。拡張機能を再び読み込むと、プロバイダーは再び使えるようになります。読み込まれていない間は、そのプロバイダーを使っている本では生成できません。エラーには、拡張機能を読み込むか、別のプロバイダーを選ぶように表示されます。プロバイダーは引き続き開いて一般設定を変更できます。Gemini の設定は拡張機能が読み込まれているときだけ表示され、変更されることはありません。

<a id="not-supported"></a>

## サポートしていない機能

- **Vertex AI**（プロジェクトと認証情報を使う Google Cloud）。対応しているのは Gemini API の API キーだけです。
- Gemini の画像生成やその他の出力形式。出力されるのはテキストだけです。
