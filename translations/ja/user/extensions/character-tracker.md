# キャラクタートラッカー

サイドバーに表示される、作品の登場人物の一覧です。各キャラクターにはタグライン、メモ、アイコン、色を設定でき、キャラクター同士の関係と、その関係をまとめたマップも表示されます。

<a id="the-characters-tab"></a>

## キャラクタータブ

[ストーリーエディター](../books/story-editor.md)の左サイドバーには、*Outline*の隣に**Characters**タブが追加されます。一覧の上には1行のボタンが並んでいます。**Add**（新しいキャラクターを追加）、ロアエントリーをインポートするメニュー、**Relationship map**、そしてプロンプト用の吹き出しボタン（名前はマウスオーバーで表示）です。

吹き出しボタンを押すと、**In prompt**、**Depth**、役割（ロール）を設定できるポップオーバーが開きます。これは[作者注](authors-note.md)と同じ仕組みです。キャラクターがプロンプトに含まれている間、ボタンは緑色になります。*In prompt*にチェックを入れると、生成のたびに、キャラクターが1つのメッセージとして渡されます。各キャラクターについて名前、かっこ内のタグライン、メモを並べ、さらに関係の一覧も含まれます（双方向の場合は`Mara -> Tomas: employs`、`<->`）。*Depth*は、そのメッセージより後ろにあるメッセージの数です（`0`は最後、指示の後、`1`はその直前）。役割は*System*、*Assistant*、*User*のいずれかです。このテキストは、ストーリーに割り当てられたコンテキスト（ルーム）のトークン枠を使います。作品にキャラクターがない間は何も挿入されません。設定は作品と一緒に保存されます。

その間にある杖のボタンには、メニュー項目**Import lore entries as characters**があります。詳細は[後述](#importing-characters-from-the-lorebook)を参照してください。

一覧は名前順に並びます。各キャラクターはそれぞれ独自の色で表示され、**name**の下に小さい文字で**tagline**を表示します（最大2行）。キャラクターごとのボタンは次のとおりです。

| ボタン | |
|---|---|
| シェブロン（山形） | キャラクターを広げ、**icon**と**note**を表示します。 |
| ペン | キャラクターをダイアログで開きます。 |
| ゴミ箱 | キャラクターとそのすべての関係を、確認の後に削除します。 |

キャラクターは変更するとすぐに作品と一緒に保存されるため、バックアップにも含まれます。

![キャラクタータブ](../../images/plugin-charactertracker-tab.png)

<a id="picking-characters-for-a-turn"></a>

## ターンのキャラクターを選ぶ

[新しいターン](../books/story-editor.md)のフォームには、**POV character**と**Present characters**の欄があります。どちらも自由入力のテキスト欄ですが、末尾に人型アイコンのボタンがあり、作品のキャラクターを名前順に一覧表示します。**POV character**の一覧で名前を選ぶと、欄の内容がその名前に置き換わります。**Present characters**の一覧で名前を選ぶと、すでに含まれていない限り、末尾にカンマ区切りで追加されます。一覧は開いたときに読み込まれるため、直前に追加したキャラクターも含まれます。欄には任意の名前を直接入力することもでき、作品のキャラクターでない名前でもかまいません。

<a id="the-character-dialog"></a>

## キャラクターダイアログ

**Add**（プラス記号のボタン。ツールチップは*Add new character*）とペンのボタンは、同じダイアログを開きます。

| 項目 | |
|---|---|
| **Name** | 必須です。 |
| **Tagline** | キャラクターを表す短い言葉。一覧と関係マップに表示されます。 |
| **Note** | 覚えておきたいことを自由に書けます。 |
| **Icon** | PNG、JPEG、GIFをアップロードできます。最大200 x 200ピクセルに縮小され、縦横比は保たれます。 |
| **Color** | 一覧と関係マップでのキャラクターの背景色。 |

項目は**Save**で反映されます。

![関係性を持つキャラクター](../../images/plugin-charactertracker-dialog.png)

未保存の変更がある状態で**Cancel**（またはEsc）を押すと、入力済みでまだ追加していない関係も含めて、変更を破棄するかどうか確認されます。

![未保存の変更があるキャラクターをキャンセルしたときの確認](../../images/plugin-charactertracker-unsaved.png)

<a id="relationships"></a>

### 関係性

既存のキャラクターを開くと、ダイアログにはそのキャラクターの関係も一覧表示されます。キャラクターが指している関係（`→`）、そのキャラクターを指している関係（`←`）、そして一方向の関係（`↔`）があり、いずれも名前とタグラインが付いています。ゴミ箱ボタンで関係を削除できます。

関係を追加するには、相手のキャラクターを検索し、**Direction**（*this character → other*、*other → this character*、または*both ways*）を選び、**Name**（例：*employs*、*friends*）を入力し、必要に応じて**Tagline**を入力して、**Add relationship**を押します（このボタンは各項目の上にあります）。関係はすぐに保存されます。新しいキャラクターは、保存した後に関係を持つことができます。

<a id="importing-characters-from-the-lorebook"></a>

## ロアブックからキャラクターをインポートする

キャラクターがすでにロアブックにある場合は、杖のメニューで自動的に作成できます。**Import lore entries as characters**を選ぶと、作品のロアブックとそのすべてのサブロアブックのエントリーを*order*順に並べたダイアログが開きます。各エントリーには名前とチェックボックスが表示され、さらに**i**アイコンを押すと、エントリーの内容をポップオーバーで確認できます。インポートするか決める前に素早く確認するのに便利です。一覧の見出しにあるチェックボックスで、すべてを選択または解除できます。**Import**を押すと、チェックされたエントリーごとに、その名前でキャラクターが作成されます（タグライン、メモ、アイコン、色は空欄のままなので、後から入力できます）。**Close**を押すと、インポートせずに閉じます。

エントリーは既存のキャラクターと照合されません。同じエントリーを2回インポートすると、キャラクターが2つ作られます。

![ロアブックからキャラクターをインポート](../../images/plugin-charactertracker-import.png)

<a id="the-relationship-map"></a>

## 関係マップ

**Relationship map**は、作品のすべての関係をグラフとして表示します。関係を持つキャラクターは、その色の上にアイコン（アイコンがなければ枠）が付いた円として表示され、名前とタグラインも表示されます。各関係は2人のキャラクターの間の矢印で、名前とタグラインが付いています。矢印は相手の方向を指します。一方向の関係は両端に矢印が付きます。関係のないキャラクターはマップに表示されません。

![関係マップ](../../images/plugin-charactertracker-map.png)

キャラクターは、ある1人を中心に同心円状に配置されます。最初は関係が最も多いキャラクターが中心になります。そのキャラクターと関係のあるキャラクターが1つ目の円に、それらのキャラクターの関係先が2つ目の円に、というように配置されます。**キャラクターをダブルクリック**すると、そのキャラクターを中心にマップを並べ直します。キャラクターをドラッグしたり、マップを移動したり、マウスホイールで拡大縮小したりすることもできます。

<a id="commands"></a>

## コマンド

キャラクターは、コマンドライン用および[エージェント](../commands/index.md)用の[コマンド](../agents.md)としても扱えます。開いている作品に対して動作します（エージェントの場合は作業コピーに対して）。開いている Characters タブには、変更がすぐに反映されます。キャラクターは**name**で指定します（大文字と小文字は区別しません）。同じ名前のキャラクターが2つある場合は、`/list-characters`内の番号（名前の順番）で指定します。関係は`/list-character-relations`内の番号で指定します。キャラクターを変更するコマンドは、指定した項目だけを変更します。空のテキストを指定すると、タグラインやメモは消去されます。アイコンはダイアログでのみ設定できます。

| コマンド | 内容 |
|---|---|
| `/list-characters` | 名前順に並んだキャラクター：タグライン、色、メモの有無、関係の数。読み取りのみ。 |
| `/get-character character` | 1人のキャラクターを、メモと関係とともに表示。読み取りのみ。 |
| `/create-character name [tagline [note [color]]]` | キャラクターを追加します。`color`は`#rrggbb`です。 |
| `/update-character character [name [tagline [note [color]]]]` | キャラクターを変更します。 |
| `/delete-character character` | 関係とともにキャラクターを削除します（確認の後）。 |
| `/list-character-relations [character]` | 関係の一覧、または1人のキャラクターの関係。読み取りのみ。 |
| `/add-character-relation source target name [tagline [bidirectional]]` | `source`から`target`への関係を追加します（*employs*）。または`bidirectional` `true`を付けると、両者が対等になる関係（*friends*）を追加します。 |
| `/update-character-relation relationship [name [tagline]]` | 関係の名前またはタグラインを変更します。 |
| `/delete-character-relation relationship` | 関係を削除します（確認の後）。 |
| `/character-tracker-map` | プロンプトに渡されるテキストとしての、キャラクターとその関係。読み取りのみ。 |

`character-tracker-map`は[{%{`{{command::character-tracker-map}}`}%}マクロ](../templates/macros.md#commands)用です。マスターテンプレート、ユーザープロンプト、またはロアブックのエントリーに入れると、Charactersタブによる自動挿入の代わりに（またはそれに加えて）、キャラクターを好きな位置にプロンプトへ配置できます。挿入が有効かどうかに関係なく、常にキャラクターの現在の状態が使われます。

追加と変更は破壊的ではありません。破壊的なのは`delete`のコマンドだけで、エージェントにはこれについて確認するよう設定できます。

Arc Outlineの[プロットウィザード](arc-outline.md)は、**Characters**ツールにチェックを入れると、同じコマンドを使います。そのため、プロットについて話している間にキャストを発展させることができます。

<a id="phone"></a>

## スマートフォン

このタブは、[作者注](authors-note.md)と同様に、ストーリーのドロワーにあり、アウトラインの隣に配置されます。POVキャラクターと登場キャラクターのボタンは、スマートフォンの新しいターンのフォームにもあります。
