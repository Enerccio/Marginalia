# 폴더

폴더는 디스크에서 파일을 정리하듯이 책을 정리합니다. 폴더에는 책과 다른 폴더를 넣을 수 있고, 깊이에는 제한이 없습니다.
책 목록은 한 번에 한 폴더씩 보여 줍니다. 폴더는 **설정**(언어, 시점, 시제, 문체, 템플릿과 프롬프트)도 담을 수 있습니다.
폴더 안의 책과 그 아래 폴더들의 책은, 자체 설정이 없는 한 이 설정을 따라 집필합니다.
폴더를 쓰는 주된 이유가 바로 이것입니다. 시리즈의 문체를 한 번만 정해 두면 시리즈의 모든 책이 그 문체를 갖게 됩니다.

![폴더가 있는 Books 탭](../../images/books-folders.png)

<a id="moving-around"></a>

## 이동하기

책 목록 위에는 현재 폴더 안의 폴더들이 정렬된 열의 순서대로 표시됩니다. 폴더의 **이름**을 클릭하면 그 폴더가 열립니다.
목록 위의 버튼 경로(`Books / Sci-fi / Expanse`)는 현재 위치를 보여 주며, 그 일부를 클릭하면 해당 위치로 돌아갈 수 있습니다.

체크박스 **Include subfolders**를 켜면 현재 폴더 아래의 모든 책이 깊이에 상관없이 표시됩니다(최상위에서는 모든 책이 표시됩니다).
또한 각 책의 위치를 보여 주는 **Folder** 열이 추가됩니다. 현재 폴더와 이 체크박스의 설정은 페이지를 새로고침해도 기억됩니다.

폴더 행에는 그 아래에 있는 책의 수가 깊이와 상관없이 표시됩니다. 책 행에는 책의 [활성 분기](branches-and-story-tree.md)의 단어 수와 토큰 수가 표시됩니다.
**Name**과 **Tags** 필터는 책뿐 아니라 폴더에도 적용됩니다(폴더에도 태그를 붙일 수 있습니다. [폴더에 태그 붙이기](#tagging-folders) 참조).
필터는 현재 폴더에서 작동하며, *Include subfolders*를 켜면 그 아래 폴더까지 적용됩니다.

폴더의 **Last Modified**는 그 안의 책을 따릅니다. 폴더 안의 책이나 그 아래 폴더의 책(또는 그 책의 부분 중 하나)이 바뀌면 폴더도 갱신된 것으로 표시됩니다.
이 열로 정렬하면 마지막으로 집필한 위치를 찾을 수 있습니다. 책을 열거나 옮기는 것은 여기에 포함되지 않습니다.

<a id="what-the-buttons-do"></a>

### 버튼의 기능

| 버튼 | |
|---|---|
| **New folder** (헤더) | 현재 폴더 안에 폴더를 만듭니다. 이름은 비워 둘 수 없고, 255자를 넘을 수 없으며, `/`를 포함할 수 없습니다. 같은 위치에 있는 다른 폴더와 이름이 같아서도 안 됩니다(대소문자는 구분하지 않습니다). |
| 폴더의 톱니바퀴 아이콘 | [폴더 설정](#folder-settings)을 엽니다. |
| 폴더의 연필 아이콘 | 폴더의 이름을 바꿉니다. |
| 폴더의 휴지통 아이콘 | 폴더를 삭제합니다. [폴더 삭제](#deleting-a-folder)를 참조하십시오. |
| **Move to folder** (책) | 책을 넣을 폴더를 고릅니다. |
| 책의 별 아이콘 | 책을 [즐겨찾기](#favorites)로 지정합니다. |
| **Add Book**, 가져오기 | 새 책은 **현재 폴더**에 들어갑니다. [복제본](managing-books.md#cloning-a-book)은 원본 바로 옆에 놓입니다. |

<a id="folder-settings"></a>

## 폴더 설정

폴더의 톱니바퀴 아이콘을 누르면 설정이 열립니다(**Organise** 창에도 같은 버튼이 있으며, 단축키는 `i`입니다):

![폴더 설정](../../images/folder-settings.png)

- **Name**, **Description**, **Tags**.
- **Language**, 그리고 책의 [Prompts](prompts.md) 탭과 같은 항목들: 마스터 템플릿, 시점, 시제, 문체, 프롬프트.
- **Versions kept per part**: [기록](version-history.md#how-many-versions-are-kept)이 폴더 안의 책과 그 아래 폴더들의 책에 대해 한 부분의 이전 버전을 몇 개까지 보관할지 정합니다. 책에 적용되는 위의 모든 제한 중 가장 엄격한 제한이 적용됩니다.
- **Extension Settings**: 불러온 [확장 기능](../extensions/index.md)에 책이 상속받는 설정이 있을 때 표시됩니다. [확장 기능의 설정](prompts.md#settings-of-extensions)을 참조하십시오.
- **Phrase watch list**: 폴더 안의 책들을 검사할 문구 목록입니다. 설정과 위쪽 폴더들의 문구 목록에 더해집니다. [문구 감시](annotations.md#watching-for-phrases)를 참조하십시오.

모든 항목은 선택 사항입니다. 비어 있는 항목은 *상속*되며, 이를 항목에 표시합니다. 항목 안의 회색 글자는 상속받는 값이고, 그 아래 줄에는 그 값의 출처가 나타납니다.
**Save**를 누르면 폴더가 저장됩니다. 이름과 설명은 언제든지 바꿀 수 있습니다. 하지만 언어나 텍스트 설정을 바꾸는 것은, 폴더 안이나 그 아래에 있는 책에서 에이전트가 작업 중일 때는 거부됩니다.
이때 메시지에 해당 책의 이름이 표시되므로, 먼저 그 책의 [실행을 일시 정지하거나 중지](../agents.md)하십시오.

<a id="where-the-settings-of-a-book-come-from"></a>

### 책의 설정은 어디에서 오는가

책은 이 설정 각각에 대해 다음 중 비어 있지 않은 첫 번째 값을 사용합니다.

1. 책 자체(*About* 및 *Prompts* 탭),
2. 책이 들어 있는 **폴더**,
3. 그 위의 폴더, 그리고 최상위까지 계속 위로,
4. **사용자 설정**(*Settings → Templates*, [계정 및 설정](../account.md) 참조),
5. **내장 기본값**.

빈 텍스트는 설정되지 않은 것으로 봅니다. 이 값은 필요할 때 조회됩니다(부분이 생성될 때, 요약을 만들 때, 부분을 다시 쓸 때 등).
책을 폴더에 넣을 때 아무것도 책에 복사되지 않습니다. 따라서 **책을 다른 폴더로 옮기면 집필 방식이 바뀌고**, 폴더의 설정을 바꾸면 자체 설정이 없는 그 아래의 모든 책이 바뀝니다.

책의 [Prompts](prompts.md#inherited-settings) 탭에서 이를 확인할 수 있습니다. 각 항목 아래에 값의 출처가 표시됩니다(*Inherited from the folder "Sci-fi"*, *Inherited from your settings*, *Built-in default*).

<a id="language"></a>

### 언어

책의 [About](managing-books.md#the-about-tab) 탭과 폴더의 **Language** 상자는 비워 둘 수 있습니다. 비워 두면 *상속*을 뜻하며, 책은 위쪽 폴더 중 가장 가까이에 있으면서 언어를 설정한 폴더의 언어를 따릅니다. 그런 폴더가 없으면 영어를 사용합니다.
빈 상자 옆에는 적용되는 언어와 그 출처가 표시됩니다. 상자에는 지우기 버튼이 있으며, 이를 누르면 다시 상속됩니다(예전에는 영어로 바뀌었습니다).
책의 언어를 보여 주거나 사용하는 모든 곳은 폴더 설정을 반영한 언어를 사용합니다. 텍스트의 하이픈 넣기, 내보내기, [Mass Change Language](#mass-changes) 표가 여기에 해당합니다.

<a id="deleting-a-folder"></a>

## 폴더 삭제

폴더의 휴지통 버튼을 누르면 어떻게 할지 묻습니다.

- **빈 폴더**는 확인 후 삭제됩니다.
- **책이나 폴더가 들어 있는 폴더**에는 **Move its content to the folder above**(기본값)와 **Delete everything in it as well**이 제시됩니다. 후자를 고르면 책과 폴더의 수를 보여 주며 다시 확인합니다. 이 경우 책은 [휴지통](../trash.md)으로 보내지며, 거기에서 되돌릴 수 있습니다. 삭제된 폴더 자체는 휴지통에 나타나지 않습니다.

안에 있는 폴더의 이름이 위쪽 폴더에 있는 폴더 이름과 같으면, 내용을 위로 옮기는 작업이 거부됩니다(이름은 고유해야 합니다). 둘 중 하나의 이름을 먼저 바꾸십시오.
에이전트가 작업 중인 책이 들어 있는 폴더는 삭제하거나 이동할 수 없습니다. 실행 중에 그 책의 설정이 바뀌게 되기 때문입니다.
<a id="organise"></a>

## 정리하기

**정리하기**(목록 머리글의 **관리** 메뉴에 있음)는 폴더 두 개를 보여주는 두 개의 창으로 된 창을 엽니다. 여기서 책과 폴더를 하나씩 열지 않고도 한쪽에서 다른 쪽으로 옮기거나 복사할 수 있습니다. 왼쪽 창은 여러분이 있던 폴더에, 오른쪽 창은 지난번에 보였던 폴더에 맞춰 열립니다.

![정리하기 창](../../images/organise-dialog.png)

| 키 | |
|---|---|
| 왼쪽 / 오른쪽 / Tab | 다른 창으로 이동합니다. |
| 위 / 아래 | 커서를 움직입니다. |
| Enter | 커서 아래의 폴더를 엽니다. |
| Backspace | 상위 폴더로 올라갑니다. |
| Space 또는 Insert | 커서 아래의 항목을 표시합니다. Shift + 위 / 아래는 커서를 움직이면서 표시합니다. |
| 확인란 클릭 | 항목을 표시하거나 표시를 해제합니다. **Shift + 클릭**은 그 확인란과 앞서 클릭한 확인란 사이의 모든 항목을 표시(또는 해제)합니다. |

창 아래쪽의 버튼 줄은 **표시된** 항목(표시된 것이 없으면 커서 아래의 항목)에 작업을 수행하며, 괄호 안에 해당 키를 보여줍니다:

| 버튼 | 키 | |
|---|---|---|
| **복사** | `c` | *다른* 창의 폴더로 복사합니다. |
| **이동** | `m` | 다른 창의 폴더로 이동합니다. |
| **새 폴더** | `n` | 활성 창의 폴더 안에 폴더를 만듭니다. |
| **이름 바꾸기** | `Shift+r` | 커서 아래의 폴더나 책의 이름을 바꿉니다. |
| **삭제** | `Delete` | 목록에서와 같이 삭제합니다. |
| **폴더 설정** | `i` | 커서 아래 폴더의 [설정](#folder-settings)을 보여줍니다. |
| **모델/프로토콜 일괄 변경**, **언어 일괄 변경**, **일괄 이름 바꾸기**, **책에 태그 달기** | `p`, `l`, `Shift+n`, `t` | 표시된 책에 대해, 또는 활성 창 폴더의 책에 대해 [일괄 변경](#mass-changes)을 수행합니다(자체 **하위 폴더 포함** 옵션 포함). 일괄 이름 바꾸기 후에는 창에 새 이름이 표시됩니다. |
| **고급 검색** | `f` | 활성 창 폴더에서 [검색](managing-books.md#advanced-search)을 수행합니다. 옵션으로 **하위 폴더 포함**을 선택할 수 있습니다. 결과에는 **폴더에서 보기**가 있으며, 이를 누르면 해당 창이 그 폴더로 이동하고 책이 표시됩니다. |
| **목록에서 폴더 보기** | `o` | 창을 닫고 활성 창의 폴더를 책 목록에서 엽니다. |

창을 닫으면 책 목록을 다시 읽으므로, 만들고 옮기고 복사하고 이름을 바꾸고 삭제한 내용이 바로 표시됩니다(목록이 있던 폴더가 사라졌다면 최상위 수준으로 이동합니다).

이 키들은 *설정*의 [키보드 단축키](../account.md#keyboard-shortcuts) 동작에 해당합니다. 거기서 키를 바꾸거나 지울 수 있습니다(기본적으로 기능 키는 없습니다. Mac과 브라우저가 이 키들을 사용하기 때문입니다). 버튼에는 설정한 키가 표시됩니다.

<a id="copying"></a>

### 복사

책을 **복사**하면 [복제본](managing-books.md#cloning-a-book)이 만들어지며, 창은 현재 분기만 복사할지 묻습니다. 폴더를 **복사**하면 원본의 설정, 설명, 태그를 가진 새 폴더가 만들어지고, 그 안의 모든 책과 폴더의 복사본이 함께 만들어집니다. 복사에는 시간이 걸릴 수 있으며, 이때는 중지할 수 없는 진행 막대가 표시됩니다. 도중에 실패하면, 그 전까지 만들어진 복사본은 각각 완전한 상태로 남습니다.

**이동**은 즉시 이루어지며, 원래 위치로 다시 옮겨서 되돌릴 수 있습니다. 폴더를 자기 자신이나 그 하위 폴더로 옮길 수는 없습니다.

<a id="when-a-name-is-taken"></a>

### 이름이 이미 쓰일 때

대상 위치에 같은 이름의 폴더가 이미 있으면, 창은 그 폴더를 어떻게 할지 묻습니다. 나머지 항목에도 같은 선택을 적용하려면 **모두에 적용**을 사용합니다:

| 선택 | |
|---|---|
| **이름 바꾸기** | 폴더에 다른 이름이 붙습니다. |
| **건너뛰기** | 폴더는 원래 자리에 그대로 남고 복사되지 않습니다. |
| **병합** | 그 안의 내용이 이미 있는 폴더로 옮겨집니다. 안에 같은 이름의 폴더가 있으면 차례로 병합됩니다. |

책은 이름이 충돌하지 않습니다. 같은 이름이 여러 개 있어도 됩니다.

<a id="mass-changes"></a>

## 일괄 변경

목록의 **관리 → 일괄 변경** 메뉴(및 정리하기의 버튼)를 사용하면 많은 책을 한 번에 바꿀 수 있습니다. **모델/프로토콜 일괄 변경**은 책 하나에 모델이나 프로토콜을 하나 지정하고(또는 둘 다 지정하고), **언어 일괄 변경**은 언어를 지정합니다. **일괄 이름 바꾸기**는 이름 앞이나 뒤에 접두사나 접미사를 붙이고, 이름 안의 텍스트를 바꾸거나 번호를 매깁니다. **책에 태그 달기**와 **폴더에 태그 달기**는 태그를 추가하거나 제거합니다. 자세한 내용은 [책 관리하기](managing-books.md#tagging-many-books-at-once)를 참고하세요. 목록에서 실행하면 현재 폴더의 책에 적용되며, 자체 **하위 폴더 포함** 옵션을 사용할 수 있습니다.

<a id="favorites"></a>

## 즐겨찾기

책 행의 별표는 그 책을 **즐겨찾기**로 지정합니다. 즐겨찾기가 하나라도 있으면 최상위 수준에 가상 폴더 **즐겨찾기**(별 모양)가 나타나고, 모든 폴더의 즐겨찾기 책이 여기에 모입니다. 이것은 보기일 뿐이므로, 여기에 책이나 폴더를 만들 수는 없습니다. 별표를 해제하면 책이 이 보기에서만 빠지고, 원래 폴더에서는 그대로 남습니다. 즐겨찾기는 설정에 저장됩니다.

<a id="tagging-folders"></a>

## 폴더에 태그 달기

폴더에도 책처럼 태그를 달 수 있습니다. **관리 → 일괄 변경 → 폴더에 태그 달기**를 사용하면 여러 폴더에 한 번에 태그를 달 수 있습니다. 폴더의 태그는 그 안에 있는 책의 태그를 바꾸지 않으며, [백업](backups.md)에도 포함되지 않습니다.

<a id="folders-and-other-features"></a>

## 폴더와 다른 기능

- **백업.** [백업](backups.md#backups-and-folders)은 책의 폴더 구조를 기억하며, 내보낸 파일에는 책이 상속받는 설정을 함께 담을 수 있습니다.
- **에이전트.** [에이전트](../agents.md#agents-and-folders)는 자신이 속한 책의 폴더 설정을 따라 글을 씁니다.
- **도움말 어시스턴트.** 허용하면 [어시스턴트](../administration/help-assistant.md#your-books)가 여러분의 책과 폴더를 찾아볼 수 있습니다.
- **휴대폰.** [휴대폰 레이아웃](../phone.md#books)은 같은 폴더를 카드 형태로 보여주며, 폴더를 만들고, 이름을 바꾸고, 설정하고, 삭제할 수 있습니다. 정리하기와 일괄 변경은 머리글의 **⋮** 메뉴에 있습니다.
- **뷰어.** [뷰어](publishing.md#folders-in-the-list)에서도 폴더 목록이 보이며, 나왔던 폴더에서 열립니다.
