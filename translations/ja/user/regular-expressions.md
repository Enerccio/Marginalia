# 正規表現

正規表現（*regex*）は、文字列をそのまま書き出す代わりに、テキストのパターンを短く記述するものです。たとえば「Harry という単語だが Harrys ではないもの」「引用符で囲まれた任意の二語」「連続する三つ以上の空白」などを表せます。Marginalia では次の二か所で正規表現を使います。

- [物語](books/story-editor.md#search-and-replace)および[ロアブック](lorebooks/entries.md#search-and-replace)の**検索と置換**。**正規表現で検索**がオンのとき有効になり、対応する[コマンド](commands/index.md)でも同様に使えます。パターンで文字列を見つけ、置換後の文字列ではその一部を再利用できます。
- [ロアブックのエントリ](lorebooks/entries.md#activation)の**正規表現**フィルター。エントリをプロンプトに入れるタイミングを決めます。

使用する方言は Java のものです。このページでは、よく使う部分を紹介します。完全なリファレンスへのリンクはページ末尾にあります。

!!!
ただの単語を探すのに正規表現は必要ありません。**正規表現で検索**がオフの場合、入力どおりの文字列がそのまま検索されるので、そこに含まれる `.` や `(` は単なるピリオドや括弧として扱われます。単一の固定された文字列では足りないときにだけ正規表現をオンにしてください。
!!!

<a id="the-building-blocks"></a>

## 基本の構成要素

| 書き方 | 一致するもの | 例 |
|---|---|---|
| 文字または数字 | その文字そのもの | `cat` は *concatenate* の中の *cat* に一致する |
| `.` | 任意の一文字（改行を除く） | `c.t` は *cat*、*cot*、*c7t* に一致する |
| `\d` `\w` `\s` | 数字、文字・数字・`_`、空白または改行 | `\d\d` は *42* に一致する |
| `[abc]` `[a-z]` | 列挙した文字のどれか一つ、または範囲 | `gr[ae]y` は *grey* と *gray* に一致する |
| `[^abc]` | 列挙したもの*以外*の一文字 | `[^"]` は引用符以外の任意の文字 |
| `\b` | 単語の境界 | `\bcat\b` は *cat* に一致するが *concatenate* には一致しない |
| `^` `$` | 行の先頭と末尾 | `^Chapter` は行頭の *Chapter* に一致する |
| `x?` `x*` `x+` | `x` が〇回または一回、任意の回数、一回以上 | `colou?r` は *color* と *colour* に一致する |
| `x{2,4}` | `x` が二回から四回 | `\.{3}` は連続する三つのドット |
| `\` | 次の文字をそのまま文字として扱う | `\.` はピリオド、`\?` は疑問符、`\(` は括弧 |

括弧で囲むと**グループ**になり、グループの中の縦棒は「または」を意味します。`(Mr|Mrs) Dursley` は *Mr Dursley* と *Mrs Dursley* に一致し、`\b(Voldemort|You-Know-Who)\b` はどちらの名前にも一致します。グループの後ろに付けた `?`、`*`、`+` はグループ全体に適用されます。`(very )+good` は *very good* と *very very good* に一致します。

`. ? * + ^ $ | \ ( ) [ ] { }` の記号には特別な意味があります。これらの記号を文字そのものとして検索するには、前に `\` を付けます。たとえば *Really?!* を探すには `Really\?!` と書きます。

正規表現はデフォルトで大文字と小文字を区別しません。つまり *harry* は *Harry* に一致しません。大文字と小文字を無視するには、先頭に `(?i)` を付けます。`(?i)harry` は *Harry*、*HARRY*、*harry* に一致します。（正規表現がオンの間、検索と置換のウィンドウでは**大文字と小文字を区別**が固定されるため、そこで無効にするにはこの方法を使います。ロアブックの**正規表現**フィルターでは常に大文字と小文字を無視します。）

長さゼロの一致（`a*` のように何も一致しないパターン）は、検索と置換では無視されます。

<a id="typical-uses-in-a-story"></a>

## 物語での典型的な使い方

各行は、本に対して行いたい操作の例です。**検索**は*検索する文字列*に入力するもの、**置換**は*置換後の文字列*に入力するものです。

| やりたいこと | 検索 | 置換 |
|---|---|---|
| 登場人物の名前を変える（ただし *Harrys* や *Harrison* のような長い単語の一部は除く） | `\bHarry\b` | `Henry` |
| 大文字と小文字を問わず名前を変える | `(?i)\bharry\b` | `Henry` |
| 名前と所有格をまとめて変える | `\bHarry('s)?\b` | `Henry$1` |
| 直線の引用符をカーリーの引用符に変える | `"([^"]*)"` | `“$1”` |
| 三つのドットを一つの三点リーダー記号にする | `\.{3}` | `…` |
| 二つ以上の空白を一つにまとめる | ` {2,}` | ` `（空白一つ） |
| 行末の空白を削除する | ` +$` | （空欄） |
| ハイフン二つからなる長いダッシュにする | ` ?-- ?` | ` — ` |
| *姓, 名* を *名 姓* に入れ替える | `(\w+), (\w+)` | `$2 $1` |
| 何も変えずに単語の使用箇所を探す | そのパターン | （空欄のまま**検索**だけを押す） |

いくつかの表記を一つの名前にまとめるには、`\b(Voldemort|You-Know-Who|He-Who-Must-Not-Be-Named)\b` を検索し、`Tom Riddle` に置換します。

<a id="taking-the-match-into-the-replacement"></a>

### 一致した内容を置換後の文字列に使う

正規表現で丸括弧に入れた部分はすべて**グループ**になり、開き括弧の位置にしたがって左から番号が付きます。置換後の文字列の `$1` は一番目のグループの文字列、`$2` は二番目のグループ、`$0` は一致全体を表します。`(\w+), (\w+)` では、一番目のグループはカンマの前の単語、二番目はカンマの後の単語なので、`$2 $1` とすると二つが入れ替わります。*Potter, Harry* は *Harry Potter* になります。

グループには名前を付けることもできます。`(?<last>\w+), (?<first>\w+)` のように書けば、置換後の文字列でその名前を使えます（`${first} ${last}`）。

置換後の文字列で `$` や `\` をそのまま文字として残したい場合は、エスケープが必要です。たとえば本文に *$5* を入れるには `\$5` と書きます。正規表現を使わない場合、置換後の文字列は入力したとおりに扱われます。

パターンが間違っている場合（閉じられていない括弧がある場合）や、置換後の文字列がパターンに存在しないグループを指定している場合は、通知で知らされ、何も起こりません。検索で本文が変わることはありません。

<a id="match-only-in-a-context"></a>

### 文脈に合う場所だけを一致させる

*先読み* `(?=...)` と *後読み* `(?<=...)` は、一致箇所の前後の文字列を確認しますが、それ自体は一致に含めません。そのため、その外側の部分だけが置換されます。

| 検索 | 見つかるもの |
|---|---|
| `Harry(?= Potter)` | *Potter* が後に続く場合の *Harry*（*Potter* はそのまま残る） |
| `(?<=Professor )McGonagall` | *Professor* の後にある *McGonagall* だけ |
| `Harry(?! Potter)` | *Potter* が後に続かない *Harry* |

<a id="lazy-and-greedy"></a>

### 最短一致と最長一致

`*` と `+` はできるだけ多くの文字に一致します。`He said "yes" and "no"` の中で `".*"` と書くと、`"yes" and "no"` 全体に一致します。`?` を付けて（`".*?"`）、または許可しない文字を指定して（`"[^"]*"`）、最初の閉じ引用符で止まるようにします。

検索は行ごとに独立して処理されます。`.` は改行をまたぎませんし、`^` と `$` は文章全体の先頭と末尾だけでなく、各部分の各行の先頭と末尾に一致します。改行に一致させるには `\n` と書きます。

<a id="in-a-lorebook-entry-filter"></a>

## ロアブックのエントリのフィルターで使う

**正規表現**に設定したロアブックのエントリのフィルターは、部分ごとのリクエストの中のどこかに一致するかどうかで判定されます。大文字と小文字は区別されません。また、このフィルターでは `.` が改行にも一致するため、`varro.*harbor` は異なる行にあっても Varro と港を見つけます。典型的なフィルターは次のとおりです。

- `\bvarro\b` - 単語全体としての Varro。
- `\b(varro|captain)\b` - Varro または船長。
- `varro.*(harbor|docks)` - Varro があり、その後に港または埠頭が出てくる場合。
- `dragons?` - *dragon* または *dragons*。
- `(?<!no )magic` - *magic*。ただし直前が *no* の場合を除く。

無効な正規表現はエントリを有効にすることはなく、その理由はログに記録されます。エントリの選ばれ方の詳細については、[エントリと有効化](lorebooks/entries.md#activation)を参照してください。

<a id="in-the-commands"></a>

## コマンドで使う

[`/search-replace-parts`](commands/index.md#commands-that-come-with-marginalia) と `/search-replace-lore-entries` では、検索と置換の後に続く三番目の引数（`true`）として正規表現を指定します。コマンドラインはスペースで区切られるため、スペースを含むパターンや置換後の文字列は二重引用符で囲みます。文字の前にあるバックスラッシュはそのまま渡されます（`\b`、`\d`）。ただし `\\` は一つのバックスラッシュに、`\"` は引用符になります。そのため、パターン中の文字どおりのバックスラッシュは `\\\\` と書きます。

```
/search-replace-parts "\bHarry\b" Henry true
/search-replace-parts "(\w+), (\w+)" "$2 $1" true
/search-replace-parts "(?i)\bharry\b" Henry true
```

コマンドは一致の一覧を表示しません。見つかった一致の数だけ置換してよいかどうかを尋ねてきます。パターンに自信がない場合は、先に**検索と置換**のウィンドウで試してください。このウィンドウでは、一致箇所を現在の状態と置換後の状態の両方で一つずつ確認できます。

<a id="tips"></a>

## ヒント

- まず**検索**でパターンを試し、いくつかの行を開いてみてください。ウィンドウには、各一致箇所とその前後の文脈が、現在の状態と置換後の状態の両方で表示されます。結果が望みどおりになった場合にだけ置換してください。
- 単純なものから始め、少しずつパターンを足していってください。見つけすぎるパターンには、通常、単語の前後に `\b` を付けるか、`*` の代わりに `?` を使うことが必要です。
- 大規模な置換の前に[バックアップ](books/backups.md)を取っておくと手軽です（`/take-backup`）。また、置換は一度開始すると途中で止めることができません。
- 要約の更新：置換が[要約](books/summaries.md)の元になった文章に触れる場合、ウィンドウは要約が古くなることを警告します。[検索と置換](books/story-editor.md#search-and-replace)を参照してください。
