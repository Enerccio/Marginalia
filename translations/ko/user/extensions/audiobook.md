# 오디오북

음성 합성 서버로 책을 파트 단위로 오디오북으로 만듭니다. 내레이터와 각 등장인물마다 목소리를 정하고, 그 목소리는 책의 파트와 함께 저장되어 리더에서 재생됩니다. 그대로 실행해 두고 거친 초안을 만들 수도 있습니다(모델이 누가 어떻게 말하는지 표시하고, 음성 서버가 읽습니다). 또는 **오디오북 스튜디오**에서 파트를 하나씩 작업하며 음성 서버로 정확히 무엇이 보내지는지 확인하고 직접 고칠 수 있으며, 결과를 챕터 표시가 있는 mp3 파일로 내보낼 수 있습니다.

이 확장 기능은 음성을 직접 만들지 않습니다. 직접 실행하는 **Chatterbox-TTS-Server**와 통신합니다([음성 서버 설정하기](audiobook-server.md) 참고). 책의 텍스트는 절대 바뀌지 않으며, 지정한 서버 외에는 어디에도 보내지지 않습니다. 오디오는 사용자의 설치 환경에 리소스로 저장되어 파트에 연결됩니다.

<a id="what-you-need"></a>

## 필요한 것

- 음성 서버와, 언어 모델과 그래픽 카드를 공유하는 경우 공간을 확보하고 다시 멈추는 요청([음성 서버 설정하기](audiobook-server.md)).
- 목소리: 복제하고 싶은 목소리마다 짧은 **참조 클립**(한 사람의 12~30초 음성, 음악 없음), 또는 서버에 있는 음성 파일 중 하나. 내레이터에게는 차분하고 안정적인 낭독 목소리가 필요합니다.
- 여러 목소리가 나오는 책의 경우, 텍스트에 라벨을 붙일 수 있는 언어 모델. 기본값은 책의 모델입니다.
- **ffmpeg**은 선택 사항입니다. 없으면 모든 기능이 mp3로 동작합니다. 서버에 ffmpeg이 있으면(Docker 이미지에 포함되어 있으며, 데스크톱에서는 `PATH` 또는 `/opt/homebrew/bin` 같은 일반적인 폴더에서 찾습니다. 다른 곳에 있으면 `MARGINALIA_FFMPEG` 변수로 지정합니다) 내보내기가 **m4b** 형식을 사용하며, 관리자는 오디오를 wav로 저장하도록 설정할 수 있습니다.

<a id="the-settings"></a>

## 설정

*설정 → 확장 기능 설정 → 오디오북 설정*은 사용자 계정의 패널입니다. 변경한 뒤에는 *설정* 페이지를 저장하세요.

<a id="backends"></a>

### 백엔드

백엔드는 음성 서버와 그 서버가 사용하는 모델을 말합니다. **+**로 추가합니다. **복제**는 선택한 백엔드(주소, 키, GPU 잠금, 목소리, 기본값, 배치 전후의 요청)를 새 이름으로 복사합니다. 같은 컴퓨터에서 다른 모델의 백엔드를 빠르게 만드는 방법입니다. 예를 들어 Chatterbox 옆에 Higgs를 두고, 그다음 모델, 주소, 시작과 중지 요청을 바꾸면 됩니다.

| 설정 | 기능 |
|---|---|
| 이름 | 변환 대화상자에 표시되는 이름. |
| 주소 | 음성 서버 또는 그 서버로 전달하는 프록시의 기본 주소. 예: `http://localhost:8004`. |
| API 키 | 서버(또는 프록시)가 요구하면 베어러 토큰으로 전송됩니다. 암호화되어 저장되며 다시 표시되지 않습니다. 교체하려면 새 키를 입력하거나 **키 제거**를 누르세요. |
| 음성 모델 | **Chatterbox Turbo**(영어, `[sigh]` 같은 사운드 태그 지원, 가장 빠르며 기본값), **Chatterbox**(영어, 낭독의 *과장 정도*(exaggeration) 설정 가능), **Chatterbox Multilingual**(23개 언어), 또는 **ComfyUI의 Higgs Audio v3**(여러 언어, 대사의 분위기를 살린 목소리, 울음·헐떡임·신음 같은 소리 지원. [아래](#higgs-audio-v3-emotions-and-sounds) 참고). 백엔드의 [GPU 잠금](../administration/gpus.md)(또는 배치 전 요청)은 이 모델이 메모리에 올라가 있도록 해야 합니다. 다른 모델이 필요한 책은 다른 백엔드를 사용합니다. |
| GPU 잠금 | 서버가 실행되는 GPU의 [GPU 잠금](../administration/gpus.md). 언어 모델이나 다른 서버([이미지 생성기](image-generator.md 포함)와 GPU를 공유할 때 사용합니다. 모든 배치와 샘플이 GPU를 차례로 사용하며, 잠금은 음성 서버를 먼저 로드합니다. 관리자가 GPU 잠금을 설정한 경우에만 표시됩니다. |
| 서버가 이 컴퓨터 또는 내 네트워크에 있음 | 로컬 네트워크 주소를 허용합니다. 클라우드의 서버라면 끄세요. 그래야 서버가 사용자 컴퓨터를 호출할 수 없습니다. |
| 요청 제한 시간 | 음성 한 조각을 기다리는 시간. |
| 다음 조각 수 후 서버 재시작 | 메모리 누수가 있어 긴 배치 중 시스템에 의해 종료되는 음성 서버용입니다. 지정한 조각 수가 지나면 배치 후 요청과 배치 전 요청(중지, 시작, 로드)을 배치 중간에 다시 실행하여, 새 서버로 작업을 이어갑니다. 0(기본값)이면 재시작하지 않습니다. 종료된 서버는 이 설정과 상관없이 다시 시작됩니다. [문제 해결](audiobook-server.md#troubleshooting) 참고. |
| 배치 전후 요청의 키 | 배치 전후 요청이 `Authorization: Bearer`로 보내는 키. 암호화되어 저장되며 다시 표시되지 않습니다(**키 제거**를 누르면 지워짐). 각 요청의 헤더에 적을 필요가 없으므로, 그 헤더를 통해 키가 노출되는 일을 막습니다. 비워 두면 위의 *API 키*를 사용합니다. 이는 LiteLLM 같은 프록시 하나가 모든 것을 처리할 때 원하는 동작입니다. 자체 `Authorization` 헤더를 가진 요청은 그 헤더를 유지합니다. |
| 내레이터 목소리 | 등장인물이 없는 책의 내레이터. 서버의 음성 파일은 `predefined:Henry.wav`처럼 적습니다. |
| 정밀도 | Higgs 전용: 모델이 계산하는 정밀도. **fp32**(기본값)가 안전한 선택입니다. AMD 그래픽 카드에서는 **bf16**이 조각을 알아볼 수 없는 소리, 효과음, 잘못된 목소리로 바꿔 놓았습니다. bf16은 그래픽 메모리를 약 절반만 필요로 하며(16GB 대신 약 8GB), 작동하는 환경에서는 더 빠릅니다. |
| 클립의 텍스트를 Higgs에 전송 | Higgs 전용, 실험적 기능: [클립의 텍스트](#voices-and-clips)가 함께 전송됩니다. 끄세요. 테스트에서 목소리가 바뀌는 현상이 있었습니다. |
| 조각 길이 확인 | 기본적으로 켜져 있습니다. 텍스트보다 훨씬 긴 조각(4초 + 단어당 0.6초 기준. 모델이 말을 계속하거나 말 대신 소리를 낸 경우)은 다음 시드로 다시 만들며, 최대 **재시도 횟수**만큼 반복합니다. 올바른 길이의 첫 번째 결과를 유지하며, 없으면 가장 짧은 결과를 유지합니다. |
| 음성 인식으로 단어 확인 | 기본적으로 꺼져 있으며, [음성 인식](#speech-recognition)이 필요합니다. 배치가 끝나면 모든 조각을 받아 적어 텍스트와 비교합니다. 단어의 **최대 단어 오류(%)**를 넘게 틀린 조각은 다음 시드로 다시 만들고 다시 확인하며, 최대 **재시도 횟수**만큼 반복합니다. 틀린 단어가 가장 적은 결과를 유지합니다. 변환 결과에는 다시 만든 조각 수와 여전히 다른 조각 수가 표시됩니다. |
| 조각 기본값 | 각 조각이 시작하는 온도, CFG 가중치, 속도, 청크 크기(스튜디오에서 개별 조각마다 바꿀 수 있습니다). Higgs는 온도만 사용합니다. |
| 배치 전, 배치 후 | 파트 배치(및 각 샘플)마다 그 전후에 보내는 요청으로, GPU 잠금 안에서 실행됩니다. 그래픽 카드를 비우고 음성 서버를 시작하는 일은 GPU 잠금이 담당합니다. [모델과 음성을 위한 GPU 하나](audiobook-server.md#one-gpu-for-the-model-and-the-speech) 참고. 비워 두면 아무 일도 하지 않습니다. |

**연결 테스트**는 배치가 하는 일을 그대로 수행합니다. GPU 잠금을 잡고(중지된 음성 서버는 시작됩니다), 배치 전 요청을 보내고, 서버가 응답하며 모델이 로드되어 있는지 확인하고, 배치 후 요청을 보냅니다. 잠금이나 요청이 없으면 응답 확인만 합니다.

다른 언어의 문자가 포함된 조각(영어 책 속의 일본어)이 있는 책은, 해당 언어용 백엔드가 있으면 다결과 다국어 모델로 보내고 언어 정보도 함께 전달합니다. 해당 백엔드가 없으면 책의 모델을 그대로 사용합니다. Higgs 책은 이런 조각을 그대로 유지합니다. Higgs가 같은 목소리로 직접 읽어 줍니다.
<a id="higgs-audio-v3-emotions-and-sounds"></a>

### Higgs Audio v3: 감정과 소리

**Higgs Audio v3 in ComfyUI** 백엔드를 쓰면 언어 모델이 붙인 라벨이 음성으로 들립니다. 백엔드의 주소는 사용자의 ComfyUI 주소입니다(TTS Audio Suite 노드가 설치된 ComfyUI, [음성 서버 설정](audiobook-server.md#higgs-audio-v3-in-comfyui) 참조).

- 대사의 **전달 방식(delivery)**에 따라 말투가 정해집니다: 슬픔, 분노, 기쁨, 재미, 긴장, 두려움, 놀람, 다정함, 비꼼, 애원, 절박함, 역겨움, 흥분, 속삭임, 고함. 강하게(강도 0.8 이상) 주면 더 표현력 있게 읽히고, 약하게(0.2 미만) 주면 담담하게 읽힙니다. 내레이터는 담담하게 읽습니다.
- 언어 모델은 Chatterbox Turbo보다 대사에 더 많은 **소리**를 넣을 수 있습니다: 웃음, 킥킥거림, 키득거림, 한숨, 숨 들이킴, 기침, 헛기침, 코 훌쩍임, 재채기, 앓는 소리, 울음, 흐느낌, 비명, 헐떡임, 신음, 허밍, 쉿 소리.
- 프로그램은 각 대사 주변의 **지문**(영어)도 읽어서, 모델이 소리를 넣지 않은 대사에 지문이 말하는 소리를 붙입니다. *"You look funny," she giggled.*에는 키득거림이, *She burst out laughing. "Careful!"*에는 웃음이, *a soft moan escaped her lips. "Yes..."*에는 신음이 붙습니다. *panting*이나 *out of breath*가 있으면 헐떡임이, *cried quietly*나 *burst into tears*가 있으면 울음이 붙습니다. 소리처럼 보이기만 하는 것은 제외합니다. 예를 들어 *"Stop!" she cried.*는 감탄(외침)이며, *moaned about the weather*, *the wind moaned*, *the floorboards groaned*, *stifled a giggle*, *didn't laugh*, 그리고 지문이 다른 이름 있는 인물에게 준 소리는 붙이지 않습니다. *"You look funny," he mocked her.*에는 비꼬거나 재미있어하는 전달 방식이 붙고 소리는 붙지 않습니다. 지문 자체는 적힌 그대로 읽힙니다.
- **내레이터는 항상 담담하게 읽습니다**: 소리도 감정도 없으며, 모델이 내레이터에게 맡긴 대사도 마찬가지입니다.
- Higgs는 분위기마다 클립이 필요하지 않습니다. 목소리 클립 하나면 충분합니다. Higgs는 클립의 녹음을 그대로 모방하므로, Chatterbox보다 깨끗한 클립이 더 중요합니다([좋은 클립](#a-good-clip)).
- 각 조각은 ComfyUI가 만들며, 조각마다 끝난 뒤 메모리를 비웁니다(조각당 몇 초). 일부 그래픽 카드가 멈추는 것을 막기 위해서입니다.
- Higgs는 마지막 단어 뒤에도 종종 소리를 이어 가서(숨소리, 다른 소리의 시작 등) 클립이 그 한가운데서 끝나며, 그러면 쉼 전에 짧은 "휙" 소리로 들립니다. **ffmpeg**이 있으면 확장 기능이 그 꼬리를 잘라내고 각 조각을 페이드아웃합니다. 없으면 조각은 Higgs가 만든 그대로 남습니다.
- Higgs Audio v3 모델은 **연구 및 비상업적 사용 라이선스** 아래에 있습니다. 판매하는 오디오북에는 Boson AI의 라이선스가 필요합니다.

<a id="speech-recognition"></a>

### 음성 인식

**음성 인식**은 대사 조각이 무슨 말을 하는지 받아 적습니다. 배치의 조각들을 확인하고(백엔드에 **Check the words with speech recognition**이 설정된 경우), [목소리 클립의 텍스트](#voices-and-clips)를 인식합니다. 실행 위치를 고르세요:

| Setting | What it does |
|---|---|
| Speech recognition | **ComfyUI (Granite ASR)**: 사용자 ComfyUI의 TTS Audio Suite에 있는 Granite 음성 모델(주소는 ComfyUI 주소). **OpenAI-compatible (whisper)**: `/v1/audio/transcriptions`를 제공하는 서버라면 무엇이든, 예를 들어 whisper 서버(faster-whisper, speaches)나 OpenAI API. |
| Address, Api key | ComfyUI 주소, 또는 API의 기본 주소(`/v1`를 붙이거나 생략). 키는 암호화되어 저장됩니다. 주소를 비워 두면 음성 인식을 하지 않습니다. |
| GPU lock | 인식이 사용하는 [GPU 잠금](../administration/gpus.md). 한 장의 카드에서 fp32 Higgs를 쓴다면, 인식에는 별도의 잠금을 주고 그 단계가 ComfyUI를 재시작하도록 하세요. ComfyUI는 음성 모델을 서버 메모리에 보관하는데, 옆에서 인식 모델을 불러오면 서버 메모리가 부족해졌기 때문입니다. |
| Model of the recognition | 비워 두면 ComfyUI는 `granite-speech-4.1-2b`, OpenAI 호환 서버는 `whisper-1`. |
| Timeout, The server is on this machine or on my network | 백엔드와 같습니다. |

**Test connection**은 ComfyUI에 노드가 있는지, 또는 서버가 응답하는지 확인합니다. 배치의 조각 확인은 배치가 끝난 뒤, 음성 서버를 돌려줄 때 이뤄지므로 인식과 음성 모델이 같은 카드를 동시에 필요로 하는 일은 없습니다.

<a id="cleanup-of-clips"></a>

### 클립 정리

**Cleanup of clips**는 [TTS Audio Suite](audiobook-server.md#higgs-audio-v3-in-comfyui)를 갖춘 ComfyUI에서 참조 클립을 정리합니다(Higgs 작업에 쓰는 것과 같은 ComfyUI). 결과는 [Voices and clips](#voices-and-clips)에 있는 클립의 새 **버전**으로 저장되며, 원래 클립은 그대로 남습니다.

| Setting | What it does |
|---|---|
| Address, Api key | ComfyUI 주소. 키는 암호화되어 저장됩니다. 주소를 비워 두면 정리를 하지 않습니다. |
| GPU lock | 정리가 사용하는 [GPU 잠금](../administration/gpus.md). 음성이나 음성 인식의 잠금(그 단계가 ComfyUI를 재시작함)과는 따로 잠금을 주어, 정리 모델이 음성 모델 옆에 절대 올라가지 않도록 하세요. |
| Timeout, The server is on this machine or on my network | 백엔드와 같습니다(시간 제한은 정리 한 번에 대한 것이며 기본값은 10분입니다. ComfyUI는 모델을 처음 쓸 때 내려받기 때문입니다). |
| Cleanup | 목소리 및 클립에서 이름으로 고를 수 있는 정리(프리셋)입니다. 각 정리는 차례로 실행되는 단계들의 목록입니다. **Default cleanups**를 누르면 기본으로 제공되는 정리가 다시 나타납니다. |

단계는 다음 중 하나입니다:

- **Separation model**: 오디오를 *extracted* 부분과 *remaining* 부분 둘로 나누고 그중 하나를 남기는 스위트의 모델. 어느 부분에 목소리가 있는지는 모델에 따라 다릅니다. 보컬 모델(`MelBandRoformer`)은 목소리를 추출하고, 노이즈 제거 모델은 노이즈를 추출하므로 remaining을 남기세요. **Aggressiveness**(0~20)는 얼마나 많이 덜어낼지를 정합니다.
- **Voice fixer**: 품질이 떨어진 목소리(전화, 오래된 녹음)를 복원합니다. 분리 단계보다 목소리의 소리를 더 많이 바꿉니다.
- **ffmpeg (here)**: **Clean with ffmpeg**의 필터로, 애플리케이션이 ComfyUI의 단계들 사이에서 실행합니다.

기본으로 제공되는 정리는 다음과 같습니다: *Voice from music*(영화나 노래에서 목소리 분리), *Remove noise*, *Restore the voice*, *Film or game clip*(음악에서 목소리를 분리한 뒤 노이즈 제거). **Test connection**은 ComfyUI에 노드가 있는지 확인하고, 모델 목록을 서버의 모델로 채웁니다. 모델은 정리에서 처음 쓸 때 ComfyUI가 내려받습니다.

<a id="shared-speech-servers"></a>

### 공유 음성 서버

여러 사용자가 있는 설치에서는 관리자가 모든 사용자를 위한 음성 서버를 둘 수 있으므로, GPU 머신을 한 번만 설정하면 되고 아무도 주소나 키를 알 필요가 없습니다. 관리자는 같은 패널(마지막 절, 관리자만 볼 수 있음)에서 이를 설정합니다. **Shared speech servers**를 열면 사용자 자신의 백엔드와 같은 필드를 가진 창이 열리며, 누가 사용할 수 있는지도 지정합니다: **all users** 또는 목록에서 고른 사용자. 그 옆의 스위치 **Users may add speech servers of their own**는 아래 백엔드를 계속 허용할지 정합니다.

사용자가 얻는 것:

- 패널 맨 위의 **Backend in use**에는 사용할 수 있는 공유 서버(*(shared)* 표시)와 사용자 자신의 서버가 나열됩니다. *Convert to audio* 창과 스튜디오는 고른 서버를 쓰며, 명령도 마찬가지입니다.
- 공유 서버는 이름만 보이며 주소, 키, 요청은 보이지 않습니다. 한 서버 주소에 대한 모든 사용자의 배치는 서로 차례를 기다리므로, 두 사용자가 같은 GPU를 동시에 두 번 시작할 수 없습니다.
- 관리자가 서버 사용 권한을 회수하면, 아직 그 서버를 지정한 작업은 거부됩니다. 다른 서버를 고르세요.
- 관리자가 사용자 자신의 서버를 끄면 패널에 그렇게 표시됩니다. 추가한 서버는 보관되며, 스위치를 다시 켜면 다시 사용됩니다.
- 공유 서버의 *Narrator voice*는 서버의 목소리 파일(`predefined:Henry.wav`)이어야 합니다. 참조 클립은 한 사용자의 리소스이므로 다른 사용자가 읽을 수 없습니다. 배우의 목소리는 평소와 같이 작동합니다.
<a id="actors"></a>

### 액터

**액터**는 당신의 음성 중 하나입니다. 참조 클립([리소스](../resources.md) 중 하나의 오디오, 또는 여기서 새로 업로드한 파일)이거나 서버의 음성 파일이며, **mood**(속삭임, 외침 같은 감정 표현)나 **language**(일본어로 말하는 클립 같은 언어)를 위한 음성을 따로 가질 수 있습니다. 언어가 감정보다 우선하며, 해당 음성이 없으면 액터의 기본 음성을 읽는 데 사용합니다. 액터는 당신의 계정에 보관되며, 어떤 책이든 내레이터와 등장인물에게 액터를 지정할 수 있습니다.

음성 옆의 **Preview**(액터, 설정, 출연진에서)는 그 음성으로 말하는 몇 문장을 재생합니다(언어 음성의 경우 해당 언어로 짧게 말합니다). GPU가 다른 작업에 쓰이고 있으면 GPU 잠금이 먼저 음성 서버를 불러옵니다. 옆의 화살표는 다른 샘플을 제공합니다. **with sounds**(한숨, 웃음, 헐떡임)는 이를 음성으로 표현할 수 있는 모델(Chatterbox Turbo, Higgs Audio v3)에서 제공되며, Higgs의 경우 라벨링된 모든 **mood**(슬픔, 속삭임, 빈정거림 등)가 제공됩니다. 액터는 이름으로 나열됩니다.

각 샘플은 GPU를 자신만을 위해 사용합니다. 샘플이 끝난 뒤에도 GPU는 음성 서버와 함께 로드된 상태로 남아 있어, 언어 모델(또는 다른 서버)의 요청이 GPU를 필요로 하기 전까지 다음 샘플이 바로 재생됩니다. **Voices and clips**를 열면 음성 서버가 미리 로드되므로 첫 샘플을 기다리지 않습니다.

### 음성과 클립

**Voices and clips**(액터 옆)는 액터와 그 음성이 복제된 클립을 한 곳에서 관리하는 창입니다. 처음에는 세 개의 탭이 나란히 있습니다: **Actors**, **Clips**, **Clip**. 탭을 끌어서 다른 탭 옆, 아래, 또는 함께 놓을 수 있으며, 창은 마지막으로 두었던 모습 그대로 다시 열립니다.

- **Actors**: 각 액터의 음성, 다른 음성(감정, 언어)의 개수, 그리고 클립 중 가장 낮은 품질을 보여 줍니다. 추가, 편집 또는 **삭제**할 수 있습니다.
- **Clips**: 당신의 클립은 **폴더**(예: 캐릭터별로 하나) 안에 있습니다. 클립 아래에는 그 클립으로 만든 **versions**가 있으며, 각각 길이, **quality**, 사용처(액터는 감정 또는 언어와 함께, 백엔드의 내레이터)가 표시됩니다. **Add a clip**으로 클립을 업로드합니다.
- **Clip**: 선택한 클립입니다.
  - **이름**과 **폴더**: 클립 이름을 바꿉니다(파일 이름은 그대로 유지됩니다). 폴더에 넣으며, 새 폴더는 이름을 입력해서 만듭니다. 버전은 자신이 만들어진 클립의 폴더에 남아 있고, 무엇으로부터 어떻게 만들어졌는지 표시됩니다.
  - **Play**로 재생하고, 무엇이 잘못되었는지 확인하고, **Replace...**하거나 **삭제**할 수 있습니다(아무도 사용하지 않을 때만 가능하며, 버전은 원본 클립으로 올라갑니다).
  - **Clean with ffmpeg**는 잔잔한 쉿 소리와 웅웅거림을 줄인 버전을 만듭니다. 음악, 효과음, 다른 목소리는 제거하지 않습니다.
  - **Clean with AI**는 선택한 [정리 방식](#cleanup-of-clips)을 ComfyUI에서 적용한 버전을 만듭니다. 백그라운드에서 실행되므로 계속 작업할 수 있으며, 버전이 준비되면 메시지가 알려 줍니다.
  - **Use this version**은 버전을 원본 클립이 쓰이던 모든 곳에 적용합니다. 해당 부분들은 새 음성으로 다시 만들어지며, 이전 클립은 삭제하기 전까지 남아 있습니다.
  - **Text of the clip**: 클립에서 말해지는 단어들입니다. 직접 입력하거나 **Recognize**를 눌러 [음성 인식](#speech-recognition)이 받아 적도록 한 뒤, 수정하고 **저장**하세요. 액터 대화창에도 액터 음성 클립에 대해 같은 필드가 표시됩니다. 버전과 대체 클립은 텍스트를 이어받습니다. Higgs는 백엔드가 보낼 때만 텍스트를 받습니다(기본값은 꺼짐).
- **Replace...**는 다른 클립(당신의 것이거나 업로드할 것)을 해당 클립이 쓰이는 모든 곳에 넣습니다.

음성을 고르는 목록(액터, 백엔드의 내레이터)에서는 클립이 *폴더 / clip › version* 형식으로 표시됩니다.

<a id="a-good-clip"></a>

#### 좋은 클립

음성 모델은 목소리만이 아니라 **recording**(녹음)을 통째로 복사합니다. 방의 울림, 쉿 소리, 영화 장면 아래의 음악이 모든 줄에 되살아나며, 종종 단어 아래에 깔리는 부드러운 "쉬익" 소리로 남는데, 결과물에 어떤 필터를 걸어도 제거되지 않습니다. 따라서 다음과 같이 하세요.

- 쉼이 제대로 있는 한 사람의 깨끗한 녹음을 사용하세요(성우의 샘플, 조용한 방에서 집에서 한 낭독). 길이는 12~30초가 좋습니다. 영화나 시리즈에서 잘라낸 클립은 최악의 경우입니다.
- 품질 표시는 클립에서 측정됩니다. **Clean**은 쉼이 음성보다 최소 45 dB 낮은 경우, **Fair**는 35~45 dB이거나 Chatterbox가 잘라내는 30초보다 긴 경우, **Poor**는 배경 소리가 있거나(35 dB 미만), 왜곡되었거나, 8초보다 짧은 경우입니다. 깨끗하지 않은 클립은 추가할 때 알려 줍니다.
- AI로 클립을 정리하세요([클립 정리](#cleanup-of-clips)). 테스트에서 *Film or game clip* 정리는 쉿 소리, 웅웅거림, 에코가 있던 클립을 *Poor*에서 *Clean*으로 바꿨습니다(쉼이 음성보다 38에서 89 dB 낮아짐). 사용하기 전에 버전을 직접 들어 보세요. 분리 모델은 숨소리나 부드러운 단어의 끝도 함께 없앨 수 있습니다. ffmpeg 정리는 지속적인 잡음만 낮추므로, 영화 클립에서는 약 3 dB 개선되는 데 그쳤고 클립은 *Poor*로 남았습니다.
- ComfyUI가 없다면 직접 정리하세요. 클립의 쉼에서 잡음 프로필을 잡아 [Audacity](https://www.audacityteam.org/)의 잡음 제거 기능을 쓰거나, 음악이 있는 클립이라면 [Ultimate Vocal Remover](https://github.com/Anjok07/ultimatevocalremovergui) 같은 보컬 제거 도구를 쓰세요.

## 책의 출연진과 발음

둘 다 책과 함께 보관되며(백업에도 함께 들어갑니다), **Convert to audio** 대화창에서 편집합니다.

**Cast**는 누가 읽을지를 정합니다. **narrator**에게 액터 하나, **other speakers**(모델이 이름을 붙였지만 출연진에 없는 누구든; 비어 있으면 내레이터가 읽음)에게 액터 하나, 그리고 각 **character**마다 액터 하나를 지정합니다. 등장인물은 이름과, 텍스트에서 그 인물을 가리킬 수 있는 다른 이름들(*Tomáš Novák*의 *Tom*)을 쉼표로 구분해 가집니다. 대사는 그 인물의 이름이나 다른 이름 중 하나가 일치하거나, 다른 등장인물과 공유하지 않는 이름의 한 단어가 일치하면(대소문자와 악센트는 무시) 그 인물에게 배정됩니다. **Add the characters of the book**은 부분들의 시점 인물과 등장 인물로 목록을 채웁니다.

![책의 출연진](../../images/plugin-audiobook-cast.png)

**Pronunciation**은 텍스트를 *음성을 위해* 어떻게 철자할지를 정합니다. 책 자체는 결코 바뀌지 않습니다. **dictionary**는 단어 전체를(대소문자 구분) 읽을 내용으로 바꿉니다. 이름이나 지어낸 단어의 다른 철자, 또는 일본어의 가나 읽기를 넣을 수 있습니다. 영어 책의 경우 규칙이 숫자, 서수, 연도, 시간, 금액, 약어도 단어로 읽고, 숫자만 있는 제목은 *Chapter four. The Arch*처럼 읽습니다(숫자 앞의 단어는 당신이 정합니다). 또 `*` 같은 마크다운 표시는 제거되며, 장면 구분(`***`, `---`)은 읽지 않고 대신 더 긴 쉼이 됩니다. 다른 언어로 된 책에는 이 규칙을 끄세요. **dictionary**는 여전히 적용됩니다. **Try a text**는 텍스트 조각이 어떻게 읽힐지 보여 줍니다. 말해지는 텍스트가 바뀐 조각만 다시 만들어지고, 나머지는 유지됩니다.

![책의 발음](../../images/plugin-audiobook-pronunciation.png)
<a id="converting-a-book"></a>

## 책 변환하기

*스토리 편집기의 도구 메뉴(톱니바퀴 버튼) → **Convert to audio***.

![시작 전 대화상자](../../images/plugin-audiobook-convert.png)

1. **backend**를 고르고 **Load**를 누르세요. 활성 분기에서 텍스트가 있는 파트가 목록으로 나타나며(첫 번째 파트는 1번), 각 파트의 상태가 함께 표시됩니다:
   *Not generated*, *Labelled*(모델 라벨이 저장됨, 아직 오디오 없음), *생성됨*(재생 버튼과 다운로드 포함) 또는 *Generated (the text changed)*(이전 텍스트로 만든 오디오라 다시 만들어짐). 스튜디오에서 final로 표시한 파트에는 *(final)*이 붙습니다.
2. 기본 버전을 원하면 **Label the parts with a language model**을 끄세요. 이 경우 내레이터가 모든 문단을 읽습니다. 켜면 모델이 대사마다 누가 말하는지, 어떻게 말하는지(차분하게, 속삭이며, 외치며 등), 그리고 어디에 효과음 태그가 들어갈지 정하고, 등장인물 목록이 목소리를 정합니다. 책에 쓸 모델이 선택되어 있으며, 원하면 다른 모델을 고를 수 있습니다. 파트는 먼저 라벨이 붙은 뒤 낭독됩니다. 텍스트에 이미 라벨이 있는 파트는 체크박스를 껐을 때도 그 라벨을 사용해 읽습니다(모델에 묻지 않음). 따라서 라벨이 붙은 책을 체크박스를 끈 채 다시 실행해도 대사가 일반 서술로 바뀌지 않습니다. 일반 서술로 읽기를 원하거나 새 라벨을 받고 싶다면 **Remove labels**를 사용하세요.
3. 파트를 체크하고(머리글의 체크박스를 누르면 모두 선택됨) 각 파트에 무엇을 할지 **계획**하세요. **계획** 열에 표시되며, 아직 아무것도 실행되지 않습니다:
   **생성**(없는 것을 만듦; 최신 상태인 파트는 다시 만들지 않음), **다시 생성**(오디오를 지우고, 라벨을 제거한 뒤, 생성), **Delete audio**(파트의 조각들과 이어 붙인 오디오를 삭제; 라벨은 유지), **Remove labels**(파트를 다음에 만들 때 모델에 다시 묻도록 함), **Clear the plan**. 한 파트에 여러 단계를 계획하면 누적됩니다(Generate 없이 Delete audio와 Remove labels만 쓰면 정리만 수행). final로 표시된 파트는 모든 계획에서 제외됩니다.
4. **시작**을 누르면 계획이 실행됩니다. 오디오나 라벨을 지우는 작업이면 먼저 확인을 묻습니다. 생성할 항목은 대기열에 들어가며, 창을 닫거나 페이지를 떠나도 계속 진행됩니다. 대기 중이거나 대기열에서 실행 중인 파트는 계획에서 제외됩니다. 파트의 행에는 상태, 지금까지 만들어진 조각들, 작업 메시지가 표시됩니다.
   모델이 파트에 라벨을 붙이는 동안 행에는 *Labelling pieces 17-32 of 120*이 표시됩니다(모델에는 한 번에 16개 조각씩 요청함). 라벨링이 끝난 파트의 **상태를 클릭**하면, 각 요청에 대해 모델의 추론과 응답을 도착하는 대로 읽을 수 있습니다. 이 내용은 작업과 함께 메모리에 보관되며, 완료된 작업을 지우거나(*Clear finished*) 애플리케이션을 재시작할 때까지 유지됩니다.

![대기열: 지금까지 만들어진 조각들과, 파트가 완료되었을 때의 다운로드](../../images/plugin-audiobook-queue.png)

파트가 어떻게 만들어지는지, 무엇을 예상해야 하는지 알 수 있도록 설명합니다:

- 텍스트는 모델이 아니라 **프로그램이 나눕니다**. 서술 조각과 직접 화법 조각으로 나뉘며, 직접 화법은 곧은 따옴표나 둥근 따옴표, 일본어 꺾쇠 괄호 사이의 말입니다(제목은 서술로 취급). 모델은 번호가 매겨진 조각에 *라벨*만 붙입니다. 효과음 태그가 있는 텍스트는, 태그만 추가되고 다른 것은 전혀 바뀌지 않은 경우에만 사용되므로, 모델이 책 내용을 바꿀 수는 없습니다.
- **누가 조각을 말하는지는 대사일 때 모델이 정하고, 서술은 내레이터의 몫입니다.** 편지, 쪽지, 메시지, 등장인물의 생각에는 따옴표가 없으므로 프로그램은 이를 서술로 취급합니다. 이런 조각은 **이탤릭으로 시작하고**(`*...*` 또는 `_..._`) 모델이 문맥(서명, "필체를 보고 누군지 분명했다" 같은 표현)에서 등장인물을 지목한 경우에만 그 인물(등장인물 목록의 목소리)이 읽습니다. 3인칭 서술은 등장인물의 시점에서 쓰였더라도("그녀는 퍼시가 방을 가로지르는 것을 지켜보았다") 항상 내레이터가 읽습니다. 이탤릭 없이 조각에 등장인물을 지정하더라도 프로그램은 이를 무시합니다. 강조, 소리, 외래어를 위한 이탤릭도 서술입니다. 단어는 항상 작가님 것입니다.
- **모델에 주는 지시문은 바꿀 수 있는 템플릿입니다.** *Settings → 확장 기능 설정 → Audiobook Settings → Labelling prompt*가 기본값입니다. 책(*Prompts* 탭 → *확장 기능 설정* → *Audiobook*)이나 폴더에도 자체 지시문을 둘 수 있습니다. 비워 두면 위쪽 폴더의 지시문이, 그것도 없으면 작가님의 기본값이, 그것도 없으면 내장 지시문이 쓰입니다. 다른 [프롬프트](../books/prompts.md)와 같은 방식으로 작성하며, 변수는 `{{characters}}`, `{{deliveries}}`, `{{tags}}`, `{{wordsPerTag}}`입니다. 힌트 팝오버에는 **기본 템플릿 삽입**이 있습니다. 지시문을 바꾸면 다음번에 파트를 만들 때 해당 파트의 라벨을 다시 요청하게 됩니다.
- **파트의 음량은 맞춰집니다.** 프로그램에 ffmpeg가 설치되어 있으면(`.m4b`를 만드는 것과 같은 ffmpeg) 모든 파트의 이어 붙인 오디오가 하나의 음량으로 맞춰집니다(EBU R128, 선형 방식이라 다이내믹은 유지됨). 기본값은 **-18 LUFS**이며, *Settings → 확장 기능 설정 → Audiobook Settings*에서 바꿀 수 있고, 여기서 끌 수도 있습니다. 조각은 서버가 만든 그대로 보존되며 이어 붙인 파트만 음량이 맞춰지므로, 오디오북이 파트마다 음량이 튀지 않습니다. **이전에 만든 파트**는 다시 변환하기 전까지 건드리지 않습니다. 다시 변환하면 저장된 조각에서 다시 이어 붙이고 음량을 맞추며, 음성 서버에는 아무것도 요청하지 않습니다(언어 모델도 언로드하지 않음). 음량 맞추기를 끄면 이미 맞춰진 파트는 그대로 남습니다. 어떤 파트에서 ffmpeg가 실패하면 그 파트는 원래 오디오를 유지하며, 결과에 이를 알려 줍니다.
- 클릭 한 번에 포함된 모든 파트는 **음성 모델마다 하나의 배치**로 만들어집니다. 배치 앞의 요청은 한 번 실행되고, 이어서 모든 조각을 낭독하고, 배치 뒤의 요청이 한 번 실행됩니다. 이렇게 해야 그래픽 카드가 파트마다 모델을 바꾸지 않습니다.
- 모든 조각은 **내용에 따라 보관됩니다**(텍스트, 목소리, 모델, 언어, 설정, 시드). 이미 최신 상태인 파트는 비용이 들지 않고, 바뀐 문단만 다시 만들어지며, 실패한 파트는 **Retry**를 누를 때 이미 만들어진 조각을 유지합니다.
- 조각들은 위치에 따라 달라지는 쉼(제목 뒤, 문단 사이, *he said* 앞)과 함께 이어 붙여져, 파트마다 하나의 mp3가 되고 그 파트와 함께 보관됩니다.
- 작가님의 생성 작업이 실행되는 동안 음성 작업은 기다리므로, 그 아래에서 언어 모델이 언로드되지 않습니다.
- 스튜디오에서 **final**로 표시한 파트는 건드리지 않으며, 대화상자에 그 개수가 표시됩니다.
- **오디오북 전체**는 최신 오디오가 있는 모든 파트를 하나의 mp3로 이어 붙이고, 파트마다 챕터 표시를 넣으며, 목록 아래에 다운로드 링크를 보여 줍니다(제외된 파트는 이름으로 표시됨). 같은 파일이 내보내기 형식 *one mp3 with chapter marks*에도 해당합니다.
- **Stop all**은 대기 중인 파트를 취소하고 실행 중인 파트도 즉시 멈춥니다. 언어 모델에 보낸 요청(라벨링)이나 음성 서버에 보낸 요청(낭독 중인 조각)은 기다리지 않고 버려집니다. 시작되기 전에 멈춘 배치는 앞의 요청을 보내지 않으므로, 언어 모델은 로드된 상태로 남습니다. **다운로드**를 누르면 완료된 파트의 mp3를 받을 수 있습니다.

## 오디오북 스튜디오

*도구 메뉴 → **오디오북 스튜디오*** (선택한 조각의 목소리와 미리듣기는 그 조각의 스피커 옆에 있습니다)는 최종 오디오북을 만드는 곳입니다. 부분 단위로 작업하며, 스크립트를 보고, 고치고, 조각을 들어 본 뒤 부분을 완성합니다.

![음성이 선택된 스튜디오](../../images/plugin-audiobook-studio.png)

- 부분에 주석을 달거나 만드는 동안에는 무언가 진행 중임을 알려 주는 막대가 나타나고, 추가 작업을 시작하는 버튼들은 기다리게 됩니다.
- **주석 달기**는 부분의 스크립트를 만듭니다. 요청하면 언어 모델을 사용하고, 그렇지 않으면 내레이터가 맡습니다. 조각들은 표로 보입니다. 열은 화자, 전달 방식, 강도, 말하는 텍스트, 그리고 바꾼 조각을 표시하는 표시입니다. 실행되는 동안에는 옆에 **중지** 버튼이 나타나며, 이 버튼을 누르면 언어 모델에 보낸 요청이 끝납니다.
- 조각을 선택하면 **화자**, **말하는 텍스트**, **전달 방식**, **강도**(목소리의 과장 정도이며, 이를 지원하는 모델에서만 쓸 수 있습니다. Higgs에서는 전달 방식과 강도가 말하는 텍스트 시작 부분의 `<|emotion:sadness|>` 같은 표시이며, 바꾸면 함께 따라 바뀝니다), **언어**, **시드**, **뒤 쉼**을 편집할 수 있습니다. **적용**을 누르면 변경 사항이 유지되고 조각이 **잠깁니다**. 새 주석 달기를 하면 잠긴 조각은 그대로 남습니다.
  **잠금 해제**를 누르면 조각이 다시 주석 달기의 대상이 됩니다. *음성 서버가 받는 요청*을 누르면 정확한 요청 내용을 볼 수 있습니다.
- **들어보기**는 조각 하나의 오디오를 만듭니다(그 조각만을 위해 음성 서버를 시작합니다). **다른 테이크**는 새 시드로 다시 만들고, **테이크**들은 보관되어 마음에 드는 것을 고를 수 있습니다(*이 테이크 사용하고 듣기*). 좋은 목소리는 종종 시드에 달려 있습니다.
- **현재 스크립트로 부분 만들기**는 조각들을 현재 상태 그대로 이어 붙입니다. 새로 주석을 달지는 않습니다.
- 부분의 **상태**는 *초안*, *검토됨*, *최종* 중 하나입니다. 최종 부분은 다시 주석이 달리거나 변환되지 않으며, 내보내기를 최종 부분으로만 제한할 수 있습니다.

## 내보내기

오디오북은 책의 *이야기 내보내기*의 한 형식입니다. **오디오북(장마다 mp3 하나, zip 파일로)**, **오디오북(장 표시가 있는 mp3 하나)**, 그리고 ffmpeg가 설치되어 있을 때는 **오디오북(장이 있는 m4b 하나)**이 있습니다. 이들은 최신 상태인 부분들의 오디오로 만들어집니다. 오디오가 없거나, 텍스트나 스튜디오의 스크립트보다 오래된 오디오를 가진 부분은 제외되며, 창에 어느 부분인지 표시됩니다. mp3 파일에는 ID3 태그(책 제목, 장, 트랙 번호)가 들어 있고, 단일 파일에는 VLC나 대부분의 오디오북 앱이 보여 주는 장 표시가 있습니다. zip에는 재생 목록이 들어 있습니다. **오디오북: 최종 표시된 부분만** 체크 상자를 선택하면 내보내기를 스튜디오에서 완성한 부분으로만 제한합니다.

**m4b**는 Apple Books와 대부분의 휴대폰 오디오북 앱이 요구하는 형식입니다. 음성에 충분한 64kbit/s의 AAC 오디오를 장, 제목, 저자, 장르 정보와 함께 MP4 컨테이너에 담습니다. m4b는 ffmpeg가 만들기 때문에 ffmpeg가 있는 서버에서만 제공됩니다. mp3로 저장된 오디오는 m4b를 만들 때 한 번 더 인코딩되며, wav로 저장된 오디오는 한 번만 인코딩됩니다.

<a id="how-the-audio-is-stored"></a>

### 오디오 저장 방식

관리자는 *설정 → 확장 설정 → 오디오북 설정*(맨 아래 섹션이며 관리자에게만 보입니다)에서 전체 설치본에 대해 저장 방식을 고릅니다.

- **mp3**(기본값): 용량이 작고, 디코더 없이 이어 붙일 수 있으며, ffmpeg가 필요하지 않습니다. m4b는 두 번째 손실 압축 단계가 됩니다.
- **wav**: 무손실이며 용량은 약 열 배입니다(한 시간 분량의 음성이 약 170MB). ffmpeg가 필요합니다. 조각은 음성 서버에 wav로 요청되고 wav로 이어 붙여집니다. 브라우저는 그대로 재생합니다. mp3 및 zip 내보내기는 ffmpeg가 (96kbit/s로) 인코딩하며, m4b는 한 번만 인코딩됩니다.

이 선택은 그 시점 이후에 만들어지는 것에 적용됩니다. 그 전에 만든 부분은 기존 오디오를 그대로 유지하며 있는 그대로 처리됩니다. 두 종류가 섞인 부분(이전에 만든 스튜디오의 잠긴 조각)은 wav로 이어 붙여지며, 두 종류가 섞인 부분들의 내보내기도 동작하지만 ffmpeg가 필요합니다.

책 전체의 내보내기는 부분들의 저장된 파일로부터 서버의 임시 파일을 만들어 그곳에서 내려받습니다. 따라서 길이가 애플리케이션의 메모리에 의해 제한되지는 않지만, 만드는 동안 임시 폴더에는 책 오디오의 약 두 배 분량의 공간이 필요합니다(wav의 경우 한 시간당 약 350MB).

![오디오북 형식이 있는 내보내기 대화상자](../../images/plugin-audiobook-export.png)

<a id="automatic-conversion"></a>

## 자동 변환

책은 부분이 최종 상태가 되면 그 부분의 오디오를 스스로 만들 수 있습니다. 자동 주석, 책에 있다면 재작성과 번역 후에, [부분 뒤에 오는 것](../books/story-editor.md#what-follows-a-generated-part)의 마지막 단계로 실행됩니다(오디오가 만들어질 때까지의 실행 목록 패널에서 확인할 수 있으며, 그 **중지**는 해당 부분을 대기열에서 뺍니다). 기본값은 **끔**입니다. 책의 *프롬프트* 탭의 확장 설정에서, 책 폴더 단위로, 또는 오디오북 설정에서 모든 책에 대해 고를 수 있습니다. 가장 가까운 설정이 우선합니다.

- **아니요**,
- **예: 내레이터가 부분을 읽음**,
- **예: 책의 모델이 표시한 인물별 음성, 등장인물이 목소리를 정함**. 모델이 없는 책은 일반 내레이션을 사용하며, 그 사실이 알림으로 전달됩니다.

![책의 설정](../../images/plugin-audiobook-auto.png)

부분은 책의 등장인물 배역과 발음 정보와 함께 대기열에 들어갑니다. 대기열에 들어갔다는 알림과 오디오가 준비되었거나 실패했다는 또 다른 알림이 나타나며, 이 알림은 생성을 시작한 페이지에서만 보입니다. 작업은 어느 경우든 *오디오로 변환* 창에 있습니다.

<a id="listening"></a>

## 듣기

오디오가 있는 부분을 가진 게시된 책(또는 리더)에는 재생 막대가 나타납니다. 재생, 일시 정지, 정지, 속도 조절이 있으며, 듣고 있는 부분은 본문에서 표시됩니다. 재생은 선택 영역이나 화면에 보이는 첫 부분에서 시작하며, 부분을 순서대로 재생하고, 현재 부분이 재생되는 동안 다음 부분을 미리 가져옵니다. 기기의 미디어 컨트롤도 책을 인식합니다. 부분의 이전 텍스트로 만든 오디오는 제공되지 않습니다. 오디오는 책의 소유자에게 제공되며, 책이 게시된 동안에는 책을 열 수 있는 모든 사람에게도 제공됩니다. 게시가 취소된 책은 즉시 제공이 중단되며(다음 부분을 불러올 때 적용됩니다).

![리더의 재생기](../../images/plugin-audiobook-player.png)

<a id="a-part-without-audio"></a>

### 오디오가 없는 부분

재생기는 오디오가 없는 부분에서 멈추어, 이야기의 한 부분이 건너뛰어지지 않도록 하며, 그 사실을 알려 줍니다. 확장 [Read Aloud](tts-reader.md)가 설치되어 있으면 재생 막대에 스피커 버튼도 나타나며, 버튼의 문구는 **이 부분(및 오디오가 없는 다음 부분들)을 브라우저의 음성으로 읽기**입니다. 누르기 전에는 기계 음성으로 아무것도 읽히지 않습니다. 누르면 그 부분과, 이어지는 오디오가 없는 부분들을 기기의 음성으로 읽고, 오디오가 있는 부분에 이르면 재생기가 다시 이어받습니다. 같은 청취 중에 이후 오디오가 없는 부분들도 다시 묻지 않고 같은 방식으로 읽힙니다. **정지**를 누르면 음성이 멈추며, 재생기를 새로 시작하면 다시 묻습니다. 음성, 속도, 음높이는 Read Aloud의 설정을 따릅니다.
## Commands

[명령](../commands/index.md)과 같은 것들입니다(스토리 편집기의 명령줄, 템플릿의 `command` 매크로, 에이전트). 부분은 변환 대화상자가 매기는 번호로 지정하거나, 이름(핸들)으로 지정합니다.

| 명령 | 기능 |
|---|---|
| `/audiobook-status [from [to]]` | 사용 중인 음성 서버, 책이 자체적으로 변환되는 방식, 오디오가 있는 부분 수(없음, 준비됨, 텍스트보다 오래됨, 스크립트보다 오래됨), 스튜디오에 나열된 각 부분의 상태, 대기열을 보여 줍니다. 책이 길 때만 느립니다. |
| `/audiobook-convert [from [to [labelling [what [wait]]]]]` | 부분들을 대기열에 넣습니다(인수가 없으면 책 전체, `from`만 주면 한 부분). `labelling` `true`는 책의 모델을 사용합니다. `what`는 `audio` 또는 `script`입니다(스튜디오용 스크립트만 만들며, 아무것도 읽지 않습니다). `wait` `true`을 붙이면 작업이 끝날 때까지 명령이 계속 실행되며, 진행 상황을 보여 주고 각 작업이 어떻게 끝났는지 알려 줍니다. 명령을 중지하면 아직 시작하지 않은 작업은 취소됩니다. |
| `/audiobook-stop` | 대기 중인 부분을 취소합니다. 실행 중인 부분은 한 조각을 마친 뒤 멈춥니다. |
| `/audiobook-set-part-status part status` | 스튜디오에서의 `draft`, `reviewed` 또는 `final`. 해당 부분에는 스크립트가 필요합니다. |
| `/audiobook-cast` | 내레이터, 대체 음성, 배우가 연결된 등장인물 캐스트. |

![명령의 결과](../../images/plugin-audiobook-command.png)

오디오는 [에이전트](../agents.md)의 숨겨진 작업 사본이 아니라 **여러분의** 책을 위해 만들어집니다. 에이전트는 캐스트를 읽을 수 있지만, 다른 명령은 거부당하며 직접 실행해야 한다는 메시지를 받습니다.
명령줄에서 실행하거나, 에이전트에게 책을 준비하는 작업(주석 달기, 검토)을 맡긴 뒤 변환은 여러분이 직접 하세요.

## Notifications

책 변환 일괄 작업이 끝나면 브라우저가 알려 줄 수 있습니다([알림](../account.md#notifications)). 음성 서버가 작업하는 동안 탭을 떠나 있어도 됩니다. *설정* 페이지의 알림 목록에는 두 줄이 있습니다: **Convert to audio**(대화상자나 명령으로 시작한 일괄 작업)와 **Convert to audio (automatic)**(자동으로 오디오가 된 새 부분). 중지한 일괄 작업은 알림을 보내지 않으며, 실패한 부분이 있는 일괄 작업은 실패했다고 알립니다.

![알림 목록](../../images/plugin-audiobook-notifications.png)

<a id="what-it-does-not-do-yet"></a>

## 아직 지원하지 않는 기능(아직)

- mp3와 wav만 지원합니다(opus는 불가). 각 조각의 음량은 음성이 내는 그대로입니다.
- 효과음이나 배경음은 없습니다.
- 음성 엔진은 두 가지입니다: Chatterbox와 Higgs Audio v3(ComfyUI 안).
- 구간 밖에서 음성을 미리 듣기(오디션)하는 기능은 없습니다.
- 캐스트는 책 백업에 *배우*의 정보를 포함하지 않습니다. 복원된 책은 캐스트를 그대로 유지하지만, 계정에 존재해야 하는 배우 이름을 가리킵니다.
