# 资源

**资源**标签页列出了你上传到 Marginalia 的文件：你的书籍中各部分的[图片](books/story-editor.md#images)，以及 [Audiobook](extensions/audiobook.md) 等扩展随之保存的音频。该标签页用于找回文件、收听音频、下载文件、在不改动使用它的书籍的情况下替换为更好的版本，以及删除你不再需要的内容。

![资源标签页](../images/resources-tab.png)

文件按照使用它们的对象分组：表格的每一行是一个对象（例如书籍的某一部分，`ChatMessage #123`），显示其文件数量、总大小以及最新文件的日期。点击该行中的箭头即可展开对象，查看其文件。表格会随着你滚动和展开分组而逐步加载，因此即使有数千个文件也能保持流畅。点击列标题即可按该列排序，分组及其中的文件会随之排列；默认情况下最新的文件排在最前。

| 行 / 列 | |
|---|---|
| **使用者** | 文件所添加到的对象。*nothing* 用于分组那些未被任何对象使用的文件。名称后面的 *(gone)* 表示该对象已被删除或已不存在，这些文件很可能已不再需要。在分组内部：图片的小预览以及上传时的文件名。 |
| **类型** | 文件的类型，例如 `image/png`。 |
| **大小** | 文件的大小；对于分组，则为其中所有文件的总和。 |
| **创建时间** | 文件上传的时间；对于分组，则为其中最新文件的时间。 |

这只是为你保留的一份记录。Marginalia 并不强制执行：部分所添加到的部分已经消失，图片仍然可以正常显示；同一张图片也可以被多个部分使用（例如在你[分支](books/branches-and-story-tree.md)故事之后，分支会拥有与其源部分相同的图片）。

<a id="play"></a>

## 播放

音频类型的文件（`audio/mpeg`、`audio/wav`……）在其他按钮前面带有 **播放**按钮（三角形）。它会在页面中播放该文件；播放时按钮变为 **暂停**，停止播放或音频结束后再变回播放。同一时间只会播放一个文件：开始播放另一个文件会停止正在播放的那个。

<a id="download"></a>

## 下载

该行中的下载按钮（向下箭头）会将文件保存到你的电脑。

<a id="replace-the-content"></a>

## 替换内容

该行中的上传按钮会打开一个对话框，供你选择新文件。新内容会被保存为一个新文件，该条目随即指向它，因此**所有使用该条目的地方都会显示新内容**；你无需修改各个部分。可以用它将图片替换为更好的版本，或修正错误的上传。

- 图片只能替换为图片（PNG、JPEG、GIF 或 WebP，最大 10 MB，与[添加图片](books/story-editor.md#images)时的要求相同）。
- 条目的名称会变为新文件的名称。
- 之前的文件不会从数据文件夹中删除，见[下文](#what-delete-does)。

![替换资源内容](../images/resources-replace.png)

<a id="deleting"></a>

## 删除

该行中的垃圾桶按钮会删除一个文件。要删除多个文件，请在第一列中勾选它们，然后选择表格上方的**删除所选**。勾选某个分组（对象所在的一行）会删除其中的所有文件。表头中的复选框会选中所有分组。Marginalia 会在删除前进行确认。

<a id="what-delete-does"></a>

### 删除的作用

- 文件会从表格以及使用它的部分中消失：该部分将不再显示图片。部分的文字、摘要和导出内容均不会改变。
- 该条目只会被**标记为已删除**。管理界面中的[清理](administration/cleanup.md)会将其从数据库中永久移除。
- **文件仍保留在数据文件夹**（`data/<your login>/images`）中，即使清理之后也是如此。删除资源本身并不会释放磁盘空间：管理员需要在管理界面的[资源文件](administration/resource-files.md)标签页中移除所有不再被使用的文件。
- 在清理移除该条目之前，你可以从[回收站](trash.md)中将其恢复：文件仍在数据文件夹中，因此图片可以再次正常显示。清理之后，只有在此之前制作的[整个数据库的备份](administration/database-backups.md)中才会包含该条目；文件本身仍保留在文件夹中。
