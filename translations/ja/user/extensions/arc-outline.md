# アークアウトライン

サイドバーにある、本の計画です。アークは章に分けられ、それぞれの状態が表示されます。また、モデルにアークや章を書いてもらうこともできます。アウトラインはストーリーのプロンプトには含まれません。ジェネレーターや[サイドクエリ](side-query.md)は、指示されたときにアウトラインを利用できます。

<a id="the-arcs-tab"></a>

## Arcsタブ

[ストーリーエディター](../books/story-editor.md)の左サイドバーに、*アウトライン*の隣へ**Arcs**タブが追加されます。**Add new arc**を押すと、アークの設定ダイアログが開きます:

| 項目 | |
|---|---|
| Title | 必須です。 |
| Description | そのアークで起こる出来事。 |
| Note (private) | 自分用のメモ。 |
| State | **Planned**、**現在**、または **Finished**。 |
| Linked part | アークまたは章が属する、物語の部分。[下記](#linking-to-the-story)を参照。 |

章にも同じ項目があります。一覧では、各アークがカードとして表示され、その下に章が字下げされて並びます。カードの色は状態に応じて変わります。Planned の状態は灰色、現在のアークは青、Finished のものはタイトルを淡くした緑です。カードのボタンは次のとおりです:

| ボタン | |
|---|---|
| カレンダー / 再生 / チェック | 状態。変更するためのメニューを開きます。 |
| シェブロン（アーク） | アークの章を隠す、または表示します。 |
| シェブロン（メモのある章） | 章の説明の下にあるメモを表示または非表示にします。ダイアログを開かずに読めます。 |
| 矢印 | アークまたは章を上下に移動します。 |
| プラス（アーク） | アークの末尾に章を追加します。 |
| 魔法の杖（アーク） | モデルにアークの章を書かせます。[下記](#generating-chapters)を参照。 |
| ターゲット（リンク先のあるアークと章） | ストーリーを、リンクされた部分までスクロールします。 |
| ペン | ダイアログで開きます。 |
| ゴミ箱 | 確認のあと、削除します（アークの場合は、その章もすべて削除されます）。 |
| ロボット（生成されたアークと章） | モデルが書いた内容を表示します。[下記](#generating-an-arc)を参照。 |

上部の魔法の杖の隣には、羽根ペンのボタンがあります。現在の章をもとに、次のターンの指示の下書きを作成します。[下記](#drafting-the-instructions-for-the-current-chapter)を参照。

![Arcsタブ: 完了したアーク、現在のアーク、計画中のアーク](../../images/plugin-arcoutline-tab.png)

<a id="linking-to-the-story"></a>

### 物語へのリンク

アークや章は、**物語の一部にリンク**できます。そうすると、計画から本文の該当箇所へ移動できます。ダイアログには **Linked part** の欄があります。これは、有効なブランチ内でのその部分の位置で、*アウトライン*タブに表示される番号どおり1から数えます（`#12`）。直接入力するか、横にある **link** ボタンを押すと、そのとき物語の中で**もっとも見えている**部分を取り込めます（先に該当箇所までスクロールしてから、ダイアログを開いてください）。**target** ボタンは、欄に入っている部分まで物語をスクロールします。リンクされたアークや章のカードには、target ボタンも表示されます。リンクはブランチ内の位置なので、その前の部分が削除または挿入されると、別の部分を指すようになります。その場合は書き換えてください。物語からのインポートでは、章のリンクが自動で設定されます。[下記](#importing-an-arc-from-the-story)を参照。

<a id="the-note-of-a-chapter"></a>

### 章のメモ

メモのある章には、右側にシェブロンが表示されます。これを押すと、一覧の説明文の下にメモが開くので、ダイアログを開かずに章の詳細（たとえばモデルが書いた内容）を読めます。もう一度押すと、メモが隠れます。どのメモを開いているかは保存されません。

![メモを表示した章](../../images/plugin-arcoutline-note.png)

<a id="moving-chapters-between-arcs"></a>

### アーク間で章を移動する

アークの先頭の章を上に移動すると、前のアークの末尾に移ります。末尾の章を下に移動すると、次のアークの先頭に移ります。矢印を押し続けると、必要な位置まで章を移動できます。

<a id="drafting-the-instructions-for-the-current-chapter"></a>

### 現在の章の指示を下書きする

*Add new arc* の隣にある羽根ペンのボタンを押すと、ウィンドウが開き、モデルが次のターンの[指示を下書き](../books/story-editor.md#drafting-the-instructions)できます。その際、物語が現在いる章のデータが **物語の計画** として使われます。現在の章は、**現在** と印のついた最初の章です。そのような章がない場合は、**Finished** でない最初の章になります。現在と印のついたアークに章がまだない場合は、そのアークだけが対象になります。モデルには、そのアークと章の説明とメモ、および次の章のタイトルと説明（メモは含みません）が渡されます。また、物語はまだその先に進んではいけない、という注意も伝えられます。ウィンドウは、新しいターンのパネルの *指示* に入力した内容を、ガイダンスとして最初から入れた状態で開きます。**Use as Instructions** を押すと、下書きがそのパネルに入り、パネルが開きます。現在の章がない場合は、ボタンにその旨が表示されます。

同じデータは、[サイドクエリ](side-query.md)でも利用できます。[下記](#the-outline-as-a-source-for-other-extensions)を参照。

<a id="finishing-an-arc"></a>

### アークを完了する

アークを **Finished** にすると、その章もすべて **Finished** になります。アークを別の状態に変更しても、章の状態はそのままです。

アウトラインは変更するとすぐに本とともに保存されるため、本のバックアップにも含まれます。

<a id="the-outline-as-a-source-for-other-extensions"></a>

## 他の拡張機能のデータソースとしてのアウトライン

アウトラインは、本に関するデータのソースとして他の拡張機能にも提供されます。[サイドクエリ](side-query.md)では、プラグのポップオーバーで **Arc outline** にチェックを入れると、質問とともにアーク、その状態、説明、章を送信できます。2つのバージョンがあります。**Arc outline** は簡潔版（説明のみ）です。**Arc outline (with notes)** は、各アークと章の説明の下にメモを追加します。生成されたアークと章の詳細は、そこに入っています。非公開のメモは、2つ目にチェックを入れた場合にのみ送信されます。3つ目のソースである **Arc outline: current chapter** は、物語が現在いるアークと章のみを送信します（[現在の章の指示を下書きする](#drafting-the-instructions-for-the-current-chapter)を参照）。

<a id="generating-an-arc"></a>

## アークを生成する

**Add new arc** の隣の魔法の杖ボタンを押すと、3つの項目があるメニューが開きます。**Generate an arc** は、モデルに新しいアークを書かせます。**Import from story** は、すでに書いた内容を要約します（[下記](#importing-an-arc-from-the-story)を参照）。**Develop the plot** は、物語がどこへ向かうかについてモデルと会話します（[下記](#developing-the-plot-in-a-conversation)を参照）。

![魔法の杖のメニュー](../../images/plugin-arcoutline-menu.png)

**Generate an arc** のダイアログは、2つの領域に分かれています。

左側には次があります:

| | |
|---|---|
| Prompt | モデルへの指示です。変数は3つあります: `{{backgroundLore}}`（本のロアブックとそのサブロアブックのエントリー）、`{{existingArcs}}`（アークと章。状態と説明を含みますが、非公開のメモは含みません）、`{{specification}}`。最初は *設定 → Extension Settings → Arc Outline* のプロンプトが入っています（変更していない場合はデフォルトのプロンプト）。ここで編集した内容は、この生成にのみ適用されます。 |
| Specification | アークに求めるもの。テーマ、登場人物、どこへ導くべきか。空欄でもかまいません。 |
| Tools | [モデル用のツール](tools.md)のスイート（名前、場所）がインストールされている場合にのみ表示されます。モデルが、何かを作り出す代わりに使ってもよいスイートとそのカテゴリを指定します。[ロア・ジェネレーター](lore-generator.md)と同じです。 |
| Model, Protocols | 最初は、本のモデルとプロトコルになっています（本に設定がない場合は、*設定* のデフォルトのものになります）。この生成にだけ別のモデルを使うには変更します。その選択は保存されません。 |
| 生成 | モデルを開始します。実行中は、ボタンが赤い **停止** になり、ダイアログの他の操作はすべて無効になります。 |

右側には、モデルが書いている途中の**推論**が表示されます。回答が始まると、提案された**アーク**も表示されます。これは名前、簡潔な説明、より長いメモからなり、アウトラインのアークのように（説明の下にメモが）表示され、回答が届くにつれて広がっていきます。説明はアウトラインに表示される部分なので、モデルには2文程度に抑えるよう求め、詳細はメモに書くよう指示しています。そのメモは、保存されたアークの**メモ**になります。モデルの生成が終わると、回答がチェックされます。有効なアークでない場合（たとえばメモがない場合）は、ダイアログにその旨が表示され、アークは保存できません。

![アークを生成中](../../images/plugin-arcoutline-generate-arc.png)

**Save as arc** を押すと、アークがアウトラインの末尾に追加されます。やり直す場合は、同じまたは変更したプロンプトや仕様で、もう一度 **生成** を押してください。前の回答は置き換えられます。
<a id="importing-an-arc-from-the-story"></a>

## ストーリーからアークを取り込む

ウォンドのメニューにある **Import from story** は、執筆済みの文章をモデルに読ませ、それを一つのアークと章として書き起こさせる機能です。すでに書いた本をアウトラインに取り込めます。モデルは常に、ダイアログを開いた時点の本の[アクティブなブランチ](../books/branches-and-story-tree.md)を読みます。ダイアログはアークのものと似ており、左側には次の項目があります。

| | |
|---|---|
| From message, To message | モデルに送るストーリーの範囲です。テキストのあるブランチのメッセージは1から番号が振られ、最初はブランチ全体が選ばれています。各欄の下には、そのメッセージの冒頭が表示されます。 |
| Number of chapters (optional) | 数を選ぶと、ちょうどその数の章になります(別の数の回答は拒否されます)。空欄にすると、モデルが話を自然に区切れるところで分けます。 |
| Link the chapters to the parts of the story | 最初からオンになっています。送った範囲の中でメッセージに1から番号が振られ、モデルは各章がどのメッセージから始まるかを示します。その章は、その部分のストーリーに[リンク](#linking-to-the-story)されます(番号はブランチ全体で数えたものなので、送る範囲に関係なく正しく対応します)。アークは最初の章が始まる部分にリンクされます。送られていないメッセージを指す回答の場合、その章はリンクされません。 |
| State of the imported arc and its chapters | 最初は **Finished** です。ストーリーはすでに書かれているためです。必要に応じて **Current** または **Planned** を選んでください。 |
| Token counter | 範囲にあるメッセージの数とそのおおよそのトークン数、そしてプロンプト全体(指示、ロア、アウトライン、ストーリー)のおおよそのトークン数が、モデルが受け取る量とともに表示されます。プロンプトが収まらなくなると警告に変わるので、その場合はメッセージの範囲を狭めてください。範囲、章の数、プロンプト、モデルに応じて値が変わります。 |
| Prompt | モデルへの指示です。変数として `{{backgroundLore}}`、`{{existingArcs}}`、`{{story}}`(範囲のメッセージ)、`{{numberOfChapters}}` が使えます。初期値は *Settings → Extension Settings → Arc Outline* の **Story import prompt** です。 |

![ストーリーからアークを取り込む](../../images/plugin-arcoutline-import.png)

ここではツールは使われません。名前はストーリーの中にあります。右側には推論が表示され、その後にモデルが書いたアークとその章が表示されます。**Save as arc** を押すと、アークとその章がアウトラインの末尾に追加されます。どの章も、モデルの推論と回答を保持しており、それぞれに専用のロボットボタンがあります。長いストーリーは、範囲ごとにアークを一つずつ、数回に分けて取り込むのがよいでしょう。
<a id="developing-the-plot-in-a-conversation"></a>

## プロットを会話で練る

杖のメニューにある **Develop the plot** は、プロットについてモデルと話すチャットを開きます。本の中身は話すだけでは変わりません。モデルは、あなたが送ると選んだものを見て、返答します。何かを決めたら、ワンクリックでアーク生成機にそれを渡せます。

左側では、モデルが何を見て、どのように手伝うかを選びます（選択内容は次回も記憶されます）。右側がチャットです。

![プロットウィザード：左がオプション、右が会話](../../images/plugin-arcoutline-wizard.png)

| | |
|---|---|
| Model, Protocols | 本のモデルとプロトコルから始まります。ここで変更すると、この会話にだけ適用されます。 |
| How the model helps | **Free talk**（あなたが主導）、**Explore directions**（物語が次に進みうるいくつかの異なる方向）、**Find the problems**（解決されていない筋、誰も守らない約束、設定との矛盾、ペース）、または **Expand an idea**（あなたのアイデアを、前提、転換点、結末、そしてアークの後に続く章にまで膨らませたもの）。 |
| Send the lorebook | 本のロアブックとそのサブロアブックのエントリー。 |
| Send the outline | **Not sent**、**Descriptions only**、または **With the notes**（あなたの非公開メモも含む）。 |
| Send the notes | [Story Notes](story-notes.md) がインストールされている場合のみ：**Not sent**、**Titles and first lines**（既定）、またはノートの **Full text**。アシスタントから隠したページは除きます。 |
| Send the summaries of the story | 生成時と同じように、要約は最新のものまでの物語を代わりに伝えます。 |
| Send the latest parts of the story | 最新の要約より後の部分（要約がオフのときは全部）のうち、**Tokens of the story** に収まる最新のもの。各部分は、物語のアウトラインでの番号とともにモデルに示されます。 |
| Tokens of the story | 物語の部分に使うトークンの上限。空欄の場合は、モデルが受け取る量の3分の1になります。 |
| Prompt | モデルへの指示。変数 `{{backgroundLore}}`、`{{outline}}`、`{{notes}}`、`{{summaries}}`、`{{story}}`、`{{mode}}` を使えます。変更は記憶されます。 |

オプションの下には、モデルが受け取る要約と物語の部分の数、そしてリクエストがモデルの受け取る分のうち何トークン使うかを示す行があります。収まらないときは警告に変わります。その場合は送る量を減らすか、[チャットを要約](#chats-branches-and-summaries)してください。本は各メッセージごとに読み直されるため、アウトラインや物語の変更は次の返答から反映されます。

右側がチャットです。メッセージを入力して **Send** を押してください（モデルが書いている間は **Stop** になります。それまでに届いた分は残ります）。各メッセージにはボタンがあります。コピー、**branch from here**、削除、そしてモデルの返答には杖のボタン **Generate an arc from this message** もあり、そのメッセージを仕様としてアーク生成機を開きます。議論が長かった場合は、まず決めたことを仕様としてまとめるようモデルに頼んでください。

<a id="letting-the-model-change-the-book"></a>

### モデルに本を変えさせる

オプションの下には **What the model may do** があります。これらのどれもチェックしないと、チャットはただの会話です。グループにチェックを入れると、モデルはそのためのツールを受け取り、あなたが頼んだり同意したりしたときに使えます。モデルは追加する前に確認し、置き換えるより追加を優先し、何をしたかを伝えるよう指示されています。

| グループ | モデルができること |
|---|---|
| **Planner** | [プランナー](../books/story-editor.md#the-planner-tab)のシーンを一覧し、追加、変更、移動、削除、完了の印付けをします。 |
| **Lorebook** | 設定を検索・読み取り、エントリーを作成し、既存のものを変更します（削除はしません）。 |
| **Outline** | アウトラインを読み、アークや章を追加、変更、移動します（削除はしません）。 |
| **Notes**（[Story Notes](story-notes.md) がインストールされている場合） | あなたのノートを検索・読み取り、そのリンクをたどります。何かを残すよう頼まれたらページを追加または既存のページに追記し、ページ内の文章を変更します（ページの削除はしません）。アシスタントから隠したページには届きません。 |
| **Generators** | アークと章の生成機を呼び出し、[Lore Generator](lore-generator.md) がインストールされている場合は設定エントリーを生成します。これらは下書きを返すだけで、モデルに指示されない限り何も保存しません。モデルは下書きをあなたに見せ、同意があれば保存します。 |
| **Tools**（ボタン。[ツールスイート](tools.md) がインストールされている場合） | 名前のツール（人名、地名）を使えます。生成機と同様に、実在する名前を提案できます。 |

- **Ask me before it changes or deletes something**（既定でオン）：既存のもの（ロアエントリー、シーン、アークなど）の本文を変更することと、削除することは、モデルが渡そうとしている内容とともに先にあなたに示され、モデルは **Allow** または **Refuse** を待ちます。シーン、エントリー、アークの追加は確認されません。チャットとプランナー、ロアブック、アウトラインで見ることができ、削除もできます。
- モデルが呼び出したツールはすべて、その返答の下に一覧されます（名前と印：✓ 成功、✗ 失敗の行です。開くと、何が渡され、何が返ってきたかが見られます）。次のメッセージには、モデルが行った呼び出しとその返り値が含まれる（長い結果は切り詰められます）ため、モデルは自分が既に何をしたかを把握し、同じエントリーを二度作りません。これらはチャットのトークン上限に含まれます。
- ツールのコスト：ツールの説明は毎回のリクエストに含まれるため、コンテキストが少ないモデルでは余裕が減ります。関数呼び出しに対応しているモデルだけがこの機能で動作し、対応していない場合はダイアログがそう伝えます。

![モデルがプランナーに2つのシーンを追加した。呼び出しは返答の下に一覧されている](../../images/plugin-arcoutline-wizard-tools.png)

<a id="chats-branches-and-summaries"></a>

### チャット、ブランチ、要約

1冊の本にはいくつでもチャットを持てます。メッセージの上の一覧から選び、**+** で新しいチャットを始め、ペンで名前を変え（それまでは最初のメッセージにちなんで名付けられます）、ゴミ箱で削除します。チャットは本と一緒に保存されます。

- **Branch** はチャットをそのまま新しいチャットにコピーします。メッセージのブランチボタンは、そのメッセージまでを含めてコピーし、そこから別の進め方で話を続けられるようにします。コピー後は元のチャットとは無関係になります。
- **Summarize the chat** は、まず要約で何を残すか、または何を強調するかを尋ねます（任意。例：「裏切り者についてのひねりと、却下した結末を残す」。空欄の場合はモデルが決めます）。次に、チャットの要約をモデルに依頼します（決めたこと、却下したこと、まだ未解決のこと、確定した名前）。その要約をメッセージとして追加します。以後、モデルが受け取るのは、その要約とそれ以降のメッセージだけで、**それより前のメッセージは含まれません**。それらは画面に残りますが、薄く表示されます。チャットが長くなりすぎてモデルに収まらないとき、または決定事項を失わずに整った状態から再開したいときに使ってください。後からもう一度要約すると、新しい要約が古いものを包含します。チャット全体をモデルに残したい場合は、先にブランチを作ってください。

![要約で何を残すかを尋ねる質問](../../images/plugin-arcoutline-wizard-summarize.png)

![要約後のチャット：それより前のメッセージは画面に薄く残る](../../images/plugin-arcoutline-wizard-summary.png)
<a id="generating-chapters"></a>

## チャプターの生成

アークにある杖のボタンは、そのアークを章に分けるようモデルに依頼します。ダイアログはアークのものと似ていて、左側に次の選択肢があります。

| | |
|---|---|
| モデルが把握している物語 | **これまでの全体**: このアークまでのアークを、その章すべてを含めて渡します。**アークの要約のみ**: 同じアークを章なしで渡します。**アークの要約と完成した章**: 同じアークを、*完成*とマークした章のみを含めて渡します。このアークより後のアークは決して送られません。 |
| 章全体に求めるもの | ペース、トーン、必ず起こるべきこと。空欄でも構いません。 |
| 章の数 | 「約八つ」のように言葉で書くか、正確な数を選びます。数を指定すると、各章について内容を書ける入力欄が章ごとに追加されます。どれも任意です。どちらか一方を使うと、もう一方はクリアされます。正確な数を指定した場合、章数が異なる回答は拒否されます。 |
| プロンプト | モデルへの指示です。変数 `{{backgroundLore}}`、`{{outline}}`、`{{numberOfChapters}}`、`{{generalSpecification}}`、`{{chapterSpecification}}` を使えます。初期値は *設定 → 拡張設定 → Arc Outline* の **Chapter generation prompt** です。 |

右側には推論が表示され、続いてそのアークが既に持っている章と、モデルが書いていく新しい章が表示されます。**Save as chapters** を押すと、新しい章がアークの末尾に追加されます。各章には短い説明が付き、詳細はそのノートに入ります(アークと同様)。新しく生成された章はすべて、モデルの推論と回答を保持し、それぞれ独自のロボットボタンを持ちます。

![アークの章を生成している様子](../../images/plugin-arcoutline-generate-chapters.png)

モデルが書いたアークや章は、その元になった**推論**と**回答**を保持します。そのロボットボタンを押すと、それらが小さなポップオーバーで開き、邪魔にならない場所に表示されます。

![モデルが書いたアークの内容](../../images/plugin-arcoutline-generated.png)

<a id="commands"></a>

## コマンド

アウトラインとその生成機能は、コマンドラインや[エージェント](../commands/index.md)向けの[コマンド](../agents.md)としても使えます。これらは開いている本(エージェントの場合はその作業用コピー)に対して動作し、開いているArcsタブには変更がすぐに表示されます。アークと章は、アウトラインに表示される**番号**で指定します。最初のアークは `1`、アークの最初の章も `1` です(前にあるものが追加、削除、移動されると番号は変わります)。アークや章を変更するコマンドは、与えられたフィールドだけを取ります。空の文字列を渡すと、説明やノートはクリアされます。

| コマンド | 働き |
|---|---|
| `/get-arc-outline [arc [notes]]` | アークを、その章、状態、説明とともにJSONで返します。非公開のノートは `notes` が `true` の場合のみ含まれます。`arc` を指定すると、そのアークだけを返します。読み取りのみです。 |
| `/add-arc title [description [note [state [position]]]]` | アークを末尾、または `position` の位置に追加します。 |
| `/update-arc arc [title [description [note [state]]]]` | アークを変更します。`state` は `PLANNED`、`CURRENT`、`FINISHED` のいずれかです(アークを完成にすると、その章も完成になります)。 |
| `/move-arc arc position` | アークを `position` の位置に移動します(1が最初)。 |
| `/delete-arc arc` | 確認の後、アークをその章ごと削除します。 |
| `/add-outline-chapter arc title [description [note [state [position]]]]` | アークに章を追加します。 |
| `/update-outline-chapter arc chapter [title [description [note [state]]]]` | 章を変更します。 |
| `/move-outline-chapter arc chapter position [to_arc]` | 章をそのアーク内で移動するか、アーク `to_arc` へ移動します。 |
| `/delete-outline-chapter arc chapter` | 確認の後、章を削除します。 |
| `/generate-arc [specification [save]]` | *Generate an arc* と同様に、新しいアークをモデルに依頼します。 |
| `/generate-outline-chapters arc [specification [count [context [save]]]]` | アークの杖ボタンと同様に、そのアークの章をモデルに依頼します。`count` は正確な章数、`context` は `EVERYTHING`(既定)、`ARCS_ONLY`、`ARCS_AND_FINISHED` のいずれかで、*モデルが把握している物語* の選択肢に対応します。 |
| `/import-arc-from-story [from [to [count [state [save [mapParts]]]]]]` | 有効なブランチのメッセージ `from` から `to` までを、章付きのアークとして要約するようモデルに依頼します(*Import from story* と同様に、本文のあるメッセージの中で番号付けされます)。`state`(既定は `FINISHED`)は、保存されるアークとその章の状態です。`mapParts` が `true` の場合、各章は開始するメッセージにリンクされ(ダイアログのチェックボックス *Map parts* と同様に、その *Linked part*)、回答には各章の部分が含まれます。 |

3つの生成コマンドは、ダイアログと同じプロンプト(*Extension Settings → Arc Outline* の設定、または既定値)、本のモデルとプロトコル(本にモデルがない場合は既定のモデル)を使い、ツールは使いません。名前が必要な呼び出し元は、[Name generator](name-generator.md) または [Name provider](name-provider.md) のコマンドで名前を取得し、それを指定文に書き込んでください。ダイアログと同様に、保存は要求された場合のみ行われます。`save` が `false`(既定)の場合は、アークまたは章をJSONで返すだけで何も保存しません。`save` が `true` の場合は、それらをアウトラインに追加し(アークは末尾に、章はアークの末尾に)、回答にはその番号が含まれます。長すぎる物語は `/import-arc-from-story` で拒否されるので、メッセージの数を減らしてください。生成コマンドには時間がかかり、実行が停止されると止まります。

追加や変更は破壊的ではありません。破壊的なのは2つの `delete` コマンドだけで、エージェントはこれらについて確認を求めるよう設定されている場合があります。
