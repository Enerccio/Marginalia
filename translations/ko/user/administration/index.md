# 관리자

관리자는 Marginalia 설치본을 관리합니다. 사용자 계정, 데이터베이스 백업, 삭제된 데이터 정리, 업데이트, 확장 기능을 다룹니다. [첫 실행](../getting-started/first-start.md) 때 만든 첫 계정은 관리자이며, 이 계정은 다른 사용자를 관리자로 지정할 수도 있습니다.

관리자도 자신의 책을 가진 일반 사용자입니다. 다른 사용자의 책, 로어북, 설정은 볼 수 없고, 그 사용자들이 모든 사람과 공유한 로어북과 프로토콜만 볼 수 있습니다.

<a id="the-admin-page"></a>

## 관리 페이지

관리자에게는 작업 공간 아래쪽에 **관리** 버튼이 있습니다. [휴대폰 레이아웃](../phone.md#administration)(창 너비가 768픽셀보다 좁은 경우)에서는 서랍의 **관리** 탭이 이 버튼을 대신합니다. 버튼을 누르면 다음 탭이 있는 관리 페이지가 열립니다.

| 탭 | |
|---|---|
| **사용자** | 계정 만들기, 편집, 삭제와 사용자에게 [권한](permissions.md) 부여. 자세한 내용은 [사용자](users.md)를 참고하세요. |
| **데이터베이스 백업** | 데이터베이스 전체의 백업을 즉시 또는 일정에 따라 만들고 복원합니다. 자세한 내용은 [데이터베이스 백업](database-backups.md)을 참고하세요. |
| **정리** | 삭제된 데이터를 영구적으로 제거합니다. 자세한 내용은 [정리](cleanup.md)를 참고하세요. |
| **리소스 파일** | 더 이상 아무것도 사용하지 않는 리소스의 파일을 찾고, ZIP으로 내려받거나 디스크에서 삭제합니다. 자세한 내용은 [리소스 파일](resource-files.md)을 참고하세요. |
| **도움말 어시스턴트** | 매뉴얼의 내용에 답하는 채팅입니다. 모델, 프롬프트, 비용 부담자를 설정합니다. 자세한 내용은 [도움말 어시스턴트](help-assistant.md)를 참고하세요. |
| **에이전트** | 에이전트나 사용자가 자체 프롬프트를 갖고 있지 않을 때 따르는 시스템 프롬프트와 압축 프롬프트입니다. 비워 두면 내장 프롬프트가 쓰입니다. 정보 아이콘의 **기본 템플릿 삽입**을 누르면 프롬프트가 채워지므로 복사본을 편집할 수 있습니다. 사용자가 에이전트로 할 수 있는 일은 [권한](permissions.md)에서 정합니다. 또한 **에이전트가 사용자의 웹훅으로 메시지를 보낼 수 있음** 옵션이 있습니다. 이 옵션이 켜져 있으면 에이전트가 사용자의 도움이 필요할 때, 사용자가 애플리케이션을 닫고 자리를 비운 상태라도 서버가 사용자가 설정에 입력한 주소를 호출합니다([사용자가 없을 때](../agents.md#when-you-are-not-there)). 이것이 받아들여지지 않는 환경이라면 끄세요. |
| **통계** | [글쓰기 통계](../books/statistics.md)를 기록할지 여부, 보관 기간, 사용자 한 명 또는 모든 사용자의 통계 삭제를 설정합니다. 자세한 내용은 [통계](statistics.md)를 참고하세요. |
| **작업** | 외부 AI에 요청한 모든 작업의 기록(누가, 언제, 어떤 호출이었고, 어떻게 끝났는지)입니다. 오래된 항목을 직접 삭제하는 필터와, 지금 실행 중인 작업을 보여 주는 `/jobs` 페이지가 있습니다. 자세한 내용은 [작업](jobs.md)을 참고하세요. |
| **GPU** | 언어 모델과 이미지 및 음성 서버가 하나의 그래픽 카드를 함께 씁니다. GPU 목록, GPU 잠금(각 모델을 어떻게 불러오고 카드에서 어떻게 내리는지), 각 GPU가 실행하는 단계, 각 GPU가 지금 점유한 내용과 **지금 해제**를 보여 줍니다. 자세한 내용은 [GPU](gpus.md)를 참고하세요. |
| **업데이트** | Docker 서버에서 실행 중인 버전, 서버가 따라가는 브랜치의 최신 버전, Marginalia를 업데이트하고 재시작하는 버튼을 보여 줍니다. 자세한 내용은 [업데이트](updates.md)를 참고하세요. |
| **확장 기능** | 확장 기능을 설치하고 제거합니다. 자세한 내용은 [확장 기능 관리](extensions.md)를 참고하세요. |

## 데이터 폴더

Marginalia가 저장하는 모든 것은 이를 실행하는 사용자의 홈 디렉터리에 있는 `.marginalia` 폴더에 있습니다([Docker 설정](../getting-started/docker-server.md)을 사용하는 경우 호스트에서는 `./data`):

| 경로 | |
|---|---|
| `marginalia.sqlite` (`-wal`, `-shm` 포함) | 데이터베이스입니다. 사용자, 책, 로어북, 설정 등 모든 것이 들어 있습니다. |
| `secret.key` | 데이터베이스에 저장된 API 키를 암호화하는 키입니다. 첫 실행 때 만들어지며, 소유자만 읽을 수 있습니다(Linux와 macOS 기준). 이 키가 없으면 저장된 API 키를 읽을 수 없습니다. 컴퓨터의 다른 사용자가 이 키를 읽을 수 있으면 로그에 그 사실이 표시됩니다: `chmod 600 secret.key`. |
| `db-backups/` | [데이터베이스 백업](database-backups.md)입니다. |
| `data/<login>/backups/manuscripts/<book id>/` | 사용자별 [책 백업](../books/backups.md)입니다. |
| `extensions/` | 설치된 [확장 기능](extensions.md)의 JAR 파일입니다. |
| `update/` | Marginalia와 Docker 서버의 [업데이트 감시기](updates.md#setting-up-the-watcher)가 주고받는 파일입니다. 상태, 마지막 업데이트 로그, 요청이 여기에 있습니다. |
| `agent-workspaces/<agent id>/` | [에이전트](../agents.md#the-working-copy)의 파일입니다(실행 사이에 보관하는 메모와 보고서). |
| `agent-runs/<run id>/` | 에이전트 실행이 보관하는 내용입니다. 변경 사항을 보여 주기 위한 책의 시작 상태(작업 복사본과 함께 삭제됨), 체크포인트, 발견 사항이 있습니다. 실행 기록이 정리로 제거되면 발견 사항도 삭제됩니다. |
| `desktop/logs/` | [데스크톱 앱](../getting-started/desktop-app.md)의 로그입니다. |

설치본 전체를 백업하려면 Marginalia를 중지하고 이 폴더를 복사하세요(`secret.key` 포함). 실행 중에는 데이터베이스를 [데이터베이스 백업](database-backups.md)으로 백업하세요. 책 백업과 확장 기능은 일반 파일이므로 언제든지 복사할 수 있습니다.
