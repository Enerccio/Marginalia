# 故事笔记

侧边栏中的一个小型知识库，用来记录你的书：你正在规划的情节、暂时还不打算用的点子、魔法体系的规则、反派真正想要什么。这些都是你自己的思考，用你自己的话写成，页面之间可以加标签和互相链接。与 [作者注记](authors-note.md) 不同，作者注记是随每次生成一起发送的一段文字，而笔记本身不会单独发送给模型。[情节向导](arc-outline.md#developing-the-plot-in-a-conversation) 和智能体可以读取这些笔记，如果你允许，也可以修改它们。

<a id="the-notes-tab"></a>

## 笔记标签页

[故事编辑器](../books/story-editor.md) 的左侧边栏在 *大纲* 旁边有一个 **笔记** 标签页。它按标题排序列出本书的所有页面。列表上方有 **添加**（新建页面）、按 **标签** 筛选（页面有标签后才会显示），以及一个搜索框，可以搜索标题、标签和页面正文。

每个页面会显示其标题、正文的第一行和标签。点击页面或铅笔图标即可打开；点击垃圾桶图标会在确认后删除该页面。标题旁可能出现两个小标记：一只划掉的眼睛（该页面 [对助手隐藏](#what-assistants-can-see)），以及一根魔杖（最近一次修改来自命令，而不是你本人）。

![笔记标签页：一个对助手隐藏的页面（眼睛）和一个情节向导添加过内容的页面（魔杖）](../../images/plugin-storynotes-tab.png)

<a id="a-page"></a>

## 一个页面

页面的对话框包含以下内容：

| | |
|---|---|
| **标题** | 必填，在本书中唯一（不区分大小写），不能包含方括号或竖线（`|`）。其他页面通过它来链接到这里。 |
| **标签** | 用逗号分隔。用于筛选列表。 |
| **正文** | Markdown 格式。**编辑** 和 **预览** 用于切换文本和显示效果。正文中的 `[[Title]]` 链接到标题为该内容的页面；`[[Title|other words]]` 同样链接到该页面，但在预览中显示 *其他文字*（`[[Language barrier|how they talk]]`）。 |
| **对助手可见** | 默认开启。见下文。 |

正文下方，对话框会列出该页面 **链接到的** 页面：链接到已存在页面的，点击即可打开；链接到不存在页面的，会提供 **创建** 选项，并以该标题新建一个页面。再下面是 **链接到此处的** 页面。重命名页面时，其他页面中指向它的 `[[links]]` 会随之更新（链接显示的文字保持不变）。

![一个页面，显示它链接到的页面以及链接到它的页面](../../images/plugin-storynotes-page.png)

**预览** 会以 Markdown 形式显示正文，每个 `[[link]]` 都呈现为链接：点击即可打开该页面（链接到不存在的页面则会以该标题新建页面）：

![同一页面的预览](../../images/plugin-storynotes-preview.png)

不点击 **保存** 则不会保存任何内容；关闭已修改的页面时，会先询问是否放弃修改。如果你在编辑页面时，该页面被命令修改了，系统会在你的版本覆盖它之前询问你。**Ctrl/Cmd+Enter** 可保存。页面与本书一起存储，因此会包含在它的备份和副本中。

<a id="what-assistants-can-see"></a>

## 助手能看到什么

"助手"指的是笔记所提供的命令，智能体、宏和情节向导都会使用它们。关闭了 **对助手可见** 的页面对它们而言并不存在：不会被列出、搜索到、读取或修改，而且当它们尝试创建一个只有该隐藏页面才有的标题时，会被拒绝。对只想让自己看到的内容，请关闭此项。你关闭的页面仍然保存在备份中。

命令如下（用于命令栏和智能体；标题即页面的地址）：

| 命令 | 说明 |
|---|---|
| `/list-notes [<tag>]`、`/get-note <note>`、`/search-notes <query>` | 列出页面；读取一个页面的正文、链接以及链接到它的页面；搜索。 |
| `/create-note <title> [<content> [<tags>]]` | 添加页面。 |
| `/append-to-note <note> <text>` | 在页面末尾添加一段。 |
| `/update-note <note> [<title> [<content> [<tags>]]]`、`/edit-note <note> <find> <replace> [<all>]` | 修改页面，或替换其中的一段文字：`find` 必须与页面中的原文完全一致（区分大小写），并且除非 `all` 为 `true`，否则只能出现一次；使用 `all` 时，每一处匹配都会被替换，适用于在整个页面中统一替换某个人名或术语。返回结果会说明替换了多少处。这些命令会改动已有文字，因此属于 *破坏性* 操作：设置为询问的智能体会先征求你的同意。 |
| `/delete-note <note>` | 删除页面，需经确认。 |
| `/note-text <note>` | 获取页面的正文，供宏使用：{%{`{{command::note-text::Magic}}`}%} 会把它插入模板。对于不存在或已隐藏的页面，结果为空。 |

被命令修改过的页面会带有魔杖标记，直到你自己保存它为止。

<a id="with-the-plot-wizard"></a>

## 与情节向导一起使用

安装此扩展后，情节弧大纲中的 [情节向导](arc-outline.md#developing-the-plot-in-a-conversation) 会提供 **发送笔记** 选项（可选发送标题及其首行、完整正文，或不发送），以及一组 **笔记** 工具：模型可以搜索和读取页面、顺着链接查看，当你要求它记录某些内容时可以新建页面或向已有页面添加内容，也可以修改页面中的文字。当 *修改或删除内容前询问我* 开启时，修改页面正文需要先征得你的同意；向导无法删除页面。选项与工具组的说明见向导的表格。

![带有笔记工具的情节向导：它读取了一个页面，并在其中添加了一个待解决的问题](../../images/plugin-storynotes-wizard.png)

<a id="other-extensions"></a>

## 其他扩展

此扩展为其他扩展提供两种文本来源（[侧边查询](side-query.md) 可通过其插入按钮附加它们）：**故事笔记（标题）** 和 **故事笔记（全部）**。两者都会排除隐藏的页面。
