# 分岐とストーリーツリー

Marginalia では、試したバージョンを捨てる必要はありません。試したすべての代替案は、ストーリーの**分岐**として保存され、そのどれにでも戻ることができます。

<a id="how-the-story-tree-works"></a>

## ストーリーツリーの仕組み

各パートは、その前のパートの続きとして書かれます。あるパートに続きが複数ある場合、ストーリーは分かれます。最初のパートから終わりまでの各経路が、それぞれ一つの分岐です。

```
#1 ─ #2 ─ #3 ─ #4 ─ #5          ← 分岐 A
           └─ #4' ─ #5' ─ #6'   ← 分岐 B（アクティブ）
```

**アクティブな分岐**は、[ストーリーエディター](story-editor.md)が表示し、続きを書く対象になる分岐です。モデルに送られるのはこの分岐のパートだけで、ほかの分岐はストーリーに影響しません。

新しい分岐を作る方法は三つあります。

| | 何が起きるか | 元のバージョン |
|---|---|---|
| **スワイプ**（最後のパート） | モデルが最後のパートの別バージョンを書きます。 | 別の分岐として残ります。 |
| **ストーリーを分岐**（任意のパート） | このパートから新しい分岐でストーリーが続きます。 | このあとのパートは元の分岐に残ります。 |
| **再生成**（最後のパート） | モデルが最後のパートを同じ場所に書き直します。 | 置き換えられ、分岐は作られません。 |

**スワイプ**と**再生成**は最後のパートのメニューにのみあり、**ストーリーを分岐**はすべてのパートのメニューにあります。

<a id="trying-another-version-of-the-last-part"></a>

## 最後のパートの別バージョンを試す

最後のパートが気に入らないときは、そのメニューから**スワイプ**を選びます。モデルは同じ[ターンの詳細](story-editor.md#turn-details)からパートを書き直し、新しいバージョンがアクティブな分岐の末尾になります。以前のバージョンは独自の分岐として残り、[ブランチ表示](#the-branch-view)から切り替えて戻ることができます。

もう一度試す前に、次に起きるべきことを変えたいときは、最後のパートの**ターンの詳細**を開き、指示を編集します。

古いバージョンが必要ない場合にだけ**再生成**を使います。これはパートを上書きします。

<a id="branching-from-an-earlier-part"></a>

## 以前のパートから分岐する

以前の時点からストーリーを別の方向へ進めたいときは、そのパートのメニューを開き、**ストーリーを分岐**を選びます。Marginalia はそのパートを新しい分岐にコピーし、アクティブな分岐の末尾にします。そのため、ストーリーエディターは今やそのパートで終わります。いつもどおり **+** で続きを書けます。

そのあとのパートは失われません。元の分岐に残ります。

そのパートの[要約](summaries.md)も、いっしょにコピーされます。

<a id="the-branch-view"></a>

## ブランチ表示

**ブランチ表示**タブには、ストーリーツリー全体が表示されます。各パートはカードになっており、日付、シーンの設定、登場人物、指示が書かれています。カードにカーソルを合わせると、すべての詳細を見られます。

![ストーリーツリー](../../images/story-tree.png)

- **アクティブな分岐**のパートは強調表示され、その末尾のパートには印が付きます。
- **ほかの分岐の末尾のパートをクリック**すると、その分岐がアクティブになります。本は*ストーリー*タブに切り替わり、その分岐を表示します。クリックできるのは分岐の末尾だけです。途中のパートから続けるには、[ストーリーを分岐](#branching-from-an-earlier-part)を使います。
- 分岐が生じない長い区間（20 パートを超えるもの）は、最初の 10 パートと最後の 10 パートを示す一つのブロックにまとめられます。ブロックをクリックすると、すべてのパートを表示します。

<a id="searching-all-branches"></a>

### すべての分岐を検索する

ツリーの上にある入力欄では、アクティブな分岐だけでなく、本のすべての分岐の本文を検索できます。探したい語を入力し、**Enter** を押すか**検索**をクリックします。入力欄は直前の検索語を覚えており、一覧から選べば同じ検索を繰り返せます。入力欄の **x** をクリックすると検索が消去されます。

- パートは、入力したすべての語を（順序を問わず）本文に含むときに一致します。たとえば `lighthouse key` は、両方の語を含むパートを見つけます。句を探すには二重引用符で囲みます：`"lighthouse key"`。
- 任意の文字列には `*` を使います。`light*` は *lighthouse* や *lightning* を見つけます。`%`、`_`、`\` を含むほかの文字は、入力どおりに検索されます。
- 大文字と小文字は区別されません。アクセント付きの文字についても、小文字で入力した語は、大文字（UPPER CASE）や先頭だけ大文字（Capitalized）の同じ語も見つけます（`žluťoučký` は *Žluťoučký* や *ŽLUŤOUČKÝ* を見つけます）。
- 検索対象はパートの本文だけです。指示、シーンの設定、ロアブックは検索されません。削除したパートも検索されません。

![検索を使ったブランチ表示](../../images/story-tree-search.png)

入力欄の隣にあるチェックボックス**バージョンを含める**をオンにすると、パートの以前の[テキストのバージョン](version-history.md#searching-the-old-text)も検索されます。古いバージョンにだけ語が含まれるパートも強調表示され、どのバージョンかが示され、**ストーリーで表示**の隣に**履歴で表示**が現れます。

一致したパートはすべて、オレンジ色で**強調表示**され、一致箇所の前後の文章が表示されます。ツリーの上の行には、見つかったパートの数が示されます。折りたたまれるはずの長い区間に一致が含まれる場合は、その区間が開かれます。検索は、消去するか本のウィンドウを閉じるまで続き、タブに戻ったときに強調表示も更新されます。

強調表示されたパートの**ストーリーで表示**をクリックすると、そのパートを読めます。

- パートがアクティブな分岐にある場合、本は*ストーリー*タブに切り替わり、そのパートまでスクロールします。
- 別の分岐にある場合は、まずその分岐がアクティブになります。その分岐は、見つかったパートより後にある、最も近い分岐の末尾で終わります（二つあれば新しいほう）。そのため、ストーリーエディターは見つかったパートと、そのあとに続く内容までを表示します。その後、本は*ストーリー*タブに切り替わり、そのパートまでスクロールします。パートは短く点滅します。

分岐を切り替えることは、ツリーで分岐の末尾をクリックするのと同じです。何も失われず、以前の分岐はそのまま残り、ツリーからいつでも戻れます。

<a id="deleting-parts-and-branches"></a>

## パートと分岐の削除

パートのメニューの**削除**は、そのパートだけを削除します。そのあとのパートは一つ前に繰り上がり、その前のパートから続きます。分岐をまるごと削除するには、末尾からパートを削除します。

*About*（概要）タブの単語数とトークン数には、本全体（すべての分岐）とアクティブな分岐の両方の数が表示されます。
