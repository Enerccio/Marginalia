# ロアブックの作成

<a id="the-lorebook-editor"></a>

## ロアブックエディター

**Lorebooks** タブを開きます。エディターには一度に一つのロアブックが表示されます。上部の **Lorebook** フィールドで選択してください。
ロアブックはあなたのアカウントに属します。他のユーザーには見えませんが、[共有](#sharing-a-lorebook)した場合は別です。

ツールバーは二段あります。ウィンドウが狭いと行が折り返されます。一段目はロアブック用（**Lorebook** から **Tag lorebooks** まで）、二段目は選択中のロアブックのエントリ用（**Add Entry** から **Refresh** まで）です。

| ボタン | |
|---|---|
| **Lorebook** | 編集するロアブックを選択します。 |
| **Only root lorebooks** | 他のロアブックのサブロアブックではないロアブックだけを一覧表示します（選択中のロアブックは一覧に残ります）。 |
| **Add Lorebook** | *New Lorebook* という名前の新しいロアブックを作成し、選択します。 |
| Clone（二枚の紙のアイコン） | 選択中のロアブックのコピーを作成します。名前を尋ねられ（初期値は元の名前に *(Copy)* を付けたもの）、コピーが選択されます。コピーには、同じエントリ（その設定、タグ、除外タグを含む）、タグ、説明、拡張機能のデータがあります。サブロアブックはコピーされず、コピーは同じサブロアブックを使います。元のロアブックは変更されません。 |
| **Delete Lorebook** | 選択中のロアブックを削除します（確認後）。 |
| Import（ファイルのアイコン） | **Import Marginalia Lorebook**、**Import from SillyTavern**、**Import from archive**（`.md` ファイルの zip）、**Import from other user**（別のユーザーが[共有](#sharing-a-lorebook)したロアブック）があります。[インポートとエクスポート](import-export.md)を参照してください。 |
| Export（ファイルのアイコン） | サブロアブックを含むロアブックをダウンロードします。[インポートとエクスポート](import-export.md#exporting)を参照してください。 |
| Tags（タグのアイコン） | **Tag lorebooks**：多数のロアブックに一度にタグを付けます。[下記](#tagging-many-at-once)を参照してください。ブックで開いているロアブックには表示されません。 |
| Description（行のアイコン、一段目の最後） | **Edit description**：ロアブックの内容を書くウィンドウを開きます。[下記](#description)を参照してください。 |
| **Add Entry** | ロアブックにエントリを追加します。[エントリと有効化](entries.md)を参照してください。 |
| **Full-screen editor** | ロアブックのエントリを、タブ付きの全画面ウィンドウで開きます。[全画面での編集](#editing-in-full-screen)を参照してください。デスクトップのみ。 |
| **Search and replace** | ロアブックのエントリの名前、テキスト、コメントにあるテキストを置換します。[検索と置換](entries.md#search-and-replace)を参照してください。 |
| **Mass edit** | ロアブックとそのサブロアブックのすべてのエントリを、一つの表で開きます。[一括編集](#mass-edit)を参照してください。 |
| Tags（タグのアイコン、**Search and replace** の右、二段目） | **Tag entries**：選択中のロアブックの多数のエントリに一度にタグを付けます。[下記](#tagging-many-at-once)を参照してください。 |
| **Preview activation** | 入力したテキストでターンを行った場合に、どのエントリが使われ、その理由が何かを表示します。[有効化のプレビュー](entries.md#preview-activation)を参照してください。 |
| **Refresh** | エントリを再読み込みします。 |
| 検索ボックス | テキストを含むエントリだけを表示します。[多数のエントリの検索と削除](entries.md#searching-and-deleting-many-entries)を参照してください。 |
| **Delete selected** | 一覧でエントリが選択されているときに表示されます。確認後に削除します。 |

ツールバーの下には、選択中のロアブックの設定があります。

| 項目 | |
|---|---|
| **Name** | ロアブックの名前。ブックやサブロアブックとして選択するときに表示されます。 |
| **Sub Lorebooks** | このロアブックに含める他のロアブックのエントリです。[下記](#sub-lorebooks)を参照してください。選択したサブロアブックの名前をクリックすると開きます。 |
| **Tags** | ロアブック全体のタグです。各エントリのタグとして扱われます。[タグ](entries.md#tags)を参照してください。 |
| **Scan depth** | `0` から `5`：使われたエントリの内容が、他のエントリのフィルターのために何回検索されるかを示します。[他のエントリによって取り込まれるエントリ](entries.md#entries-brought-in-by-other-entries)を参照してください。ブックが使うロアブックのエントリと、そのサブロアブックのエントリに適用されます。ただし、サブロアブックが独自の深度を持つ場合（次の行）は除きます。 |
| **Scan depth as a sub lorebook** | 空欄、または `0` から `5`：ブックが使うロアブックのサブロアブックであるときの、このロアブックのエントリのスキャン深度です。空欄の場合は、そのロアブックのスキャン深度を意味します。`0` は、このロアブックのエントリが他のエントリの内容によって決して見つからないことを意味します。 |
| **Enabled** | オフにすると、ロアブックは何も寄与しません（エントリもサブロアブックのエントリも）。 |
| **Share with other users** | オンにすると、他のユーザーはロアブックを閲覧し、コピーをインポートできます。[下記](#sharing-a-lorebook)を参照してください。新しいロアブックではオフです。 |

設定の下には、ロアブックの[説明](#description)があります（説明がある場合）。

エディターの残りの部分は、[エントリ](entries.md)の一覧です。すべての変更は、行うと同時に保存されます。

<a id="description"></a>

### 説明

説明は、ロアブックについての数語（または数行）です。どの世界のものか、何のためのものか、どのブックが使うか、などを書きます。ツールバーの一段目にある行のアイコンをクリックし、ウィンドウに書いて確定してください。空のテキストにすると説明は削除されます。説明があるロアブックは、設定の下に一行で表示されます。収まらない部分は省略記号で切られます。全体を読むには、マウスポインターをその行に合わせてください。説明はロアブックと一緒にコピーされ（クローン、エクスポート、インポート、バックアップ）、共有したときには、他のユーザーが名前の横で見るテキストになります。

![ロアブックの説明のウィンドウ](../../images/lorebook-description.png)

<a id="sharing-a-lorebook"></a>

### ロアブックの共有

**Share with other users** をオンにすると、このインストールのほかのすべてのユーザーには、**Import from other user**（ツールバーの一段目にあるインポートボタン）の中にこのロアブックが表示されます。名前、作成者（フルネーム、なければログイン名）、説明も表示されます。ユーザーは行を開いてエントリ（およびサブロアブックのエントリ）を読み、コピーをインポートできます。オフにすると、ロアブックはその一覧から消えます。既に作成されたコピーは、そのユーザーのものとして残ります。

* 共有は閲覧のみです。他の人があなたのロアブックを変更、削除、またはブックで使用することはできません。ロアブックはあなたのものとして残り、これまでどおり表示されます。
* インポートすると、**他のユーザーの新しいロアブック**が作成されます。ロアブックと、その**共有された**サブロアブックが（どれほど深くても）、エントリ、タグ、説明とともに、あなたのものと同じようにリンクされた状態でコピーされます。コピーは非公開（共有されていない）です。その後あなたがロアブックに何をしても、コピーには影響しません。また、コピー側で変更したことも、あなたのロアブックには反映されません。
* **それ自体が共有されているサブロアブックだけが表示され、コピーされます。** 共有されていないサブロアブックは、その下にあるすべてのもの（その下にある共有されたロアブックも含む）と一緒に除外されます。共有されていないサブロアブックを持つロアブックで **Share with other users** をオンにすると、それらも共有するかどうかの質問が表示されます。**Yes** はロアブックとそのすべて（どれほど深くても）を共有します。**No** はロアブックだけを共有します。**Cancel** は何も共有せず、チェックボックスもオフのままにします。後から追加したサブロアブックは、共有するまで共有されません。
* チェックを外すと、そのロアブックの共有だけが停止します。サブロアブックは、それらも個別にオフにするまで共有されたままです（また、他のユーザーの一覧にも単独で表示されます）。
* 削除されたロアブック、エージェントの作業用コピー、あなた自身のロアブックは一覧に表示されません。また、削除されたユーザーについては何も表示されません。

設定の下には、ロアブックの有効なエントリのトークン数の推定値が表示されます。その隣にあるリンク **Count with subbooks** は、ロアブックと、そのすべてのサブロアブック（どれほど深くても）の有効なエントリのトークンを合計し、その合計を隣に表示します。ストーリーを書くときと同様に、無効なサブロアブックは、その下にあるロアブックとともに除外され、複数の場所でサブロアブックになっているロアブックは一度だけ数えられます。合計は、クリックした時点での数です。エントリを変更すると表示は消えます。もう一度クリックすると、再び数えます。

エージェントが作業しているブックのロアブックは、読み取り専用で表示されます（[エージェント](../agents.md)を参照）。**Add Entry**、**Search and replace**、**Mass edit**、**Delete Lorebook** と設定はありません。**Add Lorebook**、インポート、エクスポート、**Refresh** は残るため、いつでも別のロアブックを作成できます。
<a id="mass-edit"></a>

## 一括編集

**Mass edit** を開くと、選択したロアブックと**そのサブロアブック**（階層の深さは問いません）のすべてのエントリが、1つの表に表示されます。並び順は各エントリの **Order** に従い、同じ Order のエントリはロアブックごとに、さらに名前順に並びます。大きなロアブックを整理するための画面です。

- 各エントリの *enabled* チェックボックス、**Entry Name**、**Order**、**Tags**、**Filtering Mode**、**Filtering**、**Insertion Mode**、**Negative Tags**、**Activation Context** とその **Parts**、パーツの範囲（**From message** と **To message**。空欄は上限なし）、**Note** を、エディタと同じようにこの表の中で直接変更できます。各エントリは1行で、表は下へスクロールします（ウィンドウが狭いときは横にもスクロールします）。**Order** を変更すると、その行は新しい位置へ移動します。表に表示されるエントリの本文は短縮されています。全文を読んだり編集したりするには、ロアブックでエントリを開いてください。
- **Lorebook** の欄には、その行のエントリがどのロアブックに属しているかが表示されます。別のロアブック（そのロアブック自身、またはそのサブロアブックのいずれか）を選ぶと、エントリをそこへ移動できます。
- 複数のエントリを移動するには、それらにチェックを入れ（ヘッダーのチェックボックスで全件を選べます）、下部の **Move to lorebook** を選んで **Move checked** を押します。
- 複数のエントリを削除するには、チェックを入れて **Delete checked** を押します。確認は1回だけ求められ、エントリは [ゴミ箱](../trash.md) に移動されます。
- エージェントが作業中のロアブックはロックされます。そのエントリはグレー表示になり、変更や移動はできず、そのロアブックへエントリを移動することもできません。ロックはロアブックごとに判定されるため、サブロアブックが別の作業で使われていてロックされていても、親のロアブックは編集できることがあります。**Refresh** を押すと、ウィンドウを読み直してロックが解除されたかどうかを確認できます。

ロアブックのエディタは、変更を加えたあとにこのウィンドウを閉じると更新されます。

<a id="editing-in-full-screen"></a>

## 全画面で編集

**全画面エディター**（ツールバーの2段目）は、選択したロアブックを画面いっぱいのウィンドウで開き、長いエントリーを編集できるようにします（エントリーの行にある展開ボタンでは、そのエントリーを開いた状態でウィンドウが開きます）。書籍のウィンドウの *Lorebook* タブにも同じボタンがあり、そこに表示されているロアブックを開きます。ウィンドウのタイトルはロアブックの名前になります。[ストーリーエディター](../books/story-editor.md)と同様にタブの集まりで、タブをドラッグすると別のタブの横または下に配置でき、タブ間のスプリッターをドラッグして大きさを変えられます。

![全画面のロアブックエディター：エントリーの一覧と、タブで開いた2つのエントリー](../../images/lorebook-fullscreen.png)

- **Entries** タブはエントリーを一覧表示します。ロアブックのページにある検索ボックスとタグ・状態のフィルターのほか、**Add Entry**、**Mass edit**、**Tag entries**、**Preview activation**、**Refresh** があります（一括編集とタグ付けの変更は、開いているタブにも反映されます）。**Include sub lorebooks** をオンにすると[サブロアブック](#sub-lorebooks)のエントリーも、それぞれロアブック名付きで一覧に加わります。その場合 **Add Entry** は、一覧の横で選んだロアブックにエントリーを追加し、そのエントリーのタブにはロアブック名が表示されます。このタブは閉じられません。各行には3つのボタンがあります：
  - **Open**（ペンのアイコン。行のダブルクリックでも可）は、最後に使ったエントリータブにエントリーを表示します。そのようなタブがない場合は、一覧の右側の列に新しいタブを開きます。
  - **Open in new tab**（矢印のアイコン）は、最後に使ったエントリータブの隣にそのエントリー用のタブを追加します。
  - **Delete**（ゴミ箱のアイコン）は確認の後にエントリーを削除し、そのタブを閉じます。

  1つのエントリーが同時に開かれるタブは1つだけです。もう一度開くと、すでにあるタブが表示されます。

- **エントリータブ**は上から、**Name**、**Order**、**Enabled** があります。続いて **Settings** があり、これは折りたためるパネルで、エントリーのその他の設定（フィルタリングのモードとフィルター、挿入モード、発動のコンテキストとパーツ、タグと除外タグ、パーツの範囲、再帰のチェックボックスと条件。[エントリーと発動](entries.md)を参照）が入っています。その下に **content** のMarkdownエディターがあり（各タブは、テキストのみ、テキストとプレビュー、プレビューのみのどれを表示しているかを、ウィンドウを開き直したときも覚えています）、**Show note** をオンにすると、その横に **note** が表示されます。目のアイコンを押すと、このエントリーの[発動プレビュー](entries.md#preview-activation)が開きます。一番下の行には、内容の推定トークン数が表示され、テンプレートに問題がある場合はその内容が赤色で表示されます（それでも保存されます）。タブを閉じるには **×** を押します。

- **エントリー内の画像。** 内容に画像を貼り付けるか、画像にドラッグ＆ドロップするか、ツールバーの画像ボタンで選択します（PNG、JPEG、GIF、WebP。10 MBまで）。画像はファイル（*Resources* タブ）に保存され、カーソルのあった位置に、`![Map](resource:…)` のような行が内容に追加されます。プレビューには画像が表示され、角かっこ内の文字がそのキャプションになります。画像をエントリーから取り除くには、その行を削除します。モデルはこの行を除いてエントリーを読みます。画像そのものが送られるのは、モデルの設定が *Multimodal (accepts images)* の場合だけです（[推論プロバイダー](../inference-providers.md)を参照）。画像はロアブックに付いて移動します。複製、共有ロアブックのコピー、エクスポートしたロアブックファイル、ファイルを含む書籍のバックアップには画像も含まれ、コピー側は独自の画像を持ちます。SillyTavern へのエクスポートと書籍のエクスポートでは画像は省かれます。ストーリーの *Lorebook* タブは、エントリーのテキストの下に画像を表示します。画像はまだトークン数の推定には含まれません。

- **エントリー間の移動。** 内容中、テキストまたはプレビューにある別のエントリーの名前やキーワードを Ctrl+クリック（Macでは Cmd+クリック）すると、最後に使ったタブでそのエントリーが開きます。Shift も押すと新しいタブで開きます。一番下の行には **Mentioned in:** の後に、その内容がこのエントリーの名前を含んでいるエントリーの一覧も表示されます。そのひとつをクリックすると開き、Shift+クリックで新しいタブになります。エントリーは、その名前と、フィルターの語句（各キーワード、*Text* フィルターの全文、正規表現が一致する内容）によって、大文字・小文字を問わず単語単位で言及されたものと見なされます。これは[再帰](entries.md)がたどるものに近いものの、同じではありません。再帰は、より長い単語の中にあるキーワードも見つけ、*AND* フィルターではすべてのキーワードを必要とし、タグと条件も確認します。

- Markdownエディターには、ツールバー（太字、斜体、取り消し線、線、見出し、引用、コード、コードブロック、表、3種類のリスト）があり、右側には表示切り替え *edit*、*edit with preview*（既定）、*preview* があります。通常のキー操作（Ctrl+B、Ctrl+I など）が使え、Tab はインデントではなく次の欄へ移動します。入力した内容は、入力が少し止まったときと、エディターを離れたときに保存されます。

- ヘッダーには、有効なエントリーの推定トークン数、**Count with subbooks**、**Search and replace** が表示されます。後者は、置換したテキストを開いているタブにも反映します。

すべての変更は行うと同時に保存されるため、**Close** で失うものはありません。ウィンドウは、ロアブックごとに閉じたときの状態を覚えています。次に同じロアブックを開くと、同じエントリーが同じタブに、同じ並びで表示されます（その後に削除されたエントリーは除かれます）。ロアブックのページは、ウィンドウを閉じるとエントリーを再度表示します。

**他の場所での変更。** タブでの変更は、その時点で保存されているエントリーに上書きする形で保存されるため、他の場所（ロアブックのページ、一括編集、別のウィンドウ）で変更されたエントリーの*他の*項目はそのまま残り、タブにも反映されます。**content** または **note** が、タブが表示してから他の場所で変更されていた場合、あなたのテキストは上書きされません。一番下の行にその旨が表示され、**Keep my text**（それでも自分のテキストを保存）と **Load the saved text**（自分のテキストを破棄）を選べます。他の場所で削除されたエントリーのタブは閉じられます。

ウィンドウは、開いている間に保存された内容にも追従します。エージェントや他のウィンドウ（別のブラウザータブ、ストーリーのロアブックタブ）がエントリーを保存または削除すると、一覧が読み込み直され、そのエントリーのタブは現在の状態を表示します（削除されたエントリーのタブは閉じられます）。**Keep my text** または **Load the saved text** の回答を待っているテキストのタブは、回答するまでそのままです。入力したのと同じ1秒の間に保存された変更は、まだ食い違うことがあります。その場合は一番下の行に、上記と同じ問い合わせが表示されます。

**エージェント。** ロアブックを使っている書籍でエージェントが作業している間は、このウィンドウは開けません。ウィンドウを開いている最中に実行が始まった場合、次に変更したとき、またはタブを切り替えたときに、ウィンドウは読み取り専用になります。バーにエージェントの名前が表示され（最後の変更を保存できなかった場合はそれも示されます）、実行を一時停止または停止してから **Check again** をクリックすると、実行が残した状態でエントリーが読み込まれ、再び編集できます。

[Lore Generator](../extensions/lore-generator.md) と [Lorebook VCS](../extensions/lorebook-vcs.md) の拡張機能もここで使えます。ワンドのボタンは一覧の行と、エントリータブの名前の行にあり、リビジョンパネルは一覧の上に、エントリーのリビジョンバーはそのタブにあります。

<a id="tagging-many-at-once"></a>

## 多数にまとめてタグを付ける

ツールバーの2つのタグボタンは、多くの項目にタグを付けたり外したりするための1つのウィンドウを開きます。**Tag lorebooks** は自分のロアブックの一覧を、**Tag entries** は選択したロアブックのエントリーを表示します。**Tag** を選ぶか（新しいタグを入力して Enter を押す）、タグを指定します。一覧にはすべての項目とそのタグが表示され、選んだタグを持つ項目が先頭に来て、そのタグが強調されます。行の **+** と **-** ボタンは、その項目に対してタグを付けるか外すかを行います。複数の項目にチェックを入れ（ヘッダーのチェックボックスで全選択）、下部の **Apply the tag to the checked** または **Remove the tag from the checked** を使うと、すべてに一括で行えます。エージェントが作業中の項目（実行中のエージェントがいる書籍のロアブック、したがってそのすべてのエントリー）は灰色になり、実行が一時停止または停止されるまで変更できません。このウィンドウは[書籍](../books/managing-books.md#tagging-many-books-at-once)にもタグを付けられます。エントリーに付くタグは通常のもので、[タグ](entries.md#tags)を参照してください。除外タグは、各エントリー自体に設定されます。

![ロアブックのエントリーにタグを付ける](../../images/multi-tag-entries.png)

<a id="using-a-lorebook-in-a-book"></a>

## ロアブックを書籍で使う

書籍を開いて **Lorebook** タブを開き、**Lorebook** 欄でロアブックを選びます。下のエディターにそのロアブックが表示されるので、書きながらエントリーを追加・変更できます。欄を空にすると、ロアブックなしで書けます。

ひとつの書籍は1つのロアブックを使います。複数を使いたい場合は、それらをサブロアブックとして含むロアブックを作り、そちらを使ってください。

同じロアブックは、いくつの書籍からでも使えます。その変更は、次に生成されるパートから、すべての書籍に反映されます。すでに書かれたパートは、書かれたときのロア設定を保ちます。
<a id="sub-lorebooks"></a>

## サブ・ローブック

**Sub Lorebooks** は、他のローブックのエントリーをこのローブックに含めます。典型的な設定は次のとおりです:

```
"Saga" (used by the books of the series)
 ├─ "World"       places, history, rules of magic
 ├─ "Characters"  the main cast
 └─ "Book 2 notes"
```

- サブ・ローブックは、それ自体のサブ・ローブックを持つことができます。すべての階層が含まれます。
- ローブックは、複数のローブックのサブ・ローブックになれます。複数の経路から到達しても、そのエントリーは一度だけ使われます。
- ローブックは、直接でも他のローブックを経由しても、自分自身を含めることはできません。そのような選択は *Cannot select sub lorebook: cycle detected.* と表示されて拒否されます。
- 無効にされたサブ・ローブックは、それが含むものすべてと一緒に除外されます。

![二つのサブ・ローブックを持つローブック：それらがある場合とない場合のトークン](../../images/lorebook-sub-lorebooks.png)

含まれるすべてのローブックのエントリーは、どのローブックから来たかに関係なく、まとめて並べられ、その [order](entries.md#order-and-insertion) で並べ替えられます。

<a id="disabling-and-deleting"></a>

## 無効化と削除

ローブックを一時的にオフにするには **Enabled** のチェックを外します。たとえば、そのローブックなしで本の読み心地がどう変わるかを確かめたいときに使えます。ローブックを使っていた本は、無効の間もそれを使わなくなりますが、チェックを入れ直すとまた使われるようになります。

**Delete Lorebook** は、そのローブックを一覧から取り除きます。それを使っていた本は、そのエントリーをもう受け取らなくなり、それをサブ・ローブックとして含んでいたローブックは、それを飛ばして扱います。データはデータベースに残り、管理者が [Cleanup](../administration/cleanup.md) を実行するまで保持されます。それまでは [Trash](../trash.md) からローブックを復元できます。[本のバックアップ](../books/backups.md) とエクスポートしたファイルにある複製は影響を受けません。
