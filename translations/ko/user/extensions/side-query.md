# 사이드 쿼리

이야기 옆에서 모델과 대화하는 기능입니다. 줄거리에 대해 묻고, 연속성을 확인하고, 이름이나 다음 장을 함께 궁리할 수 있습니다. 책에는 아무것도 추가되지 않습니다.

!!!
사이드 쿼리는 [폰 레이아웃](../phone.md#extensions)에서 동작합니다. 이 기능의 탭은 이야기의 개요 서랍에 있습니다.
!!!

![이야기 옆의 사이드 쿼리](../../images/plugin-sidequery.png)

<a id="the-side-query-tab"></a>

## 사이드 쿼리 탭

[이야기 편집기](../books/story-editor.md)의 왼쪽 사이드바에는 *개요* 옆에 **Side Query** 탭이 생깁니다. 구분선을 드래그하면 탭을 더 넓게 쓸 수 있습니다.

이 탭에는 대화가 들어 있으며, 대화마다 별도의 탭이 있습니다. **+**를 누르면 새 대화가 열리고(*Tab 2*, *Tab 3*...), 연필 아이콘은 탭의 이름을 바꾸며, **×**는 탭을 닫습니다(마지막 탭은 닫을 수 없습니다). 프로필에서 *Enable AI Tab Naming*을 켜면, 직접 이름을 바꾸지 않은 탭은 모델이 첫 답변 뒤에 이름을 붙입니다. 대화는 책에 속하며, 탭을 닫기 전까지 보관됩니다.

<a id="asking"></a>

## 질문하기

아래쪽 입력창에 질문을 쓰고 **SEND**를 누르세요. 답변은 작성되는 대로 나타납니다. *SEND* 자리에 나타나는 **STOP**은 답변을 중단합니다.

| 버튼 | |
|---|---|
| **SEND** | 질문을 보냅니다. |
| **UNDO** | 마지막 메시지를 지웁니다. 그것이 내 질문이었다면 편집할 수 있도록 입력창으로 돌아갑니다. |
| **REGENERATE** | 마지막 답변을 지우고 다시 질문합니다. |

모든 메시지에는 위아래로 **이동**, **편집**, 클립보드에 **복사**, 문맥에서 **제외**(또는 다시 포함)하는 버튼이 있습니다. 제외된 메시지는 대화에 남아 있지만 모델에게 전달되지 않습니다. 잘못된 답변을 지우지 않고 빼고 싶을 때 유용합니다.

<a id="what-the-model-sees"></a>

## 모델이 보는 내용

대화 위의 옵션들은 질문과 함께 무엇을 보낼지 정합니다:

| 옵션 | |
|---|---|
| **Lorebook** | 책의 로어(아래 참고). |
| **Chat Logs** *from* … *to* | 개요에서와 같이 1부터 번호가 매겨진, 현재 분기의 이야기 부분들 중 해당 범위. `1`부터 `6`까지는 `#1`부터 `#6`까지의 부분입니다. |
| **플러그 버튼** | 다른 확장 기능이 제공하는 데이터 목록을 열며, 각 항목에 체크박스가 있습니다(아래 참고). |
| **Tokens** | 요청의 대략적인 크기. |

!!!
*Lorebook*은 생성 과정과 같은 방식으로 로어를 모읍니다. 책의 로어북과 하위 로어북(비활성화된 로어북은 건너뜀), 그리고 태그가 책의 태그와 일치하는 활성 항목을 [매크로](../templates/macros.md)를 처리한 상태로 모읍니다. 키워드 필터는 적용되지 않습니다. 맞춰 볼 이야기 프롬프트가 없으므로 해당되는 항목은 모두 보내집니다. 항목이 설정한 변수는 저장되지 않습니다.
!!!

<a id="data-of-other-extensions"></a>

### 다른 확장 기능의 데이터

플러그 버튼은 다른 확장 기능이 제공하는 **추가 소스** 목록을 팝오버로 엽니다. 예를 들어 [Arc Outline](arc-outline.md)은 개요를 제공합니다. 모든 소스에는 체크박스가 있으며, 목록은 최대 두 부분으로 나뉩니다:

- **책에 대해**: 체크된 소스는 로어북 뒤에, 이름 아래에 요청에 추가됩니다.
- **이야기 부분에 대해**: 체크된 소스는 *Chat Logs* 범위의 이야기 부분마다 요청을 받으며, 반환된 내용은 해당 부분의 텍스트 뒤에 추가됩니다. *Chat Logs*가 켜져 있을 때만 효과가 있습니다.

선택 내용은 탭과 함께 보관됩니다. 확장 기능이 설치되어 있지 않거나(또는 중지되어 있으면) 해당 소스는 목록에 없고 전송되지도 않으며, 확장 기능이 다시 활성화되면 돌아옵니다. 제공되는 소스가 없으면 팝오버에 그렇게 표시됩니다.

요청은 다음과 같이 구성됩니다:

1. 시스템 메시지 하나: 프로필의 *Initial System Query*, 로어북 항목(*Lorebook Context*), 책에 대해 체크된 소스와 이야기 부분에 대해 체크된 소스(*Chat History Context*, 개요 번호인 *Message #1*, *#2*... 로 표시되며, 각각 체크된 이야기 부분 소스가 뒤따름);
2. 포함된 대화 메시지들을 채팅 형식으로. 프로필의 *Instructions Before User Input*은 마지막 질문의 텍스트 앞, 그 시작 부분에 놓입니다.

모델과 프로토콜은 프로필에서 가져오며(아래 참고), 기본값은 책의 설정입니다. 이야기에 관한 질문에는 보통 저렴하고 빠른 모델이면 충분합니다.

<a id="saved-queries"></a>

## 저장된 질문

자주 하는 질문은 저장해 둘 수 있습니다:

- **Save prompt**(디스크 아이콘)은 입력창의 텍스트를 목록에서 선택한 이름으로 저장하며, 이름이 선택되어 있지 않으면 이름을 묻습니다;
- **Save prompt as...**는 텍스트를 새 이름으로 저장합니다;
- 목록에서 이름을 고르면 저장된 텍스트가 입력창에 들어갑니다;
- 휴지통 버튼은 선택한 저장된 질문을 삭제합니다.

저장된 질문은 사용자 계정에 속하며, 모든 책에서 쓸 수 있습니다.

유용한 예시:

- *지금까지 등장한 이름 있는 인물을 모두 나열하고, 각각에 대해 한 줄씩 설명해 줘.*
- *아직 해결되지 않은 줄거리의 실마리는 무엇인가?*
- *이 세계의 항구 마을 이름을 다섯 개 제안해 줘.*

<a id="profiles"></a>

## 프로필

사이드 쿼리 설정은 **설정 → Extension Settings → SideQuery Settings**에 있으며, [Reviewer](reviewer.md#profiles)와 같이 **프로필** 단위로 정리되어 있습니다. 선택된 프로필이 사용됩니다:

![SideQuery 설정](../../images/plugin-sidequery-settings.png)

| 필드 | |
|---|---|
| **Profile**, **New**, **Rename**, **Delete** | 프로필을 선택하고 관리합니다. *_Default*는 이름을 바꾸거나 삭제할 수 없습니다. |
| **SideQuery Model**, **SideQuery Protocol** | 사용할 [추론 제공자](../inference-providers.md)와 [프로토콜](../protocols.md). 비워 두면 책의 설정을 따릅니다. |
| **Initial System Query** | 시스템 메시지의 시작 부분, 예: 어시스턴트의 역할. |
| **Instructions Before User Input** | 마지막 질문 바로 앞에 놓이는 텍스트 - 답변 규칙, 예: *짧게 답하세요. 가능하면 이야기를 인용하세요.* |
| **Enable AI Tab Naming** | 탭에서 첫 답변이 끝나면 모델에게 대화의 짧은 이름을 요청합니다(요청 한 번 추가). 직접 이름을 바꾼 탭은 그 이름을 유지합니다. |

변경 사항을 유지하려면 *Settings* 페이지 상단의 **Save**를 누르세요.

<a id="storage"></a>

## 저장 위치

대화는 책과 함께 저장되므로 [책 백업](../books/backups.md) 및 사본에 포함됩니다. 프로필과 저장된 질문은 사용자 설정에 저장됩니다.
