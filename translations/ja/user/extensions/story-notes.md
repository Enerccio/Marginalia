# ストーリーノート

サイドバーにある、本のための小さなウィキです。計画中のプロット、まだ使う準備ができていないアイデア、魔法体系のルール、黒幕が本当に望んでいることなど、ページごとに書き留めておけます。内容はあなた自身の考えとあなた自身の言葉で書き、ページ同士はタグとリンクでつなぎます。[作者ノート](authors-note.md)は毎回の生成に送られる1つのテキストですが、ノートは単独ではモデルに送られません。[プロットウィザード](arc-outline.md#developing-the-plot-in-a-conversation)とエージェントはノートを読むことができ、許可すれば変更することもできます。

<a id="the-notes-tab"></a>

## ノートタブ

[ストーリーエディタ](../books/story-editor.md)の左サイドバーには、*アウトライン*の隣に**ノート**タブが追加されます。タブには本のページがタイトル順に並んでいます。リストの上には、**Add**（新しいページの追加）、タグによる絞り込み（ページにタグが付くと表示されます）、タイトル・タグ・テキストを対象とした検索があります。

各ページには、タイトル、テキストの1行目、タグが表示されます。ページをクリックするか鉛筆アイコンを押すと開きます。ゴミ箱アイコンを押すと、確認の後にページが削除されます。タイトルの横には2種類の小さなマークが付くことがあります。斜線の入った目のマークは、そのページが[アシスタントから隠されている](#what-assistants-can-see)ことを示します。杖のマークは、最後の変更があなたの操作ではなくコマンドによるものだったことを示します。

![ノートタブ：アシスタントから隠されたページ（目のマーク）と、プロットウィザードが追加したページ（杖のマーク）](../../images/plugin-storynotes-tab.png)

<a id="a-page"></a>

## ページ

ページのダイアログには次の項目があります。

| | |
|---|---|
| **タイトル** | 必須。本の中で一意であること（大文字・小文字は区別しません）。括弧や縦棒（`|`）は使えません。他のページからのリンクはこのタイトルで指定します。 |
| **タグ** | カンマで区切ります。リストの絞り込みに使われます。 |
| **テキスト** | Markdownで書きます。**Write**と**Preview**で、テキストの編集と表示の切り替えができます。本文中の`[[タイトル]]`は、そのタイトルのページへのリンクになります。`[[タイトル|別の語句]]`も同じページにリンクしますが、プレビューでは*別の語句*が表示されます（例：`[[言葉の壁|話し方]]`）。 |
| **アシスタントに表示** | 初期状態ではオンです。詳しくは後述します。 |

テキストの下には、そのページが**リンクしている**ページが一覧表示されます。存在するページへのリンクは、そのページを開きます。存在しないページへのリンクには**Create**が表示され、そのタイトルで新しいページを作成します。さらにその下には、このページに**リンクしてくる**ページが表示されます。ページの名前を変更すると、他のページにある`[[リンク]]`も変更されます（リンクに表示される語句はそのまま残ります）。

![リンクしているページと、このページにリンクしてくるページを示したページ](../../images/plugin-storynotes-page.png)

**Preview**では、テキストがMarkdownとして表示され、すべての`[[リンク]]`がリンクとして表示されます。クリックするとそのページが開きます（存在しないページへのリンクを押すと、そのタイトルで新しいページが作られます）。

![同じページのプレビュー](../../images/plugin-storynotes-preview.png)

**Save**を押すまで何も保存されません。変更したままページを閉じようとすると、破棄してよいか確認されます。編集中にコマンドによってページが変更された場合は、あなたの版でそのページを上書きしてよいか確認されます。**Ctrl/Cmd+Enter**で保存できます。ページは本のデータとともに保存されるため、バックアップやコピーにも含まれます。

<a id="what-assistants-can-see"></a>

## アシスタントから見えるもの

「アシスタント」とは、ノートが提供するコマンドを利用する仕組みのことで、エージェント、マクロ、プロットウィザードがこれを使います。**アシスタントに表示**をオフにしたページは、アシスタントにとって存在しないのと同じです。一覧に出ず、検索にも見つからず、読むことも変更することもできません。さらに、そのページにしかないタイトルで作成しようとした場合は拒否されます。自分だけが見るべき内容には、この設定をオフにしてください。オフにしたページも、バックアップには引き続き含まれます。

コマンドは（コマンドバーとエージェント用です。タイトルはページのアドレスになります）次のとおりです。

| コマンド | 内容 |
|---|---|
| `/list-notes [<tag>]`, `/get-note <note>`, `/search-notes <query>` | ページの一覧、1ページの本文・リンク・そのページにリンクしているページの表示、検索を行います。 |
| `/create-note <title> [<content> [<tags>]]` | ページを追加します。 |
| `/append-to-note <note> <text>` | ページの末尾に段落を追加します。 |
| `/update-note <note> [<title> [<content> [<tags>]]]`, `/edit-note <note> <find> <replace> [<all>]` | ページを変更するか、本文の一部を置き換えます。`find`はページ内に書かれたとおりに存在しなければならず（大文字・小文字は区別されます）、`all`が`true`でない限り、ちょうど1回だけ出現する必要があります。`all`を指定すると、該当するすべての箇所を置き換えます（名前や用語をページ全体で直すときに使います）。回答では置き換えた箇所の数が示されます。これらは既存のテキストを変更するため*破壊的*な操作です。確認するように設定されたエージェントは、事前にあなたに確認します。 |
| `/delete-note <note>` | ページを削除します。確認の後に実行されます。 |
| `/note-text <note>` | ページのテキストを、マクロ用に返します。{%{`{{command::note-text::Magic}}`}%}と書くと、そのテキストをテンプレートに差し込めます。存在しないページや隠されたページの場合は空になります。 |

コマンドによって変更されたページには、あなたが自分で保存するまで杖のマークが付きます。

<a id="with-the-plot-wizard"></a>

## プロットウィザードでの利用

この拡張機能をインストールすると、Arc Outlineの[プロットウィザード](arc-outline.md#developing-the-plot-in-a-conversation)に**Send the notes**オプション（タイトルと1行目、全文、または何も送らない）と、**Notes**ツールのグループが追加されます。モデルはページを検索して読み、リンクをたどり、あなたが何かを残すよう頼んだときにはページを追加したり既存のページに追記したりでき、ページ内のテキストを変更することもできます。ページのテキストを変更する前には、*何かを変更・削除する前に確認する*がオンの間、確認が求められます。ウィザードがページを削除することはできません。オプションとツールグループについては、ウィザードの表を参照してください。

![Notesツールを使うプロットウィザード：ページを読み、未解決の問いをそのページに追加した例](../../images/plugin-storynotes-wizard.png)

<a id="other-extensions"></a>

## 他の拡張機能

この拡張機能は、他の拡張機能に2種類のテキストソースを提供します。[Side Query](side-query.md)のプラグインボタンから添付できます。ソースは**Story notes (titles)**と**Story notes (all)**です。どちらも非表示のページは含みません。
