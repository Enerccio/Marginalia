# 统计

每位用户的[写作统计](../books/statistics.md)（字数、花费的时间、每本书的大小，逐日记录）都保存在数据库中。这些记录包括用户何时在其书籍上工作、书籍的名称和文件夹，也包括已删除书籍的记录。管理页面的**统计**标签页可以用来限制这些记录。用户也可以在自己的[设置](../account.md)中做同样的事情，并在统计窗口中清除自己的统计数据。

![管理页面的统计标签页](../../images/admin-statistics.png)

| | |
|---|---|
| **记录写作统计** | 关闭后，无论用户如何选择，都会停止为所有用户记录。已记录的内容不会因此被删除。统计窗口会提示不再计入新的内容。 |
| **保留统计的时长（月）** | 超过此时长的天数会从每位用户的统计中永久删除，每天一次（约在 4:20，启动后也会很快执行一次），并在您保存时执行。留空或填 0 则保留全部。用户可以为自己选择更短的时长，但不能更长。 |
| **清除用户的统计** | 在确认后，删除所选用户的全部统计数据。其书籍不会有任何改动。 |
| **清除所有人的统计** | 对所有用户执行同样的操作。 |

已删除的统计无法恢复，除非从[数据库备份](database-backups.md)中恢复：统计数据属于数据库的一部分（单本书的备份不包含统计数据）。

[清理](cleanup.md)不会触及统计数据，因为统计数据并非被删除的对象：它们通过书籍的 ID 记录书籍，并特意在书籍被删除后继续保留。
