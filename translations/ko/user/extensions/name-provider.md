# 이름 제공자

모델이 이름을 지어내는 대신 고를 수 있도록 실제 이름을 제공합니다. 많은 나라에서 가장 흔한 이름과 성을 담고 있습니다. [이름 생성기](name-generator.md)가 해당 범주처럼 들리는 새 이름을 만들어 내는 반면, 이 확장 기능은 실제로 존재하는 이름을 제공하며, 각 이름은 로마자 표기와 원래 표기를 함께 보여 줍니다: `Satō`와 `佐藤`.

이 확장 기능에는 자체 화면이 없고 설정할 것도 없습니다. 다른 확장 기능들이 이 기능을 모델에 제공합니다. [Lore Generator](lore-generator.md#tools)와 [Arc Outline](arc-outline.md)에서는 모델이 사용할 수 있는 목록을 직접 고를 수 있습니다. 이 기능의 도구 묶음은 [도구 창](tools.md)에서 *Name provider*라는 이름으로 표시되며, *Name generator* 도구 묶음 옆에 있습니다. 두 묶음의 목록을 모두, 하나만, 또는 전혀 선택하지 않을 수 있습니다.

<a id="what-the-model-can-do"></a>

## 모델이 할 수 있는 일

| 기능 | 하는 일 |
|---|---|
| `list_real_name_lists` | 이름 목록을 나열합니다. `filter`를 주면 이름에 그 단어들이 들어 있는 목록만 나열합니다. |
| `pick_real_names` | 한 목록에서 서로 다른 이름을 무작위로 최대 100개까지 고릅니다. 각 이름은 한 쌍으로, 로마자 이름과 원래 이름입니다. |

요청한 개수보다 이름이 적은 목록은 있는 이름을 모두 돌려줍니다. 모델에게는 ([도구 창](tools.md#choosing-the-tools)의 *Name provider* 묶음 힌트를 참고하세요) 받은 이름 중에서 고르고, 받은 그대로 적으라고 전해집니다. 설정에 어울릴 때는 원래 표기를 옆에 함께 적을 수 있습니다. 같은 나라의 이름과 성을 조합하는 것도 가능합니다.

<a id="commands"></a>

## 명령

같은 이름들은 [명령](../commands/index.md)으로도 쓸 수 있습니다. 명령줄에서 쓸 수 있을 뿐 아니라, [에이전트](../agents.md)가 자신의 프롬프트 안에서 사용할 수도 있습니다(예: [Lore Generator](lore-generator.md)의 `/generate-lore-entry`):

| 명령 | 하는 일 |
|---|---|
| `/list-real-name-lists [<filter>]` | 목록을 JSON 배열로 나열합니다. 필터를 주면 이름의 모든 단어가 들어 있는 목록만 나열합니다(각 단어는 단어의 앞부분에서 시작해야 하며, 순서는 상관없고, 대소문자는 구분하지 않습니다). |
| `/pick-real-names list count` | 목록에서 이름을 무작위로 최대 100개까지 골라, 로마자 이름과 원래 이름의 쌍으로 이루어진 JSON 배열로 돌려줍니다. |

두 명령 모두 읽기만 합니다.

<a id="lists"></a>

## 목록

약 180개의 목록이 있으며, 이름은 `<Country> - Surnames`와 `<Country> - Forenames` 형식입니다. 75개 나라의 성과 106개 나라의 이름이 있습니다(`Japan - Surnames`, `Czechia - Forenames`, `Kosovo - Surnames`). 남녀 이름은 하나의 목록에 함께 들어 있습니다. 목록마다 5개에서 약 150개의 이름이 있으며, 해당 나라에서 가장 흔한 이름들입니다. 이름은 새로 만들어지지 않습니다. 받는 이름은 실제 사람들이 쓰는 이름입니다.

몇십 개의 항목은 언어별로 묶인 **그룹**입니다. `<Language> - Forenames`와 `<Language> - Surnames` 형식으로, 스페인어(18개 나라), 포르투갈어, 프랑스어, 독일어, 영어, 아랍어, 서슬라브어, 동슬라브어, 남슬라브어, 북게르만어, 북유럽어, 우랄어, 발트어, 튀르크어, 페르시아어, 중국어, 남아시아어, 동남아시아어, 캅카스어, 알바니아어, 루마니아어가 있습니다(해당 목록이 있는 경우에 한합니다). 이 그룹들도 다른 목록과 똑같이 나열되며, [도구 창](tools.md)에서는 항목 하나로 표시됩니다. 그룹의 모든 이름은 그 안의 목록 중 하나를 무작위로 골라 가져오며, 각 나라가 같은 확률을 가집니다. 그래서 20개의 이름을 요청하면 여러 나라의 이름을 받고, 같은 이름이 두 번 나오지 않습니다. 여러 언어가 쓰이는 나라(벨기에, 룩셈부르크, 몰타, 안도라)는 어떤 그룹에도 들어 있지 않습니다. 그룹은 `name-groups.json`의 한 줄이며, 자세한 내용은 [플러그인 README](https://github.com/Enerccio/Marginalia/blob/master/marginalia/plugins/name-provider/README.md#groups)를 참고하세요.

데이터는 [popular names by country dataset](https://github.com/sigpwned/popular-names-by-country-dataset)(CC0)에서 가져왔습니다. 이 데이터셋은 위키백과의 가장 흔한 성 목록과 가장 인기 있는 이름 목록을 바탕으로 합니다. 라틴 문자가 아닌 문자(중국어, 일본어, 한국어, 아랍어, 키릴 문자 등)로 쓰인 이름에는 로마자 표기가 있는데, 원본 데이터의 표기이거나 기계 번역으로 만든 표기입니다. 따라서 철자가 중요할 때는 확인하세요.

<a id="usage"></a>

## 사용법

*Admin → Extensions*에서 확장 기능을 불러오세요. 다음 생성부터 적용되며, 이 기능을 사용하는 확장 기능보다 나중에 설치하거나 언로드했다가 다시 설치한 경우에도 마찬가지입니다. 이 기능과 다른 묶음이 모두 없으면 *도구* 버튼이 나타나지 않습니다.
