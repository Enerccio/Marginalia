# 프로토콜

프로토콜은 생성 설정의 집합입니다. 샘플링 매개변수(온도, Top P, 페널티)와, 선택적으로 자체 컨텍스트 및 응답 한도를 포함합니다. [추론 제공자](inference-providers.md)는 *어떤* 모델이 글을 쓸지를 정하고, 프로토콜은 *어떻게* 쓸지를 정합니다.

프로토콜은 제공자와 별개이므로, 신중한 프로토콜과 창의적인 프로토콜처럼 여러 개를 보관해 두고 연결 설정을 건드리지 않은 채 책마다 전환할 수 있습니다. 제공자와 마찬가지로 프로토콜도 사용자 계정에 속합니다. 하나를 [공유](#sharing-a-protocol)하면 다른 사용자가 사본을 가져올 수 있습니다.

![프로토콜 탭](../images/protocols-list.png)

<a id="creating-a-protocol"></a>

## 프로토콜 만들기

**프로토콜** 탭을 열고 **프로토콜 추가**를 클릭합니다. 기존 프로토콜은 연필 버튼으로 편집하고, 휴지통 버튼으로 삭제합니다. 복제 버튼(두 장의 종이 모양)은 프로토콜의 모든 설정을 그대로 담은 사본을 만듭니다. 이름은 확인 과정에서 정하며, 기본값은 원본 이름 뒤에 *(Copy)*가 붙습니다. 잘 작동하는 설정을 잃지 않고 다른 샘플링 설정을 시험해 볼 때 유용합니다.

**다른 사용자에게서 가져오기**(목록 위쪽)는 다른 사용자가 [공유](#sharing-a-protocol)한 프로토콜을 보여 주고, 그중 하나의 사본을 가져오게 합니다.

![프로토콜 대화상자](../images/protocol-dialog.png)

| 필드 | |
|---|---|
| **이름** | 프로토콜의 이름입니다. 예: `Creative` 또는 `Long context`. |
| **유형** | 요청 형식입니다. 현재는 **채팅 완성**만 지원합니다. |
| **최대 컨텍스트 토큰** | 선택 사항입니다. 이 프로토콜을 사용하는 책의 프롬프트와 응답을 합친 전체 토큰 수입니다. 비워 두면 제공자의 **최대 컨텍스트 크기**를 사용합니다. |
| **최대 응답 토큰** | 선택 사항입니다. 가장 긴 응답의 길이입니다. 비워 두면 제공자의 **최대 응답 토큰**을 사용합니다. |
| **온도** | 글의 무작위성입니다. 낮을수록(약 `0.7`) 초점이 맞고 예측 가능하며, 높을수록(`1.0` 이상) 다양하고 뜻밖의 글이 됩니다. |
| **Top P** | 핵 샘플링입니다. 모델은 확률의 합이 이 값(`0`-`1`)에 도달할 때까지의 가장 가능성 높은 단어 중에서만 고릅니다. `0.9`-`0.95`가 흔히 쓰이는 값입니다. |
| **빈도 페널티** | 이미 등장한 횟수가 많은 단어에 감점을 주어 반복을 줄입니다. 보통 `0`-`1`입니다. |
| **존재 페널티** | 이미 한 번이라도 등장한 단어에 감점을 주어 모델이 새로운 주제로 나아가게 합니다. 보통 `0`-`1`입니다. |
| **다른 사용자와 공유** | 체크하면 다른 사용자가 이 프로토콜을 보고 사본을 가져올 수 있습니다. [아래](#sharing-a-protocol)를 참고하세요. 새 프로토콜에서는 꺼져 있습니다. |

모든 샘플링 매개변수에는 **활성화** 체크박스가 있습니다. 활성화되지 않은 매개변수는 Marginalia가 설정하지 않으며, 모델은 자체 기본값을 사용합니다. 바꾸고 싶은 것만 활성화하세요.

<a id="sharing-a-protocol"></a>

## 프로토콜 공유하기

프로토콜 대화상자에서 **다른 사용자와 공유**를 체크하면, 이 설치본의 다른 모든 사용자는 **프로토콜 추가** 옆의 **다른 사용자에게서 가져오기**에서 이 프로토콜을 이름과 작성자(성명이 있으면 성명, 없으면 로그인 ID)와 함께 보게 됩니다. 사용자는 행을 열어 설정을 살펴본 뒤 **가져오기**를 클릭할 수 있으며, 그러면 같은 설정과 이름을 가진 자신만의 프로토콜이 만들어집니다. 공유는 읽기 전용입니다. 다른 사람은 여러분의 프로토콜을 변경, 삭제, 사용할 수 없습니다. 가져온 사본은 비공개이며 원본과 연결되어 있지 않아서, 이후 어느 쪽이 바꾼 내용도 상대에게 전달되지 않습니다. 체크를 해제하면 프로토콜은 다른 사용자의 목록에서 사라지지만, 이미 만들어 둔 사본은 그 사용자의 것으로 남습니다.

## 한도

[추론 제공자](inference-providers.md#general-settings)의 한도는 항상 적용됩니다. 프로토콜은 각 한도를 개별적으로 낮출 수 있지만, 제공자의 한도를 넘게 높일 수는 없습니다.

| | 프로토콜 값을 설정한 경우 | 프로토콜 값을 비워 둔 경우 |
|---|---|---|
| 컨텍스트 | **최대 컨텍스트 토큰**, 단 제공자의 **최대 컨텍스트 크기**가 더 작으면 그 값 | 제공자의 **최대 컨텍스트 크기** |
| 응답 | **최대 응답 토큰**, 단 제공자의 **최대 응답 토큰**이 더 작으면 그 값 | 제공자의 **최대 응답 토큰** |

제공자의 컨텍스트 한도가 32 000인 상태에서 **최대 컨텍스트 토큰**을 128 000으로 설정한 프로토콜을 쓰면 32 000이 적용됩니다. 제공자가 서비스(또는 이를 공유한 관리자)가 허용하는 범위를 정하기 때문입니다.

Marginalia는 응답을 위한 공간을 비워 두고, 나머지 컨텍스트를 프롬프트로 채웁니다. 프롬프트에는 템플릿, 로어북 항목, 요약, 그리고 들어갈 수 있는 만큼의 이야기가 들어갑니다. 컨텍스트가 32 000 토큰이고 응답이 최대 2 000 토큰이라면, 프롬프트에는 30 000 토큰이 배정됩니다. 응답 한도는 API에도 전달됩니다(`max_completion_tokens`).

프로토콜 한도는 모델이 허용하는 것보다 프롬프트를 짧게 유지하고 싶을 때 사용하세요. 예를 들어 대용량 컨텍스트를 지원하는 클라우드 모델로 긴 책을 더 저렴하고 빠르게 만들거나, 일부 책의 응답을 더 짧게 유지할 때 쓸 수 있습니다. 프로토콜 한도는 이 프로토콜을 쓰는 책의 [요약](books/summaries.md)에도 사용됩니다.

꼭 필요하지 않다면 두 값을 모두 비워 두세요. 그러면 제공자의 값이 적용되고, 책의 제공자를 바꿀 때 한도도 함께 따라갑니다.

<a id="using-a-protocol-in-a-book"></a>

## 책에서 프로토콜 사용하기

각 책의 프로토콜은 **정보** 탭의 **프로토콜** 필드에서 지정합니다. 새로 만드는 모든 책에 프로토콜을 적용하려면 **설정** 탭에서 해당 프로토콜을 **기본 프로토콜**로 선택하세요. 프로토콜이 없는 책은 생성할 수 없으며 *책에 프로토콜이 없습니다.*라고 표시됩니다.

<a id="suggested-settings"></a>

## 권장 설정

출발점으로 삼고, 사용하는 모델에 맞게 조정하세요.

| 용도 | 온도 | Top P | 빈도 페널티 | 존재 페널티 |
|---|---|---|---|---|
| 균형 잡힌 문장 | `0.8` | `0.95` | 끔 | 끔 |
| 창의적이고 다양함 | `1.0` | `0.95` | `0.3` | `0.3` |
| 일관적이고 지시에 충실함 | `0.6` | `0.9` | 끔 | 끔 |

추론 모델은 샘플링 매개변수를 무시하거나 거부하는 경우가 많으므로, 이런 모델에서는 해당 매개변수를 비활성화된 상태로 두세요.
