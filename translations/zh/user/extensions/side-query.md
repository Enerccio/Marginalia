# 侧边查询

在故事旁边与模型聊天：询问情节、检查连贯性、为角色或下一章构思名字，而无需向书中添加任何内容。

!!!
侧边查询在[手机布局](../phone.md#extensions)中同样可用：它的标签页位于故事的大纲抽屉中。
!!!

![故事旁边的侧边查询](../../images/plugin-sidequery.png)

<a id="the-side-query-tab"></a>

## 侧边查询标签页

[故事编辑器](../books/story-editor.md)的左侧边栏在*大纲*旁边增加了一个**侧边查询**标签页。拖动分隔线可以为它留出更多空间。

该标签页包含多个对话，每个对话位于自己的标签中：**+** 打开新对话（*Tab 2*、*Tab 3*……），笔形按钮用于重命名标签，**×** 关闭标签（最后一个标签无法关闭）。如果在配置中启用了*Enable AI Tab Naming*，模型会在首次回答后为标签命名，除非你已自行重命名该标签。对话属于该书，在你关闭其标签之前会一直保留。

<a id="asking"></a>

## 提问

在底部的输入框中输入问题，然后点击**SEND**。回答会随着生成逐字显示；**STOP**（位于*SEND*的位置）可中断生成。

| 按钮 | |
|---|---|
| **SEND** | 发送问题。 |
| **UNDO** | 删除最后一条消息。如果它是你的问题，则会放回输入框以便编辑。 |
| **REGENERATE** | 删除最后一条回答并重新提问。 |

每条消息都有按钮，可用于上移或下移、**编辑**、将其**复制**到剪贴板，以及将其从上下文中**排除**（或重新纳入）。被排除的消息仍保留在对话中，但不会发送给模型，适合在不删除错误回答的情况下将其舍弃。

<a id="what-the-model-sees"></a>

## 模型能看到什么

对话上方的选项决定了随你的问题一同发送的内容：

| 选项 | |
|---|---|
| **Lorebook** | 书籍的设定（见下文）。 |
| **Chat Logs** *from* … *to* | 当前活动分支中该范围内的故事段落，编号与大纲中一致，从 1 开始：`1` 至 `6` 分别对应段落 `#1` 至 `#6`。 |
| **插件按钮** | 打开一个列表，显示其他扩展提供的数据，每项都有一个复选框（见下文）。 |
| **Tokens** | 请求的大致大小。 |

!!!
*Lorebook* 的收集方式与生成时相同：书籍的设定集及其子设定集（已禁用的设定集会被跳过），以及标签与该书标签相匹配的已启用条目，并处理其中的[宏](../templates/macros.md)。不应用关键词过滤——由于没有可供匹配的故事提示，因此所有适用的条目都会被发送。条目设置的变量不会被保存。
!!!

<a id="data-of-other-extensions"></a>

### 其他扩展的数据

插件按钮会打开一个弹出窗口，其中列出其他扩展提供的**附加数据源**，例如[大纲辅助](arc-outline.md)会提供你的大纲。每个数据源都有一个复选框；列表最多分为两部分：

- **关于本书**：勾选的数据源会在设定集之后加入请求，并以其名称作为标题。
- **关于故事段落**：勾选的数据源会针对*Chat Logs*范围内的每个故事段落进行询问，其返回内容会添加在该段落文本之后。仅当*Chat Logs*开启时才会生效。

该选择与标签页一同保存。如果某个扩展未安装（或已停止），其数据源不会出现在列表中，也不会被发送；扩展恢复后它们会重新出现。如果没有任何扩展提供数据，弹出窗口会对此进行说明。

请求的构建方式如下：

1. 一条系统消息：配置中的*Initial System Query*、设定集条目（*Lorebook Context*）、勾选的关于本书的数据源，以及关于故事段落的数据源（*Chat History Context*，以其大纲编号标注为*Message #1*、*#2*……，每段之后附上勾选的关于故事段落的数据源）；
2. 对话中包含的消息，以聊天形式发送。配置中的*Instructions Before User Input*会被放在你最后一个问题的开头，位于其正文之前。

模型与协议由配置决定（见下文），默认使用本书所用的模型与协议。对于关于故事的问题，通常一个便宜、快速的模型就已足够。

<a id="saved-queries"></a>

## 保存的查询

经常提出的问题可以保存：

- **Save prompt**（磁盘图标）将输入框中的文本保存到列表中所选的名称下，若未选择则会要求你输入名称；
- **Save prompt as...** 将其保存为一个新名称；
- 在列表中选择一个名称，即可将已保存的文本放入输入框；
- 垃圾桶按钮用于删除所选的已保存查询。

已保存的查询属于你的账户，在每本书中均可使用。

一些实用的示例：

- *列出目前为止出现过的所有具名角色，每人附一行简介。*
- *情节中仍有哪些线索未解决？*
- *为这个世界中的一个港口小镇提出五个名字。*

<a id="profiles"></a>

## 配置

侧边查询的设置位于 **Settings → Extension Settings → SideQuery Settings**，与[审阅器](reviewer.md#profiles)一样按**配置**组织。所选配置即为当前使用的配置：

![SideQuery 设置](../../images/plugin-sidequery-settings.png)

| 字段 | |
|---|---|
| **Profile**、**New**、**Rename**、**Delete** | 选择并管理配置。*_Default* 无法重命名或删除。 |
| **SideQuery Model**、**SideQuery Protocol** | 使用的[推理提供方](../inference-providers.md)与[协议](../protocols.md)。留空则使用本书的设置。 |
| **Initial System Query** | 系统消息的开头部分，例如助手的角色。 |
| **Instructions Before User Input** | 紧接在你最后一个问题之前放置的文本——回答的规则，例如*简要回答。可能时引用故事原文。* |
| **Enable AI Tab Naming** | 标签页中首次回答之后，模型会被要求为该对话生成一个简短名称（额外一次请求）。你重命名过的标签保留其名称。 |

点击*设置*页面顶部的**Save**以保存更改。

<a id="storage"></a>

## 存储

对话与书籍一同保存，因此它们是[书籍备份](../books/backups.md)与副本的一部分。配置和已保存的查询则存储在你的用户设置中。
