# 모델용 도구

일부 확장 기능은 모델에 **도구**를 제공합니다. 도구는 모델이 글을 쓰는 동안 호출할 수 있는 함수로, 이름을 얻거나 실제 장소를 찾아보는 데 쓰입니다. 모델이 이름이나 장소를 지어내는 대신 이 도구를 사용합니다. 한 확장 기능의 도구 묶음을 **도구 모음**이라고 하며, 현재 있는 도구 모음은 다음과 같습니다:

| 도구 모음 | 확장 기능 | 모델이 이것으로 할 수 있는 일 |
|---|---|---|
| Name generator | [Name generator](name-generator.md) | 범주(장소, 신, 한 나라의 성씨 등)에 어울리는 소리를 가진 지어낸 이름을 얻습니다. |
| Name provider | [Name provider](name-provider.md) | 원래 표기대로 된 실제 이름을 얻습니다. |
| Place provider | [Place provider](place-provider.md) | 실제 장소, 그 주변의 것들, 그리고 장소 사이의 거리를 찾아봅니다. |

도구를 사용하며 모델을 실행하는 대화상자에는 **도구** 버튼이 있습니다. 이 버튼이 있는 곳은 [Lore Generator](lore-generator.md)의 생성기와 [Arc Outline](arc-outline.md)의 생성기입니다(이야기 가져오기는 이미 이야기에 있는 이름을 사용하므로 제외됩니다). 이 버튼은 도구 모음이 하나 이상 설치되어 있을 때만 표시되며, 무언가를 선택해 두었다면 켜진 항목의 개수를 알려줍니다: **도구 (3)**.

<a id="choosing-the-tools"></a>

## 도구 고르기

**도구**를 누르면 도구 모음마다 하나씩 구획이 있는 창이 열립니다. 각 구획의 제목은 도구 모음의 이름이며, 그 옆에 선택된 항목 수가 표시됩니다. 선택된 항목이 있는 구획은 펼쳐진 상태로 시작합니다. 구획에 무엇이 있는지는 도구 모음에 따라 다릅니다:

- **항목**이 있는 도구 모음(Name generator와 Name provider는 범주나 이름 목록마다 항목이 있습니다)은 항목마다 체크박스가 있는 표를 보여 주며, 그 위에 **자체 필터 입력란**이 있습니다. 이름의 일부를 입력하면 일치하는 항목만 표시됩니다. 선택된 항목은 필터와 상관없이 표에 항상 남아 있습니다. **표시된 항목 선택**은 그 순간 표에 보이는 모든 항목을 선택하고, **표시된 항목 선택 해제**는 그 항목들을 선택 해제합니다. 아래 줄에는 선택된 항목이 몇 개인지 나타납니다. 모델은 선택된 항목만 받으며, 그 항목들을 나열하거나 그에 대한 이름을 요청할 수 있습니다. 그 밖의 항목은 받을 수 없습니다.
- **항목이 없는** 도구 모음(Place provider)은 켜거나 끌 수 있습니다: **이 도구 모음 사용**.

![Name generator의 범주를 "Japan"으로 필터링한 도구 창](../../images/tools-dialog.png)

모든 구획에는 **모델에 주는 힌트**도 있습니다. 이것은 모델이 도구 모음을 받을 때 프롬프트 끝에 덧붙는 짧은 글로, 도구를 언제 어떻게 쓸지 모델에 알려 줍니다(이름의 경우: 이름을 지어내지 말고 도구를 호출할 것, 받은 것 중에서 고를 것, 실제 이름은 받은 그대로 유지할 것). 기본 제공 문구는 입력란에 회색으로 표시됩니다. 직접 쓴 문구로 바꾸려면 입력란에 적고, 기본 문구를 쓰려면 입력란을 비워 두십시오.

![켜져 있고 모델에 주는 힌트가 펼쳐진 도구 모음, 나머지 두 구획은 접혀 있고 선택된 항목 수가 표시됨](../../images/tools-hint.png)

모델은 선택된 항목이 있는 도구 모음만 받습니다. 어느 도구 모음에도 선택된 항목이 없으면 모델은 도구를 받지 않습니다. 이 선택은 계정에 저장되므로 다음번에도 같습니다. Lore Generator는 생성한 항목마다 선택 내용을 함께 저장하며, 그 항목을 열 때 같은 선택으로 엽니다. 불러오기가 해제된 도구 모음은 건너뛰며, 확장 기능에 더 이상 없는 선택 항목은 무시합니다. 확장 기능은 Marginalia가 실행되는 동안에도 불러오거나 해제할 수 있으며, 버튼도 그에 맞춰 바뀝니다.

두 도구 모음에 같은 이름의 함수가 있으면 생성이 시작되지 않고 어느 것인지 알려 줍니다. Marginalia에 기본으로 들어 있는 도구 모음들은 이런 경우가 없습니다.

<a id="as-commands"></a>

## 명령으로

도구 모음은 [명령 막대](../commands/index.md)와 [에이전트](../agents.md)의 명령이기도 합니다(`/pick-real-names`, `/generate-names`, `/search-places` 등). 그래서 모델이 여기서 받는 것과 에이전트가 호출할 수 있는 것은 같은 이름의 같은 도구 모음입니다.

<a id="from-an-older-version"></a>

## 이전 버전에서

**Name tools** 버튼은 **도구**로 바뀌었습니다. 이전에 선택해 둔 범주는 Name generator와 Name provider의 도구 모음에서 선택된 상태로 유지됩니다. *설정 → 확장 기능 설정*에서 작성했던 힌트(*Name generator hint*, *Name provider hint*)는 이 창에서 해당 두 도구 모음의 모델용 힌트가 되었으며, 설정의 입력란은 없어졌습니다.
