# 書籍の説明文ジェネレーター

モデルに物語から書籍の**名前**と**説明文**を書かせます。物語のどの部分を読ませるかを選び、書かれた内容を書籍にコピーできます。

<a id="opening-it"></a>

## 開き方

拡張機能をインストールすると、書籍ウィンドウの **概要** タブの末尾に **名前と説明文を生成** ボタンが表示されます。[スマートフォン向けのレイアウト](../phone.md#extensions)でも使えます。ダイアログは左側に設定項目、右側に結果が表示されます。

![名前と説明文を生成するウィンドウ](../../images/plugin-book-description.png)

| 項目 | |
|---|---|
| **モデル**、**プロトコル** | 生成に使う設定です。書籍のモデルとプロトコルで始まり、なければ[アカウントと設定](../account.md)の **設定** にある既定値が使われます。この選択は今回の生成だけに適用されます。モデルが指定されていない場合は警告が表示されるだけです。 |
| **開始メッセージ**、**終了メッセージ** | 物語の範囲を、現在のブランチのうち本文のあるメッセージの番号で指定します。フィールドの下には各メッセージの冒頭が表示されるので、どのメッセージかを確認できます。初期値は物語全体です。 |
| **要約を使う** | 範囲内にすべて含まれている場合、[要約](../books/summaries.md)がそれに対応するメッセージの代わりに使われます。長い範囲を扱うときの負担を大きく減らせます。範囲の外に及ぶ要約や、もはや物語の内容と合わない要約は使われません（代わりにメッセージが使われます）。この設定は次回も記憶されます。 |
| **回答の形式** | *自動* は、モデルのサービスがスキーマ付きのJSONに対応していればそれを要求し、対応していなければMarkdownを要求します。*JSON* は必ずスキーマを指定します。*スキーマなしのJSON* は、スキーマとモデルの思考機能を同時に扱えないサーバー向けに、JSONの形式をプロンプト内で説明します。*Markdown* は、名前を最初の見出しとし、その下に説明文を書くよう求めます。モデルが何を書いても、JSONまたはMarkdownとして読み取られるため、指示を無視するモデルでも内容は理解されます。この設定は次回も記憶されます。 |

項目の下には、範囲がプロンプトを含めて何トークンになるか、モデルが何トークン受け取れるか、そして物語をそのまま送るか、先にメモにまとめる必要があるかが表示されるカウンターがあります。

**生成** でモデルを起動し、同じボタンで停止できます。名前と説明文は右側に表示され、それぞれに **書籍にコピー** ボタンがあります。これを押すと、概要タブのフィールドに文章が入り、書籍がすぐに保存されます（書籍ウィンドウのタイトルも変わります）。回答を名前と説明文として読み取れない場合は、ダイアログにモデルが書いた文章がそのまま表示されます。

<a id="a-story-that-is-too-long"></a>

## 長すぎる物語

範囲がモデルの受け取れる量を超える場合、物語は収まる大きさの部分に順番に分けられ、モデルがそれぞれの部分について**メモ**を書きます（メモは生成されるたびに *メモ* の下に表示されます）。説明文は物語ではなくメモから書かれます。まだ長すぎるメモはさらに分けて、もう一度メモにまとめられます。これは最大四回まで繰り返されます。部分より大きい1つのメッセージは、段落、行、または文の区切りで切られます。

!!!
モデルにもプロトコルにも文脈サイズが設定されていない場合、拡張機能は何が長すぎるのかを判断できないため、物語を常にそのまま送信します。
!!!

<a id="prompts"></a>

## プロンプト

プロンプトは2つあります。名前と説明文を書くプロンプトと、長い物語の一部分のメモを書くプロンプトです。これらは[継承される設定](../books/prompts.md#inherited-settings)です。書籍は自身の設定を使い、それがなければ設定を持つ一番近いフォルダーの設定を使い、それもなければ自分の設定、さらにそれもなければ組み込みの文章を使います。

| プロンプト | 変数 |
|---|---|
| **説明文のプロンプト** | `{{story}}`（物語、またはそれをまとめたメモ）、`{{fromNotes}}`、`{{bookName}}`、`{{bookDescription}}` |
| **メモのプロンプト** | `{{story}}`（部分）、`{{part}}`、`{{parts}}`、`{{bookName}}`、`{{bookDescription}}` |

書籍の *プロンプト* タブ、*拡張機能の設定* の下、フォルダーのダイアログ、またはすべての書籍に対して *設定 → 拡張機能の設定 → 書籍の説明文ジェネレーター* で設定できます。回答の書き方（JSONまたはMarkdown）を指示する文は、拡張機能が説明文のプロンプトの後に自動的に追加するため、プロンプトには何を書くかだけを書けば十分です。
