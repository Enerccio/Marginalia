# 빠른 시작

새로 설치한 상태에서 이야기의 첫 부분을 생성하기까지의 과정입니다. Marginalia가 이미
[설치](index.md)되어 있고 [관리자](first-start.md)로 로그인되어 있다고 가정합니다.

<a id="1-connect-a-model"></a>

## 1. 모델 연결하기

1. **추론 제공자** 탭을 열고 **추론 제공자 추가**를 클릭합니다.
2. **이름**을 입력합니다. 예: `OpenRouter - Claude`.
3. **일반 설정**에서 **최대 컨텍스트 크기**를 사용하는 모델의 컨텍스트 크기로 설정합니다. 예: `32000`. 그리고 **Max Reply Tokens**를 원하는 가장 긴 분량으로 설정합니다. 예: `2000`.
4. **유형별 설정**에 **OpenAI URL**(끝이 `/v1`로 끝나야 합니다)과 **API 키**를 입력합니다. 키가 없는 로컬 서버라면 비워 둡니다. **새로 고침**을 클릭한 뒤 **모델**을 고릅니다.
5. **확인**을 클릭합니다.

각 필드는 [추론 제공자](../inference-providers.md) 문서에 설명되어 있으며, 주요 서비스의 URL도 함께 나와 있습니다.

<a id="2-create-a-protocol"></a>

## 2. 프로토콜 만들기

1. **프로토콜** 탭을 열고 **프로토콜 추가**를 클릭합니다.
2. **이름**을 입력합니다. 예: `Default`.
3. **Max Context Tokens**와 **Max Reply Tokens**는 비워 둡니다. 이 경우 추론 제공자의 제한이 적용됩니다.
4. **확인**을 클릭합니다.

자세한 내용은 [프로토콜](../protocols.md)을 참고하세요.

<a id="3-set-the-defaults"></a>

## 3. 기본값 설정하기

**설정** 탭을 열고 **기본 모델**로 새로 만든 제공자를, **기본 프로토콜**로 새로 만든 프로토콜을 선택합니다. **저장**을 클릭합니다. 이후 새로 만드는 책에는 이 두 가지가 자동으로 설정되므로 매번 고를 필요가 없습니다.

![설정의 기본 모델과 프로토콜](../../images/settings-defaults.png)

<a id="4-create-a-book"></a>

## 4. 책 만들기

1. **책** 탭을 열고 **책 추가**를 클릭합니다.
2. 책의 이름을 입력합니다. 책이 열립니다.
3. **정보** 탭에서 **모델**과 **프로토콜**이 설정되어 있는지 확인합니다(기본값에서 가져온 값입니다). 원하면 이야기의 **설명**도 입력합니다.

<a id="5-write-the-first-part"></a>

## 5. 첫 부분 쓰기

1. **이야기** 탭을 엽니다.
2. 오른쪽 아래 모서리의 **+**를 클릭합니다. *새 턴 지시문* 패널이 열립니다.
3. **지시문**에 일어날 일을 설명합니다. 예:
   > 외딴 섬의 등대지기가 병에 담긴 편지를 발견한다. 편지는 그녀에게 보낸 것이며, 오십 년 뒤의 날짜가 적혀 있다. 그녀와 섬을 소개할 것. 약 800단어.

   *장면 배경*, *시점 인물*, *등장인물*은 선택 사항입니다. 모델에게 더 구체적인 방향을 주고 싶다면 입력합니다.
4. **생성**을 클릭합니다. 모델이 글을 쓰는 동안 텍스트가 나타납니다. (**+** 자리에 나타나는) 빨간색 **중지** 버튼을 누르면 생성이 멈춥니다.

![생성된 첫 부분](../../images/quick-start-first-part.png)

다음 부분을 쓰려면 **+**를 다시 클릭합니다. 각 부분은 메뉴(☰)에서 편집하거나, 다시 생성하거나, 다른 버전으로 넘겨 볼 수 있습니다. 자세한 내용은 [이야기 편집기](../books/story-editor.md)와 [분기 및 이야기 트리](../books/branches-and-story-tree.md)를 참고하세요.
