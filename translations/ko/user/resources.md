# 리소스

**리소스** 탭에는 Marginalia에 업로드한 파일 목록이 나타납니다. 여기에는 책의 파트에 붙은 [그림](books/story-editor.md#images)과, [Audiobook](extensions/audiobook.md) 같은 확장 기능이 함께 저장한 오디오가 포함됩니다. 이 탭에서는 파일을 다시 찾고, 오디오를 들어 보고, 내려받고, 그 파일을 쓰는 책은 건드리지 않은 채 더 나은 파일로 바꾸고, 더 이상 필요 없는 파일을 지울 수 있습니다.

![리소스 탭](../images/resources-tab.png)

파일은 어디에서 쓰이는지에 따라 묶여 있습니다. 표의 각 행은 하나의 객체(예: 책의 한 파트인 `ChatMessage #123`)를 나타내며, 그 객체의 파일 개수, 파일들의 총 크기, 가장 최근 파일의 날짜가 표시됩니다. 행의 화살표를 누르면 객체가 열리고 그 파일들을 볼 수 있습니다. 표는 스크롤하거나 그룹을 열 때마다 나누어 불러오므로, 파일이 수천 개여도 빠르게 동작합니다. 열 제목을 누르면 그 열을 기준으로 정렬되며, 그룹과 그 안의 파일도 함께 따라 정렬됩니다. 기본적으로는 가장 최근 파일이 맨 위에 옵니다.

| 행 / 열 | |
|---|---|
| **사용처** | 파일이 추가된 객체입니다. *없음*은 아무 곳에서도 쓰이지 않는 파일들을 묶습니다. 이름 뒤의 *(삭제됨)*은 객체가 삭제되었거나 더 이상 존재하지 않는다는 뜻이며, 이 파일들은 아마 더 이상 필요하지 않습니다. 그룹 안에서는 그림의 작은 미리 보기와 업로드된 그대로의 파일 이름이 표시됩니다. |
| **유형** | 파일의 유형입니다(예: `image/png`). |
| **크기** | 파일의 크기이며, 그룹의 경우 그 안에 있는 파일들의 합계입니다. |
| **생성됨** | 파일이 업로드된 시점이며, 그룹의 경우 가장 최근 파일의 시점입니다. |

이 표시는 참고용 메모일 뿐입니다. Marginalia는 이를 강제하지 않습니다. 그림은 파트가 사라진 뒤에도 계속 동작하며, 같은 그림을 여러 파트가 쓸 수도 있습니다(예를 들어 이야기를 [분기](books/branches-and-story-tree.md)하면, 새 가지는 원래 파트와 같은 그림을 갖게 됩니다).

<a id="play"></a>

## 재생

오디오 유형(`audio/mpeg`, `audio/wav`...) 파일의 행에는 다른 버튼들보다 앞에 **재생** 버튼(삼각형)이 있습니다. 이 버튼을 누르면 페이지 안에서 파일이 재생됩니다. 재생 중에는 버튼이 **일시 정지**로 바뀌고, 멈추거나 오디오가 끝나면 다시 재생 버튼으로 돌아갑니다. 한 번에 한 파일만 재생됩니다. 다른 파일을 재생하면 지금 재생 중인 파일은 멈춥니다.

<a id="download"></a>

## 내려받기

행의 내려받기 버튼(아래 화살표)을 누르면 파일이 컴퓨터에 저장됩니다.

<a id="replace-the-content"></a>

## 내용 바꾸기

행의 업로드 버튼을 누르면 새 파일을 고를 수 있는 대화상자가 열립니다. 새 내용은 새 파일로 저장되고 항목은 이제 그 파일을 가리키므로, **그 항목을 사용하는 모든 곳에 새 내용이 나타납니다**. 파트를 일일이 고칠 필요는 없습니다. 그림을 더 나은 버전으로 바꾸거나 잘못 업로드한 파일을 고칠 때 사용하세요.

- 그림은 그림 파일(PNG, JPEG, GIF 또는 WebP, 10 MB 이하)로만 바꿀 수 있습니다. [그림 추가](books/story-editor.md#images)와 같은 조건입니다.
- 항목의 이름은 새 파일의 이름이 됩니다.
- 이전 파일은 데이터 폴더에서 삭제되지 않습니다. [아래](#what-delete-does)를 참고하세요.

![리소스 내용 바꾸기](../images/resources-replace.png)

<a id="deleting"></a>

## 삭제

행의 휴지통 버튼은 파일 하나를 삭제합니다. 여러 파일을 삭제하려면 첫 번째 열에서 여러 항목을 체크한 뒤, 표 위의 **선택 항목 삭제**를 누르세요. 그룹(객체의 행)을 체크하면 그 그룹의 모든 파일이 삭제됩니다. 머리글의 체크박스는 모든 그룹을 선택합니다. Marginalia는 삭제하기 전에 확인을 요청합니다.

<a id="what-delete-does"></a>

### 삭제가 하는 일

- 파일은 표에서 사라지고, 그 파일을 쓰던 파트에서도 사라집니다. 파트에는 그림이 더 이상 표시되지 않습니다. 파트의 본문, 요약, 내보내기 결과는 바뀌지 않습니다.
- 항목은 **삭제됨으로 표시**될 뿐입니다. 관리 메뉴의 [정리](administration/cleanup.md)가 이를 데이터베이스에서 영구히 제거합니다.
- **파일은 데이터 폴더(`data/<your login>/images`)에 그대로 남습니다.** 정리 후에도 마찬가지입니다. 리소스를 삭제한다고 해서 디스크 공간이 자동으로 확보되지는 않습니다. 관리자는 관리 메뉴의 [리소스 파일](administration/resource-files.md) 탭에서 아무도 쓰지 않는 파일을 제거할 수 있습니다.
- 정리가 항목을 제거하기 전까지는 [휴지통](trash.md)에서 되살릴 수 있습니다. 파일이 아직 데이터 폴더에 있으므로 그림은 다시 동작합니다. 정리 후에는 그 전에 만들어 둔 [데이터베이스 전체 백업](administration/database-backups.md)에만 항목이 남아 있고, 파일 자체는 여전히 폴더에 있습니다.
