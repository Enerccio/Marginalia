# 发布与阅读器

**阅读器**是书籍的阅读视图，只显示故事的正文，不包含编辑器界面。它在手机和平板上也很好用。**发布**一本书后，同一个 Marginalia 安装实例的其他用户就可以在阅读器中阅读它。

<a id="opening-the-viewer"></a>

## 打开阅读器

阅读器位于 Marginalia 地址的 `/view` 路径下，例如：

- 桌面应用：`http://127.0.0.1:8765/view`
- 服务器：`https://marginalia.example.com/view`

阅读器使用与 Marginalia 相同的登录方式。

![阅读器的书籍列表](../../images/viewer-list.png)

列表显示你的书籍，以及它们的标签和你最后一次打开它们的时间。你可以按 **Name**（名称以指定文字开头的书籍）和 **Tags**（同时带有所选全部标签的书籍）进行筛选。可以按 **Last Opened** 或 **Name** 排序；再次点击当前生效的排序按钮，可以反转顺序。

点击一本书即可开始阅读。

<a id="folders-in-the-list"></a>

### 列表中的文件夹

列表会像工作区的手机版列表一样显示你的[文件夹](folders.md)：文件夹排在前面，每个文件夹下方标注其中的书籍数量，之后是当前文件夹中的书籍。点击文件夹即可进入。筛选条件上方的路径（`Books / Novels / Portal fantasy`）显示你当前所在的位置，点击路径中的任一部分即可返回该位置。

![阅读器中的文件夹](../../images/viewer-folder.png)

- **Include subfolders** 会列出当前文件夹下方所有层级的书籍，并在每本书的名称下显示其所在的文件夹。
- **Favorites** 是顶层中存在收藏书籍时才会出现的文件夹，会列出所有文件夹中的收藏书籍。收藏是在[书籍列表](folders.md#favorites)中设置的，而不是在阅读器中。
- 筛选条件作用于当前文件夹（勾选 *Include subfolders* 时则包括其下的子文件夹），因此若要搜索全部书籍，请回到顶层并勾选该选项。**Last Opened** 会按文件夹的最后修改时间排序。
- 阅读器会在你上次离开的文件夹中打开：读完一本书后，箭头会带你回到同一个文件夹，下次访问或刷新页面时也会从那里开始。该位置保存在浏览器的 Cookie（`marginalia_viewer_folder`）中，服务器不会保存它，因此换一个浏览器会从顶层开始。若某个文件夹已被删除，则回到顶层。

<a id="reading"></a>

## 阅读

阅读视图显示书籍的[当前分支](branches-and-story-tree.md)，从第一部分到最后一部分，采用书籍阅读样式（两端对齐，并根据书籍的[语言](managing-books.md#the-about-tab)进行断字）。其他分支、转向指令和元数据都不会显示。左上角的箭头按钮可返回列表。

右上角的圆形按钮会打开一个**文字样式**菜单，供你选择阅读样式：*Normal* 和 *Book* 样式，以及你在[设置 → Styles](../account.md#styles)中创建的样式（已勾选的样式即为当前使用的样式；在你做出选择前，默认使用 Book 样式）。菜单中只提供你自己的样式，即使是在其他用户发布的书籍中也是如此：作者写作时使用的样式不会传递给读者。你的选择保存在浏览器的 Cookie（`marginalia_reader_style`）中，因此对你在该浏览器中阅读的每本书都有效，服务器不会保存它；如果该样式不属于你（例如同一浏览器中登录了另一位用户），则会被忽略。

![阅读器中的样式菜单](../../images/viewer-style-menu.png)

![阅读一本书](../../images/viewer-reading.png)

你读到的是书籍的当前内容：新增的部分会在下次打开页面时出现。

长篇书籍会分段加载：显示的是你所在位置前后的部分，向下滚动时会加载后面（或前面）的部分，离你较远的部分则会被丢弃。如果你滚动得比加载速度还快，页面边缘会出现 *Loading* 标记。同一时间加载的部分数量不会超过[你的账户](../account.md)中 **Parts loaded at once in the story** 设置的值；若该项为空，则一次加载整本书。

阅读器会记住你在每本书中停止阅读的位置，下次打开这本书时会直接定位到该部分。该位置只保存在你浏览器的本地存储中（按书籍分别记录），不会保存到服务器上，因此换一个浏览器或清除了浏览器存储后，会从头开始。

[部分中的图片](story-editor.md#images)会显示在作者放置它们的位置（默认在文字之后，除非作者选择了其他位置）。它们会显示给你，以及[已发布](#publishing-a-book)书籍的读者，除非你在书籍的 *About* 标签页中取消勾选 **Show the images to readers**（默认是勾选的）。取消勾选后，读者看到的将只有文字，没有图片。只有在书籍处于发布状态时，图片才会从你的账户中读取；取消发布后则不再读取。

<a id="publishing-a-book"></a>

## 发布书籍

默认情况下，只有你自己能在阅读器中打开你的书籍。若要让其他用户阅读某本书：

1. 打开该书，并在其 *About* 标签页中勾选 **Published**。
2. 复制出现在 *About* 标签页复选框下方的阅读链接。该链接由你的安装实例地址（如果 Marginalia 不是部署在根路径下，还包括其上下文路径）加上 `/view/` 和书籍的 ID 组成：`<Marginalia 的地址>/view/<书籍 ID>`。在 Docker 中，Marginalia 作为根应用运行，链接形如 `https://marginalia.example.com/view/0b6f3c1e-...`；如果它部署在 `/marginalia` 这类上下文路径下，链接则为 `https://example.com/marginalia/view/0b6f3c1e-...`。（当书籍在阅读器中打开时，你也可以从浏览器的地址栏复制同样的地址。）
3. 将该地址发送给其他用户。

其他用户需要在同一个 Marginalia 安装实例上拥有账户，登录后即可看到这本书。已发布的书籍不会出现在他们的阅读器列表中，只有通过地址才能打开。他们只能阅读这本书，无法修改它。

发布时会按书籍当前的状态共享：只共享各部分的文字，部分中的图片仍然保持私有。

取消勾选 **Published** 即可停止共享：此后，除你之外的所有人访问该地址都会看到 *Book not found*。已删除的书籍则完全无法打开。
