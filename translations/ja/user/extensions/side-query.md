# サイドクエリ

ストーリーの横で使えるモデルとのチャットです。プロットについて尋ねたり、設定の整合性を確認したり、名前や次の章のアイデアを出し合ったりできます。本そのものには何も追加されません。

!!!
サイドクエリは[フォンレイアウト](../phone.md#extensions)で使えます。そのタブはストーリーのアウトline ドロワーにあります。
!!!

![ストーリーの横に表示されたサイドクエリ](../../images/plugin-sidequery.png)

<a id="the-side-query-tab"></a>

## サイドクエリタブ

[ストーリーエディタ](../books/story-editor.md)の左サイドバーには、*Outline* の隣に**サイドクエリ**タブが追加されます。区切り線をドラッグすると、表示領域を広げられます。

このタブには会話が入ります。それぞれの会話は独自のタブを持ちます。**+** で新しい会話を開きます（*Tab 2*、*Tab 3*...）。鉛筆アイコンでタブの名前を変更し、**×** で閉じます（最後のタブは閉じられません）。プロフィールで *Enable AI Tab Naming* を有効にしていると、タブ名を自分で変更していない限り、モデルが最初の回答のあとに会話に名前を付けます。会話は本に紐づき、タブを閉じるまで保存されます。

<a id="asking"></a>

## 質問する

画面下部の入力欄に質問を入力し、**SEND** をクリックします。回答は書かれたとおりに表示されます。*SEND* の代わりに表示される **STOP** で回答を中断できます。

| ボタン | |
|---|---|
| **SEND** | 質問を送信します。 |
| **UNDO** | 最後のメッセージを削除します。それが自分の質問だった場合は、編集できるよう入力欄に戻ります。 |
| **REGENERATE** | 最後の回答を削除し、もう一度質問します。 |

各メッセージには、上下に**移動**する、**編集**する、クリップボードに**コピー**する、コンテキストから**除外**する（または再び含める）ボタンがあります。除外されたメッセージは会話に残りますが、モデルには送信されません。誤った回答を削除せずに取り除きたいときに便利です。

<a id="what-the-model-sees"></a>

## モデルが見る内容

会話の上にあるオプションで、質問とともに送信する内容を選べます。

| オプション | |
|---|---|
| **Lorebook** | 本のロア（下記参照）。 |
| **Chat Logs** *from* … *to* | アクティブなブランチのストーリーパートのうち、指定範囲のもの。アウトラインと同じく1から番号が振られ、`1` から `6` は `#1` から `#6` のパートを指します。 |
| **プラグボタン** | 他の拡張機能が提供するデータの一覧を開きます。それぞれにチェックボックスがあります（下記参照）。 |
| **Tokens** | リクエストのおおよそのサイズ。 |

!!!
*Lorebook* は、生成時と同じように設定を集めます。本のロアブックとそのサブロアブックを対象にし（無効なロアブックは除外）、本のタグと一致する有効なエントリを含め、[マクロ](../templates/macros.md)を処理します。キーワードフィルタは適用されません。照合するストーリープロンプトがないため、該当するエントリはすべて送信されます。エントリによって設定された変数は保存されません。
!!!

<a id="data-of-other-extensions"></a>

### 他の拡張機能のデータ

プラグボタンを押すと、他の拡張機能が提供する**追加のソース**を示すポップオーバーが開きます。たとえば [Arc Outline](arc-outline.md) は、あなたのアウトラインを提供します。ソースごとにチェックボックスがあり、一覧は最大2つの部分に分かれます。

- **本について**: チェックされたソースは、ロアブックの後ろに、その名前の下で、リクエストに追加されます。
- **ストーリーパートについて**: チェックされたソースは *Chat Logs* の範囲にあるストーリーパートごとに問い合わせられ、返された内容がそのパートのテキストの後ろに追加されます。これは *Chat Logs* がオンのときにのみ働きます。

このチェックの選択はタブごとに保存されます。拡張機能がインストールされていない（または停止している）場合、そのソースは一覧に表示されず送信もされません。拡張機能が再び動くと、ソースも戻ってきます。提供されるソースが一つもない場合は、ポップオーバーにその旨が表示されます。

リクエストは次のように組み立てられます。

1. ひとつのシステムメッセージ：プロフィールの *Initial System Query*、ロアブックのエントリ（*Lorebook Context*）、本とストーリーパートについてチェックされたソース（*Chat History Context*。アウトラインの番号 *Message #1*、*#2*... を付けて、それぞれの後ろにストーリーパートについてチェックされたソースが続く）。
2. 含まれている会話のメッセージを、チャットとして。プロフィールの *Instructions Before User Input* は、最後の質問の本文の前、その先頭に置かれます。

モデルとプロトコルはプロフィール（下記参照）から取得され、既定では本の設定が使われます。ストーリーに関する質問なら、通常は安価で高速なモデルで十分です。

<a id="saved-queries"></a>

## 保存したクエリ

よく使う質問は保存しておけます。

- **Save prompt**（フロッピーアイコン）は、入力欄の文章を一覧で選ばれている名前で保存します。名前が未選択の場合は、名前を尋ねられます。
- **Save prompt as...** は、入力欄の文章を新しい名前で保存します。
- 一覧で名前を選ぶと、保存された文章が入力欄に入ります。
- ゴミ箱ボタンは、選択中の保存済みクエリを削除します。

保存済みクエリはあなたのアカウントに属し、どの本でも使えます。

役に立つ例：

- *これまでに登場した名前のあるキャラクターを、それぞれ一行ずつの説明付きで挙げてください。*
- *プロットでまだ解決していない伏線は何ですか？*
- *この世界の港町の名前を五つ提案してください。*

<a id="profiles"></a>

## プロフィール

サイドクエリの設定は **設定 → 拡張機能の設定 → SideQuery Settings** にあり、[Reviewer](reviewer.md#profiles)と同様に**プロフィール**単位で管理されます。選択中のプロフィールが使われます。

![SideQuery の設定](../../images/plugin-sidequery-settings.png)

| 項目 | |
|---|---|
| **Profile**、**New**、**名前を変更**、**削除** | プロフィールを選択・管理します。*_Default* は名前の変更も削除もできません。 |
| **SideQuery Model**、**SideQuery Protocol** | 使用する[推論プロバイダ](../inference-providers.md)と[プロトコル](../protocols.md)。空欄の場合は本の設定を使います。 |
| **Initial System Query** | システムメッセージの冒頭。たとえばアシスタントの役割。 |
| **Instructions Before User Input** | 最後の質問の直前に置かれる文章。回答のルール（例：*簡潔に答えてください。可能な場合は物語を引用してください。*）。 |
| **Enable AI Tab Naming** | タブで最初の回答が終わると、モデルに会話の短い名前を求めます（追加で一回リクエストします）。名前を変更したタブはその名前を保ちます。 |

変更を保存するには、*設定* ページ上部の **保存** をクリックします。

<a id="storage"></a>

## 保存先

会話は本とともに保存されるため、[本のバックアップ](../books/backups.md)やコピーにも含まれます。プロフィールと保存済みクエリは、ユーザー設定に保存されます。
