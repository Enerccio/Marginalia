# はじめに

Marginaliaはブラウザで動作します。インストール方法は次の2通りです。

| | [デスクトップアプリ](desktop-app.md) | [サーバー（Docker）](docker-server.md) |
|---|---|---|
| 向いている用途 | 1台のコンピューターを1人で使う | 複数のユーザー、または別の端末からのアクセス |
| インストール | ダウンロードして実行するだけで、他に何も入れる必要はありません | DockerとDocker Compose |
| アドレス | `http://127.0.0.1:8765`（お使いのコンピューターからのみ） | ポート`8080`。通常はHTTPSを使うリバースプロキシの背後に置きます |
| データ | `~/.marginalia` | `docker-compose.yml`の隣にある`./data` |

どちらのバージョンも同じアプリケーションで、機能（本、ロアブック、ユーザー、バックアップ、拡張機能）も同じです。
スマートフォンから書きたい場合は、サーバー版を起動し、スマートフォンのブラウザで開いてください。詳しくは
[スマートフォンでMarginaliaを使う](../phone.md)を参照してください。

Marginalia自体にはモデルがありません。文章を書くには**OpenAI互換のAPI**が必要です。クラウドサービス（OpenAI、
OpenRouterなど）か、お使いのコンピューター上で動くモデル（llama.cpp、LM Studio、Ollama、vLLMなど）を利用できます。
APIのアドレスと、APIキーを用意してください（キーが不要なローカルサーバーであれば、キーなしで動作します。[プロバイダーの追加](../inference-providers.md#adding-a-provider)を参照）。

<a id="steps"></a>

## 手順

1. Marginaliaをインストールします：[デスクトップアプリ](desktop-app.md)または[サーバー](docker-server.md)。
2. 初回起動時に[管理者アカウントを作成](first-start.md)します。
3. [クイックスタート](quick-start.md)に従って、モデルを接続し、プロトコルを作成して、本の最初の部分を書きます。
4. 任意：[サンプルの本](example-book.md)を開きます。要約、注釈、翻訳を備えた完成した物語で、長い本がどのようなものかを確認できます。
