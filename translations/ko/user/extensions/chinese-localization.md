# 중국어 현지화

사용자 인터페이스의 언어에 간체 중국어(中文（简体）)를 추가합니다.

<a id="using-it"></a>

## 사용 방법

관리자가 확장 기능을 불러오면([확장 기능 관리](../administration/extensions.md)), 작업 공간 하단의 **언어** 선택기에 *中文（简体）*가 나타납니다([휴대폰](../phone.md)에서는 메뉴 안에 있습니다). 영어, 일본어와 나란히 표시됩니다. 이를 선택하면 페이지가 다시 로드되어 중국어로 표시됩니다. 선택한 언어는 계정에 저장되므로, 로그인하는 모든 기기에서 같이 사용됩니다. 언어는 사용자마다 따로 선택합니다.

![중국어로 표시된 스토리 편집기](../../images/plugin-chineselocalization.png)

인터페이스 전체가 번역됩니다. 메뉴, 버튼, 메시지, 템플릿 변수와 매크로의 설명이 해당됩니다. 아직 중국어 번역이 없는 텍스트는 영어로 표시됩니다.

이 확장 기능은 설정의 **프롬프트 언어**(*설정 → 템플릿*, [프롬프트 언어](../account.md#prompt-language) 참고)에도 중국어를 추가합니다. 그러면 애플리케이션과 플러그인에 내장된 프롬프트가 중국어로 모델에 전송됩니다. 이 설정은 인터페이스 언어와 별개로 고를 수 있습니다. 작성한 책, 로어북, 직접 쓴 프롬프트는 변경되지 않습니다.

<a id="removing-it"></a>

## 제거하기

확장 기능을 해제하면 인터페이스와 프롬프트에서 중국어 선택이 사라집니다. 중국어를 선택했던 사용자는 다른 언어를 고를 때까지 영어로 보고, 영어로 입력하여 보냅니다. 선택 내용은 유지되며, 확장 기능을 다시 불러오면 다시 적용됩니다.

<a id="for-developers"></a>

## 개발자용

이 확장 기능은 언어를 추가하는 예시입니다. 자세한 내용은 [예제 플러그인 → 중국어 현지화](../../developer/plugins/example.md#walkthrough-chinese-localization)를 참고하십시오.
