# 真实语言翻译器

让故事中的角色说一种**真实存在的语言**：设定在日本的故事可以由你和模型用英文撰写，角色的直接对话则会变成地道的日语（假名和汉字，或罗马字），其背后保留英文原文。它就是用于现有语言的[构造语言翻译器](conlang-translator.md)：思路相同，界面相同，只是不需要词典。

!!!
故事正文保存的是**译文**。所有把故事交给模型阅读的东西（下一段生成、摘要、设定集扫描、批注、其他扩展）读取的都是对话翻译前的**英文**，因此你应当用英文撰写和引导故事。点击译出的对话即可看到英文。
!!!

!!!warning 开发中
按段落、范围和句子进行翻译，设置、书籍的标签页、阅读器、导出以及[命令](#commands)均已可用。以下功能尚未提供，参见[限制](#limits)：对译文的第二遍润色、一本书中的多种真实语言，以及为每个角色指定一种语言。
!!!

<a id="the-idea"></a>

## 基本思路

1. **语言**是交给翻译器的一组简短规则：**文字**形式（假名与汉字、纯假名、罗马字）、人名是否写出**敬称后缀**、**说话的礼貌等级**如何根据说话人与听话人的关系选定、**人名**如何书写，以及你希望遵守的其他任何内容。模型本身已经掌握该语言，因此不需要词典。语言只需在设置中保存一次，任意数量的书籍都可以使用。
2. **书籍**（或书籍所在的文件夹）选定其语言。段落可以从其菜单中**手动**翻译，可以在定稿后**自动**翻译，也可以**按范围**逐批翻译。
3. 每个段落向模型发出一次请求，对每一段直接对话进行分类（这句话是由该角色用这种语言说的，还是用英文说的，听话人能否听懂？），并把属于该语言的对话，按照角色的语气以及人物关系所要求的说话等级进行翻译。
4. 英文会作为对话的*原文*保存在书籍数据中，并被每个模型读取。译文即为正本：你手动修改的内容会被保留，你编辑过的段落也绝不会在你不知情的情况下被覆盖。

扩展会免费检查能够检查的内容：引用的对话必须出现在段落中，语言必须是本书所用的语言，译文必须采用你所要求的**文字**形式（罗马字译文中含有汉字，或纯假名译文中含有汉字，都会被保留并*报告*）。它无法检查日语本身的正确性：在进行长时间运行之前，请先通读几个段落。

## 语言

语言在 **Settings → Extension Settings → Real Language Translator** 中编辑。

| 按钮 | |
|---|---|
| **Add** | 新建语言。它以某个**预设**开始（日语假名与汉字版、纯假名版、罗马字版，或其他语言），预设会自动填入各字段；你可以随意修改。 |
| **Edit**、**Delete**、**Move up**、**Move down** | 所选语言。删除时会弹出确认。 |
| **Duplicate** | 独立的副本，并使用新名称。选定某语言的书籍会与其他同样选定该语言的所有书籍共享它；如果想为某一本书保留一套语言，可以复制一份。 |

编辑器包含以下字段：

![设置中的语言列表](../../images/plugin-reallang-settings.png)

| 字段 | |
|---|---|
| **Name** | 你给它起的名称（例如"日语，小说用罗马字"）。 |
| **The language as the model names it** | 模型在称呼该语言时所用的词（例如"Japanese"）；留空则使用名称。 |
| **Script** | *假名与汉字*、*仅假名*、*罗马字（拉丁字母）*，或*其他文字（不检查）*。 |
| **Write the honorific suffixes of names** | 人名是否写出敬称后缀：san、sama、kun……|
| **Also write how it is read (romaji)** | 同时写出译文的读音（罗马字）；弹出框会将其显示在英文之上。 |
| **Politeness and speech level**、**Names of people and places**、**Other rules** | 写给翻译器的简短说明。日语预设为前两项提供了文字（亲近的同辈之间使用普通体，与陌生人交谈使用敬体，对上级使用敬语；外国人名用片假名书写）。 |

## 为书籍选择语言

书籍窗口中 **Prompts** 标签页下的 *Extension Settings* 部分包含该扩展的字段；文件夹窗口也有相同的字段。留空即表示*继承*：先取上一级文件夹的设置，再取你的全局设置。

| 字段 | |
|---|---|
| **Language of the speech** | 书籍译入的语言。留空则该书不进行翻译。 |
| **Translate a new part by itself** | 段落定稿时自动翻译：生成之后，若书籍设有自动批注与重写，则在其之后，作为[段落后续操作](../books/story-editor.md#what-follows-a-generated-part)中的一个步骤执行（运行面板会显示该步骤，点击其 **Stop** 即可停止）。 |
| **Model of the translation**、**Protocol of the translation** | 留空时使用书籍的模型和协议，否则使用你的默认设置。 |
| **Readers of the published book see** | [阅读器](#what-the-reader-sees)所显示的内容。 |

## 书籍中的 Real language 标签页

故事窗口中有一个 **Real language** 标签页（与章节和设定集位于同一个停靠区），用于设置*本书*的语言；点击 **Refresh** 可重新读取。

![故事的 Real language 标签页，包括说话者及其理解程度](../../images/plugin-reallang-tab.png)

**说话者。** 在*本书中*由谁说这种语言（含有[多种语言](#more-than-one-language-in-a-book)的书籍，每种语言各有一个 *Speakers* 标签页）。默认情况下，除列出的角色之外，所有人都说这种语言（或仅列出的角色说这种语言）。正文可以覆盖此设置（例如"她用英语说"、"卫兵一个字也听不懂"）。为每个角色注明**性别**和**语气**：说话的礼貌等级将依此而定。在此处写下年龄、身份以及该角色与他人的说话方式（例如"年轻的军官，对上级有礼，对朋友直率"）：这正是翻译器在普通体与敬语之间做选择的依据。说话者属于本书。

每个角色还可以设定**理解程度**：*完全听不懂*、*只懂几个词*、*大部分能听懂*或*全部听懂*。留空（或选*全部听懂*）则不向模型提供任何说明。可用于那些听得懂该语言却不会说的人：*Tomáš：完全听不懂（日语）*、*其他村民：大部分能听懂*（名字只是文字，因此可以写一个群体）。这些等级在整本书中**保持不变**，作为信息提供给模型；角色如何应对，由模型自行决定，你也可以随时在指令中说明（例如"Tomáš 听不懂他们在说什么"）。它们以两种方式传达给模型：**故事模型**会收到一条包含这些等级的简短消息（像作者注释一样插入提示词中；列表上方的复选框可关闭此功能，数字表示从末尾往前数的消息条数）；而**审阅段落的模型**（*Annotate with AI*）则会将其作为事实部分的一节收到，因此它能标出对听不懂的话语做出反应的角色。如果你想自行安排这段文字的位置，可以关闭自动插入，并在模板中使用 {%{`{{command::reallang-understanding}}`}%} [宏](../templates/macros.md#commands)；它可以接受一个可选的角色列表，用于保留指定的角色。

**Languages。** 本书中除 **Language of the speech** 字段所指定语言之外的其他语言：参见[下文](#more-than-one-language-in-a-book)。

**Quick translate。** 用英文写一段文字，可选择注明由谁说、对谁说，然后点击 **Translate**：模型会依据该语言的规则进行翻译（若有多种语言，请选择其中一种）。不会写入故事；你需要自行复制译文。

**Glossary。** 故事中的人名和专有词汇在该语言中的书写方式（参见[下文一节](#the-glossary-of-names-and-special-words)）；本书的每种语言各有一个 *Glossary* 标签页。
<a id="the-glossary-of-names-and-special-words"></a>

## 术语表

如果没有术语表，同一个名字在不同部分中的写法就会不一致：`Saellen` 一处写成 `サエレン`，另一处又保留拉丁字母；`Tomáš` 一会儿变成 `トマーシュ`，一会儿变成 `トマシュ`。术语表把选择固定下来，只需确定一次。每个条目包括：

- **词条**，即故事中的写法（`Saellen`、`witch`），是条目的键，不区分大小写；
- **在译文中的写法**（`サエレン`、`魔女`），如果是标题、地名或不译的自造词，则写*保持原样*；
- **读音**（可选，适用于有读音的语言，如 `魔女` 读作 `ウィッチ`）以及给译者的**备注**（比如角色应使用的敬称、姓氏的排列顺序）；
- 该条目**是否生效**。

**三级合并。** 一种语言的术语表分为三级：**语言**级（在该语言的编辑器中设置，位于*设置 → 扩展设置*，适用于这种语言的所有书籍）、书籍所在的**文件夹**（系列作品可以为其中各书共用的名字定义统一写法；文件夹可以嵌套），以及**书籍**级（书籍自己的术语，使用最频繁）。模型拿到的是三级的并集；对于同一个词，**离书籍最近的一级优先**。因此，一本书可以采用与其文件夹不同的写法。*真实语言*标签页中的*术语表*标签会显示所有条目以及每个条目来自哪一级，并允许在条目所在的层级修改它。如果某个较高层级的词不应用于本书，可以在本书中**将其关闭**（在书籍层级建立一个处于关闭状态的条目；重新开启的方法相同，或直接删除该条目，即可恢复上级的词）。当某个书籍条目变得通用时，可以将其**上移**到文件夹或语言级别。文件夹和书籍的术语表**按语言分别保存**，因为同一个名字在每种语言中的写法各不相同。

**翻译时如何使用术语表。** 术语表是请求的一部分，因此模型会按列表中的写法书写这些词。不超过 100 个条目的术语表会完整地随每次请求发送（支持提示缓存的服务器只需读取一次）；更大的术语表则只随本部分用到的条目发送。译文生成后，插件会对其进行**检查**：如果某句台词的英文含有术语表中的词，而译文的写法与术语表不一致，该句会被保留并**报告**，由作者决定如何处理。如果模型不得不为某个名字选择书写形式，而术语表中并没有该名字，则会作为**提议**添加到本书的术语表中（*状态*列显示*已提议*）：此后模型会使用这一写法；点击*接受*表示你已审阅，点击*编辑*则可以修改。任何级别已有的词（即使是关闭状态）都不会再次被提议。

<a id="extracting-the-words-by-model"></a>

## 由模型提取词汇

对于长篇书籍，手动编写术语表非常耗时。*真实语言*标签页中术语表标签旁边的**词汇提取**标签页，可以让模型阅读一个**部分范围**，列出其中找到的名字和特殊词语，以及每个词在目标语言中的写法。所有术语表中尚不存在的发现结果，都会作为**提议**添加到本书的术语表中：模型从下一次请求起开始使用这些词；你可以在*术语表*标签中接受、编辑或删除它们。故事正文不会因此改变。

![运行后的词汇提取标签页：模型找到的术语以提议形式出现在术语表中](../../images/plugin-reallang-extraction.png)

- **语言。** 如果书籍包含多种语言，此处选择术语表所对应的语言。
- **提示词。** 给模型的指令：要寻找什么，以及每类词在该语言中应如何书写。可从库中选择，或选择*无：仅使用我的说明*。插件自带一个日语提示词（现实世界中的地点和组织使用其通用日文形式，虚构的外来名字用片假名，日本人名用汉字并标注读音，世界观中的自造词用汉字并标注片假名读音，即*议训*）；它标记为*内置*，始终可用。
- **说明。** 仅针对*本书*的自由文本，附加在提示词之后：可以指定忽略哪些内容（如次要角色）、本书中某类词的写法，或你希望采用的拼写。如果没有提示词，这就是模型得到的全部指示。
- **起始部分 / 结束部分**，然后点击**提取词汇**。各部分按顺序读取（每个部分可能需要慢速模型花费数分钟），标签页会显示*第 3 部分，共 12 部分*；点击**停止**会在当前正在读取的部分完成后停止。某个部分失败时会被计数，运行继续进行；如果书籍没有语言、没有模型，或既没有提示词也没有说明，运行将结束。

术语表中已有的词（任何级别，即使是关闭状态）会告知模型，不会再次被提议，因此对同一范围的第二次运行只会添加新出现的词。模型为某个术语归入的*类别*（如“虚构自造词 / 议训”）会写入该条目的备注中。你无需描述输出格式：无论提示词如何写，插件都要求固定的格式。

**提示词库。** *设置 → 扩展设置 → Real Language Translator* 中有**提取提示词**列表：你自己的提示词，每个都有名称和指令，可以添加、编辑、删除和调整顺序。**复制内置提示词**会将内置提示词的副本放入你的列表中以便修改。提示词属于你，而非某本书；书籍会记住它选用的提示词及其说明。

![设置中的提取提示词库](../../images/plugin-reallang-prompts.png)

## 一本书中的多种语言

包含日语和韩语使用者的故事需要两种语言。一本书会先指定**一种首要语言**（上方的字段，文件夹或你的设置也可以指定），然后**语言**标签页可以从你的库中逐个**添加其他语言**，也可以再将其移除。

- **每种语言都有自己的说话人**，各自位于独立的标签页中。首要语言由除你列出的角色以外的所有人使用，与之前相同；**你新添加的语言一开始处于“仅列出的角色使用”的状态，且尚未列出任何人**，因此在你列出说话人之前，它不会被要求翻译任何内容。当某角色的母语不是首要语言时，请将其列为首要语言的例外；否则，首要语言也会被要求翻译该角色的台词（若某句台词同时被两种语言认领，则归属于先被请求的那一种）。一个角色可以使用多种语言（在两种语言中都列出他们即可；部分文本会告诉模型某句台词使用的是哪种语言）。
- **每种语言发出一次请求**：只包含该语言的规则和备注，以及其说话人的台词。包含两种语言台词的部分需要依次发出两次请求；第二次请求读取的是第一次请求处理后的部分（其中第一种语言的台词已译出），并保持这些台词的译文不变。如果某部分的视角角色和在场角色都不属于某语言的说话人，则不会为该语言发出请求（未指明任何角色的部分，会为每种有说话人的语言发出请求）。
- **文本记住了自己的语言。** 对某一种语言再次执行**翻译对话（真实语言）**，不会改动其他语言的台词；**还原为英文**可以只针对一种语言，也可以针对全部语言。
- **当书籍有多种语言时，菜单会询问语言。** 部分的菜单（选择其中一种语言或*所有语言*）以及对选中句子的右键菜单（选择一种语言）都会如此。**翻译部分**有一个*语言*字段（默认为所有语言）；*未翻译的部分*指的是“该语言尚未翻译的部分”。
- **自动运行**会将新部分翻译成每一种可能有说话人出现在其中的语言。
<a id="translating"></a>

## 翻译

- **手动：** 部分的菜单中有 **Translate** 子菜单（在文本上右键单击也有此子菜单），其中有 **Translate dialogs (real language)**（这些项目以及 **Translate parts (real language)** 仅在具有本插件语言的书籍中显示）。已翻译的部分会**根据其英文原文**重新翻译。具有多种语言的书籍会先询问[使用哪一种](#more-than-one-language-in-a-book)。
- **自动：** 使用 **Translate a new part by itself**，生成的部分在定稿后会立即被翻译。对某部分进行*重新生成*会赋予它新的英文，并删除旧的译文。
- **翻译的后续。** 对某一部分的翻译（手动、针对选区或自动）不会阻塞页面：它会列在左下角的 [运行面板](../books/story-editor.md#the-panel-of-the-runs) 中，随着内容到达显示模型的 **推理** 或 **回答** 的末尾，并带有 **Stop** 按钮。在此期间，该部分显示 *Translating the speech of the part...*，其他操作都无法翻译它。**Stop** 会立即取消请求，且不再开始后续请求；若有多种语言，在此之前已写入的语言保持翻译状态。对[范围](#translating)的翻译有其自己的窗口，该窗口会保持打开，与故事并排显示。
- **模型遗漏的对话：** 翻译有时会让某段对话保持英文。部分菜单中的 **Translate → Translate missing dialogs (real language)** 只翻译仍为英文的对话，保留已翻译的对话不变；若选中了文本，右键菜单中的 **Translate → Translate missing dialogs in selection (real language)** 则针对所选内容涉及的对话执行。模型接收到的是部分的当前内容（包括已翻译的对话），并且只被要求翻译仍为英文的对话，因此该操作比整部分的翻译更省成本。此操作只处理对话，因此不能用于翻译模型不视为对话的句子：请为此使用 *Translate selected text*。
- **你写的句子：** 在部分的文本中选中该句，右键单击并选择 **Translate → Translate selected text (real language)**。模型会结合周围的故事进行翻译，英文作为源文本保留。包含已翻译对话的选区会被拒绝。
- **范围：** 故事菜单中的 **Translate parts (real language)** 会打开一个保持在故事旁边的窗口：可选 *Translate the parts that are not translated*、*Translate the translated parts again* 或 *Put the English back*，可指定从某一部分到另一部分，并带有 **Stop**。

![翻译一段范围部分的窗口](../../images/plugin-reallang-range.png)

译文的保存方式与文本的任何更改相同：该部分的历史记录会新增一个版本，该部分**不会被标记为已编辑**，英文原文也会保留。**你手动修改过的对话会保持原样**，无论该部分是重新翻译还是恢复为英文，因为它包含你的文字。

<a id="what-the-reader-sees"></a>

## 读者所见

已翻译的对话带有**虚线**；点击它会在弹出框中显示英文：如果该语言需要注音，则显示读音；显示说话者以及听者是否听不懂；如果你在译文完成后编辑过译文，则会显示红色提示。

**Edit the source**（弹出框中的按钮，仅在你自己的视图中可见）会打开一个窗口，显示故事中的译文以及模型所读取的英文。当母语者手动修正了日语，而英文现在表达的内容不同，或者模型误读了英文时，请使用它。保存后，该对话获得新的英文，当前译文被视为英文所对应的版本（红色提示消失），模型将读取新的英文。部分的文本不会改变。`reallang-edit-source` 命令行可执行相同操作。

**在源文本中搜索和替换**（*Real language* 标签页顶部带箭头的按钮）会打开应用程序的搜索和替换窗口，作用于当前分支中已翻译对话的英文源文本（纯文本或正则表达式）。只有源文本会改变；译文本身的文字则使用书籍的搜索和替换功能进行替换。

![编辑对话源文本的窗口](../../images/plugin-reallang-source.png)

![对对话英文源文本进行搜索和替换](../../images/plugin-reallang-search-replace.png)

![带有英文弹出框的已翻译对话](../../images/plugin-reallang-story.png)

[已发布的书籍](../books/publishing.md) 会按照书籍的设置显示：在 **Readers of the published book see** 中可选择：*the translation, the English on click*（默认）、*the translation only*（英文永远不会发送到读者的浏览器）或 *the English only*。

<a id="exporting"></a>

## 导出

当书籍包含已翻译的对话时，[导出](../books/export.md) 对话框中会出现 **Translated speech (real language)** 字段，可选：*the translation as it is*、*the English only*、*the translation with the English in footnotes* 或 *the English with the translation in footnotes*。导出操作永远不会改变书籍中存储的文本。

![包含已翻译对话的导出对话框](../../images/plugin-reallang-export.png)

<a id="together-with-the-conlang-translator"></a>

## 与 Conlang Translator 共同使用

一本书可以同时包含两者：精灵使用的虚构语言，以及城镇使用的日语。每个插件都有各自的说话者、语言设置和段落，二者的段落互不影响。所有模型读取的英文都会同时包含两者的内容。[导出](../books/export.md) 会将两者的脚注合并为同一套编号，查看器也会在同一页面中显示两者的对话。请为两者在 **Readers of the published book see** 中设置相同的值：同一页面只绘制一次，由先到达该页面的插件负责绘制。
<a id="commands"></a>

## 命令

界面中的所有操作也都是一条命令，可用于[命令行](../commands/index.md)和[智能体](../agents.md)。语言可以通过其**名称**（不区分大小写）或 id 指定；段落可以通过其句柄，或其在当前分支上的位置指定（第一段为 1）。

| 命令 | |
|---|---|
| `reallang-list`、`reallang-create`、`reallang-update`、`reallang-delete` | 语言库。`reallang-create` 接受 `preset` 参数（`ja-kana-kanji`、`ja-kana`、`ja-romaji`、`other`）。`reallang-delete` 会询问用户。 |
| `reallang-set-book-language` | 打开的书的语言（其*扩展设置*中的**发言语言**字段）。 |
| `reallang-add-book-language`、`reallang-remove-book-language` | 打开的书的其他语言。移除时会询问用户。 |
| `reallang-status` | 书的语言，以及哪些段落已翻译。 |
| `reallang-translate-part`、`reallang-translate-range`、`reallang-translate-sentence`、`reallang-translate-text`、`reallang-revert-to-source` | 翻译：单个段落（`missingOnly` 仅翻译仍为英文的发言，`within` 引用一段文字以限定范围）、一个区间（`mode` 为 *new* 或 *again*）、段落中的一个句子、仅返回结果而不保存的文本，以及还原为英文原文。可选参数 `language` 指定书中的某一种语言（默认为全部语言；句子和文本则默认为第一种语言）。 |
| `reallang-glossary`、`reallang-glossary-set`、`reallang-glossary-remove`、`reallang-glossary-accept`、`reallang-glossary-switch`、`reallang-glossary-move` | 打开的书在某一语言下的[术语表](#the-glossary-of-names-and-special-words)：读取合并后的条目及其层级；在 `level`（`language`、`folder` 配合 `folder` 名称、`book`）添加或修改条目；移除条目（会询问）；接受建议；为本书开启或关闭较高层级的词条；将本书的条目提升一级。 |
| `reallang-extract-terms`、`reallang-extraction-set` | [模型提取词汇](#extracting-the-words-by-model)：`reallang-extraction-set` 选择 `prompt` 并写入打开的书的 `specification`（未填写的部分保持不变）；`reallang-extract-terms` 读取从 *from* 到 *to* 的段落，并向本书的术语表提出词条建议（`language` 指定语言）。 |
| `reallang-extraction-prompts`、`reallang-extraction-prompt-set`、`reallang-extraction-prompt-remove` | 提取提示词库：列出内置和自定义的提示词；添加或修改一条（指定内置提示词的名称会创建一份副本）；移除一条（会询问）。 |
| `reallang-edit-source` | 设置一条已翻译发言的英文原文（`part`，`speech` 为 `reallang-list-passages` 中的编号，`source`）；当前的译文视为其对应的译文。会替换旧的原文。 |
| `reallang-get-source`、`reallang-list-passages` | 读取：模型所读取的段落文本（英文），以及段落中已翻译发言的读音和英文。 |
| `reallang-speakers`、`reallang-set-speakers-mode`、`reallang-set-speaker`、`reallang-remove-speaker` | 打开的书中谁使用该语言（`language` 指定书中的某一种语言，默认为第一种）；`reallang-set-speaker` 同时设置 `understands`（理解程度）。 |
| `reallang-set-understanding-prompt` | 是否由系统自动将理解程度插入故事的提示词，以及从末尾算起插入多少条消息。 |
| `reallang-understanding` | 以文本形式列出哪些人听不懂哪种语言，用于 {%{`{{command::reallang-understanding::<characters>}}`}%} [宏](../templates/macros.md#commands)（角色为可选参数）。 |

语言只是几行规则，在智能体运行时没有工作副本（Conlang Translator 会连同词典一起复制语言）：智能体创建或修改语言时，会立即改动你的语言库。发言者、书的设置和段落都属于这本书，智能体运行时使用的书副本会携带它们。

<a id="limits"></a>

## 限制

- **质量取决于模型。** 敬语是日语中最难的部分；规则和关于字符的说明会起指导作用，但需要由人阅读少数段落才能判断它们是否足够。
- **发言者决定询问哪些语言**，依据段落的视角和在场角色。若某个角色没有被段落点名，而该语言的发言者列表中又没有他，那么这段发言可能会被遗漏；请求内部则以段落文本为准。
- **没有第二轮处理**，不会为了自然度重写译文，也尚未提供回译检查。
- **没有注音（furigana）。** 读音只是弹出框中的一行文字，而不是页面中的振假名（ruby）文本。
- **由另一个翻译插件翻译过的段落**，本模型会读取其中的译文（而非英文原文），并且只会被告知该处的发言使用了另一种语言。
- **手机端**可以使用面板和编辑器；故事一侧的功能（菜单、区间窗口、在故事中点击）尚未在手机上测试。
