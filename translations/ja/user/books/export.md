# 書籍のエクスポート

エクスポートは、ストーリーを読んだり、印刷したり、送ったり、ほかの場所で公開したりできるファイルに変換します。[バックアップ](backups.md)と異なり、完成した本として、テキストだけを含みます。

エクスポートの対象になるのは[アクティブなブランチ](branches-and-story-tree.md)だけで、ストーリーエディタに表示されている部分と同じです。ストーリーの別のバージョンをエクスポートするには、先にそのブランチへ切り替えてください。

<a id="exporting"></a>

## エクスポート

1. 本を開き、**ストーリー**タブに移動します。
2. 下部バーの設定メニュー（⚙）を開き、**ストーリーをエクスポート**を選びます。
3. ダイアログに入力して、**エクスポート**を選びます。
4. Marginalia がブランチの部分を集めてファイルを書き出します。長い本では少し時間がかかります。進行状況バーで進み具合が分かります。
5. ファイルの準備ができると、ダウンロードを促すダイアログが表示されます。保存するには**ダウンロード**ボタンを選びます。

![「ストーリーをエクスポート」ダイアログ](../../images/export-dialog.png)

| 項目 | |
|---|---|
| **形式** | ファイルの種類。下記を参照してください。 |
| **印刷スタイル** | フォントや色を持つ形式（HTML、Word、PDF、EPUB）でのみ使用します。テキストの見た目で、*エクスポート用*のスタイルから選びます。アプリケーションは各形式に1つずつ用意しています。**HTML ページ**、**電子書籍（EPUB）**、**PDF の本**、**Word 文書**がそれで、これらはエクスポートが従来から使っていた見た目で、形式を選ぶと自動的に選択されます。独自のスタイルを作ることもできます。[印刷スタイル](#print-styles)を参照してください。[設定 → エクスポート](../account.md#exports)で形式ごとに選んだスタイルが、あらかじめ選択されています。 |
| **ファイル名** | ダウンロードされるファイルの名前です。Marginalia が付ける拡張子は含みません。初期値は本の名前です。 |
| **書名** | ファイル内のタイトル（タイトルページとファイルのプロパティ）です。初期値は本の名前です。変更しても本の名前は変わりません。 |
| **著者** | 初期値は[アカウント](../account.md)に登録した氏名です。空欄の場合、著者は書かれません。 |
| **開始メッセージ**、**終了メッセージ** | エクスポートする部分の範囲です。部分はストーリーの順に1から数え、テキストのない部分は数えません。**終了メッセージ**を空欄にすると、最後までエクスポートします。 |
| **タイトルページを含める** | ファイルの最初のページに、タイトルと著者を載せます。 |
| **執筆の内訳を含める** | ファイルの最後に、誰が文章を書いたかを示す短い記載を付けます。自分が書いた語数と、モデルが生成した語数を、語数と割合で、使用したモデルとともに示します。出版社やコンテストによっては、この記載を求められることがあります。内容は、エクスポートする部分の[バージョン履歴](version-history.md)から計算されます（[生成されたテキストのハイライト](story-editor.md#highlighting-generated-text)を参照）。SillyTavern のチャットには提供されません。記載の文言は[設定 → エクスポート](../account.md#exports)にあるテンプレートです。 |

![完成したエクスポート、ダウンロード可能な状態](../../images/export-download.png)

## 形式

| 形式 | |
|---|---|
| **プレーンテキスト**（`.txt`） | UTF-8 のテキストだけです。*斜体*などの書式は取り除かれ、段落は空行で区切られます。 |
| **Markdown**（`.md`） | ストーリーに書かれたままの Markdown テキストです。Obsidian や Typora などのエディタ、静的サイト、リポジトリでの利用に向いています。強調、見出し、引用、リスト、コードブロック、場面転換は Markdown のまま残ります。テキスト内の生の HTML は入力どおりに残され、表示するかどうかは Markdown リーダーが決めます。 |
| **HTML**（`.html`） | 本のようなスタイルを含む1ページです。どのブラウザでも同じように見えます。印刷でき、外部ファイルはありません。 |
| **Word 文書**（`.docx`） | Word、LibreOffice などの類似プログラムで開けます。本文は両端揃えで、タイトルと著者はファイルのプロパティに設定されます。 |
| **PDF**（`.pdf`） | A5 判のページです。ラテン文字、ギリシャ文字、キリル文字を収録した埋め込みフォントと、かな、漢字、日本語の句読点のために同梱の日本語フォント（Noto Sans JP）を使います。ほかの文字体系のテキスト（中国語のみの漢字、ハングル、アラビア文字）は描画されません。PDF にそのためのフォントがないためです。 |
| **EPUB**（`.epub`） | 電子書籍リーダーや読書アプリ向けの電子書籍です。長い本は、読者の表示を速く保つため、EPUB 内でいくつかのファイルに分割されます。 |
| **Archive of Our Own 用 HTML**（`.html`） | AO3 に投稿するための形式です。[下記](#for-other-tools)を参照してください。 |
| **front matter 付き Markdown**（`.md`） | 静的サイトジェネレーター向けです。[下記](#for-other-tools)を参照してください。 |
| **SillyTavern チャット**（`.jsonl`） | ストーリーをチャットとして書き出します。[下記](#for-other-tools)を参照してください。 |
| **Obsidian ボールト**（`.zip`） | 章とロアブックを、相互にリンクしたノートとして書き出します。[下記](#for-other-tools)を参照してください。 |
| **LaTeX**（`.zip`） | 本の LaTeX プロジェクト（`main.tex` と画像）です。[下記](#for-other-tools)を参照してください。 |

部分のテキストは Markdown です。強調、見出し、引用、リスト、コードブロック、場面転換（`---`）は、それらを表示できるすべての形式で保たれます。テキスト内の生の HTML は文字として表示され、実行されることはありません。

<a id="footnotes"></a>

## 脚注

脚注は、部分のテキストに、マークを置く位置で `[^1]` と書き、単独の行に `[^1]: 注の内容` と書きます（ラベルは任意の語で構いません）。すべての形式で脚注を扱えます。**Markdown** は構文をそのまま残します。**HTML**、**EPUB**、**Archive of Our Own 用 HTML** は、小さく上付きにした番号を付け、その部分の本文の下にある注へリンクします（AO3 は、同エディタが保持する単純なマークアップを受け取ります）。**プレーンテキスト**は、マークを `[1]` と書き、注は部分の本文の後に `[1]` で始まる行として書きます。これは文末注の一般的な体裁です。**Word** と **PDF** は本物の脚注を持ちます。マークは小さく上付きにした番号で、注は同じページの下部に、やや小さい文字で載ります（PDF では短い罫線の下に置かれ、各ページは注に必要な場所を確保するようにレイアウトされます）。Word は番号の付与と配置を自動で行うため、文書を編集すると注も追従します。拡張機能も脚注を使えます。たとえば Conlang Translator 拡張機能は、各発話の英訳を脚注として書きます。

<a id="images"></a>

## 画像

部分の[画像](story-editor.md#images)は、その位置の指定どおりに配置されます（別の場所を選んでいない限り、本文の後になります）。キャプションも含まれ、与えた幅で表示されます（本文の幅に対する割合です。幅を指定しない場合、画像は元の大きさを保ち、ページに収まるよう縮小されます）。すべての形式で、画像の横に本文を回り込ませられるわけではありません：

| 形式 | |
|---|---|
| **HTML**、**EPUB** | 埋め込まれます（ページ内、または本のファイルとして）。本文は画像の左右に回り込みます。中央に置かれた画像は、2つの段組みの本文の間に入ります。画面が狭いと、画像は本文の上に置かれます。段組みに対応しないリーダー（一部の電子書籍端末）では、最初の本文、画像、残りの本文が上から順に並びます。同じ位置に並んだ画像は、横一列に並びます。 |
| **Word 文書** | 本文が回り込む画像は、小さな表の中に入ります。Word はそれを側面または中央に配置し、本文を周囲に回り込ませます（中央の場合は左右両側に、行ごとに回り込みます）。キャプションは画像の下に置かれます。幅が指定され、横に並べて収まる画像は、表の1行になります。 |
| **PDF** | 本文は画像の側面に回り込みます。キャプションは画像の下に描かれます。中央に置かれた画像は、左揃えの2つの段組みの本文の間に入ります（ページ末尾に収まらない帯は、次のページから始まります）。幅が指定され、横に並んで収まる画像は1行になります。ページの残りの部分に対して高すぎる画像は、次のページに送られます。 |
| **Markdown** | `![キャプション](data:...)` の形で画像をファイル内に埋め込み、キャプションは画像の下に斜体で置かれます。そのため、ファイルは1つのままです。本文中の位置は保たれますが、幅と本文の回り込みは保たれません。埋め込み画像を表示しないリーダーもあります（GitHub は表示しません）。また、画像の多い本では行が非常に長くなります。Markdown でエクスポートするときにだけ、部分に画像を添付してください。 |
| **プレーンテキスト** | 画像のある位置に、`[Image]` または `[Image: キャプション]` と記されます。 |
| **Archive of Our Own 用 HTML** | `[Image: キャプション]` と記されます。AO3 は、画像をリンクからのみ受け付けるためです。 |
| **Obsidian ボールト** | ボールトの `Attachments` フォルダに保存され、その章のノートの、画像の位置に埋め込まれます。キャプションは斜体で添えられます。 |
| **LaTeX** | プロジェクトの `images` フォルダに保存され、画像の位置で本文に組み込まれます（図は画像の幅で、本文の幅を超えません）。キャプションは画像の下に置かれます。本文は画像を回り込みません。 |
| **SillyTavern チャット** | 含まれません。チャットにはテキストしかないためです。 |
<a id="for-other-tools"></a>

## その他のツール向け

これらの形式は、読むためではなく、それを読み込むツール向けに作られています。*印刷スタイル*の選択肢はありません。

**Archive of Our Own 向けの HTML。** AO3 は作品のタイトル、作者、章のタイトルを専用の入力欄で求め、知らないもの（スタイルブロック、本文を囲むページ、リンクでない画像）を捨てるため、このファイルにはタイトルページがありません。貼り付けた後の見た目を確認するには、ブラウザで開いてください。どの章（見出しで始まる部分と、次の見出しまでの後続の部分）にも、見出しの上に 2 つのコメント `BEGIN chapter N` と `END chapter N` が付きます。その間にあるものを AO3 の章の HTML エディタにコピーし、タイトルは章のタイトル欄に入れてください。HTML はタグの間に改行のないきれいな HTML です。AO3 は改行を `<br>` に変換するためです。

**フロントマター付きの Markdown。** *Markdown* 形式と同じ Markdown ですが、ファイルの先頭に YAML ブロック（`title`、`author`、`lang`、書き出しの `date`）が付き、Jekyll、Hugo、Eleventy などの生成ツールが読み取ります。タイトルページの代わりになるため、**タイトルページを含める**は効果がありません。このブロックは [設定 → エクスポート](../account.md#exports) で変更できるテンプレートです（`{{title}}`、`{{author}}`、`{{language}}`、`{{exportDate}}`。タイトルと作者は二重引用符の中で使えるようすでにエスケープされています）。

**SillyTavern のチャット。** SillyTavern のチャットインポートが読む JSON Lines ファイルです。キャラクターは本の名前になり、あなたが作者になります。物語の各部分はキャラクターのメッセージ（本文）になり、その部分が指示をもとに書かれていた場合は、その指示があなたのメッセージとして本文の前に置かれます。部分にモデルの推論があれば、それはそのメッセージの推論として残ります。タイトルページは適用されません。

**Obsidian ボールト。** 本の名前のフォルダを含む ZIP です。展開してフォルダをボールトとして開いてください。本の名前のノート（フロントマター、タイトルページ、章と設定集の一覧）、`Chapters` 内の各章のノート（前後の章へのリンク付き）、本とそのサブ設定集の[設定集](../lorebooks/index.md)で有効になっている各項目のノートを `Lore/<設定集>` に含みます（項目のタグはノートのタグになり、そのコメントはコールアウトになります）。画像は `Attachments` に入ります。どのノートでも、項目名が最初に出てくる箇所（綴りどおりの、単語単位で 3 文字以上の名前）は、その項目のノートへのリンクになるため、グラフビューで各項目がどの章にあるかが分かります。見出しのある部分は章の始まりになります。最初の見出しより前の部分は *Beginning* のノート（本に見出しがない場合は *Story*）になります。フロントマターとタイトルページは、[設定 → エクスポート](../account.md#exports) で変更できるテンプレートです。

**LaTeX。** 本の名前のフォルダを含む ZIP です。`main.tex` は `pdflatex`、`xelatex`、`lualatex` でコンパイルできる `book` で、各部分の画像は `images` にあります。タイトルページは、[タイトルページのテンプレート](../account.md#exports)から作られる `titlepage` です。物語の最も浅い見出しは章になり、次のレベルは節になり、以下同様です。番号は付きません（物語は章に自分で名前を付けるため）が、目次には並びます。強調、引用、リスト、コードブロック、場面転換は LaTeX で対応する形になり、脚注は本物の脚注になります。LaTeX にとって意味を持つ文字は通常の文字として書かれ、本の言語が一般的なものであれば、その言語に応じたハイフネーション（`babel`）が選ばれます。日本語、中国語、韓国語の本文がある本には `xelatex` か `lualatex` が必要です（`pdflatex` はメッセージを出して止まります）。ファイルはそのために `xeCJK` または `luatexja` を読み込みます。`xelatex` の場合は、文字を含むフォントを設定してください（変更する行はその上のコメントにあり、例えば `\setCJKmainfont{Noto Serif CJK JP}`）。そうしないと、`xeCJK` に付属する中国語フォントだけが使われます。ZIP を [Overleaf](https://www.overleaf.com) にアップロードするか、展開して `pdflatex main.tex` を実行してください（目次のために 2 回）。印刷スタイルは適用されません。見た目はクラスによって決まります。変更するには `main.tex` のプリアンブルを編集してください。

## 印刷スタイル

エクスポートでは、[設定 → スタイル](../account.md#styles) にあるテキストスタイルのうち **エクスポート用** と印が付いたものが使われます。スタイルは本用（ストーリーと読者用）かエクスポート用のどちらかです。*テキストのスタイルを変更*メニューと読者画面には前者だけが表示され、エクスポートのダイアログには後者だけが表示されます。組み込みの 4 つは各形式の見た目です。**複製** を使って（または本用スタイルを複製し、**エクスポート用** にチェックを入れて）独自のスタイルを作れます。例えば、紙に印刷するための本のスタイルなどです。スタイルは紙向けに計算されます。アプリケーションのテーマに依存する色（ダークテーマの明るい文字）は、白いページ向けの暗い色になります。

| 形式 | スタイルによって決まるもの |
|---|---|
| **HTML** | カスタム CSS、ドロップキャップ、テキストの幅、背景を含む、スタイルのスタイルシート全体。タイトルページと目次は、その形式の見た目を保ちます。 |
| **EPUB** | カスタム CSS を除いた、スタイルのスタイルシート（すべての電子書籍リーダーがカスタム CSS を理解するわけではなく、一部のリーダーは独自のフォントやサイズを設定するため）。 |
| **PDF** | フォントファミリー（フォントスタックから選ばれる、埋め込みフォントの明朝、ゴシック、等幅）、サイズ、行の高さ、配置、段落の間隔、字下げ、ページの**背景色**（タイトルページを含むページ全体）、本文、斜体、太字、引用、見出し、場面転換の色、見出しの配置とサイズ、場面転換の記号。 |
| **Word 文書** | PDF と同じですが、埋め込みフォントの代わりに、スタイルで指定されたフォント名が使われます（そのフォントがコンピューターにない場合、Word は自分のフォントを表示します）。背景はページの色です。Word は画面上では表示しますが、印刷オプションで *背景色と画像を印刷* がオンにされていない限り印刷しません。 |

ドロップキャップ、カスタム CSS（PDF、Word、EPUB）、見出しのスモールキャピタル、テキストの幅は、PDF と Word のファイルでは作られません。

<a id="title-page-template"></a>

## タイトルページのテンプレート

タイトルページは、形式ごとに 1 つずつあるテンプレートから作られます。[設定 → エクスポート](../account.md#exports) で変更してください。テンプレートは Markdown で、`{{title}}`（ダイアログの本のタイトル）と `{{author}}` を使えます。例えば `## {{title}}` と、`written by {{author}}` という行です。既定では、タイトルが見出しになり、作者が斜体で書かれます。

同じテンプレート（タイトルページ、フロントマター、著作者表示）は、**1 冊の本またはフォルダごとに**変更できます。本の *プロンプト* タブと、フォルダのウィンドウの **拡張機能の設定** には、エクスポート形式ごとのパネルがあり、そのテンプレートごとに入力欄があります。本自身の版が最初に使われ、なければその上にある最も近いフォルダの版、なければ *設定 → エクスポート* の自分の版、なければ既定の版が使われます。そのため、シリーズごとに独自のタイトルページを持てます。空の入力欄は継承され、どこから継承されたかが表示されます。
<a id="table-of-contents"></a>

## 目次

テキストに章が含まれている場合、ファイルにはタイトルページの後に目次が追加されます。章とは、Markdown の見出し（`#` で始まる行、例: `# Chapter 3: The Harbour`）を含む物語の一部のことです。これは、ストーリーのサイドバーで [Chapter Marker](../extensions/chapter-marker.md) プラグインが使うのと同じルールです。部分の最初の見出しがその部分のタイトルになります。見出しのない部分は、その前の章に属します。見出しが一つもない物語には目次はありません。

![エクスポートされた PDF のタイトルページと目次](../../images/export-result.png)

PDF、Word、EPUB では、すべての章が新しいページから始まります。タイトルページと目次も、それぞれ独立したページになります。

項目は各章へのリンクになっています。

| 形式 | |
|---|---|
| **HTML** | ページ内の各章へのリンクになります。 |
| **PDF** | 章のページ番号付きのクリック可能な項目になります。また、章は PDF リーダーがページの横に表示するアウトライン（しおり）にも含まれます。 |
| **EPUB** | リーダーの目次になります。タイトルページの後の、書籍のページでもあります。 |
| **Word 文書**（`.docx`） | 章のページ番号付きのクリック可能な項目になります。Word はファイルを開くときにフィールドの更新を求めるので、ページ番号を入力するには **はい** を選択してください（LibreOffice は自動で入力します）。Word の目次フィールドではなく、リンクの一覧です。 |
| **Markdown** | 目次はありません。章の見出しはテキストに残り、ほとんどの Markdown エディタはそれらからアウトラインを作成します。 |
| **プレーンテキスト** | 目次はありません。 |

<a id="page-numbers"></a>

## ページ番号

PDF と Word のファイルには、タイトルページを除くすべてのページのフッターにページ番号があります。番号はファイル内でのページの位置です。そのため、タイトルページは 1 ページ目で、その後の最初のページは 2 ページ目になります。その他の形式には独自のページがないため、ページ番号はありません。

<a id="the-title-page"></a>

## タイトルページ

**タイトルページを含める** を選択すると、ファイルの先頭に、書籍のタイトルと著者名だけを載せた独立のページが付きます。このページは組み込みのテンプレート（`DEFAULT_EXPORT_HEADER_TEMPLATE`）から作られ、現時点ではアプリケーション内で編集できません。

<a id="good-to-know"></a>

## 知っておくと便利なこと

- エクスポートは、**エクスポート** を選択した時点でのブランチのスナップショットです。その後に生成または編集された部分は、ファイルに含まれません。
- エクスポートされたファイルは、ダウンロードダイアログを閉じるまでしか保存されません。後で必要になった場合は、もう一度エクスポートしてください。
- 要約、ロアブック、指示文、モデルの推論過程はエクスポートされず、エクスポートされるのは部分のテキストと画像だけです。すべてを保存するには、[バックアップ](backups.md) を作成してください。
