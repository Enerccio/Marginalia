# xAI Grok

xAI の Grok モデルを、xAI 独自の API 経由で [推論プロバイダー](../inference-providers.md) として追加します。

Grok は、通常の *OpenAI Compatible* プロバイダーと URL `https://api.x.ai/v1` でも利用できます。この拡張機能は xAI API に直接接続するため、推論を推論として表示し、xAI が報告する正確なトークン数（推論トークンを含む）と件数を扱えます。また、このサービス向けのモデル一覧と接続テストも用意されています。

!!!warning ストーリー本文は xAI に送信されます
このプロバイダーを使う AI のリクエストはすべて（ストーリーを含むプロンプト、ロアブックのエントリーと要約、モデルの回答、エージェントやコマンドが送る画像）、xAI のサーバー（`api.x.ai`、または設定したプロキシ）に送信されます。そこでどう扱われるかは、API 向けの xAI の利用規約とプライバシーポリシーによって決まります。他のプロバイダーは、あなたが選んだサーバー（自分で運用するものを含む）に送信します。xAI に送信してよいと確認できていないテキストには、このプロバイダーを使わないでください。他のユーザーと共有しているサーバーでは、このプロバイダーの AI を共有する管理者が、利用する全員のストーリー本文を xAI に送ることになります。
!!!

<a id="installing"></a>

## インストール

*Admin → Extensions* で拡張機能を読み込みます（[拡張機能の管理](../administration/extensions.md)を参照）。読み込まれると、推論プロバイダーのダイアログの **Type** リストに **Extension** の項目が追加され、*Per Type Settings* タブの上部にある **Provider** リストに **xAI Grok** が表示されます。

<a id="adding-a-grok-provider"></a>

## Grok プロバイダーの追加

1. [xAI Console](https://console.x.ai) で API キーを取得します。
2. **Inference Providers** タブで **Add Inference Provider** をクリックし、**Name** を入力して、種類に **Extension**、プロバイダーに **xAI Grok** を選びます。
3. *General Settings*（コンテキストサイズ、応答サイズ、[推論](#reasoning)）と *Per Type Settings* タブのプロバイダー設定を入力し、**Test Connection** をクリックします。

![Grok プロバイダー](../../images/plugin-grok.png)

![一覧の Grok プロバイダー](../../images/plugin-grok-list.png)

| 項目 | |
|---|---|
| **Api Key** | xAI Console のキーです。暗号化して保存され、再表示されません。プロバイダーを編集するときに **Reset** をクリックすると、別のキーを入力できます。 |
| **Model** | 使用するモデルで、例は `grok-4` や `grok-3-mini` です。**Refresh** を押すと、キーで使えるモデルの一覧が表示されます。一覧にない名前を直接入力することもできます。 |
| **URL** | 任意です。空欄なら xAI の API（`https://api.x.ai/v1`）を使います。プロキシ経由で送信する場合に設定します。 |
| **Timeout (seconds)** | xAI の応答を待つ時間、また書き始めた後に次のテキストを待つ時間です。既定値は 300 です。 |
| **Retries** | xAI がレート制限（429）やサーバーエラー（5xx）を返したとき、または接続できなかったときに、リクエストを繰り返す回数です。既定値は 2 で、0 にすると再試行しません。 |
| **Send the reasoning effort** | *Automatic* は `grok-3-mini` のモデルにのみ推論の強度を送信します。*Always* はすべてのモデルに、*Never* はどのモデルにも送信しません。 |

**Test Connection** は、モデルの一覧を取得し、選んだモデルに数トークンの生成を依頼します。ダイアログに入力した値を使います（保存する前でも可能です）。

<a id="reasoning"></a>

## 推論

推論の設定は、他のプロバイダーと同様にプロバイダーの一般設定にあります。推論を有効にすると、モデルが示す推論はストーリー部分の推論として届きます。推論の強度は、それを受け付けるモデルにだけ送信されます（`grok-3-mini` では *low*、medium と high の場合は *high*）。他の Grok モデルは既定の動作で推論し、このパラメーターは受け付けません。

<a id="what-works"></a>

## 対応している機能

ストリーミング、停止、JSON スキーマ、モデルが呼び出せる関数、画像（JPEG、PNG）とテキストファイルの添付、共有 AI の制限、使用量の集計は、OpenAI 互換プロバイダーと同様に動作します。使用量は xAI が報告した値で、推論トークンは生成トークンとして数えられます。温度、top p、および [プロトコル](../protocols.md) のペナルティは、有効な場合に送信されます。一部の推論モデルはペナルティを受け付けません。非対応: xAI のサーバー側ツール（ライブ検索、コード実行）と、画像・動画の生成。
