# フォルダ

フォルダは、ディスク上のフォルダがファイルを整理するように、本を整理します。フォルダには本や他のフォルダを入れられ、その階層は必要なだけ深くできます。本の一覧には一度に一つのフォルダの内容が表示されます。フォルダには**設定**（言語、視点、時制、文体、テンプレートとプロンプト）も保存できます。そのフォルダにある本と、その下のフォルダにある本は、独自の設定を持たない限り、その設定で執筆されます。フォルダを使う主な理由はここにあります。シリーズの文体を一度設定すれば、そのシリーズのすべての本にそれが適用されます。

![フォルダのある「本」タブ](../../images/books-folders.png)

<a id="moving-around"></a>

## 移動する

本の上にある一覧には、現在のフォルダ内のフォルダが、並べ替えた列の順に表示されます。フォルダの**名前**をクリックすると、そのフォルダを開けます。一覧の上にあるボタンの経路（`Books / Sci-fi / Expanse`）が現在位置を示します。その一部をクリックすると、そこまで戻れます。

チェックボックス**サブフォルダを含める**をオンにすると、現在のフォルダの下にあるすべての本（どの深さのものも含みます。最上位では、すべての本です）が一覧に表示され、各本の場所を示す**フォルダ**列が追加されます。現在のフォルダとこのチェックボックスの状態は、ページを再読み込みしても保持されます。

フォルダの行には、その下にあるすべての本の数（どの深さのものも含みます）が表示されます。本の行には、その[アクティブなブランチ](branches-and-story-tree.md)の語数とトークン数が表示されます。**名前**と**タグ**のフィルターは、本だけでなくフォルダにも働きます（フォルダもタグを持てます。[フォルダへのタグ付け](#tagging-folders)を参照）。対象は現在のフォルダ、または*サブフォルダを含める*を使った場合はその下のフォルダです。

フォルダの**最終更新**は、その中の本に連動します。フォルダ内の本、またはその下のフォルダの本（もしくはそのパート）が変更されると、そのフォルダも更新されたことになります。この列で並べ替えると、最後にどこで執筆したかがわかります。本を開くことや移動することは、更新には含まれません。

<a id="what-the-buttons-do"></a>

### ボタンの働き

| ボタン | |
|---|---|
| **新しいフォルダ**（ヘッダー） | 現在のフォルダの中にフォルダを作成します。名前は空であってはならず、255文字を超えてはならず、`/`を含んではならず、同じ場所にある別のフォルダの名前と同じであってはなりません（大文字と小文字は区別しません）。 |
| フォルダの歯車 | [フォルダの設定](#folder-settings)を開きます。 |
| フォルダのペン | 名前を変更します。 |
| フォルダのゴミ箱 | フォルダを削除します。[フォルダの削除](#deleting-a-folder)を参照してください。 |
| **フォルダに移動**（本） | 本を入れるフォルダを選びます。 |
| 本の星 | 本を[お気に入り](#favorites)に登録します。 |
| **本を追加**、各種インポート | 新しい本は**現在のフォルダ**に入ります。[複製](managing-books.md#cloning-a-book)された本は元の本の隣に置かれます。 |

<a id="folder-settings"></a>

## フォルダの設定

フォルダの歯車を押すと、その設定が開きます（**整理**ウィンドウにも同じボタンがあり、キーは `i` です）。

![フォルダの設定](../../images/folder-settings.png)

- **名前**、**説明**、**タグ**。
- **言語**と、本の[プロンプト](prompts.md)タブと同じ項目：マスターテンプレート、視点、時制、文体、プロンプト。
- **パートごとに保持するバージョン数**：フォルダ内の本と、その下のフォルダの本について、パートの以前のバージョンを[履歴](version-history.md#how-many-versions-are-kept)で何個保持するかを指定します。上記のすべての制限のうち、最も厳しいものが本に適用されます。
- **拡張機能の設定**：読み込まれている[拡張機能](../extensions/index.md)に、本が継承する設定がある場合に表示されます。[拡張機能の設定](prompts.md#settings-of-extensions)を参照してください。

すべて任意です。空の欄は*継承*され、その旨が表示されます。欄の灰色の文字は継承される値で、その下の行にはその由来が示されます。フォルダを保存するには**保存**を押します。名前と説明はいつでも変更できます。ただし、フォルダ内またはその下にある本で、エージェントが作業中の場合は、言語やテキストに関する設定の変更は拒否されます。メッセージには本の名前が表示されるので、先に[その実行を一時停止または停止](../agents.md)してください。

<a id="where-the-settings-of-a-book-come-from"></a>

### 本の設定の由来

本は、これらの各設定について、次のうち空でない最初の値を使います。

1. 本そのもの（*概要*と*プロンプト*タブ）。
2. 本が入っているフォルダ。
3. そのフォルダの上のフォルダ、というように最上位まで。
4. あなたの**ユーザー設定**（*設定 → テンプレート*。[アカウントと設定](../account.md)を参照）。
5. **組み込みのデフォルト**。

空白のテキストは未設定とみなされます。これは必要になったときに参照されます（パートの生成、要約の作成、パートの書き直しなど）。フォルダに入れたときに本へ何かをコピーすることはありません。そのため、**本を別のフォルダに移動すると執筆の仕方が変わり**、フォルダの設定を変更すると、独自の設定を持たないその下のすべての本が変わります。

本の[プロンプト](prompts.md#inherited-settings)タブにこれが表示されます。各項目の下には、その値の由来が示されます（*フォルダ「Sci-fi」から継承*、*ユーザー設定から継承*、または*組み込みのデフォルト*）。

<a id="language"></a>

### 言語

本の**言語**欄（[概要](managing-books.md#the-about-tab)タブ）とフォルダの言語欄は空のままにできます。空欄は*継承*を意味し、本は、その上にある最も近いフォルダで言語が設定されていればその言語を使い、なければ英語になります。空欄の場合は、どの言語が使われ、その由来はどこかが表示されます。この欄にはクリアボタンがあり、押すと再び継承されます（以前は英語になっていました）。本の言語を表示したり使ったりするすべての箇所では、フォルダと組み合わせた結果の言語が使われます。テキストのハイフネーション、エクスポート、[言語の一括変更](#mass-changes)の表が該当します。

<a id="deleting-a-folder"></a>

## フォルダの削除

フォルダのゴミ箱ボタンを押すと、どうするかを尋ねられます。

- **空のフォルダ**は、確認の後に削除されます。
- **本やフォルダが入っているフォルダ**では、**中身を上のフォルダに移動する**（既定）か、**中身もすべて削除する**を選べます。後者を選ぶと、本とフォルダの数を示して再度確認され、本は[ゴミ箱](../trash.md)に移動します。そこから元に戻せます。削除されたフォルダ自体はゴミ箱には表示されません。

中にあるフォルダの名前が、上のフォルダにある別のフォルダの名前と同じ場合、中身を上に移動することはできません（名前は一意である必要があるため）。先にどちらかの名前を変更してください。エージェントが作業している本が入っているフォルダは、削除も移動もできません。実行中にその本の設定が変わってしまうためです。
<a id="organise"></a>

## 整理

**整理**（一覧のヘッダーにある**管理**メニュー）を開くと、2つのペインにそれぞれフォルダを表示したウィンドウが開きます。本やフォルダを一つずつ開かずに、一方のペインから他方へ移動やコピーができます。開くときは、左ペインに直前にいたフォルダ、右ペインに前回表示していたフォルダが表示されます。

![整理ウィンドウ](../../images/organise-dialog.png)

| キー | |
|---|---|
| Left / Right / Tab | もう一方のペイン。 |
| Up / Down | カーソルの移動。 |
| Enter | カーソル位置のフォルダを開く。 |
| Backspace | 1つ上の階層に戻る。 |
| Space or Insert | カーソル位置の項目をマークする。Shift + Up / Down で移動しながらマークする。 |
| チェックボックスをクリック | 項目のマークを付けるか外す。**Shift + クリック** では、そのチェックボックスと直前にクリックしたボックスの間にあるすべての項目にマークを付ける（または解除する）。 |

下部のボタン列は、**マーク**された項目（何もマークされていない場合はカーソル位置の項目）に対して操作を行います。各ボタンのキーは括弧内に表示されます。

| ボタン | キー | |
|---|---|---|
| **コピー** | `c` | *もう一方*のペインのフォルダにコピーする。 |
| **移動** | `m` | もう一方のペインのフォルダに移動する。 |
| **新しいフォルダ** | `n` | アクティブなペインのフォルダに新しいフォルダを作る。 |
| **名前を変更** | `Shift+r` | カーソル位置のフォルダまたは本の名前を変更する。 |
| **削除** | `Delete` | 一覧と同様に削除する。 |
| **フォルダの設定** | `i` | カーソル位置のフォルダの[設定](#folder-settings)。 |
| **モデル/プロトコルの一括変更**, **言語の一括変更**, **名前の一括変更**, **本にタグを付ける** | `p`, `l`, `Shift+n`, `t` | マークされた本、またはアクティブなペインのフォルダの本に対する[一括変更](#mass-changes)（それぞれ独自の*サブフォルダを含める*を指定できます）。名前の一括変更の後、ペインには新しい名前が表示されます。 |
| **詳細検索** | `f` | アクティブなペインのフォルダで[検索](managing-books.md#advanced-search)する。必要に応じて*サブフォルダを含める*を指定できます。結果には**フォルダ内で表示**があり、それを選ぶとそのフォルダにペインが移動し、該当する本にマークが付きます。 |
| **一覧にフォルダを表示** | `o` | ウィンドウを閉じて、アクティブなペインのフォルダを本の一覧で開く。 |

ウィンドウを閉じると本の一覧が再読み込みされるため、作成、移動、コピー、名前変更、削除した内容がすぐに反映されます。（一覧で表示していたフォルダが削除されている場合は、最上位の階層に移動します。）

これらのキーは、*設定*の[キーボードショートカット](../account.md#keyboard-shortcuts)の操作に対応しています。そこで変更または削除できます。既定ではファンクションキーは割り当てられていません（Macやブラウザがそれらを使用するためです）。ボタンには、設定したキーが表示されます。

<a id="copying"></a>

### コピー

本の**コピー**は、[クローン](managing-books.md#cloning-a-book)として作成されます。ウィンドウは、現在のブランチだけを取り込むかどうかを尋ねます。

フォルダのコピーは、元のフォルダの設定、説明、タグを持つ新しいフォルダになり、その中のすべての本とフォルダのコピーも含まれます。コピーには時間がかかることがあるため、停止できない進捗バーを表示しながら実行されます。途中で失敗した場合、それまでに作成されたコピーは残り、どれも完全な状態です。

**移動**は即座に行われ、移動先から元に戻すことで取り消せます。フォルダを自分自身や、その下位のフォルダに移動することはできません。

<a id="when-a-name-is-taken"></a>

### 名前が重複しているとき

移動先に同じ名前のフォルダがすでにある場合、ウィンドウはそのフォルダをどう扱うかを尋ねます。残りについては**すべてに適用**で一括指定できます。

| 選択肢 | |
|---|---|
| **名前を変更** | フォルダに別の名前が付けられる。 |
| **スキップ** | 元の場所に残される（コピーされない）。 |
| **統合** | 中身が既存のフォルダに入れられ、その中の同名のフォルダも順に統合される。 |

本が衝突することはありません。本の名前は重複してもかまいません。

<a id="mass-changes"></a>

## 一括変更

一覧の**管理 → Mass changes**メニュー（および**整理**のボタン）を使うと、多数の本をまとめて変更できます。**モデル/プロトコルの一括変更**は、一つのモデルやプロトコルを本に設定します。**言語の一括変更**は言語を設定します。**名前の一括変更**は、名前に接頭辞や接尾辞を付けたり、名前内の文字列を置き換えたり、番号を振ったりします。**本にタグを付ける**と**フォルダにタグを付ける**は、タグを追加または削除します。詳しくは[本の管理](managing-books.md#tagging-many-books-at-once)を参照してください。一覧から実行する場合は、現在のフォルダの本が対象になり、それぞれ独自の*サブフォルダを含める*を指定できます。

<a id="favorites"></a>

## お気に入り

本の行の星印を付けると、その本が**お気に入り**になります。お気に入りがある間、最上位の階層には、すべてのフォルダのお気に入りの本をまとめた仮想フォルダ**お気に入り**（星印付き）が表示されます。これは表示だけのフォルダです。このフォルダに本やフォルダを作ることはできません。星印を外すと、本はこのフォルダから消えますが、元のフォルダからは消えません。お気に入りは設定に保存されます。

<a id="tagging-folders"></a>

## フォルダへのタグ付け

フォルダにも、本と同様にタグを付けられます。**管理 → Mass changes → フォルダにタグを付ける**を使うと、多数のフォルダにまとめてタグを付けられます。フォルダのタグは、その中の本のタグを変更せず、[バックアップ](backups.md)にも含まれません。

<a id="folders-and-other-features"></a>

## フォルダとその他の機能

- **バックアップ。** [バックアップ](backups.md#backups-and-folders)は、本が属するフォルダを記憶しており、書き出したファイルには、本が継承する設定を含めることができます。
- **エージェント。** [エージェント](../agents.md#agents-and-folders)は、本が属するフォルダの設定を使って執筆します。
- **ヘルプアシスタント。** 許可すると、[アシスタント](../administration/help-assistant.md#your-books)があなたの本やフォルダを検索できるようになります。
- **スマートフォン。** [スマートフォン用レイアウト](../phone.md#books)では、同じフォルダがカードとして表示され、作成、名前変更、設定、削除ができます。整理と一括変更は、ヘッダーの**⋮**メニューにあります。
- **ビューアー。** [ビューアー](publishing.md#folders-in-the-list)でもフォルダが一覧表示され、最後に離れたフォルダで開きます。
