# 첫 실행

<a id="create-the-administrator"></a>

## 관리자 생성

Marginalia를 비어 있는 데이터베이스로 시작하면 로그인 화면 대신 첫 번째 계정을 요청합니다.
이 계정은 **관리자**입니다. 사용자 관리, 데이터베이스 백업, 정리 작업과 확장 기능을 관리할 수 있습니다.

![관리자 계정 생성](../../images/first-start.png)

다음 항목을 입력하세요:

| 필드 | |
|---|---|
| **Username** | 로그인 이름입니다. |
| **Full Name** | 애플리케이션에 표시되는 이름입니다. |
| **Password**, **Repeat password** | 두 값이 일치해야 합니다. Marginalia는 빈 비밀번호도 허용하지만, 서버에서는 절대 비워 두지 마세요. 그렇지 않으면 사용자 이름만으로 누구든 관리자로 로그인할 수 있습니다. |

*Administrator*는 체크되어 있으며, 첫 번째 계정에서는 변경할 수 없습니다. **OK**를 클릭하세요. 페이지가 다시 로드되고 로그인 화면이 나타납니다.

!!!
비밀번호를 기억해 두세요. 이메일로 비밀번호를 재설정하는 기능은 없습니다. 다른 관리자는 *Admin → Users*에서 사용자의 새 비밀번호를 설정할 수 있습니다.
!!!

<a id="log-in"></a>

## 로그인

새 계정으로 로그인하세요. **Save login**을 체크하면 브라우저가 30일 동안 로그인 상태를 유지합니다. 이 기능은 HTTPS 환경이나 데스크톱 앱을 사용하는 `127.0.0.1`에서만 동작합니다([서버](docker-server.md#https-and-reverse-proxy) 참조).

![로그인 화면](../../images/login.png)

로그인 폼 아래에는 Marginalia의 버전과, 빌드된 Git 커밋의 짧은 ID가 표시됩니다(예: `Marginalia 1.5.0 (93ec118)`).

<a id="the-workspace"></a>

## 작업 공간

로그인하면 작업 공간이 나타납니다. 왼쪽의 탭은 다음과 같습니다:

| 탭 | |
|---|---|
| **Books** | 내 책 목록입니다. 책을 열면 스토리 편집기가 표시됩니다. [책](../books/index.md)을 참조하세요. |
| **Lorebooks** | 프롬프트에 사용되는 세계관 및 캐릭터 메모입니다. [로어북](../lorebooks/index.md)을 참조하세요. |
| **Settings** | 개인 설정입니다. 새 책의 기본 모델과 프로토콜, 프롬프트 템플릿, 백업 등을 설정합니다. [계정 및 설정](../account.md)을 참조하세요. |
| **Protocols** | 생성 설정입니다. [프로토콜](../protocols.md)을 참조하세요. |
| **Inference Providers** | Marginalia가 연결하는 모델입니다. [추론 제공자](../inference-providers.md)를 참조하세요. |
| **Resources** | 업로드한 파일입니다. [리소스](../resources.md)를 참조하세요. |
| **Trash** | 삭제한 항목입니다. 관리자가 정리하기 전까지 보관됩니다. [휴지통](../trash.md)을 참조하세요. |

하단에는 **Admin**(관리자 전용), **Language** 선택기, **Change Password**, **Logout**이 있습니다(*Admin* 페이지는 [관리](../administration/index.md)를 참조하세요).

![첫 로그인 후의 작업 공간](../../images/workspace.png)

같은 버전 정보가 페이지 왼쪽 아래에 작은 글씨로 표시되어 있습니다. 마우스를 올리면 커밋의 전체 ID와 커밋 및 빌드 시각을 볼 수 있습니다. 문제를 보고할 때 이 정보를 알려 주세요. 개발용 체크아웃(`mvn jetty:run`)에서 실행한 빌드는 버전 대신 `dev`로 표시됩니다.

Marginalia는 마지막으로 머물렀던 위치를 기억합니다. 다음에 (어느 기기에서든) 로그인하면 같은 탭이 열리고, 책 목록의 필터, 같은 로어북과 열어 두었던 로어북 항목이 그대로 나타납니다. 책을 열어 둔 상태였다면 그 책도 같은 탭에서 다시 열립니다. 이때 입력해 두었던 장면, POV 캐릭터, 등장 캐릭터, 다음 부분을 위한 지시사항도 함께 복원됩니다. 이미 존재하지 않는 항목(삭제된 책, 로어북 또는 태그)은 건너뜁니다. 삭제된 책은 열리지 않습니다.

[빠른 시작](quick-start.md)으로 계속하세요.
