# チャプターマーカー

[ストーリーエディター](../books/story-editor.md)の**アウトライン**を目次に変換します。

![アウトラインの中の章](../../images/plugin-chaptermarker.png)

<a id="how-it-works"></a>

## 仕組み

パートのテキストに Markdown の見出し（`#` で始まる行）が含まれている場合、そのパートのアウトライン上の項目には、通常の`#n (DB ID: m)`ラベルの代わりに、見出しが強調表示されて表示されます。

```
# Chapter 3: The Harbour

Rain had been falling on Ostra since dawn...
```

は、アウトラインでは **5. Chapter 3: The Harbour** と表示されます。番号はブランチ内でのパートの位置で、その後に見出しが続きます。見出しのないパートは通常のラベルのままです。

- 見出しはパート内のどの行に書いてもかまいません。複数ある場合は、最初の見出しが使われます。
- どの見出しレベルでも機能します（`#`、`##`、`###`...）。
- [編集](../books/story-editor.md#editing-the-text)を保存すると、アウトラインがすぐに更新されます。見出しを追加すると章が始まり、削除するとそのパートは前のパートに統合されます。

<a id="usage"></a>

## 使い方

設定するものはありません。見出しをパートに自分で書くか、指示でモデルに頼んでください。例：*Start a new chapter titled "The Harbour" with a Markdown heading.*

!!!
デフォルトの[ユーザープロンプト](../books/prompts.md#user-prompt)では、モデルにタイトルや章の見出しを書かないよう指示しています。
モデルに見出しを書いてほしい場合は、指示の中でそのように明示するか、ユーザープロンプトのその規則を変更してください。
!!!

見出しはストーリー本文の一部なので、モデルにも送信され、[ビューアー](../books/publishing.md)やバックアップにも表示されます。

同じ規則で、[書き出した書籍](../books/export.md#table-of-contents)の目次にも章が見つけられます。
