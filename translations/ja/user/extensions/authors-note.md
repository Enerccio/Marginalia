# 作者ノート

本の生成のたびにモデルへ送られるメモです。今このトーンで書いてほしい、現在の章が何についてか、モデルがよく忘れてしまう注意事項などを書けます。ターンの指示とは違い、ノートは変更するまで残ります。

<a id="the-authors-note-tab"></a>

## 作者ノートタブ

[ストーリーエディター](../books/story-editor.md)の左サイドバーには、*アウトライン*の隣に **作者ノート** タブが追加されます。変更は入力と同時に本へ保存され、次の生成から使われます。

![作者ノートタブ](../../images/plugin-authorsnote.png)

| フィールド | |
|---|---|
| **プロンプトに挿入** | ノートを削除せずにオン・オフを切り替えます。 |
| **挿入の深さ** | ノートを置く位置を、プロンプト末尾からのメッセージ数で指定します。`0` - ターンの指示の後（一番最後のメッセージ）、`1` - その直前、`2` - 最後のストーリーパートの前、というように続きます。深さを大きくすると、ノートはシステムプロンプトの直後に置かれます。 |
| **ロール** | ノートを *システム*、*ユーザー*、*アシスタント* のどのメッセージとして送るかを指定します。 |
| **作者ノート** | モデルに送られるテキストです。空のノートは送られません。その下には、トークン数で見た大きさの目安が表示されます。 |
| **作者ノート（非公開）** | 自分用のメモ（計画、覚え書きなど）です。モデルには決して送られません。 |

!!!
ノートがプロンプトの末尾に近いほど、効果は強くなります。ロールを *システム* にした深さ `1` が良い出発点です。
ノートは[テンプレート](../templates/macros.md)として処理されません。マクロはそのまま書かれた形で送られます。
!!!

<a id="how-the-prompt-looks"></a>

## プロンプトの構成

生成では、まずシステムプロンプトを送り、次にストーリーをチャットとして送ります（各パートは *ストーリーを生成* に対するモデルの応答として送られます）。最後にターンの指示を送ります。深さ `1` のとき、ノートはターンの指示の直前に挿入されます。

1. システムプロンプト（テンプレート、ロア、要約）
2. ストーリーパート…
3. **作者ノート**
4. ターンの指示

ノートのトークンは、ストーリーに使える余地から差し引かれます。ノートが長いほど、プロンプトに入るストーリーパートは減ります。残りのプロンプトを入れる余地すらないほど長いノートは、*コンテキストの上限が足りません* と表示して生成を止めます。

<a id="the-note-as-a-macro"></a>

## マクロとしてのノート

自動挿入の代わりに（または加えて）、[{%{`{{command::authors-note}}`}%} マクロ](../templates/macros.md#commands)でノートを自分で配置できます。マスターテンプレート、ユーザープロンプト、またはロアのエントリーに置くと、プロンプトの好きな位置にノートの本文が出力されます。**プロンプトに挿入** がオンかオフかに関係なく、現在保存されているノートをそのまま出力します。そのため、マクロで配置するときはこのチェックをオフにしてください。さもないと、モデルはノートを二度受け取ります。深さとロールはマクロには適用されません（ノートはマクロを含むメッセージの一部になります）。空のノートは何も出力しません。

<a id="storage"></a>

## 保存

ノートは本と一緒に保存されるため、[本のバックアップ](../books/backups.md)やコピーにも含まれます。
