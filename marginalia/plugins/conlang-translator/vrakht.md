=== VRAKHT CORE GRAMMAR SPECIFICATION & COMMON ELEMENTS ===
1. COMMON ELEMENTS
   [Mood Particles (Sentence Prefixes)]
   Da   - Statement / Declaration (factual, narrative)
   Frag - Question / Inquiry (replaces '?')
   Bef  - Command / Imperative (subject 'du'/'ek' can be omitted)
   [Attitudinal & Tone Prefixes]
   Gna  - Polite / Subservient (Used toward superiors or in formal petitions)
   Mok  - Sarcastic / Mocking (Signals irony, sarcasm, or insincerity)
   Hoh  - Patronizing / Condescending (Used by superiors talking down to thrails/subordinates)
   Fall - Dejecting / Resigned (Signals defeat, despair, or reluctant acceptance)
   Droh - Threatening / Hostile (Signals underlying menace or imminent violent intent)
   Acht - Urgent / Panic / Warning (Signals immediate danger or battlefield alarm)
   [Pronouns]
   Ek   - I / We / First-person (singular & plural)
   Du   - You / Second-person (singular & plural)
   Es   - He / She / It / They / Third-person
   [Tense Particles (Pre-verb)]
   ja   - Past tense
   nu   - Present tense (optional/default)
   ve   - Future tense
   [Negation & Degree Markers]
   ne   - Not / Un- / Negation (pre-verb or pre-adjective)

   vok  - Most / -est / Supreme (superlative prefix)
   [Role Particles (Post-verb Noun Flags)]
   za   - Direct Object (Target / Patient / Accusative)

   mit  - Instrument / Means (With / By using / Instrumental)

   [Clause Linkers & Conjunctions]
   und  - And (addition)
   ab   - But (contrast / resistance)
   ven  - If / When (condition)
   den  - Because / Therefore (cause / effect)
   ke   - Who / Which / That (relative clause operator)
   [Core Functional Verbs]

   mak  - Do / Make / Perform
   gab  - Give / Offer
   den  - Think / Consider
   deng - Obey / Serve / Follow
   se   - See / Observe
   marsh- Go / March / Move
   drak - Fight / Attack / Conflict

2. SYNTAX AND GRAMMAR RULES
   RULE 1: MASTER SENTENCE BLUEPRINT
   Every sentence strictly adheres to this linear structure:
   [Mood Particle] + [Subject NP] + [Verb Unit] + [Role Particle 1 + Object NP 1] + [Role Particle 2 + Object NP 2] ...
- Mood Particle: Mandatory first token (Da, Frag, Bef).
- Subject NP: Max 1 noun (optionally preceded by adjectives). Uses no role particle.
- Verb Unit: Contains [Tense] + [Negation] + [Adverbs] + [Verb Stem].
- Object Stream: Unlimited post-verbal noun phrases. EVERY object MUST be flagged with a Role Particle (za, ge, mit, lok, von).
  RULE 2: NO INFLECTIONS
- Verbs NEVER conjugate for person, number, or tense (tenses rely strictly on particles: ja, nu, ve).
- Nouns NEVER declaim for case or gender. Plurals are indicated by adding 'mun' (e.g., skag-mun = enemies).
- Adjectives NEVER change form.
  RULE 3: MODIFIER-BEFORE-HEAD SYMMETRY
- Adjectives precede Nouns: [Adj] + [Noun] (e.g., 'krag eiz' = strong iron).
- Adverbs precede Verbs: [Adv] + [Verb] (e.g., 'krag drak' = fight strongly).
- Modifier + Head Compounding: Form complex terms by linking roots with hyphens (e.g., 'eiz-blod' = iron-blood / veteran).
  RULE 4: ZERO-COPULA (NO "TO BE")
- Place an adjective directly after a noun to form a full statement without a verb:
  [Noun] + [Adj] = "[Noun] is [Adj]".
  Example: "Da eiz krag" = The iron is strong.
  RULE 5: COMMAND BREVITY
- When using the 'Bef' mood particle, the subject (Du/Ek) may be dropped entirely.
  Example: "Bef deng za rokh" = Obey the lord!
  RULE 6: LINEAR CLAUSE CHAINING (NO NESTING)
- Complex sentences link simple SVO blocks using Linkers (und, ab, ven, den, ke).
- Mood Persistence: The initial Mood Particle governs subsequent linked clauses unless mood changes.
- Mood Reset: If mood changes between clauses, insert a new Mood Particle immediately after the linker.
- Relative Clause Flattening: Use 'ke' directly after a noun to link an action clause describing that noun.
  Example: "Da ek ja-se za skag ke ja-flie" = I saw the enemy who fled.
  RULE 7: No articles
- za is strictly a Direct Object flag, NOT the word "the". NEVER place za after other role particles (e.g., write ge rokh, NEVER ge za rokh).
  RULE 8: NATURAL GENDER
- There is no grammatical gender. Nouns never change form for gender. To state natural gender, attach frou- (female) or man- (male) before the noun (e.g., frou-rokh = female commander, frou-drak = female soldier).

### LANGUAGE INSTRUCTION: VRAKHT (THE IMPERIAL TONGUE)
You are capable of speaking and translating Vrakht. When speaking or translating Vrakht, strictly obey these mechanical rules:

1. SENTENCE STRUCTURE: Every sentence MUST start with a Mood Particle (`Da` = Statement, `Frag` = Question, `Bef` = Command).
    - Blueprint: `[Mood]` + `[Subject]` + `[Tense + Verb]` + `[Role Particle + Object]`
    - Objects MUST use role flags: `za` (Direct Object), `ge` (Recipient/To), `mit` (Instrument/With), `lok` (Location), `von` (Source/From).
    - Example: "Da ek ve-deng za vrak-rokh." (I will obey the emperor.)

2. NO INFLECTIONS / FLEXIBLE ROOTS:
    - Verbs do NOT conjugate. Use tense prefixes: `ja` (past), `nu` (present), `ve` (future).
    - Nouns do NOT change form. Add `-mun` for plurals (`skag-mun` = enemies).
    - Drop "to be" entirely for adjective statements: "Da eiz krag." (The iron is strong.)

3. COMPOUNDING: Combine basic roots using hyphens to invent complex concepts dynamically (e.g., `eiz-blod` = veteran, `drak-karn` = battlefield, `vrak-haus` = fortress).

4. NO NESTED CLAUSES: Keep sentences linear. Chain clauses using linkers (`und`, `ab`, `ven`, `den`, `ke`).
