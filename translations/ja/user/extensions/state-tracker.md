# 状態トラッカー

キャラクターの現在の**状態**を追跡します。服装、持ち物、手にしている武器、負傷、気分など、あなたが定義したものが対象です。追跡中のキャラクターの状態は、プロンプトに組み込まれます。モデルは、剣を二章前に失ったことや、マントがずぶ濡れであることをすぐに忘れてしまいます。状態トラッカーを使うと、場面に登場する追跡対象のキャラクターごとに、今何が事実なのかがプロンプトに示されます。

!!!
追跡するキャラクターと、そのキャラクターについて何を追跡するかは、あなたが選びます。タブに追加したキャラクターだけがモデルに説明され、しかもそれは書いている部分の*登場人物*に含まれている間だけです。このバージョンでは、状態はあなたが自分で管理します（または、下記のコマンドを使うエージェントが管理します）。物語に沿ってモデルが状態を更新する機能は、後のバージョンで提供されます。
!!!

<a id="categories"></a>

## カテゴリー

**カテゴリー**とは、キャラクターについて追跡できる項目のひとつです。各カテゴリーには次の要素があります。

- **名前**。プロンプトでもこの名前で呼ばれます（*Wearing*、*Weapon at hand*、*Carrying*）。
- **種類**:
  - **Single value**: 短い値ひとつです。新しい値が古い値を置き換えます（手にしている武器、場所など）。
  - **List**: 項目を一つずつ追加・削除します（持ち物、負傷など）。
  - **Description**: 全体を書き換える文章ひとつです（服装、気分など）。
- **モデルへの指示**: そのカテゴリーに何を書くべきか、何を書くべきでないか。モデルは物語に沿って書くときにこれを読みます。
- **テキストに書かれたことだけ**: オンのときは、テキストがそう述べた場合にのみ値が変わります。オフのときは、明らかな結果（泳いだ後で濡れている、など）にも反応します。これも、モデルが物語に沿って書くときに使われます。
- **空のときは「none」と書く**: キャラクターに値がないとき（武器を失ったときなど）、カテゴリーを省くのではなく、プロンプトに *none* と書かれます。

<a id="my-categories"></a>

### 自分のカテゴリー

自分のカテゴリーは **Settings → Extension Settings → State Tracker** にあります。本は、ここからカテゴリーをコピーします。変更するまでは、*Wearing*、*Weapon at hand*、*Carrying*、*Injuries*、*Mood* の5つの組み込みカテゴリーがあります。カテゴリーの追加、編集、削除はそこで行い、設定画面で **保存** を押します。**Reset to the built-in categories** を押すと、組み込みの5つに戻ります。

<a id="the-categories-of-a-book"></a>

### 本のカテゴリー

本は、使っているカテゴリーそれぞれの**独自のコピー**を持ちます。そのため、バックアップやエクスポートには必要なものがすべて含まれ、自分のカテゴリーを削除しても本が壊れることはありません。状態タブの **Categories of this book** ボタンで、それらが一覧表示されます。

- **Add from my categories** は、自分のカテゴリーのひとつを本にコピーします。
- **New category for this book** は、この本だけに存在するカテゴリーを作ります（船の積荷、魔法の調律など）。このカテゴリーには *Only in this book* と表示されます。**Save to my categories** を押すと自分のカテゴリーに追加され、他の本でも使えるようになります。
- 自分のカテゴリーと同じではなくなったコピーには *Differs from your category* と表示されます。**Update from my categories** を押すと、自分の版が取り込まれます。指示を変えるとモデルの動作も変わるため、あなたの操作なしに更新されることはありません。
- カテゴリーを編集すると、変更されるのはこの本だけです。キャラクターがそのカテゴリーの値を持っている間は、種類を変えることはできません。
- 本からカテゴリーを削除すると、すべてのキャラクターのそのカテゴリーの値も削除されます。

<a id="the-state-tab"></a>

## 「状態」タブ

ストーリーエディターの[左サイドバー](../books/story-editor.md)に、**状態**タブが追加されます。変更内容はすべて、変更するたびに本に保存されます。

**Track a character** は、**名前**、任意で **別名**（部分の *登場人物* 欄に書かれる、そのキャラクターの別の名前。コンマで区切ります）、そして **追跡するカテゴリー** を尋ねます。リストには本のカテゴリーと自分のカテゴリーが表示され、自分のカテゴリーを選ぶとそれが本にコピーされます。馬は *Injuries* だけを追跡し、ヒロインはすべてを追跡する、といったことも可能です。

追跡中のキャラクターはそれぞれ、カテゴリーを現在の値とともに表示します。

- **+** は、単一値または説明のカテゴリーの値を設定します（現在の値は**履歴**に移ります）。リストの場合は項目を追加します。
- ペンのアイコンは値を編集し、×印は値を**削除**します。もはや事実ではないため、値は履歴に移り、モデルには送られません。
- 錠のマークは、値を**ロック**します（傷跡、家の剣など）。今後提供される「整理」機能は、モデルとともに動作するもので、ロックされた値には触れません。
- **履歴** は、そのカテゴリーの過去の値を、終わった理由（*replaced* または *removed*）とともに表示します。**復元** は過去の値を現在の値に戻します（単一値または説明のカテゴリーでは、現在の値が代わりに履歴へ移ります）。**Delete** は、値を完全に削除します。

キャラクターのペンアイコンは、その名前、別名、カテゴリーを編集します。カテゴリーのチェックを外すと非表示になりますが、値は残ります。再びチェックを入れると、値が戻ります。ゴミ箱アイコンは、そのキャラクターの追跡を止め、状態全体を削除します。

<a id="in-the-prompt"></a>

## プロンプトへの組み込み

歯車ボタンには、本の設定があります。

- **In prompt** は、追跡中のキャラクターのうち場面に登場する者の状態を、すべての生成のプロンプトに挿入します（オンのとき歯車は緑色になります）。
- **Depth** と **ロール** は、作者注（Author's Note）と同様に、どこに入るかを指定します。**Depth** は、その後ろにあるメッセージの数です（0ならターンの指示の直後、1ならその直前）。
- **Name separators** は、*登場人物* 欄をどのように区切るかを指定します。既定では `,` `;` `/` `|` と改行です。かっこ内の注記は無視されるため、`Mara (asleep), Fiora` でどちらも見つかります。

プロンプトには、伝えるべき内容のある、場面の登場人物が含まれます。

```
The current state of the characters of this scene. Keep to it; it changes only when the story changes it:

Fiora:
- Wearing: torn green cloak, leather boots
- Weapon at hand: none
- Carrying: rope; lantern
```

同じテキストは、テンプレートの任意の場所に、マクロ {%{`{{command::state-tracker-block::{{presentCharacters}}}}`}%} で入れることもできます（引数には任意の名前のリストを使えます）。このマクロは、**In prompt** がオンかどうかにかかわらず状態を出力します。そのため、マクロを使うときは **In prompt** をオフにしてください。さもないと、モデルが状態を二度受け取ってしまいます。

<a id="commands"></a>

## コマンド

コマンドバーとエージェント向けです。

| コマンド | 内容 |
|---|---|
| `state-status` | 設定、本のカテゴリー、およびコピーを持たない自分のカテゴリー。 |
| `list-state-characters` | 追跡中のキャラクターとそのカテゴリー。 |
| `track-state-character` | キャラクターの追跡を開始します。名前、別名、名前で指定したカテゴリー。 |
| `stop-tracking-state-character` | キャラクターの追跡を止め、その状態を削除します（事前に確認します）。 |
| `list-character-state` | キャラクターの値（現在のものと過去のもの）を番号付きで表示します。 |
| `set-character-state` | 値を設定します。キャラクター、カテゴリー、テキストを指定します。 |
| `remove-character-state` | 番号を指定して値を削除します。値は履歴に移ります。 |
| `state-tracker-block` | キャラクターのリストに対するプロンプトのテキスト（マクロ）。 |
