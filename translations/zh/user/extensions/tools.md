# 模型的工具

有些扩展会为模型提供**工具**：这些是模型在写作时可以调用的函数，用来获取名字、查找真实地点等，而不必凭空编造。同一个扩展的工具称为一个**套件**，目前的套件如下：

| 套件 | 扩展 | 模型可以用它做什么 |
|---|---|---|
| 名称生成器 | [名称生成器](name-generator.md) | 获取按某一类别（地名、神名、某国姓氏等）仿造出来的名字。 |
| 名称提供器 | [名称提供器](name-provider.md) | 获取保留原始拼写的真实名字。 |
| 地点提供器 | [地点提供器](place-provider.md) | 查找真实地点、其周边环境以及彼此之间的距离。 |

带有工具的模型对话框中有一个**Tools**按钮：它出现在[设定生成器](lore-generator.md)和[剧情大纲](arc-outline.md)的生成器中（不包括剧情导入，因为它使用的名字已经在故事中了）。只有至少安装了一个套件时才会显示该按钮。选中某些内容后，按钮会显示已开启的数量，例如**Tools (3)**。

<a id="choosing-the-tools"></a>

## 选择工具

点击**Tools**会打开一个窗口，每个套件各占一节，节名为套件名称，并显示其中已勾选的数量。含有已勾选项的节默认展开。每节的内容取决于套件的类型：

- 带有**条目**的套件（名称生成器和名称提供器各自按类别或名单列出条目）会显示一个表格，每行带一个复选框，表格上方有该节**自己的筛选框**：输入名字的一部分，即可只显示匹配的条目。已勾选的条目始终保留在表格中，不受筛选影响。**Check shown**会勾选当前表格中显示的所有条目，**Uncheck shown**则取消勾选，下方一行会显示已勾选的数量。模型只会获得已勾选的条目：它可以列出这些条目，并请求其中某些条目的名字，而无法访问其他条目。
- **没有条目**的套件（地点提供器）只有开和关两种状态，即**Use this suite**。

![Tools窗口，名称生成器的类别已用“Japan”筛选](../../images/tools-dialog.png)

每个节还有一个**Hint for the model**。这是一段简短的文字，在模型获得该套件时附加到提示词末尾，告诉模型何时以及如何使用这些工具（例如对名字而言：调用工具而不是凭空编造名字，从返回的结果中挑选，并保持返回的真实名字不变）。内置的文字以灰色显示在输入框中；如果想替换它，请写入你自己的文字；将输入框留空则使用内置文字。

![一个已开启的套件，其提示展开显示；另外两节已折叠，并显示已勾选的条目数量](../../images/tools-hint.png)

模型只会获得至少勾选了一项的套件：如果所有套件都没有勾选任何内容，模型就不会获得任何工具。该选择会保存在你的账户中，下次使用时保持不变；设定生成器还会将选择保存到其生成的每个条目中，并在打开该条目时恢复这些选择。已卸载的套件会被跳过，扩展已不再包含的已勾选条目会被忽略。扩展可以在Marginalia运行时加载和卸载，按钮会随之更新。

如果两个套件中有同名的函数，生成将无法启动，并会指出冲突的套件；Marginalia自带的套件之间不存在此类冲突。

<a id="as-commands"></a>

## 作为命令使用

这些套件同时也是[命令栏](../commands/index.md)和[智能体](../agents.md)中的命令（例如`/pick-real-names`、`/generate-names`、`/search-places`……）。因此，模型在此处获得的工具与智能体可以调用的工具是同一个套件，名称也相同。

<a id="from-an-older-version"></a>

## 旧版本说明

原来的**Name tools**按钮已改名为**Tools**。你之前勾选的类别，现在已在名称生成器和名称提供器的套件中保持勾选状态。你在*Settings → Extension Settings*中编写的提示（*Name generator hint*、*Name provider hint*），现在变成了这两个套件在此窗口中的提示；设置中的对应输入框已被移除。
