# 書籍

書籍とは、ひとつの物語のことです。パートごとに指示を与えるとモデルが文章を書き、書籍には関連するすべてのもの、つまりすべての分岐を含むストーリーツリー、文体を決めるプロンプト、世界観とキャラクターを収めたロアブック、要約、バックアップが保存されます。

![ストーリーエディタの書籍](../../images/hero-story-editor.png)

<a id="parts-and-branches"></a>

## パートと分岐

書籍は**パート**で構成されます。各パートはモデルの応答ひとつで、あなたがそのパートに与えた指示（場面、視点人物、登場人物と起こるべきこと）に基づいて書かれます。

パートはツリー状になっています。通常は物語を続けるだけですが、最後のパートの別バージョンを書いたり、以前のパートまで戻ってそこから別の展開で続けたりすることもできます。最初から終わりまでの each 経路が**分岐**です。作業中の分岐が**アクティブな分岐**で、ストーリーエディタに表示され、そのパートだけがモデルに送られます。詳しくは [ブランチとストーリーツリー](branches-and-story-tree.md) を参照してください。

<a id="the-book-window"></a>

## 書籍ウィンドウ

書籍を開くと、次のタブを持つウィンドウが表示されます。

| タブ | |
|---|---|
| **概要** | 名前、タグ、説明、言語、モデル、プロトコル、公開設定、文字数などです。詳しくは [書籍の管理](managing-books.md) を参照してください。 |
| **プロンプト** | この書籍のテンプレートと文体の設定です。詳しくは [書籍のプロンプト](prompts.md) を参照してください。 |
| **ロアブック** | この書籍のロアブックと、そのエントリです。サブロアブックがある場合は、2つ目のボックス**表示するロアブック**で、書籍のロアブックを変えずに、タブをそれらのいずれか（と元に戻すことも）に切り替えられます。**サブロアブック**欄でサブロアブックの名前をクリックしても同じことができます。詳しくは [ロアブック](../lorebooks/index.md) を参照してください。 |
| **ストーリー** | パートを書いて生成するストーリーエディタです。詳しくは [ストーリーエディタ](story-editor.md) を参照してください。 |
| **ブランチ表示** | すべての分岐を含むストーリーツリーです。詳しくは [ブランチとストーリーツリー](branches-and-story-tree.md) を参照してください。 |
| **バックアップ** | 書籍のバックアップです。詳しくは [書籍のバックアップ](backups.md) を参照してください。 |

書籍の日ごとの推移（語数、時間、トークン、サイズ）と、執筆した日のカレンダーは、その**統計**ウィンドウで確認できます。詳しくは [執筆統計](statistics.md) を参照してください。

物語は、*ストーリー*タブの設定メニューからファイルとして Marginalia の外に書き出せます。詳しくは [書籍のエクスポート](export.md) を参照してください。

パートのない書籍は*概要*が、パートのある書籍は*ストーリー*が最初に開きます。すべての変更はすぐに保存され、**保存**ボタンはありません。**終了**で書籍を閉じます。

パートの生成中は、生成が終わるか停止するまで、他のタブと*終了*は無効になります。
