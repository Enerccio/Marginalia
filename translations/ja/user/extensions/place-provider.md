# 場所プロバイダー

モデルが場所を作り出す代わりに、地球上の実在する場所を調べられるようにします。対象は都市、国、海と湾、川、湖、
島、山、砂漠、港と空港で、座標と所在する国も得られます。また、ある場所の周辺に何があるか、二つの場所がどれだけ離れているかも
答えられるため、実在の地図上に設定された物語は、距離や隣接関係も正しく描かれます。

この拡張機能には専用の画面はなく、設定するものもありません。[Lore Generator](lore-generator.md#tools)と
[Arc Outline](arc-outline.md)は、**ツール**ボタン（[モデルのためのツール](tools.md)）の中の *場所プロバイダー* のツール群として、
オンまたはオフの状態でモデルに提供します。また、[エージェント](../agents.md)やコマンドラインからも使えるコマンドとして用意されています。

<a id="what-it-knows"></a>

## 何を知っているか

データは [Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン）で、**主要な**場所の地図です。約 18 000 件あり、
そのうち 4 900 都市、250 か国、4 500 の州・地方、1 100 の川、500 の湖、400 の島、350 の山と山脈、1 000 の港、900 の空港を含みます。
これは地名事典ではありません。小さな小川や村は含まれていません。Natural Earth は多くの入り江も湾として描いているため、カナダの入り江を尋ねると、
その数百にのぼるブリティッシュコロンビア州の海岸線ではなく、持っている四つ（Hamilton Inlet、Bathurst Inlet、Minto Inlet、Richard Collinson Inlet）が返されます。

<a id="commands"></a>

## コマンド

いずれも読み取りのみを行います。

| コマンド | 働き |
|---|---|
| `/list-place-types` | 場所の種類（`city`、`capital`、`bay`、`inlet`、`river`、`mountain range`、`island`…）を、それぞれの件数とともに一覧表示します。 |
| `/search-places query [type [country [limit]]]` | 名前、種類、国で検索し、最も一致するものを先頭に返します。クエリに `*` を指定すると任意の名前を意味します。`/search-places * inlets Canada` はカナダの入り江を一覧表示します。 |
| `/places-near place radius_km [type [limit]]` | 場所または地点から半径内にある場所を、近い順に、キロメートル単位の距離と方角とともに返します。 |
| `/distance-between from to` | 地球上の直線距離（道路距離ではない）をキロメートルとマイルで、方角とともに返します。 |

*場所* は名前（`Ottawa`。同名の場所が複数ある場合は `Paris, France` のように、カンマの後ろに国または州を書いて選びます）または
座標（`45.42, -75.69`）で指定します。*種類* は複数形でも、人が話すとおりの書き方でもかまいません（`inlets`、`mountains`、`towns`、`states`）。
*国* は名前またはコードで指定します（`Canada`、`Czechia`、`CA`、`CAN`）。名前は大文字小文字とアクセント記号を区別せずに比較されます。
一度に返される場所は最大 100 件です（上限を指定しない場合は 25 件）。回答には、全体で何件該当したかも示されます。

種類で検索すると、名前にその語を含む、似た水域の種類の場所も見つかります。たとえば `inlet` で検索すると、Natural Earth が湾と呼んでいる Hamilton Inlet も見つかります。

<a id="using-it-from-an-agent"></a>

## エージェントから使う

コマンドの使用を許可されたエージェント（*All non-destructive* の選択と *Auditor* の役割に含まれます）は、それらを関数として呼び出せます。
これは「最初の章は、首都から海路で二日の、ノルウェーのフィヨルドに面した漁村に設定して」といったプロンプトのために作られています。エージェントは
`fjords of Norway` を検索し、一つを選び、オスロまでの距離を求めます。

<a id="usage"></a>

## 使い方

*管理 → 拡張機能* でこの拡張機能を読み込みます。Lore Generator と Arc Outline では、**ツール** の中の場所プロバイダーにある *このツール群を使う* にチェックを入れます。
そのヒントは、場所がどこにあるか、どれだけ離れているかを推測せず、実在する場所を調べるようモデルに伝えます。
