# 아크 개요

사이드바에 있는 책의 계획입니다. 아크(arc)마다 여러 챕터로 나뉘며, 각 항목의 상태가 함께 표시되고, 모델이 아크와 챕터를 대신 작성할 수 있습니다. 개요는 스토리 프롬프트의 일부가 아닙니다. 생성기와 [Side Query](side-query.md)는 요청할 때 개요를 사용할 수 있습니다.

<a id="the-arcs-tab"></a>

## Arcs 탭

[스토리 편집기](../books/story-editor.md)의 왼쪽 사이드바에는 *Outline* 옆에 **Arcs** 탭이 생깁니다. **Add new arc**를 누르면 아크의 대화상자가 열립니다:

| 항목 | |
|---|---|
| Title | 필수 항목입니다. |
| Description | 그 아크에서 일어나는 일. |
| Note (private) | 자신을 위한 메모. |
| State | **Planned**, **Current** 또는 **Finished**. |
| Linked part | 아크나 챕터가 속한 스토리의 부분. [아래](#linking-to-the-story) 참조. |

챕터도 같은 항목을 가집니다. 목록에서 각 아크는 카드로 표시되고, 그 아래에 챕터들이 들여쓰기되어 나타납니다. 카드의 색은 상태를 따릅니다. 계획됨은 회색, 현재 아크는 파란색, 완료된 아크는 제목이 흐려진 초록색입니다. 카드의 버튼은 다음과 같습니다:

| 버튼 | |
|---|---|
| 달력 / 재생 / 체크 | 상태. 상태를 바꾸는 메뉴를 엽니다. |
| 꺾쇠 (아크) | 아크의 챕터를 숨기거나 보입니다. |
| 꺾쇠 (메모가 있는 챕터) | 챕터 설명 아래의 메모를 보이거나 숨깁니다. 대화상자를 열지 않고 읽을 수 있습니다. |
| 화살표 | 아크 또는 챕터를 위아래로 옮깁니다. |
| 플러스 (아크) | 아크 끝에 챕터를 추가합니다. |
| 마법봉 (아크) | 모델에게 아크의 챕터를 써 달라고 요청합니다. [아래](#generating-chapters) 참조. |
| 압정 | 아크 또는 챕터를 스토리에서 가장 잘 보이는 부분에 연결(고정)합니다. [아래](#linking-to-the-story) 참조. |
| 과녁 (연결된 부분이 있는 아크와 챕터) | 연결된 부분으로 스토리를 스크롤합니다. |
| 펜 | 대화상자에서 엽니다. |
| 휴지통 | 삭제합니다(아크라면 모든 챕터와 함께). 확인 후 실행됩니다. |
| 로봇 (생성된 아크와 챕터) | 모델이 쓴 내용을 보여줍니다. [아래](#generating-an-arc) 참조. |

위쪽 마법봉 옆에는 깃털 달린 펜이 있습니다. 현재 챕터로부터 다음 턴의 지시문 초안을 작성합니다. [아래](#drafting-the-instructions-for-the-current-chapter) 참조.

![Arcs 탭: 완료된 아크, 현재 아크, 계획된 아크](../../images/plugin-arcoutline-tab.png)

<a id="linking-to-the-story"></a>

### 스토리와 연결하기

아크나 챕터는 **스토리의 한 부분에 연결**할 수 있어, 계획에서 본문의 해당 위치로 바로 이동할 수 있습니다. 대화상자에는 **Linked part** 항목이 있습니다. 이는 활성 분기에서 해당 부분의 위치이며, *Outline* 탭에 표시되는 것처럼 1부터 번호가 매겨집니다(`#12`). 직접 입력하거나, 옆의 **link** 버튼을 눌러 그 순간 스토리에서 **가장 잘 보이는** 부분을 가져올 수 있습니다(먼저 해당 위치로 스크롤한 다음 대화상자를 여세요). **target** 버튼은 항목에 입력된 부분으로 스토리를 스크롤합니다. 연결된 아크나 챕터는 카드에도 target 버튼이 있습니다. 카드의 **thumbtack**은 대화상자 없이 link 버튼과 같은 일을 합니다. 챕터가 시작되는 곳으로 스토리를 스크롤한 뒤 누르면 됩니다. 링크는 분기 안의 위치이므로, 앞의 부분이 삭제되거나 삽입되면 다른 부분을 가리키게 됩니다. 그럴 때는 링크를 바꾸세요. 스토리에서 가져오기를 하면 챕터가 자동으로 연결됩니다. [아래](#importing-an-arc-from-the-story) 참조.

<a id="chapter-headings-in-the-text"></a>

### 본문의 챕터 제목

위쪽 마법봉 메뉴의 **Chapter headings in the text**는 각 챕터가 [연결된](#linking-to-the-story) 부분의 시작에 제목을 씁니다. 예를 들어 `# Chapter 4: The Storm`처럼 쓰여, 스토리 본문이 챕터 구성을 담게 됩니다(Chapter Marker 확장과 내보내기가 이것을 인식합니다). 설정을 바꾸면 대화상자에 쓰일 제목과 해당 부분이 목록으로 표시됩니다:

| 옵션 | |
|---|---|
| Arcs get headings too | 꺼짐: 챕터에만 제목이 붙고 아크는 제외됩니다(`#`). 켜짐: 모든 아크에 제목이 붙고(`#`) 그 챕터는 한 단계 아래 수준으로 붙습니다(`##`). 직접 연결되지 않은 아크는 첫 번째 연결 챕터의 부분으로 갑니다. |
| Prefix of the arcs / of the chapters | 숫자 앞에 오는 단어. 처음에는 *Part*와 *Chapter*. 비우면 `4. The Storm`. |
| Numbers | 아라비아 숫자(1, 2, 3), 로마 숫자(I, II, III) 또는 없음. 챕터는 연결 여부와 관계없이 개요에서의 위치로 번호가 매겨지므로, 아직 쓰지 않은 챕터의 번호는 비어 있습니다. |
| Number the chapters from 1 in every arc | 꺼져 있으면 챕터는 책 전체에 걸쳐 번호가 매겨집니다. |
| Put the titles into the headings | 꺼짐이면 `Chapter 4`만 씁니다. |
| Remove every other heading of the story first | 새 제목을 쓰기 전에 활성 분기의 모든 제목 줄을 지웁니다. 마지막 실행 이후 챕터의 연결 위치가 바뀐 경우에 사용합니다. |
| Keep the summaries valid | 처음에는 켜짐. 제목은 사건을 바꾸지 않으므로, 변경 이전 스토리를 설명하던 요약을 다시 유효하게 표시합니다(이미 오래된 요약은 여전히 오래된 상태로 남습니다). |

**Write the headings**를 누르면 제목이 들어갑니다. 부분이 이미 시작하고 있던 제목은 교체되므로, 개요를 바꾼 뒤 다시 실행해도 제목이 두 번 들어가지 않습니다. **Remove all headings**(확인 후)는 활성 분기 본문에서 모든 제목 줄을 삭제합니다. 바뀐 부분마다 이전 본문은 기록에 남습니다. 연결이 없는 완료 또는 현재 챕터와 활성 분기의 끝을 넘어선 연결은 제목을 받지 못하며 보고됩니다. 옵션은 기억됩니다.

<a id="the-note-of-a-chapter"></a>

### 챕터의 메모

메모가 있는 챕터는 오른쪽에 꺾쇠가 보입니다. 이것을 누르면 목록에서 설명 아래에 메모가 열리므로, 대화상자를 열지 않고도 챕터의 세부 내용(예: 모델이 작성한 내용)을 읽을 수 있습니다. 다시 누르면 메모가 숨겨집니다. 어떤 메모가 열려 있는지는 저장되지 않습니다.

![메모가 표시된 챕터](../../images/plugin-arcoutline-note.png)

<a id="moving-chapters-between-arcs"></a>

### 아크 사이에서 챕터 옮기기

아크의 첫 자리에서 위로 옮긴 챕터는 앞 아크의 끝으로 갑니다. 마지막 자리에서 아래로 옮긴 챕터는 다음 아크의 시작으로 갑니다. 필요한 만큼 화살표를 계속 누르면 챕터를 원하는 곳까지 옮길 수 있습니다.

<a id="drafting-the-instructions-for-the-current-chapter"></a>

### 현재 챕터의 지시문 초안 작성하기

*Add new arc* 옆의 깃털 달린 펜은, 스토리가 머무는 챕터의 데이터를 **Plan of the Story**로 삼아 모델이 다음 턴의 [지시문 초안](../books/story-editor.md#drafting-the-instructions)을 작성하도록 하는 창을 엽니다. 현재 챕터는 **Current**로 표시된 첫 챕터입니다. 그런 챕터가 없으면 **Finished**가 아닌 첫 챕터이고, 챕터가 아직 없는 현재 표시 아크는 단독으로 쓰입니다. 모델은 그 아크와 챕터를 설명 및 메모와 함께 받고, 그 다음 챕터의 제목과 설명(메모는 제외)을 받습니다. 스토리가 아직 거기까지 가면 안 된다는 경고와 함께입니다. 창은 새 턴 패널의 *Instructions*에 입력한 내용을 안내로 삼아 시작합니다. **Use as Instructions**를 누르면 초안이 그 패널에 들어가고 패널이 열립니다. 현재 챕터가 없으면 버튼이 그 사실을 알려 줍니다.

같은 데이터는 [Side Query](side-query.md)의 원천이기도 합니다. [아래](#the-outline-as-a-source-for-other-extensions) 참조.

<a id="finishing-an-arc"></a>

### 아크 완료하기

아크를 **Finished**로 표시하면 그 아크의 모든 챕터도 함께 **Finished**로 표시됩니다. 아크를 다른 상태로 바꾸면 챕터는 그대로 둡니다.

개요는 바꾸는 즉시 책과 함께 저장되므로, 책의 백업에도 포함됩니다.

<a id="the-outline-as-a-source-for-other-extensions"></a>

## 다른 확장 기능의 자료원으로서의 개요

개요는 책에 관한 데이터의 원천으로 다른 확장 기능에도 제공됩니다. [Side Query](side-query.md)에서 플러그 팝오버의 **Arc outline**을 체크하면, 질문과 함께 아크, 상태, 설명, 챕터를 보낼 수 있습니다. 두 가지 버전이 있습니다. **Arc outline**은 간결한 버전(설명만)이고, **Arc outline (with notes)**는 모든 아크와 챕터의 메모를 설명 아래에 덧붙입니다. 생성된 아크와 챕터의 세부 내용이 있는 곳이 바로 여기입니다. 자신의 비공개 메모는 두 번째 항목을 체크했을 때만 전송됩니다. 세 번째 원천인 **Arc outline: current chapter**는 스토리가 머무는 아크와 챕터만 보냅니다([현재 챕터의 지시문 초안 작성하기](#drafting-the-instructions-for-the-current-chapter) 참조).
<a id="generating-an-arc"></a>

## 아크 생성하기

**Add new arc**(새 아크 추가) 버튼 옆의 마법봉 버튼을 누르면 세 개의 항목이 있는 메뉴가 열립니다. **Generate an arc**(아크 생성)는 모델에게 새 아크를 써 달라고 요청하고, **Import from story**(이야기에서 가져오기)는 이미 쓴 내용을 요약하며([아래](#importing-an-arc-from-the-story) 참고), **Develop the plot**(줄거리 발전)은 이야기가 어디로 갈지 모델과 나누는 대화입니다([아래](#developing-the-plot-in-a-conversation) 참고).

![마법봉 메뉴](../../images/plugin-arcoutline-menu.png)

**Generate an arc** 대화상자는 두 부분으로 나뉩니다.

왼쪽에는 다음이 있습니다:

| | |
|---|---|
| Prompt | 모델에게 주는 지시문으로, 세 개의 변수가 있습니다: `{{backgroundLore}}`(책의 로어북과 하위 로어북의 항목), `{{existingArcs}}`(아크와 챕터, 그 상태와 설명. 개인 메모는 제외됩니다), `{{specification}}`. 처음에는 *Settings → Extension Settings → Arc Outline*(설정 → 확장 설정 → Arc Outline)의 프롬프트로 채워집니다(설정을 바꾸지 않았다면 기본 프롬프트). 여기서 고친 내용은 이번 생성에만 적용됩니다. |
| Specification | 아크에서 원하는 것: 주제, 등장인물, 이야기가 향할 곳. 비워 둘 수 있습니다. |
| Tools | [모델이 사용할 도구 모음](tools.md)이 설치되어 있을 때만 표시됩니다(이름, 장소). 어떤 도구 모음과 그 범주를 모델이 사용할 수 있는지 정하며, 모델이 무언가를 지어내는 대신 이를 사용하게 됩니다. [Lore Generator](lore-generator.md)에서와 같습니다. |
| Model, Protocols | 책의 모델과 프로토콜로 시작합니다(책에 설정이 없으면 *Settings*의 기본값). 이번 생성에만 다른 모델을 쓰려면 바꾸면 됩니다. 선택은 저장되지 않습니다. |
| Generate | 모델을 실행합니다. 실행 중에는 버튼이 빨간색 **Stop**(중지)이 되고, 대화상자의 나머지 항목은 모두 비활성화됩니다. |

오른쪽에는 모델이 써 내려가는 **reasoning**(추론)이 보이고, 답변이 시작되자마자 모델이 제안하는 **arc**(아크)가 나타납니다. 이름, 짧은 설명, 그리고 더 긴 노트로 구성되며, 아웃라인의 아크처럼(설명 아래에 노트가 붙어) 표시되고 답변이 흘러 들어오는 대로 커집니다. 아웃라인이 보여 주는 것은 설명이므로, 모델에게는 설명을 두어 문장으로 짧게 유지하고 세부 내용은 노트에 적으라고 요청합니다. 노트는 저장된 아크의 **Note**(노트)가 됩니다.
모델의 답변이 끝나면 답변이 검사됩니다. 올바른 아크가 아니라면(예를 들어 노트가 없으면) 대화상자가 이를 알려 주고, 그 아크는 저장할 수 없습니다.

![아크 생성 중](../../images/plugin-arcoutline-generate-arc.png)

**Save as arc**(아크로 저장)는 아크를 아웃라인의 끝에 추가합니다. 다시 시도하려면 같은 프롬프트나 명세를 그대로 두거나 바꾼 뒤 **Generate**를 한 번 더 누르십시오. 이전 답변은 대체됩니다.

<a id="importing-an-arc-from-the-story"></a>

## 이야기에서 아크 가져오기

마법봉 메뉴의 **Import from story**는 이야기의 일부를 모델이 읽고 그것을 챕터들과 함께 하나의 아크로 정리하게 합니다. 이미 쓴 책을 아웃라인으로 가져오고 싶을 때 쓰십시오. 모델은 대화상자를 여는 시점의 책의 [활성 가지](../books/branches-and-story-tree.md)를 항상 읽습니다. 대화상자는 아크용과 비슷하며, 왼쪽에 다음 선택 항목이 있습니다:

| | |
|---|---|
| From message, To message | 보낼 이야기의 범위. 가지에서 텍스트가 있는 메시지에는 1부터 번호가 붙습니다. 처음에는 가지 전체가 선택됩니다. 각 필드 아래에는 그 필드가 가리키는 메시지의 앞부분이 표시됩니다. |
| Number of chapters (optional) | 숫자를 고르면 정확히 그 수만큼의 챕터를 받습니다(다른 수의 답변은 거부됩니다). 비워 두면 모델이 이야기가 자연스럽게 나뉘는 곳에서 나눕니다. |
| Link the chapters to the parts of the story | 처음에는 켜져 있습니다. 메시지는 보내는 범위 안에서 1부터 번호가 매겨지며, 모델은 각 챕터가 어느 메시지에서 시작하는지 알려 줍니다. 챕터는 그 이야기 부분에 [연결](#linking-to-the-story)됩니다(전체 가지 기준 번호이므로 범위와 상관없이 정확합니다). 아크는 첫 챕터가 시작하는 부분에 연결됩니다. 보내지 않은 메시지를 가리키는 답변이면 해당 챕터는 연결되지 않습니다. |
| State of the imported arc and its chapters | 이야기는 이미 완성되었으므로 처음에는 **Finished**(완료)입니다. 필요하면 **Current**(진행 중)나 **Planned**(예정)를 고르십시오. |
| Token counter | 범위에 있는 메시지 수와 그 대략적인 토큰 수, 그리고 전체 프롬프트(지시문, 로어, 아웃라인, 이야기)의 대략적인 토큰 수를 모델이 받는 양과 함께 보여 줍니다. 프롬프트가 맞지 않으면 경고로 바뀌며, 그때는 메시지를 더 적게 고르십시오. 범위, 챕터 수, 프롬프트, 모델에 따라 값이 갱신됩니다. |
| Prompt | 모델에게 주는 지시문으로, 변수 `{{backgroundLore}}`, `{{existingArcs}}`, `{{story}}`(범위의 메시지들)와 `{{numberOfChapters}}`가 있습니다. 처음에는 *Settings → Extension Settings → Arc Outline*의 **Story import prompt**(이야기 가져오기 프롬프트)로 채워집니다. |

![이야기에서 아크 가져오기](../../images/plugin-arcoutline-import.png)

여기에는 도구가 없습니다. 이름은 이야기 안에 있습니다. 오른쪽에는 추론이 나오고, 이어서 모델이 쓰는 아크와 그 챕터들이 나타납니다. **Save as arc**를 누르면 챕터들과 함께 아크가 아웃라인의 끝에 추가됩니다. 각 챕터는 모델의 추론과 답변을 그대로 간직하며, 각자 로봇 버튼을 가집니다. 긴 이야기는 여러 번에 나누어, 범위마다 하나의 아크씩 가져오는 것이 가장 좋습니다.
<a id="developing-the-plot-in-a-conversation"></a>

## 대화로 플롯 발전시키기

마법봉 메뉴의 **Develop the plot**을 선택하면 플롯에 관해 모델과 대화하는 채팅이 열립니다. 대화만으로는 책의 내용이 바뀌지 않습니다. 모델은 여러분이 보내기로 고른 것만 보고 답하며, 합의한 내용이 생기면 클릭 한 번으로 아크 생성기에 넘길 수 있습니다.

왼쪽에서는 모델이 무엇을 보고 어떻게 도울지 고르고(선택은 다음번을 위해 기억됩니다), 오른쪽에는 채팅이 있습니다:

![플롯 마법사: 왼쪽의 옵션과 오른쪽의 대화](../../images/plugin-arcoutline-wizard.png)

| | |
|---|---|
| 모델, 프로토콜 | 책의 모델과 프로토콜로 시작합니다. 변경하면 이 대화에만 적용됩니다. |
| 모델의 도움 방식 | **자유 대화**(여러분이 주도합니다), **방향 탐색**(이야기가 다음에 갈 수 있는 서로 다른 여러 방향), **문제 찾기**(해결되지 않은 실타래, 아무도 지키지 않은 약속, 설정과의 모순, 전개 속도) 또는 **아이디어 확장**(여러분의 아이디어를 전제, 전환점, 결말, 그리고 여러분의 아크 뒤에 어울리는 챕터로 키웁니다). |
| 로어북 보내기 | 책의 로어북과 하위 로어북의 항목들. |
| 개요 보내기 | **보내지 않음**, **설명만**, 또는 **메모 포함**(여러분의 비공개 메모도 포함). |
| 노트 보내기 | [Story Notes](story-notes.md)가 설치된 경우에만: **보내지 않음**, **제목과 첫 줄**(기본값) 또는 어시스턴트에게 숨긴 페이지를 제외한 노트 **전체 텍스트**. |
| 이야기 요약 보내기 | 요약은 생성 때와 같은 방식으로, 가장 최신 요약까지의 이야기를 대신합니다. |
| 이야기의 최신 파트 보내기 | 최신 요약 이후의 파트(요약을 끄면 모든 파트), **이야기 토큰**에 맞는 가장 최신 파트. 각 파트는 이야기 개요에 있는 번호와 함께 모델에 보입니다. |
| 이야기 토큰 | 이야기 파트에 쓸 최대 토큰 수. 비워 두면 모델이 받는 양의 3분의 1입니다. |
| 프롬프트 | 모델을 위한 지시문이며, 변수 `{{backgroundLore}}`, `{{outline}}`, `{{notes}}`, `{{summaries}}`, `{{story}}`, `{{mode}}`를 사용할 수 있습니다. 변경 내용은 기억됩니다. |

옵션 아래의 한 줄에는 모델이 받는 요약과 이야기 파트의 개수, 그리고 요청이 모델이 받는 것 중 얼마만큼의 토큰을 차지하는지가 표시됩니다. 맞지 않으면 경고로 바뀌니, 더 적게 보내거나 [채팅을 요약](#chats-branches-and-summaries)하세요. 메시지를 보낼 때마다 책을 다시 읽으므로, 개요나 이야기를 바꾸면 다음 답변에 바로 반영됩니다.

오른쪽은 채팅입니다. 메시지를 입력하고 **Send**를 누르세요(모델이 쓰는 동안에는 **Stop**이 됩니다. 이미 도착한 내용은 남습니다). 각 메시지에는 버튼이 있습니다: 복사, **여기서 분기**, 삭제, 그리고 모델의 답변에는 마법봉도 있어서 **Generate an arc from this message**를 누르면 그 메시지를 명세로 삼아 아크 생성기가 열립니다. 논의가 길었다면, 먼저 모델에게 여러분이 정한 내용을 명세로 요약해 달라고 하세요.

<a id="letting-the-model-change-the-book"></a>

### 모델이 책을 바꾸도록 허용하기

옵션 아래에는 **What the model may do**가 있습니다. 아무것도 체크하지 않으면 채팅은 대화일 뿐입니다. 그룹을 체크하면 모델은 그 그룹의 도구를 얻고, 여러분이 요청하거나 동의할 때 이를 사용할 수 있습니다. 모델은 추가하기 전에 먼저 살펴보고, 교체보다 추가를 우선하며, 무엇을 했는지 말하도록 지시받습니다:

| 그룹 | 모델이 할 수 있는 것 |
|---|---|
| **Planner** | [플래너](../books/story-editor.md#the-planner-tab)의 장면 목록을 보고, 장면을 추가, 변경, 이동, 삭제하고 완료 표시를 할 수 있습니다. |
| **Lorebook** | 로어를 검색하고 읽으며, 항목을 만들고 기존 항목을 변경할 수 있습니다(삭제는 불가). |
| **Outline** | 개요를 읽고, 아크와 챕터를 추가, 변경, 이동할 수 있습니다(삭제는 불가). |
| **Notes**([Story Notes](story-notes.md)가 설치된 경우) | 노트를 검색하고 읽으며 링크를 따라갈 수 있고, 여러분이 무언가를 기억해 두라고 하면 페이지를 추가하거나 기존 페이지에 덧붙이며, 페이지의 텍스트를 바꿀 수 있습니다(페이지 삭제는 불가). 어시스턴트에게 숨긴 페이지에는 접근할 수 없습니다. |
| **Characters**([Character Tracker](character-tracker.md)가 설치된 경우) | 책의 등장인물과 그들의 관계를 읽고, 등장인물과 관계를 추가하고, 변경(이름, 한 줄 소개, 메모, 색상)하고, 삭제할 수 있습니다. 삭제만 실행 전에 확인을 받으며, 변경은 확인을 받지 않습니다. 변경 내용은 채팅과 Characters 탭에서 볼 수 있습니다. 모델은 목록의 번호로 등장인물을 지목할 수 있으며, 질문과 채팅에는 번호와 함께 등장인물의 이름이 표시됩니다. |
| **Generators** | 아크 생성기와 챕터 생성기를 호출하고, [Lore Generator](lore-generator.md)가 설치된 경우 로어 항목을 생성할 수 있습니다. 이들은 초안을 반환할 뿐, 모델이 지시받지 않는 한 아무것도 저장하지 않습니다. 모델은 초안을 여러분에게 보여 주고, 여러분이 동의하면 저장합니다. |
| **Tools**(버튼, [도구 모음](tools.md)이 설치된 경우) | 생성기에서와 같이 이름 도구(인물 이름, 장소 이름)를 사용하므로, 모델은 실제 이름을 제안할 수 있습니다. |

- **변경하거나 삭제하기 전에 나에게 물어보기**(기본적으로 켜짐): 기존 내용(로어 항목, 장면, 아크)의 텍스트를 바꾸는 것과 삭제는, 모델이 넘기려는 내용과 함께 먼저 여러분에게 보여지며, 모델은 **Allow** 또는 **Refuse**를 기다립니다. 장면, 항목, 아크를 추가하는 것은 묻지 않습니다. 대신 채팅과 플래너, 로어북, 개요에서 확인할 수 있고, 삭제도 할 수 있습니다.
- 모델이 호출한 모든 도구는 해당 답변 아래에 나열됩니다(이름과 표시가 있는 줄: ✓ 성공, ✗ 실패. 열면 무엇을 넘겼고 무엇이 돌아왔는지 볼 수 있습니다). 다음 메시지에는 모델이 한 호출과 그 결과가 함께 전달되므로(긴 결과는 잘림), 모델은 이미 한 일을 알고 같은 항목을 다시 만들지 않습니다. 이 내용은 채팅의 토큰 한도에도 포함됩니다.
- 도구의 비용: 도구 설명은 모든 요청에 포함되므로, 컨텍스트가 부족한 모델은 여유가 줄어듭니다. 함수 호출을 할 수 있는 모델에서만 작동하며, 그렇지 않은 모델이면 대화 상자가 그렇다고 알려 줍니다.

![모델이 플래너에 장면 두 개를 추가했으며, 그 호출은 답변 아래에 나열되어 있습니다](../../images/plugin-arcoutline-wizard-tools.png)

<a id="chats-branches-and-summaries"></a>

### 채팅, 분기, 요약

책에는 원하는 만큼 채팅을 둘 수 있습니다. 메시지 위의 목록에서 하나를 고르고, **+**는 새 채팅을 시작하며, 연필은 이름을 바꾸고(그 전까지는 여러분의 첫 메시지 이름이 붙습니다), 휴지통은 삭제합니다. 채팅은 책과 함께 저장됩니다.

- **Branch**는 채팅을 있는 그대로 새 채팅으로 복사합니다. 메시지의 분기 버튼은 그 메시지까지를 복사하므로, 그 지점부터 다른 방향으로 대화를 이어 갈 수 있습니다. 이후 복사본은 원본과 아무 관련이 없습니다.
- **Summarize the chat**은 먼저 요약이 무엇을 남기거나 강조해야 하는지 묻고(선택 사항이며, 예를 들어 "배신자에 관한 반전과 우리가 거절한 결말은 남겨 줘", 비워 두면 모델이 결정합니다), 그다음 모델에게 채팅의 요약(정한 내용, 거절한 내용, 아직 열린 문제, 확정된 이름)을 요청해 메시지로 추가합니다. 이후 모델은 그 요약과 그 뒤의 메시지만 받고, 위쪽의 메시지들은 **받지 않습니다**. 그 메시지들은 화면에 흐리게 남아 있습니다. 채팅이 모델에게 너무 길어졌을 때, 또는 결정 사항은 잃지 않고 깨끗한 상태에서 다시 시작하고 싶을 때 쓰세요. 나중에 다시 요약하면 새 요약이 이전 요약까지 포함합니다. 채팅 전체를 모델에게 계속 보여 주고 싶다면, 먼저 분기하세요.

![요약에 무엇을 남길지 묻는 질문](../../images/plugin-arcoutline-wizard-summarize.png)

![요약 이후의 채팅: 그 위의 메시지들은 흐리게 화면에 남아 있습니다](../../images/plugin-arcoutline-wizard-summary.png)
<a id="generating-chapters"></a>

## 챕터 생성

아크의 마술봉 버튼은 모델에게 그 아크를 챕터로 나누어 달라고 요청합니다. 대화상자는 아크용과 비슷하며, 왼쪽에 다음 선택지가 있습니다:

| | |
|---|---|
| 모델이 알고 있는 이야기 범위 | **Whole story so far**: 이 아크까지의 모든 아크와 그 챕터 전부. **Arc summaries only**: 같은 아크들이지만 챕터는 제외. **Arc summaries and finished chapters**: 같은 아크들이며, *Finished*로 표시한 챕터만 포함. 이 아크 이후의 아크는 절대 전송되지 않습니다. |
| 챕터 전반에 대해 원하는 것 | 진행 속도, 어조, 반드시 일어나야 할 일. 비워 둘 수 있습니다. |
| 챕터 수 | 글로 적거나("about eight" 같이) 정확한 숫자를 고를 수 있습니다. 숫자를 고르면 챕터마다 내용을 적을 수 있는 입력란이 추가되며, 모두 선택 사항입니다. 둘 중 하나를 사용하면 다른 쪽은 지워집니다. 정확한 숫자를 지정하면, 그와 다른 개수의 챕터를 담은 답변은 거부됩니다. |
| 프롬프트 | 모델에 대한 지시문이며, 변수 `{{backgroundLore}}`, `{{outline}}`, `{{numberOfChapters}}`, `{{generalSpecification}}`, `{{chapterSpecification}}`를 사용할 수 있습니다. 처음에는 *Settings → Extension Settings → Arc Outline*의 **Chapter generation prompt**로 채워집니다. |

오른쪽에는 먼저 추론 과정이, 그다음 이미 가진 챕터가 있는 아크와, 모델이 작성하는 대로 나타나는 새 챕터가 보입니다. **Save as chapters**를 누르면 새 챕터가 아크 끝에 추가되며, 각 챕터에는 간략한 설명이 붙고 자세한 내용은 노트에 들어갑니다(아크와 같습니다). 새로 만든 모든 챕터는 모델의 추론 과정과 답변을 보존하며, 각자 로봇 버튼을 가집니다.

![아크의 챕터 생성하기](../../images/plugin-arcoutline-generate-chapters.png)

모델이 작성한 아크나 챕터는 그것이 나온 **추론 과정**과 **답변**을 보존합니다. 그 위의 로봇 버튼을 누르면 이 내용이 작은 팝오버로 열리며, 화면을 가리지 않습니다.

![모델이 아크에 대해 작성한 내용](../../images/plugin-arcoutline-generated.png)

## 명령

개요와 그 생성기도 [명령](../commands/index.md)으로 사용할 수 있으며, 명령줄과 [에이전트](../agents.md)에서 쓸 수 있습니다. 명령은 열려 있는 책에 대해 동작하며(에이전트의 경우 작업 사본에 대해), 열려 있는 Arcs 탭에는 변경 사항이 즉시 나타납니다. 아크와 챕터는 개요에 표시된 **번호**로 지정합니다. 첫 번째 아크는 `1`, 아크의 첫 번째 챕터는 `1`입니다(앞에 있는 항목이 추가, 삭제 또는 이동되면 번호가 바뀝니다). 아크나 챕터를 변경하는 명령은 지정한 필드만 받으며, 빈 텍스트를 주면 설명이나 노트가 지워집니다.

| 명령 | 하는 일 |
|---|---|
| `/get-arc-outline [arc [notes]]` | 아크와 그 챕터, 상태, 설명을 JSON으로 반환합니다. 비공개 노트는 `notes` `true`와 함께 있을 때만 포함하며, `arc`은 해당 아크 하나만 반환합니다. 읽기 전용입니다. |
| `/add-arc title [description [note [state [position]]]]` | 아크를 추가합니다. 끝에 또는 `position` 위치에 추가합니다. |
| `/update-arc arc [title [description [note [state]]]]` | 아크를 변경합니다. `state`는 `PLANNED`, `CURRENT` 또는 `FINISHED`입니다(아크를 완료하면 그 챕터도 완료됩니다). |
| `/move-arc arc position` | 아크를 `position` 위치로 옮깁니다(1이 첫 번째입니다). |
| `/delete-arc arc` | 확인을 거친 후 아크를 챕터와 함께 삭제합니다. |
| `/add-outline-chapter arc title [description [note [state [position]]]]` | 아크에 챕터를 추가합니다. |
| `/update-outline-chapter arc chapter [title [description [note [state]]]]` | 챕터를 변경합니다. |
| `/move-outline-chapter arc chapter position [to_arc]` | 챕터를 같은 아크 안에서 옮기거나, 아크 `to_arc`로 옮깁니다. |
| `/delete-outline-chapter arc chapter` | 확인을 거친 후 챕터를 삭제합니다. |
| `/generate-arc [specification [save]]` | *Generate an arc*와 같이, 모델에게 새 아크를 요청합니다. |
| `/generate-outline-chapters arc [specification [count [context [save]]]]` | 아크의 마술봉 버튼과 같이, 모델에게 아크의 챕터를 요청합니다. `count`는 정확한 챕터 수이고, `context`는 *What the model knows of the story* 선택지의 `EVERYTHING`(기본값), `ARCS_ONLY` 또는 `ARCS_AND_FINISHED`입니다. |
| `/import-arc-from-story [from [to [count [state [save [mapParts]]]]]]` | 활성 브랜치의 메시지 `from`부터 `to`까지를 (*Import from story*에서처럼 텍스트가 있는 메시지 중 번호를 매겨) 챕터가 있는 아크로 요약하도록 모델에 요청합니다. `state`(기본값 `FINISHED`)은 저장된 아크와 그 챕터의 상태입니다. `mapParts` `true`와 함께 사용하면 모든 챕터가 자신이 시작되는 메시지에 연결되며(대화상자의 *Map parts* 체크 박스가 하는 것처럼 *Linked part*로 설정), 답변에 각 챕터의 구간(part)이 포함됩니다. |

세 가지 생성 명령은 대화상자와 같은 프롬프트(*Extension Settings → Arc Outline*의 설정 또는 기본값), 책의 모델과 프로토콜(책에 모델이 없으면 기본 모델)을 사용하며 도구는 쓰지 않습니다. 이름이 필요한 호출자는 [Name generator](name-generator.md) 또는 [Name provider](name-provider.md)의 명령으로 이름을 얻어 명세에 기록하면 됩니다. 대화상자와 마찬가지로 요청받았을 때만 저장합니다. `save` `false`(기본값)를 사용하면 아크나 챕터를 JSON으로 반환하고 아무것도 저장하지 않으며, `save` `true`를 사용하면 개요에 추가합니다(아크는 끝에, 챕터는 아크의 끝에). 이때 답변에는 추가된 항목의 번호가 포함됩니다. 이야기가 모델의 허용 범위를 넘을 만큼 길면 `/import-arc-from-story`가 거부하므로 메시지를 더 적게 선택하세요. 생성 명령은 시간이 걸리며, 실행이 중지되면 함께 멈춥니다.

추가와 변경은 파괴적이지 않으며, 파괴적인 것은 두 개의 `delete` 명령뿐입니다. 에이전트는 이 명령에 대해 사용자에게 묻도록 설정될 수 있습니다.
