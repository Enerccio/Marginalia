# 리뷰어

모델이 여러분이 작성한 글을 검토하게 합니다. 독자 반응, 편집자의 비평, 연속성 점검 등 무엇이든 프롬프트로 요청할 수 있습니다. 리뷰는 파트와 함께 이야기 옆에 보관되며, 책의 일부가 되지는 않습니다.

![스토리 파트에 대한 리뷰](../../images/plugin-reviewer.png)

<a id="reviewing-a-part"></a>

## 파트 리뷰하기

[스토리 편집기](../books/story-editor.md)의 각 파트 메뉴(☰)에는 **리뷰** 하위 메뉴가 있습니다.

| 항목 | |
|---|---|
| **리뷰 보기 / 생성** | 리뷰 대화상자를 엽니다. 파트에 리뷰가 없으면 바로 하나를 생성합니다. |
| **고급 옵션** | [고급 옵션](#advanced-options)을 연 뒤, 그 옵션으로 리뷰를 생성합니다. |
| **리뷰 삭제** | 해당 파트의 리뷰를 모두 삭제합니다. |

리뷰 대화상자에서는 다음과 같이 할 수 있습니다.

- **‹** / **›**로 파트의 리뷰를 넘겨 봅니다. 마지막 리뷰에서 **›**를 누르면 새 리뷰를 생성합니다.
- **생성 중지**는 작성 중인 리뷰를 중단합니다.
- 리뷰 텍스트를 클릭하면 편집할 수 있으며, 입력란 바깥을 클릭하면 저장됩니다.
- *사고 과정*은 [추론 모델](../inference-providers.md#reasoning-models)의 추론 내용을 보여 줍니다.
- **닫기**는 대화상자를 닫습니다.

<a id="what-the-model-gets"></a>

## 모델이 받는 내용

기본적으로 리뷰는 파트를 작성할 때 사용한 **것과 같은 프롬프트**를 사용합니다(*표준 프롬프트 정보 사용*). 시스템 프롬프트(설정집과 요약 포함), 앞선 파트들, 그리고 해당 파트, 마지막으로 리뷰 프롬프트 순서입니다. 모델은 이야기의 전체 맥락을 갖춘 상태에서 파트를 검토합니다.

프로필에 **사전 프롬프트**가 설정되어 있다면, 시스템 메시지로 가장 먼저 전달됩니다.

<a id="advanced-options"></a>

## 고급 옵션

| 옵션 | |
|---|---|
| **프롬프트 재정의** | 이 리뷰에만 쓸 다른 리뷰 프롬프트입니다. 프로필의 프롬프트로 시작합니다. |
| **표준 프롬프트 정보 사용** | 켜면: 위에서 설명한 대로 파트를 작성할 때 사용한 프롬프트를 씁니다. 끄면: 아래 옵션에 따라 스토리 파트만 보냅니다. |
| **설정집 포함** | (끈 경우에만) 파트를 작성할 때 활성화되어 있던 설정을 추가합니다. |
| **요약 포함** | (끈 경우에만) 먼저 이야기의 [요약](../books/summaries.md)을 보낸 다음, 가장 최근 요약 이후의 파트를 보냅니다. 생성할 때와 같은 방식입니다. 가장 최근 요약이 적용된 파트와 그 이전의 모든 파트는 요약으로 대체됩니다. 요약은 토큰 한도에서 먼저 자리를 차지하고, 나머지 자리는 파트가 가장 최근 것부터 차지합니다. 요약을 만든 뒤 해당 이야기가 변경되었다면 그 요약은 보내지 않습니다(리뷰가 요약을 삭제하지는 않습니다). 끄면: 요약 없이, 들어갈 만큼의 최근 파트를 보냅니다. |
| **원문 텍스트 보내기** | 번역기([실시간 언어 번역기](real-language-translator.md), [컨랭 번역기](conlang-translator.md))가 로드되어 있을 때만 표시됩니다. 끄면: 모든 모델이 그러하듯, 리뷰는 번역된 대사 뒤에 있는 영어 원문을 읽습니다. 켜면: 검토 대상 파트(그리고 *표준 프롬프트 정보 사용*을 끈 경우에는 앞선 파트)를 저장된 그대로, 대사는 번역된 상태로 보냅니다. *표준 프롬프트 정보 사용*을 켠 상태에서 파트를 작성할 때 쓴 프롬프트는 영어 원문으로 만들어졌으므로, 그대로 유지됩니다. |
| **토큰 한도** | (끈 경우에만) 보낼 이야기의 토큰 수입니다. 검토 대상 파트까지 포함하여 가장 최근 파트부터, 들어갈 만큼 보냅니다. 모델의 프롬프트가 차지하는 공간을 먼저 확보합니다. |

*표준 프롬프트 정보 사용*을 끄면, 대화상자에 요청의 크기(*총 토큰*)가 표시됩니다. **생성**을 누르면 이 옵션을 적용한 리뷰 대화상자가 열리며, 그 대화상자에서 이후에 생성하는 리뷰도 같은 옵션을 사용합니다.

![고급 리뷰 옵션](../../images/plugin-reviewer-advanced.png)

## 프로필

리뷰어 설정은 **설정 → 확장 설정 → 리뷰어 설정**에 있습니다. 설정은 **프로필** 단위로 구성됩니다.

![리뷰어 설정](../../images/plugin-reviewer-settings.png)

| 필드 | |
|---|---|
| **프로필** | 편집할 프로필입니다. 모든 리뷰에 이 프로필이 사용됩니다. |
| **새로 만들기**, **이름 바꾸기**, **삭제** | 프로필을 관리합니다. *_Default* 프로필은 이름을 바꾸거나 삭제할 수 없습니다. |
| **리뷰어 모델** | 리뷰를 작성하는 [추론 제공자](../inference-providers.md)입니다. 비워 두면 책의 모델을 사용합니다. |
| **리뷰어 프로토콜** | [프로토콜](../protocols.md)입니다. 비워 두면 책의 프로토콜을 사용합니다. |
| **리뷰 사전 프롬프트(시스템)** | 가장 먼저 보내는 시스템 메시지입니다. 예: *당신은 까다로운 소설 편집자입니다.* |
| **리뷰 사후 프롬프트(사용자)** | 리뷰 요청으로, 가장 마지막에 보냅니다. |

변경 사항을 유지하려면 *설정* 페이지 상단의 **저장**을 클릭하세요.

기본 사후 프롬프트는 이야기 포럼의 토론을 흉내 냅니다. 서로 다른 독자 서른 명이 긍정적이거나 부정적인 답글을 단, 가상의 스레드입니다. 다른 아이디어는 다음과 같습니다.

- *마지막 파트에서, 앞선 이야기와 비교해 연속성 오류를 나열하세요. 해당 문장을 인용하세요.*
- *라인 편집자로서, 마지막 파트의 상투적 표현, 반복, 약한 동사를 지적하고 제안을 덧붙이세요.*
- *처음 읽는 독자가 이 파트의 끝에서 어떤 기분일지, 그리고 다음에 무엇을 기대할지 서술하세요.*

리뷰 종류마다 프로필을 하나씩 만들고, 리뷰하기 전에 원하는 프로필을 선택하세요. 리뷰에 더 저렴한 모델을 쓰면 비용을 줄일 수 있습니다. 그 모델을 프로필의 *리뷰어 모델*로 설정하세요.

<a id="storage"></a>

## 저장

리뷰는 스토리 파트와 함께 저장되므로, [책 백업](../books/backups.md)과 사본에도 포함됩니다. [가지 이야기 만들기](../books/branches-and-story-tree.md#branching-from-an-earlier-part)는 리뷰를 복사하지 않습니다. 프로필은 사용자 설정에 저장됩니다.
