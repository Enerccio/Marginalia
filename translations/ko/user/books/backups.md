# 책 백업

책 백업은 책 한 권의 스냅샷입니다. 설정과 프롬프트, 모든 분기의 모든 파트, 요약, 태그, 로어북이 포함됩니다. 백업은 이야기의 이전 상태로 돌아가거나, 책을 복사하거나, 책을 다른 Marginalia 설치본이나 다른 사용자에게 옮길 때 사용합니다.

책 백업은 관리자가 전체 설치본에 대해 만드는 [데이터베이스 백업](../administration/database-backups.md)과 별개입니다.

![책의 백업 탭](../../images/book-backups.png)

<a id="taking-a-backup"></a>

## 백업 만들기

책의 **백업** 탭에서 **백업 만들기**를 클릭합니다. 백업은 목록 맨 위에 나타나며, **날짜**, 포함된 **메시지**(파트) 수, 그리고 파트가 사용하는 **이미지**([파트의 그림](story-editor.md#images)) 수가 함께 표시됩니다.

백업은 [아래](#automatic-backups)에서 설명하는 것처럼 자동으로 만들 수도 있습니다.

백업에는 전체 이야기 트리, 요약, 파트의 [주석](annotations.md)이 들어 있습니다. 백업을 복원하거나, 책을 복사하거나, 백업을 가져오면 주석도 함께 돌아옵니다.

<a id="the-history-of-the-parts"></a>

## 파트의 기록

백업에는 요청하지 않으면 파트의 [버전 기록](version-history.md)이 포함되지 않습니다. **백업 만들기** 옆의 **버전 기록 포함**을 체크하세요. 처음에는 체크가 해제되어 있습니다. 기록의 크기가 이야기의 몇 배가 될 수 있기 때문입니다. 이런 백업을 책으로든 복사본으로든 복원하면, 버전은 이름, 생성된 버전의 추론 과정, 기록의 휴지통과 함께 돌아옵니다. 버전은 복원되는 책의 한도에 맞춰 잘려 나갑니다. 자동 백업에는 기록이 포함되지 않습니다. 기록 없이 백업을 복원하면 각 파트에 최초 버전 하나만 생깁니다. 기록 기능이 생기기 전에 만든 책과 같은 방식입니다.

<a id="backups-and-folders"></a>

## 백업과 폴더

백업에는 책이 들어 있던 [폴더](folders.md)가 최상위부터 차례로 기록됩니다. 각 폴더의 이름, 설명, 언어, 그리고 폴더가 설정하는 텍스트 설정도 함께 저장됩니다. **새 책으로 복원**과 **백업 복제**는 새 책을 백업에 적힌 폴더에 넣습니다. 그 폴더를 아직 가지고 있다면 말이죠. 없다면 같은 이름의 폴더에 넣습니다. 가지고 있는 폴더는 그대로 쓰고, 없는 폴더는 원래 설정을 가진 채로 만듭니다. 폴더 없이 저장된 백업이나 폴더를 만들 수 없는 경우에는 최상위 수준으로 복원됩니다. 책에 대한 **복원**(전체 또는 메시지만)은 책을 원래 폴더에 그대로 둡니다. 폴더의 태그는 백업에 포함되지 않습니다. 이전에 만든 백업은 예전과 같이 복원됩니다.

<a id="pictures-in-a-backup"></a>

## 백업 속 그림

백업에는 파트가 **어떤 그림**을 가지고 있는지(그리고 그 설명문)는 기록되지만, **그림 파일 자체는** 포함되지 않습니다. 이렇게 해야 백업과 자동 백업이 작게 유지됩니다. 그림은 [리소스](../resources.md)에 그대로 남아 있습니다. 그림을 백업과 함께 보관하려면 백업을 [내보낼](#exporting-and-importing) 때 그림도 함께 묶으세요.

<a id="restoring-a-backup"></a>

## 백업 복원

백업 옆의 **복원**을 클릭한 다음 옵션을 고릅니다.

| 옵션 | 복원되는 내용 |
|---|---|
| **전체 복원** | 모든 것: 이름, 설명, 공개 설정, 프롬프트와 기타 책 설정, 태그, 모델, 프로토콜, 로어북, 그리고 모든 파트. |
| **메시지만 복원** | 파트(모든 분기)와 요약만 복원합니다. 책의 현재 설정, 프롬프트, 로어북은 그대로 유지됩니다. |

!!!warning
복원하면 책의 **모든 파트**가 백업에 든 파트로 바뀝니다. 백업 이후에 쓴 파트는 사라집니다. 나중에 되돌리고 싶을 수 있다면 먼저 현재 상태를 백업해 두세요.
!!!

책 창이 닫혔다가 복원된 책과 함께 다시 열립니다.

복원된 파트의 그림과 파트가 가리키는 그 밖의 파일(예: [오디오북](../extensions/audiobook.md)의 음성)은 백업이 나열한 것들이며, [리소스](../resources.md)에 아직 남아 있는 경우에만 복원됩니다. 백업 이후에 삭제한 리소스는 파트에서 사라집니다. [가져온](#importing-a-backup) 리소스를 포함한 내보내기에서 온 백업이 아니라면, 삭제된 파일은 복원되지 않습니다.

**모델과 프로토콜**은 사용자의 추론 제공자와 프로토콜 중에서 찾습니다. 먼저 백업에 있던 정확히 같은 것을 찾고, 없으면 같은 이름의 것을 찾습니다. 둘 다 없으면 책은 현재 모델이나 프로토콜을 그대로 유지합니다.

백업의 **로어북**은 사용자의 것과 비교됩니다. 같은 이름이지만 다른 식별자를 가진 로어북이 있으면, Marginalia는 로어북마다 백업의 것을 **기존 항목에 연결**할지 **새로 만들기**할지 묻습니다. 아예 가지고 있지 않은 로어북은 **가져오기**하거나 **가져오지 않음**으로 제외할 수 있습니다.

![로어북 처리 방법 선택](../../images/lorebook-import.png)

<a id="copying-a-book"></a>

## 책 복사

**백업 복제**는 백업으로부터 사용자가 입력한 이름의 새 책을 만듭니다. 원본 책은 바뀌지 않습니다. 복사본으로 과감한 실험을 해 보거나, 같은 시작으로 새 책을 시작하고 싶을 때 쓰세요.

백업이 리소스(그림, 오디오북의 음성, 그 밖의 파일)를 가리키고 있으면 Marginalia는 **리소스 포함** 또는 **리소스 제외**를 묻습니다.

- *리소스 포함*을 고르면 새 책은 그 리소스의 **자체 사본**을 갖습니다(같은 파일이 [리소스](../resources.md)에 새 항목으로 추가됩니다). 그래서 한 책에서 그림을 삭제하거나 바꿔도 다른 책에는 영향이 없습니다. 백업을 만든 뒤 삭제한 리소스는 제외됩니다.
- *리소스 제외*를 고르면 텍스트만 복제합니다.

![리소스 포함 또는 제외 복제](../../images/backup-clone-images.png)

## 내보내기와 가져오기

**내보내기**는 백업을 JSON 파일(`<book name>_backup.json`)로 다운로드합니다. 이 파일은 추가 사본으로 보관하거나, 다른 설치본으로 가져갈 때 사용할 수 있습니다.

백업이 리소스를 가리키고 있으면, Marginalia는 그 리소스를 함께 묶을지 묻습니다. 리소스에는 파트의 그림과 그 데이터가 이름으로 참조하는 다른 모든 파일(예: 오디오북의 음성 파일)이 포함됩니다:

![그림이 있는 백업 내보내기](../../images/backup-export-images.png)

- **리소스 제외**를 선택하면 위와 같이 JSON이 바로 다운로드됩니다. 리소스는 JSON 안에서 참조만 될 뿐 파일이 포함되지는 않습니다.
- **리소스 포함**을 선택하면 백업과 모든 리소스가 **ZIP 파일**(`<book name>_backup.zip`)로 묶입니다. 진행률 막대로 완료된 항목 수를 확인할 수 있습니다. 파일은 한 번에 하나씩 디스크에 만들어지므로, 큰 파일이 많은 책이라도 메모리를 많이 사용하지 않습니다. 긴 책의 오디오북은 수백 메가바이트에 이를 수 있으니, 정말 필요할 때만 묶으세요. 준비가 끝나면 **다운로드**를 클릭하세요. 이 파일은 해당 대화상자를 닫을 때까지만 보관됩니다.

리소스를 삭제했거나 파일이 없어서 묶을 수 없는 경우, 대화상자에 제외된 리소스의 개수가 표시됩니다.

**상속된 설정을 내보내기에 포함** 체크박스(기본값은 켜짐이며 내보내기 버튼 옆에 있습니다)는 파일에 기록될 설정을 결정합니다. 이 설정은 책이 [폴더](folders.md#where-the-settings-of-a-book-come-from)에서 물려받은 설정입니다. 체크박스를 켜면, 책이 직접 설정하지 않은 언어, 마스터 템플릿, 시점, 시제, 문체, 프롬프트 값이 파일에 책 자체의 값으로 기록됩니다. 이 값은 백업을 만들 당시 책이 속해 있던 폴더(가까운 폴더부터)에서 가져오고, 그다음 사용자의 설정에서 가져옵니다. 그래서 같은 폴더나 설정이 없는 설치본이나 계정에서도 책이 같은 모습으로 읽힙니다. 기본 제공 기본값은 기록되지 않습니다. 체크박스를 끄면 파일에는 책이 직접 설정한 내용만 들어갑니다. 파일에는 책이 어느 폴더에 있는지가 기록되지 않습니다. 책을 어느 폴더에 둘지는 각 설치본의 로컬 선택입니다. (이야기 내보내기인 [책 내보내기](export.md)는 본문만 기록하며 설정은 포함하지 않습니다.)

ZIP 파일에는 `backup.json`(JSON과 동일한 내용), `resources.json`(리소스 목록)과 파일들이 들어 있습니다. 압축을 풀 필요는 없습니다. 백업을 다시 가져올 때 `.json`과 `.zip` 모두 사용할 수 있습니다.

백업 파일을 다시 가져오는 방법은 두 가지입니다:

- *백업* 탭의 **백업 가져오기**는 파일을 **이 책**의 백업 목록에 추가합니다. *복원*을 누르기 전까지는 아무것도 바뀌지 않습니다.
- *설정* 탭의 **새 책으로 백업 가져오기**는 파일로부터 **새 책**을 만듭니다.

두 방법 모두 `.json` 또는 `.zip` 파일을 받습니다. 파일은 서버에 업로드된 뒤 서버에서 읽히므로, 큰 백업도 문제없습니다.

<a id="importing-a-backup"></a>

### 백업 가져오기

백업 파일이 그림이 들어 있는 ZIP이면, 그림이 먼저 [리소스](../resources.md)에 추가되고 백업은 그 그림을 사용합니다. 이미 가지고 있는 그림(같은 파일)은 다시 저장되지 않고 기존 것이 사용됩니다. 그래서 내가 내보낸 파일을 다시 가져와도 아무것도 추가되지 않습니다. 그림이 없는 JSON 파일은 있는 그대로 가져옵니다.

**새 책으로** 가져오면, 같은 그림을 이미 가지고 있더라도 새 책은 리소스에 **자기만의 항목**을 갖습니다. 이 항목들은 같은 파일을 가리키므로 디스크 공간은 두 번 쓰이지 않습니다. 파일에 그림이 없으면(일반 JSON), 새 책은 파일이 나열한 그림 중 여전히 가지고 있는 그림의 사본을 받습니다. 가지고 있지 않은 그림은 제외됩니다. 파일에 있는 항목 중 사용할 수 없는 그림(PNG, JPEG, GIF, WebP가 아니거나 너무 큰 파일)은 무시됩니다.

<a id="importing-a-backup-as-a-new-book"></a>

### 백업을 새 책으로 가져오기

1. **설정** 탭을 열고 **새 책으로 백업 가져오기**를 클릭하세요.
2. **새 책 이름**을 입력하세요. 이름을 입력해야 업로드가 활성화됩니다.
3. 백업 파일을 업로드하세요.
4. 요청되면 로어북을 어떻게 할지 결정하세요.

새 책은 *책* 탭에 나타납니다.

<a id="deleting-backups"></a>

## 백업 삭제

휴지통 버튼은 백업을 완전히 삭제합니다. 자동 백업은 자동으로 정리되지 않으며, 직접 삭제할 때까지 남아 있습니다.

<a id="automatic-backups"></a>

## 자동 백업

Marginalia는 글을 쓰는 동안 스스로 백업을 만들 수 있습니다. 모든 책의 기본값은 **설정 → 일반 설정 → 백업 전략**에서 지정하세요:

| 전략 | |
|---|---|
| **백업 없음** | 자동 백업을 만들지 않습니다. |
| **N개 메시지 후** | 생성된 파트 *N*개마다 백업을 만듭니다. |
| **N분 후** | 마지막 자동 백업 이후 *N*분이 지났을 때, 파트가 생성되면 백업을 만듭니다. |

특정 책만 다른 전략을 쓰려면, 그 책의 *백업* 탭에서 **원고별 재정의**를 체크한 뒤 전략과 숫자를 선택하세요. 체크를 해제하면 책은 *설정*의 기본값으로 돌아갑니다.

자동 백업은 파트가 생성된 후에만 만들어집니다. 그래서 읽기만 하는 책은 새 백업이 생기지 않습니다.

<a id="where-backups-are-stored"></a>

## 백업이 저장되는 위치

각 백업은 Marginalia 데이터 폴더 안의 JSON 파일입니다:

```
~/.marginalia/data/<your login>/backups/manuscripts/<book id>/
```

[Docker 버전](../getting-started/docker-server.md)에서는 호스트의 `./data/data/<login>/...` 경로에 해당합니다. 이 파일들은 데이터베이스 안에 들어 있지 않으므로, [데이터베이스 백업](../administration/database-backups.md)에는 포함되지 않습니다. 직접 만드는 백업에는 `.marginalia` 폴더 전체를 포함하세요.

그림 파일도 백업에 들어 있지 않습니다. `backups` 옆의 `data/<your login>/images` 폴더에 있습니다. 이 파일들도 [데이터베이스 백업](../administration/database-backups.md)에는 들어 있지 않으니, 자세한 내용은 그 문서를 참고하세요.
