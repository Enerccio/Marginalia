# 정규 표현식

정규 표현식(*regex*)은 텍스트를 철자 그대로 적는 대신 패턴으로 묘사하는 짧은 식입니다. 예를 들면 "Harry라는 단어이지만 Harrys는 아닌 것", "따옴표로 묶인 두 단어", "연속된 공백 세 개 이상" 같은 것입니다. Marginalia는 두 곳에서 정규 표현식을 사용합니다:

- **정규식으로 검색**이 켜져 있을 때, [이야기](books/story-editor.md#search-and-replace)와 [로어북](lorebooks/entries.md#search-and-replace)의 **찾기 및 바꾸기**, 그리고 이와 맞는 [명령](commands/index.md). 패턴이 텍스트를 찾고, 바꿀 내용에서는 찾은 텍스트의 일부를 다시 사용할 수 있습니다.
- [로어북 항목](lorebooks/entries.md#activation)의 **정규식** 필터. 이 필터는 항목이 프롬프트에 언제 들어갈지를 결정합니다.

사용하는 방언은 Java의 것입니다. 이 페이지에서는 가장 자주 쓰게 될 내용을 보여 주며, 전체 참고 자료는 끝에 링크되어 있습니다.

!!!
일반 단어를 찾는 데는 정규 표현식이 필요하지 않습니다. **정규식으로 검색**이 꺼져 있으면 텍스트는 입력한 그대로 검색되므로, 그 안의 `.`이나 `(`는 그저 점이나 괄호일 뿐입니다. 고정된 텍스트 하나로는 부족할 때만 정규식을 켜세요.
!!!

## 기본 구성 요소

| 입력 | 일치하는 대상 | 예시 |
|---|---|---|
| 문자 또는 숫자 | 그 문자 | `cat`은 *concatenate*에서 *cat*을 찾습니다 |
| `.` | 줄바꿈을 제외한 임의의 문자 하나 | `c.t`는 *cat*, *cot*, *c7t*를 찾습니다 |
| `\d` `\w` `\s` | 숫자, 문자/숫자/`_`, 공백 또는 줄바꿈 | `\d\d`는 *42*를 찾습니다 |
| `[abc]` `[a-z]` | 나열된 문자 중 하나, 또는 범위 | `gr[ae]y`는 *grey*와 *gray*를 찾습니다 |
| `[^abc]` | 나열되지 *않은* 문자 하나 | `[^"]`는 따옴표를 제외한 모든 문자입니다 |
| `\b` | 단어의 경계 | `\bcat\b`는 *cat*은 찾지만 *concatenate*는 찾지 않습니다 |
| `^` `$` | 줄의 시작과 끝 | `^Chapter`는 줄 맨 앞의 *Chapter*를 찾습니다 |
| `x?` `x*` `x+` | `x`가 0번 또는 1번, 0번 이상, 1번 이상 | `colou?r`는 *color*와 *colour*를 찾습니다 |
| `x{2,4}` | `x`가 2번에서 4번 | `\.{3}`은 연속된 점 세 개입니다 |
| `\` | 다음 문자를 글자 그대로 취급 | `\.`은 점, `\?`는 물음표, `\(`는 괄호입니다 |

괄호는 **그룹**을 만들며, 그룹 안의 세로 막대는 "또는"을 뜻합니다. `(Mr|Mrs) Dursley`는 *Mr Dursley*와 *Mrs Dursley*를 찾고, `\b(Voldemort|You-Know-Who)\b`는 두 이름 중 하나를 찾습니다. 그룹 뒤의 `?`, `*`, `+`는 그룹 전체에 적용됩니다. `(very )+good`은 *very good*과 *very very good*을 찾습니다.

`. ? * + ^ $ | \ ( ) [ ] { }` 문자들은 고유한 의미를 가집니다. 이 문자들을 그 자체로 찾으려면 앞에 `\`를 붙이세요. 예를 들어 *Really?!*를 찾으려면 `Really\?!`라고 씁니다.

기본적으로 정규식은 대소문자를 구분하지 않습니다. 즉 *harry*는 *Harry*를 찾지 못합니다. 대소문자를 무시하려면 시작 부분에 `(?i)`를 넣으세요. `(?i)harry`는 *Harry*, *HARRY*, *harry*를 모두 찾습니다. (찾기 및 바꾸기 창은 정규식이 켜져 있는 동안 **대소문자 구분**을 잠가 두므로, 그 창에서는 이 방법으로 대소문자 구분을 끕니다. 로어북의 **정규식** 필터는 항상 대소문자를 무시합니다.)

길이가 전혀 없는 일치(`a*`처럼 아무것도 일치시키지 않을 수 있는 패턴)는 찾기 및 바꾸기에서 무시됩니다.

<a id="typical-uses-in-a-story"></a>

## 이야기에서의 전형적인 사용법

각 행은 책에 대해 하고 싶을 수 있는 작업입니다. **검색**은 *찾을 내용*에 입력하는 것이고, **바꾸기**는 *바꿀 내용*에 입력하는 것입니다.

| 원하는 것 | 검색 | 바꾸기 |
|---|---|---|
| 더 긴 단어의 일부가 아닌 인물 이름 바꾸기 (*Harry*는 바꾸고 *Harrys*나 *Harrison*은 그대로 두기) | `\bHarry\b` | `Henry` |
| 대소문자와 상관없이 이름 바꾸기 | `(?i)\bharry\b` | `Henry` |
| 이름과 소유격을 한 번에 바꾸기 | `\bHarry('s)?\b` | `Henry$1` |
| 직선 따옴표를 곡선 따옴표로 바꾸기 | `"([^"]*)"` | `“$1”` |
| 점 세 개를 말줄임표 문자 하나로 바꾸기 | `\.{3}` | `…` |
| 두 개 이상의 공백을 하나로 바꾸기 | ` {2,}` | ` ` (공백 하나) |
| 줄 끝의 공백 지우기 | ` +$` | (비워 두기) |
| 하이픈 두 개로 된 긴 줄표 만들기 | ` ?-- ?` | ` — ` |
| *성, 이름*을 *이름 성*으로 바꾸기 | `(\w+), (\w+)` | `$2 $1` |
| 아무것도 바꾸지 않고 단어가 쓰인 곳만 찾기 | 패턴 | (비워 두고 **검색**만 누르기) |

여러 철자를 하나의 이름으로 통일하려면 `\b(Voldemort|You-Know-Who|He-Who-Must-Not-Be-Named)\b`을 검색하고 `Tom Riddle`로 바꾸세요.

<a id="taking-the-match-into-the-replacement"></a>

### 일치 내용을 바꿀 내용에 가져오기

정규 표현식에서 둥근 괄호로 묶인 모든 부분은 **그룹**이며, 여는 괄호의 위치에 따라 왼쪽에서부터 번호가 매겨집니다. 바꿀 내용의 `$1`은 첫 번째 그룹의 텍스트이고, `$2`는 두 번째 그룹, `$0`은 일치한 전체 텍스트입니다. `(\w+), (\w+)`에서 첫 번째 그룹은 쉼표 앞의 단어이고 두 번째 그룹은 쉼표 뒤의 단어이므로, `$2 $1`은 둘을 맞바꿉니다. 즉 *Potter, Harry*가 *Harry Potter*가 됩니다.

`(?<last>\w+), (?<first>\w+)`처럼 그룹에 이름을 붙이고, 바꿀 내용에서 그 이름을 쓸 수도 있습니다: `${first} ${last}`.

바꿀 내용에서 `$`나 `\`를 그 자체로 남겨야 하면 이스케이프해야 합니다. 텍스트에 *$5*를 넣으려면 `\$5`라고 쓰세요. 정규식을 사용하지 않을 때는 바꿀 내용이 항상 입력한 그대로 취급됩니다.

패턴이 잘못되었거나(닫히지 않은 괄호 등), 바꿀 내용이 패턴에 없는 그룹을 가리키면 알림이 표시되고 아무 일도 일어나지 않습니다. 검색은 절대로 아무것도 바꾸지 않습니다.

<a id="match-only-in-a-context"></a>

### 문맥 안에서만 일치시키기

*선행 탐색* `(?=...)`과 *후행 탐색* `(?<=...)`은 일치하는 부분을 가져가지 않고 그 주변의 텍스트를 살펴봅니다. 따라서 그 바깥 부분만 바뀝니다:

| 검색 | 찾는 대상 |
|---|---|
| `Harry(?= Potter)` | *Potter*가 뒤따를 때만 *Harry* (*Potter*는 건드리지 않음) |
| `(?<=Professor )McGonagall` | *Professor* 뒤에 있을 때만 *McGonagall* |
| `Harry(?! Potter)` | *Potter*가 뒤따르지 않는 *Harry* |

<a id="lazy-and-greedy"></a>

### 느긋하게 또는 탐욕스럽게

`*`와 `+`는 가능한 한 많은 부분을 가져갑니다. `He said "yes" and "no"`에서 `".*"` 패턴은 `"yes" and "no"` 전체와 일치합니다. 첫 번째 닫는 따옴표에서 멈추려면 `?`를 붙이거나(`".*?"`), 허용되지 않는 것을 적으세요(`"[^"]*"`).

검색은 각 줄을 따로따로 처리합니다. `.`은 줄바꿈을 넘지 않으며, `^`와 `$`는 전체 텍스트의 시작과 끝이 아니라 부분의 모든 줄의 시작과 끝에 일치합니다. 줄바꿈과 일치시키려면 `\n`을 쓰세요.

<a id="in-a-lorebook-entry-filter"></a>

## 로어북 항목 필터에서

**정규식**으로 설정된 로어북 항목의 필터는 해당 부분의 요청 어디에서든 일치하는지 검사됩니다. 이때 대소문자는 무시되며, 여기서는 `.`이 줄바꿈과도 일치합니다. 따라서 `varro.*harbor`는 서로 다른 줄에 있더라도 Varro와 항구를 찾습니다. 일반적인 필터는 다음과 같습니다:

- `\bvarro\b` - 온전한 단어로서의 Varro.
- `\b(varro|captain)\b` - Varro 또는 captain.
- `varro.*(harbor|docks)` - Varro가 나오고, 그 뒤에 harbor 또는 docks가 나오는 경우.
- `dragons?` - *dragon* 또는 *dragons*.
- `(?<!no )magic` - *magic*, 단 바로 앞에 *no*가 있는 경우는 제외.

잘못된 정규식은 항목을 절대 활성화하지 않으며, 그 이유는 로그에 기록됩니다. 항목이 선택되는 나머지 방식은 [항목과 활성화](lorebooks/entries.md#activation)를 참고하세요.

<a id="in-the-commands"></a>

## 명령에서

[`/search-replace-parts`](commands/index.md#commands-that-come-with-marginalia)와 `/search-replace-lore-entries`는 검색어와 바꿀 내용 다음의 세 번째 인수로 정규식 사용 여부(`true`)를 받습니다. 명령줄은 공백을 기준으로 나뉘므로, 공백이 들어 있는 패턴이나 바꿀 내용은 큰따옴표로 묶어야 합니다. 문자 앞의 백슬래시는 그대로 전달됩니다(`\b`, `\d`). 하지만 `\\`는 백슬래시 하나가 되고 `\"`는 따옴표가 되므로, 패턴에서 백슬래시 자체를 나타내려면 `\\\\`라고 써야 합니다.

```
/search-replace-parts "\bHarry\b" Henry true
/search-replace-parts "(\w+), (\w+)" "$2 $1" true
/search-replace-parts "(?i)\bharry\b" Henry true
```

명령은 일치 목록을 보여 주지 않습니다. 대신 찾은 일치 개수만큼 바꿀지 묻습니다. 패턴이 확실하지 않다면 먼저 **찾기 및 바꾸기** 창에서 시험해 보세요. 이 창은 각 일치 항목을 현재 모습과 바뀐 뒤의 모습으로 모두 보여 줍니다.

<a id="tips"></a>

## 팁

- 먼저 **검색**으로 패턴을 시험하고 몇 개의 행을 열어 보세요. 창은 각 일치 항목을 주변 텍스트와 함께, 현재 모습과 바뀐 뒤의 모습으로 보여 줍니다. 결과가 원하는 대로일 때만 바꾸세요.
- 단순하게 시작해서 패턴을 단계적으로 늘리세요. 너무 많이 찾는 패턴은 보통 단어 주변에 `\b`가 필요하거나, `*`를 멈추기 위해 `?`가 필요합니다.
- 큰 바꾸기를 하기 전에 [백업](books/backups.md)을 만들어 두는 것은 비용이 거의 들지 않습니다(`/take-backup`). 바꾸기는 한 번 시작되면 중단할 수 없습니다.
- 요약이 바뀌는 경우: 바꾸기가 [요약](books/summaries.md)의 원본이 된 텍스트를 건드리면, 창은 해당 요약이 오래된 상태가 될 것이라고 경고합니다. [찾기 및 바꾸기](books/story-editor.md#search-and-replace)를 참고하세요.

## 더 읽을거리

이 페이지는 기초만 다룹니다. Java 문법 전체(모든 구문, 플래그, 문자 클래스)는 [`java.util.regex.Pattern` 문서](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/util/regex/Pattern.html)에 있으며, 바꿀 내용의 문법(`$1`, `${name}`, `\$`)은 [`Matcher.appendReplacement`](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/util/regex/Matcher.html#appendReplacement(java.lang.StringBuilder,java.lang.String))에 있습니다.
