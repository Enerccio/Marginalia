# 作业

应用向**外部 AI** 提出的每一项请求都是一个*作业*：生成、摘要、注释、代理运行、将章节转换为音频、图片。每个作业都会记录其所属用户、开始和结束时间、结束方式，以及它向模型或语音、图片后端发出的每一次*调用*，每次调用同样有自己的开始和结束时间。管理页面的 **Jobs** 标签页显示该日志；页面 `/jobs` 显示当前正在运行的内容。

只保留元数据：用户是谁、何时、耗时多久、使用哪个 AI 或服务器（AI 的名称，或语音或图片服务器的主机名；绝不包括地址路径或查询参数）、模型、结束方式，以及失败时的简短错误信息。**不存储任何提示词、回答或文本**。

<a id="what-is-one-job"></a>

## 什么是一个作业

- **没有分组的请求**（生成、注释、重写、模拟输入、单个部分的摘要、向帮助助手提问、插件的请求，例如翻译某个部分或某条设定条目）各自是一个作业，只包含一次调用。其类型即工作的类型（`generation`、`annotate`、`summary`……）。
- **摘要的重写**是一个作业（`summary`），每写一条摘要有一次调用。
- **代理运行的一个工作会话**是一个作业（`agent`），每轮代理有一次调用；暂停后再恢复的运行，每个会话各有一个作业，子代理的请求各自是独立的作业。
- **转换为音频**时，每批部分是一个作业（`audiobook`），标注模型的请求以及每个被朗读的片段都作为其调用。
- 由**图片生成器**制作的图片是一个独立作业（`image-generator`），包含一次图片调用。

<a id="what-runs-now-jobs"></a>

## 当前运行：`/jobs`

![正在进行生成的 /jobs 页面](../../images/jobs-live.png)

打开 `/jobs` 地址（例如 `http://localhost:8080/jobs`；标签页的 **Open the live view** 链接可直接打开）。与其他页面一样，它要求登录，且只对管理员显示内容。列表每两秒刷新一次，对每个正在运行的作业显示：用户、类型、已运行时长、已完成的调用数量，以及当前正在进行的内容（AI 或服务器，以及调用等待了多久），还有该作业所服务的运行的书籍，以及其 **Stop** 按钮。当服务器似乎繁忙时，这是快速查看的方式：大量调用在等待同一个模型，就说明了一切为何都很慢。

在作业下方，**Runs on the books** 列出目前正在某本书上工作的运行，并防止其中部分内容在运行期间被删除或修改（参见[运行面板](../books/story-editor.md#the-panel-of-the-runs)，它向每位用户显示其自己书籍的相同信息）：用户、书籍、运行的内容、所处阶段（面板显示的文字，如 *Waiting for the model*、*The model is thinking/writing...*、*Working*、*Waits for you*；对于生成，则显示其阶段，例如写作其部分时的 *INFERENCE*；打开的书籍窗口在此处不显示任何内容）、开始时间，以及它持有的对象数量（书籍、部分）。打开的书籍窗口本身也是一个运行。**Stop** 以运行用户的身份停止该运行。**End** 在提问之后结束运行，但不停止其工作：它所持有的内容会立即释放。仅在运行永不结束时使用；其工作可能在被唤醒时仍会写入。大多数此类运行会自行结束：一小时内无任何工作、且不等待你或其模型的运行，会被服务器结束，关闭页面的窗口也是如此。

<a id="the-log-the-jobs-tab"></a>

## 日志：Jobs 标签页

![管理页面的 Jobs 标签页](../../images/admin-jobs.png)

| | |
|---|---|
| **User, Kind, Status** | 筛选条件。*kind* 即作业的类型（`generation`、`summary`、`annotate`、`agent`、`audiobook`、`image-generator`……）；未指明其工作的代码所发出的请求显示为 `untagged`。 |
| **Older than (days)** | 仅显示在该天数或更早之前开始的作业。 |
| **Refresh** | 重新读取日志。 |
| **Delete these jobs** | 在一次询问（告知数量）之后，永久删除筛选所显示的作业及其调用。未设置任何筛选时，会删除整个日志。 |
| **Open the live view** | 在新标签页中打开 `/jobs`。 |

点击某一行可查看该作业的调用：类型（语言模型、音频、图片）、AI 或服务器、模型、开始、结束、时长、状态，以及失败调用的错误。显示为失败的作业，表示其中有一次调用失败，或被运行它的代码标记为失败结束；已取消的调用是你停止的调用（或作业结束时仍在运行的调用）。

![有声书转换的调用](../../images/admin-jobs-calls.png)

失败的作业会显示哪次调用失败及原因：

![语音调用出错的失败转换](../../images/admin-jobs-failed.png)

**不会自动删除任何内容。** 日志会随每个请求增长，因此需要时常清理：设置 *Older than (days)*（例如 30），查看列出的内容后删除。[清理](cleanup.md)会在删除用户时同时删除该用户的作业。

![早于 30 天的作业，以及删除前的询问](../../images/admin-jobs-old.png)

![删除作业前的询问](../../images/admin-jobs-delete.png)

作业在结束时才写入日志；仍在运行的作业只存在于 `/jobs` 中。若应用停止，正在运行的作业会丢失（它们从未完成）。无人结束且半小时内不进行任何调用的作业，会被视为已完成而结束。
