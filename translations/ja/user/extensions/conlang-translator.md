# 人工言語翻訳

物語の登場人物に、あなたが作った言語（人工言語）を話させられます。言語（その規則と単語）を説明すると、モデルがその言語を話す登場人物の**直接話法**を書きます。物語側には、その裏にある英語が残ります。

!!!
物語の本文には**人工言語**が入ります。物語を読んでモデルに渡すもの（次の生成、要約、ロアブックの走査、注釈、ほかの拡張機能）はすべて、そのセリフを翻訳する元になった**英語**を読みます。そのため、モデルは言語を理解しなくても物語を続けられます。翻訳されたセリフをクリックすると英語が表示されます。
!!!

!!!warning 作業中
この拡張機能は、ここで説明する画面を使う人間のほか、[コマンド](#commands)を通じてエージェントからも使えます。スマートフォンでは一部の機能のみ利用できます。[制限](#limits)を参照してください。
!!!

<a id="the-idea"></a>

## 基本の考え方

1. **言語**は二つの要素からなります。**規則**（モデル向けに文法書のように書いた文章）と**語彙集**（単語。大部分はモデルが書き、あなたが判断します）です。言語は設定に一度保存され、いくつの本でも同じ言語を使えます。
2. **本**（または本のフォルダ）が使う言語を選びます。パートは、そのメニューから**手作業で**翻訳するか、確定したら**自動的に**翻訳するか、**範囲をまとめて**翻訳できます。
3. パートごとに一回のリクエストをモデルに送り、すべての直接話法を分類します（そのセリフは、この言語で話されているか、それとも物語の共通語で話され、聞き手に理解されているか、を判定します）。そして、言語で話されているセリフを翻訳します。言語に無い単語は規則に従って作り出され、**その理由とともに報告され**、**新規**として語彙集に追加されます。受け入れる、変更する、ロックする、捨てる、はあなたが選べます。
4. 英語は（本のデータの中で、セリフの*原文*として）保存され、すべてのモデルが読みます。人工言語が原典です。手で変更した箇所はそのまま残り、編集したパートが、あなたの知らないうちに上書きされることは決してありません。

## 言語

言語は **設定 → 拡張機能の設定 → Conlang Translator** で編集します。ここには登録されている言語の一覧が表示されます。

![設定画面の言語](../../images/plugin-conlang-settings.png)

| ボタン | |
|---|---|
| **New language** | 空の言語を作成します。 |
| **Design a language** | モデルが新しい言語の各部分を提案し、あなたが編集して採用する[ウィザード](#the-designer)です。 |
| **Edit** | 選択した言語の[エディタ](#the-editor)を開きます。 |
| **Duplicate** | 名前を新しくした独立した複製を作ります。単語もすべて含まれます。変更を試すときに使います。複製は、**一冊の本のためだけの言語**を持つ唯一の方法でもあります。言語を選んだ本は、同じ言語を選んだ他のすべての本と共有されるためです。 |
| **Compare** | 別の言語の変更を選択中の言語に取り込みます。取り込み前に[レビュー](#comparing-and-merging)があります。 |
| **Export**, **Import** | 言語をドキュメント (JSON) として書き出し、読み込みます。本へのリンクは含まず、規則と語彙のみです。すでに同じ名前の言語がある場合の読み込みでは、差分のレビューか新しい言語として取り込むかを選べます。 |
| **Delete** | 確認のあとに削除されます。 |

画面の上部には、**デザイナーのモデルとプロトコル**があります。一覧の下には、本やフォルダーが**継承**する設定があります。言語、部分ごとの自動翻訳の有無、翻訳に使うモデルとプロトコルです。本やフォルダーは独自の設定を持つこともできます。詳しくは[本の言語の選択](#choosing-the-language-of-a-book)を参照してください。設定画面で **Save** を押すと変更が保存されます。その間に翻訳で追加された単語は失われません。触っていない言語は、設定画面を保存するときに読み直されます。

<a id="the-editor"></a>

### エディタ

エディタは5つのタブを持つウィンドウです。**Save** を押すまでコピー上で作業し、サイズ変更、ドラッグ、最大化ができます。

| タブ | |
|---|---|
| **Overview** | 名前、自分用の説明、オプション **A hyphen is a part of a word** (オフの場合 `thal-orun` と `thalorun` は同じ単語になります。オンの場合、ハイフンは語形の一部になります)、そしてデザイナーが参照する **example book** と **example lorebook** を設定します。 |
| **Rules** | 規則を**セクション**ごとに管理します (音と綴り、文法、語形成など)。各セクションには**誰が読むか**が示されます。*the translator* (すべてのリクエストで送信)、*only the designer* (言語の歴史や単語作成のための注記)、*nobody* (自分用のメモ) のいずれかです。プラグインは規則を解析しません。規則はモデルに向けたテキストとして扱われます。 |
| **Categories** | 単語のグループです (*People & Social*、*Nature*、*Particles* など)。語彙はこの見出しの下に表示され、モデルにも同じ見出しで送られます。**always sent** に指定したカテゴリ (助詞、代名詞、数詞など) は、語彙が大きすぎて全体を送れない場合でも、すべてのリクエストに含まれます。 |
| **Registers** | 話し方のスタイル (*formal*、*soft*、*vulgar*、*archaic* など) と注記です。一つの概念にはレジスターごとに異なる語形を持たせられます。モデルは話す相手と話者に応じて選びます。 |
| **Lexicon** | 単語です。詳しくは下記を参照してください。 |

![言語の規則](../../images/plugin-conlang-rules.png)

<a id="the-lexicon"></a>

### 語彙

![言語の語彙](../../images/plugin-conlang-lexicon.png)

語彙の表には **search** (単語または意味で検索) と、**category** および **status** による絞り込みがあります。操作は **Add**、**Edit**、**Accept**、**Lock**、**Retire**、**Delete**、**Accept all new** です。一つの単語は次の要素を持ちます。

- **形** (物語での書き方)。必要に応じて、**文字体系**ごとの形、**カテゴリ**、**種類** (root、compound、particle、name、number、phrase) も持ちます。
- 一つ以上の**意味**です。同音異義語は複数の意味を持てます。各意味には品詞と注記があります。さらに、同じ概念の**別の語形**も持てます (同じ物事を表す、丁寧語、柔らかい語、卑語など)。これらは一緒に表示され、一緒にモデルへ送られます。
- **根拠** (rationale)。モデルがその単語を選んだ理由 (規則や語根) です。単語を判断するために読み、後続のリクエストにも戻されるため、次の造語も同じ論理に従います。
- **由来** (origin)。あなたが作ったか、モデルが作ったかを示します。モデルの場合は、どの部分のために作られたか、モデル名、作成時刻も記録されます。モデルの単語をあなたが編集すると、その単語はあなたのものになります。
- **状態** (status)。**New** (モデルが作ったが、まだ確認していない)、**Accepted** (採用済み)、**Locked** (モデルは使えるが再定義はできない)、**Retired** (残すがモデルには提示しない。置き換えられた単語向け) のいずれかです。

モデルが必要としているのに語彙にない単語は、**新しいからといって捨てられることはありません**。すぐに語彙に追加され、次の部分でも同じ言い方が使われるようになります。状態は *New* として保留されます。翻訳で語彙にない単語が使われていて、モデルがそれを**報告していない**場合は、誤りかどうかを判断できないため、フラグが付けられます。

<a id="names-for-the-name-generator"></a>

### 名前ジェネレーター用の名前

エディタの **Names** タブでは、言語を[名前ジェネレーター](name-generator.md)で使えるようにします。生成される名前は、その言語らしい響きになります。まず**名前のカテゴリ**を追加します (例: *Places* や *People*)。次に、そのカテゴリを構成する語彙の単語にチェックを入れます。**search** とカテゴリフィルターで一覧を絞り込めます。**Check all shown** と **Uncheck all shown** は、表示されている単語に対して働きます。**Preview names** を押すと、保存する前に、現在チェックされている単語から20個の名前を作って見せます。名前ジェネレーターは、チェックされた単語でマルコフ連鎖を学習します。そのため、カテゴリには数語が必要です (十数語以上あると、より良い名前が得られます)。

保存されるのは単語ではなく、あなたの選択だけです。変更された単語は現在の状態のまま読まれ、削除または Retired にした単語は、名前の生成時に除外されます。設定を保存すると、そのカテゴリが名前ジェネレーター (ロア生成と、アークのアウトラインの **Tools** ダイアログ、`generate-names` コマンド、エージェントの実行) に *Conlang - 言語 - カテゴリ* として表示されます。これはあなた専用です。同じインストールを使う他のユーザーには、あなたのカテゴリは見えません。

![Names タブ: 名前のカテゴリ、それを構成する単語、そこから作られた20個の名前](../../images/plugin-conlang-names.png)

<a id="the-designer"></a>

### デザイナー

エディタの **Design with AI** メニューは、モデルに助けを求めます。その際、言語は**現在の状態のまま** (規則、レジスター、カテゴリ、語彙、例のロアブック) 渡されます。また、結果は常に**提案**として返され、あなたが確認するまで何も書き込まれません。

![デザイナーのメニュー](../../images/plugin-conlang-designer-menu.png)

| 操作 | |
|---|---|
| **Generate words...** | カテゴリの単語を、数と注記 (「包囲陣地の炊事場」など) を指定して生成します。 |
| **Add a section with AI...** | 不足している部分 (数詞、色、丁寧さなど) の規則のセクションと、それに必要な単語を新しく追加します。 |
| **Rewrite a section...** | 指示に従って、モデルがセクションを書き直します。モデルは**セクション全体**を返すため、非常に長いセクションは時間もコストもかかります。セクションは短く、一つの話題に絞ってください。 |
| **Review the language** | 矛盾、欠落、音の体系を壊す単語の一覧を示します。各項目にはセクションと修正案が付きます。何も変更されません。 |
| **Ask the designer...** | 会話形式です。単語やセクションを含む回答は、変更としてレビューできます。 |

パネルの **Design a language** は、7つのステップからなるウィザードです (ブリーフ、音、文字、文法、語形成、カテゴリごとの最初の単語、文を使ったテスト)。各ステップはモデルが提案するセクションで、あなたが編集し、注記を加えて洗練させ、採用します。言語は **Finish** を押すまでウィンドウの中にしか存在しません。

![言語を設計するウィザード](../../images/plugin-conlang-wizard.png)

<a id="comparing-and-merging"></a>

### 比較と統合

**Compare** (および、すでに持っている言語の読み込み) を行うと、2つの言語の差分を示すウィンドウが開きます。差分は各行にチェックボックス付きで表示されます。言語のフィールド、規則、カテゴリ、レジスター、単語、名前のカテゴリのうち、追加、変更、削除、移動されたものが対象です。両側が異なる変更をした箇所は**競合**になります。競合の場合は、相手の値を選ぶか自分で書くまで、あなたの値が保持されます。選んだ内容は画面上の言語に書き込まれ、設定画面を保存したときに保存されます。同じウィンドウには、デザイナーの提案も表示されます。

![2つの言語の差分のレビュー](../../images/plugin-conlang-review.png)

## 本の言語の選択

![本の項目](../../images/plugin-conlang-book.png)

| 項目 | |
|---|---|
| **Language of the speech** | 本を翻訳する先の言語です。空欄の場合、本は翻訳されません。 |
| **Translate a new part by itself** | 部分が確定したときに翻訳されます。確定とは、生成のあと、自動の注釈と推敲 (本にそれらがある場合)のあと、または[部分の後に続く処理](../books/story-editor.md#what-follows-a-generated-part)のステップとして行われたときです (実行パネルに表示され、その **Stop** で停止できます)。 |

<a id="the-conlang-tab-of-the-book"></a>

## 言語の Conlang タブ

ストーリーウィンドウには、この本の言語のための **Conlang** タブがあります（章とロアブックと同じドックにあり、好きな場所にドラッグできます）。このタブには四つの下位タブがあります。言語を本のウィンドウで変更したあとは、**更新** で言語を読み直せます。[複数の言語](#more-than-one-language-in-a-book)を持つ本では、**更新** の隣に欄があり、**単語**、**話者**、**Quick translate** の各タブがどの言語について表示するかを選べます。

<a id="words"></a>

### 単語

本の言語の語彙集です。検索、フィルター、[エディター](#the-lexicon)の操作があり、執筆中に単語を調べたり、編集したり、モデルが作った単語を承認したり、単語をロックまたは廃止したりできます。変更はすぐにライブラリに保存されます（そのあいだに翻訳が追加した単語も失われません）。

<a id="speakers"></a>

### 話者

**この本の中で**その言語を話すのは誰かを決めます。話者は本に属し、言語には属しません。同じ言語は別の物語では別の人たちが話すので、言語を複製、書き出し、比較しても、登場人物は付いてきません。

既定では、**リストにあるキャラクター以外の全員がその言語を話します**（あるいは逆に、リストにある人だけが話します）。これはあくまで既定値です。本文がそれを上書きすることがあり（「彼女は共通語で言った」「衛兵はひと言も理解できなかった」など）、どの発話についてもモデルが判断します。各キャラクターについては、**性別**（性別を文法で示す言語では、本文が「彼女」としか書いていないと誤りが出るため重要です）と**声**（「丁寧、簡潔、粗野」など）を記録できます。モデルはこれを言語のレジスターと照らし合わせます。変更はすぐに本に保存されます。

各キャラクターには**理解度**も設定できます。*まったく分からない*、*いくつかの単語が分かる*、*ほとんど追える*、*すべて追える* のいずれかです。空のままにする（または *すべて追える* にする）と、モデルには何も伝えられません。この設定は、言語を話さないが耳にする人たちに使います。例：*Tomáš: まったく分からない*、*Other villagers: ほとんど追える*（名前は単なるテキストなので、集団でも指定できます）。理解度レベルは**本全体で固定**で、情報としてモデルに渡されます。それをどう扱うかはモデル次第です。また、指示でさらに詳しく書くこともできます（「Tomáš は彼らの言うことが分からない」など）。モデルへは二通りで届きます。**物語のモデル**には、レベルを示す短いメッセージが届きます（作者注と同じようにプロンプトに挿入されます。上のリストの上にあるチェックボックスでオフにでき、その横の数字は末尾から何件目までのメッセージに入れるかを表します）。また、**部分を見直すモデル**（*AI で注釈を付ける*）には、事実の一節として届くので、理解できない言葉に反応するキャラクターにフラグを立てられます。文章を自分で配置したい場合は、挿入をオフにして、テンプレートの {%{`{{command::conlang-understanding}}`}%} [マクロ](../templates/macros.md#commands)を使ってください。任意で、残すキャラクターのリストを取ることができます。

![Conlang タブ：話者と、言語が分からない二人のキャラクター](../../images/plugin-conlang-tab.png)

<a id="languages"></a>

### 言語

本の、**話し言葉の言語** 欄が示す言語以外の、本のほかの言語です。詳しくは[一冊の本の中の複数の言語](#more-than-one-language-in-a-book)を参照してください。

### Quick translate

英語で文章（句、名前、まだ書いていない一行など）を書き、必要なら誰が誰に言うかも書いて、**翻訳** を押します。モデルは、規則、レジスター、語彙集、そして文章中に名前が出てくるキャラクターの注記を使って、その文章を本の言語に翻訳します。何も物語には書き込まれません。結果は翻訳文、選択についての注記、そして語彙集に無かった**翻訳に必要だった単語**です。各単語には意味と理由が付きます。欲しいものを選び、**選択した単語を取り込む** を押してください。単語は、翻訳された部分の単語と同じく、*新規* として語彙集に入ります。翻訳の中の単語で、語彙集にも報告にもないものは、警告として一覧に出ます。

<a id="more-than-one-language-in-a-book"></a>

## 一冊の本の中の複数の言語

叙事詩では、エルフのための言語、ドワーフのための言語、オークのための言語がそれぞれ存在することがあります。本では**まず一つの言語**を指定します（上の欄で、フォルダーや設定がそれを与えることもあります）。**Conlang** タブの **Languages** タブでは、ライブラリから**ほかの言語**を一つずつ追加したり、取り除いたりできます。

- **言語ごとに話者が別々にいます。** *Speakers* タブは、上の欄で選んだ言語についての話者です。最初の言語は、これまでどおり、リストに載せたキャラクター以外の全員が話します。追加した言語は「リストに載せたキャラクターだけが話す」状態で始まり、リストには誰も入っていません。したがって、誰かを載せるまでは何も求められません。あるキャラクターの言語が別の言語であるなら、そのキャラクターを最初の言語の例外として載せてください。そうしないと、最初の言語でもそのキャラクターの発話を求められてしまいます（二つの言語が同じ発話を主張する場合、その発話は先に求められる方に属します）。キャラクターは複数の言語を話すこともできます（両方のリストに載せてください。その部分の本文が、発話がどの言語によるものかをモデルに伝えます）。
- **言語ごとに一つずつリクエストを出します。** リクエストには一つの言語の規則と語彙集だけが含まれ、その言語の話者の発話だけが含まれます。二つの言語の発話を持つ部分は、二つのリクエストを順に出します。二つ目のリクエストは、最初のリクエストの発話を英語のまま読み、それらの発話は翻訳済みのまま残します。視点人物と登場人物がすべてある言語の話者の外にいる部分は、その言語については求められません（キャラクターの名前が出てこない部分は、話者がいるすべての言語について求められます）。
- **段落は自分の言語を知っています。** ポップオーバー、書き出し、ビューアーはこれまでどおり動きます。**Translate dialogs (constructed language)** を一つの言語に対して実行しても、ほかの言語の発話には触れません。**Put the English back** は、一つの言語にも、すべての言語にも使えます。
- **メニューは、本に複数の言語があるとき、どの言語かを尋ねます。** 部分のメニュー（*Translate dialogs (constructed language)*：いずれかの言語、または *All languages*）と、選択した文を右クリックしたときのメニュー（一つの言語）です。**Translate parts (constructed language)** には *Language* 欄があります（既定はすべての言語）。*the parts that are not translated* は「その言語では翻訳されていない」という意味です。
- **自動実行**は、新しい部分を、話者が登場しうるすべての言語に翻訳します。
<a id="translating"></a>

## 翻訳

- **手動で:** パートのメニューには **翻訳** のサブメニューがあります(テキストの右クリックにもあります)。その中に **翻訳 (構築言語のセリフ)** があります。これらの項目と **パートを翻訳** は、この拡張機能の言語を持つ本でのみ表示されます。すでに翻訳されているパートは、**英語の原文から**再度翻訳されます。そのため、ルールや語彙集を変更した後にパートを翻訳し直すのもこの方法です。複数の言語がある本では、まず[どの言語か](#more-than-one-language-in-a-book)を尋ねられます。
- **自動で:** **新しいパートを自動で翻訳** を使うと、生成されたパートは確定するとすぐに翻訳されます。パートを*再生成*すると、新しい英語が与えられ、古い翻訳は削除されます。
- **モデルが見逃したセリフ:** 翻訳で、セリフが英語のまま残ることがあります。パートのメニューの **翻訳 → 翻訳されていないセリフを翻訳 (構築言語)** は、まだ英語のままのセリフだけを翻訳し、翻訳済みのセリフはそのまま残します。テキストを選択した状態で右クリックの **翻訳 → 選択範囲の翻訳されていないセリフを翻訳 (構築言語)** を使うと、選択範囲に含まれるセリフだけが対象になります。モデルには、翻訳済みのセリフを含んだパートがそのまま送られ、まだ英語のセリフだけを翻訳するよう求められます。そのため、パート全体を翻訳するより処理が軽くなります。書き出されるのはセリフだけなので、モデルがセリフとして認識していない文を翻訳する方法ではありません。その場合は *選択したテキストを翻訳* を使ってください。
- **あなたが書いた一文:** パートの本文でその文を選択し、右クリックして **翻訳 → 選択したテキストを翻訳 (構築言語)** を選びます。モデルは、言語、登場人物のメモ、そしてその周囲の物語を踏まえて、選択したテキストを翻訳します(前後の空白と引用符の対は除かれます)。テキストは翻訳に置き換えられ、英語はセリフの原文として残ります。そのため、ほかのセリフと同じように、クリックすると英語が表示されます。モデルが新たに作った語は、翻訳されたパートの場合と同じく、*新規*として語彙集に追加されます。翻訳済みのセリフを含む選択範囲は受け付けられません(先に英語に戻してください)。また、その間に変更されたパートでの選択も受け付けられません。
- **範囲指定:** 物語のツールメニューにある **パートを翻訳 (構築言語)** を開くと、物語の横に開いたままのウィンドウが表示されます。

  ![パートを翻訳](../../images/plugin-conlang-range.png)

  **開始パート** と **終了パート**(テキストのあるパートを、書き出しと同じく1から数えます)を選び、何をするかを選択します。選択肢は、*翻訳されていないパートを翻訳*、*翻訳済みのパートを再翻訳*(ルールや語彙集を変更した後)、または *英語に戻す*(確認の後)です。ウィンドウには、範囲に含まれるパートの数と、その選択が対象とするパートの数が表示され、*パート n / m* と、**停止** が表示されます。**停止** は、処理中のパートが終わった後に有効になります(開始されたモデルへの要求は取り消せません)。失敗したパートは数えられ、処理は続行されます。言語やモデルがない場合は処理が終了します。処理が終わると物語は描き直されます。実行中に編集したパートは、その一つだけが失敗し、処理全体は止まりません。

翻訳は、テキストへのほかの変更と同じように保存されます。パートの履歴にはバージョンが追加されますが、パートは**編集済みとしてマークされません**し、英語も残ります。**手で変更したセリフは**、パートを再翻訳したり英語に戻したりしても**そのまま残ります**。そこにはあなたの言葉が含まれているからです。

!!!
翻訳には、モデルがそのパートにかける時間がかかります。考えるローカルモデルでは数分かかることもあります。拡張機能は、モデルに考えさせるよう指示します(性・数・文体の翻訳は、そうした方がずっと良くなります)。そのため、モデルの出力上限には余裕を持たせてください。
!!!

## 読者に見えるもの

<a id="in-the-story"></a>

### 物語の中で

翻訳されたセリフには**点線**が付きます。それをクリックすると、ポップオーバーに英語が表示されます。誰が話したかが示され、聞き手がその言語を理解しない場合は *(聞き手には通じない)* と表示されます。赤い注記は、翻訳の後に構築言語のテキストを編集したことを示します。その場合、英語は現在の内容と違っているかもしれません。

**原文を編集** (ポップオーバーのボタン。自分のビューでのみ表示され、公開された本の読者には表示されません)を押すと、小さなウィンドウが開きます。そこには、物語にある現在の翻訳と、モデルが読む英語が表示されます。ネイティブスピーカーが翻訳を手で直したのに英語が違う内容になっている場合や、モデルが英語を誤って訳した場合に使います。保存すると、そのセリフには新しい英語が与えられます。現在の翻訳が、その英語に対応するものとして扱われ(赤い注記は消えます)、以後モデルはその場所に新しい英語を読みます。パートのテキストは変わりません。*翻訳 (構築言語のセリフ)* をもう一度実行すると、両方が置き換えられます。`conlang-edit-source` はコマンドラインから同じことをします。

![セリフの原文を編集するウィンドウ](../../images/plugin-conlang-source.png)

**原文の検索と置換** (Conlang タブの上部にある矢印のボタン)を押すと、アプリケーションの検索と置換のウィンドウが開き、現在の分岐にある翻訳済みセリフの英語の原文を対象にします(プレーンテキストまたは正規表現、大文字小文字の区別あり/なし)。表には、一致のあるセリフがパートとセリフ番号ごとに並びます。英語で同じ名前が二通りに綴られている場合などに使います。変わるのは原文だけです。翻訳そのものの語句を変えるには、本の検索と置換を使ってください。検索の後に原文が変更されたセリフはそのまま残され、件数に数えられます。

![英語の原文に対する検索と置換](../../images/plugin-conlang-search-replace.png)

![翻訳されたセリフの背後にある英語](../../images/plugin-conlang-story.png)

<a id="the-viewer"></a>

### ビューアー

[公開された本](../books/publishing.md)のビューアーは、**読者に見せるもの**という欄(本の設定またはそのフォルダーの選択。自分の既定値は読者に何を見せるかを決めません)で指定された方法で、翻訳されたセリフを表示します:

| | |
|---|---|
| **構築言語、クリックで英語** | 既定値です。クリック(スマートフォンではタップ)すると英語のポップオーバーが開きます。 |
| **構築言語のみ** | 英語が読者のブラウザーに送られることは決してありません。 |
| **英語のみ** | 翻訳されていない本として表示されます。 |

クリックするモードでは、ページには構築言語だけが含まれ、セリフの英語はクリックされたときにサーバーから取得されます。

![ビューアーで、翻訳されたセリフの背後にある英語](../../images/plugin-conlang-viewer.png)

## 書き出し

本に翻訳されたセリフがある場合、[書き出し](../books/export.md)ダイアログには **翻訳されたセリフ** という欄があります:

![書き出しダイアログ](../../images/plugin-conlang-export.png)

| | |
|---|---|
| **構築言語、そのまま** | 既定値です。保存されているとおりのテキストです。 |
| **英語のみ** | セリフがその英語に置き換えられます。 |
| **構築言語、英語は脚注に** | 翻訳された各セリフに、英語(と話者)の脚注が付きます。 |
| **英語、構築言語は脚注に** | 上の逆です。 |

脚注は[書き出しの脚注](../books/export.md#footnotes)です。HTML と EPUB ではリンクされた注、プレーンテキストではパートごとの末尾の注、Word と PDF ではページ下部の本物の脚注になります。翻訳された後に編集したセリフはそのまま残り、脚注は付きません。書き出しによって、本の保存されたテキストが変更されることは決してありません。
<a id="commands"></a>

## コマンド

画面でできることはすべてコマンドでもできます。[コマンドライン](../commands/index.md)からも、[エージェント](../agents.md)からも使えます。エージェントは、人が対話画面に触れなくても、言語を作り、育て、本を翻訳し、結果を確認できます。言語は**名前**（大文字小文字は区別されません）か id で指定します。文法規則のセクションはタイトルか、`conlang-list-rules` での番号で指定します。カテゴリーは名前か番号で、単語は形で指定します（`conlang-list-words` の id は、同形異義語を区別するためだけに使います）。パートは、アプリケーションの他のコマンドと同じく、ハンドルか、有効な分岐上の位置で指定します（最初のパートは 1）。コマンドラインでは、コマンドのすべての引数を指定できます。エージェントは、省略可能な引数を省いてもかまいません。

<a id="agent-runs"></a>

### エージェントの実行

エージェントは**本のコピー**の上で作業します。言語は本の一部ではないため、エージェントがユーザーの知らないうちにライブラリを変えてしまうことはありません。実行が言語を**変更する**最初のとき（単語、文法規則、または翻訳が新しく作る単語を変えるとき）、その言語は、コピー元のバージョンとともに本のコピーにコピーされます。それ以降、実行は自分のコピーを読み書きします。読むだけの実行や、既存の単語だけで翻訳する実行は、何もコピーしません。このコピーは、本のコピーが行く先に一緒に行きます。チェックポイントとその復元、実行の確認、そして削除もこれに含まれます。

実行の結果を**適用**すると、言語は本に入り、**ライブラリには入りません**。すると本の **Conlang** タブに *An agent run changed the language ...* が表示され、**Review** と **Drop** が出ます。
**Review** では、3つのバージョンを比べます。実行がコピーした時点の言語、実行によるバージョン、そして今のライブラリにある言語です。そのため、その間にライブラリで変更した内容は保たれ、双方が変更した箇所は、ユーザーが決める衝突になります。コマンドからは、`conlang-pending-changes` で変更を番号付きで一覧し、`conlang-take-pending-changes` で取り込みます（こちらはユーザーに確認します）。実行が作った言語は、確認の後に全体が追加されます。

実行は、言語を最初に変更するまではライブラリを読み、その後は自分のコピーを使います。実行が動いている間にユーザーが言語を変えても、実行にはその変更が見えませんが、失われることもありません。

<a id="limits"></a>

## 制限事項

- **品質はモデルに依存します。** 拡張機能は、無料でできる範囲を確認します（引用された発言がパートに含まれているか、言語、語彙に対する単語、複合語と接辞の規則）。残りは報告しますが、文法は確認しません。長い実行の前に、いくつかのパートで言語を試してください。同じ誤りが繰り返される場合は、デザイナーの **Review the language** を使ってください。
- **言語は、それを使う本の間で共有されます。** 単語を変更すると、また翻訳が追加した単語も、シリーズのすべての本で変わります。これは意図した動作です（ひとつの世界）。言語を分けて扱うには **Duplicate** を使います。
- **エージェントによる言語の変更は、本の中で待機します。** 実行を適用した後に、ユーザーがライブラリに取り込みます。実行中も言語はロックされません。
- **コマンドは、物語の中の単語を置き換えません。** また、再翻訳では、英語が変わっていない翻訳を残すことはできません（範囲のすべてのパートが再度尋ねられます）。
- **スマートフォン**では、パネル、エディター、確認画面、ウィザードを使えます。ただし語彙のグリッドは横にスクロールします。ビューアーで発言をタップする操作は動作します。物語側（パートのメニュー、範囲のウィンドウ、物語のクリック）は、スマートフォンでは試していません。
