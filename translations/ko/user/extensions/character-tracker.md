# 캐릭터 트래커

사이드바에 나타나는 책의 등장인물 목록입니다. 각 인물의 한 줄 소개, 메모, 아이콘, 색상, 인물 사이의 관계, 그리고 관계 지도를 한눈에 볼 수 있습니다.

<a id="the-characters-tab"></a>

## 캐릭터 탭

[스토리 편집기](../books/story-editor.md)의 왼쪽 사이드바에는 *개요* 옆에 **Characters** 탭이 추가됩니다. 목록 위에는 버튼 한 줄이 있습니다: **Add**(새 인물 추가), 로어북 항목을 가져오는 메뉴, **Relationship map**, 그리고 프롬프트용 말풍선 버튼(마우스를 올리면 이름이 표시됩니다).

말풍선 버튼을 누르면 [작가 메모](authors-note.md)와 같은 **In prompt**, **Depth**, 역할 설정이 있는 팝오버가 열립니다. 인물이 프롬프트에 들어가 있는 동안 버튼은 초록색으로 표시됩니다. *In prompt*를 체크하면 모든 생성 때마다 인물 정보가 하나의 메시지로 전달됩니다. 각 인물의 이름, 대괄호 안의 한 줄 소개, 메모가 한 줄씩 들어가고, 이어서 관계 목록이 붙습니다(`Mara -> Tomas: employs`처럼 쌍방향이면 `<->`로 표시됩니다). *Depth*는 이 메시지 뒤에 오는 메시지 수입니다(`0`이면 맨 끝, 즉 지시문 뒤, `1`이면 그 바로 앞). 역할은 *System*, *Assistant*, *User* 중에서 고를 수 있습니다. 이 텍스트는 스토리의 토큰 공간을 사용합니다. 책에 인물이 없으면 아무것도 삽입되지 않습니다. 설정은 책과 함께 저장됩니다.

두 버튼 사이에 있는 마법봉 버튼에는 **Import lore entries as characters** 메뉴 항목이 있습니다. 자세한 내용은 [아래](#importing-characters-from-the-lorebook)를 보십시오.

목록은 이름순으로 정렬됩니다. 각 인물은 고유한 색을 가지며, **이름**이 표시되고 그 아래에 더 작은 글씨로 **한 줄 소개**가 나옵니다(최대 두 줄). 인물별 버튼은 다음과 같습니다:

| 버튼 | |
|---|---|
| 꺾쇠 | 인물을 펼쳐 **아이콘**과 **메모**를 보여줍니다. |
| 연필 | 대화상자에서 인물을 엽니다. |
| 휴지통 | 확인 후 인물과 모든 관계를 삭제합니다. |

인물을 바꾸면 즉시 책과 함께 저장되므로 백업에도 포함됩니다.

![캐릭터 탭](../../images/plugin-charactertracker-tab.png)

## 턴에 등장인물 고르기

[새 턴](../books/story-editor.md) 양식에는 **POV character**와 **Present characters** 필드가 있습니다. 두 필드는 여전히 자유 입력 텍스트이지만, 각 필드 끝에는 사람 아이콘 버튼이 있어 책의 인물을 이름순으로 나열합니다. **POV character** 목록에서 고른 이름은 필드의 기존 내용을 대체하고, **Present characters** 목록에서 고른 이름은 쉼표 뒤 맨 끝에 추가되며, 이미 들어 있으면 추가되지 않습니다. 목록은 열 때 읽히므로 방금 추가한 인물도 목록에 나타납니다. 필드에 직접 아무 이름이나 입력할 수도 있으며, 책에 없는 인물의 이름이라도 괜찮습니다.

<a id="the-character-dialog"></a>

## 인물 대화상자

**Add**(더하기 버튼, 툴팁은 *Add new character*)와 연필 버튼은 같은 대화상자를 엽니다:

| 필드 | |
|---|---|
| **Name** | 필수입니다. |
| **Tagline** | 인물에 대한 몇 마디 설명으로, 목록과 지도에 표시됩니다. |
| **Note** | 기억해 두고 싶은 무엇이든 적을 수 있습니다. |
| **Icon** | PNG, JPEG 또는 GIF를 업로드합니다. 비율을 유지하며 최대 200 x 200 픽셀로 축소됩니다. |
| **Color** | 목록과 지도에서 인물의 배경색입니다. |

필드 내용은 **Save**로 적용됩니다.

![관계가 있는 인물](../../images/plugin-charactertracker-dialog.png)

저장하지 않은 변경 사항이 있는 상태에서 **Cancel**(또는 Esc)을 누르면, 입력했지만 아직 추가하지 않은 관계도 포함하여 버릴지 묻는 확인창이 나옵니다.

![저장하지 않은 변경 사항이 있는 인물을 취소할 때 나오는 확인창](../../images/plugin-charactertracker-unsaved.png)

<a id="relationships"></a>

### 관계

기존 인물을 열면 대화상자에는 그 인물의 관계도 나열됩니다. 인물이 가리키는 관계(`→`), 그 인물을 가리키는 관계(`←`), 그리고 단방향이 아닌 관계(`↔`)가 각각 이름과 한 줄 소개와 함께 표시됩니다. 휴지통 버튼은 해당 관계를 삭제합니다.

관계를 추가하려면 다른 인물을 검색하고, **Direction**(*this character → other*, *other → this character*, *both ways* 중 하나)을 고른 뒤, **Name**(예: *employs*, *friends*)을 입력하고, 필요하면 **Tagline**을 적은 다음 **Add relationship**(버튼은 이 필드들 위에 있습니다)을 누릅니다. 관계는 즉시 저장됩니다. 새 인물은 한 번 저장한 뒤에야 관계를 가질 수 있습니다.

<a id="importing-characters-from-the-lorebook"></a>

## 로어북에서 인물 가져오기

등장인물이 이미 로어북에 있다면 마법봉 메뉴로 인물을 만들 수 있습니다. **Import lore entries as characters**를 누르면 책의 로어북과 모든 하위 로어북의 항목이 *order* 순으로 정렬되어 나타나는 대화상자가 열립니다. 각 항목에는 이름과 체크박스가 있고, **i** 아이콘을 누르면 팝오버에서 항목의 내용을 미리 볼 수 있어 결정 전에 빠르게 확인할 수 있습니다. 목록 머리글의 체크박스는 전체를 선택하거나 해제합니다. **Import**를 누르면 체크된 각 항목의 이름으로 인물이 하나씩 만들어지며(한 줄 소개, 메모, 아이콘, 색상은 비어 있어 나중에 채우면 됩니다), **Close**를 누르면 가져오지 않고 닫힙니다.

항목은 이미 있는 인물과 비교되지 않습니다. 같은 항목을 두 번 가져오면 인물이 두 개 만들어집니다.

![로어북에서 인물 가져오기](../../images/plugin-charactertracker-import.png)

<a id="the-relationship-map"></a>

## 관계 지도

**Relationship map**은 책의 모든 관계를 그래프로 보여줍니다. 관계가 있는 인물은 모두 자기 색 위에 아이콘(아이콘이 없으면 상자)이 있는 원으로 표시되며, 이름과 한 줄 소개가 함께 나옵니다. 각 관계는 두 인물 사이의 화살표이며, 이름과 한 줄 소개가 함께 표시됩니다. 화살표는 대상을 가리키며, 단방향이 아닌 관계는 양끝에 화살표가 있습니다. 관계가 없는 인물은 지도에 나오지 않습니다.

![관계 지도](../../images/plugin-charactertracker-map.png)

인물들은 한 인물을 중심으로 고리 모양으로 배치됩니다. 처음에는 관계가 가장 많은 인물이 중심이 됩니다. 중심 인물과 관계가 있는 인물들은 첫 번째 고리에, 그 인물들과 관계가 있는 인물들은 두 번째 고리에 놓이는 식입니다. **인물을 더블클릭**하면 그 인물을 중심으로 지도가 다시 배치됩니다. 인물을 끌어다 놓을 수도 있고, 지도를 옮기거나 마우스 휠로 확대·축소할 수도 있습니다.

<a id="commands"></a>

## 명령

인물은 [명령](../commands/index.md)으로도 다룰 수 있으며, 명령줄과 [에이전트](../agents.md)에서 사용할 수 있습니다. 명령은 열려 있는 책(에이전트는 작업 사본)에 적용되며, 캐릭터 탭이 열려 있으면 변경 사항이 즉시 표시됩니다. 인물은 **name**(대소문자 구분 없음)으로 지정하거나, 같은 이름의 인물이 둘 이상일 때는 `/list-characters`에서 보이는 **번호**(이름순 번호)로 지정합니다. 관계는 `/list-character-relations`에서 보이는 번호로 지정합니다. 인물을 변경하는 명령은 지정한 필드만 바꾸며, 빈 텍스트를 주면 한 줄 소개나 메모가 지워집니다. 아이콘은 대화상자에서만 설정할 수 있습니다.

| 명령 | 역할 |
|---|---|
| `/list-characters` | 인물을 이름순으로 나열합니다: 한 줄 소개, 색상, 메모 유무, 관계 수. 읽기 전용입니다. |
| `/get-character character` | 인물 한 명의 메모와 관계를 보여줍니다. 읽기 전용입니다. |
| `/create-character name [tagline [note [color]]]` | 인물을 추가합니다. `color`는 `#rrggbb` 형식입니다. |
| `/update-character character [name [tagline [note [color]]]]` | 인물을 변경합니다. |
| `/delete-character character` | 확인 후 인물과 그 관계를 삭제합니다. |
| `/list-character-relations [character]` | 관계 전체 또는 한 인물의 관계를 보여줍니다. 읽기 전용입니다. |
| `/add-character-relation source target name [tagline [bidirectional]]` | `source`에서 `target`으로 가는 관계(*employs*)를 추가합니다. `bidirectional`을 `true`로 주면 양방향 관계(*friends*)를 추가합니다. |
| `/update-character-relation relationship [name [tagline]]` | 관계의 이름이나 한 줄 소개를 바꿉니다. |
| `/delete-character-relation relationship` | 확인 후 관계를 삭제합니다. |
| `/character-tracker-map` | 인물과 관계를 프롬프트가 받는 텍스트 형태로 보여줍니다. 읽기 전용입니다. |

`character-tracker-map`은 [{%{`{{command::character-tracker-map}}`}%} 매크로](../templates/macros.md#commands)를 위해 만들어졌습니다. 마스터 템플릿, 사용자 프롬프트, 또는 로어북 항목에 넣으면, 캐릭터 탭의 자동 삽입(또는 그 삽입과 함께) 대신 원하는 위치에 인물을 배치할 수 있습니다. 삽입 기능이 켜져 있든 꺼져 있든 항상 인물의 현재 상태를 보여줍니다.

추가와 변경은 파괴적이지 않으며, 파괴적인 것은 `delete` 명령뿐입니다. 에이전트는 이 명령을 실행하기 전에 확인을 요청하도록 설정될 수 있습니다.

<a id="phone"></a>

## 휴대폰

이 탭은 [작가 메모](authors-note.md)와 마찬가지로 스토리 서랍에서 개요 옆에 있습니다. 시점 인물과 등장인물을 고르는 버튼은 휴대폰의 새 턴 양식에도 있습니다.
