# 책

책은 하나의 이야기입니다. 부분 단위로 지시를 내리면 모델이 본문을 쓰고, 책은 이에 딸린 모든 것을 보관합니다.
분기를 포함한 이야기 트리, 문체를 정하는 프롬프트, 세계와 인물을 담은 로어북, 요약과 백업이 그것입니다.

![이야기 편집기의 책](../../images/hero-story-editor.png)

<a id="parts-and-branches"></a>

## 부분과 분기

책은 **부분**으로 이루어집니다. 각 부분은 모델의 한 번의 응답이며, 여러분이 그 부분에 준 지시(장면, 시점 인물, 등장인물과 일어날 일)에 따라 작성됩니다.

부분들은 트리를 이룹니다. 보통은 이야기를 이어서 쓰면 되지만, 마지막 부분의 다른 버전을 쓰거나, 이전 부분 중 어디로든 돌아가 다르게 이어 쓸 수도 있습니다. 처음부터 끝까지 이어지는 각 경로가 **분기**입니다. 지금 작업 중인 분기가 **활성 분기**이며, 이야기 편집기는 이것을 보여 주고 모델에는 이 분기의 부분만 보냅니다. 자세한 내용은 [분기와 이야기 트리](branches-and-story-tree.md)를 보십시오.

<a id="the-book-window"></a>

## 책 창

책을 열면 다음 탭이 있는 창이 나타납니다.

| 탭 | |
|---|---|
| **정보** | 이름, 태그, 설명, 언어, 모델, 프로토콜, 공개 설정과 단어 수. [책 관리](managing-books.md)를 보십시오. |
| **프롬프트** | 이 책의 템플릿과 문체 설정. [책 프롬프트](prompts.md)를 보십시오. |
| **로어북** | 이 책의 로어북과 그 항목. 하위 로어북이 있으면 두 번째 상자 **표시된 로어북**에서 어느 하위 로어북으로든 탭을 전환할 수 있으며(다시 돌아오기도 가능), 책의 로어북은 바뀌지 않습니다. **하위 로어북** 목록에서 하위 로어북의 이름을 클릭해도 같은 일이 일어납니다. [로어북](../lorebooks/index.md)을 보십시오. |
| **이야기** | 부분을 쓰고 생성하는 이야기 편집기. [이야기 편집기](story-editor.md)를 보십시오. |
| **분기 보기** | 모든 분기가 담긴 이야기 트리. [분기와 이야기 트리](branches-and-story-tree.md)를 보십시오. |
| **백업** | 책의 백업. [책 백업](backups.md)을 보십시오. |

책이 날마다 어떻게 쓰였는지(단어, 시간, 토큰, 크기)와 글을 쓴 날들의 달력은 **통계** 창에서 볼 수 있습니다. [글쓰기 통계](statistics.md)를 보십시오.

이야기는 *이야기* 탭의 설정 메뉴에서 파일로 Marginalia 밖으로 꺼낼 수 있습니다. [책 내보내기](export.md)를 보십시오.

부분이 없는 책은 *정보*가 열리고, 부분이 있는 책은 *이야기*가 열립니다. 모든 변경 사항은 즉시 저장되며 *저장* 버튼은 없습니다. **종료**를 누르면 책이 닫힙니다.

부분을 생성하는 동안에는 생성이 끝나거나 중지할 때까지 다른 탭과 *종료*가 비활성화됩니다.
