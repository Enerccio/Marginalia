# 책 설명 생성기

모델이 이야기를 바탕으로 책의 **이름**과 **설명**을 써 줍니다. 모델이 읽을 이야기의 범위를 고르고, 모델이 쓴 내용을 책에 복사해 넣을 수 있습니다.

<a id="opening-it"></a>

## 여는 방법

확장 기능을 설치하면 책 창의 **정보** 탭 끝에 **이름과 설명 생성** 버튼이 있습니다. [휴대폰 레이아웃](../phone.md#extensions)에서도 동작합니다. 대화상자는 왼쪽에 옵션, 오른쪽에 결과가 나타납니다.

![이름과 설명을 생성하는 창](../../images/plugin-book-description.png)

| 옵션 | |
|---|---|
| **모델**, **프로토콜** | 생성에 사용할 모델과 프로토콜입니다. 처음에는 책의 모델과 프로토콜을 쓰고, 없으면 *설정*의 기본값을 씁니다([계정 및 설정](../account.md) 참고). 이 선택은 이번 생성에만 적용됩니다. 모델이 없으면 경고만 표시됩니다. |
| **시작 메시지**, **끝 메시지** | 활성 분기에서 텍스트가 있는 메시지의 번호로 정한 이야기의 범위입니다. 입력란 아래에 메시지의 앞부분이 표시되므로 어떤 메시지인지 확인할 수 있습니다. 처음에는 이야기 전체가 선택됩니다. |
| **요약 사용** | 범위 안에 모든 메시지가 들어 있을 때, [요약](../books/summaries.md)이 그 요약이 다루는 메시지를 대신합니다. 이렇게 하면 긴 범위도 훨씬 적은 비용으로 처리할 수 있습니다. 범위를 벗어나는 요약은 사용하지 않으며, 더 이상 이야기를 설명하지 않는 요약도 사용하지 않습니다(대신 메시지를 사용합니다). 다음번을 위해 기억됩니다. |
| **응답 형식** | *자동*은 모델의 서비스가 스키마를 지원하면 스키마가 있는 JSON을, 지원하지 않으면 Markdown을 요청합니다. *JSON*은 반드시 스키마를 사용합니다. *스키마 없는 JSON*은 서버가 모델의 사고 과정과 함께 스키마를 처리하지 못할 때를 위해, 스키마 대신 프롬프트에 JSON 형식을 설명합니다. *Markdown*은 이름을 첫 번째 제목으로, 설명을 그 아래에 쓰도록 요청합니다. 모델이 무엇을 쓰든 JSON이나 Markdown으로 읽으므로, 지시를 무시하는 모델의 답도 이해됩니다. 다음번을 위해 기억됩니다. |

옵션 아래에는 범위가 프롬프트와 함께 몇 개의 토큰인지, 모델이 몇 개를 받는지, 그리고 이야기를 그대로 보낼지 아니면 먼저 메모로 만들어야 하는지를 보여 주는 카운터가 있습니다.

**생성**을 누르면 모델이 시작되고, 같은 버튼으로 멈출 수 있습니다. 이름과 설명이 오른쪽에 나타나며, 각각 자기만의 **책에 복사** 버튼이 있습니다. 이 버튼은 텍스트를 정보 탭의 입력란에 넣고 책을 즉시 저장합니다(책 창의 제목도 바뀝니다). 답변을 이름과 설명으로 읽을 수 없으면, 대화상자가 모델이 쓴 텍스트를 보여 줍니다.

<a id="a-story-that-is-too-long"></a>

## 너무 긴 이야기

범위가 모델이 받을 수 있는 양을 넘으면, 이야기를 들어갈 만한 부분들로 순서대로 나눕니다. 모델은 각 부분마다 **메모**를 씁니다(메모는 만들어지는 대로 *메모* 아래에 나타납니다). 그다음 설명은 이야기 대신 메모를 바탕으로 씁니다. 여전히 너무 긴 메모는 다시 나누고 다시 메모로 만들며, 최대 네 번까지 반복합니다. 부분보다 큰 메시지 하나는 문단, 줄, 또는 문장 단위로 잘립니다.

!!!
모델과 프로토콜 모두 컨텍스트 크기가 설정되어 있지 않으면, 플러그인은 무엇이 너무 긴지 알 수 없으므로 항상 이야기를 그대로 보냅니다.
!!!

<a id="prompts"></a>

## 프롬프트

프롬프트는 두 가지입니다. 하나는 이름과 설명을 쓰는 프롬프트이고, 다른 하나는 긴 이야기의 한 부분에 대한 메모를 쓰는 프롬프트입니다. 이들은 [상속되는 설정](../books/prompts.md#inherited-settings)입니다. 책은 자신의 설정을 쓰고, 없으면 직접 설정을 가진 가장 가까운 상위 폴더의 설정을 쓰며, 그것도 없으면 사용자의 설정을, 그마저도 없으면 기본 제공 텍스트를 씁니다.

| 프롬프트 | 변수 |
|---|---|
| **설명 프롬프트** | `{{story}}`(이야기, 또는 이야기로 만든 메모), `{{fromNotes}}`, `{{bookName}}`, `{{bookDescription}}` |
| **메모 프롬프트** | `{{story}}`(부분), `{{part}}`, `{{parts}}`, `{{bookName}}`, `{{bookDescription}}` |

책의 *프롬프트* 탭에서, *확장 기능 설정* 아래에서, 폴더의 대화상자에서, 또는 모든 책에 대해 *설정 → 확장 기능 설정 → Book Description Generator*에서 설정할 수 있습니다. 모델에게 답변 형식(JSON 또는 Markdown)을 알려 주는 지시는 확장 기능이 설명 프롬프트 뒤에 자동으로 덧붙이므로, 여러분의 프롬프트에는 무엇을 써야 하는지만 적으면 됩니다.
