# 书籍

一本书就是一个故事。你分段给出指令，模型生成文本，书中保存着与之相关的一切：包含所有分支的故事树、塑造文风的提示词、包含世界观和角色的设定集、摘要和备份。

![故事编辑器中的一本书](../../images/hero-story-editor.png)

<a id="parts-and-branches"></a>

## 部分与分支

一本书由**部分**组成。每个部分都是模型的一次回答，依据你为它给出的指令（场景、视角人物、在场角色以及应当发生的事）写成。

各部分构成一棵树。通常你只需继续写故事，但你也可以为最后一个部分再写一个版本，或者回到之前的任一部分，从那里换一种方式继续。从开头到某个结尾的每条路径都是一个**分支**。你正在处理的分支是**当前分支**；故事编辑器会显示它，且只有它的部分会被发送给模型。参见[分支与故事树](branches-and-story-tree.md)。

<a id="the-book-window"></a>

## 书籍窗口

打开一本书，会显示其窗口，包含以下标签页：

| 标签页 | |
|---|---|
| **关于** | 名称、标签、简介、语言、模型、协议、发布以及字数统计。参见[管理书籍](managing-books.md)。 |
| **提示词** | 本书的模板和文风设置。参见[书籍提示词](prompts.md)。 |
| **设定集** | 本书的设定集及其条目。当设定集下有子设定集时，第二个框 **显示的设定集** 可将标签页切换到其中任意一个（也可切换回来），而不会改变本书的设定集；点击 **子设定集** 中子设定集的名称也能达到同样效果。参见[设定集](../lorebooks/index.md)。 |
| **故事** | 故事编辑器，在此编写和生成部分。参见[故事编辑器](story-editor.md)。 |
| **分支视图** | 包含所有分支的故事树。参见[分支与故事树](branches-and-story-tree.md)。 |
| **备份** | 本书的备份。参见[书籍备份](backups.md)。 |

每天写作的字数、时间、令牌和大小等变化，以及你写作的日历，可在其 **统计** 窗口中查看，参见[写作统计](statistics.md)。

可以通过 *故事* 标签页的设置菜单，将故事以文件形式导出到 Marginalia 之外，参见[导出书籍](export.md)。

没有部分的书籍默认打开 *关于* 标签页，有部分的书籍则打开 *故事* 标签页。所有更改都会立即保存；没有 *保存* 按钮。**退出** 用于关闭书籍。

在生成某个部分期间，其他标签页和 *退出* 都会被禁用，直到生成结束或你将其停止。
