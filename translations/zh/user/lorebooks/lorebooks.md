# 创建知识库

<a id="the-lorebook-editor"></a>

## 知识库编辑器

打开 **Lorebooks** 标签页。编辑器一次只显示一个知识库；在顶部的 **Lorebook** 字段中选择要编辑的知识库。
知识库属于您的账户：其他用户看不到它们，除非您[共享](#sharing-a-lorebook)了某个知识库。

工具栏分为两行，在窗口较窄时会换行显示：第一行用于知识库（从 **Lorebook** 到 **Tag lorebooks**），第二行用于所选知识库的条目（从 **Add Entry** 到 **Refresh**）。

| 按钮 | |
|---|---|
| **Lorebook** | 选择要编辑的知识库。 |
| **Only root lorebooks** | 只列出不是其他知识库子知识库的知识库（所选知识库仍保留在列表中）。 |
| **Add Lorebook** | 创建一个名为 *New Lorebook* 的新知识库并将其选中。 |
| Clone（两张纸图标） | 复制所选知识库：会询问名称（原名称后加上 *(Copy)*），然后选中副本。副本包含相同的条目（及其设置、标签和负面标签）、标签、描述和扩展数据。其子知识库不会被复制，副本与原知识库使用相同的子知识库。原知识库不会被更改。 |
| **Delete Lorebook** | 删除所选知识库（需确认）。 |
| Import（文件图标） | **Import Marginalia Lorebook**、**Import from SillyTavern**、**Import from archive**（`.md` 文件的 zip 压缩包）或 **Import from other user**（其他用户[共享](#sharing-a-lorebook)的知识库），参见[导入与导出](import-export.md)。 |
| Export（文件图标） | 下载该知识库及其子知识库，参见[导入与导出](import-export.md#exporting)。 |
| Tags（标签图标） | **Tag lorebooks**：一次为多个知识库添加标签，参见[下文](#tagging-many-at-once)。在书中打开的知识库上不显示。 |
| Description（行条图标，第一行最右侧） | **Edit description**：打开一个窗口，用于填写知识库的内容简介，参见[下文](#description)。 |
| **Add Entry** | 向知识库添加条目，参见[条目与激活](entries.md)。 |
| **Full-screen editor** | 以带标签页的全屏窗口打开知识库的条目，参见[全屏编辑](#editing-in-full-screen)。仅限桌面端。 |
| **Search and replace** | 替换知识库条目的名称、正文和注释中的文本，参见[查找和替换](entries.md#search-and-replace)。 |
| **Mass edit** | 将知识库及其子知识库的所有条目在一个表格中打开，参见[批量编辑](#mass-edit)。 |
| Tags（标签图标，位于 **Search and replace** 右侧，第二行） | **Tag entries**：一次为所选知识库的多个条目添加标签，参见[下文](#tagging-many-at-once)。 |
| **Preview activation** | 显示您输入的文本在一轮生成中会使用哪些条目以及原因，参见[预览激活](entries.md#preview-activation)。 |
| **Refresh** | 重新加载条目。 |
| 搜索框 | 只显示包含该文本的条目，参见[搜索并删除多个条目](entries.md#searching-and-deleting-many-entries)。 |
| **Delete selected** | 在列表中选中条目时出现；确认后删除这些条目。 |

工具栏下方是所选知识库的设置：

| 字段 | |
|---|---|
| **Name** | 知识库的名称，在为某本书或作为子知识库选择它时显示。 |
| **Sub Lorebooks** | 其条目会与本知识库一起使用的其他知识库，参见[下文](#sub-lorebooks)。点击已选子知识库的名称可将其打开。 |
| **Tags** | 整个知识库的标签；它们被视为每个条目的标签，参见[标签](entries.md#tags)。 |
| **Scan depth** | `0` 到 `5`：已被使用的条目的内容会被搜索多少轮，以用于其他条目的过滤器，参见[被其他条目带入的条目](entries.md#entries-brought-in-by-other-entries)。它对书所使用的知识库的条目及其子知识库的条目都有效，除非某个子知识库有自己的深度（见下一行）。 |
| **Scan depth as a sub lorebook** | 留空，或 `0` 到 `5`：当本知识库作为书所使用的知识库的子知识库时，其条目的扫描深度。留空表示使用该知识库的扫描深度；`0` 表示本知识库的条目永远不会被其他内容找到。 |
| **Enabled** | 取消勾选时，该知识库不产生任何作用——其条目及其子知识库的条目都不会被使用。 |
| **Share with other users** | 勾选后，其他用户可以查看该知识库并导入一份副本，参见[下文](#sharing-a-lorebook)。新建的知识库默认未勾选。 |

设置下方是知识库的[描述](#description)（如果有的话）。

编辑器的其余部分是[条目](entries.md)列表。所有更改在您进行时即会自动保存。

<a id="description"></a>

### 描述

描述是关于该知识库的几句话（或几行文字）：它是什么世界、用于什么、哪本书在使用它。点击工具栏第一行的行条图标，在窗口中填写后确认；文本为空则删除描述。有描述的知识库会在其设置下方以一行显示，放不下时以省略号截断；将鼠标指针停留在该行上即可读到全文。描述会随知识库一起被复制（克隆、导出、导入、备份），并且是您共享该知识库时，其他用户在名称旁看到的文字。

![知识库描述窗口](../../images/lorebook-description.png)

<a id="sharing-a-lorebook"></a>

### 共享知识库

勾选 **Share with other users**，本安装实例的每位其他用户都能在 **Import from other user**（工具栏第一行的导入按钮）中看到该知识库，包括其名称、作者（您的全名，若没有则为您的登录名）以及描述。他们可以展开一行以阅读条目（以及子知识库的条目），并导入一份副本。取消勾选后，该知识库会从他们的列表中消失；他们已经制作的副本仍归其所有。

* 共享仅供阅读。其他人不能更改、删除或在书中使用您的知识库；您的知识库仍归您所有，您看到的与之前一样。
* 导入会为**其他用户**创建**新的知识库**：即该知识库及其**已共享**的子知识库（无论嵌套多深），包括条目、标签和描述，并按照您的知识库的方式相互关联。这些副本是私有的（未共享）；您之后对自己的知识库所做的任何操作都不会影响它们，它们的更改也不会影响您的知识库。
* **只有本身已共享的子知识库会被显示和复制。** 未共享的子知识库连同其下的所有内容都会被排除在外，包括其下已共享的知识库。当您为带有未共享子知识库的知识库勾选 **Share with other users** 时，会弹出一个问题，询问是否也共享它们：**Yes** 表示共享该知识库及其所有子知识库（无论嵌套多深），**No** 表示只共享该知识库，**Cancel** 表示什么都不共享，并保持复选框未勾选。之后添加的子知识库在您共享之前不会被共享。
* 取消勾选该复选框只会停止共享该知识库；其子知识库仍保持共享状态（并会在他人的列表中单独出现），直到您也取消勾选它们。
* 已删除的知识库、智能体的工作副本以及您自己的知识库不会出现在列表中；已被删除的用户也不会在列表中留下任何内容。

设置下方会显示知识库中已启用条目的 token 估算值。其旁边的 **Count with subbooks** 链接会汇总该知识库及其所有子知识库（无论嵌套多深）中已启用条目的 token 数，并在旁边显示总数。与故事写作时一样，被禁用的子知识库连同其下的知识库一起被排除在外；作为多处子知识库的知识库只计算一次。
该总数是您点击那一刻的统计：更改某个条目后它会消失，再次点击即可重新统计。

当智能体正在处理某本书时，该书所使用的知识库以只读方式显示（参见[智能体](../agents.md)），此时不显示 **Add Entry**、**Search and replace**、**Mass edit**、**Delete Lorebook** 以及设置区域；**Add Lorebook**、导入、导出和 **Refresh** 仍然保留，因此您始终可以开始另一个知识库。
<a id="mass-edit"></a>

## 批量编辑

**批量编辑**会打开一个窗口，把所选世界书**及其所有子世界书**（无论嵌套多深）的每个条目放在同一张表格中。条目按**顺序**排列（先按世界书，再按名称，顺序相同的条目）。它用于整理大型世界书：

- 可以直接修改条目的*启用*复选框、**条目名称**、**顺序**、**标签**、**过滤模式**、**过滤**、**插入模式**、**负面标签**、**激活上下文**及其**片段**、片段范围（**起始消息**和**结束消息**，留空表示不限制）以及条目的**备注**，与编辑器中的操作相同。每个条目占一行，表格可以上下滚动（窗口较窄时也可左右滚动）。修改顺序后，该行会移动到新的位置。表格中的条目文本是缩略显示的；如需阅读或编辑完整内容，请在世界书中打开该条目。
- 每行的**世界书**下拉框显示该条目所属的世界书。选择另一个世界书（世界书本身或其任一子世界书）即可将条目移动到那里。
- 要移动多个条目，请勾选它们（表头的复选框可全选），然后在底部选择**移动到世界书**，再点击**移动所选**。
- 要删除多个条目，请勾选它们并点击**删除所选**；系统会询问一次，然后将它们移入[回收站](../trash.md)。
- 正被智能体使用的世界书会被锁定：其条目显示为灰色，无法修改或移动，也无法将其他条目移入其中。锁定状态按每个世界书分别检查，因此某个子世界书可能被锁定（正被另一本书使用），而其上级世界书仍可编辑。点击**刷新**可重新读取窗口，以查看锁定是否已解除。

修改后关闭窗口时，编辑器中的世界书会随之刷新。

## 全屏编辑

**全屏编辑器**（工具栏第二行）会在一个铺满屏幕的窗口中打开所选的世界书，便于编辑较长的条目（某个条目行中的展开按钮会打开直接定位到该条目的窗口）；书的*世界书*标签页中也有同样的按钮，用于打开该页面显示的世界书。窗口标题为世界书的名称。它与[故事编辑器](../books/story-editor.md)一样由多个标签页组成：拖动标签页可将其放在另一个标签页旁边或下方，拖动它们之间的分隔条可调整大小。

![全屏世界书编辑器：条目列表以及两个在标签页中打开的条目](../../images/lorebook-fullscreen.png)

- **条目**标签页列出所有条目，带有世界书页面的搜索框以及标签和状态筛选器，并提供**添加条目**、**批量编辑**、**给条目加标签**、**预览激活**和**刷新**按钮（批量编辑和标签的更改也会在已打开的标签页中显示）。勾选**包含子世界书**后，它也会列出[子世界书](#sub-lorebooks)中的条目，每个条目都带有其所属世界书的名称；此时**添加条目**会将条目添加到其旁边所选的世界书中，并且此类条目的标签页会标明其所属世界书。该标签页无法关闭。每一行有三个按钮：
  - **打开**（铅笔图标，双击该行也可以）会在你最后使用的条目标签页中显示该条目；若没有这样的标签页，则在列表右侧的一栏中打开一个新的；
  - **在新标签页中打开**（箭头图标）会在你最后使用的条目标签页旁边为该条目添加一个标签页；
  - **删除**（垃圾桶图标）会在确认后删除该条目，并关闭其标签页。

  同一条目最多只在一个标签页中打开：再次打开时会显示它已有的那个标签页。
- **条目标签页**从上到下包括：**名称**、**顺序**和**启用**；**设置**面板（可折叠），其中是该条目的其余设置（筛选模式和筛选器、插入模式、激活上下文和部分、标签和负面标签、部分范围、递归复选框及条件，参见[条目与激活](entries.md)）；然后是 Markdown 编辑器中的**内容**，其旁边是在勾选**显示备注**时出现的**备注**。每个标签页都会记住它显示的是文本、文本与预览，还是仅预览，重新打开窗口时也保持不变。眼睛图标会打开该条目的[激活预览](entries.md#preview-activation)。底部一行显示内容的估计令牌数，若其模板有问题则以红色显示问题所在（仍会照常保存）。用标签页上的**×**关闭该标签页。
- **条目中的图片。**将图片粘贴到内容中，将其拖放到内容上，或使用工具栏的图片按钮选择图片（PNG、JPEG、GIF 或 WebP，最大 10 MB）。图片会与你的文件一起存储（*资源*标签页），并在光标所在位置生成形如 `![Map](resource:…)` 的一行；预览中会显示图片，方括号中的文字即为其图注。删除该行即可将图片从条目中移除。模型读取条目时会忽略这些行。只有在模型设置中勾选了*发送世界书图片*时，图片本身才会发送（参见[推理服务提供商](../inference-providers.md)）。图片随世界书一起流转：副本、共享世界书的复制、导出的世界书文件以及带文件的书籍备份都会携带图片，且副本会获得各自的图片。SillyTavern 导出和书籍导出则不包含图片。故事的*世界书*标签页会在条目文本下方显示图片。目前图片不计入令牌估算。
- **在条目之间跳转。**在内容中（无论是文本还是预览中）按住 Ctrl 点击（Mac 上为 Cmd 点击）另一个条目的名称或关键词，即可在你最后使用的标签页中打开该条目；再加上 Shift 则在新标签页中打开。底部一行还会在**提及于：**之后列出内容中提到本条目名称的条目；点击其中一个即可打开，Shift+点击则在新标签页中打开。条目通过其名称以及其筛选器中的词语来被识别（每个关键词、*文本*筛选器的整段文字，或正则表达式所匹配的内容），以整词匹配，不区分大小写。这与[递归](entries.md)所追踪的内容相近，但并不完全相同：递归还能找到较长单词中的关键词，要求 *AND* 筛选器的所有关键词都匹配，并会检查标签和条件。
- Markdown 编辑器有一个工具栏（粗体、斜体、删除线、分隔线、标题、引用、代码、代码块、表格以及三种列表），右侧有*编辑*、*编辑与预览*（默认）和*预览*三种视图。常用快捷键均可使用（Ctrl+B、Ctrl+I 等）；Tab 键会移动到下一个字段，而不是缩进。你输入的内容会在停止输入片刻后以及离开编辑器时自动保存。
- 窗口顶部显示已启用条目的估计令牌数，以及**包含子书计数**和**搜索与替换**按钮；后者также会在已打开的标签页中替换文本。

所有更改在你编辑时即时保存，因此点击**关闭**不会丢失任何内容。窗口会为每个世界书记住你的离开状态：下次以相同条目和相同标签页打开时，布局也保持一致（已删除的条目会被略去）。关闭窗口后，世界书页面会重新显示条目。

**在别处所做的更改。**标签页中的更改会以该条目当前保存的状态写入条目，因此在别处（世界书页面、批量编辑、另一窗口）对条目*其他*字段所做的更改会被保留，且标签页会显示这些更改。如果自标签页显示以来，**内容**或**备注**在别处被更改，你的文本不会覆盖已保存的内容：底部一行会说明此情况，并提供**保留我的文本**（仍然保存你的内容）和**加载已保存的文本**（放弃你的内容）两个选项。在别处被删除的条目会关闭其标签页。

窗口在打开期间也会跟随已保存的变化：当某个代理或另一窗口（另一个浏览器标签页、故事的世界书标签页）保存或删除条目时，列表会重新加载，该条目的标签页会显示其当前状态（已删除条目的标签页会关闭）。等待**保留我的文本**或**加载已保存的文本**选择的标签页会保持原样，直到你做出选择。在你输入的同一秒内保存的更改可能仍会交叉，此时底部一行会按上述方式询问。

**代理。**当代理正在处理使用该世界书的书籍时，窗口不会提供。如果在窗口打开期间开始运行，窗口会在你下一次更改或切换标签页时转为只读：一个提示条会注明代理的名称（并说明你最后一次更改是否未能保存）。暂停或停止运行，然后点击**重新检查**：条目会按运行停止时的状态重新加载，你即可再次编辑。

[Lore Generator](../extensions/lore-generator.md) 和 [Lorebook VCS](../extensions/lorebook-vcs.md) 扩展也可在此使用：魔杖图标位于列表的行中以及条目标签页的名称行中，修订面板位于列表上方，条目的修订栏位于其标签页中。

<a id="tagging-many-at-once"></a>

## 批量添加标签

工具栏上的两个标签按钮会打开同一个窗口，用于为多个项目添加或移除标签：**给世界书加标签**列出你的所有世界书，**给条目加标签**列出所选世界书中的条目。选择**标签**（或输入新标签并按 Enter）；列表会显示每个项目及其标签，带有所选标签的项目会排在前面，且该标签会被高亮。每行的**+**和**-**按钮可为该项目添加或移除标签；勾选多个项目（表头的复选框可全选），然后使用底部的**为已勾选项添加标签**或**从已勾选项移除标签**按钮，即可对它们全部执行操作。代理正在处理的项目（运行中代理所在书籍的世界书，因而也包括其所有条目）会显示为灰色，在运行暂停或停止之前无法更改。该窗口同样可为[书籍](../books/managing-books.md#tagging-many-books-at-once)加标签。

它为条目添加的标签是普通标签，参见[标签](entries.md#tags)；负面标签则直接设置在条目本身上。

<a id="using-a-lorebook-in-a-book"></a>

## 在书籍中使用世界书

打开书籍及其**世界书**标签页，在**世界书**字段中选择一个世界书。下方的编辑器会显示该世界书，因此你可以在写作时添加和修改条目。清空该字段即可在不使用世界书的情况下写作。

一本书只使用一个世界书。若要使用多个，请创建一个将它们作为子世界书包含在内的世界书，并使用该世界书。

同一个世界书可以被任意数量的书籍使用。对它的更改会从下一次生成的部分起影响所有这些书籍；已经写好的部分则保留写作时所用的设定。
<a id="sub-lorebooks"></a>

## 子设定集

**子设定集**会把其他设定集的条目纳入当前设定集。一个典型的设置如下：

```
"Saga" (used by the books of the series)
 ├─ "World"       places, history, rules of magic
 ├─ "Characters"  the main cast
 └─ "Book 2 notes"
```

- 子设定集自己也可以包含子设定集；所有层级都会被包含。
- 一个设定集可以同时是多个设定集的子设定集。当它被多次引用时，其条目仍然只会被使用一次。
- 设定集不能直接或通过其他设定集包含自身：这样的选择会被拒绝，并显示 *Cannot select sub lorebook: cycle detected.*
- 被禁用的子设定集会连同它所包含的内容一起被排除在外。

![一个包含两个子设定集的设定集：带与不带子设定集时的词元数](../../images/lorebook-sub-lorebooks.png)

所有被包含的设定集的条目会合并在一起，并按照它们的 [顺序](entries.md#order-and-insertion) 排序，无论它们来自哪个设定集。

<a id="disabling-and-deleting"></a>

## 禁用与删除

取消勾选 **Enabled** 可以暂时关闭某个设定集，例如想看看没有它时书的走向如何。使用它的书会停止使用该设定集；重新勾选即可恢复使用。

**Delete Lorebook** 会将该设定集从你的列表中移除。之前使用它的书不再获取其条目，包含它作为子设定集的设定集也会跳过它。数据仍保留在数据库中，直到管理员运行 [清理](../administration/cleanup.md)；在此之前，你可以从 [回收站](../trash.md) 恢复该设定集。[书籍备份](../books/backups.md) 和导出文件中的副本不受影响。
