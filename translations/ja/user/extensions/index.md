# 拡張機能

拡張機能は、アプリケーション本体を変更せずにMarginaliaへ機能を追加します。Marginaliaには30個の拡張機能が付属しています。

| 拡張機能 | 追加される機能 |
|---|---|
| [xAI Grok](grok.md) | xAI独自のAPIを介して、推論プロバイダーとしてxAIのGrokモデルを使えるようにします。推論の内容は回答と分けて表示されます。 |
| [アーク概要](arc-outline.md) | 本のアークと各章の状態を、サイドバーに表示します。モデルにアークを書いてもらうこともできます。 |
| [Anthropic Claude](anthropic.md) | Anthropic独自のAPIを介して、推論プロバイダーとしてAnthropicのClaudeモデルを使えるようにします。思考の要約は推論として表示されます。 |
| [オーディオブック](audiobook.md) | 音声サーバーを使って本をオーディオブックに変換します。語り手と各キャラクターに声を割り当て、最終版はスタジオで仕上げ、章のマーク付きmp3として書き出せます。[音声サーバーの設定](audiobook-server.md) |
| [作者注記](authors-note.md) | モデルへの注記を作成し、本のすべての生成に挿入します。 |
| [ベータリーダー](beta-readers.md) | 架空の読者（ペルソナ）を作成し、本について単独またはグループでチャットできます。 |
| [本の説明文生成](book-description-generator.md) | 物語の範囲をもとに、本の名前と説明文をモデルに書いてもらいます。概要タブのボタンから実行します。 |
| [章マーカー](chapter-marker.md) | パート内のMarkdownの見出しから、ストーリーアウトラインに章のタイトルを設定します。 |
| [キャラクタートラッカー](character-tracker.md) | 本の登場人物と関係性を管理し、その関係図を表示します。 |
| [人工言語翻訳](conlang-translator.md) | あなたが定義した人工言語でキャラクターの台詞を表示します。モデル用に英語の原文を残し、読者はクリックして原文を見られます。 |
| [Gemma 4ツール修正](gemma-4-tools-fix.md) | ツールの結果に別のロールを要求する古いGemma 4モデルでも関数呼び出しが動くようにします。最新のチャットテンプレートを使う場合は不要です。 |
| [Google Gemini](google-genai.md) | Google独自のAPIを介して、推論プロバイダーとしてGoogleのGeminiモデルを使えるようにします。思考の要約は推論として表示されます。 |
| [画像生成](image-generator.md) | 物語の一部の画像を作成します。モデルがプロンプトを書き、ComfyUIまたはOpenAI形式の画像APIが描画します。やり直しや採用も選べます。 |
| [プロンプト履歴](prompt-history.md) | セッション内（およびエージェントの実行ごと）で、モデルに送った直近20件のリクエストを、回答と推論とともに保存します。プラグインのデバッグやプロンプトの確認に使えます。*Settings → Extension Settings*またはエージェントのコンソールから開きます。 |
| [プロンプト検査](prompt-inspector.md) | 生成のプロンプトを表示し、モデルに送信する前に確認を求めます。物語の設定メニューでオンとオフを切り替えます。 |
| [指示のエクスポート](instruction-exporter.md) | 物語の指示、シーンの設定、キャラクターをクリップボードにコピーします。 |
| [知識トラッカー](knowledge-tracker.md) | 追跡対象のキャラクターが知っていることと知らないことを管理し、プロンプトに組み込みます。これにより、キャラクターが持つはずのない知識をモデルが与えなくなります。 |
| [設定生成](lore-generator.md) | 既存の設定をもとに、ロアブックのエントリーの内容をモデルに書いてもらいます。 |
| [ロアブックVCS](lorebook-vcs.md) | ロアブックのエントリーの改訂履歴を管理します。 |
| [漫画生成](manga-generator.md) | 物語の一部を、ページとコマのある漫画の脚本と、画像生成用のタグに変換します。 |
| [モデル用ツール](tools.md) | 生成ツールの**Tools**ボタンです。モデルが使ってよいツールのスイート（名前や地名など）と、そのカテゴリーを設定します。 |
| [名前生成](name-generator.md) | モデルが名前を自作する代わりに使える名前を提供します。マルコフ連鎖による約1270種類の名前リストを含みます。 |
| [名前プロバイダー](name-provider.md) | モデルが選べる実在の名前を提供します。約100か国の名と姓を、原語の綴りで含みます。 |
| [地名プロバイダー](place-provider.md) | モデルが調べられる実在の地名を提供します。都市、海、湾、川、山などを座標と国とともに含み、ある場所の周辺や二つの場所の距離も調べられます。 |
| [実在言語翻訳](real-language-translator.md) | キャラクターの台詞を実在の言語で表示します（日本を舞台にした物語なら日本語）。モデル用に英語の原文を残し、読者はクリックして原文を見られます。 |
| [レビュアー](reviewer.md) | モデルが書いた物語のパートのレビュー（読者の反応や批評）を作成します。 |
| [サイドクエリ](side-query.md) | 物語の隣で、本についてモデルとチャットできます。 |
| [コンバーター](sillytavern-converter.md) | 物語の隣にSillyTavernのチャットを表示し、そこからモデルが準備する詳細をもとに、チャットを物語として書き直せます。また、古い本（バックアップまたは本そのもの）のパートを指示とともに読み込み、書き直すこともできます。 |
| [状態トラッカー](state-tracker.md) | 追跡対象のキャラクターの現在の状態（服装、所持品、手にしている武器、負傷、気分、または独自のカテゴリー）を管理し、プロンプトに組み込んでモデルがそれに沿うようにします。 |
| [ストーリーノート](story-notes.md) | 自分のページ（タグやページ間のリンク付き）による小さなウィキを、サイドバーに表示します。プロット、アイデア、世界の設定に使えます。プロットウィザードとエージェントは、許可したページを読み取り、変更できます。 |
| [読み上げ](tts-reader.md) | 公開された本を、ビューアーで端末の音声を使って読み上げます。 |
| [中国語ローカライズ](chinese-localization.md) | ユーザーインターフェースの言語として簡体字中国語を追加します。 |

<a id="installing"></a>

## インストール

拡張機能はMarginaliaのインストール全体に対して**管理者**がインストールします。*Admin → Extensions*で行います。
拡張機能はJARファイルで、**Load Extension (.jar)**からアップロードします。詳細は[拡張機能の管理](../administration/extensions.md)を参照してください。

インストールされた拡張機能は、すべてのユーザーが利用できます。Marginaliaの実行中に読み込まれた拡張機能は、その後に開いたウィンドウに表示されます。本を閉じてから開き直す（またはページを再読み込みする）と表示されます。

!!!warning バージョンを合わせる
拡張機能はMarginaliaの特定のバージョンのユーザーインターフェースに組み込まれます。別のバージョン向けに作られた拡張機能は、動作しなくなったり、アプリケーションの一部を壊したりすることがあります。お使いのバージョンのMarginaliaに付属する拡張機能を使用してください。
!!!

上記の拡張機能はMarginaliaのソースコード（`marginalia/plugins`）の一部であり、別途ビルドされます。詳しくは[プラグインのREADME](https://github.com/Enerccio/Marginalia/blob/master/marginalia/plugins/README.md)を参照してください。

<a id="extensions-on-a-phone"></a>

## スマートフォンでの拡張機能

[スマートフォン向けのレイアウト](../phone.md)は独自のクラスを持つため、拡張機能はこれに対応している必要があります。アーク概要、作者注記、ベータリーダー、章マーカー、キャラクタートラッカー、指示のエクスポート、レビュアーは対応しています。サイドクエリ、設定生成、ロアブックVCSはスマートフォンでは何も追加しません（[スマートフォンでのMarginaliaの使い方](../phone.md#extensions)を参照）。名前生成、名前プロバイダー、地名プロバイダー、Gemma 4ツール修正、Google Geminiには独自の画面がありません（Google Geminiはモデルのダイアログにプロバイダーを追加するだけで、これはスマートフォンにもあります）。中国語ローカライズは、スマートフォンのメニューの言語選択に含まれます。拡張機能のインストールはAdminページから行いますが、スマートフォンにはこのページがありません。

<a id="extension-settings"></a>

## 拡張機能の設定

設定を持つ拡張機能は、**Settings → Extension Settings**（*Settings*ページの3番目のタブ）にセクションを追加します。
これらの設定は、*Settings*の他の項目と同じくあなたのアカウントに属し、その**Save**ボタンで保存されます。

<a id="where-extension-data-is-kept"></a>

## 拡張機能のデータの保存先

拡張機能は、データを関連するデータとともに保存します。レビューは物語のパートと、会話は本と、改訂履歴はロアブックとともに保存されるため、[データベースのバックアップ](../administration/database-backups.md)に含まれます。[本のバックアップ](../books/backups.md)とエクスポートにも含まれるかどうかは、各拡張機能のページに記載されています。

拡張機能をアンインストールしてもそのデータは削除されません。再びインストールすると、データも元に戻ります。
