# ベータリーダー

あなたが作り出す読者と、本についてのチャットです。**ペルソナ**（名前、アイコン、その人物がどのように読み、何を大事にするかを数行で記述したもの）を定義すると、モデルがその人物を演じます。読者は一人でも、互いに議論する複数人のグループでも、物語の各部分にその読者らしく反応します。読者の発言は、本の一部にはなりません。

![2人のペルソナによるグループチャット](../../images/plugin-betareaders-chat.png)

<a id="the-beta-readers-tab"></a>

## ベータリーダーのタブ

[ストーリーエディタ](../books/story-editor.md)の左サイドバーには、*アウトライン*の隣に**ベータリーダー**タブが追加されます。このタブには、本の開いているチャットごとにタブがあります。**+**でチャットを始められ、その隣のメニュー（⋮）には次の項目があります。

| 項目 | |
|---|---|
| 新しいチャット | **+**と同じです。 |
| チャットの名前を変更 | チャットのタイトルを変更します。 |
| チャットを閉じる | タブを閉じます。チャットは保存されたまま、*閉じたチャット*に入ります。 |
| チャットの設定 | [チャットのオプション](#the-options-of-a-chat)を変更します。 |
| チャットを削除 | 確認の後、チャットとその履歴を削除します。 |
| この本のペルソナ | この本だけに属するペルソナです。[後述](#personas)を参照してください。 |
| 閉じたチャット | 閉じたチャットをもう一度開きます。 |

チャットは本と一緒に保存されるので、本のバックアップにも含まれます。

![最初のチャットの前のタブ](../../images/plugin-betareaders-tab.png)

![チャットのメニュー](../../images/plugin-betareaders-menu.png)

<a id="personas"></a>

## ペルソナ

ペルソナには、**名前**、**説明**（モデルが演じる内容：その人物がどのように読むか、何を好み、何にいらだつか）、そして任意で**アイコン**（小さく縮小された画像）があります。アイコンがない場合、ペルソナは名前の頭文字を入れた円で表示されます。

あなたのアカウントのペルソナは、*設定 → 拡張機能の設定 → ベータリーダー*にある**ペルソナライブラリ**に入っており、Athena、Vesper、Ember、Quill、Nox、Sable の6人の読者から始まります。**ペルソナを編集**を押すと、ライブラリがウィンドウで開き、ペルソナの追加、編集、コピー、削除、並べ替えができます。アイコンのアップロードや、ライブラリに欠けているスターターペルソナの追加も行えます。変更は**保存**で適用され、**キャンセル**で破棄されます。

![ペルソナライブラリ](../../images/plugin-betareaders-library.png)

本には独自のペルソナを持たせることもできます。チャットのメニューにある*この本のペルソナ*を開くと、同じウィンドウに、この本だけが提供するペルソナが表示されます。チャットに選ぶ際には、それらには*(この本)*と表示されます。

![本のペルソナ](../../images/plugin-betareaders-book-personas.png)

ペルソナのウィンドウにある**モデルで作成**は、作成を代わりに行います。ペルソナを数語で説明し（*誰が犯人で、なぜそうしたかだけを気にする読者*など）、ボタンを押すと、モデルがライブラリの文体に合わせて**名前**と**説明**を埋めます。これらは単なる入力欄なので、自由に変更するか、もう一度作成し直し、よければ**保存**してください。文章を作成するモデルは、チャットで使われているモデルです（本のペルソナの場合は本のモデル、ライブラリの場合はプラグインの設定にあるモデル、それ以外はあなたの既定のモデル）。リストにある既存の名前はモデルに伝えられるので、同じ名前が付けられることはありません。

![モデルが書いたペルソナ](../../images/plugin-betareaders-write-persona.png)

チャットは自分のペルソナの**コピー**を保持するので、ライブラリを変更しても、すでに始まったチャットは変わりません。コピーは、あなたが求めたときに変更されます（[グループ](#a-group)を参照してください）。

<a id="starting-a-chat"></a>

## チャットを始める

**+**を押すと、新しいチャットのウィンドウが開きます。

![新しいチャットのウィンドウ](../../images/plugin-betareaders-new-chat.png)

| 欄 | |
|---|---|
| 種類 | **一人のペルソナ**または**グループ**。後から変更することはできません。 |
| タイトル | 空欄の場合は、ペルソナの名前が使われます。 |
| ペルソナ | 一人のチャットでは一人のペルソナ。グループでは少なくとも一人のペルソナ（グループは一人で始めて、後から他のペルソナを加えることもできます）。 |

折りたたまれている部分**ストーリー、媒体、モデル、形式**には、[チャットのオプション](#the-options-of-a-chat)が入っています。どの項目も空欄のままにでき、その場合は継承されます。

**一人のペルソナ**のチャットは、あなたとそのペルソナとの会話です。**グループ**は、その場にいるすべてのペルソナが、あなたとも互いとも交わす会話です。一つの返信で複数のペルソナが次々に話すことがあり、意見が食い違ったり、からかい合ったり、互いの意見を発展させたりすることもあります。返信のメッセージには、地の文（*ナレーター*）も入ることがあります。これは、そのペルソナがしている動作を短く描写したものです。
<a id="talking"></a>

## 話す

下の入力欄に書き込んで **送信** を押すと、返答が書かれていくのに合わせて表示されます。モデルが返答している間は *停止* と表示されるボタンになり、**停止** を押すと途中で止められます。1回の返答はモデルの1ターンにあたり、モデルが考えた内容（閉じられた **推論** の節。考える機能のないモデルでは表示されません）と、ペルソナたちのメッセージ（それぞれの行動と発言）からなります。

<a id="sending-a-scene"></a>

### 場面を送る

**場面として送信**（*送信* の隣）は、発言の代わりに文章を場面として送ります。たとえば場面の転換（*照明が落ち、バーは静まり返る。*）や、自分の行動の描写（*原稿を机に置いて、待つ。*）です。履歴では **場面** カードとして表示され、ペルソナたちはメッセージと同じように、それが起きた時点で反応します。会話の開始位置を決めるのはチャットの場面（[下記](#the-scene)を参照）で、その後に起こることを書くのがこのボタンです。場面のメッセージは、自分のメッセージと同じように編集や削除ができます。物語の一部を送ることはありません（*最新のパートを含める* の欄は *送信* に属します）。

![チャットの履歴の場面と、それへの返答](../../images/plugin-betareaders-scene.png)

グループのペルソナたちには、最後に送ったメッセージの末尾時点で誰が同席しているかが伝えられます（この情報は保存されません）。そのため、ペルソナを加えたり外したりしても、それ以前の履歴が変わることはありません。

<a id="sending-the-story"></a>

### 物語を送る

チャットは物語の写しを保持しません。ペルソナに**渡した**パートを覚えていて、要求のたびに、今の物語から読ませる物語を組み立て直します。渡したパートと、古いほうのパートの代わりに入れる要約を、モデルのコンテキストに収まる範囲で並べます。パートはそれを渡したメッセージの前に置かれるので、各パートは要求の中に一度だけ入り、さらにパートを渡しても要求の先頭は同じテキストのままです。要求の先頭だけを保持するモデルサーバーでは、新しく増えた部分だけを読むことになります。パートを編集すると編集後の内容が読まれ、削除したパートはもう読まれなくなります。そのため、そのパートを渡したメッセージから後の要求が変わります。後から作った要約は、次のメッセージ以降、それが説明するパートの代わりになります。

**最新のパートを含める** は、ペルソナにより多くの物語を読ませるための欄です。まだ渡していないパートを追加します（[下記](#how-much-of-the-story-the-personas-read)を参照）。オフのままにすると、ただ会話を続けて、物語は後から渡せます。欄のラベルには追加されるパートの数が表示されます（*物語を含める（5パート）*、*最新のパートを含める（新規2）*、*新規なし*）。この数は物語に合わせて自動的に変わります。パートを追加、編集、削除したり、分岐を切り替えたりすると数字が変わり、新しいものがあるとチェックが入ります。自分のメッセージには、どのパートを渡したかが表示されます（*パート1-5を送信済み*）。

入力欄の隣にある **最後のパート** と **最初のパート** は、[ペルソナが読む物語の範囲](#how-much-of-the-story-the-personas-read)を決めるものです。読み進めるにつれて、ここで変更してください。

入力欄の下には、ペルソナたちが読んだ範囲（*ペルソナが読んだのは: パート1-5*）と、コンテキストの大きさ（*コンテキスト: 2,266 / 30,720 トークン*）が表示されます。これは次のメッセージで送られる量、つまり履歴、入力中の文章、そして *最新のパートを含める* にチェックを入れた場合はそれによって追加されるパートを示します。チェックを入れたとき、または入力中に一時停止したときに変わります。パートには少なくとも全体の半分のコンテキストが割り当てられます。履歴がその横に収まらない場合、古いメッセージ（それが渡したパートを含む）は要求から外されますが、削除はされず、その数が通知で示されます。

<a id="changing-the-conversation"></a>

### 会話を変更する

| ボタン | |
|---|---|
| ペン（自分のメッセージ） | メッセージを編集します。それで渡したパートは渡したままになります。 |
| ゴミ箱 | 自分のメッセージ、または返答の中の1つのメッセージを削除します（ターンの残りはそのまま残り、モデルは削除された状態のターンを見ます）。 |
| 再生成 | 最後の返答を破棄して、もう一度尋ねます。 |

返答が失敗したか、返答がない場合、パネルにその旨が表示され、**もう一度尋ねる** が提示されます。

![メッセージの操作](../../images/plugin-betareaders-actions.png)

<a id="a-group"></a>

### グループ

会話の上にある *ペルソナ（n）* は、同席しているメンバーの一覧です。グループでは次のことができます。

- ライブラリまたは本から **ペルソナを呼び入れる**。任意で、グループに加わった理由を伝えるメモを付けられます（「マラは本全体を読んでいる」）。履歴には1行が追加され（*マラが会話に加わりました。*）、モデルはいつ加わったかを知ることができます。
- ペルソナを **退場させる**（その行の矢印ボタン）。ここでも任意でメモを付けられます。退場したペルソナは一覧に残り、灰色で *(退場)* と表示されます。最後の1人は退場できません。
- **ライブラリから更新**: ライブラリ（または本）にある、ペルソナの現在の説明とアイコンを、そのチャットに取り込みます。

![グループに加わったペルソナ](../../images/plugin-betareaders-joined.png)

![ペルソナを呼び入れる](../../images/plugin-betareaders-bring-in.png)

## 1つのチャットのオプション

新しいチャットのウィンドウと **Chat settings** には同じオプションがあります。どれも空欄のままにでき、その場合はチャットがそれを継承します。

| オプション | |
|---|---|
| Your name | ペルソナがあなたを呼ぶ名前です。メッセージにも *You* の代わりにこの名前が表示されます。空欄の場合は名前なし。 |
| Scene | 会話がどこで、どのように行われるかを数文で書きます。例：*閉店後の雨の降るバー*、*読書会のあとのビデオ通話*。設定しない場合、チャットはオンラインチャットになります。[下記](#the-scene)を参照。実行中のチャットでこれを変えると、次のリクエストからシステムプロンプトが変わり、履歴には行が残りません。これから起こる出来事には [シーンのメッセージ](#sending-a-scene) を使ってください。 |
| Medium | テキストが何を表すか。本、映画、テレビシリーズ、マンガやコミック、オーディオドラマ、舞台劇、ゲームやビジュアルノベルなど。ペルソナは、その媒体の観客がするように反応します。実行中のチャットでこれを変えると、履歴に行が残ります（*From now on the text is read as: ...*）。 |
| Model | 応答するAIです。 |
| Protocol | これに使う[プロトコル](../protocols.md)です。 |
| Reply format | モデルにどのように書かせるかです。**Automatic**（モデルがスキーマに従えるならスキーマ付きのJSON、そうでなければ自由記述）、**JSON**（常にスキーマ付き）、**JSON without a schema** または **Free text** があります。[推論](#the-reasoning)を参照。 |
| Personas read up to part | [ネタバレの上限](#how-much-of-the-story-the-personas-read)です。新しいチャットのウィンドウにのみ表示され、既存のチャットではテキスト入力欄の下にあります。 |
| Start from part | ペルソナが読む物語の始まりとなるパートです。上と同じです。 |
| Use the summaries of the story | 下記を参照。 |
| Most messages in a turn | あなたの1つのメッセージに対して、ペルソナが返信として書く最大メッセージ数です（1〜50）。空欄の場合は、*Settings → Extension Settings → Beta Readers* での設定が使われます。これを超える返信は途中で切られ、モデルにその上限が伝えられます。 |

![チャットの設定](../../images/plugin-betareaders-chat-settings.png)

<a id="the-reasoning"></a>

### 推論

返信の上に表示される **Reasoning** は、サーバーが送ってくるモデルの思考です（Marginaliaの他の生成機能と同じです）。思考をしないモデルには何もなく、何も表示されません。プラグインは、独自の推論をモデルに求めることはしません。スキーマの下で書かれた数文は、思考というより計画に近くなり、思考するモデルの邪魔になるだけだからです。`<think>` タグの間に本文として書かれた思考も、推論として表示されます。

**JSON without a schema**（*Chat settings* にあります）は、同じJSONをプロンプトの中だけで求め、レスポンス形式は指定しません。サーバーがスキーマとモデルの思考を同時に扱えない場合に使ってください。

<a id="the-text-as-it-is-written"></a>

### 書かれていくままのテキスト

返信は、モデルが書いていくのに合わせて、メッセージごと、単語ごとに表示されます。誰が話しているかが分かった時点で、書きかけのメッセージが現れ、だんだん長くなります。行動を表すパートは、その種類が書かれた時点で表示されるので、ジェスチャーが最初から発言に見えてしまうことはありません。

返信が伸びると、会話もそれに合わせて下へ追従します。前の部分を読むために上へスクロールすると、その位置に留まります。最後まで戻ると、また追従します。メッセージを送ると、必ず一番下に移動します。

<a id="the-scene"></a>

### シーン

シーンは、すべてのチャットのシステムプロンプトに入るテキストです。プロンプトの後に入るので、ペルソナは自分たちがどこにいて、互いにどう話すかを把握できます。これは[継承される設定](../books/prompts.md#inherited-settings)です。チャット自身の設定があればそれを使い、なければ本の設定、なければ最も近いフォルダーの設定、それもなければ *Settings → Extension Settings → Beta Readers* の設定、それもなければ組み込みの設定、つまり**オンラインチャット**を使います。オンラインチャットでは、全員がどこからでも短いメッセージを書きます。`{{scene}}` を含む独自のプロンプトがあれば、そこにシーンの位置が決まります。含まれていなければ、シーンはプロンプトの後に追加されます。

<a id="how-much-of-the-story-the-personas-read"></a>

### ペルソナが読む物語の範囲

パートは、物語の *Outline* タブと同じく1から番号が振られています。

- **Personas read up to part**（テキスト入力欄の下にある **Last part** 欄）はネタバレの上限です。ペルソナは、それより後のパートを決して受け取りません。また、要約はこの上限までの物語からのみ集められます。物語が先に進んだら上げてください。次のメッセージで、それまで除外されていたパートが新しいものとして提示されます。下げると、ペルソナはすぐに後のパートを読むのをやめます。
- **Start from part**（**First part** 欄）は、それより前のパートを、要約としてさえも除外します。ペルソナに1つの章だけを読ませたいときに使います。
- **Use the summaries of the story**（初期状態でオン）は、物語を要約から始め、そのうち最も新しいものより後のパートを続けて読ませます。これにより長い物語も小さく保てます。要約は、物語が冒頭から始まる場合にのみ使われます。

最後のパートより後の最初のパートは受け付けられません。

これらをテキスト入力欄の下で変更すると（入力を止めるか、ステップボタンをクリックした時点で保存されます）、次のメッセージから、ペルソナが読む物語が変わります。物語はメッセージごとに組み立てられるので、何も再送信はされません。

![パート2から3だけを読むチャット](../../images/plugin-betareaders-spoiler.png)

ロアブックはペルソナに送られません。ペルソナが知っているのは、物語が彼らに語ることだけです。

<a id="settings"></a>

## 設定

*Settings → Extension Settings → Beta Readers* がデフォルト設定の場所です。

![プラグインの設定](../../images/plugin-betareaders-settings.png)

| 設定 | |
|---|---|
| Medium | チャットの媒体です。 |
| Model of the chats | AIです。空欄の場合は本のモデルが使われます。 |
| Protocol of the chats | 空欄の場合は本のプロトコルが使われます。 |
| Prompt of a chat with one persona | 1対1のチャットのシステムプロンプトです。空欄の場合は組み込みのプロンプトが使われます。 |
| Prompt of a group chat | グループチャットのシステムプロンプトです。空欄の場合は組み込みのプロンプトが使われます。 |
| Scene | [上記](#the-scene)を参照。空欄の場合はオンラインチャットです。 |
| Most messages in a turn | 独自の上限を設定していない、すべてのチャットに対して、あなたの1つのメッセージへの返信としてペルソナが書く最大メッセージ数です（1〜50）。空欄の場合は自動で、1人のペルソナのチャットは3、グループの場合はペルソナ1人につき約2（最大8）です。上限を短くすると返信も短くなります。ペルソナの会話が途中で切れてしまう場合は、上限を上げてください。 |
| Persona library | **Edit personas**。[上記](#personas)を参照。 |
| Mediums | **Edit mediums**：各媒体には名前と、その媒体にペルソナがどう反応するかを指示するプロンプトがあります。**Restore the built-in mediums** は、足りない組み込みの媒体を追加します。 |

プロンプト内の `{{medium}}` は媒体のテキストに、`{{scene}}` はシーンに置き換えられます。設定は *Settings* ページの **Save** ボタンで保存されます。

シーン、媒体、モデル、プロトコル、2つのプロンプトも[継承される設定](../books/prompts.md#inherited-settings)です。本の *Prompts* タブと[フォルダー](../books/folders.md)の設定には、**Extension Settings** セクションにこれらがあります。本は自身の値を使い、なければ最も近いフォルダーの値、なければ *Settings* の値、それもなければ組み込みの値を使います。モデルとプロトコルの本の設定は最後の手段です。チャットは、媒体、モデル、プロトコルについて、自身の[オプション](#the-options-of-a-chat)で個別に上書きします。

<a id="on-a-phone"></a>

## スマートフォンで

使えます。**Beta Readers** タブは物語のアウトライン・ドロワーにあります。チャットはデスクトップと同じです。会話の場所は狭いので、横向きの方が操作しやすいです。[スマートフォンでMarginaliaを使う](../phone.md#extensions)を参照してください。

## 保存

本のペルソナとチャットは、本の属性に保存されます（そのためバックアップにも含まれます）。あなたのアカウントのペルソナと、ユーザー設定の各設定は、それぞれアカウントとユーザー設定に保存されます。モデルへの依頼は、AIの通常の制限のもとで行われ、そのトークンは本の使用量として数えられます。
