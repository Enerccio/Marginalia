# The layer of every main class, for LayerDependencyTest (see TODO.REFACTOR.md).
#
#   <layer> <name>
#
# <layer> is "platform" (no story concept: what Joi and the visual novel build on) or "app" (Marginalia itself).
# <name> is a package or a class, relative to com.github.enerccio.marginalia ("." alone is the base package itself).
# The longest name that matches wins, so a package gets a default and the classes that differ are listed under it.
# Nested classes go with their outer class. A class that no line matches fails the test: decide its layer here.
