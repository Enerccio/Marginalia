# チャプターマーカー

[ストーリーエディタ](../books/story-editor.md)の**アウトライン**を目次に変換します。

![アウトラインの章](../../images/plugin-chaptermarker.png)

<a id="how-it-works"></a>

## 仕組み

パートのテキストにMarkdownの見出し（`#`で始まる行）が含まれている場合、そのパートのアウトライン上の項目には、通常の`#n (DB ID: m)`というラベルの代わりに、見出しが強調表示されて表示されます。

```
# 第3章：港町

雨はオストラの夜明けからずっと降り続いていた...
```

アウトラインでは**5. 第3章：港町**と表示されます。番号はブランチ内でのパートの位置で、その後ろに見出しが続きます。見出しのないパートは通常のラベルのままです。

- 見出しはパートのどの行にあってもかまいません。複数ある場合は最初のものが使われます。
- 見出しのレベルは任意です（`#`、`##`、`###`...）。
- [編集](../books/story-editor.md#editing-the-text)を保存するとすぐにアウトラインが更新されます。見出しを追加すると章が始まり、削除するとそのパートは前のパートに統合されます。

<a id="usage"></a>

## 使い方

設定する項目はありません。見出しをパートに自分で書き込むか、指示でモデルに頼んでください。例：*「Markdownの見出しで『港町』という題名の新しい章を始めてください。」*

!!!
デフォルトの[ユーザープロンプト](../books/prompts.md#user-prompt)では、モデルに題名や章の見出しを書かないよう指示しています。モデルに書かせたい場合は、指示内容でそのように明記するか、ユーザープロンプトのこの規則を変更してください。
!!!

見出しはストーリーテキストの一部なので、モデルにも送信され、[ビューア](../books/publishing.md)やバックアップにも表示されます。

同じ規則で、[書き出した本](../books/export.md#table-of-contents)の目次にも章が検出されます。
