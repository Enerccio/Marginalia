# 読み上げ

デバイスの音声を使って、公開された本を[ビューア](../books/publishing.md)で読み上げます。

<a id="using-it"></a>

## 使い方

リーダーには、右上の文体ボタンの隣に小さなコントロールがあります。

- **再生**は、画面に表示されている部分、または選択したテキストの先頭の部分から始まります。読み上げ中の部分はハイライトされて画面内にスクロールされ、続きの部分は読み進めるにつれて読み込まれます。
- **一時停止**と**停止**。
- **歯車**を押すと設定が開きます。**音声**（まずはブラウザーの音声のうち、本の言語のもの。既定値はその言語で最も良い音声です）、**速度**、**ピッチ**を設定できます。

<a id="good-to-know"></a>

## 知っておくと良いこと

- 音声はブラウザー（`speechSynthesis`）が生成します。何もサーバーに送信されず、設定もブラウザーに保存されるため、その設定はそのデバイスとブラウザーに紐づきます。音声の種類と品質も、それらに依存します。
- 読み上げられるのは、ページ上のテキストです。[Conlang](conlang-translator.md)と[Real Language](real-language-translator.md)の翻訳機能による翻訳された発話は、本に表示されているとおりに読み上げられます。
- 一時停止に対応していない電話機もあります。その場合、読み上げはその場で止まります。
- [Audiobook](audiobook.md#a-part-without-audio)拡張機能を使っている場合、まだ音声のない部分は、そのプレーヤーに表示されるボタンを押すと、ブラウザーの音声で読み上げられます。
- 本を離れると読み上げは止まります。ブラウザーが読み上げに対応していない場合、このコントロールは表示されません。
