# 有声书

用文字转语音服务器把一本书逐段制成有声书：为旁白和每个角色分别设定一个声音，这些声音与书的各段保存在一起，并在阅读器中播放。你可以让它自动运行（由模型标注谁在说话以及如何说，语音服务器负责朗读），快速得到一份粗略的草稿；也可以在 **有声书工作室** 中逐段处理，查看发送给语音服务器的确切内容并手动修改，最后导出为带章节标记的 mp3 文件。

该扩展本身不合成语音：它与你自行运行的 **Chatterbox-TTS-Server** 通信（参见[搭建语音服务器](audiobook-server.md)）。书的正文从不被改动，也只会发送给你指定的服务器；生成的音频保存在你自己的安装中，作为与各段相关联的资源。

<a id="what-you-need"></a>

## 你需要准备的东西

- 一台语音服务器；如果它与你的语言模型共用一块显卡，还需要在开始和结束工作时自动腾出显存的请求（[搭建语音服务器](audiobook-server.md)）。
- 声音：每个你想克隆的声音都需要一段简短的 **参考音频**（一个人的 12 到 30 秒录音，不含音乐），或者使用服务器自带的声音文件之一。旁白需要平稳、沉稳的朗读声音。
- 对于多角色的书，需要一个能为文本做标注的语言模型。默认使用该书所用的模型。
- **ffmpeg** 是可选的。没有它，一切仍可用 mp3 完成。有了它（Docker 镜像中已包含；在桌面环境中，它应位于 `PATH` 中，或位于 `/opt/homebrew/bin` 等常见目录；若位于其他位置，用环境变量 `MARGINALIA_FFMPEG` 指明），导出时可得到 **m4b** 格式；管理员还可以选择以 wav 格式保存音频。

<a id="the-settings"></a>

## 设置

*设置 → 扩展设置 → 有声书设置* 是你账户的设置面板；修改后请保存 *设置* 页面。

![带有后端和演员的面板](../../images/plugin-audiobook-settings.png)

<a id="backends"></a>

### 后端

后端是一台语音服务器及其所用的模型。点击 **+** 添加一个。

| 设置 | 作用 |
|---|---|
| 名称 | 在“转换”对话框中显示的名称。 |
| 地址 | 语音服务器的基础地址，或转发到它的服务的地址，例如 `http://localhost:8004`。 |
| Api 密钥 | 若服务器（或你的代理）需要，则以 bearer 令牌的形式发送。它以加密方式保存，之后不再显示；输入新值即可替换，或点击 **移除密钥**。 |
| 语音模型 | **Chatterbox Turbo**（英语，支持 `[sigh]` 等声音标签，速度最快，为默认值）、**Chatterbox**（英语，可调节朗读的 *夸张度*）或 **Chatterbox Multilingual**（23 种语言）。批处理之前的请求必须让该模型保持加载状态。需要其他模型的书应使用另一个后端。 |
| GPU（名称） | 可选。共用同一块 GPU 的服务器（包括 [图像生成器](image-generator.md) 所用的服务器）应在此填写相同的名称：它们的任务会相互等待，而使用其他模型的后端则会等待其他任务完成。留空：只有发往同一地址的批处理会相互等待。 |
| 服务器位于本机或我的网络中 | 允许访问本地网络中的地址。若服务器位于云端，请保持关闭：这样它就无法被诱导去调用你自己的机器。 |
| 请求超时 | 等待一段语音返回的最长时间。 |
| 每处理多少段后重启服务器 | 针对会泄漏内存、在长批处理中被系统终止的语音服务器：每完成这么多段后，批处理中途会重新发出批处理之后及之前的请求（停止、启动、加载），之后工作将在一个全新的服务器上继续。0（默认值）表示从不这样做。服务器崩溃后无论此设置如何都会重新启动，参见[故障排除](audiobook-server.md#troubleshooting)。 |
| 批处理前后请求的密钥 | 批处理前后的请求以 `Authorization: Bearer` 形式携带的密钥。它以加密方式保存，之后不再显示（**移除密钥** 可将其清除），因此无需写入每个请求的请求头中（那样会被读取到）。留空：使用上面的 *Api 密钥*，当一个代理（例如 LiteLLM）为所有服务提供转发时，这正是你需要的。请求若自带 `Authorization` 请求头，则保留其自身的值。 |
| 旁白声音 | 没有角色表的书所用的旁白。服务器的声音文件写作 `predefined:Henry.wav`。 |
| 段落默认值 | 每段开始时使用的温度、CFG 权重、语速和分块大小（工作室可以为单独一段修改）。 |
| 批处理前、批处理后 | 围绕一批段落所发出的请求：*前* 释放显卡并启动语音服务器，*后* 将其停止。参见[一块 GPU 同时用于模型与语音](audiobook-server.md#one-gpu-for-the-model-and-the-speech)。留空则不做任何操作。 |

**测试连接** 执行的操作与一次批处理相同：先发出批处理前的请求（因此已停止的语音服务器会被启动），然后询问服务器是否在线并已加载模型，最后发出批处理后的请求。若没有任何请求设置，则只做询问。

若某本书包含其他文字系统的段落（英文书中的日文），并且你为其配置了多语言模型的后端，则这些段落会以其语言交由多语言模型处理；若没有配置，它们仍使用该书所用的模型。

<a id="shared-speech-servers"></a>

### 共享语音服务器

在多用户的安装中，管理员可以为所有人保留语音服务器，这样一台 GPU 机器只需设置一次，其他人无需填写地址或密钥。管理员在同一面板的最后几节（仅管理员可见）中操作：**共享语音服务器** 会打开一个窗口，其字段与你自己的后端相同，另外还可以指定谁能使用它：**所有用户**，或列表中选定的用户。该处还有一个开关 **用户可以添加自己的语音服务器**，用于决定下面的后端是否仍被允许使用。

你将获得以下内容：

- 面板顶部的 **正在使用的后端** 会列出你可以使用的共享服务器（标注 *（共享）*）以及你自己的服务器。*转换为音频* 窗口和工作室使用你所选的那一个；命令同样使用它。
- 你只能看到共享服务器的名称，永远看不到它的地址、密钥或请求内容。同一语音服务器地址上所有用户的批处理会相互等待，因此两个用户不会同时占用同一块 GPU。
- 当管理员将某个共享服务器从你这里收回时，仍指向它的任务会被拒绝；请改选其他服务器。
- 当管理员关闭你自己服务器的使用权限时，面板会给出提示。你添加的服务器会被保留，若开关重新打开，它们会再次被使用。
- 共享服务器的 *旁白声音* 应使用服务器的声音文件（`predefined:Henry.wav`）：参考音频属于某一个用户的资源，其他人无法读取。你的演员的声音照常可用。

<a id="actors"></a>

### 演员

**演员** 是你的一种声音：可以是一段参考音频（你的音频[资源](../resources.md)之一，或在此处新上传的一段），也可以是服务器的声音文件；并且可以为 **情绪**（耳语、呼喊）或 **语言**（一段说日语的音频）设置各自的声音。语言优先于情绪；若没有为它们设置声音，则由演员本身的声音朗读。你的演员保存在你的账户中；任何一本书都可以把演员分配给其旁白和角色。

声音旁边的 **预览**（在演员、设置和角色表中均有）会用该声音朗读一句简短的句子（若是语言声音，则使用该语言朗读），并播放出来；若批处理前的请求会启动语音服务器，则预览也会启动它。演员按名称列出。

![带有情绪声音的演员](../../images/plugin-audiobook-actor.png)

<a id="the-cast-and-the-pronunciation-of-a-book"></a>

## 有声书的声音演员与发音

两者都保存在书中（随书的备份一起保存），并可在 **Convert to audio** 对话框中编辑。

**Cast** 指定由谁朗读：**narrator**（旁白）一名演员，**other speakers**（其他说话者）一名演员（即模型给出、而演员表中没有对应角色的说话者；为空时由旁白朗读），以及每个 **character**（角色）各一名演员。角色有一个名字，以及文本中可能用来指代它的其他名字（例如 *Tom* 对应 *Tomáš Novák*），各名字之间用逗号分隔。当说话内容所属的名字、其他名字之一，或名字中某个不与其他角色共用的词，与角色匹配时（忽略大小写和重音符号），该段台词即归属于该角色。**Add the characters of the book** 会根据各部分的视角人物和出场人物，自动填充角色列表。

![有声书的声音演员表](../../images/plugin-audiobook-cast.png)

**Pronunciation** 指文本“用于语音”时的拼写方式；书的原文本身从不被改动。**dictionary**（词典）按整词替换（区分大小写），将其替换为朗读时应发出的读音：可用于为人名或自创词提供拼读替代，或为日语提供假名读法。对于英文书籍，规则还会将其他内容朗读为文字：数字、序数词、年份、时间、金额和缩写都会转为单词；仅由数字构成的标题会读作 *Chapter four. The Arch*（数字前的词由你自定）；Markdown 标记（如 `*`）会被省略；场景分隔符（`***`、`---`）不会被朗读，而是形成一个较长的停顿。若书是其他语言，请关闭这些规则；词典仍然生效。**Try a text** 可预览一段文本将被如何朗读。文本的朗读内容若有变化，则会重新生成该段，其他段落保持不变。

![有声书的发音设置](../../images/plugin-audiobook-pronunciation.png)

## 转换有声书

*故事编辑器的工具菜单（齿轮按钮）→ **Convert to audio***。

![开始前的对话框](../../images/plugin-audiobook-convert.png)

1. 选择 **backend**，然后按 **Load**：列出当前分支中有文本的各部分（第一部分为 1），并显示每一部分的状态：
   *Not generated*、*Labelled*（已保存模型的标注，尚无音频）、*Generated*（带播放按钮和下载）或
   *Generated (the text changed)*（音频是根据旧文本生成的，将重新生成）；工作室标记为定稿的部分会加上 *(final)*。
2. 若要使用普通版本，请保持 **Label the parts with a language model** 为关闭状态：旁白者会朗读每一段。开启后，模型会决定每段对白由谁说、以何种方式说（平静、耳语、大喊……）以及音效标签放在何处，角色表会分配声音。书籍所用的模型已被选定，你也可以换一个。各部分先进行标注，然后再朗读。如果某部分的文本已有标注，即使该选项关闭，也会按这些标注朗读（不会再询问模型），因此重新运行已标注的书籍而不开启该选项时，其对白不会变成普通旁白；**Remove labels** 用于要求改回普通旁白或重新标注。
3. 勾选各部分（标题栏中的复选框会全部勾选），然后用 **plan** 选择要执行的操作；**Plan** 列会显示该操作，但尚未执行任何内容：
   **Generate**（生成缺少的部分；已是最新的部分不会重新生成）、**Regenerate**（删除音频、移除标注，然后生成）、**Delete audio**（删除该部分的音频片段和合并后的音频；标注保留）、**Remove labels**（下次生成该部分时会重新询问模型）、**Clear the plan**。同一部分的多个步骤会叠加（不带 Generate 的 Delete audio 和 Remove labels 只做清理）；标记为定稿的部分会被排除在所有计划之外。
4. **Start** 执行计划。当计划要删除音频或标注时，程序会先询问。需要生成的内容会进入你的队列，关闭窗口或离开页面后队列仍会继续运行；正在等待或在队列中运行的部分不会被纳入计划。各部分的状态、已生成的片段和任务消息会显示在该部分的行上。
   模型为某部分标注时，该行会显示 *Labelling pieces 17-32 of 120*（模型每次处理 16 个片段）；**点击已标注部分的状态**，即可在结果陆续返回时查看模型每次请求的推理过程和回答。这些内容保存在内存中，与任务一同保留，直到清除已完成的任务（*Clear finished*）或应用重启为止。

![队列：已生成的片段，以及部分完成后的下载链接](../../images/plugin-audiobook-queue.png)

每个部分的制作过程如下，便于你了解预期结果：

- 文本由程序**切分**，而非由模型切分，分为旁白片段和直接对白片段（对白位于直引号、弯引号或日文方括号之间；标题属于旁白）。模型只负责为编号后的片段*标注*。只有当带有音效标签的文本仅仅是在原片段上添加了标签、其他内容未作任何改动时，才会使用该文本，因此模型永远无法改动你的书。
- **对白由谁说，由模型决定；旁白则由旁白者朗读。**信件、便条、消息或角色的内心独白没有引号，因此程序将其视为旁白。只有当这类片段**以斜体开头**（`*...*` 或 `_..._`），并且模型根据上下文（如署名、“笔迹一看便知”）指出是哪个角色时，该片段才会由角色（角色表中的声音）朗读。第三人称叙述即使是从某个角色的视角出发（“她看着珀西穿过房间”），也始终由旁白者朗读：对于模型为无斜体片段指定的角色，程序会忽略。用于强调、声音或外语词的斜体同样属于旁白。文字始终是你的原文。
- **模型的指令是可以修改的模板。***设置 → 扩展设置 → Audiobook Settings → Labelling prompt* 是你的默认指令；一本书（*Prompts* 标签页 → *Extension Settings* → *Audiobook*）或一个文件夹可以有自己的指令。留空则依次使用上一级文件夹的指令、你的默认指令，最后是内置指令。其写法与其他[提示词](../books/prompts.md)相同：变量有 `{{characters}}`、`{{deliveries}}`、`{{tags}}` 和 `{{wordsPerTag}}`，提示弹出框中有 **Insert Default Template**。修改指令后，待生成部分的标注会在下次生成时重新请求。
- **各部分的响度会被统一**，前提是安装了程序 ffmpeg（与生成 `.m4b` 所用的相同）：每个部分合并后的音频会被调整到同一响度（EBU R128，线性模式，因此动态范围保持不变），默认为 **-18 LUFS**，你可以在 *设置 → 扩展设置 → Audiobook Settings* 中修改，也可以在那里关闭此功能。各片段保持服务器生成时的原样，只调整合并后的部分音频，因此有声书在各部分之间不会出现音量跳变。**之前生成的部分**在你重新转换之前不会被改动：重新转换会从已保存的片段重新合并并统一响度，且不会向语音服务器发出任何请求（也不会卸载语言模型）。关闭响度统一后，已统一过的部分保持原样。若某部分的 ffmpeg 失败，该部分保留原有音频，并在结果中说明。
- 一次点击所涉及的所有部分，会按**语音模型**分批（每个模型一个批次）制作：批次前的请求只运行一次，然后朗读所有片段，最后运行批次后的请求。这样可以避免显卡在每个部分之间反复切换模型。
- 每个片段都**按内容保存**（文本、声音、模型、语言、设置、随机种子）。已是最新的部分不会产生任何开销，修改过的段落是唯一需要重新生成的片段；失败的部分在你按下 **Retry** 时会保留已生成的片段。
- 片段按其所在位置使用不同的停顿（标题之后、段落之间、*他说*之前）拼接成每个部分一个 mp3 文件，并与该部分保存在一起。
- 你的生成任务运行期间，语音会排队等待，因此语言模型不会在其中途被卸载。
- 你在工作室中标记为**定稿**的部分不会被改动，对话框会显示被跳过的数量。
- **整本有声书**会把每个已有最新音频的部分合并为一个 mp3，每个部分对应一个章节标记，并在列表下方显示下载链接（未包含的部分会被列出）。同一文件也是导出格式 *one mp3 with chapter marks*。
- **Stop all** 会立即取消等待中的部分，并中止正在运行的部分：对语言模型（标注）或语音服务器（正在朗读的片段）的请求会被直接丢弃，而不是等待其完成。在开始前就被停止的批次不会发送其之前的请求，因此语言模型保持加载状态。**Download** 可下载已完成部分的 mp3。
<a id="the-audiobook-studio"></a>

## 录音工作室

*工具菜单 → **有声书工作室*** (所选片段的语音及其预览位于其说话人旁边) 是最终有声书逐部分制作的地方：你可以看到脚本，修改它，试听一个片段并制作该部分。

![选中一段语音的工作室](../../images/plugin-audiobook-studio.png)

- 在标注或制作某部分期间，会有一个提示条显示正在进行某项工作，而会启动更多工作的按钮则会等待。
- **标注** 会生成该部分的脚本 (如果你要求，则使用语言模型；否则使用旁白者)，并以表格形式显示各片段：说话人、演绎方式、强度、朗读文本，以及已修改片段的标记。运行期间，其旁边会出现一个 **停止** 按钮，用于结束对语言模型的请求。
- 选择一个片段以编辑其 **说话人**、**朗读文本**、**演绎方式**、**强度** (声音的夸张程度，适用于具备该参数的模型)、**语言**、**种子**、其 **之后停顿**。**应用** 会保留修改并 **锁定** 该片段：新的标注会保留已锁定的片段不变。**解锁** 则将其交还给标注。*语音服务器收到的请求* 会显示确切的请求内容。
- **试听** 会生成某个片段的音频 (仅该片段；会为其启动语音服务器)；**另一版本** 会用新的种子重新生成，并且 **版本** 会被保留，以便你选择喜欢的那一个 (*使用此版本并试听*)。好的声音往往取决于种子。
- **根据此脚本制作该部分** 会按原样拼接各片段，不进行新的标注。
- 部分的 **状态** 为 *草稿*、*已审阅* 或 *定稿*。定稿的部分不会被再次标注或转换，并且导出可以限定为仅导出定稿的部分。

<a id="exporting"></a>

## 导出

有声书是书籍 *导出故事* 中的一种格式：**有声书 (每章一个 mp3，打包为 zip)**、**有声书 (一个带章节标记的 mp3)**，以及在安装了 ffmpeg 时的 **有声书 (一个带章节的 m4b)**。它们由那些保持最新的部分的音频制成：没有音频的部分，或音频早于其文本或工作室中脚本的部分，会被排除，窗口会说明原因。mp3 文件带有 ID3 标签 (书名、章节、音轨)，单个文件带有章节标记，VLC 及大多数有声书应用都能显示；zip 包含一个播放列表。复选框 **有声书：仅限标记为定稿的部分** 会将导出限制为你在工作室中完成的部分。

**m4b** 是 Apple Books 及大多数手机有声书应用所需的格式：AAC 音频 (64 kbit/s，对语音已足够)，封装在带有章节、书名、作者和类型的 MP4 容器中。它由 ffmpeg 生成，因此该格式仅在安装了 ffmpeg 的服务器上提供。以 mp3 存储的音频会为此再次编码；以 wav 存储的音频只编码一次。

<a id="how-the-audio-is-stored"></a>

### 音频的存储方式

管理员在 *设置 → 扩展设置 → 有声书设置* (最后一节，仅管理员可见) 中为整个安装选择存储方式：

- **mp3** (默认)：体积小，无需解码器即可拼接，不需要 ffmpeg。m4b 则是第二次有损编码。
- **wav**：无损，体积约为十倍 (一小时的语音约 170 MB)，需要 ffmpeg。各片段以 wav 格式从语音服务器请求，并以 wav 拼接；浏览器按原样播放；mp3 和 zip 导出由 ffmpeg 编码 (96 kbit/s)，m4b 只编码一次。

该选择适用于从此之后制作的内容。之前制作的部分保留其音频，并按原样理解；两种类型混合的部分 (之前工作室中锁定的片段) 会以 wav 拼接，两种类型部分的导出可以进行，但需要 ffmpeg。

![带有有声书格式的导出对话框](../../images/plugin-audiobook-export.png)

<a id="automatic-conversion"></a>

## 自动转换

一本书可以在某部分定稿后自动为新部分生成音频：在自动标注、重写 (如果书籍有该功能) 和翻译之后，作为 [部分之后的流程](../books/story-editor.md#what-follows-a-generated-part) 的最后一步 (在运行面板中，直到音频生成为止；其 **停止** 会将该部分移出队列)。默认 **关闭**。可在书籍的 *提示* 选项卡的扩展设置中选择，也可为一个文件夹中的书籍选择，或在有声书设置中为你的所有书籍选择；以最近的设置为准：

- **否**，
- **是：由旁白者朗读该部分**，
- **是：由书籍的模型标注，角色表提供声音**；没有模型的书籍使用普通旁白，并会向你说明。

![书籍中的设置](../../images/plugin-audiobook-auto.png)

该部分进入你的队列，并带有书籍的角色表和发音。一条通知会告诉你它已排队，另一条会告诉你其音频已就绪或失败；它们仅在启动生成的页面中显示，无论如何，任务都在 *转换为音频* 窗口中。

<a id="listening"></a>

## 收听

已发布的书籍 (或阅读器) 中，若有带音频的部分，会显示播放条：播放、暂停、停止、速度，以及正在朗读的部分在文本中的标记。它从所选内容或当前可见的第一个部分开始，按顺序播放各部分，并在当前部分播放时预先获取下一部分；设备的媒体控制器可识别该书。由旧版文本生成的部分音频不会提供。音频提供给书籍所有者，并且在书籍发布期间，提供给所有能打开它的人；一本被撤回发布的书会立即停止提供 (在下一部分时播放器重新加载)。

![阅读器中的播放器](../../images/plugin-audiobook-player.png)

<a id="a-part-without-audio"></a>

### 没有音频的部分

播放器会在没有音频的部分处停止，以免跳过故事的某部分，并会说明这一点。若安装了扩展 [朗读](tts-reader.md)，播放条还会显示一个扬声器按钮 **用浏览器的声音朗读此部分 (以及之后没有音频的部分)**。除非你按下它，否则不会用机器声音朗读任何内容。随后它会用你设备的声音朗读该部分以及之后没有音频的各部分；当遇到带有音频的部分时，播放器会重新接管。在同一次收听中，之后没有音频的部分会以同样的方式朗读，无需再次询问；**停止** 会将其静音，重新开始播放器时会再次询问。声音、速度和音调与朗读扩展相同。

<a id="commands"></a>

## 命令

与 [命令](../commands/index.md) 中的内容相同 (故事编辑器的命令行、模板的 `command` 宏、智能体)。各部分按转换对话框中的编号编号，或以其句柄命名。

| 命令 | 作用 |
|---|---|
| `/audiobook-status [from [to]]` | 正在使用的语音服务器，书籍如何自动转换，有多少部分有音频 (无、就绪、早于文本、早于脚本)，列出的每个部分在工作室中的状态，以及队列。仅在书籍很长时较慢。 |
| `/audiobook-convert [from [to [labelling [what [wait]]]]]` | 将各部分放入队列 (无参数时为整本书，只给出 `from` 时为一个部分)。`labelling` 为 `true` 时使用书籍的模型；`what` 为 `audio` 或 `script` (仅为工作室生成脚本，不进行朗读)。`wait` 为 `true` 时，命令会一直等待直到任务结束，显示进度并说明各任务如何结束；停止它会取消尚未开始的任务。 |
| `/audiobook-stop` | 取消等待中的部分；正在运行的部分会在其片段结束后停止。 |
| `/audiobook-set-part-status part status` | 在工作室中设置为 `draft`、`reviewed` 或 `final`；该部分需要有脚本。 |
| `/audiobook-cast` | 旁白者、备用声音，以及角色表及其配音演员。 |

![命令的结果](../../images/plugin-audiobook-command.png)

音频是为**你的**书制作的，而不是为 [智能体](../agents.md) 的隐藏工作副本制作的：智能体可以读取角色表，但其他命令会被拒绝，并提示你必须自行运行它们。可从命令行运行这些命令，或将准备书籍的任务 (标注、审阅) 交给智能体，然后由你自己进行转换。
<a id="notifications"></a>

## 通知

批量转换结束后，浏览器可以提醒你（[通知](../account.md#notifications)，这样你可以在语音服务器工作时离开此标签页）。在*设置*页面的通知列表中有两行：**转换为音频**（你在对话框中或通过命令启动的批量任务）和 **转换为音频（自动）**（由系统自动转换为音频的新片段）。你中途停止的批量任务不会发出通知；如果批量任务中有片段失败，通知会说明该任务失败。

![通知列表](../../images/plugin-audiobook-notifications.png)

<a id="what-it-does-not-do-yet"></a>

## 目前不支持的功能

- 仅支持 mp3 和 wav（不支持 opus）；片段的响度取决于声音本身。
- 没有音效或环境音。
- 仅有一个语音引擎 Chatterbox，其他引擎是下一步计划。
- 不能在片段之外试听声音。
- 角色表不属于书籍的*演员*备份内容：恢复的书籍会保留其角色表，但其中指定的演员必须已存在于你的账户中。
