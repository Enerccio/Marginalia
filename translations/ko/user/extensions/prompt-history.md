# 프롬프트 기록

모델에 실제로 전송된 내용과 모델의 응답을 보여줍니다. 플러그인을 디버깅하거나, 일반 생성 이외의 작업에서 프롬프트에 무엇이 들어갔는지 확인할 때 사용합니다.

<a id="how-it-works"></a>

## 작동 방식

이 확장 기능은 현재 세션에서 모델에 보낸 마지막 **20개의 요청**을 저장합니다. 저장되는 내용은 전송된 메시지, 모델의 응답, 그리고 모델의 추론(제공자가 전달하는 경우)입니다. 생성 요청을 포함해 모든 종류의 요청이 저장됩니다. *설정 → 확장 기능 설정*에 **Prompt history** 패널이 추가되며, **Show prompt history** 버튼을 누르면 가장 최근 요청이 맨 위에 오는 목록이 열립니다. 목록에는 다음 정보가 표시됩니다.

- 요청의 **날짜**
- **모델**: AI의 이름과 모델 ID
- **요청 유형**: `generation`(새 부분, 스와이프, 재생성), `annotate`, `summary`, `impersonate`, `redraft`, `agent`, `help`, 또는 확장 기능이 정의한 작업의 이름
- 상태(실행 중, 완료, 취소, 실패)와 소요 시간

목록에서 요청을 선택하면 목록 아래의 탭에서 내용을 읽을 수 있습니다. **Request** 탭에는 역할별로 구분된 각 메시지가, **추론** 탭에는 모델의 추론이, **Response** 탭에는 응답, 모델이 호출한 함수, 실패한 요청의 오류가 표시됩니다. **새로 고침**을 누르면 목록을 다시 불러오고, **지우기**를 누르면 목록이 비워집니다. 요청은 전송되는 순간 목록에 추가되며, 실행 중에는 모델이 작성하는 대로 응답과 추론이 대화 상자에서 계속 늘어납니다.

![요청 기록](../../images/plugin-prompt-history.png)

[에이전트](../agents.md)의 경우, 콘솔 하단에 있는 **Prompt history** 버튼을 누르면 해당 실행의 요청 목록이 같은 방식으로 열립니다.

<a id="notes"></a>

## 참고 사항

- 기록은 메모리에만 보관되며, 공간을 적게 차지하도록 압축됩니다. 로그아웃하거나 서버를 재시작하면 사라지며, 백업에도 포함되지 않습니다.
- 브라우저 세션마다 고유한 목록이 있습니다. 에이전트의 요청은 이 목록에 포함되지 않습니다. 에이전트의 요청은 실행별로 저장되며(실행당 20개, 최근 10번의 실행), 해당 실행의 콘솔에서 확인할 수 있습니다.
- 메시지는 스토리 본문을 포함해 전체가 표시됩니다.
