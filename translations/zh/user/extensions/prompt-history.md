# 提示历史

显示真正发送给模型的内容以及模型的回复，用于调试插件，或查看除常规生成以外任何请求的提示词。

<a id="how-it-works"></a>

## 工作原理

该扩展会在您的会话中保留发送给模型的最近 **20 个请求**：已发送的消息、模型的回复以及推理过程（如果服务商返回了推理内容）。所有类型的请求都会保留，包括常规生成。它会在 *Settings → Extension Settings* 中添加面板 **Prompt history**；点击按钮 **Show prompt history** 即可打开列表，最新的请求排在最前，列表包含以下信息：

- 请求的**日期**，
- **模型**：AI 的名称和模型 ID，
- **请求类型**：`generation`（新的段落、滑动切换或重新生成）、`annotate`、`summary`、`impersonate`、`redraft`、`agent`、`help`，或扩展自定义工作类型的名称，
- 状态（运行中、已完成、已取消、失败）以及耗时。

在列表下方的标签页中选择一个请求即可查看详情：**Request**（按角色列出每条消息）、**Reasoning** 和 **Response**（回复、模型调用的函数，以及失败请求的错误）。**Refresh** 用于重新加载列表，**Clear** 用于清空列表。请求在发送时就会出现在列表中：运行期间，随着模型逐步生成，对话框中的回复和推理内容也会不断增长。

![请求历史](../../images/plugin-prompt-history.png)

对于[智能体](../agents.md)，其控制台底部有按钮 **Prompt history**：点击后会打开同样的列表，其中显示该次运行的请求。

<a id="notes"></a>

## 注意事项

- 历史记录仅保存在内存中，并经过压缩以减少占用空间。注销或服务器重启后将被清除，且不包含在备份中。
- 每个浏览器会话都有自己的列表。智能体的请求不在其中：它们按运行次数分别保存（每次运行保留 20 个，最多保留最近 10 次运行），并在该次运行的控制台中显示。
- 消息会完整显示，包括故事正文。
