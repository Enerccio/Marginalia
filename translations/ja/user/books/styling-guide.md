# スタイルガイド：本を自分の本らしく見せる

**テキストスタイル**は、パーツの文章の見え方を決めます。フォント、色、本文の幅、見出し、場面どうしの区切り線などです。このガイドでは、最初の変更から完成した見た目までを順に説明します。最後には、ダウンロードできる完全な例を示します。ホラー小説のためのスタイルで、すべてのオプションと独自の CSS を使っています。

どこでスタイルが使われるかは、次の表のとおりです。

| 場所 | 何が起きるか |
|---|---|
| **ストーリーエディター** | 本のスタイル（またはデフォルト）が、すべてのパーツの見た目になります。[テキストスタイル](story-editor.md#text-styles)を参照してください。 |
| **リーダー** | [公開された本](publishing.md)は、*読者*が自分のスタイルから選んだスタイルで読まれます（選ぶまではブックスタイル）。 |
| **エクスポート** | **For exports** を付けたスタイルは、[エクスポートダイアログ](export.md#print-styles)で選びます。HTML と EPUB はスタイルシートを使い、PDF と Word は数値を使います（[各エクスポートが使う項目](#what-the-exports-take)を参照）。 |

<a id="make-your-first-style"></a>

## 最初のスタイルを作る

1. **設定 → スタイル**を開きます（[スタイルタブ](../account.md#styles)）。
2. リストで **ブック** を選び、**複製** を押します。組み込みのスタイルは変更できないので、作業は必ず *ブック (copy)* という名前のコピーから始まります。名前を付けてください。
3. **オプション** タブでいくつかの項目を変更します。フォームの下にある **プレビュー** に見本の文章（章のタイトル、強調、引用、場面転換、小さめの見出し）が表示され、入力するたびに変化を反映します。
4. 設定の **保存** を押します。それまでは何も保存されず、**変更を破棄** で作業を捨てられます。
5. ストーリーエディターで設定メニュー（⚙）→ **表示** → **テキストのスタイルを変更** を開き、自分のスタイルにチェックを入れます。これは本ごとに保存されます。すべての本で使うには、リストでそのスタイルを選んで **デフォルトにする** を押します。

![物語のメニューにあるスタイル](../../images/story-style-menu.png)

空欄の項目はアプリケーションの見た目のままになるので、スタイルには変えたい部分だけを書けば十分です。すべての項目が空のスタイルは、素のままの見た目になります。

<a id="the-options"></a>

## オプション

どの欄にも CSS の値を入力します。よく使う単位は、`rem`（ページの文字の大きさ。1rem は通常 16px）、`em`（現在の文字の大きさ）、`px`、`%` です。色は `#336699`、`rgb(51, 102, 153)`、`ivory` のような名前で指定できます。

<a id="text"></a>

### テキスト

| オプション | 働き | 例 |
|---|---|---|
| **Font family** | 文字のフォント。候補を並べると、コンピューターにある最初のフォントが使われます。最後には総称ファミリー（`serif`、`sans-serif`、`monospace`）を置くとよいでしょう。 | `"Garamond", "Georgia", serif` |
| **フォントサイズ** | 文字の大きさ。 | `1.1rem` |
| **行の高さ** | 行どうしの間隔。単位なしの数値はフォントサイズの倍率になります。 | `1.7` |
| **文字間隔**、**単語の間隔** | 文字どうし、単語どうしの余白。小さな値で十分です。わずかな文字間隔で文章が軽やかに見えます。 | `0.01em`、`0.05em` |
| **文字色** | 文字の色。 | `#cfc6bb` |
| **Text align** | `left`、`right`、`center`、`justify` のいずれか。 | `justify` |
| **Hyphenation** | 行末で長い単語を分割します。本の[言語](managing-books.md#the-about-tab)の辞書を使うので、先に言語を設定してください。*justify* と組み合わせると効果的です。 | オン |
| **Paragraph spacing** | 段落の下の余白。本は通常、余白を小さくするか、字下げをする場合はなしにします。 | `0.3em` |
| **1行目のインデント** | 段落の1行目を字下げします。印刷された本と同じ方式です。ただし見出しや場面転換の直後は除きます。 | `1.5em` |
| **Drop cap** | 見出しの後に続く最初の段落の先頭文字を大きくします。 | オン |

<a id="page"></a>

### ページ

| オプション | 働き | 例 |
|---|---|---|
| **テキストの幅** | 独自の幅の段組みを中央に配置します。1行あたり60〜75文字が最も読みやすく、目安は `34em` から `40em` です。 | `38em` |
| **背景色** | 文字の後ろの色。文字のブロックだけでなく、領域全体を塗ります。背景の上で読みやすい文字色を選んでください。 | `#0c0a0a` |

<a id="emphasis-links-and-code"></a>

### 強調、リンク、コード

| オプション | 働き |
|---|---|
| **Emphasis color** | *斜体*の文字の色。 |
| **Strong color** | **太字**の文字の色。 |
| **リンクの色** | リンクの色。 |
| **Code font family** | `code` とコードブロックのフォント。 |

<a id="quotes"></a>

### 引用

| オプション | 働き |
|---|---|
| **Quote color** | 引用（`> 一行`）の文字の色。 |
| **Quote border color** | 引用の横にある線の色。 |

<a id="headings"></a>

### 見出し

| オプション | 働き |
|---|---|
| **Heading font family** | `#`、`##`、`###` の見出しのフォント。 |
| **Heading size** | 第1レベルの大きさ。下のレベルは比率に応じて小さくなります。 |
| **見出しの色** | 見出しの色。 |
| **Heading align** | `left`、`center`、`right` のいずれか。 |
| **Heading small caps** | 見出しをスモールキャピタルで組みます。 |

<a id="scene-break"></a>

### 場面転換

本文の中で `---` だけの行は、場面どうしの区切りになります。初期設定では3つの点が表示されます。**Scene break text** には代わりに表示する文字（`* * *`、`~`、`† † †`）を入力し、**場面転換の色** にはその色を指定します。

<a id="custom-css"></a>

## カスタム CSS

オプションでは、よくある変更をまかなえます。それ以外の変更には、**カスタム CSS** タブで自分の CSS を書きます。書かれた CSS はすべての設定の後に追加され、そのスタイルの中だけに適用されます。書き方は2通りです。

- **単純な宣言**は、文章を囲む領域全体に適用されます。

  ```css
  box-shadow: inset 0 0 120px rgba(0, 0, 0, 0.8);
  ```

- **セレクターを含むルール**は、前に `&`（スタイルの領域）を付けても、付けなくても書けます。どちらの場合も、このスタイルの文章にだけ届きます。

  ```css
  & .chat-message-markdown h1 { text-shadow: 0 0 12px #8e1b17; }
  & .chat-message-markdown a:hover { color: #b3261e; }
  ```

パーツの文章は `chat-message-markdown` というクラスを持つ要素の中にあるので、文章の中の要素を指定するセレクターはそこから始まります。CSS 欄の下にある **生成された CSS** 欄には、オプションから作られるスタイルシートが表示されます。そのセレクターを見れば、何を上書きできるかがわかります。

| 変更したいもの | セレクター（`& .chat-message-markdown` の後ろ） |
|---|---|
| 段落 | `p` |
| 見出し | `h1`、`h2`、`h3` |
| 斜体、太字 | `em`、`strong` |
| リンク | `a`、`a:hover` |
| 引用 | `blockquote` |
| リスト | `ul`、`ol`、`li` |
| コード | `code`（行内）、`pre`（ブロック） |
| 場面転換 | `hr`、`hr::after`（記号） |
| 段落の1行目 | `p::first-line` |
| 選択したテキスト | `::selection` |

知っておいてほしいことは次のとおりです。

- **波かっこ `{ }` は対応している必要があります**。対応していないと、保存時にスタイルが受け付けられません。コメント `/* ... */` は使えます。
- アプリケーションが必要とするいくつかのルールには `!important` が付いています（文章が領域より広がらないこと、長い単語が折り返されること、段落の改行が保たれること）。自分の CSS でこれらを上書きすることはできません。それ以外のものはすべて上書きできます。自分の CSS が最後に来るためです。
- CSS で変えられるのは見た目であり、文章の内容ではありません。文章の周りのツールバーやタブには影響しません。
- カスタム CSS は、ストーリー、リーダー、HTML エクスポートで使われます。EPUB、PDF、Word では使われません。

<a id="what-the-exports-take"></a>

## 各エクスポートが使う項目

エクスポート用のスタイルは[エクスポートダイアログ](export.md#print-styles)で選びます。スタイルを **複製** し、**For exports** にチェックを入れるか、アプリケーションに付属する4つのスタイルのいずれかから始めてください。アプリケーションのテーマに依存する色（ダークテーマの明るい文字など）は、エクスポートの際に白いページ向けの暗い色になります。

| | HTML | EPUB | PDF | Word |
|---|---|---|---|---|
| フォント、大きさ、行の高さ、間隔、配置、1行目のインデント | ✓ | ✓ | ✓ | ✓ |
| 文字、強調、太字、引用、見出し、場面転換の色 | ✓ | ✓ | ✓ | ✓ |
| 背景色 | ✓ | ✓ | ✓ | ✓（ページの色） |
| テキストの幅、ドロップキャップ、ハイフネーション、見出しのスモールキャピタル | ✓ | ✓ | | |
| カスタム CSS | ✓ | | | |

電子書籍リーダーは、スタイルシートの指定に関係なく、独自のフォント、大きさ、色を使うことがよくあります。PDF と Word は、その形式が持つフォントしか使えません。PDF では、書いたフォントの候補から明朝体、ゴシック体、等幅体のいずれかが選ばれます。Word では、候補の最初のフォント名が指定され、コンピューターにそのフォントがなければ Word 自身の代わりのフォントが表示されます。
<a id="share-a-style-export-and-import"></a>

## スタイルの共有: エクスポートとインポート

スタイルの一覧の下にある **エクスポート** は、選択したスタイルをファイル（`name.style.json`）として保存します。組み込みのスタイルもエクスポートできます。**インポート** はそのようなファイルを読み込みます。インポートしたスタイルは、あなたのスタイルに新しいスタイルとして追加されます。**保存** を押すまでは保存されず、名前もそのまま残るため、同じ名前のスタイルが既にある場合は名前を変更してください。

ファイルは JSON 形式です:

```json
{
  "format": "marginalia-text-style",
  "version": 1,
  "styles": [
    {
      "name": "My style",
      "forExport": false,
      "options": { "FONT_SIZE": "1.1rem", "TEXT_COLOR": "#222222" },
      "customCss": "& .chat-message-markdown h1 { letter-spacing: 0.1em; }"
    }
  ]
}
```

複数のスタイルを含めることもできますし、手で書くこともできます。オプションは大文字の名前で指定します（`FONT_SIZE`、`TEXT_COLOR`、`SCENE_BREAK_TEXT` など）。すべてのオプションは[ホラーの例](#an-example-a-horror-book)に含まれています。このバージョンの Marginalia が知らないオプションは除外され（その数が通知されます）、新しい形式バージョンのファイルは拒否されます。カスタム CSS の波括弧が対応していないスタイルも同様に拒否されます。

<a id="an-example-a-horror-book"></a>

## 例: ホラー小説

[ホラー用スタイルをダウンロード](../../files/horror-book.style.json)（`horror-book.style.json`）し、*設定 → スタイル* でインポートして選択すると、プレビューで確認できます。このスタイルは**すべてのオプション**を設定し、オプションで対応できない部分にはカスタム CSS を使っています:

| | |
|---|---|
| **ページ** | ほぼ黒の背景 `#0c0a0a`、幅 `38em` の段組み、端に向かって暗くなるビネット（カスタム CSS）。 |
| **テキスト** | Garamond・`1.12rem`、行の高さ `1.8`、ハイフネーション付きの両端揃え、段落の最初の行は `1.6em` の字下げ、段落間の余白はほぼなし。印刷された小説のような体裁です。本文は古い紙のような灰色 `#cfc6bb`、各見出しの後にドロップキャップが付きます。 |
| **強調** | 斜体はくすんだバラ色 `#b99a94`、太字は血のような赤 `#b3261e`。 |
| **リンク** | 不健康な緑 `#8fa07e`。ポインターが乗ると赤く波線になります（カスタム CSS）。 |
| **引用** | 灰色の文字、濃い赤の罫線 `#5c1010`、背後にうっすらと赤い染み（カスタム CSS）。 |
| **見出し** | Palatino のスモールキャピタル、中央揃え、濃い赤 `#8e1b17`、うっすらとした光彩（カスタム CSS）。 |
| **場面転換** | 濃い赤の `† † †`。リストの点の代わりに十字が付きます（カスタム CSS）。 |
| **コード** | Courier New、ほぼ黒の背景。 |

![ホラー調のスタイルで表示した物語](../../images/story-style-horror.png)

実際の文章で試すには、パート内に次の文章を貼り付けてください（またはプレビューに似た見本が表示されます）:

```markdown
# 第一章: ハロー通りの家

三日間、雨が降り続いていた。マラがその扉を見つけたのは、そのときだった。家の見取り図には載っておらず、触れるとそれは**温かかった**。

> 夜になったら開けてはならない。 — 漆喰に引っかいて書かれている。彼女の字ではない

彼女は階段を下りながら段を数えた。十三段。下には次のものがあった:

- まだ灯っているランタン。
- 壁の方を向いて置かれた椅子。
- 埃の上に書かれた自分の名前。

---

朝になるとランタンは消えていて、[家の記録](https://example.com)には、四十年間誰も住んでいないと書かれていた。
```

次に文章を変えてみてください。背景を `#14100c`（ろうそくの灯りの茶色）にする、**テキストの幅** を `32em` にしてページを細くする、あるいはカスタム CSS を削除してオプションだけの効果を確かめる、などです。気に入った見た目になったら **エクスポート** して、ファイルを本と一緒に保管してください。
