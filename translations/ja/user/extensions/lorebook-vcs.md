# Lorebook VCS

[ロアブックエントリー](../lorebooks/entries.md)の改訂履歴です。過去の設定を保存しておき、切り替えて使えます。たとえば、戦争の前後の世界の状態や、物語の異なる時点でのキャラクターの状態を管理できます。

!!!
Lorebook VCS は[スマートフォン向けレイアウト](../phone.md#extensions)でも使えます。パネルはロアブックの **有効** の行の下にあり、エントリーの改訂はフォームの上部にあります。
!!!

!!!
[全画面エディター](../lorebooks/lorebooks.md#editing-in-full-screen)では、**Lorebook Revisions** の行がエントリーの一覧の上にあり、エントリーのタブの名前の行の下に改訂バーがあります。改訂を切り替えると、タブ内にすぐ反映されます。
!!!

改訂とは、エントリー全体のスナップショットです。名前、内容、メモ、有効、順序、フィルターとフィルタリングモード、挿入モード、**内容を他のエントリーのフィルターの検索対象にしない**、タグ、ネガティブタグが含まれます。(このフラグが導入される前に作られた改訂では、オフとして扱われます。)

<a id="entry-revisions"></a>

## エントリーの改訂

拡張機能をインストールすると、ロアブックエントリーの詳細(⌄)の先頭に改訂バーが表示されます。

```
Revision: 2 / 3            [−]  [‹]  [Rev 2 (2026-10-08 14:30:12) ▾]  [›]  [+]
Modified: 2026-10-08 14:30:12
```

改訂はスロットのように機能します。エントリーには常にいずれか一つの改訂が表示されており、それを**現在の改訂**と呼びます。エントリーに加えた変更は、その現在の改訂に保存されます。生成はエントリーの現在の状態を使うため、モデルが参照するのは現在の改訂です。

| コントロール | |
|---|---|
| **+** | エントリーの現在の状態を新しい改訂として保存し、それを現在の改訂にします。 |
| **‹** / **›**、または一覧 | 前の改訂 / 次の改訂 / 選んだ改訂に切り替えます。離れた改訂には編集内容が残り、もう一方の改訂がエントリーに読み込まれます。 |
| **−** | 現在の改訂を削除し、前の改訂に切り替えます。最後に残った改訂は削除できません。 |
| *n / total*、*Modified* | 現在の改訂の番号と、最後に変更された日時です。 |

エントリーの詳細を初めて開くと、そのエントリーの現在の状態が改訂 1 になります。

典型的な使い方は次のとおりです。

1. キャラクターのエントリーを開き、**+** をクリックします。改訂 2 は改訂 1 のコピーになります。
2. 改訂 2 を、第 10 章の出来事の後のキャラクターに書き換えます。
3. 執筆します。第 5 章を編集し直すときは、**‹** で改訂 1 に切り替えます。後で **›** を使えば元の改訂に戻れます。

<a id="lorebook-revisions"></a>

## ロアブックの改訂

ロアブックのエディターには、ボタンが二つ並んだ **Lorebook Revisions** の行があります。これらのボタンは、エディターで選択中のロアブックに対して動作します。

| ボタン | |
|---|---|
| export | ロアブックの全エントリーの履歴を `<lorebook>_vcs_history.json` としてダウンロードします。 |
| import | **Import Marginalia VCS JSON** - この拡張機能でエクスポートした履歴です。**Import SillyTavern VCS Extension JSON** - SillyTavern のロアブック版履歴拡張機能の履歴です。 |

インポートするとロアブックの履歴が**置き換え**られます。ロアブックにすでに履歴がある場合や、ファイルが別のロアブックからエクスポートされたものである場合は、先に確認を求められます。

Marginalia の履歴は、まずエントリー自体を手がかりにしてエントリーと対応付けられます。対応するエントリーが見つからない場合、たとえば履歴が別のコピーのロアブックから来た場合は、現在の改訂の名前と順序で対応付けられます。名前を持つエントリーが一つしかない場合は、名前だけで対応付けられます。どのエントリーとも対応しない履歴はスキップされ、その件数が確認画面に表示されます。

SillyTavern の履歴は、ロアブック内での位置によってエントリーと対応付けられます。そのため、エントリーを追加または削除する前に、[同じワールドインフォから取り込んだ](../lorebooks/import-export.md#importing-sillytavern-world-info)ロアブックにインポートしてください。その改訂のトリガーキーは、[ワールドインフォのインポート](../lorebooks/import-export.md#importing-sillytavern-world-info)と同じ方法で、エントリーのフィルターに変換されます。

<a id="storage"></a>

## 保存

履歴はロアブックと一緒にデータベースに保存されるため、[データベースのバックアップ](../administration/database-backups.md)にも含まれます。拡張機能がロアブックに保存したデータは、[ロアブックのエクスポート](../lorebooks/import-export.md#exporting)、[ブックのバックアップ](../books/backups.md)内のロアブック、および[エージェント](../agents.md)が作業するロアブックのコピーにも書き出されます。ただし、ロアブックをインポートすると新しいエントリーが作成されます。履歴は古いエントリーの識別情報に紐づいているため、インポートされたエントリーには表示されません。履歴をインポートしたコピーに移すには、元のロアブックから履歴をエクスポートし、コピーにインポートしてください。その場合、エントリーは名前と順序で対応付けられます([ロアブックの改訂](#lorebook-revisions)を参照)。
