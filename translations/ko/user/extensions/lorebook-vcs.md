# 로어북 VCS

[로어북 항목](../lorebooks/entries.md)의 리비전 이력입니다. 설정의 이전 버전을 보관하고 그 사이를 전환할 수 있습니다. 예를 들어 전쟁 전후의 세계 상태나, 이야기의 여러 시점에서의 캐릭터 모습을 따로 저장해 둘 수 있습니다.

!!!
로어북 VCS는 [휴대폰 레이아웃](../phone.md#extensions)에서도 작동합니다. 패널은 로어북의 *사용* 행 아래에 있고, 항목의 리비전은 항목 양식의 맨 위에 있습니다.
!!!

!!!
[전체 화면 편집기](../lorebooks/lorebooks.md#editing-in-full-screen)에서는 항목 목록 위에 **Lorebook Revisions** 행이 있고, 항목의 리비전 막대는 탭의 이름 행 아래에 있습니다. 리비전을 전환하면 탭에 바로 표시됩니다.
!!!

리비전은 항목 전체의 스냅샷입니다. 이름, 내용, 메모, 사용, 순서, 필터와 필터링 방식, 삽입 방식, *이 항목의 내용에서 다른 항목을 검색하지 않음*, 태그와 네거티브 태그가 모두 포함됩니다. (이 플래그가 생기기 전에 만든 리비전은 꺼짐으로 읽힙니다.)

<a id="entry-revisions"></a>

## 항목 리비전

확장 기능을 설치하면 로어북 항목의 상세 정보(⌄)가 리비전 막대로 시작합니다.

```
Revision: 2 / 3            [−]  [‹]  [Rev 2 (2026-10-08 14:30:12) ▾]  [›]  [+]
Modified: 2026-10-08 14:30:12
```

리비전은 슬롯처럼 작동합니다. 항목에는 항상 리비전 하나가 표시되며, 이를 **현재 리비전**이라고 합니다. 항목에서 바꾸는 내용은 그 현재 리비전에 저장됩니다. 생성은 항목을 있는 그대로 사용하므로, 모델이 보는 것도 현재 리비전입니다.

| 컨트롤 | |
|---|---|
| **+** | 항목을 지금 상태 그대로 새 리비전으로 저장하고 이를 현재 리비전으로 만듭니다. |
| **‹** / **›**, 또는 목록 | 이전 / 다음 / 선택한 리비전으로 전환합니다. 편집한 내용은 떠나는 리비전에 그대로 남고, 다른 리비전이 항목에 불러와집니다. |
| **−** | 현재 리비전을 삭제하고 이전 리비전으로 전환합니다. 마지막으로 남은 리비전은 삭제할 수 없습니다. |
| *n / total*, *Modified* | 어느 리비전이 현재인지, 그리고 마지막으로 변경된 시점. |

항목의 상세 정보를 처음 열면, 그 항목의 현재 상태가 리비전 1이 됩니다.

일반적인 사용 예는 다음과 같습니다.

1. 캐릭터의 항목을 열고 **+**를 클릭합니다. 리비전 2는 리비전 1의 복사본입니다.
2. 리비전 2를 10장의 사건 이후의 캐릭터 모습으로 바꿉니다.
3. 집필합니다. 5장을 고치려고 돌아가면 **‹**로 리비전 1로 전환하고, 나중에 **›**로 다시 전환합니다.

<a id="lorebook-revisions"></a>

## 로어북 리비전

로어북 편집기에는 버튼 두 개가 있는 **Lorebook Revisions** 행이 추가됩니다. 이 버튼들은 편집기에서 선택한 로어북에 대해 작동합니다.

| 버튼 | |
|---|---|
| 내보내기 | 로어북의 모든 항목의 이력을 `<lorebook>_vcs_history.json`으로 다운로드합니다. |
| 가져오기 | **Import Marginalia VCS JSON** - 이 확장 기능으로 내보낸 이력. **Import SillyTavern VCS Extension JSON** - SillyTavern의 로어북 버전 이력 확장 기능에서 나온 이력. |

가져오기는 로어북의 이력을 **대체**합니다. 로어북에 이미 이력이 있거나 파일이 다른 로어북에서 내보낸 것이면, 가져오기 전에 확인을 요청합니다.

Marginalia 이력은 먼저 항목 자체를 기준으로 항목과 대응됩니다. 찾지 못한 항목(예: 이력이 로어북의 다른 사본에서 온 경우)은 현재 리비전의 이름과 순서로 대응되며, 하나의 항목만 해당 이름을 가진 경우에는 이름만으로 대응됩니다. 어떤 항목과도 대응되지 않는 이력은 건너뛰며, 확인 창에 그 개수가 표시됩니다.

SillyTavern 이력은 로어북에서의 위치로 항목과 대응되므로, 항목을 추가하거나 삭제하기 전에 [같은 월드 정보에서 가져온](../lorebooks/import-export.md#importing-sillytavern-world-info) 로어북에 가져오십시오. 리비전의 트리거 키는 [월드 정보 가져오기](../lorebooks/import-export.md#importing-sillytavern-world-info)가 변환하는 것과 같은 방식으로 항목의 필터가 됩니다.

<a id="storage"></a>

## 저장

이력은 로어북과 함께 데이터베이스에 저장되므로 [데이터베이스 백업](../administration/database-backups.md)에 포함됩니다. 확장 기능이 로어북에 보관하는 데이터는 [로어북 내보내기](../lorebooks/import-export.md#exporting)와 [책 백업](../books/backups.md)의 로어북에도 기록되며, [에이전트](../agents.md)가 작업하는 책 로어북 사본에도 들어갑니다. 하지만 로어북을 가져오면 새 항목이 만들어지고, 이력은 이전 항목의 정체성에 속하므로 새 항목에는 나타나지 않습니다. 이력을 가져온 사본으로 옮기려면 원본에서 이력을 내보낸 뒤 사본에 가져오십시오. 그러면 항목은 이름과 순서로 대응됩니다 (see [로어북 리비전](#lorebook-revisions) 참조).
