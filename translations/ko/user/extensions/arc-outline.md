# 아크 개요

사이드바에 보이는 책의 계획입니다. 아크(arc)마다 여러 챕터로 나뉘며, 각각의 상태를 확인할 수 있습니다. 모델이 아크와 챕터를 대신 작성해 줄 수도 있습니다. 개요는 이야기 프롬프트의 일부가 아닙니다. 생성기와 [사이드 쿼리](side-query.md)는 요청할 때 개요를 활용할 수 있습니다.

<a id="the-arcs-tab"></a>

## 아크 탭

[이야기 편집기](../books/story-editor.md)의 왼쪽 사이드바에는 *개요* 옆에 **Arcs** 탭이 생깁니다. **Add new arc**를 누르면 아크의 대화 상자가 열립니다.

| 필드 | |
|---|---|
| 제목 | 필수 항목입니다. |
| 설명 | 이 아크에서 일어나는 일입니다. |
| 메모 (비공개) | 나만 보는 메모입니다. |
| 상태 | **Planned**, **Current** 또는 **Finished**. |
| 연결된 부분 | 아크나 챕터가 속한 이야기의 부분입니다. [아래](#linking-to-the-story)를 참고하세요. |

챕터에도 같은 필드가 있습니다. 목록에서는 각 아크가 카드로 표시되며, 그 아래에 챕터가 들여쓰기되어 나타납니다. 카드의 색은 상태를 따릅니다. 계획된 아크는 회색, 현재 아크는 파란색, 완료된 아크는 초록색이며 제목이 흐리게 표시됩니다. 카드의 버튼은 다음과 같습니다.

| 버튼 | |
|---|---|
| 달력 / 재생 / 체크 | 상태입니다. 누르면 상태를 바꾸는 메뉴가 열립니다. |
| 꺾쇠 (아크) | 아크의 챕터를 숨기거나 표시합니다. |
| 꺾쇠 (메모가 있는 챕터) | 챕터의 메모를 설명 아래에 표시하거나 숨깁니다. 대화 상자를 열지 않고도 읽을 수 있습니다. |
| 화살표 | 아크나 챕터를 위아래로 옮깁니다. |
| 더하기 (아크) | 아크의 끝에 챕터를 추가합니다. |
| 마법봉 (아크) | 모델에게 아크의 챕터를 작성하도록 요청합니다. [아래](#generating-chapters)를 참고하세요. |
| 표적 (연결된 부분이 있는 아크와 챕터) | 연결된 부분으로 이야기를 스크롤합니다. |
| 펜 | 대화 상자에서 편집합니다. |
| 휴지통 | 확인 후 삭제합니다(아크는 모든 챕터와 함께 삭제됩니다). |
| 로봇 (생성된 아크와 챕터) | 모델이 작성한 내용을 보여 줍니다. [아래](#generating-an-arc)를 참고하세요. |

맨 위의 마법봉 옆에는 깃털이 달린 펜이 있습니다. 이 버튼은 현재 챕터를 바탕으로 다음 턴의 지시문 초안을 작성합니다. [아래](#drafting-the-instructions-for-the-current-chapter)를 참고하세요.

![Arcs 탭: 완료된 아크, 현재 아크, 계획된 아크](../../images/plugin-arcoutline-tab.png)

<a id="linking-to-the-story"></a>

### 이야기와 연결하기

아크나 챕터를 **이야기의 한 부분과 연결**할 수 있으므로, 계획에서 본문의 해당 위치로 바로 이동할 수 있습니다. 대화 상자에는 **연결된 부분** 필드가 있습니다. 이 필드에는 활성 가지에서 부분의 위치를 적으며, 번호는 *개요* 탭에 표시된 것처럼 1부터 시작합니다(`#12`). 직접 입력하거나, 옆의 **link** 버튼을 눌러 그 순간 이야기에서 **가장 많이 보이는** 부분을 가져올 수 있습니다(먼저 이야기에서 해당 위치로 스크롤한 뒤 대화 상자를 여세요). **target** 버튼을 누르면 이야기가 필드에 적힌 부분으로 스크롤됩니다. 연결된 아크나 챕터의 카드에도 target 버튼이 있습니다. 연결은 가지에서의 위치를 가리키므로, 앞쪽 부분이 삭제되거나 삽입되면 다른 부분을 가리키게 됩니다. 그럴 때는 연결을 바꿔 주세요. 이야기에서 가져오기를 하면 챕터가 자동으로 연결됩니다. [아래](#importing-an-arc-from-the-story)를 참고하세요.

<a id="the-note-of-a-chapter"></a>

### 챕터의 메모

메모가 있는 챕터의 오른쪽에는 꺾쇠가 보입니다. 이것을 누르면 목록에서 설명 아래에 메모가 열립니다. 그래서 대화 상자를 열지 않고도 챕터의 세부 사항(예를 들어 모델이 작성한 내용)을 읽을 수 있습니다. 다시 누르면 메모가 접힙니다. 어떤 메모가 열려 있는지는 저장되지 않습니다.

![메모가 표시된 챕터](../../images/plugin-arcoutline-note.png)

<a id="moving-chapters-between-arcs"></a>

### 챕터를 아크 사이로 옮기기

아크의 첫 자리에 있는 챕터를 위로 옮기면 이전 아크의 끝으로 가고, 마지막 자리에 있는 챕터를 아래로 옮기면 다음 아크의 시작으로 갑니다. 필요한 만큼 화살표를 계속 누르면 됩니다.

<a id="drafting-the-instructions-for-the-current-chapter"></a>

### 현재 챕터의 지시문 초안 작성

*Add new arc* 옆의 깃털 달린 펜은 창을 엽니다. 이 창에서 모델이 다음 턴의 [지시문을 초안으로 작성](../books/story-editor.md#drafting-the-instructions)합니다. 이때 이야기가 있는 챕터의 데이터가 **이야기 계획**으로 사용됩니다. 현재 챕터는 **Current**로 표시된 첫 챕터이며, 그런 챕터가 없으면 **Finished**가 아닌 첫 챕터입니다. 현재로 표시되었지만 아직 챕터가 없는 아크는 단독으로 쓰입니다. 모델은 그 아크와 챕터를 설명 및 메모와 함께 받고, 다음 챕터의 제목과 설명(메모는 제외)도 함께 받습니다. 이야기가 아직 그 챕터에 도달하면 안 된다는 경고도 함께 전달됩니다. 창은 새 턴 패널의 *지시문*에 입력해 둔 내용을 안내로 삼아 시작합니다. **Use as Instructions**를 누르면 초안이 그 패널에 들어가고 패널이 열립니다. 현재 챕터가 없으면 버튼에 그 사실이 표시됩니다.

같은 데이터는 [사이드 쿼리](side-query.md)의 출처로도 쓰입니다. [아래](#the-outline-as-a-source-for-other-extensions)를 참고하세요.

<a id="finishing-an-arc"></a>

### 아크 완료하기

아크를 **Finished**로 표시하면 그 아크의 모든 챕터도 **Finished**로 표시됩니다. 아크를 다른 상태로 바꾸면 챕터의 상태는 그대로 유지됩니다.

개요는 바꾸는 즉시 책과 함께 저장되므로, 책의 백업에도 포함됩니다.

<a id="the-outline-as-a-source-for-other-extensions"></a>

## 다른 확장 기능의 출처로서의 개요

개요는 책에 관한 데이터의 출처로서 다른 확장 기능에도 제공됩니다. [사이드 쿼리](side-query.md)의 플러그 팝오버에서 **Arc outline**을 체크하면 질문과 함께 아크, 각 아크의 상태, 설명, 챕터를 보낼 수 있습니다. 버전은 두 가지입니다. **Arc outline**은 간략한 버전으로 설명만 포함하고, **Arc outline (with notes)**는 각 아크와 챕터의 메모를 설명 아래에 추가합니다. 생성된 아크와 챕터의 세부 사항이 바로 이 메모에 들어 있습니다. 비공개 메모는 두 번째 항목을 체크했을 때에만 전송됩니다. 세 번째 출처인 **Arc outline: current chapter**는 이야기가 있는 아크와 챕터만 보냅니다([현재 챕터의 지시문 초안 작성](#drafting-the-instructions-for-the-current-chapter)을 참고하세요).

<a id="generating-an-arc"></a>

## 아크 생성하기

*Add new arc* 옆의 마법봉 버튼은 세 개의 항목이 있는 메뉴를 엽니다. **Generate an arc**는 모델에게 새 아크를 작성하도록 요청합니다. **Import from story**는 이미 작성한 내용을 요약합니다. [아래](#importing-an-arc-from-the-story)를 참고하세요. **Develop the plot**은 이야기가 어디로 가는지에 관해 모델과 나누는 대화입니다. [아래](#developing-the-plot-in-a-conversation)를 참고하세요.

![마법봉 메뉴](../../images/plugin-arcoutline-menu.png)

**Generate an arc**의 대화 상자는 두 부분으로 나뉩니다.

왼쪽에는 다음이 있습니다.

| | |
|---|---|
| 프롬프트 | 모델에게 주는 지시문이며, 세 가지 변수를 사용합니다. `{{backgroundLore}}`(책의 로어북과 하위 로어북의 항목), `{{existingArcs}}`(아크와 챕터, 상태와 설명 포함, 단 비공개 메모는 제외), `{{specification}}`입니다. 처음에는 *Settings → Extension Settings → Arc Outline*의 프롬프트로 채워집니다(바꾼 적이 없다면 기본 프롬프트). 여기서 수정한 내용은 이번 생성에만 적용됩니다. |
| 명세 | 아크에 원하는 것, 즉 주제, 등장인물, 어디로 이어져야 하는지입니다. 비워 둘 수 있습니다. |
| 도구 | [모델용 도구](tools.md) 묶음(이름, 장소)이 설치된 경우에만 나타납니다. 모델이 무언가를 지어내는 대신 사용할 수 있는 묶음과 그 범주를 고릅니다. [로어 생성기](lore-generator.md)와 같습니다. |
| 모델, 프로토콜 | 책의 모델과 프로토콜(책에 설정이 없으면 *설정*에서 지정한 기본값)로 시작합니다. 이번 생성에만 다른 모델을 쓰려면 바꾸세요. 이 선택은 저장되지 않습니다. |
| 생성 | 모델을 실행합니다. 실행되는 동안 버튼은 빨간색 **Stop**이 되고, 대화 상자의 다른 모든 항목은 비활성화됩니다. |

오른쪽에는 모델의 **추론**이 작성되는 대로 보이고, 답변이 시작되면 모델이 제안하는 **아크**가 나타납니다. 이름, 짧은 설명, 더 긴 메모로 구성되며, 개요의 아크처럼(설명 아래에 메모가 붙는 형태로) 표시되고 답변이 흘러들어오면서 점점 길어집니다. 설명은 개요에 표시되는 내용이므로, 모델에게는 설명을 두어 문장으로 줄이고 세부 사항은 메모에 적도록 요청합니다. 메모는 저장된 아크의 **메모**가 됩니다. 모델이 작업을 마치면 답변을 검사합니다. 유효한 아크가 아니면(예를 들어 메모가 없으면) 대화 상자가 이를 알리고 아크를 저장할 수 없습니다.

![아크 생성 중](../../images/plugin-arcoutline-generate-arc.png)

**Save as arc**는 아크를 개요의 끝에 추가합니다. 다시 시도하려면 같은 프롬프트나 명세를 그대로 두거나 바꾼 뒤 **Generate**를 한 번 더 누르세요. 이전 답변은 대체됩니다.
<a id="importing-an-arc-from-the-story"></a>

## story에서 아크 가져오기

마법봉 메뉴의 **Import from story**는 모델이 여러분의 이야기 일부를 읽고, 그 내용을 챕터가 있는 하나의 아크로 정리하도록 요청합니다. 이렇게 하면 이미 쓴 책을 아웃라인으로 가져올 수 있습니다. 모델은 항상 대화창을 열 때의 책의 [활성 분기](../books/branches-and-story-tree.md)를 읽습니다. 대화창은 아크용과 비슷하며, 왼쪽에 다음 선택지가 있습니다.

| | |
|---|---|
| From message, To message | 보낼 이야기의 범위입니다. 텍스트가 있는 분기의 메시지는 1부터 번호가 매겨집니다. 처음에는 분기 전체가 선택되어 있습니다. 각 입력란 아래에는 그 입력란이 가리키는 메시지의 시작 부분이 표시됩니다. |
| Number of chapters (optional) | 숫자를 고르면 정확히 그 수만큼의 챕터를 받습니다(다른 수의 답변은 거부됩니다). 비워 두면 모델이 이야기가 자연스럽게 나뉘는 곳에서 나눕니다. |
| Link the chapters to the parts of the story | 처음부터 켜져 있습니다. 보낸 범위 안에서 메시지에 번호가 1부터 매겨지고, 모델은 각 챕터가 어느 메시지에서 시작하는지 알려 줍니다. 그러면 해당 챕터는 이야기의 그 부분에 [연결](#linking-to-the-story)됩니다(전체 분기 기준의 번호이므로 범위와 상관없이 정확합니다). 아크는 첫 번째 챕터가 시작하는 부분에 연결됩니다. 보내지 않은 메시지를 가리키는 답변이면 해당 챕터는 연결되지 않은 상태로 남습니다. |
| State of the imported arc and its chapters | 이야기는 이미 완성되어 있으므로 처음에는 **Finished**입니다. 필요하면 **Current** 또는 **Planned**를 고르세요. |
| Token counter | 범위에 메시지가 몇 개인지, 그리고 대략적인 토큰 수를 보여 줍니다. 또한 전체 프롬프트(지침, 로어, 아웃라인, 이야기)의 대략적인 토큰 수와 모델이 처리할 수 있는 양도 함께 보여 줍니다. 프롬프트가 들어가지 않으면 경고로 바뀌며, 그때는 메시지 수를 줄이세요. 범위, 챕터 수, 프롬프트, 모델에 따라 값이 바뀝니다. |
| Prompt | 모델에 주는 지침입니다. 변수 `{{backgroundLore}}`, `{{existingArcs}}`, `{{story}}`(범위의 메시지), `{{numberOfChapters}}`를 사용할 수 있습니다. 처음에는 *Settings → Extension Settings → Arc Outline*의 **Story import prompt**에서 가져온 내용으로 채워져 있습니다. |

![Importing an arc from the story](../../images/plugin-arcoutline-import.png)

여기에는 도구가 없으며, 이름은 이야기 안에 있습니다. 오른쪽에는 모델의 추론이 나타난 뒤, 모델이 작성한 아크와 그 챕터들이 표시됩니다. **Save as arc**를 누르면 아크와 챕터들이 아웃라인 끝에 추가됩니다. 각 항목은 모델의 추론과 답변을 그대로 간직하며, 각자 고유한 로봇 버튼을 가집니다. 긴 이야기는 여러 번에 나누어 가져오는 것이 좋습니다. 범위마다 아크 하나씩 만드세요.
<a id="developing-the-plot-in-a-conversation"></a>

## 대화로 플롯 발전시키기

마법봉 메뉴의 **Develop the plot**은 플롯에 관해 모델과 대화하는 창을 엽니다. 대화만으로는 책의 어떤 내용도 바뀌지 않습니다. 모델은 여러분이 골라 보낸 것을 보고 답하며, 합의한 내용이 생기면 한 번의 클릭으로 아크 생성기에 넘길 수 있습니다.

왼쪽에서는 모델이 무엇을 보고 어떻게 도울지 고르고(선택은 다음번을 위해 기억됩니다), 오른쪽에는 대화창이 있습니다:

![플롯 마법사: 왼쪽의 옵션, 오른쪽의 대화](../../images/plugin-arcoutline-wizard.png)

| | |
|---|---|
| Model, Protocols | 책의 모델과 프로토콜로 시작합니다. 바꾸면 이 대화에만 적용됩니다. |
| How the model helps | **Free talk**(여러분이 이끕니다), **Explore directions**(이야기가 이어질 수 있는 서로 다른 여러 방향), **Find the problems**(해결되지 않은 실타래, 아무도 지키지 않는 약속, 설정과의 모순, 전개 속도), 또는 **Expand an idea**(여러분의 아이디어를 전제, 전환점, 결말, 그리고 여러분의 아크 뒤에 맞는 챕터로 키우기)입니다. |
| Send the lorebook | 책의 로어북과 하위 로어북의 항목들입니다. |
| Send the outline | **Not sent**, **Descriptions only**, 또는 **With the notes**(여러분의 비공개 메모도 포함) 중 하나입니다. |
| Send the notes | [Story Notes](story-notes.md)가 설치된 경우에만 해당합니다: **Not sent**, **Titles and first lines**(기본값), 또는 어시스턴트에게 숨긴 페이지를 제외한 메모의 **Full text**입니다. |
| Send the summaries of the story | 요약은 생성이 보내는 방식 그대로, 가장 최근 요약까지의 이야기를 대신합니다. |
| Send the latest parts of the story | 가장 최근 요약 이후의 파트들(요약이 꺼져 있으면 전부)이며, **Tokens of the story**에 맞는 가장 최근 것들입니다. 각 파트는 이야기 개요에 있는 번호와 함께 모델에 보입니다. |
| Tokens of the story | 이야기 파트에 쓸 최대 토큰 수입니다. 비워 두면 모델이 받는 양의 3분의 1입니다. |
| Prompt | 모델에 대한 지시문이며, 변수 `{{backgroundLore}}`, `{{outline}}`, `{{notes}}`, `{{summaries}}`, `{{story}}`, `{{mode}}`를 씁니다. 바꾼 내용은 기억됩니다. |

옵션 아래의 한 줄은 모델이 요약과 이야기 파트를 몇 개 받는지, 그리고 요청이 모델이 받는 양 중 몇 토큰을 차지하는지 알려 줍니다. 맞지 않으면 경고로 바뀌니, 더 적게 보내거나 [대화를 요약](#chats-branches-and-summaries)하세요. 책은 메시지마다 다시 읽히므로, 개요나 이야기의 변경은 다음 답변에 바로 반영됩니다.

오른쪽은 대화창입니다. 메시지를 입력하고 **Send**를 누르세요(모델이 쓰는 동안에는 **Stop**이 됩니다. 도착한 내용은 남습니다). 각 메시지에는 버튼이 있습니다: 복사, **branch from here**, 삭제, 그리고 모델의 답변에는 마법봉도 있어 **Generate an arc from this message**를 누르면 그 메시지를 명세로 삼아 아크 생성기가 열립니다. 논의가 길었다면 먼저 모델에게 결정한 내용을 명세로 요약하도록 요청하세요.

<a id="letting-the-model-change-the-book"></a>

### 모델이 책을 바꾸게 하기

옵션 아래에는 **What the model may do**가 있습니다. 아무것도 체크하지 않으면 대화는 그저 이야기일 뿐입니다. 그룹을 체크하면 모델은 그 그룹을 위한 도구를 받고, 여러분이 요청하거나 동의했을 때 사용할 수 있습니다. 모델은 추가하기 전에 먼저 살펴보고, 바꾸기보다 추가를 우선하며, 무엇을 했는지 말하도록 지시받습니다:

| 그룹 | 모델이 할 수 있는 일 |
|---|---|
| **Planner** | [플래너](../books/story-editor.md#the-planner-tab)의 장면을 나열하고, 추가하고, 바꾸고, 옮기고, 삭제하고, 완료로 표시할 수 있습니다. |
| **Lorebook** | 설정을 검색하고 읽고, 항목을 만들고 기존 항목을 바꿀 수 있습니다(삭제는 불가). |
| **Outline** | 개요를 읽고, 아크와 챕터를 추가하고, 바꾸고, 옮길 수 있습니다(삭제는 불가). |
| **Notes**([Story Notes](story-notes.md)가 설치된 경우) | 여러분의 메모를 검색하고 읽으며 그 링크를 따라갈 수 있고, 여러분이 무언가를 기억해 두라고 요청하면 페이지를 추가하거나 기존 페이지에 덧붙일 수 있으며, 페이지 안의 글을 바꿀 수 있습니다(페이지 삭제는 불가). 어시스턴트에게 숨긴 페이지에는 접근할 수 없습니다. |
| **Generators** | 아크와 챕터 생성기를 호출하고, [Lore Generator](lore-generator.md)가 설치된 경우 설정 항목을 생성할 수 있습니다. 이들은 초안을 돌려줄 뿐, 모델이 그렇게 하라고 지시받지 않는 한 아무것도 저장하지 않습니다. 모델은 초안을 여러분에게 보여 주고, 여러분이 동의하면 저장합니다. |
| **Tools**(버튼, [도구 모음](tools.md)이 설치된 경우) | 이름 도구(이름, 장소)를 생성기에서처럼 쓸 수 있어, 모델이 실제 이름을 제안할 수 있습니다. |

- **Ask me before it changes or deletes something**(기본으로 켜짐): 기존 내용(설정 항목, 장면, 아크)의 글을 바꾸거나 삭제하려 하면, 모델이 넘기려는 내용과 함께 먼저 여러분에게 보이고, 모델은 **Allow** 또는 **Refuse**를 기다립니다. 장면, 항목, 아크를 추가하는 것은 묻지 않습니다. 대화창과 플래너, 로어북, 개요에서 확인할 수 있고, 삭제도 할 수 있습니다.
- 모델이 호출한 모든 도구는 그 답변 아래에 나열됩니다(이름과 표시가 붙은 줄: ✓ 성공, ✗ 실패. 열면 무엇이 전달되었고 무엇이 돌아왔는지 볼 수 있습니다). 다음 메시지들에는 모델이 한 호출과 돌아온 결과가 담겨(긴 결과는 잘림), 모델은 이미 무엇을 했는지 알고 같은 항목을 또 만들지 않습니다. 이 내용은 대화의 토큰 한도에 포함됩니다.
- 도구의 비용: 도구 설명은 모든 요청에 포함되므로, 컨텍스트가 부족한 모델은 여유가 줄어듭니다. 함수 호출을 할 수 있는 모델만 동작하며, 그렇지 않은 모델이면 대화창이 그렇다고 알려 줍니다.

![모델이 플래너에 장면 두 개를 추가했습니다. 호출 내역은 답변 아래에 나열됩니다](../../images/plugin-arcoutline-wizard-tools.png)

<a id="chats-branches-and-summaries"></a>

### 대화, 분기, 요약

책에는 대화를 몇 개든 둘 수 있습니다. 메시지 위의 목록에서 하나를 고르고, **+**는 새 대화를 시작하며, 연필은 이름을 바꾸고(그전까지는 여러분의 첫 메시지 이름이 붙습니다), 휴지통은 삭제합니다. 대화는 책과 함께 저장됩니다.

- **Branch**는 대화를 현재 상태 그대로 새 대화로 복사합니다. 메시지의 분기 버튼은 그 메시지까지 복사하여, 거기서부터 다른 방향으로 이야기를 이어 가게 합니다. 이후 복사본은 원본과 아무 관계가 없습니다.
- **Summarize the chat**은 먼저 요약이 무엇을 남기거나 강조해야 하는지 묻고(선택 사항입니다. 예: "배신자에 관한 반전과 우리가 거부한 결말을 남겨 줘". 비워 두면 모델이 정합니다), 그다음 대화의 요약을 모델에게 요청합니다(결정한 것, 거부한 것, 아직 열려 있는 것, 확정된 이름들). 요약은 메시지로 추가됩니다. 그 뒤로 모델은 그 요약과 그 이후의 메시지들을 받고, 그 위의 메시지들은 **받지 않습니다**. 그 메시지들은 흐리게 처리된 채 화면에 남습니다. 대화가 모델이 감당하기에 너무 길어졌을 때, 또는 결정 사항을 잃지 않고 깨끗한 상태에서 다시 시작하고 싶을 때 쓰세요. 나중에 다시 요약하면 새 요약이 이전 요약을 포함합니다. 대화 전체를 모델에게 남겨 두고 싶다면 먼저 분기하세요.

![요약이 무엇을 남겨야 하는지 묻는 질문](../../images/plugin-arcoutline-wizard-summarize.png)

![요약 이후의 대화: 그 위의 메시지들은 흐리게 처리되어 화면에 남습니다](../../images/plugin-arcoutline-wizard-summary.png)
<a id="generating-chapters"></a>

## 챕터 생성

아크에 있는 마법봉 버튼은 모델에게 그 아크를 챕터로 나누어 달라고 요청합니다. 대화상자는 아크의 것과 비슷하며, 왼쪽에는 다음 선택지가 있습니다:

| | |
|---|---|
| 모델이 이야기에 대해 아는 내용 | **지금까지의 전체 이야기**: 이 아크까지의 아크들과 그 모든 챕터. **아크 요약만**: 챕터 없이 같은 아크들. **아크 요약과 완료된 챕터**: 같은 아크들과, *완료*로 표시한 챕터만. 이 아크 이후의 아크는 절대 전송되지 않습니다. |
| 챕터 전체에 대한 요청 사항 | 전개 속도, 어조, 반드시 일어나야 할 일. 비워 둘 수 있습니다. |
| 챕터 수 | "약 여덟 개"처럼 말로 쓰거나 정확한 숫자를 고릅니다. 숫자를 지정하면 챕터마다 내용을 적을 수 있는 텍스트 영역이 추가되며, 모두 선택 사항입니다. 둘 중 하나를 사용하면 다른 쪽은 지워집니다. 정확한 숫자를 지정하면 챕터 수가 다른 응답은 거부됩니다. |
| 프롬프트 | 모델에게 주는 지시문이며, 변수 `{{backgroundLore}}`, `{{outline}}`, `{{numberOfChapters}}`, `{{generalSpecification}}`, `{{chapterSpecification}}`을 사용합니다. *설정 → 확장 설정 → Arc Outline*의 **Chapter generation prompt**로 시작합니다. |

오른쪽에는 먼저 추론 과정이 보이고, 그다음 이미 가지고 있는 챕터가 달린 아크, 그리고 모델이 작성하는 새 챕터가 차례로 보입니다. **Save as chapters**를 누르면 새 챕터가 아크의 끝에 추가되며, 각 챕터에는 짧은 설명과 메모에 자세한 내용이 담깁니다(아크와 같습니다). 새로 만들어진 챕터마다 모델의 추론 과정과 응답이 함께 저장되며, 각자 로봇 버튼을 가집니다.

![아크의 챕터 생성하기](../../images/plugin-arcoutline-generate-chapters.png)

모델이 작성한 아크나 챕터는 **추론 과정**과 그것이 나온 **응답**을 함께 보관합니다. 그 위의 로봇 버튼을 누르면 작은 팝오버에 두 가지가 열리며, 화면을 가리지 않습니다.

![모델이 아크에 대해 작성한 내용](../../images/plugin-arcoutline-generated.png)

## 명령

아웃라인과 그 생성기는 [명령](../commands/index.md)으로도 쓸 수 있으며, 명령줄과 [에이전트](../agents.md)에서 사용할 수 있습니다. 이들은 열려 있는 책에 대해 작동합니다(에이전트의 경우에는 작업 복사본에 대해). 열린 Arcs 탭에는 변경 사항이 즉시 표시됩니다. 아크와 챕터는 아웃라인에 표시된 **번호**로 지정합니다. 첫 번째 아크는 `1`, 아크의 첫 번째 챕터도 `1`입니다(앞쪽에서 무엇인가를 추가, 삭제 또는 이동하면 번호가 바뀝니다). 아크나 챕터를 바꾸는 명령은 주어진 필드만 받으며, 빈 텍스트를 주면 설명이나 메모가 지워집니다.

| 명령 | 하는 일 |
|---|---|
| `/get-arc-outline [arc [notes]]` | 아크와 그 챕터, 상태, 설명을 JSON으로 반환합니다. 비공개 메모는 `notes`를 `true`로 줄 때만 포함됩니다. `arc`를 주면 그 아크 하나만 반환합니다. 읽기 전용입니다. |
| `/add-arc title [description [note [state [position]]]]` | 아크를 추가합니다. 끝에 추가하거나 `position` 위치에 추가합니다. |
| `/update-arc arc [title [description [note [state]]]]` | 아크를 변경합니다. `state`는 `PLANNED`, `CURRENT` 또는 `FINISHED`입니다(아크를 완료하면 그 챕터도 완료됩니다). |
| `/move-arc arc position` | 아크를 `position` 위치로 옮깁니다(1이 첫 번째입니다). |
| `/delete-arc arc` | 확인을 거친 뒤 아크를 챕터와 함께 삭제합니다. |
| `/add-outline-chapter arc title [description [note [state [position]]]]` | 아크에 챕터를 추가합니다. |
| `/update-outline-chapter arc chapter [title [description [note [state]]]]` | 챕터를 변경합니다. |
| `/move-outline-chapter arc chapter position [to_arc]` | 챕터를 같은 아크 안에서 옮기거나, `to_arc` 아크로 옮깁니다. |
| `/delete-outline-chapter arc chapter` | 확인을 거친 뒤 챕터를 삭제합니다. |
| `/generate-arc [specification [save]]` | *Generate an arc*가 하는 것처럼 모델에게 새 아크를 요청합니다. |
| `/generate-outline-chapters arc [specification [count [context [save]]]]` | 아크의 마법봉이 하는 것처럼 모델에게 그 아크의 챕터를 요청합니다. `count`는 정확한 챕터 수이고, `context`는 *모델이 이야기에 대해 아는 내용* 선택지처럼 `EVERYTHING`(기본값), `ARCS_ONLY` 또는 `ARCS_AND_FINISHED`입니다. |
| `/import-arc-from-story [from [to [count [state [save [mapParts]]]]]]` | 활성 분기의 `from`부터 `to`까지의 메시지를(*스토리에서 가져오기*에서처럼 텍스트가 있는 메시지 중에서 번호를 매겨) 챕터가 있는 아크로 요약해 달라고 모델에게 요청합니다. `state`(기본값 `FINISHED`)는 저장되는 아크와 그 챕터의 상태입니다. `mapParts`를 `true`로 주면 모든 챕터가 시작되는 메시지에 연결되며(대화상자의 *Map parts* 체크박스가 하는 것처럼 각 챕터의 *Linked part*가 됩니다), 응답에는 각 챕터의 파트가 포함됩니다. |

세 가지 생성 명령은 대화상자와 같은 프롬프트(*설정 → 확장 설정 → Arc Outline*, 또는 기본값), 책의 모델과 프로토콜(책에 모델이 없으면 기본 모델), 그리고 도구를 사용하지 않습니다. 이름이 필요한 호출자는 [이름 생성기](name-generator.md) 또는 [이름 제공자](name-provider.md)의 명령으로 이름을 얻어 명세에 넣어야 합니다. 대화상자와 마찬가지로 요청이 있을 때만 저장합니다. `save`가 `false`(기본값)이면 아크나 챕터를 JSON으로 반환하고 아무것도 저장하지 않으며, `save`가 `true`이면 아웃라인에 추가합니다(아크는 끝에, 챕터는 아크의 끝에). 이때 응답에는 새로 추가된 항목의 번호가 포함됩니다. 모델이 처리하기에 이야기가 너무 길면 `/import-arc-from-story`는 요청을 거부하므로 메시지 범위를 줄여야 합니다. 생성 명령은 시간이 걸리며, 실행이 중지되면 함께 멈춥니다.

추가와 변경은 파괴적이지 않으며, 두 개의 `delete` 명령만 그렇습니다. 에이전트는 이 명령에 대해 사용자에게 확인을 요청하도록 설정될 수 있습니다.
