# 스토리 노트

사이드바에 있는 작은 위키입니다. 계획 중인 줄거리, 아직 쓸 준비가 되지 않은 아이디어, 마법 체계의 규칙, 악당이 정말 원하는 것 등을 페이지로 정리할 수 있습니다. 노트는 여러분이 자신의 말로 적은 생각이며, 태그와 페이지 사이 링크를 달 수 있습니다. 모든 생성 요청에 함께 보내지는 하나의 텍스트인 [작가의 노트](authors-note.md)와 달리, 스토리 노트는 그 자체로 모델에 전송되지 않습니다. [플롯 마법사](arc-outline.md#developing-the-plot-in-a-conversation)와 에이전트는 노트를 읽을 수 있고, 허용하면 노트를 바꿀 수도 있습니다.

<a id="the-notes-tab"></a>

## 노트 탭

[스토리 편집기](../books/story-editor.md)의 왼쪽 사이드바에는 *개요* 옆에 **Notes** 탭이 생깁니다. 이 탭에는 책의 페이지가 제목순으로 나열됩니다. 목록 위에는 **Add**(새 페이지), 태그 필터(페이지에 태그가 붙으면 표시됨), 제목·태그·페이지 텍스트를 대상으로 하는 검색창이 있습니다.

각 페이지에는 제목, 텍스트의 첫 줄, 태그가 표시됩니다. 페이지를 클릭하거나 연필 아이콘을 누르면 열리고, 휴지통을 누르면 확인 후 삭제됩니다. 제목 옆에는 두 가지 작은 표시가 붙을 수 있습니다. 감긴 눈은 페이지가 [어시스턴트에게 숨겨져 있음](#what-assistants-can-see)을 뜻하고, 마법봉은 마지막 변경이 여러분이 아니라 명령에서 나왔음을 뜻합니다.

![노트 탭: 어시스턴트에게 숨겨진 페이지(눈 표시)와 플롯 마법사가 내용을 추가한 페이지(마법봉 표시)](../../images/plugin-storynotes-tab.png)

<a id="a-page"></a>

## 페이지

페이지 대화상자에는 다음 항목이 있습니다.

| | |
|---|---|
| **제목** | 필수 항목이며, 책 안에서 고유해야 합니다(대소문자는 구분하지 않음). 대괄호나 세로 막대(`|`)는 쓸 수 없습니다. 다른 페이지들이 이 제목으로 링크합니다. |
| **태그** | 쉼표로 구분합니다. 목록을 걸러 내는 데 쓰입니다. |
| **텍스트** | Markdown 형식입니다. **Write**와 **Preview**로 텍스트 편집과 표시 모습 보기를 전환합니다. 텍스트 안의 `[[제목]]`은 그 제목의 페이지로 연결되는 링크가 됩니다. `[[제목|다른 말]]`도 같은 페이지로 연결되지만, 미리 보기에서는 *다른 말*이 표시됩니다(`[[언어 장벽|말하는 방식]]`). |
| **어시스턴트에게 보이기** | 기본으로 켜져 있습니다. 아래를 참고하세요. |

텍스트 아래에는 대화상자가 해당 텍스트가 **링크하는** 페이지 목록을 보여 줍니다. 존재하는 페이지로의 링크를 누르면 그 페이지가 열리고, 존재하지 않는 페이지로의 링크에는 **Create** 버튼이 나타나며 그 제목으로 새 페이지를 만듭니다. 그 아래에는 이 페이지를 **링크하는** 페이지들이 나옵니다. 페이지 이름을 바꾸면 다른 페이지들에 있는 해당 `[[링크]]`도 함께 바뀝니다(링크에 표시되던 단어는 그대로 남습니다).

![링크하는 페이지와 이 페이지를 링크하는 페이지가 함께 표시된 페이지](../../images/plugin-storynotes-page.png)

**Preview**를 누르면 텍스트가 Markdown으로 표시되고, 모든 `[[링크]]`는 클릭할 수 있는 링크로 나타납니다. 클릭하면 해당 페이지가 열리며, 존재하지 않는 페이지로의 링크를 클릭하면 그 제목으로 새 페이지가 만들어집니다.

![같은 페이지의 미리 보기](../../images/plugin-storynotes-preview.png)

**Save**를 누르기 전까지는 아무것도 저장되지 않습니다. 변경된 페이지를 닫으려고 하면 변경 내용을 버릴지 묻습니다. 편집하는 도중에 명령으로 페이지가 바뀌었다면, 여러분의 버전으로 덮어쓰기 전에 확인을 받습니다. **Ctrl/Cmd+Enter**를 누르면 저장됩니다. 페이지는 책과 함께 저장되므로 책의 백업과 복사본에도 포함됩니다.

<a id="what-assistants-can-see"></a>

## 어시스턴트가 볼 수 있는 것

"어시스턴트"란 노트 기능이 제공하는 명령들을 가리키며, 에이전트, 매크로, 플롯 마법사가 이를 사용합니다. **어시스턴트에게 보이기**가 꺼져 있는 페이지는 어시스턴트에게 존재하지 않는 것과 같습니다. 목록에도 나타나지 않고, 검색되지도, 읽히지도, 변경되지도 않습니다. 그 페이지에만 있는 제목으로 새 페이지를 만들려고 하면 거부됩니다. 여러분만 봐야 하는 페이지에 대해서는 이 옵션을 끄세요. 꺼 둔 페이지도 백업에는 여전히 들어 있습니다.

명령은 명령 막대와 에이전트에서 사용할 수 있습니다. 제목은 페이지의 주소 역할을 합니다.

| 명령 | |
|---|---|
| `/list-notes [<tag>]`, `/get-note <note>`, `/search-notes <query>` | 페이지 목록, 텍스트와 링크 및 그 페이지를 링크하는 페이지들이 포함된 한 페이지, 그리고 검색을 보여 줍니다. |
| `/create-note <title> [<content> [<tags>]]` | 페이지를 추가합니다. |
| `/append-to-note <note> <text>` | 페이지 끝에 단락을 추가합니다. |
| `/update-note <note> [<title> [<content> [<tags>]]]`, `/edit-note <note> <find> <replace> [<all>]` | 페이지를 바꾸거나 텍스트의 일부를 교체합니다. `find`는 페이지에 적힌 그대로(대소문자 구분) 있어야 하며, `all`이 `true`가 아니라면 정확히 한 번만 나타나야 합니다. `all`이 `true`이면 모든 등장 위치가 교체되므로, 이름이나 용어를 문서 전체에서 바꿀 때 유용합니다. 답변에는 교체된 부분의 개수가 표시됩니다. 이 명령들은 기존 텍스트를 바꾸므로 *파괴적*입니다. 확인 후 실행하도록 설정된 에이전트라면 먼저 여러분에게 묻습니다. |
| `/delete-note <note>` | 확인 후 페이지를 삭제합니다. |
| `/note-text <note>` | 매크로용 페이지 텍스트입니다. {%{`{{command::note-text::Magic}}`}%}는 그 텍스트를 템플릿에 넣습니다. 존재하지 않거나 숨겨진 페이지라면 빈 값입니다. |

명령으로 변경된 페이지에는 여러분이 직접 저장하기 전까지 마법봉 표시가 붙습니다.

<a id="with-the-plot-wizard"></a>

## 플롯 마법사와 함께

이 확장 기능이 설치되어 있으면, 아크 개요의 [플롯 마법사](arc-outline.md#developing-the-plot-in-a-conversation)에 **Send the notes** 옵션(제목과 첫 줄, 전체 텍스트, 또는 아무것도 보내지 않기)과 **Notes** 도구 그룹이 추가됩니다. 모델은 페이지를 검색하고 읽고, 링크를 따라가고, 여러분이 무언가를 기억해 두라고 요청하면 페이지를 추가하거나 기존 페이지에 내용을 덧붙이고, 페이지의 텍스트를 바꿀 수 있습니다. **Ask me before it changes or deletes something**이 켜져 있으면 페이지 텍스트를 바꾸기 전에 먼저 묻습니다. 마법사는 페이지를 삭제할 수 없습니다. 옵션과 도구 그룹은 마법사 표에서 확인할 수 있습니다.

![Notes 도구를 사용하는 플롯 마법사: 페이지를 읽고 열린 질문을 그 페이지에 추가했습니다](../../images/plugin-storynotes-wizard.png)

<a id="other-extensions"></a>

## 다른 확장 기능

이 확장 기능은 다른 확장 기능에 두 가지 텍스트 원본을 제공합니다. [Side Query](side-query.md)는 플러그 버튼에서 이를 첨부할 수 있습니다. 원본은 **Story notes (titles)**와 **Story notes (all)**입니다. 두 원본 모두 숨겨진 페이지는 제외합니다.
