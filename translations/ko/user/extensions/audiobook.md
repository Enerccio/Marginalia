# 오디오북

text-to-speech 서버를 사용해 책을 부분별로 오디오북으로 만듭니다. 내레이터와 등장인물마다 목소리를 정하고, 그 목소리는 책의 각 부분과 함께 저장되어 리더에서 재생됩니다. 초안을 빠르게 만들려면 자동으로 실행할 수 있습니다(모델이 누가 어떻게 말하는지 표시하고, 음성 서버가 읽습니다). 부분마다 따로 작업하려면 **Audiobook studio**에서 음성 서버로 정확히 무엇이 전송되는지 확인하고 직접 수정할 수 있으며, 결과는 챕터 표시가 있는 mp3 파일로 내보낼 수 있습니다.

이 확장 기능은 음성을 직접 만들지 않습니다. 사용자가 실행하는 **Chatterbox-TTS-Server**와 통신합니다([음성 서버 설정](audiobook-server.md) 참고). 책의 텍스트는 절대 변경되지 않으며, 지정한 서버 외에는 어디에도 전송되지 않습니다. 오디오는 사용자의 설치 환경에 리소스로 저장되며, 각 부분에 연결됩니다.

<a id="what-you-need"></a>

## 필요한 것

- 음성 서버와, 서버가 언어 모델과 그래픽 카드를 함께 쓰는 경우에는 음성 서버를 위해 공간을 비우고 다시 멈추는 요청([음성 서버 설정](audiobook-server.md) 참고).
- 목소리: 복제하려는 목소리마다 짧은 **참조 클립**(한 사람의 목소리 12~30초, 음악 없음), 또는 서버에 있는 음성 파일 중 하나. 내레이터에게는 차분하고 일정한 낭독 목소리가 필요합니다.
- 여러 목소리가 등장하는 책의 경우, 텍스트에 표시를 달 수 있는 언어 모델. 기본적으로는 책의 모델을 사용합니다.
- **ffmpeg**은 선택 사항입니다. 없으면 모든 기능이 mp3로 작동합니다. 서버에 ffmpeg가 있으면(Docker 이미지에 포함되어 있고, 데스크톱에서는 `PATH` 또는 `/opt/homebrew/bin` 같은 일반 폴더에서 찾습니다. 다른 위치에 있으면 `MARGINALIA_FFMPEG` 변수로 경로를 지정합니다) 내보내기 형식으로 **m4b**를 쓸 수 있고, 관리자는 오디오를 wav로 저장하도록 설정할 수 있습니다.

<a id="the-settings"></a>

## 설정

*Settings → Extension Settings → Audiobook Settings*는 사용자 계정의 패널입니다. 변경한 뒤에는 *Settings* 페이지를 저장하세요.

![백엔드와 배우가 있는 패널](../../images/plugin-audiobook-settings.png)

<a id="backends"></a>

### 백엔드

백엔드는 음성 서버와 그 서버가 사용하는 모델입니다. **+**로 추가합니다.

| 설정 | 기능 |
|---|---|
| Name | Convert 대화상자에 표시되는 이름. |
| Address | 음성 서버, 또는 요청을 음성 서버로 전달하는 주소의 기본 주소. 예: `http://localhost:8004`. |
| Api key | 서버(또는 프록시)가 요구하면 bearer 토큰으로 전송됩니다. 암호화되어 저장되며 다시 표시되지 않습니다. 새 키를 입력해 교체하거나 **Remove the key**를 누르세요. |
| Speech model | **Chatterbox Turbo**(영어, `[sigh]` 같은 사운드 태그 지원, 가장 빠르며 기본값), **Chatterbox**(영어, 전달 방식의 *exaggeration* 지원) 또는 **Chatterbox Multilingual**(23개 언어). 일괄 작업 전 요청은 이 모델이 로드된 상태로 남아 있어야 합니다. 다른 모델이 필요한 책은 다른 백엔드를 사용합니다. |
| GPU (name) | 선택 사항. 하나의 GPU를 공유하는 서버(그리고 [Image Generator](image-generator.md)의 서버도 포함)에 같은 이름을 지정하면, 그 작업들이 서로 기다립니다. 다른 모델의 백엔드는 나머지 작업이 끝날 때까지 기다립니다. 비워 두면 같은 주소로 가는 일괄 작업끼리만 서로 기다립니다. |
| The server is on this machine or on my network | 로컬 네트워크 주소를 허용합니다. 클라우드의 서버라면 끄세요. 그래야 서버가 사용자 본인의 컴퓨터를 호출하도록 만들 수 없습니다. |
| Timeout of a request | 음성 한 조각을 기다리는 시간. |
| Restart the server after (pieces) | 메모리가 새고 긴 일괄 작업 중 시스템에 의해 종료되는 음성 서버를 위한 설정입니다. 이 개수의 조각을 처리한 뒤, 일괄 작업 중간에 작업 후 요청과 그다음 작업 전 요청을 다시 보냅니다(중지, 시작, 로드). 그러면 작업은 새로 시작된 서버로 계속됩니다. 0(기본값)이면 이 동작을 하지 않습니다. 종료된 서버는 이 설정과 관계없이 다시 시작됩니다. [문제 해결](audiobook-server.md#troubleshooting)을 참고하세요. |
| Key of the requests around a batch | 일괄 작업 전후 요청이 `Authorization: Bearer`로 보내는 키. 암호화되어 저장되며 다시 표시되지 않습니다(**Remove the key**로 지울 수 있습니다). 따라서 읽힐 수 있는 각 요청의 헤더에 키를 적을 필요가 없습니다. 비워 두면 위의 *Api key*가 사용됩니다. 이는 LiteLLM 같은 하나의 프록시가 모든 것을 처리하는 경우에 원하는 동작입니다. 자체 `Authorization` 헤더를 가진 요청은 그 헤더를 그대로 유지합니다. |
| Narrator voice | 등장인물이 없는 책의 내레이터. 서버의 음성 파일은 `predefined:Henry.wav`처럼 씁니다. |
| Defaults of a segment | 조각이 처음 시작할 때 쓰는 temperature, CFG weight, speed, chunk size 값(studio에서는 조각 하나에 대해 바꿀 수 있습니다). |
| Before a batch, After a batch | 부분들의 일괄 작업 전후에 보내는 요청. *before*는 그래픽 카드를 비우고 음성 서버를 시작하고, *after*는 서버를 멈춥니다. [하나의 GPU로 모델과 음성 함께 쓰기](audiobook-server.md#one-gpu-for-the-model-and-the-speech)를 참고하세요. 비워 두면 아무것도 하지 않습니다. |

**Test connection**은 일괄 작업과 같은 동작을 합니다. 일괄 작업 전 요청을 보내 (멈춰 있는 음성 서버를 시작), 서버가 응답하는지와 모델이 로드되었는지 확인하고, 일괄 작업 후 요청을 보냅니다. 요청 설정이 없으면 서버에 확인만 합니다.

다른 문자 체계의 조각이 있는 책(영어 책 속의 일본어)은, 해당 언어를 처리할 백엔드가 있으면 그 언어와 함께 다국어 모델로 보냅니다. 백엔드가 없으면 책의 모델에 남습니다.

<a id="shared-speech-servers"></a>

### 공유 음성 서버

여러 사용자가 있는 설치 환경에서 관리자는 모두가 쓸 수 있는 음성 서버를 둘 수 있습니다. 그러면 GPU 기기를 한 번만 설정하면 되고, 사용자는 주소나 키를 알 필요가 없습니다. 관리자는 같은 패널의 마지막 부분(관리자에게만 보임)에서 설정합니다. **Shared speech servers**를 열면 사용자의 백엔드와 같은 필드가 있는 창이 나오며, 누가 사용할 수 있는지도 정합니다: **all users** 또는 목록에서 고른 사용자. 그 아래의 스위치 **Users may add speech servers of their own**은 아래의 백엔드를 계속 허용할지 정합니다.

사용자가 얻는 것:

- 패널 맨 위의 **Backend in use**에는 사용할 수 있는 공유 서버(*(shared)*로 표시)와 사용자 본인의 서버가 나열됩니다. *Convert to audio* 창과 studio는 사용자가 고른 서버를 사용하며, 명령도 같은 서버를 사용합니다.
- 공유 서버의 이름만 보이며, 주소, 키, 요청 내용은 보이지 않습니다. 같은 음성 서버 주소를 쓰는 모든 사용자의 일괄 작업은 서로 기다리므로, 두 사용자가 같은 GPU를 동시에 두 번 쓰는 일은 없습니다.
- 관리자가 서버를 사용자에게서 빼앗으면, 여전히 그 서버를 지정한 작업은 거부됩니다. 다른 서버를 고르세요.
- 관리자가 사용자 본인의 서버를 끄면 패널에 그 사실이 표시됩니다. 사용자가 추가한 서버는 보관되며, 스위치를 다시 켜면 다시 사용됩니다.
- 공유 서버의 *Narrator voice*는 서버의 음성 파일(`predefined:Henry.wav`)이어야 합니다. 참조 클립은 한 사용자의 리소스이므로 다른 사용자가 읽을 수 없습니다. 사용자의 배우 목소리는 평소와 같이 작동합니다.

<a id="actors"></a>

### 배우

**배우(actor)**는 사용자의 목소리입니다. 참조 클립(사용자의 오디오 [리소스](../resources.md) 중 하나, 또는 여기에서 새로 업로드한 것) 또는 서버의 음성 파일로 만들며, **mood**(속삭임, 외침)나 **language**(일본어를 말하는 클립)에 대한 별도 목소리를 가질 수 있습니다. language가 mood보다 우선하며, 해당 목소리가 없으면 배우의 기본 목소리로 읽습니다. 배우는 사용자 계정에 보관되며, 어떤 책이든 배우를 내레이터나 등장인물에게 배정할 수 있습니다.

목소리 옆의 **Preview**(배우, 설정, 캐스트에서)는 그 목소리로 짧은 문장을 말하고 재생합니다(language의 경우 해당 언어로). 일괄 작업 전 요청이 음성 서버를 시작하도록 되어 있다면 서버도 함께 시작합니다. 배우는 이름순으로 나열됩니다.

![mood용 목소리가 있는 배우](../../images/plugin-audiobook-actor.png)

<a id="the-cast-and-the-pronunciation-of-a-book"></a>

## 책의 등장인물과 발음

둘 다 책과 함께 보관되며(백업에도 함께 들어갑니다) **Convert to audio** 대화상자에서 편집합니다.

**Cast**는 누가 읽을지를 정합니다. **narrator**에는 배우 한 명을, **other speakers**(캐스트에 없는 화자를 모델이 지정한 경우, 그 화자용)에는 배우 한 명을, 각 **character**에는 배우 한 명을 지정합니다. 빈칸이면 narrator가 읽습니다. 등장인물에는 이름과, 텍스트가 그 인물을 부를 때 쓸 수 있는 다른 이름들을 쉼표로 구분해 적습니다(*Tomáš Novák*의 경우 *Tom*). 대소문자와 악센트를 무시하고 이름, 다른 이름 중 하나, 또는 다른 인물과 겹치지 않는 이름의 한 단어가 일치하면 그 인물의 대사로 처리됩니다. **Add the characters of the book**을 누르면 각 부의 시점 인물과 등장인물로 목록이 채워집니다.

![책의 등장인물 목록](../../images/plugin-audiobook-cast.png)

**Pronunciation**은 텍스트를 *음성을 위해* 어떻게 표기할지를 정합니다. 책 원문은 결코 바뀌지 않습니다. **dictionary**는 단어 전체를(대소문자를 구분합니다) 읽을 내용으로 바꿉니다. 이름이나 직접 만든 단어에는 다른 철자를, 일본어에는 가나 읽기를 지정할 수 있습니다. 영어 책의 경우 규칙은 다른 것들도 소리 내어 읽습니다. 숫자, 서수, 연도, 시간, 금액, 약어는 단어로 읽고, 숫자만 있는 제목은 *Chapter four. The Arch*처럼 읽습니다(숫자 앞의 단어는 직접 정합니다). `*` 같은 마크다운 표시는 제외되고, 장면 전환(`***`, `---`)은 읽지 않고 더 긴 휴지로 처리됩니다. 다른 언어의 책이라면 규칙을 끄세요. 사전은 여전히 적용됩니다. **Try a text**는 텍스트가 어떻게 읽힐지 보여 줍니다. 읽히는 내용이 바뀐 조각만 다시 만들어지고, 나머지는 그대로 유지됩니다.

![책의 발음 설정](../../images/plugin-audiobook-pronunciation.png)
<a id="converting-a-book"></a>

## 책 변환하기

*스토리 편집기의 도구 메뉴(톱니바퀴 버튼) → **오디오로 변환***.

![시작하기 전 대화상자](../../images/plugin-audiobook-convert.png)

1. **백엔드**를 고르고 **Load**를 누릅니다. 활성 가지의 텍스트가 있는 부분이 목록으로 나타나며(첫 번째 부분은 1), 각 부분의 상태가 함께 표시됩니다.
   *Not generated*, *Labelled*(모델의 라벨은 저장되었지만 아직 오디오는 없음), *Generated*(재생 버튼과 다운로드 버튼이 있음), 또는
   *Generated (the text changed)*(오디오가 이전 텍스트로 만들어졌으므로 다시 만들어야 함). 스튜디오에서 *final*로 표시한 부분에는 *(final)*이 붙습니다.
2. 기본 버전을 원하면 **Label the parts with a language model**을 끈 상태로 둡니다. 이때 내레이터가 모든 문단을 읽습니다. 켜면 모델이 각 대사를 누가 말하는지, 어떤 방식으로(차분하게, 속삭이며, 소리치며 등) 말하는지, 그리고 효과음 태그를 어디에 넣을지 정하고, 등장인물 목록이 목소리를 배정합니다. 책에 선택된 모델을 사용하며, 원하면 다른 모델을 고를 수 있습니다. 부분은 먼저 라벨이 붙은 뒤 읽힙니다. 텍스트에 대해 이미 라벨이 있는 부분은 상자를 끈 상태에서도 그 라벨대로 읽힙니다(모델에게 다시 묻지 않습니다). 그래서 라벨이 있는 책을 상자를 끄고 다시 실행해도 대사가 평범한 서술로 바뀌지 않습니다. 평범한 서술을 원하거나 새 라벨을 원할 때는 **Remove labels**를 누르면 됩니다.
3. 부분을 선택하고(머리글의 상자를 누르면 전부 선택됨) **plan**으로 각 부분에 무엇을 할지 정합니다. **Plan** 열에 그 계획이 표시되며, 아직 아무것도 실행되지 않습니다.
   **Generate**(없는 것만 만듦. 최신 상태인 부분은 다시 만들지 않음), **Regenerate**(오디오를 지우고, 라벨을 지우고, 생성), **Delete audio**(부분의 조각과 합쳐진 오디오를 삭제. 라벨은 남음), **Remove labels**(다음에 그 부분을 만들 때 모델에게 다시 물음), **Clear the plan**(계획 지우기). 한 부분에 여러 단계가 누적됩니다(Generate 없이 Delete audio와 Remove labels만 있으면 정리만 합니다). *final*로 표시된 부분은 어떤 계획에서도 제외됩니다.
4. **Start**를 누르면 계획이 실행됩니다. 오디오나 라벨을 지우는 작업이면 먼저 확인을 묻습니다. 생성할 항목은 대기열에 들어가며, 이 대기열은 창을 닫거나 페이지를 떠나도 계속 진행됩니다. 대기 중이거나 대기열에서 실행 중인 부분은 계획에서 제외됩니다. 각 부분의 행에는 상태, 지금까지 만들어진 조각, 작업 메시지가 표시됩니다.
   모델이 부분에 라벨을 붙이는 동안에는 행에 *Labelling pieces 17-32 of 120*이 나타납니다(모델은 한 번에 조각 16개씩 질문을 받습니다). 라벨이 붙은 부분의 상태를 **클릭**하면 각 요청에 대해 모델의 추론과 답변이 도착하는 대로 볼 수 있습니다. 이 내용은 완료된 작업을 *Clear finished*로 지우거나 애플리케이션을 다시 시작할 때까지 작업과 함께 메모리에 보관됩니다.

![대기열: 지금까지 만들어진 조각, 그리고 부분이 완료되면 나타나는 다운로드](../../images/plugin-audiobook-queue.png)

부분이 만들어지는 방식은 다음과 같습니다. 무엇을 기대하면 좋을지 알아 두세요.

- 텍스트는 모델이 아니라 **프로그램이 나눕니다**. 서술 조각과 직접 대화 조각으로 나뉘며, 대화는 직선형 또는 곡선형 큰따옴표나 일본어 낫표(「 」) 사이의 글입니다. 제목은 서술로 취급합니다. 모델은 번호가 붙은 조각에 *라벨*만 붙입니다. 효과음 태그가 있는 텍스트는 태그가 추가된 조각이고 다른 것이 바뀌지 않았을 때만 사용되므로, 모델이 책의 내용을 바꿀 수는 없습니다.
- **대화를 누가 말하는지는 대화 조각에 대해 모델이 정하고, 서술은 내레이터의 몫입니다.** 편지, 쪽지, 메시지, 등장인물의 생각에는 큰따옴표가 없으므로 프로그램은 이를 서술로 봅니다. 이런 조각은 **기울임꼴로 시작할 때**(`*...*` 또는 `_..._`) 그리고 모델이 문맥(서명, "필체가 분명했다" 같은 표현)으로 등장인물을 지목할 때만 그 인물(등장인물 목록의 목소리)이 읽습니다. 등장인물의 시점에서 서술되더라도 3인칭 서술은 항상 내레이터가 읽습니다("She watched as Percy crossed the room"처럼). 프로그램은 기울임꼴이 없는 조각에 모델이 붙인 인물 지정을 무시합니다. 강조, 소리, 외래어를 위한 기울임꼴도 서술로 취급합니다. 단어는 언제나 작가님의 글 그대로입니다.
- **모델에게 주는 지시문은 바꿀 수 있는 템플릿입니다.** *Settings → Extension Settings → Audiobook Settings → Labelling prompt*가 기본값이며, 책(*Prompts* 탭 → *Extension Settings* → *Audiobook*)이나 폴더에도 자체 지시문을 둘 수 있습니다. 비워 두면 상위 폴더의 지시문을 쓰고, 그다음 작가님의 기본값, 마지막으로 내장 지시문을 씁니다. 지시문은 다른 [프롬프트](../books/prompts.md)와 같은 방식으로 씁니다. 사용할 변수는 `{{characters}}`, `{{deliveries}}`, `{{tags}}`, `{{wordsPerTag}}`이며, 힌트 팝오버에는 **Insert Default Template**이 있습니다. 지시문을 바꾸면 다음에 해당 부분을 만들 때 라벨을 다시 요청합니다.
- **부분들의 음량은 맞춰집니다.** 프로그램의 ffmpeg가 설치되어 있으면(`.m4b`를 만드는 것과 같은 ffmpeg) 모든 부분의 합쳐진 오디오가 하나의 음량으로 맞춰집니다(EBU R128, 선형 방식이므로 다이내믹은 유지됨). 기본값은 **-18 LUFS**이며, *Settings → Extension Settings → Audiobook Settings*에서 바꿀 수 있고 여기서 끌 수도 있습니다. 조각은 서버가 만든 그대로 두고, 합쳐진 부분만 음량을 맞추므로 부분이 바뀔 때 오디오 크기가 튀지 않습니다. **이전에 만든 부분**은 다시 변환하기 전까지 건드리지 않습니다. 다시 변환하면 저장된 조각에서 다시 합쳐 음량을 맞추며, 음성 서버에는 아무것도 요청하지 않습니다(언어 모델을 내리지도 않습니다). 음량 맞춤을 끄면 이미 맞춰진 부분은 그대로 남습니다. 어떤 부분에서 ffmpeg가 실패하면 그 부분은 원래 오디오를 유지하며, 결과에 그 사실이 표시됩니다.
- 한 번의 클릭으로 만들어지는 모든 부분은 **음성 모델별 배치 하나**로 처리됩니다. 배치 앞의 요청은 한 번 실행되고, 그다음 모든 조각을 읽고, 배치 뒤의 요청이 한 번 실행됩니다. 이렇게 해야 그래픽 카드가 부분마다 모델을 바꾸지 않습니다.
- 모든 조각은 **내용(텍스트, 목소리, 모델, 언어, 설정, 시드)에 따라 보관됩니다.** 이미 최신 상태인 부분은 비용이 들지 않고, 바뀐 문단만 다시 만들어지며, 실패한 부분은 **Retry**를 누르면 이미 만들어진 조각을 그대로 유지합니다.
- 조각들은 위치에 따라 달라지는 쉼으로(제목 뒤, 문단 사이, *he said* 앞) 이어 붙여져, 부분마다 mp3 파일 하나가 되고 그 부분과 함께 보관됩니다.
- 작가님의 생성 작업이 실행되는 동안에는 음성 작업이 기다리므로, 그 아래에서 언어 모델이 내려가지 않습니다.
- 스튜디오에서 **final**로 표시한 부분은 건드리지 않으며, 대화상자에 그 개수가 표시됩니다.
- **오디오북 전체**는 최신 오디오가 있는 모든 부분을 하나의 mp3로 합치고, 부분마다 챕터 표시를 붙이며, 목록 아래에 다운로드 링크를 보여 줍니다(제외된 부분은 이름으로 표시됨). 같은 파일이 *챕터 표시가 있는 mp3 하나* 내보내기 형식이기도 합니다.
- **Stop all**은 대기 중인 부분을 취소하고 실행 중인 부분을 즉시 멈춥니다. 언어 모델 요청(라벨 붙이기)이나 음성 서버 요청(읽고 있는 조각)은 기다리지 않고 버려집니다. 시작 전에 멈춘 배치는 앞선 요청을 보내지 않으므로 언어 모델이 계속 로드된 상태로 남습니다. **Download**는 완료된 부분의 mp3를 내려받게 합니다.
<a id="the-audiobook-studio"></a>

## 오디오북 스튜디오

*도구 메뉴 → **Audiobook studio*** (선택한 대사의 목소리와 미리듣기가 스피커 옆에 있습니다)는 최종 오디오북을 한 부씩 만드는 곳입니다. 스크립트를 보고, 고치고, 대사를 들어 보고, 부를 만듭니다.

![대사가 선택된 스튜디오](../../images/plugin-audiobook-studio.png)

- 부가 주석 달기 중이거나 만들어지는 중에는 무언가 진행 중임을 알리는 막대가 나타나며, 추가 작업을 시작하는 버튼은 기다립니다.
- **주석 달기**는 부의 스크립트를 만들고(요청하면 언어 모델로, 아니면 내레이터로), 대사들을 표로 보여 줍니다. 표의 열은 화자, 전달 방식, 강도, 읽을 글, 수정한 대사 표시입니다. 실행 중에는 옆에 **중지** 버튼이 나타나 언어 모델에 대한 요청을 끝냅니다.
- 대사를 선택하면 **화자**, **읽을 글**, **전달 방식**, **강도**(목소리의 과장 정도, 이를 지원하는 모델에 한함), **언어**, **시드**, **뒤 쉼**을 고칠 수 있습니다. **적용**은 변경을 유지하고 그 대사를 **잠급니다**. 새 주석 달기는 잠긴 대사를 그대로 둡니다.
  **잠금 해제**를 누르면 대사가 다시 주석 달기의 대상이 됩니다. *음성 서버가 받는 요청*에서 정확한 요청 내용을 볼 수 있습니다.
- **듣기**는 대사 하나의 오디오를 만듭니다(그 대사만, 이를 위해 음성 서버가 시작됩니다). **다른 테이크**는 새 시드로 다시 만들며, **테이크**는 보관되어 마음에 드는 것을 고를 수 있습니다(*이 테이크를 쓰고 듣기*). 좋은 목소리는 흔히 시드에 달려 있습니다.
- **이 스크립트로 부 만들기**는 대사들을 현재 상태 그대로 이어 붙입니다. 새로 주석을 달지는 않습니다.
- 부의 **상태**는 *초안*, *검토됨*, *최종* 중 하나입니다. 최종 부는 다시 주석이 달리거나 변환되지 않으며, 내보내기를 최종 부로만 제한할 수 있습니다.

<a id="exporting"></a>

## 내보내기

오디오북은 책의 *이야기 내보내기*의 한 형식입니다: **Audiobook (one mp3 per chapter, in a zip)**, **Audiobook (one mp3 with chapter marks)**, 그리고 ffmpeg이 설치되어 있을 때는 **Audiobook (one m4b with chapters)**. 이 형식들은 최신 상태인 부들의 오디오로 만들어집니다. 오디오가 없거나, 본문이나 스튜디오의 스크립트보다 오래된 오디오를 가진 부는 제외되고, 창에 그 사실이 표시됩니다. mp3 파일에는 ID3 태그(책 제목, 장, 트랙)가 들어 있고, 단일 파일에는 VLC와 대부분의 오디오북 앱이 보여 주는 장 표시가 있습니다. zip에는 재생 목록이 있습니다. 확인란 **Audiobook: only the parts marked final**을 선택하면 스튜디오에서 완료한 부로만 내보내기가 제한됩니다.

**m4b**는 Apple Books와 대부분의 휴대폰 오디오북 앱이 원하는 형식입니다. 음성에 충분한 64kbit/s AAC 오디오를 장, 제목, 저자, 장르 정보와 함께 MP4 컨테이너에 담습니다. ffmpeg이 만들기 때문에, 이 형식은 ffmpeg이 설치된 서버에서만 제공됩니다. mp3로 저장된 오디오는 이를 위해 한 번 더 인코딩되고, wav로 저장된 오디오는 한 번만 인코딩됩니다.

<a id="how-the-audio-is-stored"></a>

### 오디오 저장 방식

관리자는 *설정 → 확장 설정 → Audiobook Settings*(마지막 섹션이며 관리자만 볼 수 있음)에서 설치 전체에 적용할 방식을 고를 수 있습니다:

- **mp3**(기본값): 용량이 작고, 디코더 없이 이어 붙이며, ffmpeg이 필요 없습니다. m4b는 한 번 더 손실 압축하는 단계가 됩니다.
- **wav**: 무손실이며 용량은 약 10배(한 시간의 음성이 약 170MB)입니다. ffmpeg이 필요합니다. 부들은 음성 서버에 wav로 요청되고 wav로 이어 붙여집니다. 브라우저는 그대로 재생합니다. mp3 및 zip 내보내기는 ffmpeg이 (96kbit/s로) 인코딩하며, m4b는 한 번만 인코딩됩니다.

이 선택은 그 시점부터 만들어지는 것에 적용됩니다. 그 전에 만들어진 부는 오디오를 그대로 유지하며 있는 그대로 인식됩니다. 두 종류가 섞인 부(이전에 스튜디오에서 잠근 대사)는 wav로 이어 붙여지며, 두 종류가 섞인 부들의 내보내기도 작동하지만 ffmpeg이 필요합니다.

![오디오북 형식이 있는 내보내기 대화 상자](../../images/plugin-audiobook-export.png)

## 자동 변환

책은 부가 **최종** 상태가 되는 즉시, 스스로 그 부의 오디오를 만들 수 있습니다. 자동 주석 달기, 재초안, 번역(책에 있다면) 뒤에, [생성된 부 이후의 과정](../books/story-editor.md#what-follows-a-generated-part)의 마지막 단계로 실행됩니다(오디오가 만들어질 때까지의 실행 목록 패널에서 확인할 수 있으며, 그 **중지**를 누르면 부가 대기열에서 빠집니다). 기본값은 **끔**입니다. 책의 *프롬프트* 탭에서 확장 설정 아래 선택하거나, 책 폴더 단위로, 또는 오디오북 설정에서 모든 책에 대해 선택합니다. 가장 가까운 설정이 우선합니다:

- **아니요**,
- **예: 내레이터가 부를 읽습니다**,
- **예: 책의 모델이 화자를 표시하고, 등장인물 목록이 목소리를 정합니다**. 모델이 없는 책은 단순한 내레이션을 받으며, 그 사실이 알려집니다.

![책의 설정](../../images/plugin-audiobook-auto.png)

부는 책의 등장인물 목록과 발음 정보와 함께 대기열에 들어갑니다. 한 알림은 대기열에 들어갔다고 알려 주고, 다른 알림은 오디오가 준비되었거나 실패했다고 알려 줍니다. 이 알림은 생성을 시작한 페이지에서만 보이며, 작업은 어느 경우든 *오디오로 변환* 창에 있습니다.

<a id="listening"></a>

## 듣기

오디오가 있는 부를 가진 게시된 책(또는 리더)에는 재생 막대가 나타납니다. 재생, 일시정지, 정지, 속도, 그리고 재생 중인 부가 본문에서 표시되는 기능이 있습니다. 선택 영역이나 화면에 보이는 첫 부에서 시작하고, 부들을 순서대로 재생하며, 현재 부가 재생되는 동안 다음 부를 미리 가져옵니다. 기기의 미디어 컨트롤도 책을 인식합니다. 부의 이전 본문으로 만들어진 오디오는 제공되지 않습니다. 오디오는 책의 소유자에게, 그리고 책이 게시된 동안에는 책을 열 수 있는 모든 사람에게 제공됩니다. 게시가 취소된 책은 즉시 제공이 중단됩니다(다음 부에서 재생기가 로드될 때).

![리더의 재생기](../../images/plugin-audiobook-player.png)

<a id="a-part-without-audio"></a>

### 오디오가 없는 부

재생기는 오디오가 없는 부에서 멈추고, 이야기의 부가 건너뛰어지지 않도록 그 사실을 알립니다. [Read Aloud](tts-reader.md) 확장이 설치되어 있으면 막대에 스피커 버튼도 나타나며, 그 버튼은 **이 부(그리고 오디오가 없는 다음 부들)를 브라우저의 음성으로 읽기**라고 표시됩니다. 누르기 전에는 기계 음성으로 아무것도 읽지 않습니다. 누르면 그 부와 이어지는, 오디오가 없는 부들을 기기의 음성으로 읽고, 오디오가 있는 부에 도달하면 재생기가 다시 넘겨받습니다. 같은 청취 중 나중에 나오는, 오디오가 없는 부들도 다시 묻지 않고 같은 방식으로 읽습니다. **중지**를 누르면 음성이 멈추며, 재생기를 새로 시작하면 다시 묻습니다. 음성, 속도, 음높이는 Read Aloud의 설정을 따릅니다.

<a id="commands"></a>

## 명령

[명령](../commands/index.md)(이야기 편집기의 명령줄, 템플릿의 `command` 매크로, 에이전트)에서도 같은 일을 할 수 있습니다. 부는 변환 대화 상자가 번호를 매기는 방식대로 번호가 매겨지거나, 식별자로 지정합니다.

| 명령 | 하는 일 |
|---|---|
| `/audiobook-status [from [to]]` | 사용 중인 음성 서버, 책이 스스로 변환하는 방식, 오디오가 있는 부의 수(없음, 준비됨, 본문보다 오래됨, 스크립트보다 오래됨), 나열된 각 부의 스튜디오 상태, 그리고 대기열. 책이 길 때만 느립니다. |
| `/audiobook-convert [from [to [labelling [what [wait]]]]]` | 부들을 대기열에 넣습니다(인수가 없으면 책 전체, `from`만 주면 한 부). `labelling`이 `true`이면 책의 모델을 사용합니다. `what`은 `audio` 또는 `script`입니다(`script`는 스튜디오용 스크립트만 만들며, 아무것도 읽지 않습니다). `wait`이 `true`이면 작업이 끝날 때까지 명령이 기다리고, 진행 상황을 보여 주며 각 작업이 어떻게 끝났는지 알려 줍니다. 명령을 중지하면 아직 시작하지 않은 작업은 취소됩니다. |
| `/audiobook-stop` | 대기 중인 부들을 취소합니다. 실행 중인 부는 현재 대사를 마친 뒤 멈춥니다. |
| `/audiobook-set-part-status part status` | 스튜디오에서 `draft`, `reviewed` 또는 `final`로 설정합니다. 부에 스크립트가 있어야 합니다. |
| `/audiobook-cast` | 내레이터, 대체 화자, 그리고 등장인물 목록과 그 연기자를 보여 줍니다. |

![명령의 결과](../../images/plugin-audiobook-command.png)

오디오는 [에이전트](../agents.md)가 쓰는 숨겨진 작업용 사본이 아니라 **당신의** 책을 위해 만들어집니다. 에이전트는 등장인물 목록을 읽을 수 있지만, 다른 명령은 거부당하며 직접 실행해야 한다는 안내를 받습니다. 명령 줄에서 실행하거나, 에이전트에게 책을 준비하는 작업(주석 달기, 검토)을 맡기고 변환은 직접 하십시오.
<a id="notifications"></a>

## 알림

일괄 변환이 끝나면 브라우저가 알려 줄 수 있습니다([알림](../account.md#notifications)). 그러면 음성 서버가 작업하는 동안 탭을 떠나 있어도 됩니다. *설정* 페이지의 알림 목록에는 두 줄이 있습니다. **Convert to audio**(대화상자나 명령으로 시작한 일괄 작업)와 **Convert to audio (automatic)**(자동으로 오디오로 변환된 새 부분)입니다. 중지한 일괄 작업은 알림을 보내지 않으며, 실패한 부분이 있는 일괄 작업은 실패했다고 알려 줍니다.

![알림 목록](../../images/plugin-audiobook-notifications.png)

<a id="what-it-does-not-do-yet"></a>

## 아직 지원하지 않는 기능

- mp3와 wav만 지원합니다(opus는 지원하지 않음). 조각들의 음량은 음성이 내는 그대로입니다.
- 효과음이나 배경음은 없습니다.
- 음성 엔진은 Chatterbox 하나뿐입니다. 다른 엔진은 다음 단계에서 추가할 예정입니다.
- 세그먼트 바깥에서 목소리를 미리 듣는 기능(audition)은 없습니다.
- 출연진(cast)은 책의 *actors* 백업에 포함되지 않습니다. 복원한 책은 출연진을 유지하지만, 계정에 이미 있어야 하는 배우 이름을 가리킵니다.
