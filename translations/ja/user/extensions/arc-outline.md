# アークのアウトライン

サイドバーに表示される本の計画です。アークごとにチャプターが分かれ、それぞれの状態が示され、モデルがアークとチャプターを書くこともできます。アウトラインはストーリープロンプトの一部ではありません。ジェネレーターや[Side Query](side-query.md)は、依頼されたときにこれを利用できます。

<a id="the-arcs-tab"></a>

## 「Arcs」タブ

[ストーリーエディター](../books/story-editor.md)の左サイドバーには、*Outline*の隣に**Arcs**タブが表示されます。**Add new arc**を押すと、アークのダイアログが開きます:

| 項目 | |
|---|---|
| Title | 必須。 |
| Description | そのアークで起きること。 |
| Note (private) | 自分用のメモ。 |
| State | **Planned**、**Current**、**Finished**のいずれか。 |
| Linked part | アークまたはチャプターが属する物語の部分。[下記](#linking-to-the-story)を参照。 |

チャプターも同じ項目を持ちます。一覧では、各アークがカードとして表示され、その下に字下げされたチャプターが並びます。カードの色は状態に応じて変わります。計画中は灰色、現在のものは青、完了したものは緑で、タイトルは薄く表示されます。カードのボタンは次のとおりです:

| ボタン | |
|---|---|
| calendar / play / check | 状態。メニューを開いて変更します。 |
| chevron (arcs) | アークのチャプターを隠す、または表示します。 |
| chevron (chapters with a note) | チャプターのメモを説明の下に表示または非表示にします。ダイアログを開かずに読めます。 |
| arrows | アークまたはチャプターを上下に移動します。 |
| plus (arcs) | アークの末尾にチャプターを追加します。 |
| wand (arcs) | モデルにアークのチャプターを書かせます。[下記](#generating-chapters)を参照。 |
| thumbtack | アークまたはチャプターを、物語の中で最も目立つ部分にリンク（ピン留め）します。[下記](#linking-to-the-story)を参照。 |
| target (arcs and chapters with a linked part) | 物語を、リンクされた部分までスクロールします。 |
| pen | ダイアログで開きます。 |
| trash | アーク（その全チャプターを含む）を削除します。確認後に削除されます。 |
| robot (generated arcs and chapters) | モデルが書いた内容を表示します。[下記](#generating-an-arc)を参照。 |

上部のwandの隣には、羽根ペンのボタンがあります。現在のチャプターから次のターンの指示の下書きを作成します。[下記](#drafting-the-instructions-for-the-current-chapter)を参照。

![「Arcs」タブ：完了、現在、計画中のアーク](../../images/plugin-arcoutline-tab.png)

<a id="linking-to-the-story"></a>

### 物語へのリンク

アークまたはチャプターを**物語の一部にリンク**できます。これにより、アウトラインから本文の該当箇所へ移動できます。ダイアログには**Linked part**欄があり、アクティブなブランチ内の部分の位置を入力します。番号は*Outline*タブに表示されるものと同じく1から数えます（`#12`）。直接入力するか、その横の**link**ボタンを押すと、そのときに物語で**最も目立つ**部分を取り込めます（先に該当箇所までスクロールしてから、ダイアログを開いてください）。**target**ボタンは、欄にある部分まで物語をスクロールします。リンクされたアークやチャプターは、カード上にもtargetボタンがあります。カード上の**thumbtack**は、ダイアログを使わずにリンクボタンと同じ働きをします。チャプターの始まる位置まで物語をスクロールして押してください。リンクはブランチ内の位置を指すため、その前の部分が削除または挿入されると別の部分を指すようになります。その場合は変更してください。物語からのインポートでは、チャプターのリンクが自動で設定されます。[下記](#importing-an-arc-from-the-story)を参照。

<a id="chapter-headings-in-the-text"></a>

### 本文中のチャプター見出し

上部のwandのメニューにある**Chapter headings in the text**は、各チャプターが[リンク](#linking-to-the-story)されている部分の先頭に見出しを書き込みます。例えば`# Chapter 4: The Storm`のような見出しです。これにより物語の本文にチャプターが含まれ、Chapter Markerエクステンションやエクスポートでそれを拾えるようになります。ダイアログには、設定を変更するたびに書き込まれる見出しと、その部分が一覧で表示されます:

| 選択肢 | |
|---|---|
| Arcs get headings too | オフ：チャプターのみに見出しが付き（`#`）、アークは対象外です。オン：すべてのアークに見出しが付き（`#`）、そのチャプターはその一段下に付きます（`##`）。アーク自体がリンクされていない場合は、最初にリンクされたチャプターの部分に付きます。 |
| Prefix of the arcs / of the chapters | 数字の前に付く語。初期値は*Part*と*Chapter*です。空にすると`4. The Storm`になります。 |
| Numbers | アラビア数字（1, 2, 3）、ローマ数字（I, II, III）、または番号なし。チャプターは、リンクされているかどうかにかかわらず、アウトラインでの位置によって番号が付けられます。そのため、まだ書かれていないチャプターの番号は空いたままになります。 |
| Number the chapters from 1 in every arc | オフの場合、チャプターは本全体を通して番号が付けられます。 |
| Put the titles into the headings | オフの場合は`Chapter 4`のみになります。 |
| Remove every other heading of the story first | 新しい見出しを書き込む前に、アクティブなブランチの見出し行をすべて削除します。前回の実行後にチャプターのリンクが別の場所へ変わった場合に使います。 |
| Keep the summaries valid | 初期状態ではオンです。見出しは出来事を変えないため、変更前の物語を基にした要約は再び有効とみなされます（すでに古くなっていた要約は古いままです）。 |

**Write the headings**を押すと見出しが書き込まれます。部分が既に先頭に持っている見出しは置き換えられるため、アウトラインを変更した後にもう一度実行しても二重になりません。**Remove all headings**（確認後）は、アクティブなブランチの本文から見出し行をすべて削除します。変更されたそれぞれの部分は、古い本文を履歴に残します。リンクのない完了または現在のチャプター、およびアクティブなブランチの末尾を超えたリンクには見出しが付かず、報告されます。選択した設定は記憶されます。

<a id="the-note-of-a-chapter"></a>

### チャプターのメモ

メモのあるチャプターには、右側にシェブロンが表示されます。これを押すと、一覧の説明の下にメモが開きます。ダイアログを開かずに、チャプターの詳細（例えばモデルが書いた内容）を読めます。もう一度押すとメモが隠れます。どのメモが開いているかは保存されません。

![メモを表示したチャプター](../../images/plugin-arcoutline-note.png)

<a id="moving-chapters-between-arcs"></a>

### アーク間でのチャプターの移動

アークの最初の位置から上に移動したチャプターは、前のアークの末尾に移ります。最後の位置から下に移動したチャプターは、次のアークの先頭に移ります。矢印を押し続けると、必要なだけチャプターを移動できます。

<a id="drafting-the-instructions-for-the-current-chapter"></a>

### 現在のチャプターの指示の下書き

*Add new arc*の横にある羽根ペンのボタンは、ウィンドウを開きます。このウィンドウでモデルに、次のターンの[指示の下書き](../books/story-editor.md#drafting-the-instructions)を作らせることができます。その際、物語が今いるチャプターのデータを**Plan of the Story**として使います。現在のチャプターとは、**Current**とマークされた最初のチャプターです。そのようなチャプターがない場合は、**Finished**ではない最初のチャプターです。チャプターがまだない現在のアークは、単独で扱われます。モデルには、そのアークとチャプターを説明とメモとともに渡します。さらに次のチャプターのタイトルと説明（メモは除く）も渡し、物語がまだそこに到達してはならないという注意も伝えます。ウィンドウは、新しいターンのパネルの*Instructions*に入力された内容を指示として開始します。**Use as Instructions**を押すと、下書きがそのパネルに入り、パネルが開きます。現在のチャプターがない場合、ボタンにはその旨が表示されます。

同じデータは[Side Query](side-query.md)の情報源としても使われます。[下記](#the-outline-as-a-source-for-other-extensions)を参照。

<a id="finishing-an-arc"></a>

### アークの完了

アークを**Finished**にすると、そのすべてのチャプターも**Finished**になります。アークを別の状態に変更しても、チャプターの状態はそのまま残ります。

アウトラインは変更するとすぐに本とともに保存されるため、バックアップにも含まれます。

<a id="the-outline-as-a-source-for-other-extensions"></a>

## 他のエクステンションの情報源としてのアウトライン

アウトラインは、本に関するデータの情報源として他のエクステンションに提供されます。[Side Query](side-query.md)で、プラグのポップオーバーの**Arc outline**にチェックを入れると、質問とともにアーク、その状態、説明、チャプターを送信できます。2つのバージョンがあります。**Arc outline**は簡潔な版（説明のみ）です。**Arc outline (with notes)**は、各アークとチャプターのメモを説明の下に追加します。生成されたアークやチャプターの詳細はこのメモに入っています。非公開のメモは、2つ目を選んだ場合にのみ送信されます。3つ目の情報源である**Arc outline: current chapter**は、物語が今いるアークとチャプターだけを送信します（[現在のチャプターの指示の下書き](#drafting-the-instructions-for-the-current-chapter)を参照）。
<a id="generating-an-arc"></a>

## アークを生成する

**Add new arc** の横にある杖ボタンを押すと、三つの項目があるメニューが開きます。**Generate an arc** はモデルに新しいアークを書かせます。**Import from story** は、すでに書いた内容を要約します（[後述](#importing-an-arc-from-the-story)）。**Develop the plot** は、物語がどこへ向かうかについてモデルと対話する機能です（[後述](#developing-the-plot-in-a-conversation)）。

![杖ボタンのメニュー](../../images/plugin-arcoutline-menu.png)

 **Generate an arc** のダイアログは二つの部分に分かれています。

左側には次の項目があります：

| | |
|---|---|
| Prompt | モデルへの指示です。三つの変数があります：`{{backgroundLore}}`（本の lorebook とそのサブ lorebook の項目）、`{{existingArcs}}`（アークと章を、その状態と説明とともに。ただし非公開のメモは含みません）、`{{specification}}`。最初は *Settings → Extension Settings → Arc Outline* のプロンプト（既定のプロンプト、変更していない場合）から始まります。ここで編集した内容は、この生成にのみ適用されます。 |
| Specification | モデルに求めるアークの内容です。テーマ、登場人物、どこへ導くかなどを書きます。空でも構いません。 |
| Tools | [モデル向けのツール群](tools.md)がインストールされている場合のみ表示されます（名前や場所など）。モデルが作り物を発明する代わりに使ってよいツール群と、そのカテゴリを選びます。[ロア・ジェネレーター](lore-generator.md)と同じです。 |
| Model, Protocols | 本のモデルとプロトコル（本に設定がない場合は *Settings* の既定値）が初期値です。この生成のためだけ別のモデルを使うには変更します。その選択は保存されません。 |
| Generate | モデルを起動します。実行中、ボタンは赤い **Stop** に変わり、ダイアログの他の要素はすべて無効になります。 |

右側には、モデルが書いている途中の**推論**が表示されます。回答が始まると、提案された**アーク**も表示されます。アークは名前、簡潔な説明、そしてより長いノートからなり、アウトラインのアークと同じように（説明の下にノートがあります）、回答が流れ込むにつれて少しずつ伸びていきます。説明はアウトラインに表示される部分なので、モデルには二、三文にとどめ、詳細はノートに書くよう求めています。ノートは保存されたアークの**Note**になります。モデルの生成が終わると回答が検査されます。有効なアークでない場合（たとえばノートがないなど）、ダイアログがそれを知らせ、アークは保存できません。

![アークを生成する](../../images/plugin-arcoutline-generate-arc.png)

**Save as arc** を押すと、アークがアウトラインの末尾に追加されます。やり直すには、プロンプトまたは仕様を同じまま、あるいは変えて、もう一度 **Generate** を押します。前の回答は置き換えられます。

<a id="importing-an-arc-from-the-story"></a>

## 物語からアークを取り込む

杖ボタンのメニューにある **Import from story** は、物語の一部をモデルに読ませ、それを章を含む一つのアークとして書き出させる機能です。これにより、すでに書いた本をアウトラインに取り込めます。モデルは常に、ダイアログを開いた時点の本の[アクティブなブランチ](../books/branches-and-story-tree.md)を読みます。ダイアログはアークのものと似ていて、左側には次の選択肢があります：

| | |
|---|---|
| From message, To message | 送信する物語の範囲です。テキストのあるブランチのメッセージは1から番号が振られています。最初はブランチ全体が選ばれています。各欄の下には、それが指すメッセージの冒頭が表示されます。 |
| Number of chapters (optional) | 数字を選ぶと、ちょうどその数の章を得られます（別の数の回答は拒否されます）。空のままにすると、モデルが物語の自然な区切りで分割します。 |
| Link the chapters to the parts of the story | 最初はオンです。送信した範囲内でメッセージに1から番号が振られ、モデルは各章がどのメッセージから始まるかを示します。その章は、物語のその部分に[リンク](#linking-to-the-story)されます（ブランチ全体での番号で、範囲に関係なく正しく対応します）。アークは、最初の章が始まる部分に紐付けられます。送信されなかったメッセージを指す回答では、章はリンクされないままになります。 |
| State of the imported arc and its chapters | 最初は **Finished** です（物語は書き終えられているため）。必要な場合は **Current** または **Planned** を選びます。 |
| Token counter | 範囲にあるメッセージの数と、そのおおよそのトークン数、およびプロンプト全体（指示、ロア、アウトライン、物語）のおおよそのトークン数が、モデルが扱える量と並んで表示されます。プロンプトが収まらない場合は警告に変わるので、メッセージの数を減らしてください。範囲、章の数、プロンプト、モデルに応じて更新されます。 |
| Prompt | モデルへの指示です。変数 `{{backgroundLore}}`、`{{existingArcs}}`、`{{story}}`（範囲内のメッセージ）、`{{numberOfChapters}}` があります。最初は *Settings → Extension Settings → Arc Outline* の **Story import prompt** から始まります。 |

![物語からアークを取り込む](../../images/plugin-arcoutline-import.png)

ここにはツールはありません。名前は物語の中にあります。右側には、まず推論が、次にモデルが書いていくアークとその章が表示されます。**Save as arc** を押すと、章とともにアークがアウトラインの末尾に追加されます。各アークと章は、モデルの推論と回答をそれぞれ保持し、それぞれ専用のロボットボタンを持ちます。長い物語は、範囲ごとに一つのアークとして、数回に分けて取り込むのが最適です。
<a id="developing-the-plot-in-a-conversation"></a>

## 会話でプロットを練る

杖のメニューにある**Develop the plot**は、プロットについてモデルと話すチャットを開きます。会話をしても本の内容は変わりません。モデルはあなたが送った内容を見て返答します。合意したことは、ワンクリックでアーク生成機に渡せます。

左側では、モデルが何を見て、どのように手伝うかを選びます（選択は次回も保存されます）。右側がチャットです。

![プロットウィザード: 左側にオプション、右側に会話](../../images/plugin-arcoutline-wizard.png)

| | |
|---|---|
| Model, Protocols | 本のモデルとプロトコルから始まります。変更はこの会話にだけ適用されます。 |
| How the model helps | **Free talk**（あなたが主導）、**Explore directions**（物語が次に進みうる、互いに異なるいくつかの方向）、**Find the problems**（未解決の糸、守られていない約束、ロアとの矛盾、ペース）、または**Expand an idea**（あなたのアイデアを、前提、転換点、結末、アークの後に続く章へと発展させる）。 |
| Send the lorebook | 本のロアブックとそのサブロアブックのエントリ。 |
| Send the outline | **Not sent**、**Descriptions only**、または**With the notes**（あなた自身の非公開メモも含む）。 |
| Send the notes | [Story Notes](story-notes.md) がインストールされている場合のみ。**Not sent**、**Titles and first lines**（既定）、またはメモの**Full text**。アシスタントから隠したページは除きます。 |
| Send the summaries of the story | 生成時と同じく、最新の要約までの物語の代わりに要約を送ります。 |
| Send the latest parts of the story | 最新の要約より後のパート（要約をオフにしている場合はすべて）のうち、**Tokens of the story**に収まる最新のもの。各パートは、アウトラインでの番号とともにモデルに示されます。 |
| Tokens of the story | 物語パートのトークン数の上限。空欄の場合は、モデルが扱える量の3分の1。 |
| Prompt | モデルへの指示。変数 `{{backgroundLore}}`、`{{outline}}`、`{{notes}}`、`{{summaries}}`、`{{story}}`、`{{mode}}` を使えます。変更は保存されます。 |

オプションの下の行には、モデルが受け取る要約と物語パートの数と、リクエストがモデルの扱える量に対してどれだけのトークンを使うかが表示されます。収まらない場合は警告になります。その場合は送る量を減らすか、[チャットを要約](#chats-branches-and-summaries)してください。本はメッセージごとに読み直されるので、アウトラインや物語の変更は次の回答に反映されます。

右側がチャットです。メッセージを入力して**Send**を押します。モデルが書いている間は**Stop**になり、届いた分は残ります。各メッセージには、コピー、**branch from here**、削除のボタンがあります。モデルの回答には、さらに杖のボタン**Generate an arc from this message**もあり、そのメッセージを仕様としてアーク生成機を開きます。議論が長くなった場合は、先にモデルに決めたことを仕様としてまとめてもらってください。

<a id="letting-the-model-change-the-book"></a>

### モデルに本を変更させる

オプションの下に**What the model may do**があります。どれもチェックしなければ、チャットは単なる会話です。グループにチェックを入れると、モデルはそのためのツールを使えるようになり、あなたが頼んだときや合意したときに使えます。モデルは、追加する前に確認し、置き換えるより追加を優先し、何をしたかを報告するよう指示されています。

| グループ | モデルができること |
|---|---|
| **Planner** | [planner](../books/story-editor.md#the-planner-tab)のシーンを一覧し、追加、変更、移動、削除し、完了にマークする。 |
| **Lorebook** | ロアを検索して読み、エントリを作成し、既存のエントリを変更する（削除はしない）。 |
| **Outline** | アウトラインを読み、アークと章を追加、変更、移動する（削除はしない）。 |
| **Notes**（[Story Notes](story-notes.md)がインストールされている場合） | メモを検索して読み、リンクをたどる。あなたが何かを残すよう頼んだとき、ページを追加するか既存のページに追記する。ページ内のテキストを変更する（ページの削除はしない）。アシスタントから隠したページには届かない。 |
| **Characters**（[Character Tracker](character-tracker.md)がインストールされている場合） | 本の登場人物と関係性を読み、登場人物と関係性を追加し、変更（名前、キャッチコピー、メモ、色）し、削除する。削除だけは実行前に確認されます。変更は確認されず、チャットと Characters タブで確認できます。モデルは一覧の番号で登場人物を指定することがあります。その場合、質問とチャットには登場人物の名前が併記されます。 |
| **Generators** | アークと章の生成機を呼び出し、[Lore Generator](lore-generator.md)がインストールされている場合はロアのエントリを生成する。生成されたものは下書きとして返され、モデルに指示されない限り保存されません。モデルは下書きをあなたに見せ、合意すると保存します。 |
| **Tools**（ボタン、[tool suite](tools.md)がインストールされている場合） | 名前のツール（人名、地名）。生成機と同様に、実際の名前を提案できるようになります。 |

- **Ask me before it changes or deletes something**（既定でオン）: 既存のもの（ロアのエントリ、シーン、アーク）のテキストを変更する場合と、削除する場合は、モデルが渡そうとする内容とともに先に表示され、モデルは**Allow**または**Refuse**を待ちます。シーン、エントリ、アークの追加は確認されません。チャット、計画表、ロアブック、またはアウトラインで確認でき、削除もできます。
- モデルが呼び出したツールは、すべて回答の下に一覧されます（名前と印の行。✓は成功、✗は失敗。開くと、渡された内容と返ってきた内容が見られます）。次のメッセージには、モデルが行った呼び出しとその結果が含まれます（長い結果は切り詰められます）。そのためモデルは、すでに行ったことを把握し、同じエントリを二度作ることはありません。これらはチャットのトークン上限に含まれます。
- ツールのコスト: ツールの説明はすべてのリクエストに含まれるため、コンテキストの少ないモデルでは使える余地が減ります。関数呼び出しに対応したモデルでのみ動作します。対応していないモデルの場合は、ダイアログにその旨が表示されます。

![モデルは計画表に2つのシーンを追加した。その呼び出しは回答の下に一覧されている](../../images/plugin-arcoutline-wizard-tools.png)

<a id="chats-branches-and-summaries"></a>

### チャット、ブランチ、要約

一冊の本には任意の数のチャットを持てます。メッセージ一覧の上のリストからチャットを選び、**+**で新しいチャットを始め、ペンで名前を変更し（名前が変わるまでは最初のメッセージにちなんだ名前になります）、ゴミ箱で削除します。チャットは本とともに保存されます。

- **Branch**は、チャットをそのままの状態で新しいチャットにコピーします。メッセージのブランチボタンは、そのメッセージまでを含めてコピーし、そこから別の方向に会話を進められるようにします。コピーは、その後は元のチャットと無関係になります。
- **Summarize the chat**は、まず要約で何を残すか、何を強調するかを尋ねます（任意。例: "keep the twist about the traitor and the ending we rejected"。空欄ならモデルが決めます）。その後、モデルにチャットの要約（決めたこと、退けたこと、未解決のこと、確定した名前）を依頼し、メッセージとして追加します。以後、モデルは要約とその後のメッセージを受け取り、**その上のメッセージは受け取りません**。それらは画面に薄く表示されたまま残ります。チャットがモデルにとって長くなりすぎたときや、決定を失わずに状態をリセットしたいときに使います。後で再び要約すると、新しい要約が古い要約を含みます。チャット全体をモデルに渡し続けたい場合は、先にブランチしてください。

![要約で何を残すかを尋ねる質問](../../images/plugin-arcoutline-wizard-summarize.png)

![要約の後のチャット: 要約より上のメッセージは薄く画面に残る](../../images/plugin-arcoutline-wizard-summary.png)
<a id="generating-chapters"></a>

## 章の生成

アークの杖ボタンを押すと、そのアークを章に分けるようモデルに依頼します。ダイアログはアークのものと似ており、左側に次の項目があります:

| | |
|---|---|
| What the model knows of the story | **Whole story so far**: このアークまでのアークを、そのすべての章とともに。**Arc summaries only**: 同じアークを章なしで。**Arc summaries and finished chapters**: 同じアークを、*Finished* とマークした章だけとともに。このアークより後のアークは決して送信されません。 |
| What you want from the chapters in general | ペース、トーン、必ず起こるべきこと。空でもかまいません。 |
| Number of chapters | 言葉で書く（"about eight" のように）か、正確な数を選びます。数を指定すると、各章ごとにテキストエリアが追加され、その章に何を含めるべきかを書けます。いずれも任意です。どちらか一方を使うと、もう一方は消去されます。正確な数を指定した場合、章の数が異なる回答は拒否されます。 |
| Prompt | モデルへの指示。変数 `{{backgroundLore}}`、`{{outline}}`、`{{numberOfChapters}}`、`{{generalSpecification}}`、`{{chapterSpecification}}` を使えます。初期値は *Settings → Extension Settings → Arc Outline* の **Chapter generation prompt** です。 |

右側には、まず推論が表示され、その後に既存の章を含むアーク、そしてモデルが書いていく新しい章が表示されます。**Save as chapters** を押すと、それらの章はアークの末尾に追加されます。各章には簡潔な説明が付き、詳細はそのノートに入ります（アークと同様）。新しい章はすべて、モデルの推論と回答を保持し、それぞれ独自のロボットボタンを持ちます。

![アークの章を生成しているところ](../../images/plugin-arcoutline-generate-chapters.png)

モデルが書いたアークや章は、その元になった **reasoning**（推論）と **answer**（回答）を保持します。そこにあるロボットボタンを押すと、それらが邪魔にならない小さなポップオーバーで開きます。

![モデルが書いたアークの内容](../../images/plugin-arcoutline-generated.png)

<a id="commands"></a>

## コマンド

アウトラインとその生成機能は、コマンドラインおよび[エージェント](../commands/index.md)向けの[コマンド](../agents.md)としても提供されています。これらは開いている本に対して働きます（エージェントの場合は作業コピーに対して）。開いている Arcs タブには、変更がすぐに表示されます。アークと章は、アウトラインに表示されている通りの**番号**で指定します。最初のアークは `1`、アーク内の最初の章は `1` です（前にあるものが追加・削除・移動されると番号が変わります）。アークや章を変更するコマンドは、与えたフィールドだけを受け取ります。空のテキストを与えると、説明やノートが消去されます。

| コマンド | 何をするか |
|---|---|
| `/get-arc-outline [arc [notes]]` | アークとその章、状態、説明を JSON で返します。非公開のノートは `notes` `true` を付けた場合のみ。`arc` はそのアーク単独を返します。読み取りのみ。 |
| `/add-arc title [description [note [state [position]]]]` | アークを追加します。末尾、または `position` の位置に。 |
| `/update-arc arc [title [description [note [state]]]]` | アークを変更します。`state` は `PLANNED`、`CURRENT`、`FINISHED` のいずれかです（アークを完了にすると、その章も完了になります）。 |
| `/move-arc arc position` | アークを位置 `position` に移動します（1 が最初）。 |
| `/delete-arc arc` | アークを章ごと削除します。確認の後。 |
| `/add-outline-chapter arc title [description [note [state [position]]]]` | アークに章を追加します。 |
| `/update-outline-chapter arc chapter [title [description [note [state]]]]` | 章を変更します。 |
| `/move-outline-chapter arc chapter position [to_arc]` | 章をそのアーク内で移動するか、アーク `to_arc` に移動します。 |
| `/delete-outline-chapter arc chapter` | 章を削除します。確認の後。 |
| `/generate-arc [specification [save]]` | *Generate an arc* と同様に、モデルに新しいアークを依頼します。 |
| `/generate-outline-chapters arc [specification [count [context [save]]]]` | アークの杖ボタンと同様に、モデルにそのアークの章を依頼します。`count` は正確な章数、`context` は `EVERYTHING`（既定値）、`ARCS_ONLY`、`ARCS_AND_FINISHED` のいずれかです（*What the model knows of the story* の選択肢と同様）。 |
| `/import-arc-from-story [from [to [count [state [save [mapParts]]]]]]` | アクティブなブランチのメッセージ `from` から `to` までを要約し、章付きのアークとして依頼します（*Import from story* と同様に、テキストを持つメッセージの中で番号付け）。`state`（既定値 `FINISHED`）は保存されたアークとその章の状態です。`mapParts` `true` を付けると、各章がそれが始まるメッセージにリンクされ（ダイアログのチェックボックス *Map parts* と同様に、その章の *Linked part*）、回答には各章の部分が含まれます。 |

3 つの生成コマンドは、ダイアログと同じプロンプト（お使いの *Extension Settings → Arc Outline*、または既定値）、本のモデルとプロトコル（本にモデルがない場合は既定のモデル）を使い、ツールは使いません。名前が必要な呼び出し元は、[名前生成器](name-generator.md)または[名前プロバイダー](name-provider.md)のコマンドで名前を取得し、それを仕様に書き込みます。ダイアログと同様に、保存は要求された場合にのみ行われます。`save` `false`（既定値）を付けると、アークや章を JSON として返し、何も保存しません。`save` `true` を付けると、それらをアウトラインに追加し（アークは末尾、章はそのアークの末尾）、回答にはそれらの番号が含まれます。モデルには長すぎる物語は `/import-arc-from-story` によって拒否されます。その場合はメッセージを減らしてください。生成コマンドには時間がかかり、実行が停止されると止まります。

追加と変更は破壊的ではありません。破壊的なのは `delete` の 2 つのコマンドだけで、エージェントはこれについて確認を求めるよう設定できます。
