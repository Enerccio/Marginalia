# プロンプト履歴

モデルに実際に送られた内容と、モデルの回答を表示します。プラグインのデバッグや、通常の生成以外の処理でプロンプトに何が含まれているかの確認に使えます。

<a id="how-it-works"></a>

## 仕組み

この拡張機能は、セッション中にモデルへ送信された直近の **20 件のリクエスト** を保持します。保持するのは、送信されたメッセージ、モデルの回答、そして推論内容（プロバイダーが送ってくる場合）です。生成だけでなく、あらゆる種類のリクエストが対象です。*Settings → Extension Settings* にパネル **Prompt history** を追加し、**Show prompt history** ボタンでリストを開きます。リストは新しいリクエストほど上に並び、各項目には次の情報が表示されます。

- リクエストの**日付**
- **モデル**：AI の名前とモデル ID
- **リクエストの種類**：`generation`（新しいパート、スワイプ、再生成）、`annotate`、`summary`、`impersonate`、`redraft`、`agent`、`help`、または拡張機能独自の作業種別の名前
- ステータス（実行中、完了、キャンセル、失敗）と所要時間

リクエストを選ぶと、リストの下にあるタブで内容を読めます。**Request**（ロールごとの各メッセージ）、**推論**、**Response**（回答、モデルが呼び出した関数、失敗したリクエストのエラー）の各タブがあります。**更新** でリストを再読み込みし、**クリア** でリストを空にします。リクエストは送信された時点でリストに載ります。実行中は、モデルが書き進めるにつれて回答と推論の内容がダイアログ内で増えていきます。

![リクエストの履歴](../../images/plugin-prompt-history.png)

[エージェント](../agents.md) の場合は、そのコンソールのフッターにある **Prompt history** ボタンで、その実行のリクエストを含む同じリストを開けます。

<a id="notes"></a>

## 注意事項

- 履歴はメモリ上にのみ保持され、省メモリになるよう圧縮されています。ログアウトやサーバーの再起動で消え、バックアップには含まれません。
- ブラウザセッションごとに個別のリストがあります。エージェントのリクエストはこのリストには含まれません。実行ごとに保持され（直近 10 回の実行について、各実行 20 件まで）、その実行のコンソールから表示されます。
- メッセージは省略されずに全文が表示され、物語の本文も含まれます。
