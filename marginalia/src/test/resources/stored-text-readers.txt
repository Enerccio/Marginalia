# Files of the application that read the text of a part as it is STORED (ChatMessage.getResponse() or ChatMessage::getResponse).
#
# An extension may keep the story in another form than a model should read it (the Conlang Translator stores the speech in a constructed
# language and gives the model the English it was made from). Everything that gives the text of a part to a MODEL must take it from
# PartTextRegistry (forModel / modelText), and everything that works on the text as it is stored (the editor, the history, the offsets of the
# annotations, the hash of a summary, the search and replace, the export, the backups) keeps getResponse().
#
# StoredTextReadersTest fails for a file that reads the stored text and is not in this list, and for a file in this list that does not. When
# you add a reader: does it send the text to a model? Then use PartTextRegistry. Only then add the file here, under the right heading.
