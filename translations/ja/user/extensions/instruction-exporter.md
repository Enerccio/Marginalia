# インストラクションのエクスポーター

ストーリーの指示（シーンの設定、視点キャラクター、登場キャラクター）をクリップボードにコピーします。

<a id="how-it-works"></a>

## 仕組み

この拡張機能は、[ストーリーエディター](../books/story-editor.md)の設定メニュー（⚙）に **Export instructions** を追加します。
現在のブランチのパートを、最初のパートから物語の現在の終わりまで順にたどり、各パートの生成元になったフィールドを集めて、ひとつのテキストとしてコピーします。入力されているフィールドは、フィールド名、コロン、そして次の行に内容、の順で書かれます。パートどうしは空行で区切られ、物語の順序に並びます。

![設定メニューの Export instructions](../../images/plugin-instructionexporter.png)

```
Scene Setting:
A harbour town at dawn
POV Character:
Mara
Present Characters:
Mara, the harbourmaster
Instructions:
Mara arrives and is questioned.

Scene Setting:
...
```

空のフィールドは省かれ、何も入力されていないパートも省かれます。テキストは好きな場所に貼り付けられます。本のプロットの概要を残すため、別の本で指示を再利用するため、あるいは他の人に渡すためなどに使えます。

<a id="usage"></a>

## 使い方

設定はありません。本を開き、設定メニューから *Export instructions* を選んでください。テキストがクリップボードに入ったことを通知が知らせます。ブランチにこれらのフィールドが何も入力されていない場合は、何もコピーされず、その旨が表示されます。

エクスポートされるのは現在のブランチだけです。別のブランチを対象にするには、先にそのブランチへ切り替えてください。

!!!
ブラウザーは、ページが `https://` で開かれているか `localhost` 上にある場合にしか、クリップボードへの書き込みを許可しません。他のアドレスを平文の `http://` で開いている場合、この項目は効果がありません。
!!!
