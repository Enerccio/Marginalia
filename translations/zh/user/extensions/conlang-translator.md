# Conlang 翻译器

让你故事中的角色能够说一种人工构造的语言。你描述这门语言（它的规则和词汇），模型会为说这种语言的角色撰写**直接引语**，而故事则保留其背后的英文。

!!!
故事文本保存的是**人工语言**。所有向模型读取故事的部分（下一次生成、摘要、词条扫描、批注、其他扩展）读取的都是译出该引语所依据的**英文**，因此模型无需理解你的语言也能继续故事。点击已翻译的引语会显示英文。
!!!

!!!warning 正在进行中
该扩展可供使用此处所述界面的用户使用，也可通过[命令](#commands)供智能体使用。手机端只具备部分功能，参见[限制](#limits)。
!!!

<a id="the-idea"></a>

## 构思

1. **语言**由两部分组成：**规则**（为模型编写的文本，类似语法书）和**词典**（词汇，主要由模型撰写，并由你审定）。语言保存在你的设置中，只需保存一次，任意数量的书都可以使用它。
2. 一本**书**（或一个文件夹中的书）选择自己的语言。某个部分可以从其菜单**手动**翻译，在定稿后**自动**翻译，或**每次一个范围**地翻译。
3. 每个部分向模型发出一次请求，对每段直接引语进行分类（它是否用该语言说出，还是用故事的通用语言说出、由听者能够理解），并翻译其中属于该语言的引语。语言缺少的词由规则创造，**并附上理由**进行报告，同时作为**新增**词条加入词典，供你接受、修改、锁定或删除。
4. 英文保存在书的数据中（作为引语的*原文*），并被每个模型读取。人工语言才是原稿：你手动修改的内容会被保留，你编辑过的部分也绝不会在你不知情的情况下被覆盖。
<a id="languages"></a>

## 语言

语言在 **设置 → 扩展设置 → Conlang Translator** 中编辑，这里列出你的所有语言。

![设置中的语言](../../images/plugin-conlang-settings.png)

| 按钮 | |
|---|---|
| **新建语言** | 一种空白语言。 |
| **设计语言** | 一个[向导](#the-designer)，由模型提出新语言的每个部分，你编辑并接受。 |
| **编辑** | 所选语言的[编辑器](#the-editor)。 |
| **复制** | 一份独立的副本，带有新名称，词语也一并复制。用于尝试修改（复制也是让语言*只属于一本书*的唯一方式：选用某语言的书会与其他选用该语言的书共享它）。 |
| **比较** | 将另一种语言的变更带入所选语言，经过[审阅](#comparing-and-merging)后生效。 |
| **导出**、**导入** | 将语言保存为文档（JSON）：包括规则和词库，但不含与某本书的关联。若导入的语言与你已有的语言同名，会提供差异审阅或作为新语言导入两种选择。 |
| **删除** | 删除前会有确认提示。 |

顶部是**设计者的模型和协议**。列表下方是书和文件夹**继承**自你的设置：语言、部分是否单独翻译，以及翻译所用的模型和协议。书或文件夹可以设置自己的值，参见[选择书的语言](#choosing-the-language-of-a-book)。**保存**设置页面以保留你的更改（翻译期间新增的词语不会丢失：你未修改的语言会在保存设置页面时重新读取）。

<a id="the-editor"></a>

### 编辑器

编辑器是一个包含五个标签页的窗口；在点击**保存**之前，它都在一个副本上工作。窗口可以调整大小、拖动和最大化。

| 标签页 | |
|---|---|
| **概览** | 名称、供你自己阅读的描述、选项**连字符是词的一部分**（关闭时：`thal-orun` 与 `thalorun` 是同一个词；开启时，连字符属于词形），以及设计者所读取的**示例书**和**示例设定集**。 |
| **规则** | 以**分节**形式列出的规则（发音与拼写、语法、构词等）。每一节都注明**由谁阅读**：*翻译者*（随每个请求发送）、*仅设计者*（语言的历史、造词笔记）或*无人*（你自己的笔记）。插件不解析规则：它们只是供模型阅读的文本。 |
| **类别** | 词语的分组（*人物与社会*、*自然*、*小品词*等）。词库会按这些标题显示并发送给模型。**始终发送**的类别（小品词、代词、数词）即使词库太大无法整体发送，也会进入每个请求。 |
| **语域** | 说话的风格（*正式*、*温和*、*粗俗*、*古雅*等），并附有说明。一个概念可以为每种语域提供一个形式；模型会根据说话者与对象来选择。 |
| **词库** | 词语，见下文。 |

![语言的规则](../../images/plugin-conlang-rules.png)

<a id="the-lexicon"></a>

### 词库

![语言的词库](../../images/plugin-conlang-lexicon.png)

词表上方有**搜索**（按词或词义）、按**类别**和**状态**筛选，以及操作按钮**添加**、**编辑**、**接受**、**锁定**、**退役**、**删除**和**全部接受新词**。每个词语包含：

- **词形**（故事中的写法），可选地附上某种**文字**中的写法，以及一个**类别**和一个**种类**（词根、复合词、小品词、名称、数词、短语）；
- 一个或多个**词义**（同音词有多个，每个都带有词性和说明），以及**该概念的其他形式**（同一事物的正式、温和和粗俗用词，会一并显示和发送）；
- **依据**：模型选择该词的原因（规则或词根）。你通过它判断词语是否合适，它也会随后续请求一起发送，使下一次造词遵循相同的逻辑；
- **来源**：你自己的，或模型的（附带它为哪一部分而造、所用模型和时间）。你编辑过的模型词语会变成你的词语；
- **状态**：**新**（模型造出，你还未查看）、**已接受**、**已锁定**（模型可以使用，但不能重新定义）或**已退役**（保留，但不再提供给模型：用于已被替换的词语）。

模型需要而词库中缺少的词语**绝不会因为是新词而被丢弃**：它会立即加入，使下一部分以相同的方式表达同一意思，并以*新*状态等待。如果译文使用了词库中没有、且模型**未**报告的词语，它会被标记，因为没人能判断这个词是否有误。

<a id="names-for-the-name-generator"></a>

### 名称生成器的名称

编辑器的**名称**标签页让该语言可用于[名称生成器](name-generator.md)：它生成的名字听起来像该语言。添加一个**名称类别**（例如*地名*或*人名*），然后勾选组成它的词库词语。**搜索**和**类别筛选**可以缩小列表，**勾选所有显示项**和**取消勾选所有显示项**作用于当前显示的词语，**预览名称**会根据当前勾选的词语生成 20 个名字，无需先保存任何内容。名称生成器会在所勾选的词语上训练马尔可夫链，因此一个类别至少需要几个词（十几个或更多会得到更好的名字）。

保存的只是你的选择，而不是词语本身：你修改的词语会按当前内容读取，你删除或退役的词语在生成名字时会被排除。保存设置后，该类别会以*Conlang - 语言 - 类别*的形式出现在名称生成器中（设定集生成器及情节大纲的**工具**对话框、`generate-names` 命令、智能体的运行）。它是你个人的：安装实例的其他用户只能看到他们自己的类别。

![名称标签页：一个名称类别、组成它的词语，以及由它们生成的二十个名字](../../images/plugin-conlang-names.png)

<a id="the-designer"></a>

### 设计者

编辑器的**用 AI 设计**菜单会请求模型提供帮助，总是基于语言**当前的样子**（其规则、语域、类别、词库以及示例设定集），并且总是以**提案**的形式出现：在你审阅之前不会写入任何内容。

![设计者的菜单](../../images/plugin-conlang-designer-menu.png)

| 操作 | |
|---|---|
| **生成词语...** | 为某个类别生成若干词语，并可附上说明（例如"围城营地的厨房"）。 |
| **用 AI 添加一节...** | 为缺失的内容（数词、颜色、礼貌用语）添加一节新规则，以及它所需的词语。 |
| **重写一节...** | 模型按你的要求重写某一节。模型会返回**整节内容**，因此很长的一节会慢且费用高：请让各节保持简短，每节只讲一个主题。 |
| **审查语言** | 列出矛盾、缺漏以及破坏发音系统的词语，每项都附有所在节和修正建议。不会更改任何内容。 |
| **询问设计者...** | 一段对话；包含词语或章节的回答可以作为变更进行审阅。 |

面板中的**设计语言**是一个七步向导（概要、发音、书写、语法、构词、按类别的首批词语，以及用句子进行的测试）。每一步都是模型提出、由你编辑、用说明加以改进并接受的一节；在点击**完成**之前，该语言只存在于窗口中。

![设计语言的向导](../../images/plugin-conlang-wizard.png)

<a id="comparing-and-merging"></a>

### 比较与合并

**比较**（以及导入你已有的语言）会打开一个窗口，列出两种语言之间的差异，每一项都带有一个复选框：语言字段、规则、类别、语域、词语以及名称类别中，新增、更改、删除或移动的内容。如果双方以不同方式修改了同一处，就是**冲突**：在你选择对方的值或自己写一个新值之前，保留你的值。你的选择会写入屏幕上的语言，并在保存设置页面时存储。同一窗口也会显示设计者的提案。

![两种语言之间差异的审阅](../../images/plugin-conlang-review.png)

## 选择书的语言

书窗口的**提示词**标签页（位于*扩展设置*下）包含该扩展的字段；文件夹窗口也有相同的字段。留空表示*继承*：先看上级文件夹，再看你的用户设置。

![书的字段](../../images/plugin-conlang-book.png)

| 字段 | |
|---|---|
| **言语的语言** | 本书译成的语言。留空：本书不翻译。 |
| **单独翻译新部分** | 当某部分定稿时进行翻译：在一次生成之后、在自动注释和重写之后（如果本书有这些步骤），或作为[部分之后的后续步骤](../books/story-editor.md#what-follows-a-generated-part)之一（运行面板会显示它，其**停止**按钮可以终止它）。 |
| **翻译的模型**、**翻译的协议** | 留空：使用本书的模型和协议，否则使用你的默认值。 |
| **已发布书籍的读者所见** | [查看器](#the-viewer)所显示的内容。 |
<a id="the-conlang-tab-of-the-book"></a>

## Conlang 标签页

故事窗口有一个 **Conlang** 标签页（与章节和设定集在同一个停靠区；可随意拖动位置），用于本书的语言。它有四个子标签页，**刷新** 会在你于本书窗口中修改语言后重新读取该语言。如果一本书有[多种语言](#more-than-one-language-in-a-book)，**刷新** 旁边会有一个字段，用于选择 *词汇*、*说话者* 和 *快速翻译* 标签页针对哪一种语言。

<a id="words"></a>

### 词汇

本书语言的词典，带有搜索、筛选以及[编辑器](#the-lexicon)的操作：你写作时可以随时查词、编辑词条、接受模型新造的词，或锁定、废弃某个词。更改会立即保存到你的库中（同时期翻译新增的词不会丢失）。

<a id="speakers"></a>

### 说话者

**在本书中**谁说这种语言。说话者属于本书，而不属于语言：同一种语言在另一个故事中由其他人说，因此你复制、导出或比较某种语言时，不会带上任何角色。

默认情况下，**除列出的角色外，所有人都说这种语言**（或者反过来，只有列出的角色说）。这只是默认设置：正文可以覆盖它（“她用通用语说”“卫兵一个字也听不懂”），模型会针对每一句话作出判断。对于每个角色，你可以注明**性别**（对于区分性别的语言，若段落只写“她”，没有此信息就容易出错），以及**语气**（“正式、干脆、粗犷”），模型会据此匹配该语言的语域。更改会立即保存到本书中。

每个角色还可以设置一个**理解程度**：*完全听不懂*、*只懂几个词*、*大致能懂*或*全部能懂*。留空（或选择*全部能懂*）则不会告知模型任何信息。这适用于那些听得到这种语言却不会说的人，例如：*Tomáš：完全听不懂*，*其他村民：大致能懂*（名字只是文本，因此也可以写一个群体）。这些级别在整本书中是**固定不变的**，作为信息交给模型；角色如何对待它，由模型决定，你也随时可以在指令中补充说明（“Tomáš 听不懂他们在说什么”）。它们通过两种方式传达给模型：**故事模型**会收到一条简短消息，列出这些级别（像作者注释一样插入到提示词中；列表上方的复选框可关闭此功能，旁边的数字表示从末尾数起第几条消息开始插入）；而**审阅段落的模型**（*用 AI 批注*）会将其作为事实部分的一节获得这些信息，从而能够标记出对听不懂的话作出反应的角色。如果你希望自己安排这段文字的位置，可以关闭自动插入，并在模板中使用 {%{`{{command::conlang-understanding}}`}%} [宏](../templates/macros.md#commands)；它接受一个可选的角色列表，用于只保留指定角色。

![Conlang 标签页：说话者，以及两个听不懂该语言的角色](../../images/plugin-conlang-tab.png)

<a id="languages"></a>

### 语言

本书除 **“语言”字段**（即该字段指定的*言语语言*）之外的其他语言。参见[一本书中的多种语言](#more-than-one-language-in-a-book)。

<a id="quick-translate"></a>

### 快速翻译

输入一段英文（一个短语、一个名字、一句你还没写出的台词），可选择填写谁说、对谁说，然后点击**翻译**：模型会依照本书的规则、语域、词汇以及正文中提到的角色的注释，将其翻译为本书语言。结果不会写入故事中。输出包括译文、一条关于选择的说明，以及译文中**所需但词汇表中缺少的词**，每个词附有其释义和原因；勾选你想要的词，然后点击**导入所选词汇**：它们会以*新*词的身份进入词汇表，与已翻译段落中的词相同。译文中既不在词汇表中、也未被报告的词，会以警告形式列出。

<a id="more-than-one-language-in-a-book"></a>

## 一本书中的多种语言

一部史诗可能为精灵准备一种语言，为矮人准备另一种，再为兽人准备第三种。本书首先指定**一种主语言**（即上方的字段，文件夹或你的设置也可能提供该值），而 **Conlang** 标签页中的**语言**子标签页可以从你的库中逐个添加**其他语言**，也可以再将其移除。

- **每种语言都有自己的说话者。** *说话者*标签页针对上方字段所选的语言。主语言照旧由除你所列角色外的所有人说；**你新添加的语言默认为“仅列出的角色说这种语言”，且初始没有任何角色**，因此在你列出说话者之前，系统不会就此询问任何内容。如果某个角色的母语是另一种语言，请将其作为主语言的例外列出，否则系统也会询问该角色的言语是否属于主语言（同时被两种语言认领的言语归于先被询问的那一种）。一个角色可以说多种语言（将其列入两种语言的说话者中；段落的正文会告诉模型某段言语使用的是哪一种语言）。
- **每种语言一次请求。** 每次请求只包含一种语言的规则和词汇，并且只包含该语言说话者的言语；如果一个段落中同时有两种语言的言语，则会依次发出两次请求。第二次请求会读取经过第一次翻译后、其中第一种语言的言语已保留为英文的段落，并保持那些言语已翻译的状态。若一个段落的视角人物和在场角色都不在某种语言的说话者之列，则不会为该语言发出请求（若段落中没有提及任何角色，则会为每一种有说话者的语言发出请求）。
- **段落知道自己的语言。** 弹出窗口、导出和查看器的工作方式与之前相同；**翻译对话（人造语言）**针对某一种语言进行时，会保留其他语言的言语不变，而**还原为英文**既可以针对某一种语言，也可以针对所有语言。
- **当一本书有多种语言时，菜单会询问使用哪种语言。** 段落的菜单（*翻译对话（人造语言）*：选择其中一种语言或*所有语言*）以及对选中句子的右键菜单（针对一种语言）都会如此。**翻译段落（人造语言）**有一个*语言*字段（默认为所有语言）；*未翻译的段落*指“在该语言中未被翻译的段落”。
- **自动运行**会将新段落翻译为每一种可能有其说话者出现在其中的语言。
<a id="translating"></a>

## 翻译

- **手动翻译：**某个部分的菜单中有 **Translate** 子菜单（在文本上右键单击也有此菜单），其中有 **Translate dialogs (constructed language)**（这些项目以及 **Translate parts** 仅在带有本插件语言的书籍中显示）。已翻译的部分会**根据其英文原文**重新翻译，因此在规则或词典更改后，这也是重新翻译某个部分的方法。拥有多种语言的书籍会先询问[使用哪一种](#more-than-one-language-in-a-book)。
- **自动翻译：**启用 **Translate a new part by itself** 后，生成的部分一经定稿即会被自动翻译。对某个部分进行*重新生成*时，它会获得新的英文，旧的译文会被删除。
- **模型遗漏的对话：**翻译有时会让某句对话保持英文。某个部分菜单中的 **Translate → Translate missing dialogs (constructed language)** 只翻译仍为英文的对话，已翻译的对话保持不变；若选中了文本，右键菜单 **Translate → Translate missing dialogs in selection (constructed language)** 则只处理选区所涉及的对话。发送给模型的是该部分的原样内容（包括已翻译的对话），模型只需处理仍为英文的对话，因此比翻译整个部分更省成本。此功能只写入对话，因此不适用于模型未视为对话的句子：请改用 *Translate selected text*。
- **你写的一句话：**在某个部分的文本中选中该句，右键单击并选择 **Translate → Translate selected text (constructed language)**。模型会结合所选语言、人物备注以及周围的故事内容翻译所选文本（首尾的空格和引号不计入）。文本会被译文替换，英文则保留为该对话的源文，因此点击对话即可像其他已翻译对话一样显示英文。模型为此新造的词会以*新词*的形式加入词典，与翻译部分时相同。若选区包含已翻译的对话，会被拒绝（请先恢复英文）；若所在部分在此期间已被更改，同样会被拒绝。
- **范围翻译：**故事工具菜单中的 **Translate parts (constructed language)** 会打开一个窗口，该窗口会保持在故事旁边打开。

  ![Translate parts](../../images/plugin-conlang-range.png)

  选择 **From part** 和 **To part**（只计有文本的部分，从 1 开始计数，与导出时一致），并选择要执行的操作：*Translate the parts that are not translated*、*Translate the translated parts again*（在规则或词典更改后使用）或 *Put the English back*（会先询问确认）。窗口会显示该范围包含多少个部分、操作涉及多少个部分，并显示 *Part n of m*，以及一个 **Stop** 按钮。点击 **Stop** 会在当前正在处理的部分完成后生效（已发出的模型请求无法撤回）。处理失败的部分会被计数，任务继续进行；缺少语言或模型则会终止任务。任务结束后，故事会重新绘制。若在任务运行期间编辑某个部分，只会使该部分失败，不影响整个任务。

译文的保存与文本的任何其他更改相同：该部分的历史记录会新增一个版本，该部分**不会被标记为已编辑**，英文原文也会保留。**你手动更改过的对话在重新翻译或恢复为英文时会保持不变**，因为其中包含你的文字。

!!!
翻译所需时间取决于模型处理该部分的时间：在会进行思考的本地模型上可能需要数分钟。本扩展会要求模型进行思考（这样对性别、数和语域的翻译效果好得多），因此请为模型设置较大的输出上限。
!!!

<a id="what-the-reader-sees"></a>

## 读者看到的内容

<a id="in-the-story"></a>

### 在故事中

已翻译的对话带有**虚线**。点击它会在弹出框中显示英文：说话者是谁，以及当听者不懂该语言时显示 *(not understood by the listener)*；若你在翻译后编辑过语言文本，会显示一条红色提示，说明英文可能已与现在的内容不符。

**Edit the source**（弹出框中的按钮，仅在你自己的视图中可见；已发布书籍的读者看不到）会打开一个小窗口，其中显示故事中当前的译文以及模型所读取的英文。当母语者手动修正了译文而英文已不符，或模型对英文理解有误时，请使用此功能。保存后，该对话会获得新的英文，并将当前的译文确认为英文所对应的译文（红色提示随之消失），此后模型将读取新的英文。部分的文本不会改变，而再次执行 *Translate dialogs (constructed language)* 会同时替换二者。`conlang-edit-source` 可从命令行执行相同操作。

![The window that edits the source of a speech](../../images/plugin-conlang-source.png)

**在源文中搜索和替换**（Conlang 标签页顶部带箭头的按钮）会打开应用程序的搜索和替换窗口，作用于当前分支中已翻译对话的英文源文（可使用纯文本或正则表达式，可区分或不区分大小写；表格按部分和对话编号列出有匹配的对话）。用于修正英文中同一名字拼写不一致的情况。此功能只更改源文；若要更改译文本身，请使用书籍的搜索和替换。搜索之后源文已被更改的对话将保持不变，并被计数。

![Search and replace over the English sources of the speeches](../../images/plugin-conlang-search-replace.png)

![The English behind a translated speech](../../images/plugin-conlang-story.png)

<a id="the-viewer"></a>

### 查看器

[已发布书籍](../books/publishing.md)的查看器会按书籍的设置显示已翻译的对话，该设置位于字段 **Readers of the published book see** 中（可选择书籍或其文件夹；你个人的默认设置从不决定读者看到的内容）：

| | |
|---|---|
| **The conlang, the English on a click** | 默认设置。点击（手机上为轻触）时弹出英文。 |
| **The conlang only** | 英文永远不会发送到读者的浏览器。 |
| **The English only** | 书籍如同从未被翻译过一样显示。 |

在点击模式下，页面只包含语言文本；读者点击某句对话时，才会从服务器获取其英文。

![The English behind a translated speech, in the viewer](../../images/plugin-conlang-viewer.png)

<a id="exporting"></a>

## 导出

当书籍包含已翻译的对话时，[导出](../books/export.md)对话框中会出现字段 **Translated speech**：

![The export dialog](../../images/plugin-conlang-export.png)

| | |
|---|---|
| **The conlang, as it is** | 默认：按存储时的原样导出文本。 |
| **The English only** | 对话被替换为其英文。 |
| **The conlang, the English in footnotes** | 每句已翻译的对话都会附带一条脚注，内容为英文（及说话者）。 |
| **The English, the conlang in footnotes** | 与上面相反。 |

这些脚注即[导出的脚注](../books/export.md#footnotes)：HTML 和 EPUB 中为带链接的注释，纯文本中为每个部分之后的尾注，Word 和 PDF 中则为页面底部的真正脚注。若某句对话在翻译后被你编辑过，它将保持原样，且没有脚注。导出操作绝不会更改书籍中存储的文本。
<a id="commands"></a>

## 命令

应用的所有界面操作也都是一条命令，可用于[命令行](../commands/index.md)，也可供[智能体](../agents.md)调用：智能体可以创建语言、扩充语言、翻译整本书并检查结果，而无需人工操作对话框。语言通过其**名称**（不区分大小写）或 id 指定；规则章节通过标题或其在 `conlang-list-rules` 中的编号指定；类别通过名称或编号指定；词条通过其形式指定（仅当需要区分同音词时，才使用 `conlang-list-words` 的 id）；分部（part）的写法与应用中其他命令相同，即用其句柄或其在当前分支上的位置指定（第一部分为 1）。命令行接受某命令的全部参数；智能体可以省略可选参数。

| 命令 | |
|---|---|
| `conlang-list`、`conlang-get`、`conlang-create`、`conlang-duplicate`、`conlang-update`、`conlang-delete`、`conlang-export`、`conlang-import`、`conlang-set-references` | 语言库。`conlang-delete` 会询问用户，且智能体不可用。 |

| `conlang-set-book-language` | 打开的书所用的语言（其 *Extension Settings* 中的 **Language of the speech** 字段）。 |
| `conlang-add-book-language`、`conlang-remove-book-language` | 打开的书所用的其他语言。删除会询问用户，且智能体不可用。 |

| `conlang-status` | 书的语言，以及哪些分部已翻译。 |
| `conlang-translate-part`、`conlang-translate-range`、`conlang-translate-sentence`、`conlang-translate-text`、`conlang-revert-to-source` | 翻译：一个分部（`missingOnly` 只翻译仍为英文的话语，`within` 引用一段文字以限定范围）、一个范围（`mode` 为 *new* 或 *again*）、分部中的一句话、仅返回结果而不写入的文本，以及恢复英文原文。范围翻译和恢复英文原文都会请求用户确认 *again*。可选参数 `language` 指定书中的某一种语言（默认为全部；句子和文本默认为第一种）。 |

<a id="agent-runs"></a>

### 智能体运行

智能体在书的**副本**上工作，而语言不属于书的一部分，因此智能体无法在你不知情的情况下改动你的语言库。运行中第一次**修改**某种语言（修改词条、规则，或翻译时新增的词）时，该语言会连同它被复制时的版本一起复制进书的副本；此后，本次运行读写的是它自己的副本。只读的运行，或只使用现有词汇进行翻译的运行，从不复制任何内容。该副本随书的副本一同存在：检查点及其恢复、本次运行的审查以及删除，都作用于它。

当你**应用**运行的结果时，语言会进入书中，**而不是你的语言库**。书的 **Conlang** 标签页随后会显示 *An agent run changed the language ...*，并提供 **Review** 和 **Drop** 按钮。
Review 会比较三个版本：运行复制该语言时的版本、运行产生的版本，以及你现在的语言库版本。因此，你在此期间对语言库所做的改动会被保留；若你们双方都改动了同一处，则形成冲突，由你决定。通过命令同样可以完成：`conlang-pending-changes` 以编号列出这些更改，`conlang-take-pending-changes` 接收它们（会询问用户确认）。运行新建的语言，在你确认后会整体加入。

运行在首次修改某种语言之前读取语言库；之后则读取它自己的副本。因此，你在运行进行期间对语言所做的修改，运行看不到，但也不会丢失。

<a id="limits"></a>

## 限制

- **质量取决于模型。** 扩展会免费检查其能检查的内容（引用的话语是否在分部中、语言是否正确、词是否与词库及复合词和词缀规则相符），并报告其余问题；它不检查你的语法。在长时间运行前，先在几个分部上试用语言，并在同一错误反复出现时使用设计器的 **Review the language**。
- **语言由使用它的多本书共享。** 你修改的词，或翻译添加的词，会对该系列的每本书都生效。这是有意为之（一个世界观），如需将语言分开，请使用 **Duplicate**。
- **智能体对语言的修改会先保留在书中。** 运行应用之后，由你将其纳入语言库；运行进行期间，语言不会被锁定。
- **命令不会替换故事中的文字**，重新翻译也无法保留英文未变的译文（范围内的每个分部都会重新请求翻译）。
- **手机端**提供面板、编辑器、审查和向导，但词库表格需横向滚动；在查看器中点按话语可以正常使用；故事一侧的功能（分部菜单、范围窗口、点击故事）未在手机上测试。
