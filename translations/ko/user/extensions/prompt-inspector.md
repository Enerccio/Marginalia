# 프롬프트 검사기

생성 요청이 모델로 전송되기 직전의 프롬프트를 보여 주고, 전송할지 묻습니다.

<a id="how-it-works"></a>

## 작동 방식

이 확장 기능은 [스토리 편집기](../books/story-editor.md)의 설정 메뉴(⚙)에 있는 *분석* 그룹에 **Inspect prompt before sending**을 추가합니다. 체크 박스 항목이며, 선택하면 검사가 켜지고 다시 선택하면 꺼집니다. 이 선택은 사용자 설정이므로 모든 책에 적용됩니다.

검사가 켜져 있으면 생성(새 부분, 스와이프, 재생성)은 요청 직전에 멈추고 **Send this prompt to the model?** 대화 상자를 엽니다. 여기에 표시되는 텍스트는 다른 모든 확장 기능이 프롬프트를 바꾼 뒤의, 모델이 실제로 받게 될 프롬프트입니다. 각 메시지는 역할별로 나뉘어 표시됩니다. `[SYSTEM]`(템플릿, 로어, 요약), 이야기의 앞부분이 `[USER]`와 `[ASSISTANT]` 메시지로, 그리고 마지막 턴의 지시문이 나옵니다. 함께 보내는 이미지는 해당 메시지의 끝에서 계산됩니다.

![모델로 보내기 전의 프롬프트](../../images/plugin-prompt-inspector.png)

- **Send**를 누르면 요청이 전송되고 생성은 평소처럼 진행됩니다.
- **Cancel**을 누르면 생성이 중단됩니다. 이 생성을 위해 시작된 부분은 다시 제거됩니다(재생성된 부분은 원래 텍스트를 되돌려 받습니다). 텍스트가 도착하기 전에 생성이 실패했을 때와 같습니다.

<a id="notes"></a>

## 참고

- 프롬프트는 다른 생성과 마찬가지로 먼저 만들어지고, 요청 직전 마지막 단계에서 확인을 받습니다. 요약이 유효하지 않게 되었다면, 요약 없이 계속할지에 대한 평소의 질문이 프롬프트를 보여 주기 전에 나옵니다. 답하기 전에는 모델에 어떤 요청도 보내지 않습니다.
- 스토리 편집기에서 시작된 생성만 보류됩니다. [에이전트](../agents.md)와 명령은 프롬프트를 보여 줄 페이지가 없으므로, 그 생성은 묻지 않고 진행됩니다.
- 대화 상자는 이동하고 크기를 조절할 수 있으며, 텍스트를 선택해 복사할 수도 있습니다. 반드시 응답해야 합니다. Esc 키와 바깥쪽 클릭으로는 닫히지 않습니다. 대화 상자가 열린 상태에서 페이지를 닫으면 *Cancel*로 간주됩니다. 서버가 페이지가 사라졌음을 알아채는 즉시 생성이 중단되고 아무것도 전송되지 않습니다(이에는 시간이 조금 걸릴 수 있습니다).
- 다른 사용자에게는 묻지 않으며, 페이지를 새로 고쳐도 이 설정은 유지됩니다.
