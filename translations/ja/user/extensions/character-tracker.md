# キャラクタートラッカー

サイドバーに表示される、作品の登場人物の一覧です。各キャラクターにはキャッチコピー、メモ、アイコン、色を設定でき、キャラクター同士の関係と、その関係を示す地図も確認できます。

<a id="the-characters-tab"></a>

## Charactersタブ

[ストーリーエディター](../books/story-editor.md)の左サイドバーには、*アウトライン*の隣に**Characters**タブが追加されます。一覧の上には一行のボタンが並んでおり、**追加**（新しいキャラクターを作成）、ロアブックのエントリーをインポートするメニュー、**Relationship map**、そしてプロンプト用の吹き出しボタン（ホバーすると名前が表示されます）があります。

吹き出しボタンを押すと、[作者メモ](authors-note.md)と同様に、**In prompt**、**Depth**、役割を設定するポップオーバーが開きます。キャラクターがプロンプトに含まれている間、このボタンは緑色になります。*In prompt*にチェックを入れると、生成のたびにキャラクターがメッセージとして送られます。各キャラクターは、名前、キャッチコピー（括弧付き）、メモを並べた一行として、さらに関係の一覧（`Mara -> Tomas: employs`のように表示し、双方向の場合は`<->`）として含まれます。*Depth*は、そのメッセージより後にあるメッセージの数です（`0`は最後尾、つまりあなたの指示より後、`1`はその直前）。役割は*System*、*Assistant*、*User*から選べます。このテキストは作品のストーリー用のトークン枠を使います。キャラクターが一人もいない場合は何も挿入されません。設定は作品と一緒に保存されます。

その間にある杖のボタンには、**Import lore entries as characters**というメニュー項目があり、詳しくは[下記](#importing-characters-from-the-lorebook)を参照してください。

一覧は名前順に並びます。各キャラクターにはそれぞれ異なる色が付き、**名前**の下に小さめの文字で**キャッチコピー**が表示されます（最大二行）。キャラクターごとのボタンは次のとおりです。

| ボタン | |
|---|---|
| シェブロン | キャラクターを展開し、**アイコン**と**メモ**を表示します。 |
| ペン | キャラクターをダイアログで開きます。 |
| ゴミ箱 | 確認のあと、キャラクターとそのすべての関係を削除します。 |

キャラクターは変更するとすぐに作品と一緒に保存されるので、バックアップにも含まれます。

![Charactersタブ](../../images/plugin-charactertracker-tab.png)

<a id="picking-characters-for-a-turn"></a>

## ターンの登場人物を選ぶ

[新しいターン](../books/story-editor.md)のフォームには、**POV character**と**Present characters**の欄があります。どちらも自由入力ですが、末尾には人の形のアイコンのボタンがあり、作品のキャラクターを名前順に一覧表示します。**POV character**の一覧で選んだ名前は、欄の内容を置き換えます。**Present characters**の一覧で選んだ名前は、まだ入っていなければ、カンマを挟んで末尾に追加されます。一覧は開いたときに読み込まれるので、少し前に追加したキャラクターも含まれます。一覧にない名前を直接入力することもでき、欄の名前が作品のキャラクターである必要はありません。

<a id="the-character-dialog"></a>

## キャラクターのダイアログ

**追加**（プラス記号のボタンで、ツールチップは*Add new character*）とペンのボタンは、同じダイアログを開きます。

| 欄 | |
|---|---|
| **Name** | 必須です。 |
| **Tagline** | キャラクターについての短い説明で、一覧と地図に表示されます。 |
| **Note** | 覚えておきたいことを自由に書けます。 |
| **Icon** | PNG、JPEG、GIFをアップロードできます。最大200 x 200ピクセルに縮小され、縦横比は保たれます。 |
| **Color** | 一覧と地図でのキャラクターの背景色です。 |

各欄の内容は**保存**で反映されます。

![関係を持つキャラクター](../../images/plugin-charactertracker-dialog.png)

保存していない変更がある状態で**キャンセル**（またはEsc）を押すと、まだ追加していない関係の入力も含めて、破棄するかどうかを確認されます。

![未保存の変更があるキャラクターをキャンセルしたときの確認](../../images/plugin-charactertracker-unsaved.png)

<a id="relationships"></a>

### 関係

既存のキャラクターを開くと、ダイアログにはそのキャラクターの関係も表示されます。キャラクターが指す関係（`→`）、そのキャラクターを指す関係（`←`）、一方向ではない関係（`↔`）があり、それぞれに名前とキャッチコピーが付いています。ゴミ箱のボタンで関係を削除できます。

関係を追加するには、相手のキャラクターを検索し、**Direction**（*this character → other*、*other → this character*、*both ways*）を選び、**Name**（例：*employs*、*friends*）を入力し、必要に応じて**Tagline**を入力してから、**Add relationship**を押します（ボタンはこれらの欄の上にあります）。関係はすぐに保存されます。新しいキャラクターは、保存したあとに関係を持てるようになります。

<a id="importing-characters-from-the-lorebook"></a>

## ロアブックからキャラクターをインポートする

登場人物がすでにロアブックにある場合は、杖のメニューからまとめて作成できます。**Import lore entries as characters**を選ぶと、作品のロアブックとそのすべてのサブロアブックのエントリーが、*order*順に並んだダイアログが開きます。各エントリーには名前とチェックボックスがあり、**i**アイコンを押すとエントリーの内容がポップオーバーで表示されるので、決める前に素早く確認できます。一覧の見出しにあるチェックボックスで、すべてのエントリーをまとめてチェックまたは解除できます。**Import**を押すと、チェックされたエントリーの名前ごとにキャラクターが作成されます（キャッチコピー、メモ、アイコン、色は空のままなので、後から入力します）。**Close**を押すと、インポートせずに終わります。

エントリーは既存のキャラクターと照合されません。同じエントリーを二度インポートすると、キャラクターが二つ作成されます。

![ロアブックからのキャラクターのインポート](../../images/plugin-charactertracker-import.png)

<a id="the-relationship-map"></a>

## 関係マップ

**Relationship map**は、作品のすべての関係をグラフとして表示します。関係を持つキャラクターはそれぞれ、その色の上にアイコン（アイコンがなければ箱）を載せた円として表示され、名前とキャッチコピーが付きます。関係はそれぞれ二人のキャラクターを結ぶ矢印で、名前とキャッチコピーが付きます。矢印は指し先を示し、一方向ではない関係は両端に矢印が付きます。関係のないキャラクターは地図に表示されません。

![関係マップ](../../images/plugin-charactertracker-map.png)

キャラクターは、一人のキャラクターを中心とした同心円状に配置されます。最初の中心は、関係が最も多いキャラクターです。その中心と関係があるキャラクターが第一の円に、そのキャラクターたちと関係があるキャラクターが第二の円に、というように並びます。**キャラクターをダブルクリック**すると、そのキャラクターを中心に地図を並べ直します。キャラクターをドラッグしたり、地図を動かしたり、マウスホイールでズームしたりすることもできます。

<a id="commands"></a>

## コマンド

キャラクターは、コマンドライン用と[エージェント](../commands/index.md)用の[コマンド](../agents.md)としても使えます。これらは開いている作品に対して動作します（エージェントの場合は作業用のコピーに対して）。開いているCharactersタブには、変更がすぐに反映されます。キャラクターは**名前**で指定します（大文字と小文字は区別しません）。同じ名前のキャラクターが複数いる場合は、`/list-characters`で表示される番号（名前の順番）で指定します。関係は`/list-character-relations`で表示される番号で指定します。キャラクターを変更するコマンドは、指定した欄だけを変更します。空の文字列を指定すると、キャッチコピーやメモが消去されます。アイコンはダイアログからしか設定できません。

| コマンド | 内容 |
|---|---|
| `/list-characters` | キャラクターを名前順に表示します。キャッチコピー、色、メモの有無、関係の数を含みます。読み取りのみ。 |
| `/get-character character` | キャラクター一人のメモと関係を表示します。読み取りのみ。 |
| `/create-character name [tagline [note [color]]]` | キャラクターを追加します。`color`は`#rrggbb`の形式です。 |
| `/update-character character [name [tagline [note [color]]]]` | キャラクターを変更します。 |
| `/delete-character character` | 確認のあと、キャラクターとその関係を削除します。 |
| `/list-character-relations [character]` | 関係を表示します。キャラクターを指定すると、そのキャラクターの関係だけを表示します。読み取りのみ。 |
| `/add-character-relation source target name [tagline [bidirectional]]` | `source`から`target`への関係（*employs*）を追加します。`bidirectional`に`true`を指定すると、双方向の関係（*friends*）を追加します。 |
| `/update-character-relation relationship [name [tagline]]` | 関係の名前またはキャッチコピーを変更します。 |
| `/delete-character-relation relationship` | 確認のあと、関係を削除します。 |
| `/character-tracker-map` | キャラクターとその関係を、プロンプトが受け取るテキストとして表示します。読み取りのみ。 |

`character-tracker-map`は[{%{`{{command::character-tracker-map}}`}%}マクロ](../templates/macros.md#commands)のために作られています。マスターテンプレート、ユーザープロンプト、またはロアブックのエントリーに入れると、Charactersタブによる自動挿入の代わりに（または自動挿入に加えて）、キャラクターを好きな位置に配置できます。自動挿入がオンかどうかに関係なく、常にキャラクターの現在の状態を反映します。

追加と変更は元に戻せない操作ではありません。取り消しが難しいのは`delete`コマンドだけで、エージェントにはこれらについて確認を求める設定をすることができます。

<a id="phone"></a>

## スマートフォン

このタブは、[作者メモ](authors-note.md)と同様に、アウトラインの隣にある、ストーリーのドロワーの中にあります。POVキャラクターと登場キャラクターのボタンは、スマートフォンの新しいターンのフォームにもあります。
