# アカウントと設定

Marginalia で作成したものはすべてあなたのアカウントに属します。本、ロアブック、タグ、推論プロバイダー、プロトコル、設定などが対象です。他のユーザーには（[公開](books/publishing.md)した本を除き）見えず、あなたも他のユーザーのものは見られません。

<a id="your-account"></a>

## あなたのアカウント

ワークスペースの下部にあるボタンです。

| ボタン | |
|---|---|
| **Language** | ユーザーインターフェースの言語です。[言語](#language)を参照してください。 |
| 太陽／月のボタン | 言語の隣にあり、ダークテーマとライトテーマを切り替えます。[テーマ](#theme)を参照してください。 |
| **Change Password** | パスワード、ユーザー名、氏名を変更します。下記を参照してください。 |
| **Logout** | この端末からログアウトします。 |
| **Admin** | 管理者のみが使用できます。[管理](administration/index.md)を参照してください。 |

<a id="changing-the-password"></a>

### パスワードの変更

**Change Password** を押すと、**Username**、**Full Name**、**Current Password**、**Password**、**Repeat password** を入力するダイアログが開きます。

- 変更のたびに**現在のパスワード**を入力してください（アカウントにパスワードがない場合は空欄のままにします）。
- パスワードを変更するには、新しいパスワードを両方のパスワード欄に入力します。
- 名前だけを変更してパスワードはそのままにする場合は、両方のパスワード欄を空欄にします。
- **Log out everywhere else（他のブラウザと保存されたすべてのログイン情報からログアウト）** にチェックを入れると、パスワードを変更せずに、他のすべての端末でアカウントをログアウトさせられます。下記を参照してください。
- ユーザー名は、他のアカウントが使用中のものにはできません。

**OK** を押して保存します。現在のパスワードが間違っている場合は、何も保存されません。

パスワードを変更すると、保存されているすべてのログイン情報（*Save login*）が終了します。この端末を含むすべての端末で、新しいパスワードで再度ログインする必要があります。また、今開いている他のセッション（別の端末で開いているワークスペースのブラウザ）も終了します。作業中のセッションだけが継続されます。端末を紛失した場合やパスワードが漏えいした場合は、パスワードを変更することで、その端末からもログアウトされます。

**Log out everywhere else** は、新しいパスワードを設定せずに同じことを行います。アカウントに保存されているすべてのログイン情報が忘れられ、開いている他のすべてのセッションが終了します。たとえば自分の端末ではないコンピューターでログインしたままにしてしまった場合に使ってください。このダイアログの他の変更と同様に、現在のパスワードが必要です。いま作業しているセッションは残りますが、その保存されたログイン情報も忘れられるため、このブラウザでは次回もパスワードを求められます。

<a id="language"></a>

### 言語

ボタンの上にある **Language** の選択欄で、ユーザーインターフェースを別の言語に切り替えられます。選択内容はアカウントに保存されます。ページは新しい言語で再読み込みされ、開いているほかのすべてのページ（他の端末のものも含む）も同様に再読み込みされます。次回ログインした際にもこの言語が使われます。ログイン画面は常に既定の言語で表示されます。

一覧に表示されるのは、インストール済みの言語だけです。英語、日本語、フランス語、スペイン語、ドイツ語、韓国語、イタリア語は Marginalia に同梱されています。管理者は[拡張機能](extensions/index.md)を読み込むことで言語を追加できます。例として[中国語の翻訳](extensions/chinese-localization.md)があります。翻訳されていない文言は英語で表示されます。同梱の拡張機能は、日本語、中国語、フランス語、スペイン語、ドイツ語、韓国語、イタリア語の文言を含みます（中国語の文言は中国語の翻訳を読み込んだときに表示されます）。日付は、その言語の書き方で表示されます。本とその本文は翻訳されず、インターフェースだけが翻訳されます。

![言語の選択欄](../images/language-selector.png)

![日本語で表示されたワークスペース](../images/ui-japanese.png)

<a id="theme"></a>

### テーマ

**Language** の選択欄の隣にあるボタンで、ユーザーインターフェースをダークテーマ（既定）とライトテーマで切り替えます。選択内容はアカウントに保存され、次回ログインした際に、どの端末でも使われます。別のタブで開いているページは、再読み込みすると切り替わります。グラフと関係図は、開いたときにテーマの色を使います。

![ライトテーマのワークスペース](../images/theme-light.png)

<a id="logging-in"></a>

### ログイン

ログイン画面の **Save login** を選ぶと、この端末では30日間ログインしたままになります（サーバーでは HTTPS が必要です。[Server (Docker)](getting-started/docker-server.md#https-and-reverse-proxy)を参照してください）。**Logout** を押すと終了します。

アカウントにはパスワードを設定しないこともできます。その場合はユーザー名だけでログインします。管理者があなたのパスワードを忘れた場合に消去したときも、この方法でログインし、すぐに **Change Password** で新しいパスワードを設定してください。これは自分のコンピューターのデスクトップアプリでは便利ですが、他の人がアクセスできるサーバーでは決して行わないでください。

<a id="settings"></a>

## 設定

**Settings** タブには、すべての本に共通する既定値があります。

![Settings タブ](../images/settings-defaults.png)

上部には3つのボタンがあります。

- **バックアップを新しい本としてインポート** - バックアップファイルから本を作成します。[本のバックアップ](books/backups.md#importing-a-backup-as-a-new-book)を参照してください。
- **変更を破棄** - 保存されていない変更を捨て、保存済みの設定を読み込み直します。
- **保存** - 設定を保存します。

!!!info 未保存の変更
設定は自動では保存されません。いずれかの項目を変更すると（拡張機能の設定も含みます）、上部に *Unsaved changes* が表示され、他のタブ、**Admin**、**Logout** が使えなくなります。**保存**または**変更を破棄**を押すと、ロックが解除されます。
!!!

<a id="prompt-language"></a>

#### プロンプトの言語

**Prompt language** は組み込みプロンプトの言語を選びます。空のフィールドが何を表すか（別の言語を選ぶとグレーの文字がすぐに変わります）、そして生成、要約、書き直し、注釈、代筆のためにモデルへ送られる内容がこれで決まります。[プラグイン](templates/index.md)のうち独自のプロンプトを持つもの（Arc Outline、Beta Readers、Book Description Generator、Lore Generator、Manga Generator、SillyTavern Converter、Knowledge Tracker、Audiobook）と、エージェントのプロンプトもこれに従います。アプリの表示言語とは独立しているので、アプリを英語で使いながら日本語のプロンプトを送ることもできます。モデルは物語の言語で書かれた指示に最もよく従うので、本を書いている言語を選んでください。変わるのは組み込みプロンプトだけです。ここでも、本やフォルダでも、自分で書いたプロンプトはそのまま残ります。[エージェント](agents.md)は、この設定ではなく、エージェントの設定（エージェントの *Language*）で決まった言語でプロンプトと通知を読みます。

これらの既定値は、**自分のフィールドが空であるすべての本**にすぐ適用されます。新しい本だけではありません。自分の *Prompts* タブで値を設定した本はそのまま残ります。つまり:

- すべての本に共通する設定はここで行います。
- ある本だけの特別な設定は、その本の *Prompts* タブで行います。
- 本のフィールドを空にすると、*Settings* の既定値に戻ります。

<a id="styles"></a>

### スタイル

本の文体です。パートのテキストが物語の中や読者に対してどう見えるかを決めます。タブには、アプリが用意し変更できない **Normal** と **Book** のスタイル（*built in* と表示されます）と、あなた自身のスタイルが並びます。リストでスタイルを選ぶと、右側で編集できます。リストの下のボタン:

- **Duplicate** - 選択したスタイルから自分のスタイルを作ります（組み込みのものからも作れます。これが始め方です）。名前は *... (copy)* になり、後で名前を変えたり内容を変えたりできます。
- **Delete** - 自分のスタイルを削除します。組み込みのスタイルは削除できません。
- **Set as default** - そのスタイルを、本が別のものを[選ばない](books/story-editor.md#text-styles)限り使われる既定のスタイルにします。既定のスタイルはリストで *default* と表示されます。
- **Export** と **Import** - 選択したスタイルを `.style.json` ファイルとして保存します。また、そのようなファイルのスタイルを自分のスタイルに追加します（設定を保存するまで保存されません）。[スタイルを共有する](books/styling-guide.md#share-a-style-export-and-import) を参照してください。

[文体ガイド](books/styling-guide.md)では、すべての項目を順に説明し、ダウンロードできる例のスタイルも用意しています。

![選択された文体ガイドのホラースタイルが表示されたスタイルタブ](../images/settings-styles.png)

自分のスタイルの場合、右側のフォームには **Name**、**For exports (not offered for books)** のチェックボックス、そして二つのタブがあります。スタイルは本用かエクスポート用のどちらかです。エクスポート用のスタイルは[エクスポートの画面](books/export.md#print-styles)で選べ（アプリには HTML、EPUB、PDF、Word のエクスポートの見た目が四つ用意されています）、本の既定のスタイルにはできません。本用のスタイルはエクスポートの画面には表示されません。リストでは *(export)* と表示されます。

- **Options** - グループ別に並んでいます。*Text*（フォント、サイズ、行の高さ、文字と単語の間隔、色、配置、ハイフネーション、段落の間隔、段落の **first line indent**（字下げ）、見出しの後の **drop cap**（ドロップキャップ））、*Page*（本文の幅、中央揃え、テキストの後ろ全体を埋める **background color**（背景色））、*Emphasis, links and code*（斜体と太字とリンクの色、コードのフォント）、*Quotes*、*Headings*（フォント、第一レベルのサイズ、色、配置、スモールキャップス）、そして *Scene break*（`---`）の記号と色です。入力欄には任意の CSS の値（`1.1rem`、`#336699`、`var(--lumo-body-text-color)` など）を書けます。空の欄はアプリの見た目のままです。フォントの欄には一般的なフォントの並びが用意されており、自分で書くこともできます。
- **Custom CSS** - 自分で書く CSS です。オプションの後に追加され、スタイルの中でだけ適用されるので、ここに書くルールはこのスタイルのテキストだけに働きます。`.chat-message-markdown p { text-indent: 1.5em !important; }` は段落を字下げし、`font-size: 1.2rem;` のような単純な宣言は、テキスト全体に適用されます。その下の **Generated CSS** には、オプションから作られたスタイルシートが表示されます（読み取り専用）。波括弧 `{ }` は対応していなければならず、対応していないとスタイルは保存されません。

![スタイルの Custom CSS タブ](../images/settings-styles-css.png)

フォームの下の **Preview** には、そのスタイルで表示したサンプルのテキストが出ます。入力するたびに変更が反映されます。

ほかのタブと同様に、スタイルタブも設定の **Save** で保存されます。**Discard Changes** はスタイルの変更も破棄します。複製、編集、削除、既定の設定は作業中のコピーだけを変えるので、どれかを行うと *Unsaved changes*（とロック）が表示されます。名前がないスタイル、または波括弧が対応していない Custom CSS は、保存時に受け付けられません。
<a id="exports"></a>

### エクスポート

各ファイル形式をどのように書き出すかの設定です。タブには、設定できる項目がある形式ごとにセクションがあります（**Plain text**、**Markdown**、**HTML**、**Word**、**PDF**、**EPUB**、**Markdown with front matter**、**Obsidian vault**。名前をクリックすると開きます）。

- **Print style**（HTML、Word、PDF、EPUB。フォントや色を持つ形式）- [書き出しダイアログ](books/export.md)でその形式に最初に選ばれているスタイルです。初期値は、その形式についてアプリケーションが用意している見た目（**HTML page**、**PDF book**など）です。一覧には、[書き出し用スタイル](#styles)の組み込みのものと、あなたが作ったものが並びます。別のスタイルを選ぶと、ダイアログで一回ごとに変更しない限り、その形式は毎回そのスタイルで書き出されます。
- **Front matter**（Markdown with front matter と Obsidian vault）- ファイルの先頭に置く YAML ブロックです。`{{title}}`、`{{author}}`、`{{language}}`、`{{exportDate}}` を使えます。空欄の場合は既定のブロックになります。
- **Title page**（他のツール向けの形式を除くすべての形式。Obsidian vault は本のノートに持っています）- 扉ページのテンプレートです。Markdown を書き出す Handlebars テンプレートで、`{{title}}` と `{{author}}` を使えます（欄の情報アイコンに一覧があります）。空欄の場合は既定のものになり、タイトルを見出しとして、その下に著者名を斜体で置きます。情報ポップオーバーの **Fill default** を押すと、既定の内容から始められます。
- **Authorship statement**（SillyTavern chat を除くすべての形式）- 書き出しの **執筆の内訳を含める** のチェックボックスを付けたときに、末尾へ加える文章です。使える変数は `{{title}}`、`{{author}}`、`{{totalWords}}`、`{{writtenWords}}`、`{{generatedWords}}`、`{{writtenPercent}}`、`{{generatedPercent}}`、`{{models}}` です（`{{models}}` はモデル名をカンマで区切ったもので、モデルがない場合は空になります）。空欄の場合は既定の文章になります。

これらはあなたの版です。本やフォルダーにはそれぞれ独自の版を持たせることができます。詳しくは [Title page template](books/export.md#title-page-template) を参照してください。このタブは設定の **Save** で保存され、**Discard Changes** で変更が破棄されます。他のタブと同じです。テンプレートが正しくない場合は、保存時に拒否されます。Styles タブで作ったスタイルは、保存後にここで選べるようになります。

![HTML セクションを開いた Exports タブ](../images/settings-exports.png)

<a id="tags"></a>

### タグ

あなたのすべてのタグ（本、ロアブック、ロアブックのエントリーに付けたもの）を、それぞれが関連づいているオブジェクトの数とともに一覧にした表です。列の見出しをクリックすると、その列で並べ替えます。他のタブと違い、すぐに反映されます。未保存の変更の対象ではなく、保存するものもありません。

![Tags タブ](../images/settings-tags.png)

| ボタン | |
|---|---|
| **Rename**（鉛筆）| タグの新しい名前を尋ねます。関連するすべてのオブジェクトは、新しい名前のタグを持つようになります。 |
| **Delete**（ゴミ箱）| 確認を求めたあと、タグを削除し、それを持つすべてのオブジェクトから取り除きます。 |

新しい名前が別のタグの名前と同じ場合（名前は大文字と小文字を区別せずに比べます）、名前を変えると二つのタグが同じになってしまうため、**merge**（統合）するかどうかを尋ねられます。統合すると、名前を変えるタグが付いていたものはすべて既存のタグに移され、名前を変えたタグは削除されます。両方が付いていたオブジェクトは、既存のタグが一度だけ付いた状態になります。キャンセルすると何も変わらず、タグは元の名前のままです。

![二つのタグを統合するかどうかの確認](../images/tag-merge.png)

### キーボードショートカット

[ストーリーエディターのショートカット](books/story-editor.md#keyboard-shortcuts)のキーです（コンピューターのストーリーエディターで使えます。[スマートフォン向けレイアウト](phone.md)にはありません）。
この表には、すべてのアクションを、[拡張機能](extensions/index.md)が追加するものも含めて、そのキーとともに載せています。また、書籍一覧の [Organise](books/folders.md#organise) ウィンドウのボタンのキーも載っています。ストーリーの設定メニュー、パートのメニュー、そのテキストの右クリックメニューのすべての項目は、ここではアクションになっています（多くは、あなたがキーを割り当てるまでキーがありません）。メニューには、項目の横にキーが表示されます。

| ボタン | |
|---|---|
| **Record** | 新しいキーの組み合わせを押します（修飾キーを先に、または同時に押します。例：`Ctrl+Shift+K`）。他の場所をクリックするとキャンセルされます。 |
| **Reset to default** | アクションを既定のキーに戻します。 |
| **Clear** | アクションからキーを外します。 |

赤い注記は、二つのアクションが同じキーを共有している場合、ブラウザーが自分用に確保しているキー（`Ctrl+N`、`Ctrl+T`、`Ctrl+W` など。ページには届きません）、そして `Alt` と文字の組み合わせ（一部のキーボード、たとえば macOS では文字を入力してしまいます）を示します。`Ctrl`、`Alt`、`Meta` のないキーは、テキスト欄にフォーカスがないときだけ働きます。キーは他の設定と同じく **Save** で保存され、開いているストーリーにはすぐに反映されます。

### 通知

モデルの処理が終わったときに、ブラウザーのデスクトップ通知を出します。そのため、処理中にタブを離れることができます。このタブには、チェックボックス **Use desktop notifications**、以下のボタン、そして通知の対象となる項目の一覧があります。

- **Story generation**、**Annotate with AI**、**Annotate with AI (automatic)**、**Redraft**、**Redraft (automatic)**、**Draft Instructions**、**Summary**、**Resummarize all summaries**、**Help assistant**、そして[拡張機能](extensions/index.md)が追加するもの（拡張機能の名前がつきます。例：*Reviewer: generate a review*、*Lore Generator: generate lore*、*Image Generator: generate the image*、*Arc Outline: generate chapters*など）。*Manga Generator* の項目のうち *(automatic)* と付いたものは、その連続モードです。
- *(automatic)* と付いた項目は、本が自分で始める実行です。生成のあとの[自動注釈](books/story-editor.md)と、それに続く書き直しです。あなたが自分で開くダイアログとは別に選びます。**Annotate with AI** にチェックが入っていて **Annotate with AI (automatic)** が入っていなければ、自動注釈は通知しません。自動の項目だけにチェックが入っていれば、通知するのは自動注釈だけです。
- エラーで終わった実行（*… failed*）も通知します。自分で止めた実行は通知しません。

チェックボックスをオンにすると、あなたのアカウントで通知が有効になり、二つのボタンが使えるようになります。**Register this browser** を押すと、ブラウザーに許可を求めます（この操作によってのみ求められます）。ボタンの下の行には、このブラウザーの状態が表示されます。許可済み、ブロック中（ブラウザーのサイト設定で許可してください）、または未確認、のいずれかです。この許可はアカウントではなく、ブラウザーに属します。通知を受け取りたいブラウザーや機器は、それぞれ一度ずつ登録が必要です。チェックボックスと一覧はどこでも同じです。**Send a test notification** を押すと、すぐに一つ表示されます。ページが前面にあるときでも表示されます。

**Filter** 欄は名前で一覧を絞り込みます。**Check shown** と **Uncheck shown** は、表示されている項目だけに働き、それ以外の項目はそのままです。通知は、あなたがページを見ていないとき（別のタブにいる、またはウィンドウが前面にない）にだけ表示されます。通知をクリックすると、ページが前面に戻ります。

通知には `https://` のアドレスか `localhost` が必要です。ネットワーク内のサーバーの平文の `http://` アドレスでは、ブラウザーは通知を提供せず、タブにその旨が表示されます。ブラウザーがスリープさせたタブ（多くはスマートフォン）でも通知は表示できません。このタブは、他のタブと同じく、設定の **Save** で保存されます。
