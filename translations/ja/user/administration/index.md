# 管理

管理者はMarginaliaのインストールを管理します。具体的には、ユーザーアカウント、データベースのバックアップ、削除済みデータのクリーンアップ、
アップデート、拡張機能です。[初回起動](../getting-started/first-start.md)時に作成される最初のアカウントは管理者であり、
ほかのユーザーを管理者に指定することもできます。

管理者も通常のユーザーであり、自分の本を持っています。ほかのユーザーの本、ロアブック、設定は見えません。見えるのは、それらのユーザーが全員と共有しているロアブックとプロトコルだけです。

<a id="the-admin-page"></a>

## 管理ページ

管理者はワークスペースの下部に**管理**ボタンがあります。[スマートフォン向けレイアウト](../phone.md#administration)（幅768ピクセル未満のウィンドウ）では、ドロワーのタブ**管理**になります。管理ページが開き、次のタブがあります。

| タブ | |
|---|---|
| **ユーザー** | アカウントの作成、編集、削除、ユーザーへの[権限](permissions.md)の付与。[ユーザー](users.md)を参照。 |
| **データベースのバックアップ** | データベース全体のバックアップ（手動またはスケジュール）と復元。[データベースのバックアップ](database-backups.md)を参照。 |
| **クリーンアップ** | 削除済みデータを完全に削除します。[クリーンアップ](cleanup.md)を参照。 |
| **リソースファイル** | もう使われていないリソースのファイルを探し、ZIPとしてダウンロードしたうえで、ディスクから削除します。[リソースファイル](resource-files.md)を参照。 |
| **ヘルプアシスタント** | マニュアルの内容に答えるチャットです。モデル、プロンプト、その費用の負担者を設定します。[ヘルプアシスタント](help-assistant.md)を参照。 |
| **エージェント** | エージェントが、自分にもユーザーにも独自のものがない場合に従うシステムプロンプトとコンパクションプロンプトです。空欄の場合は組み込みのプロンプトが使われます。情報アイコンにある**既定のテンプレートを挿入**を押すと、それが入力されるので、コピーを編集できます。ユーザーがエージェントに対して何をしてよいかは、その[権限](permissions.md)で決まります。また、**エージェントがユーザーのWebhookへメッセージを送ることを許可する**もあります。これをオンにすると、エージェントが必要とし、ユーザーがアプリを閉じている場合に、サーバーがユーザーの設定に入力されたアドレスを呼び出します（[不在時](../agents.md#when-you-are-not-there)を参照）。許容できない場合はオフにしてください。 |
| **統計** | [執筆統計](../books/statistics.md)を記録するかどうか、保存期間、ユーザー単位または全体での統計の消去。[統計](statistics.md)を参照。 |
| **ジョブ** | 外部のAIに依頼されたことすべての記録（誰が、いつ、どの呼び出しを、どう終わったか）、古いエントリを手動で削除するフィルター、そして現在実行中のジョブを表示するページ`/jobs`です。[ジョブ](jobs.md)を参照。 |
| **アップデート** | Dockerサーバーの場合：実行中のバージョン、サーバーが追従するブランチの最新バージョン、そしてMarginaliaを更新して再起動するボタン。[アップデート](updates.md)を参照。 |
| **拡張機能** | 拡張機能のインストールと削除。[拡張機能の管理](extensions.md)を参照。 |

## データフォルダー

Marginaliaが保存するものはすべて、実行するユーザーのホームディレクトリにある`.marginalia`フォルダーにあります（[Dockerでの構成](../getting-started/docker-server.md)の場合はホスト上の`./data`）。

| パス | |
|---|---|
| `marginalia.sqlite`（`-wal`、`-shm`を伴う） | データベース。ユーザー、本、ロアブック、設定などすべてが入っています。 |
| `secret.key` | データベース内のAPIキーを暗号化する鍵。最初の起動時に作成され、所有者のみが読み取れます（LinuxとmacOS）。これがないと、保存されたAPIキーを読み取れません。コンピューターの他のユーザーが読み取れる場合、ログにその旨が出力されます：`chmod 600 secret.key`。 |
| `db-backups/` | [データベースのバックアップ](database-backups.md)。 |
| `data/<login>/backups/manuscripts/<book id>/` | 各ユーザーの[本のバックアップ](../books/backups.md)。 |
| `extensions/` | インストール済みの[拡張機能](extensions.md)のJARファイル。 |
| `update/` | MarginaliaとDockerサーバーの[アップデートウォッチャー](updates.md#setting-up-the-watcher)がやり取りするファイル：状態、直近のアップデートのログ、要求。 |
| `agent-workspaces/<agent id>/` | [エージェント](../agents.md#the-working-copy)のファイル（実行をまたいで保持されるメモとレポート）。 |
| `agent-runs/<run id>/` | エージェントの実行が保持するもの：変更を表示するための本の開始時点（作業コピーとともに削除されます）、チェックポイント、所見（クリーンアップで実行が消去されると削除されます）。 |
| `desktop/logs/` | [デスクトップアプリ](../getting-started/desktop-app.md)のログ。 |

インストール全体をバックアップするには、Marginaliaを停止して、このフォルダー（`secret.key`を含む）をコピーします。実行中は、データベースについては[データベースのバックアップ](database-backups.md)を使ってください。本のバックアップと拡張機能は普通のファイルなので、いつでもコピーできます。
