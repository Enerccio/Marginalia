# 帮助助手

帮助助手是一个聊天窗口，它根据手册回答有关 Marginalia 的问题。管理员选择它使用的模型，并在可以使用它的用户的[权限](permissions.md)中授予 **Help assistant** 权限（管理员始终可以使用）；这些用户无需自己的模型。在引入权限之前就已存在的用户，如果当时助手已开启，则会获得该权限；新用户则没有该权限。

用户获得使用权限后，会在窗口右下角看到一个圆形的机器人按钮。点击它即可打开聊天窗口；面板会显示由哪个模型作答，并在适用用户的额度限制时发出警告（参见 [谁来付费](#who-pays)）。模型会在手册中查找答案（它可以搜索手册并阅读其页面），将所引用的页面列为指向[已发布手册](https://enerccio.github.io/Marginalia/)的链接（在新标签页中打开），并作出解释：它不会更改任何内容，除非用户允许，否则也看不到用户的书籍（参见 [你的书籍](#your-books)）。出现故障时，它还能查看问题所在（参见 [出错时](#when-something-goes-wrong)），并且在你允许的情况下，可以带用户前往相应位置（参见 [指路](#showing-the-way)）。对话会保留到用户退出登录为止（关闭面板或重新加载页面都不会清除），点击扫帚按钮可清空对话。当手册已翻译为用户界面所用的语言时，它会以该语言阅读手册，链接也指向该语言的手册；未翻译的页面则以英文阅读。

![帮助助手回答问题](../../images/help-assistant.png)

用户打开 Marginalia 时会出现该按钮，而模型和额度警告则在每次打开面板时读取；如果你收回该权限或删除模型，已打开该页面的用户在重新加载页面（或打开面板）后将失去该按钮。

<a id="settings"></a>

## 设置

打开 **Admin → Help assistant**：

![Help assistant 标签页](../../images/admin-help-assistant.png)

| 设置 | |
|---|---|
| **Model** | 你*自己的*[模型](../inference-providers.md)之一，可以共享给用户，也可以不共享。其他管理员共享的模型不会出现在列表中。 |
| **Allow reading administration data** | 允许助手*在管理员提出请求时*读取扩展的状态和日志、数据库备份以及管理页面上的其他数据，参见[管理数据](#administration-data)。默认关闭。 |
| **Prompt for administrators**、**Prompt for other users** | 模型在每次提问时收到的指令；参见[提示词](#prompts)。 |

有两项设置取决于用户，位于该用户的 **Help assistant** [权限](permissions.md#settings-of-a-permission)中（在 **Admin → Users** 中点击钥匙按钮即可打开；两项默认均关闭）：

| 权限的设置 | |
|---|---|
| **Apply limits** | 仅适用于共享模型，参见[谁来付费](#who-pays)。 |
| **Allow navigating the interface** | 当用户要求助手指出某些内容的位置时，允许它打开某个部分、选择某个标签页，或打开用于添加内容的对话框，参见[指路](#showing-the-way)。 |

没有此类权限的管理员，两项均按关闭处理。

设置通过 **Save** 保存。助手向模型发出请求时不使用[协议](../protocols.md)，因此模型自身的设置仍然适用。当模型被删除，或其所有者不再是管理员时，助手会自动停止工作，这样属于普通用户的模型就不会被分享给所有人。

<a id="what-the-assistant-sees-of-the-screen"></a>

## 助手能看到的屏幕内容

模型可以查看用户当前正在做什么（当问题涉及"这里"或"这个"时，它会被告知要去查看）：哪个部分、标签页或对话框处于打开状态，并为屏幕的每个部分提供简短描述，例如所打开书籍的标题及其打开的标签页，或打开的对话框标题。未打开的标签页只会列出，只有在问题需要时才会读取。对于打开的表单，它还能获知当前的问题所在：表单标记为无效的字段及其显示的信息，未填写的必填字段，以及表单对多个字段之间进行的检查（对于模型，即响应必须小于上下文）。它只能获得字段的*名称*，永远不会获得在字段中输入的内容。它永远不会获得故事正文、词条正文、API 密钥或密码。

![助手解释为何新模型的表单暂时无法保存](../../images/help-assistant-form.png)

<a id="your-books"></a>

## 你的书籍

助手面板中有一个复选框 **Let the assistant look at my books**，默认关闭，由每位用户自行设置（保存在其个人设置中）。复选框下方的提示说明了它的含义：助手会读取书籍的文件夹名称、标题、描述和写作设置，并搜索其文本，但永远不会读取故事正文；所读取的内容会发送给负责回答的 AI，即你在上面选择的模型，因此如果该模型是你无法控制的外部服务，请告知用户。

![助手面板中书籍的复选框](../../images/help-assistant-books.png)

开启后，模型将获得三个函数，均为只读，且只针对提问用户自己的书籍：

| 函数 | |
|---|---|
| `list_folder` | 某个文件夹的子文件夹（每个子文件夹下的书籍数量），以及其中书籍的标题和描述。像 `Sci-fi/Expanse` 这样的路径指定某个文件夹，不指定则为顶层。 |
| `search_books` | 按标题或描述中的词语，或按故事正文，查找书籍，可选择限定在某个文件夹内（"我那本关于真正恋人的书在哪里？"）。它会说明匹配内容所在的位置及所在文件夹；找到的文本不会返回。 |
| `get_book_settings` | 书籍的语言、视角、时态和风格，以及每项设置的来源（书籍本身、文件夹、用户设置或内置默认值）。提示词只会以*自定义文本*或*内置文本*的形式告知，并说明其来源。 |

它不能更改、移动或创建任何内容。列表会被截断（最多一百项，匹配最多二十条），描述也会被缩短。

<a id="when-something-goes-wrong"></a>

## 出错时

当用户说某件事失败了（"我遇到错误""没有保存""模型不回答"）时，助手可以读取 Marginalia 向用户显示过的内容：最近的错误、发往模型提供方的失败请求（密钥错误、模型不存在、达到额度上限、超时……）、警告，以及未能保存的表单的提示信息，按从新到旧排列，并附上每项发生于多久以前。它会解释消息的含义以及该如何修正；对于打开的表单，它会指出应修改哪些字段。

以下内容会被记录，记录位置如下：

* 用户在通知中看到的所有错误或警告，以及未通过验证的表单信息，都会在本次会话中保留（最近 20 条）；
* 意外故障（即弹出堆栈跟踪对话框的故障）和发往提供方的失败请求，同样会由浏览器标签页保留（最近 3 条，存放于其会话存储中），因此在页面重新加载或会话过期后仍然可以查看。

助手获得的是用户所见的文本，对于故障，还包括异常的名称和消息，但不包括堆栈跟踪。每段文本都会截断至 400 个字符，看起来像密钥、令牌或密码的内容会被删除；不过，消息文本中仍可能包含提供方或系统返回的部分内容，例如提供方对某次请求的回应。负责作答的是你所选择的模型，它可能是外部提供方：在[选择模型](#settings)时请记住这一点。
<a id="showing-the-way"></a>

## 通过界面引导

在用户权限中开启 **允许浏览界面**后，当用户提出请求时（"告诉我词条书在哪里"、"带我去备份"、"怎么添加模型？"），助手可以在窗口内完成以下操作：打开某个区域（书籍、词条书、设置等）、打开管理页面（仅管理员可见）、切换到设置、管理页面或故事编辑器中的某个标签页，或者点击按钮打开添加书籍、模型或协议的对话框。对话框只会打开，在用户填写并确认之前不会创建任何内容；如果已有其他对话框处于打开状态，则不会提供此操作。完成操作后，助手会告知用户它做了什么。

除此之外，它不能做任何其他事情：不会点击其他按钮、不输入文字、不保存、不删除、不生成内容、不关闭对话框，也不会退出登录。用户无法打开的内容，助手也无法代为打开。助手不会主动移动，只在被请求时才会移动。若导航已被锁定（打开的区域有未保存的更改，或正在生成一本书），助手也无法移动。

![助手应用户要求打开了"数据库备份"标签页](../../images/help-assistant-navigate.png)

开启此功能后，模型还会获知屏幕上各元素的名称及其功能，这与 [助手能看到的屏幕内容](#what-the-assistant-sees-of-the-screen) 中的信息性质相同。

<a id="administration-data"></a>

## 管理数据

在开启 **允许读取管理数据** 后，助手可以为请求帮助的管理员读取管理页面的数据（"为什么 Side Query 不工作？"、"最近一次备份是什么时候？"）。对其他任何人都不开放：普通用户无论设置如何都无法获取这些数据，并且每次读取时都会重新检查权限。

| 主题 | 读取的内容 |
|---|---|
| 扩展 | 每个已安装的[扩展](../extensions/index.md)，包括版本、是否处于启用状态、是否被您手动停止或启动失败，以及其验证结果 |
| 扩展日志 | 其日志的最后若干行（默认 40 行，最多 200 行），与 **管理 → 扩展 → 日志** 中显示的内容相同 |
| 用户 | 用户总数、管理员数量以及被锁定的用户数量；不包括用户名 |
| 数据库备份 | 数据库大小、备份数量及最新备份的时间、备份计划，以及是否有待执行的恢复 |
| 清理 | [清理](cleanup.md)将会删除的内容（实际上不会删除任何东西），以及阻止清理的因素 |
| 应用 | Java 版本、内存占用以及应用已运行的时长 |

这些数据仅供读取：助手无法在此处启动、停止或删除任何内容。请注意，所有这些数据都会发送给负责回答的模型，该模型可能来自外部服务商；另外，扩展日志中可能包含扩展自身写入的文本（每条日志行会被截断至 400 个字符，密钥、令牌和密码会被移除，但除此之外不做其他处理）。因此，该设置默认关闭，需要您手动开启。

<a id="prompts"></a>

## 提示词

提示词有两份：一份供管理员使用（管理员可以询问管理页面相关问题），另一份供其他所有人使用（他们会被告知管理功能仅限管理员）。两份提示词均预先填入默认内容；修改文本并保存后即可生效，点击 **恢复为默认值** 可以还原默认内容。如果提示词为空或与默认内容相同，则会被存储为"默认"，因此它会随着 Marginalia 新版本的发布而自动改进；而您修改过的提示词则由您自行负责保持更新。

提示词中的 `{{manualIndex}}` 会被替换为手册页面列表（包括路径、标题及每页的主题简介），模型正是借此得知自己可以阅读哪些页面。如果省略它，模型就只能通过搜索来查找页面。请保留要求模型在手册中查找信息的指令，以及在手册未涵盖某个问题时明确说明的指令，否则回答的可靠性会降低。读取错误、在界面中导航以及读取管理数据这几类工具的使用规则，由 Marginalia 自动添加到提示词中（您无需在提示词中保留这些内容），并且仅针对已获授权的工具添加。

<a id="who-pays"></a>

## 费用由谁承担

用户从不会看到模型或其 API 密钥；他们的提问均通过应用程序完成。

| 模型 | 用户权限中的 **应用限额** | 结果 |
|---|---|---|
| 共享 | 开启 | 提问与对共享模型发出的其他请求一样：会检查您为该用户设置的[限额](../inference-providers.md#limits-of-shared-providers)，并将消耗的令牌计入该用户的用量。若用户已达到限额（或无权使用该模型），则不会获得回答。 |
| 共享 | 关闭 | 由模型的所有者承担费用。用户的限额被忽略，不会为该用户计入任何用量。 |
| 非共享 | （无影响） | 由模型的所有者承担费用：没有限额，也不会为用户计入用量。该模型仅供助手使用。 |

您自己的提问也按相同方式计算，对您而言，该模型只是另一个普通模型。
