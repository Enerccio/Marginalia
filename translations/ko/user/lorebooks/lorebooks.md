# 로어북 만들기

<a id="the-lorebook-editor"></a>

## 로어북 편집기

**Lorebooks** 탭을 엽니다. 편집기는 한 번에 로어북 하나를 보여 주며, 상단의 **Lorebook** 필드에서 편집할 로어북을 고릅니다.
로어북은 사용자의 계정에 속합니다. 다른 사용자는 [공유](#sharing-a-lorebook)한 로어북만 볼 수 있습니다.

도구 모음은 두 줄로 되어 있으며, 창이 좁으면 더 많은 줄로 나뉩니다. 첫 번째 줄은 로어북용 버튼(**Lorebook**부터 **Tag lorebooks**까지)이고, 두 번째 줄은 선택한 로어북의 항목용 버튼(**Add Entry**부터 **Refresh**까지)입니다.

| 버튼 | |
|---|---|
| **Lorebook** | 편집할 로어북을 고릅니다. |
| **Only root lorebooks** | 다른 로어북의 하위 로어북이 아닌 로어북만 나열합니다(선택한 로어북은 목록에 그대로 남습니다). |
| **Add Lorebook** | *New Lorebook*이라는 이름의 새 로어북을 만들고 선택합니다. |
| 복제(두 장의 종이 아이콘) | 선택한 로어북의 사본을 만듭니다. 이름을 묻는데, 기본값은 원본 이름에 *(Copy)*를 붙인 것입니다. 사본을 선택합니다. 사본에는 원본과 같은 항목(설정, 태그, 부정 태그 포함), 태그, 설명, 확장 기능 데이터가 복사됩니다. 하위 로어북은 복사되지 않으며, 사본도 원본과 같은 하위 로어북을 사용합니다. 원본은 바뀌지 않습니다. |
| **Delete Lorebook** | 선택한 로어북을 삭제합니다(확인 후). |
| 가져오기(파일 아이콘) | **Import Marginalia Lorebook**, **Import from SillyTavern**, **Import from archive**(`.md` 파일들을 묶은 zip 파일), **Import from other user**(다른 사용자가 [공유](#sharing-a-lorebook)한 로어북) 중에서 고릅니다. [가져오기 및 내보내기](import-export.md)를 보세요. |
| 내보내기(파일 아이콘) | 하위 로어북을 포함한 로어북을 다운로드합니다. [가져오기 및 내보내기](import-export.md#exporting)를 보세요. |
| 태그(태그 아이콘) | **Tag lorebooks**: 여러 로어북에 한꺼번에 태그를 붙입니다. [아래](#tagging-many-at-once)를 보세요. 책에서 열려 있는 로어북에는 표시되지 않습니다. |
| 설명(줄 아이콘, 첫 번째 줄의 맨 오른쪽) | **Edit description**: 로어북의 내용을 적는 창을 엽니다. [아래](#description)를 보세요. |
| **Add Entry** | 로어북에 항목을 추가합니다. [항목과 활성화](entries.md)를 보세요. |
| **Full-screen editor** | 로어북의 항목들을 탭이 있는 전체 화면 창에서 엽니다. [전체 화면에서 편집하기](#editing-in-full-screen)를 보세요. 데스크톱에서만 사용할 수 있습니다. |
| **Search and replace** | 로어북 항목의 이름, 본문, 주석에 있는 텍스트를 바꿉니다. [찾아서 바꾸기](entries.md#search-and-replace)를 보세요. |
| **Mass edit** | 로어북과 하위 로어북의 모든 항목을 하나의 표에 엽니다. [일괄 편집](#mass-edit)을 보세요. |
| 태그(태그 아이콘, 두 번째 줄의 **Search and replace** 오른쪽) | **Tag entries**: 선택한 로어북의 여러 항목에 한꺼번에 태그를 붙입니다. [아래](#tagging-many-at-once)를 보세요. |
| **Preview activation** | 입력한 텍스트로 턴을 진행할 때 어떤 항목이 사용되는지, 그 이유와 함께 보여 줍니다. [활성화 미리 보기](entries.md#preview-activation)를 보세요. |
| **Refresh** | 항목을 다시 읽어 옵니다. |
| 검색 상자 | 입력한 텍스트가 들어 있는 항목만 보여 줍니다. [많은 항목 검색 및 삭제](entries.md#searching-and-deleting-many-entries)를 보세요. |
| **Delete selected** | 목록에서 항목을 선택하면 나타납니다. 확인 후 선택한 항목을 삭제합니다. |

도구 모음 아래에는 선택한 로어북의 설정이 있습니다:

| 필드 | |
|---|---|
| **Name** | 로어북의 이름입니다. 책에 연결하거나 하위 로어북으로 고를 때 표시됩니다. |
| **Sub Lorebooks** | 이 로어북과 함께 항목이 포함되는 다른 로어북입니다. [아래](#sub-lorebooks)를 보세요. 선택한 하위 로어북의 이름을 클릭하면 그 로어북이 열립니다. |
| **Tags** | 로어북 전체의 태그입니다. 각 항목의 태그로도 적용됩니다. [태그](entries.md#tags)를 보세요. |
| **Scan depth** | `0`부터 `5`까지의 값입니다. 사용된 항목의 내용을 다른 항목의 필터에 맞는지 찾는 횟수를 정합니다. [다른 항목이 불러온 항목](entries.md#entries-brought-in-by-other-entries)을 보세요. 책이 사용하는 로어북의 항목과 그 하위 로어북의 항목에 적용되며, 하위 로어북이 자체 깊이를 가진 경우(다음 행)에는 예외입니다. |
| **Scan depth as a sub lorebook** | 비워 두거나 `0`부터 `5`까지의 값입니다. 이 로어북이 책이 사용하는 로어북의 하위 로어북일 때 이 로어북 항목에 적용되는 검색 깊이입니다. 비워 두면 그 로어북의 검색 깊이를 따릅니다. `0`이면 다른 항목의 내용으로는 이 로어북의 항목이 절대 불러와지지 않습니다. |
| **Enabled** | 체크를 해제하면 로어북은 아무것도 기여하지 않습니다. 항목도, 하위 로어북의 항목도 포함되지 않습니다. |
| **Share with other users** | 체크하면 다른 사용자가 로어북을 열어 보고 사본을 가져올 수 있습니다. [아래](#sharing-a-lorebook)를 보세요. 새 로어북은 기본적으로 꺼져 있습니다. |

설정 아래에는 로어북의 [설명](#description)이 있습니다(설명이 있는 경우에만 표시됩니다).

편집기의 나머지 부분은 [항목](entries.md) 목록입니다. 모든 변경 사항은 입력하는 즉시 저장됩니다.

<a id="description"></a>

### 설명

설명은 로어북에 대해 몇 단어(또는 몇 줄)로 적는 소개입니다. 어떤 세계를 다루는지, 무엇에 쓰이는지, 어떤 책이 사용하는지 등을 적으면 됩니다. 도구 모음 첫 번째 줄의 줄 아이콘을 클릭하고, 창에 내용을 적은 뒤 확인합니다. 내용을 비워 두면 설명이 삭제됩니다. 설명이 있는 로어북은 설정 아래에 한 줄로 표시되며, 공간이 모자라면 줄임표(...)로 잘립니다. 전체 내용을 보려면 그 줄에 마우스 포인터를 올리세요. 설명은 로어북과 함께 복제, 내보내기, 가져오기, 백업에 포함되며, 로어북을 공유하면 다른 사용자가 이름 옆에서 보는 텍스트이기도 합니다.

### 로어북 공유하기

**Share with other users**를 체크하면 이 설치 환경의 다른 모든 사용자는 **Import from other user**(도구 모음 첫 번째 줄의 가져오기 버튼)에서 이 로어북을 보게 됩니다. 이름, 작성자(사용자의 전체 이름이며, 없으면 로그인 ID), 설명이 함께 표시됩니다. 사용자는 행을 열어 항목(및 하위 로어북의 항목)을 읽고 사본을 가져올 수 있습니다. 체크를 해제하면 로어북이 다른 사용자의 목록에서 사라집니다. 이미 만들어 둔 사본은 그 사용자의 것으로 남습니다.

* 공유는 읽기 전용입니다. 다른 사용자는 여러분의 로어북을 바꾸거나, 삭제하거나, 책에서 사용할 수 없습니다. 로어북은 여전히 여러분의 것이며, 여러분은 전과 같이 볼 수 있습니다.
* 가져오기를 하면 **다른 사용자의 새 로어북**이 만들어집니다. 로어북과 **공유된** 하위 로어북이 (깊이에 관계없이) 항목, 태그, 설명과 함께 복사되며, 여러분의 로어북과 같은 방식으로 연결됩니다. 복사본은 비공개(공유되지 않음)이며, 여러분이 원본 로어북을 나중에 무엇을 하든 복사본에는 반영되지 않습니다. 반대로 복사본을 바꾸어도 여러분의 로어북에는 영향을 주지 않습니다.
* **자체적으로 공유된 하위 로어북만 표시되고 복사됩니다.** 공유되지 않은 하위 로어북은, 그 아래에 있는 모든 것과 함께 제외됩니다. 그 아래에 공유된 로어북이 있더라도 마찬가지입니다. 공유되지 않은 하위 로어북이 있는 로어북에서 **Share with other users**를 체크하면, 하위 로어북도 함께 공유할지 묻는 질문이 나옵니다. **Yes**를 누르면 로어북과 모든 하위 로어북(깊이에 관계없이)이 공유되고, **No**를 누르면 로어북만 공유되며, **Cancel**을 누르면 아무것도 공유되지 않고 체크 상자도 해제된 상태로 남습니다. 나중에 추가한 하위 로어북은 직접 공유하기 전까지 공유되지 않습니다.
* 체크 상자를 해제하면 그 로어북의 공유만 중단됩니다. 하위 로어북은 따로 해제하기 전까지 계속 공유된 상태로 남으며, 다른 사용자의 목록에도 계속 나타납니다.
* 삭제된 로어북, 에이전트의 작업용 사본, 여러분의 로어북은 목록에 나타나지 않습니다. 삭제된 사용자의 로어북도 목록에 나타나지 않습니다.

설정 아래에는 로어북의 활성화된 항목에 대한 토큰 수 추정치가 표시됩니다. 옆의 **Count with subbooks** 링크를 누르면 로어북과 그 아래 모든 하위 로어북(깊이에 관계없이)의 활성화된 항목 토큰 수를 합산하여 옆에 총계를 보여 줍니다. 이야기를 쓸 때와 마찬가지로, 비활성화된 하위 로어북은 그 아래의 로어북과 함께 제외되며, 여러 곳에서 하위 로어북으로 쓰이는 로어북은 한 번만 계산됩니다. 총계는 클릭하는 순간의 값입니다. 항목을 바꾸면 총계가 사라지므로, 다시 클릭해서 계산하세요.

에이전트가 작업 중인 책의 로어북은 읽기 전용으로 표시됩니다([에이전트](../agents.md)를 보세요). 이 경우 **Add Entry**, **Search and replace**, **Mass edit**, **Delete Lorebook**과 설정 항목은 보이지 않습니다. 다만 **Add Lorebook**, 가져오기, 내보내기, **Refresh**는 그대로 남아 있으므로, 언제든 새 로어북을 시작할 수 있습니다.
<a id="mass-edit"></a>

## 대량 편집

**Mass edit** 창은 선택한 로어북과 **그 하위 로어북**(깊이 제한 없음)의 모든 항목을 하나의 표에 보여 줍니다. 항목은 **Order** 순서로 정렬되며, 같은 순서의 항목은 로어북별로, 그다음 이름순으로 정렬됩니다. 큰 로어북을 정리할 때 사용합니다.

- 항목의 *enabled* 체크박스, **Entry Name**, **Order**, **Tags**, **Filtering Mode**, **Filtering**, **Insertion Mode**, **Negative Tags**, **Activation Context**와 그 **Parts**, 적용 범위(**From message**와 **To message**, 비워 두면 제한 없음), 항목의 **Note**를 편집기에서처럼 제자리에서 바꿀 수 있습니다. 항목 하나가 표의 한 줄이며, 표는 아래로(창이 좁으면 옆으로도) 스크롤됩니다. **Order**를 바꾸면 해당 줄이 새 위치로 이동합니다. 표에서는 항목의 본문이 줄여서 표시됩니다. 전체 내용을 읽거나 편집하려면 로어북에서 항목을 여세요.
- 줄의 **Lorebook** 상자는 항목이 어느 로어북에 있는지 보여 줍니다. 다른 로어북(해당 로어북 자체나 하위 로어북 중 아무 것이나)을 고르면 항목이 그곳으로 옮겨집니다.
- 여러 항목을 옮기려면 체크박스로 선택하세요(헤더의 체크박스는 전체를 선택합니다). 아래쪽에서 **Move to lorebook**을 고른 뒤 **Move checked**를 누르세요.
- 여러 항목을 삭제하려면 선택한 뒤 **Delete checked**를 누르세요. 한 번 확인을 묻고, 항목을 [휴지통](../trash.md)으로 옮깁니다.
- 에이전트가 작업 중인 로어북은 잠깁니다. 그 항목들은 회색으로 표시되며 변경하거나 옮길 수 없고, 그 로어북으로 다른 항목을 옮길 수도 없습니다. 잠금은 로어북마다 따로 확인되므로, 하위 로어북 하나가 다른 책에서 사용 중이라 잠겨 있어도 상위 로어북은 잠기지 않을 수 있습니다. **Refresh**를 누르면 창을 다시 읽어 잠금이 풀렸는지 확인합니다.

창을 닫을 때 변경 사항이 있었다면 편집기의 로어북도 새로 고쳐집니다.

## 전체 화면에서 편집

**전체 화면 편집기**(도구 모음의 두 번째 줄)는 선택한 로어북을 화면 전체를 채우는 창으로 엽니다. 긴 항목을 편집할 때 쓰기 좋습니다. 항목 줄의 확장 버튼을 누르면 그 항목이 열린 상태로 창이 뜹니다. 책 창의 *Lorebook* 탭에도 같은 버튼이 있으며, 이 버튼은 그 탭에 표시된 로어북을 엽니다. 창의 제목은 로어북의 이름입니다. 창은 [스토리 편집기](../books/story-editor.md)와 같은 방식으로 탭들의 집합입니다. 탭을 끌어 다른 탭의 옆이나 아래에 놓을 수 있고, 탭 사이의 스플리터를 끌어 크기를 조절할 수 있습니다.

![항목 목록과 탭으로 열린 항목 두 개가 보이는 전체 화면 로어북 편집기](../../images/lorebook-fullscreen.png)

- **Entries** 탭은 항목 목록을 보여 줍니다. 로어북 페이지의 검색 상자와 태그 및 상태 필터도 여기에 있습니다. 이 탭에는 **Add Entry**, **Mass edit**, **Tag entries**, **Preview activation**, **Refresh** 버튼이 있습니다(일괄 편집과 태그 변경은 열린 탭에도 바로 반영됩니다). **Include sub lorebooks**를 켜면 [하위 로어북](#sub-lorebooks)의 항목도 함께 목록에 나타나며, 각 항목 옆에는 소속 로어북의 이름이 표시됩니다. 이때 **Add Entry**는 목록 옆에서 고른 로어북에 항목을 추가합니다. 이런 항목의 탭에는 소속 로어북의 이름이 표시됩니다. **Entries** 탭은 닫을 수 없습니다. 목록의 각 행에는 버튼이 세 개 있습니다.
  - **Open**(연필 아이콘, 행을 두 번 클릭해도 됩니다)은 마지막으로 사용한 항목 탭에 항목을 보여 줍니다. 그런 탭이 없으면 목록 오른쪽의 열에 새 탭을 엽니다.
  - **Open in new tab**(화살표 아이콘)은 마지막으로 사용한 항목 탭 옆에 이 항목의 탭을 추가합니다.
  - **Delete**(휴지통 아이콘)는 확인 후 항목을 삭제하고, 그 항목의 탭도 닫습니다.

  한 항목은 최대 한 개의 탭에서만 열립니다. 이미 열린 항목을 다시 열면 그 항목의 기존 탭이 표시됩니다.
- **항목 탭**의 위쪽에는 **Name**, **Order**, **Enabled**가 있습니다. 그 아래에는 접을 수 있는 패널인 **Settings**가 있으며, 여기에는 항목의 나머지 설정이 들어 있습니다(필터링 방식과 필터, 삽입 방식, 활성화 문맥과 부분, 태그와 음의 태그, 부분의 범위, 재귀 확인란과 조건. 자세한 내용은 [Entries & activation](entries.md)을 참고하세요). 그 아래에는 Markdown 편집기 형태의 **content**가 있습니다. 각 탭은 텍스트만 보기, 텍스트와 미리보기 함께 보기, 미리보기만 보기 중 무엇을 보여 줄지 기억하며, 창을 다시 열어도 이 설정이 유지됩니다. **Show note**를 체크하면 **content** 옆에 **note**가 나타납니다. 눈 아이콘을 누르면 이 항목의 [활성화 미리보기](entries.md#preview-activation)가 열립니다. 하단 줄에는 content의 추정 토큰 수가 표시되며, 템플릿에 문제가 있으면 빨간색으로 그 내용이 나타납니다(문제가 있어도 저장은 됩니다). 탭을 닫으려면 **×**를 누르세요.
- **항목의 이미지.** 이미지를 content에 붙여 넣거나, content 위로 끌어 놓거나, 도구 모음의 이미지 버튼으로 고를 수 있습니다(PNG, JPEG, GIF, WebP 형식, 최대 10 MB). 이미지는 파일(*Resources* 탭)에 저장되고, content에는 커서가 있던 자리에 `![Map](resource:…)`과 같은 줄이 추가됩니다. 미리보기에는 이미지가 표시되며, 대괄호 안의 글은 이미지 설명입니다. 항목에서 이미지를 빼려면 그 줄을 지우면 됩니다. 모델은 이런 줄을 제외하고 항목을 읽습니다. 이미지 자체는 모델 설정이 *Multimodal (accepts images)*인 경우에만 전송됩니다(자세한 내용은 [Inference providers](../inference-providers.md) 참고). 이미지는 로어북과 함께 이동합니다. 복제본, 공유 로어북의 사본, 내보낸 로어북 파일, 파일을 포함한 책 백업에는 이미지가 함께 들어가며, 사본에는 그 사본만의 이미지가 생깁니다. SillyTavern 내보내기와 책 내보내기에서는 이미지가 빠집니다. 스토리의 *Lorebook* 탭은 항목 텍스트 아래에 이미지를 보여 줍니다. 이미지는 아직 토큰 추정에 포함되지 않습니다.
- **항목 사이 이동.** 항목의 content에서 다른 항목의 이름이나 키워드를 Ctrl+클릭(Mac에서는 Cmd+클릭)하면, 본문이나 미리보기 어디에 있든 마지막으로 사용한 탭에서 그 항목이 열립니다. Shift를 함께 누르면 새 탭에서 엽니다. 하단 줄에는 **Mentioned in:** 뒤로 이 항목의 이름을 언급하는 항목들도 나열됩니다. 하나를 클릭하면 열리고, Shift+클릭하면 새 탭에 열립니다. 항목은 이름과 필터의 단어로 인식됩니다(각 키워드, *Text* 필터의 전체 텍스트, 정규 표현식이 매치하는 내용). 이때 단어 단위로 비교하며 대소문자는 구분하지 않습니다. 이 기능은 [재귀](entries.md)가 따라가는 방식과 비슷하지만 같지는 않습니다. 재귀는 더 긴 단어 안의 키워드도 찾고, *AND* 필터의 모든 키워드를 요구하며, 태그와 조건도 확인합니다.
- Markdown 편집기에는 도구 모음(굵게, 기울임, 취소선, 줄, 제목, 인용, 코드, 코드 블록, 표, 세 가지 목록)이 있고, 오른쪽에는 *edit*, *edit with preview*(기본값), *preview* 보기 전환이 있습니다. Ctrl+B, Ctrl+I 같은 일반적인 단축키가 동작합니다. Tab은 들여쓰기 대신 다음 입력란으로 이동합니다. 입력한 내용은 입력을 잠시 멈추거나 편집기를 떠날 때 저장됩니다.
- 머리글에는 사용 중인 항목의 추정 토큰 수, **Count with subbooks**, **Search and replace**가 표시됩니다. **Search and replace**로 바꾼 텍스트는 열린 탭에도 반영됩니다.

모든 변경은 입력하는 즉시 저장되므로 **Close**를 눌러도 잃는 것이 없습니다. 창은 로어북별로 마지막 상태를 기억합니다. 다음에 같은 로어북을 열면 같은 항목이 같은 탭에 같은 배치로 나타납니다(그 뒤에 삭제된 항목은 제외됩니다). 창을 닫으면 로어북 페이지에 항목이 다시 표시됩니다.

**다른 곳에서 이루어진 변경.** 탭에서 한 변경은 그 순간 저장된 항목에 반영됩니다. 따라서 다른 곳(로어북 페이지, 일괄 편집, 다른 창)에서 항목의 *다른* 필드를 바꾸었다면 그 변경은 유지되고, 탭에도 그 변경이 나타납니다. 탭이 내용을 보여 준 뒤에 다른 곳에서 **content**나 **note**가 바뀌었다면, 여러분의 텍스트는 그 변경 위에 저장되지 않습니다. 하단 줄이 이를 알려 주며, **Keep my text**(그래도 내 텍스트 저장)와 **Load the saved text**(내 텍스트 버리기) 중에서 고를 수 있습니다. 다른 곳에서 삭제된 항목의 탭은 닫힙니다.
창이 열려 있는 동안 저장되는 내용도 따라갑니다. 에이전트나 다른 창(다른 브라우저 탭, 스토리의 로어북 탭)이 항목을 저장하거나 삭제하면 목록이 다시 로드되고, 그 항목의 탭도 현재 상태를 보여 줍니다(삭제된 항목의 탭은 닫힙니다). 텍스트가 **Keep my text** 또는 **Load the saved text**를 기다리는 탭은 여러분이 응답할 때까지 그대로 둡니다. 여러분이 입력한 같은 초에 저장된 변경은 엇갈릴 수 있으며, 이때 하단 줄이 위와 같이 묻습니다.

**에이전트.** 로어북을 사용하는 책에서 에이전트가 작업 중이면 이 창은 열리지 않습니다. 창이 열린 상태에서 실행이 시작되면, 다음 변경을 하거나 탭을 바꿀 때 창이 읽기 전용으로 바뀝니다. 이때 상단 막대에 에이전트의 이름이 표시되고, 마지막 변경이 저장되지 못했는지도 알려 줍니다. 실행을 일시 정지하거나 중지한 뒤 **Check again**을 누르세요. 그러면 실행이 남긴 상태로 항목이 다시 로드되고, 다시 편집할 수 있습니다.

[Lore Generator](../extensions/lore-generator.md)와 [Lorebook VCS](../extensions/lorebook-vcs.md) 확장 기능도 여기서 동작합니다. 마술봉 아이콘은 목록의 행과 항목 탭의 이름 행에 있고, 리비전 패널은 목록 위에, 항목의 리비전 막대는 그 항목의 탭에 있습니다.

<a id="tagging-many-at-once"></a>

## 여러 항목에 한꺼번에 태그 붙이기

도구 모음의 태그 버튼 두 개는 여러 항목에 태그를 붙이거나 떼는 창 하나를 엽니다. **Tag lorebooks**는 여러분의 로어북 목록을, **Tag entries**는 선택한 로어북의 항목 목록을 보여 줍니다. **Tag**에서 태그를 고르거나(새 태그를 입력하고 Enter를 누를 수도 있습니다) 목록은 각 항목과 그 태그를 보여 줍니다. 고른 태그가 붙은 항목이 먼저 나오며, 그 태그는 강조 표시됩니다. 각 행의 **+**와 **-** 버튼은 그 항목에 태그를 붙이거나 뗍니다. 여러 항목을 체크하고(머리글의 상자를 체크하면 전체가 선택됩니다), 아래의 **Apply the tag to the checked** 또는 **Remove the tag from the checked**를 누르면 선택한 모든 항목에 한꺼번에 적용됩니다. 에이전트가 작업 중인 항목(실행 중인 에이전트가 있는 책의 로어북, 따라서 그 안의 모든 항목)은 회색으로 표시되며, 실행이 일시 정지되거나 중지될 때까지 바꿀 수 없습니다. 이 창은 [책](../books/managing-books.md#tagging-many-books-at-once)에도 태그를 붙일 수 있습니다.
이 창이 항목에 붙이는 태그는 일반 태그입니다(자세한 내용은 [Tags](entries.md#tags) 참고). 음의 태그는 항목 자체에 설정됩니다.

<a id="using-a-lorebook-in-a-book"></a>

## 책에서 로어북 사용하기

책을 열고 **Lorebook** 탭을 선택한 뒤, **Lorebook** 입력란에서 로어북을 고르세요. 그 아래의 편집기에 로어북이 표시되므로, 글을 쓰면서 항목을 추가하고 바꿀 수 있습니다. 입력란을 비우면 로어북 없이 글을 쓸 수 있습니다.

책은 로어북 하나를 사용합니다. 여러 로어북을 사용하려면, 그것들을 하위 로어북으로 포함하는 로어북을 만들고 그 로어북을 사용하세요.

같은 로어북을 원하는 만큼 많은 책이 사용할 수 있습니다. 로어북을 바꾸면 그다음에 생성되는 부분부터 모든 책에 반영됩니다. 이미 쓰인 부분은 그 부분이 쓰일 때의 로어를 그대로 유지합니다.
<a id="sub-lorebooks"></a>

## 하위 로어북

**Sub Lorebooks**에는 다른 로어북의 항목이 이 로어북에 포함됩니다. 일반적인 구성은 다음과 같습니다:

```
"Saga" (used by the books of the series)
 ├─ "World"       places, history, rules of magic
 ├─ "Characters"  the main cast
 └─ "Book 2 notes"
```

- 하위 로어북도 자체적으로 하위 로어북을 가질 수 있으며, 모든 단계가 포함됩니다.
- 하나의 로어북은 여러 로어북의 하위 로어북이 될 수 있습니다. 여러 경로로 같은 로어북에 도달하더라도
  그 항목은 한 번만 사용됩니다.
- 로어북은 직접 또는 다른 로어북을 거쳐서라도 자기 자신을 포함할 수 없습니다. 이런 선택은
  *Cannot select sub lorebook: cycle detected.* 메시지와 함께 거부됩니다.
- 비활성화된 하위 로어북은 그것이 포함하는 모든 로어북과 함께 제외됩니다.

![두 개의 하위 로어북을 가진 로어북: 하위 로어북이 있을 때와 없을 때의 토큰](../../images/lorebook-sub-lorebooks.png)

포함된 모든 로어북의 항목은 어느 로어북에서 왔는지와 관계없이 하나로 합쳐져 [순서](entries.md#order-and-insertion) 기준으로 정렬됩니다.

<a id="disabling-and-deleting"></a>

## 비활성화와 삭제

잠시 로어북을 끄고 싶다면 **Enabled**의 체크를 해제하세요. 예를 들어 로어북 없이 책이 어떻게 읽히는지 확인할 때 유용합니다. 책에 연결된 상태는 그대로 유지되며, 다시 체크하면 로어북이 정상적으로 작동합니다.

**Delete Lorebook**은 로어북을 목록에서 제거합니다. 이 로어북을 사용하던 책은 더 이상 그 항목을 받지 않으며, 이 로어북을 하위 로어북으로 포함하던 로어북은 이를 건너뜁니다. 데이터는 관리자가 [정리](../administration/cleanup.md)를 실행할 때까지 데이터베이스에 남아 있으며, 그 전까지는 [휴지통](../trash.md)에서 로어북을 복원할 수 있습니다. [책 백업](../books/backups.md)에 있는 사본과 내보낸 파일에는 영향을 주지 않습니다.
