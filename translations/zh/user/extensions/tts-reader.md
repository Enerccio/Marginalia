# 朗读

使用设备的语音，在[阅读器](../books/publishing.md)中朗读已发布的书籍。

<a id="using-it"></a>

## 使用方法

阅读器在右上角样式按钮旁边有一个小控件：

- **播放**从当前屏幕上的部分开始，或从你选中文本的起始处开始。正在朗读的部分会被高亮显示，并滚动到可见区域，朗读过程中后续部分会陆续加载。
- **暂停**和**停止**。
- **齿轮**图标打开设置：**语音**（先列出浏览器中与书籍语言相同的语音；默认是该语言下最好的语音）、**语速**和**音调**。

<a id="good-to-know"></a>

## 注意事项

- 语音由你的浏览器生成（`speechSynthesis`）。内容不会发送到服务器，设置保存在浏览器中，因此只属于该设备和该浏览器。语音及其质量取决于设备和浏览器。
- 朗读的是页面上的文本：[人工语言](conlang-translator.md)和[真实语言](real-language-translator.md)翻译器的译文，会按书中的显示方式朗读。
- 并非所有手机都支持暂停；在这些设备上，朗读会停在当前位置。
- 使用[有声书](audiobook.md#a-part-without-audio)扩展时，在其播放器提供的按钮上按下后，浏览器的语音可以朗读尚无音频的部分。
- 离开书籍会停止朗读。如果浏览器不能发声，该控件会被隐藏。
