# 統計

すべてのユーザーの[執筆統計](../books/statistics.md)(語数、作業時間、各ブックのサイズを日ごとに記録したもの)は、データベースに保存されます。統計には、ユーザーがいつブックに取り組んだか、ブックの名前とフォルダーに加え、削除されたブックのものも記録されます。管理ページの **統計** タブで、これを制限できます。ユーザーは自分の[設定](../account.md)で同じことができ、統計ウィンドウから自分の統計を消去することもできます。

![管理ページの統計タブ](../../images/admin-statistics.png)

| | |
|---|---|
| **執筆統計を記録する** | オフにすると、すべてのユーザーについて、ユーザーの選択に関係なく記録が止まります。すでに記録されたものは削除されません。統計ウィンドウには、新たに数えられるものがないと表示されます。 |
| **統計を保持する期間(月)** | これより古い日は、すべてのユーザーの統計から完全に削除されます。削除は1日に1回(午前4時20分ごろ、および起動直後にも)、また保存したときにも行われます。空または0の場合は、すべて保持されます。ユーザーは自分について、より短い期間を選ぶことはできますが、より長い期間は選べません。 |
| **ユーザーの統計を消去** | 選択したユーザーのすべての統計を、確認のあとに削除します。そのユーザーのブックは変更されません。 |
| **全員の統計を消去** | 同じ操作を、すべてのユーザーに対して行います。 |

削除された統計は、[データベースのバックアップ](database-backups.md)からしか復元できません。統計はデータベースの一部であり、単一ブックのバックアップには含まれないためです。

[クリーンアップ](cleanup.md)は統計には影響しません。統計は削除されたオブジェクトではなく、ブックをそのIDで参照しており、意図的にブックの削除後も残るからです。
