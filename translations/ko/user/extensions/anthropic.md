# Anthropic Claude

Anthropic의 Claude 모델을 [추론 제공자](../inference-providers.md)로 추가합니다. OpenAI 호환 API가 아니라 Anthropic 자체 API를 통해 연결됩니다.

Claude는 OpenRouter 같은 집계 서비스를 통해 일반 *OpenAI 호환* 제공자로도 사용할 수 있습니다. 이 확장 기능은 Claude API에 직접 연결합니다(Anthropic SDK 사용). 그래서 호환 엔드포인트에서는 할 수 없는 기능을 제공합니다. 추론으로 표시되는 **모델 사고의 요약**, Claude 4.6 이후 모델의 추론 강도, 그리고 Anthropic이 보고하고 계산하는 정확한 토큰 수가 그것입니다.

!!!warning 이야기 본문이 Anthropic으로 전송됩니다
이 제공자를 사용하는 AI의 모든 요청은 Anthropic 서버(`api.anthropic.com`, 또는 설정한 프록시)로 전송됩니다. 여기에는 이야기가 담긴 프롬프트, 로어북 항목과 요약, 모델의 응답, 에이전트나 명령이 보내는 파일과 그림이 모두 포함됩니다. 그 이후의 처리(보관 기간, 요청을 거부할 수 있는 안전장치 등)는 API에 대한 Anthropic의 약관과 개인정보 처리방침에 따릅니다. 다른 제공자는 여러분이 선택한 서버, 즉 직접 운영하는 서버로 전송될 수 있습니다.
Anthropic으로 보내도 되는 텍스트에만 이 제공자를 사용하세요. 다른 사용자와 함께 쓰는 서버에서 이 제공자를 사용하는 AI를 공유하는 관리자는 그 AI를 쓰는 모든 사용자의 이야기 본문을 Anthropic으로 보내게 됩니다.
!!!

<a id="installing"></a>

## 설치

*관리자 → 확장 기능*에서 확장 기능을 불러오세요. 자세한 내용은 [확장 기능 관리](../administration/extensions.md)를 참고하세요.
JAR 파일이 약 36MB로 큽니다. Anthropic SDK와 SDK에만 필요한 라이브러리가 들어 있기 때문입니다. Marginalia의 다른 부분은 이 라이브러리를 사용하지 않습니다.

확장 기능을 불러오면 추론 제공자 대화상자의 **유형** 목록에 **확장 기능** 항목이 추가됩니다. *유형별 설정* 탭 상단의 **제공자** 목록에는 **Anthropic Claude**가 나타납니다(이것이 유일한 항목이면 자동으로 선택됩니다). AI를 제공하는 확장 기능이 하나도 불러와져 있지 않으면 **확장 기능** 항목은 나타나지 않습니다.

<a id="adding-a-claude-provider"></a>

## Claude 제공자 추가하기

1. [Claude Console](https://platform.claude.com)에서 API 키를 발급받으세요.
2. **추론 제공자** 탭에서 **추론 제공자 추가**를 클릭하고 **이름**을 입력하세요. 유형은 **확장 기능**, 제공자는 **Anthropic Claude**를 선택하세요.
3. *일반 설정*(컨텍스트 크기, 응답 크기, [추론](#reasoning))과 *유형별 설정* 탭의 제공자 설정을 입력한 뒤 **연결 테스트**를 클릭하세요.

| 필드 | |
|---|---|
| **API 키** | Claude Console의 키입니다. 암호화되어 저장되며 다시 표시되지 않습니다. 제공자를 편집할 때 다른 키를 입력하려면 **초기화**를 클릭하세요. |
| **모델** | 사용할 모델입니다(예: `claude-opus-5-5`, `claude-sonnet-5-5`). **새로 고침**을 누르면 키로 사용할 수 있는 모델 목록이 나타납니다. 목록에 없는 이름도 직접 입력할 수 있습니다. |
| **URL** | 선택 사항입니다. 비워 두면 Anthropic API(`api.anthropic.com`)를 사용합니다. 요청을 프록시를 거쳐 보내려면 여기에 주소를 입력하세요. |
| **제한 시간 (초)** | Anthropic이 응답하기까지, 그리고 응답을 쓰기 시작한 뒤 다음 텍스트가 오기까지 기다리는 시간입니다. 기본값은 300입니다. |
| **재시도 횟수** | Anthropic이 요청 제한(429), 서버 오류(5xx, 과부하를 뜻하는 529 포함) 응답을 보내거나 연결할 수 없을 때 요청을 몇 번 다시 보낼지 정합니다. 기본값은 2이며, 0으로 설정하면 재시도를 하지 않습니다. |

**연결 테스트**는 모델 목록을 가져온 뒤, 선택한 모델에 대화상자에 입력한 값으로 몇 개의 토큰을 요청합니다. 값을 저장하기 전에 확인할 수 있습니다.

## 추론

추론 설정은 다른 제공자와 마찬가지로 제공자의 일반 설정에 있습니다.

- **추론 사용**을 끄면 사고와 관련된 내용을 전혀 보내지 않습니다. 기본적으로 생각하는 모델(Opus 5.5는 생각을 끌 수 없습니다)은 생각하며, 그 사고 과정은 표시되지 않습니다. 나머지 모델은 생각하지 않습니다.
- 켜면 모델이 사고 요약을 보내고, 그 요약은 이야기 부분의 추론으로 표시됩니다. Claude 4.6 이후 모델에서는 **추론 강도**(낮음, 중간, 높음)가 모델의 노력 수준이 되며, 적응형 사고가 적용됩니다. 즉 모델이 얼마나 생각할지를 스스로 결정합니다. 그 이전 모델(Claude 4.5 및 그 이전, Haiku 4.5 포함)에서는 사고 토큰 예산이 1,024, 8,192, 24,576 중 하나로 정해집니다. **없음**은 끄는 것과 같습니다.

사고 토큰은 생성된 토큰으로 계산되며, 설정한 응답 크기에서 차감됩니다. 모델이 응답 크기를 모두 사고에 쓰면 이야기 부분이 비어 돌아오고, 응답 크기가 모두 소진되었다는 오류가 표시됩니다. 이때는 **최대 응답 토큰**을 올리거나 추론 강도를 낮추세요. Claude는 모든 요청에 응답 크기가 필요합니다. 제공자와 프로토콜 모두 응답 크기를 설정하지 않았다면 16,000이 사용됩니다.

<a id="what-works"></a>

## 지원되는 기능

이야기에 필요한 기능은 대부분 OpenAI 호환 제공자와 같이 동작합니다. 스트리밍, 생성 중지, 요약, [모델을 호출하는 확장 기능](index.md), 모델이 호출할 수 있는 함수([이름 생성기](name-generator.md)가 일부를 제공합니다), 메시지에 첨부하는 그림(JPEG, PNG, GIF, WebP), PDF 및 텍스트 파일을 사용할 수 있습니다. 사용자가 쓴 토큰은 Anthropic이 보고한 수치를 바탕으로 **전송된 토큰**과 **생성된 토큰** 열에 집계됩니다. 캐시에서 읽은 토큰과 캐시에 쓴 토큰은 전송된 토큰으로 집계됩니다. 공유 제공자의 [제한](../inference-providers.md#limits-of-shared-providers)도 그대로 적용됩니다.

이야기에 표시되는 토큰 수(부분의 크기, 프롬프트)는 Anthropic이 계산합니다(모델의 `count_tokens` 요청을 사용합니다). 각 텍스트마다 한 번씩 계산하며, 결과는 저장되어 다시 사용됩니다. Anthropic에 요청할 수 없는 경우(키가 없거나, 네트워크가 끊기거나, 오류가 발생한 경우)에는 Marginalia가 1분 동안 자체적으로 토큰 수를 추정한 뒤 다시 시도합니다. 다른 저장 작업이 진행되는 동안 저장되거나 편집되는 텍스트도 같은 방식으로 추정합니다.

다른 제공자와 다른 점은 두 가지입니다.

- **프로토콜의 온도, top p, 반복 패널티는 전송되지 않습니다.** 현재 Claude API는 이 값들을 거부합니다. 모델은 자체 설정으로 샘플링합니다. 프로토콜의 응답 크기는 사용됩니다.
- 대화는 사용자 메시지로 시작하고 사용자 메시지로 끝나야 하며, Claude는 응답을 이어서 쓰지 않습니다. 책의 프롬프트는 항상 이 형식을 따릅니다. 그렇지 않은 확장 기능의 요청은 "잘못된 요청(bad request)" 오류와 함께 거부됩니다.

<a id="when-the-extension-is-not-loaded"></a>

## 확장 기능이 불러와져 있지 않을 때

확장 기능을 해제해도 만들어 둔 제공자는 목록에 남습니다. 유형은 *확장 기능: anthropic*으로 표시되며, 확장 기능을 다시 불러오면 다시 작동합니다. 확장 기능이 없는 동안 이 제공자를 사용하는 책은 생성할 수 없습니다. 오류 메시지는 확장 기능을 불러오거나 다른 제공자를 선택하라고 안내합니다. 제공자는 여전히 열어서 일반 설정을 바꿀 수 있습니다. Claude 설정은 확장 기능이 불러와져 있을 때만 표시되며, 그동안 값은 변경되지 않습니다.

<a id="not-supported"></a>

## 지원하지 않는 기능

- **Amazon Bedrock, Google Vertex AI, Microsoft Foundry.** Claude API의 API 키만 지원합니다.
- 프롬프트 캐싱과 Anthropic 서버에서 실행되는 도구(웹 검색, 코드 실행).
