# 写作统计

Marginalia 会按天记录你的书发生了什么：你写了多少字，模型写了多少字，你写作了多长时间，发送给模型的 token 有多少，书变得多大。**统计**窗口以数字、图表和一份你工作过的日子的**日历**来展示这些内容，并显示你的**连续天数**和**每日目标**。

这些数字只属于你：每个账户只能看到自己的书。统计从 1.6.0 版本开始计数；在此之前发生的事情会尽可能地[根据各部分的历史重建](#days-before-the-statistics)。

<a id="opening-the-window"></a>

## 打开窗口

- **一本书：** 设置菜单（故事下方的齿轮图标）中有**统计**。该窗口统计这一本书。
- **所有书：** 书籍列表的**管理**菜单中有**统计**。该窗口将你所有的书汇总，并多出两个标签页，**书籍**和**按书**。

两个窗口的工作方式相同。顶部可以选择**时段**（*今天*、*昨天*、*最近 7 天*、*最近 30 天*、*本月*、*全部时间*，或带有**从**和**到**日期的*自定义*）以及**统计对象**：**全部**、**我**（你和你要求的模型）或**智能体**（[智能体](../agents.md)所做的工作，单独保存）。日期以服务器时钟为准。

![一本书的统计：每日数据](../../images/statistics-book.png)

选择栏下方是该时段的合计，然后是各个标签页。

<a id="what-is-counted"></a>

## 统计哪些内容

| | |
|---|---|
| **写下的字数** | 你亲自写下的字：你在某个部分中输入的文字，无论是在故事编辑器中还是在你编辑部分的任何其他地方。 |
| **生成的字数** | 模型为这本书写下的字。 |
| **删除的字数** | 消失的字：你从某个部分剪切掉的文字，或你删除的部分。 |
| **创建的部分**、**删除的部分**、**编辑** | 创建和删除了多少个部分，以及你保存了多少次已修改的部分。 |
| **发送的 token**、**生成的 token**、**请求** | 为这本书发送给模型的内容（每次都是完整提示词）以及返回的内容，以及共发出了多少次请求。 |
| **打开** | 这本书在你屏幕上打开了多长时间。 |
| **编辑中** | 你在某个部分中打字的时长。长时间停顿会让计时停止。 |
| **生成中** | 模型为这本书工作的时长。 |
| **智能体运行中** | 智能体在这本书上工作的时长。 |
| **增长** | 该时段内书增大（或缩小）了多少字。 |

时间是实际的钟表时间。当两本书同时打开，或三个智能体一起运行时，合计只会把这段时间计算一次，因此各本书的时间相加可能会超过总计（窗口中会有说明）。字数和 token 则是可以直接相加的。

导入书籍或文本（归档文件、来自 SillyTavern 的聊天记录）、复制书籍以及恢复备份，都不计入任何统计：这些文字并非在此处写成。智能体的工作在其一侧计入（**智能体**），计入的是原书，尽管它们是在副本上工作；其中包括被丢弃或从未合并回书中的工作。

<a id="the-tabs"></a>

## 标签页

| 标签页 | |
|---|---|
| **日** | 每个有内容的日子占一行：以上所有数字，最新的在前。点击表头可排序。 |
| **字数** | 每天写下、生成和删除的字数图表。较长的时段会按周或按月合并。 |
| **时间** | 打开、编辑、生成以及智能体运行中的小时数图表。 |
| **Token** | 发送和生成的 token 图表。 |
| **大小** | 每天结束时书的大小，以及每天增长了多少，可选择以**字数**或 **Token** 计。 |
| **书籍** | （所有书）每本书一行，也包括在[回收站](../trash.md)中或已消失的书，显示其文件夹、数字、时间、增长量及其占比。**显示已删除的书籍**会隐藏回收站中的书和已消失的书。点击某本书即可打开它。 |
| **按书** | （所有书）以柱状图显示各本书，按你在**图表依据**中选择的数字排列。显示最大的十本，其余合并为一根柱子，即*其他*。 |
| **日历** | 你工作过的日子、你的连续天数和你的目标，见下文。 |

![每日时间](../../images/statistics-time.png)

书的大小会在变化后片刻测得，依据的是各部分已保存的字数和 token。旧部分的 token 是它被写下时计算的数字，因此更改书的模型不会改变任何数字。

<a id="the-calendar"></a>

## 日历

**日历**标签页为过去一年的每一天显示一个小方块（53 周，手机上为 16 周），每列一周，最新的一天位于右下角，并以一个边框标出。方块越深，表示你当天做的事情越多。将指针悬停在某一天上，即可看到日期、你写下的字数、你编辑的时间，以及你最后一次在那天工作的时刻（由历史重建的日子后面带有 `~`）。

![所有书的日历，以及当日目标](../../images/statistics-global-calendar.png)

当你写下了字、编辑了某个部分、创建了某个部分，或花费了编辑时间，这一天就算作**有工作**。智能体所做的事、仅被生成的字数，以及打开书籍，都不计入：日历关注的是*你的*写作。方块只比空白方块稍深一点，则表示那天你工作过，但写得很少。

你可以通过**写下的字数**或**编辑**（编辑的分钟数）来选择方块的着色方式。无论上方选择的**时段**是什么，日历始终显示最近的几周。

日历上方：

| | |
|---|---|
| **当前连续天数** | 从今天往回数，你连续工作过的天数。尚未工作的今天不会中断连续天数：此时连续天数从昨天开始计算。 |
| **最长连续天数** | 全部时间内，最长的连续工作天数。 |
| **有工作的天数** | 所示方块中，你工作过的天数。 |
| **目标连续天数**、**最长目标连续天数** | 与上面的连续天数相同，但针对达到每日目标的天数（在你设置目标时，位于所有书籍的窗口中）。 |

<a id="the-daily-goal"></a>

### 每日目标

在**设置**标签页的常规设置中设定目标：

| 字段 | |
|---|---|
| **每日目标：写下的字数** | 你在一天内写下的字数，合计所有书。模型生成的字数不计入。 |
| **每日目标：编辑的分钟数** | 你在一天内编辑的分钟数，合计所有书。 |

![设置中的目标](../../images/settings-daily-goal.png)

字段留空则表示没有目标。两项都设定时，一天只有同时达到**两项**才算达成目标。**所有书**的窗口会以两根条形显示你今天完成了多少（*今天：310 / 500 字*），日历的着色随目标变化（达成目标的一天颜色最深），**目标连续天数**则统计达成目标的天数。没有目标时，着色以日历中你最忙碌的一天为准。单本书的窗口没有目标（对单本书而言，覆盖所有书的目标意义不大）：其方块以该书最忙碌的一天为基准着色。

当某一天没有记录时间（见下文），且日历按**编辑**着色时，该天只会被标记为有工作的一天。

![手机上所有书的统计](../../images/phone-statistics.png)

<a id="days-before-the-statistics"></a>

## 统计功能出现之前的日子

1.6.0 版本之前没有保存统计数据。Marginalia 更新时，会根据各部分的历史重建之前的日子：部分的第一个版本即为以当时的字数创建的部分，之后的版本为编辑，已消失的部分则为删除。这些日子只是估算。它们在日子列表中以 `~` 标记，窗口会说明共有多少天；重建日子的 token 只是下限。**时间**无法重建，因为从未有人记录过：窗口会说明从哪一天起开始记录时间（*时间记录自 ...起*），之前的日子显示为破折号，并且不计入时间图表。**日历**会将重建的日子与其他日子一样计为有工作的日子。
<a id="privacy-clearing-not-recording-keeping-less"></a>

## 隐私：清除，不记录，少留存

统计数据记录了你何时在某本书上工作、工作了多长时间，并保存每本书的名称和文件夹，也包括你已删除的书。这些数据属于你，由你决定保留多少。

![设置中的“记录写作统计”和“统计保留时长”](../../images/settings-statistics-privacy.png)

- **清除本书的统计**（书籍窗口中的按钮）和**清除所有统计**（所有书籍窗口中的按钮）会在确认后永久删除计数、时长和大小。书籍本身不会被改动。此后统计从零开始重新计数。
- 在书籍列表中，已在回收站或已消失的书籍会有**遗忘**按钮，它只删除该书的统计数据。
- [设置](../account.md)中的**记录写作统计**会为你的书籍关闭计数。已记录的数据会保留，直到你清除它；窗口会说明不再计入新数据。管理员也可以为所有人关闭记录，并显示同样的说明。
- 设置中的**统计保留时长（月）**会删除早于该时长的日数据，每天一次，并在你保存时执行。留空或填 0 则保留全部。管理员可以为所有人设定上限，两者取较短的一个。对于书籍的大小数据，会保留上限之前的最后一条记录，以便仍能算出第一个被保留的那一天的增长量。

[管理员](../administration/statistics.md)可以清除某个用户或所有用户的统计数据。

<a id="commands"></a>

## 命令

两个[命令](../commands/index.md)读取相同的数字：`/get-book-statistics [range] [side]` 用于当前打开的书籍，按天显示；`/get-statistics [range] [by] [side]` 用于你的所有书籍，按天或按书籍显示。范围可以是 `today`、`yesterday`、`last-7-days`、`last-30-days`、`this-month`、`all-time`、某一天（`2026-03-14`），或两天之间（`2026-03-01..2026-03-14`）。[智能体](../agents.md)同样可以使用这些命令。
