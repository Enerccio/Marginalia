# 中文本地化

为用户界面添加简体中文（中文（简体））语言。

<a id="using-it"></a>

## 使用方法

管理员加载该扩展（参见[管理扩展](../administration/extensions.md)）后，*中文（简体）*会出现在工作区底部的**语言**选择器中（在[手机](../phone.md)上位于菜单中），与英语和日语并列。选择它后页面会以中文重新加载；该选择会保存在您的账户中，因此您在任何设备上登录时都会使用它。每位用户各自选择自己的语言。

![中文界面的故事编辑器](../../images/plugin-chineselocalization.png)

界面已完成翻译：菜单、按钮、消息、模板变量和宏的说明等均已翻译。尚无中文译文的文本仍以英文显示。

该扩展还会在设置的**提示语言**中添加中文（*设置 → 模板*，参见[提示语言](../account.md#prompt-language)）：此时应用和插件的内置提示将以中文发送。这一选项独立于界面语言。您的书籍、角色设定库以及您自己编写的提示均不会被更改。

<a id="removing-it"></a>

## 移除方法

卸载该扩展会同时取消界面和提示的中文语言。已选择中文的用户将看到并发送英文内容，直到他们选择其他语言为止；其选择会被保留，并在重新加载该扩展后再次生效。
