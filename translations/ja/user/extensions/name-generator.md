# 名前ジェネレーター

モデルが名前を自分で考え出すかわりに、名前を求められるようにします。名前は実在する名前のリストから取られます。多くの国の名と姓、地名、神々、怪物、薬品、企業、食べ物などが含まれます。マルコフ連鎖によって新しい名前が作られるため、そのカテゴリらしく聞こえますが、リストの複製にはなりません。

この拡張機能には専用の画面も設定項目もありません。ほかの拡張機能がその機能をモデルに提供します。現時点では、[ロア・ジェネレーター](lore-generator.md#tools)と[アーク・アウトライン](arc-outline.md)がこれにあたります。そこでは、モデルが使ってよいカテゴリを選べます（[モデル向けのツール](tools.md)を参照）。このスイートの名前は *Name generator* で、架空の名前ではなく実在の名前を返す[名前プロバイダー](name-provider.md)の *Name provider* と並んで置かれています。

![ロア・ジェネレーターのツールウィンドウで名前のカテゴリを選ぶ](../../images/tools-dialog.png)

<a id="what-the-model-can-do"></a>

## モデルにできること

| 機能 | 内容 |
|---|---|
| `list_name_categories` | 名前のカテゴリを一覧表示します。`filter` を指定すると、その語を名前に含むカテゴリだけを表示します。 |
| `generate_names` | 1つのカテゴリから新しい名前を最大100個作ります。任意で最短と最長の長さを指定できます。 |

長さを指定しない場合、名前はそのカテゴリの名前として普通の長さになります（長い企業名のカテゴリでは長い名前、短い名のカテゴリでは短い名前になります）。モデルは2文字から30文字までの間で別の長さを指定できます。小さなカテゴリでは、異なる名前が出尽くすため、要求した数より少なく返ることがあります。モデルは、名前のひとつを選ぶことも、変更することも、二つを組み合わせることもできます。詳しくは[ツールウィンドウ](tools.md#choosing-the-tools)にある *Name generator* スイートのヒントを参照してください。

<a id="commands"></a>

## コマンド

同じ名前は[コマンド](../commands/index.md)としても使えます。コマンドラインからも、[エージェント](../agents.md)からも使え、エージェントは自分のプロンプトの中でこれらを使えます（例えば[ロア・ジェネレーター](lore-generator.md)の `/generate-lore-entry` など）。

| コマンド | 内容 |
|---|---|
| `/list-name-categories [<filter>]` | カテゴリを JSON 配列として一覧表示します。フィルターを指定すると、名前のすべての語を含むカテゴリだけを表示します（各語は単語の先頭で始まる必要があり、順序は問わず、大文字と小文字は区別しません。例えば `chad male` は *Africa - Central Africa - Chad - Male* を見つけますが、*…Female* は見つけません）。 |
| `/generate-names category count [min_length [max_length]]` | カテゴリの名前を最大100個作り、JSON 配列で返します。毎回異なる名前が作られます。 |

どちらも読み取りのみです。

<a id="categories"></a>

## カテゴリ

カテゴリは約1270あります。名前を見れば内容がわかります。

- **世界の名と姓**。ケイト・モンクの Onomastikon に由来します（例：`Europe Western - France - Surnames`、`Ancient World - Egypt - Male`、`India - Hindu Gods - Goddesses`）。数百あります。
- **75か国の姓**。[国別人気名データセット](https://github.com/sigpwned/popular-names-by-country-dataset)（CC0）のローマ字化された姓です（例：`Armenia - Surnames`、`Japan - Surnames`、`Kosovo - Surnames`）。リストは小さめ（6個から約150個）なので、連鎖は短く、新しい名前は実在する名前に近くなります。実在する名前そのものが必要な場合は、[名前プロバイダー](name-provider.md)を使ってください。
- **ほかのコレクションのリスト**。神々、天使、悪魔、古代の都市と国家、皇帝、惑星（fantasygen）、そして Corpora（動物、タロット、トールキンの名前、『ゲーム・オブ・スローンズ』の家、薬品、病院、織物、宝石、プログラミング言語など）と markov-namegen-lib（ポケモン、ドラゴン、カクテル、銀行、ローマの地名など）です。

<a id="groups"></a>

### グループ

約170項目は、カテゴリをまとめた**グループ**です。ある言語の小さなリストを多数まとめるため、*Germany - Germanic - Male*、*Germany - Biblical - Male*、*Austria - First names - Male* などから選ぶかわりに、`German - Male` と指定できます。グループもカテゴリと同じように一覧に表示され、[ツールウィンドウ](tools.md)では一つの項目になります。グループは次のとおりです。

- **言語別**。該当するリストがあるものには `- Male`、`- Female`、`- Surnames` があります。ドイツ語、フランス語、スペイン語（姓にはラテンアメリカを含む）、イタリア語、ポルトガル語、オランダ語、スカンジナビア語、フィン語系、バルト語、アイルランド語、スコットランド語、ウェールズ語、ケルト語（すべて）、西・東・南スラブ語、ギリシャ語、ハンガリー語、ルーマニア語、アルバニア語、コーカサス諸語、テュルク語、ペルシア語、アラビア語、ユダヤ語、ヒンディー語（男性名の四つのアルファベット順リストをまとめたもの）、南アジア、東南アジア、マレー・インドネシア語、ポリネシア語、アフリカの地域（西、東、南、北、中央）。`Chinese`、`Japanese`、`Korean`、`Vietnamese` には `- Surnames` があります。
- **性別を問わないもの**。`<Language> - Forenames`（`German - Forenames`、`Spanish - Forenames`、`Celtic - Forenames` など）は、その言語の男性と女性のリストに加え、両性のリストも含みます。そのため、一度の呼び出しで男性と女性の名前が混ざって返ります（割合はリストの大きさに従い、ほとんどは男性が半分から四分の三程度です）。中国語、日本語、韓国語、ベトナム語にもあります。男女の割合が偏ってしまう言語（テュルク語、南アジア、西・南アフリカ、マレー・インドネシア語）には、男性と女性のグループしかありません。
- **過去のもの**。アングロサクソン、中世ゲルマン、中世英語、古代近東です。
- **北米先住民**。`Native American - Male`、`- Female`、`- Surnames`（Onomastikon の北米のカテゴリ：アパッチ、スー、イロコイ、チェロキー、イヌイットなど）と、中央アメリカと南アメリカ（アステカ、マヤ、インカ、アマゾン）の同様のものです。
- **その他**。`English - Surnames`（父称、職業、地名など）、`Saints`、`Deities`、`Fantasy Creatures`、`Game of Thrones Houses`。

拡張機能は、名前を作るたびに、まずグループのカテゴリのひとつをランダムに選び、そのカテゴリの連鎖（通常の長さ）で名前を作ります。これにより、名前は多くの民族や言語のごちゃ混ぜではなく、ひとつの民族や言語らしく聞こえます。また、一度の呼び出しで複数の民族の名前が返ることもあります。出身や文字で分けられている国のリストは、大きさに応じて選ばれます（600個の名前のリストは、10個のリストより選ばれやすくなります）。一方、言語全体や国全体のグループ（テュルク語、コーカサス諸語、バルト語、ポリネシア語、アフリカの地域、北米先住民など）では、すべての構成要素が同じ確率で選ばれます。一部のグループは出典が短く、英訳が部分的なもの（*Calf-Woman* など）もあるため、名前は粗くなります。
グループは `name-groups.json` の一行として定義されており（構成要素と選び方）、詳しくは[プラグインのREADME](https://github.com/Enerccio/Marginalia/blob/master/marginalia/plugins/name-generator/README.md#groups)を参照してください。

各カテゴリには、そのカテゴリに最も適した長さの連鎖があります（短いリストには短い連鎖が使われ、元の名前の繰り返しが少なくなります）。また、そのカテゴリの名前が通常持つ長さも決まっています。リストそのものは Marginalia の一部ではなく、含まれているのは確率だけです。そのため、元の名前を拡張機能から読み出すことはできません。出典の一部には独自のライセンスがあります。詳しくは[プラグインのREADME](https://github.com/Enerccio/Marginalia/blob/master/marginalia/plugins/name-generator/README.md)を参照してください。

<a id="usage"></a>

## 使い方

*Admin → Extensions* で拡張機能を読み込みます。次回の生成から適用されます。この機能を使う拡張機能は、読み込まれたときにこれを見つけます。後からインストールされた場合や、一度アンロードして再インストールされた場合も同様です。ロア・ジェネレーターを再起動する必要はありません。この拡張機能とほかのスイートがなければ、ロア・ジェネレーターには *ツール* ボタンが表示されません。
