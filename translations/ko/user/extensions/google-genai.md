# Google Gemini

Google의 Gemini 모델을 [추론 제공자](../inference-providers.md)로 추가합니다. OpenAI 호환 엔드포인트 대신 Google의 API를 직접 사용합니다.

Google은 OpenAI 호환 엔드포인트도 제공하며, 이는 일반 *OpenAI 호환* 제공자와 함께 쓸 수 있습니다. 이 확장 기능은 Gemini API를 직접(Google Gen AI SDK를 통해) 호출하며, 이렇게 해야만 가능한 기능이 있습니다. 모델의 생각을 요약한 내용을 추론으로 표시하는 기능, Gemini 3의 생각 수준과 이전 모델의 생각 예산 설정, 안전 필터, 그리고 Google이 보고하는 정확한 토큰 수가 여기에 해당합니다. 호환 엔드포인트에서는 이런 기능을 쓸 수 없습니다.

!!!warning 이야기 본문이 Google로 전송됩니다
이 제공자를 사용하는 AI의 모든 요청은 - 이야기가 담긴 프롬프트, 로어북 항목과 요약, 모델의 응답, 에이전트나 명령이 보내는 파일과 그림 - Google의 서버(`generativelanguage.googleapis.com`, 또는 설정한 프록시)로 전송됩니다. 그곳에서 데이터가 어떻게 보관되고 사용되는지(보관 기간, 모델 개선에 사용되는지 여부)는 Gemini API에 대한 Google의 약관과 개인정보 처리방침이 정하며, 이는 API 키의 요금제에 따라 다릅니다. 다른 제공자는 사용자가 선택한 서버(본인의 서버일 수도 있는 곳)로 전송합니다. 전송해도 괜찮은 것이 아니라면 이 제공자를 사용하지 마세요. 다른 사용자와 함께 쓰는 서버에서 관리자가 이 제공자의 AI를 공유하면, 그 AI를 사용하는 모든 사람의 이야기 본문이 Google로 전송됩니다.
!!!

<a id="installing"></a>

## 설치

*관리 → 확장 기능*에서 확장 기능을 불러옵니다. 자세한 내용은 [확장 기능 관리](../administration/extensions.md)를 참고하세요. JAR 파일은 약 14 MB로 큽니다. Google SDK와 SDK만 필요로 하는 라이브러리가 포함되어 있기 때문입니다. Marginalia의 다른 부분은 이 라이브러리를 사용하지 않습니다.

확장 기능을 불러오면 추론 제공자 대화상자의 **유형** 목록에 **확장 기능** 항목이 새로 생기고, *유형별 설정* 탭 상단의 **제공자** 목록에 **Google Gemini**가 나타납니다(이것이 유일한 항목이면 자동으로 선택됩니다). AI를 제공하는 확장 기능이 불러와지지 않은 상태에서는 **확장 기능**이 표시되지 않습니다.

<a id="adding-a-gemini-provider"></a>

## Gemini 제공자 추가하기

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 API 키를 발급받습니다.
2. **추론 제공자** 탭에서 **추론 제공자 추가**를 클릭하고, **이름**을 입력한 뒤, 유형으로 **확장 기능**을, 제공자로 **Google Gemini**를 선택합니다.
3. *일반 설정*(컨텍스트 크기, 응답 크기, [추론](#reasoning))과 *유형별 설정* 탭의 제공자 설정을 입력한 뒤 **연결 테스트**를 클릭합니다.

![확장 기능 유형 제공자의 일반 설정](../../images/plugin-googlegenai-general.png)

![Google Gemini 제공자의 유형별 설정](../../images/plugin-googlegenai.png)

제공자는 다른 제공자와 마찬가지로 목록에 나타나며, *유형* 열에 제공자 이름이 표시됩니다:

![Google Gemini 제공자가 있는 추론 제공자 목록](../../images/plugin-googlegenai-list.png)

| 필드 | |
|---|---|
| **API 키** | Google AI Studio의 키입니다. 암호화되어 저장되며 다시 표시되지 않습니다. 제공자를 편집할 때 다른 키를 입력하려면 **초기화**를 클릭하세요. |
| **모델** | 사용할 모델입니다(예: `gemini-2.5-flash`, `gemini-3-pro-preview`). **새로 고침**을 누르면 키로 텍스트 작성에 사용할 수 있는 모델 목록이 나타납니다. 목록에 없는 이름도 직접 입력할 수 있습니다. |
| **URL** | 선택 사항입니다. 비워 두면 Google의 API(`generativelanguage.googleapis.com`)를 사용하며, 요청을 프록시로 보내려면 이 값을 설정하세요. |
| **제한 시간 (초)** | Google이 응답하기까지, 그리고 글을 쓰기 시작한 뒤 다음 텍스트가 오기까지 기다리는 시간입니다. 기본값은 300입니다. |
| **재시도 횟수** | Google이 속도 제한(429)이나 서버 오류(5xx)로 응답하거나 연결할 수 없을 때 요청을 몇 번 반복할지 정합니다. 기본값은 2이며, 0으로 설정하면 재시도를 끕니다. |
| **안전 필터 끄기** | 조절 가능한 안전 범주(괴롭힘, 혐오 발언, 성적 노골성, 위험한 콘텐츠)에 대해 `BLOCK_NONE`을 보냅니다. 픽션은 종종 필터에 걸리므로 유용합니다. 다만 Google은 무엇을 보내든 일부 콘텐츠를 계속 차단합니다. |

**연결 테스트**는 모델 목록을 가져오고, 선택한 모델에 몇 개의 토큰을 생성해 보라고 요청합니다. 대화상자에 입력한 값을 기준으로 하며, 저장하기 전에도 실행할 수 있습니다.

<a id="reasoning"></a>

## 추론

추론 설정은 다른 제공자와 같이 제공자의 일반 설정에서 조정합니다.

- **추론 사용**을 끄면 모델은 기본 설정대로 생각하며, 그 생각은 표시되지 않습니다.
- 켜면 모델이 생각의 요약을 보내고, 그 요약이 이야기 부분의 추론으로 표시됩니다. **추론 강도**는 모델이 얼마나 생각할지를 정합니다. Gemini 3 모델에서는 생각 수준(낮음, 중간, 높음)이고, 이전 모델에서는 1,024, 8,192, 24,576 생각 토큰의 예산입니다. **없음**은 끄는 것과 같습니다.

생각 토큰은 생성된 토큰으로 집계되며, 설정한 응답 크기에서 차감됩니다. 모델이 응답 크기를 모두 생각에 쓰면 이야기 부분이 비어서 돌아오고, 오류 메시지에 응답 크기를 모두 사용했다고 나타납니다. 이때는 **최대 응답 토큰**을 올리거나 추론 강도를 낮추세요.

<a id="what-works"></a>

## 작동하는 기능

이야기에 필요한 기능은 모두 OpenAI 호환 제공자와 같이 작동합니다. 스트리밍, 생성 중단, 요약, [모델을 호출하는 확장 기능](index.md), 모델이 호출할 수 있는 함수(일부는 [이름 생성기](name-generator.md)가 제공합니다), 메시지에 첨부한 이미지와 파일이 여기에 포함됩니다. 사용자가 쓴 토큰은 Google이 보고한 수치를 바탕으로 **전송된 토큰**과 **생성된 토큰** 열에 집계되며, 공유 제공자의 [제한](../inference-providers.md#limits-of-shared-providers)도 적용됩니다.

이야기에 표시되는 토큰 수(부분의 크기, 프롬프트)는 Google이 계산합니다(모델의 `countTokens` 요청). 각 텍스트마다 한 번씩 계산되며, 결과는 저장됩니다. Google에 요청할 수 없는 경우(키가 없거나, 네트워크가 없거나, 오류가 발생한 경우)에는 Marginalia가 1분 동안 자체적으로 개수를 추정한 뒤 다시 Google에 요청합니다. 다른 저장 작업이 진행 중일 때 저장되거나 편집된 텍스트도 추정됩니다. 추정값은 Google이 청구하는 값과 조금 다를 수 있습니다.

<a id="when-the-extension-is-not-loaded"></a>

## 확장 기능이 불러와지지 않은 경우

확장 기능의 불러오기를 해제해도 만들어 둔 제공자는 *확장 기능: google-genai* 유형으로 목록에 남아 있으며, 확장 기능을 다시 불러오면 작동합니다. 확장 기능이 불러와지지 않은 상태에서는 이 제공자를 사용하는 책이 생성할 수 없습니다. 오류 메시지가 확장 기능을 불러오라거나 다른 제공자를 선택하라고 안내합니다. 불러와지지 않은 상태에서도 제공자를 열어 일반 설정을 바꿀 수 있습니다. Gemini 설정은 확장 기능이 불러와졌을 때만 표시되며, 그동안에는 값이 변경되지 않습니다.

<a id="not-supported"></a>

## 지원하지 않는 기능

- **Vertex AI**(프로젝트와 자격 증명을 사용하는 Google Cloud). Gemini API의 API 키만 지원합니다.
- 이미지 생성 등 Gemini의 다른 출력 형식. 텍스트만 작성됩니다.
