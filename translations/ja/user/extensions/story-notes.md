# ストーリーノート

サイドバーにある、本のための小さなウィキです。計画中のプロット、まだ使う準備のできていないアイデア、魔法体系のルール、悪役が本当に望んでいることなど、ページごとにまとめられます。内容はあなた自身の考えを、あなた自身の言葉で書いたものです。タグやページ同士のリンクも使えます。[作者のノート](authors-note.md)は生成のたびにモデルへ送られる1つのテキストですが、ノートはそれ単体ではモデルに送られません。[プロットウィザード](arc-outline.md#developing-the-plot-in-a-conversation)やエージェントはノートを読むことができ、許可すればノートを変更することもできます。

<a id="the-notes-tab"></a>

## ノートタブ

[ストーリーエディタ](../books/story-editor.md)の左サイドバーには、*アウトライン*の隣に**ノート**タブがあります。このタブには、本のページがタイトル順に並んで表示されます。リストの上には、**追加**（新しいページを作成）、**タグ**での絞り込み（ページにタグが付いたときに表示されます）、そしてタイトル・タグ・ページ本文を対象とした検索があります。

各ページには、タイトル、本文の1行目、タグが表示されます。ページをクリックするか鉛筆のアイコンを押すと開きます。ゴミ箱のアイコンを押すと、確認の後にページが削除されます。タイトルの後ろには、2つの小さなマークが付くことがあります。目が斜線で消されたマークは、そのページが[アシスタントから隠されている](#what-assistants-can-see)ことを示します。杖のマークは、最後の変更がユーザーの操作ではなくコマンドによるものだったことを示します。

![ノートタブ：アシスタントから隠されたページ（目のマーク）と、プロットウィザードが追記したページ（杖のマーク）](../../images/plugin-storynotes-tab.png)

<a id="a-page"></a>

## ページ

ページのダイアログには、次の項目があります。

| | |
|---|---|
| **タイトル** | 必須。本の中で一意であること（大文字と小文字は区別しません）。角かっこや縦棒は使えません（`|`）。他のページはこのタイトルを使ってリンクします。 |
| **タグ** | カンマで区切って入力します。リストの絞り込みに使われます。 |
| **テキスト** | Markdownで書きます。**書く**と**プレビュー**で、テキストの編集と表示結果を切り替えられます。本文中の`[[Title]]`は、そのタイトルのページへのリンクになります。`[[Title|other words]]`もそのページへのリンクですが、プレビューでは*別の言葉*（`[[Language barrier|how they talk]]`）が表示されます。 |
| **アシスタントに表示** | 初期状態ではオンです。詳しくは後述します。 |

テキストの下には、ダイアログがそのテキストが**リンクしている**ページを一覧表示します。存在するページへのリンクはそのページを開き、存在しないページへのリンクには**作成**が表示され、そのタイトルで新しいページを作成します。その下には、このページに**リンクしている**ページが表示されます。ページ名を変更すると、他のページにある`[[links]]`が新しい名前に書き換えられます（リンクに表示される文字は変わりません）。

![リンクしているページと、このページにリンクしているページを表示したページ](../../images/plugin-storynotes-page.png)

**プレビュー**では、テキストがMarkdownとして表示され、すべての`[[link]]`がリンクとして表示されます。クリックするとそのページが開きます（存在しないページへのリンクをクリックすると、そのタイトルで新しいページが作成されます）。

![同じページのプレビュー](../../images/plugin-storynotes-preview.png)

**保存**を押すまでは何も保存されません。変更したページを閉じようとすると、変更を破棄するかどうか確認されます。編集中のページがコマンドによって変更された場合は、あなたの版で上書きしてよいかどうか確認されます。**Ctrl/Cmd+Enter**で保存できます。ページは本のデータと一緒に保存されるため、バックアップやコピーにも含まれます。

<a id="what-assistants-can-see"></a>

## アシスタントから見えるもの

「アシスタント」とは、ノートが提供するコマンドを利用する仕組みのことです。エージェント、マクロ、プロットウィザードがこれを使います。**アシスタントに表示**がオフになっているページは、アシスタントにとって存在しないのと同じです。一覧に出ず、検索されず、読まれず、変更もされません。また、そのページにしかないタイトルでページを作成しようとしても拒否されます。あなただけが見るべき内容には、この設定をオフにしてください。アシスタントから隠したページも、バックアップには引き続き含まれます。

コマンドは、コマンドバーとエージェントの両方で使えます。タイトルはページのアドレスとして使われます。

| コマンド | |
|---|---|
| `/list-notes [<tag>]`、`/get-note <note>`、`/search-notes <query>` | ページの一覧、1ページの本文・リンク・そのページにリンクしているページ、そして検索。 |
| `/create-note <title> [<content> [<tags>]]` | ページを追加します。 |
| `/append-to-note <note> <text>` | ページの末尾に段落を追加します。 |
| `/update-note <note> [<title> [<content> [<tags>]]]`、`/edit-note <note> <find> <replace> [<all>]` | ページを変更するか、本文の一部を置き換えます。`find`はページ内に書かれているとおりに存在しなければならず（大文字と小文字は区別されます）、`all`が`true`でない限り、ちょうど1回だけ出現する必要があります。`all`を使うと、出現するすべての箇所が置き換えられます。人名や用語をページ全体で書き換えたいときに便利です。結果には、置き換えられた箇所の数が表示されます。これらのコマンドは既存のテキストを変更するため*破壊的*です。確認モードに設定されたエージェントは、実行前にあなたに確認します。 |
| `/delete-note <note>` | ページを削除します。確認の後に実行されます。 |
| `/note-text <note>` | ページの本文を取得します。マクロ用です。{%{`{{command::note-text::Magic}}`}%}と書くと、その本文がテンプレートに差し込まれます。存在しないページや隠されたページの場合は空になります。 |

コマンドによって変更されたページには、あなたが自分で保存するまで杖のマークが付きます。

<a id="with-the-plot-wizard"></a>

## プロットウィザードと使う

この拡張機能がインストールされている場合、アークアウトラインの[プロットウィザード](arc-outline.md#developing-the-plot-in-a-conversation)に**ノートを送る**オプション（タイトルと1行目、全文、または何も送らない）と、**ノート**ツールのグループが追加されます。モデルはページを検索して読んだり、リンクをたどったり、あなたが何かを残すよう頼んだときにページを追加したり既存のページに追記したり、ページ内のテキストを変更したりできます。**何かを変更または削除する前に確認する**がオンのあいだは、ページのテキストを変更する前に確認されます。ウィザードがページを削除することはできません。このオプションとグループについては、ウィザードの表を参照してください。

![ノートのツールを使うプロットウィザード：ページを読み、未解決の問いをそこに追加したところ](../../images/plugin-storynotes-wizard.png)

<a id="other-extensions"></a>

## 他の拡張機能

この拡張機能は、他の拡張機能に2種類のテキストソースを提供します。[サイドクエリ](side-query.md)は、プラグボタンからこれらを添付できます。その2つとは、**ストーリーノート（タイトル）**と**ストーリーノート（すべて）**です。どちらも隠されたページは含みません。
