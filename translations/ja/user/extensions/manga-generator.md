# マンガジェネレーター

物語をマンガにします。モデルが本の一部をページとコマからなる脚本に作り替え、そのあとで各コマの画像生成タグを書きます。Stable Diffusion、Forge、Midjourney などにそのまま使えます。SillyTavern の [MangaGenerator](https://github.com/Enerccio/SillyTavern-MangaGenerator) 拡張機能を移植したものです。

<a id="opening-it"></a>

## 開き方

[ストーリーエディター](../books/story-editor.md)の設定メニュー（⚙）から **マンガジェネレーター** を選びます。大きなウィンドウが開きます。ストーリー画面そのものには何も追加されません。ウィンドウはドラッグで動かせ、サイズも変えられます。

<a id="mangas"></a>

## マンガ

1 冊の本に複数のマンガを持たせられます。マンガはウィンドウ上部にタブで表示されます。タブの横のボタンで、マンガの追加（+）、名前の変更、左右への移動、削除ができます。マンガは本と一緒に保存されるので、本のバックアップやコピーにも含まれます。

タブの下には、開いているマンガの設定があります。

| 設定 | 役割 |
|---|---|
| モデルとプロトコル | リクエストの送り先です。初期値は本のモデルで、直前の選択が記憶されます。 |
| トークン予算 | モデルに求める脚本の長さです（プロンプト中の `{{tokenBudget}}`）。 |
| セクションごとのパート数 | 新しいセクションが取り込むストーリーのパート数です。 |
| 前の文脈 / 後の文脈 | 新しいセクションが背景としてモデルに渡す、前後のパート数です。 |
| 脚本プロンプト、タグプロンプト | このマンガで組み込みのプロンプトを置き換えます。**デフォルトに戻す**で組み込みの文面に戻ります。 |
| 追加ルール | 脚本プロンプトの `{{additionalRules}}` の位置に入ります。独自のルール（効果音なし、画風など）を書くのに使います。 |
| すべてコピー | マンガのすべての脚本と、すべてのタグ文をまとめてクリップボードにコピーします。 |
| 連続モード | マンガを自動で生成します。[連続モード](#continuous-mode)を参照してください。 |

<a id="settings"></a>

## 設定

*設定 → 拡張機能の設定 → Manga Generator Settings* には、**新しい**マンガが最初に使う値を設定します。トークン予算、セクションごとのパート数、前後の文脈、脚本プロンプト、タグプロンプト、追加ルールのほか、すべてのマンガに共通する指示を、リクエストの前に毎回添える文章としても設定できます。プロンプトを空のままにする、または変更しない場合は組み込みのものが使われます。作成済みのマンガは、それぞれ自分の設定を保持します。このパネルは *設定* ページの **保存** ボタンで保存します。

<a id="sections"></a>

## セクション

**セクションを追加** を押すと、直前のセクションの続きのパートを対象とするセクションが追加されます（最初のセクションはパート 1 から始まります）。パートは概要と同じく 1 から番号が振られます。セクションには次の項目が表示されます。

- **パート〜から / パート〜まで**（取り込み）：モデルがコマに変換するパートです。
- **パート〜から / パート〜まで**（文脈）：モデルが読むパートです。取り込み範囲の外にあるものは背景（それより前の出来事、またはこの後に続く出来事）にすぎず、モデルはそれらを取り込まないよう指示されます。4 つの数字はいつでも変更でき、別の範囲を取り込みたいときに使います。

各セクションには **脚本** と **タグ** の 2 つの表示があります。

1. **脚本を生成** を押すと、脚本がセクションにストリーミングで書き込まれます。推論を行うモデルの思考過程は、脚本の上に表示されます（*12.3 秒間思考* など）。脚本のページ番号は直前のセクションから続き、直前の脚本で既に扱われた内容は繰り返しません。
2. **タグ** に切り替えて **タグを生成** を押すと、脚本の各コマについて、登場人物と場面のタグが生成されます。

![脚本を表示したセクションのあるマンガジェネレーターのウィンドウ](../../images/plugin-manga.png)

どちらの文章も手で**編集**（ペンのアイコン）でき、**コピー**もできます。生成は **中止** で止められ、それまでにモデルが書いた分は残ります。セクションはそれぞれ独立して生成されるので、複数のセクションを同時に始められます。いずれかのモデルが書いている間は、セクションを削除することも、マンガを変更することもできません。

![同じセクションのタグ表示](../../images/plugin-manga-tags.png)

**上書き** を使うと、1 つのセクションだけに独自の脚本プロンプト、タグプロンプト、追加ルールを設定できます。マンガのルールを置き換えるのではなく追加する **ルールの追記** を指定することもできます。目のアイコンを押すと、モデルに実際に送られるリクエストと、そのサイズが表示されます。

<a id="continuous-mode"></a>

## 連続モード

**連続モード**（*セクションを追加* の隣）を使うと、マンガが自動で書き進められます。テキストの種類を 1 つずつ生成するので、モデルには同じプロンプトが何度も送られます（プロンプトのキャッシュを持つサーバーであれば、それを再利用できます）。ボタン横の欄で、生成する内容を選びます。

- **脚本のみ**：セクションを順番にたどり、脚本がまだないセクションすべての脚本を生成します（脚本のあるセクションはそのままです）。すべてに脚本ができると、次のパートのためのセクションを追加します（*セクションを追加* と同じく、マンガの *セクションごとのパート数* と文脈の設定を使います）。そのセクションの脚本を生成し、物語に取り込むパートがなくなるまで続けます。
- **タグのみ**：脚本はあるがタグがないすべてのセクションについて、タグを生成します。セクションは追加しません。すべての脚本にタグができた時点で終わります。

どちらの場合も、**連続モードを停止** を押すと終わります（ボタンがそれに変わります。それまでにモデルが書いた分は残ります）。モデルでエラーが起きた場合、取り込むパートに本文のないセクションがあった場合、空の応答が返った場合も、メッセージとともに停止します。実行中はセクションを手で生成・変更することも、マンガを変更することもできません。実行中にウィンドウを閉じると、[実行中の一覧パネル](../books/story-editor.md#the-panel-of-the-runs)にまとめられ、処理は続きます。そこで停止すると止まります。処理中の各セクションは、表示領域に自動的にスクロールされます。両方を行うには、先に *脚本のみ* を実行し、そのあと *タグのみ* を実行してください。

<a id="the-lore-and-the-size-of-the-context"></a>

## ロアと文脈のサイズ

モデルには、セクションのパートの本文と、その本文が必要とするロアが渡されます。ロアとは、本のロアブックのエントリー（およびそのサブのロアブック）のうち、本文中にフィルターのキーワードが現れるものです。検索は生成時と同じ方法で、スキャンの深さも含みます。常時有効なエントリーも含まれます。そのため、そのパートに登場する人物や場所は説明文と一緒にモデルに届き、画像のタグに必要な情報になります。

これらはすべて、モデルの**コンテキストサイズ**に収まる必要があります。コンテキストサイズとは、AI とプロトコルのコンテキストから返信のための余白を引いた量です。エントリーが収まらない場合、後のものから除外されます（何件除外されたかが通知され、目のアイコンにも表示されます）。セクションを小さくするか、ロアを短くしてください。ロアを除いても収まらないリクエストも、警告付きで送信されます。

<a id="what-is-different-from-sillytavern"></a>

## SillyTavern との違い

- チャットのメッセージは物語の**パート**にあたります。メッセージの前に名前は付かず、ペルソナやキャラクターカードもありません。登場人物はロアブックから取得されます。
- 拡張機能のワールドインフォの「トリガー」は必要ありません。ロアは本文そのものによって有効になります。
- コンテキストサイズは AI とプロトコルから取得されるので、そのための設定はありません。
- 物語の 1 パートは一般的なチャットメッセージよりずっと長いため、新しいセクションは前後に 1 パートずつの文脈を付けた 3 パートになります。これは設定で変更できます（上記参照）。
- タブはドラッグではなく、矢印ボタンで移動します。
