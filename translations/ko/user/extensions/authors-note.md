# 작가의 노트

책을 생성할 때마다 모델에게 함께 보내지는 메모입니다. 지금 원하는 어조, 현재 챕터의 내용, 모델이 자꾸 잊어버리는 사항 등을 적어 둘 수 있습니다. 한 턴의 지시와 달리 노트는 직접 바꾸기 전까지 계속 유지됩니다.

<a id="the-authors-note-tab"></a>

## 작가의 노트 탭

[스토리 편집기](../books/story-editor.md)의 왼쪽 사이드바에서 *개요* 옆에 **작가의 노트** 탭이 생깁니다. 입력하는 내용은 책에 바로 저장되며, 다음 생성부터 사용됩니다.

![작가의 노트 탭](../../images/plugin-authorsnote.png)

| 필드 | |
|---|---|
| **프롬프트에 삽입** | 노트를 삭제하지 않고 켜거나 끕니다. |
| **삽입 깊이** | 노트가 놓일 위치를 프롬프트 끝에서부터 메시지 개수로 셉니다: `0` - 턴의 지시 바로 뒤(맨 마지막 메시지), `1` - 지시 바로 앞, `2` - 마지막 스토리 파트 앞, 이런 식입니다. 깊이를 크게 하면 노트가 시스템 프롬프트 바로 뒤에 놓입니다. |
| **역할** | 노트를 *시스템*, *사용자*, *어시스턴트* 중 어떤 메시지로 보낼지 정합니다. |
| **작가의 노트** | 모델에게 전달되는 텍스트입니다. 비어 있는 노트는 보내지지 않습니다. 아래에는 노트 크기를 토큰 수로 추정한 값이 표시됩니다. |
| **작가의 노트(비공개)** | 나만 보는 메모입니다(계획, 상기 사항 등). 모델에게는 절대 보내지지 않습니다. |

!!!
노트가 프롬프트 끝에 가까울수록 효과가 강해집니다. 역할을 *시스템*으로 하고 깊이를 `1`로 두는 것이 좋은 출발점입니다.
노트는 [템플릿](../templates/macros.md)으로 처리되지 않습니다. 매크로는 적힌 그대로 전송됩니다.
!!!

<a id="how-the-prompt-looks"></a>

## 프롬프트의 구성

생성 시에는 먼저 시스템 프롬프트가 보내지고, 그다음 스토리가 채팅 형태로 이어지며(각 파트는 *스토리 생성*에 대한 모델의 답변으로 취급됩니다), 마지막으로 턴의 지시가 보내집니다. 깊이가 `1`이면 노트는 지시 바로 앞에 삽입됩니다.

1. 시스템 프롬프트(템플릿, 로어, 요약)
2. 스토리 파트들…
3. **작가의 노트**
4. 턴의 지시

노트의 토큰은 스토리에 쓸 수 있는 공간에서 차감됩니다. 노트가 길수록 프롬프트에 들어가는 스토리 파트는 줄어듭니다. 노트 때문에 나머지 프롬프트를 넣을 공간조차 남지 않으면 생성이 *컨텍스트 한도가 부족합니다* 메시지와 함께 중단됩니다.

<a id="the-note-as-a-macro"></a>

## 매크로로 쓰는 노트

자동 삽입 대신(또는 자동 삽입과 함께) [{%{`{{command::authors-note}}`}%} 매크로](../templates/macros.md#commands)로 노트를 직접 배치할 수 있습니다. 이 매크로를 마스터 템플릿, 사용자 프롬프트 또는 로어 항목에 넣으면, 프롬프트에서 원하는 위치에 노트의 텍스트가 출력됩니다. 매크로는 **프롬프트에 삽입** 설정과 관계없이 현재 저장된 노트를 그대로 출력하므로, 매크로로 배치할 때는 이 설정을 끄십시오. 그렇지 않으면 모델이 노트를 두 번 받게 됩니다. 깊이와 역할은 매크로에 적용되지 않습니다(노트는 매크로가 들어 있는 메시지의 일부가 됩니다). 비어 있는 노트는 아무것도 출력하지 않습니다.

<a id="storage"></a>

## 저장

노트는 책과 함께 저장되므로 [책 백업](../books/backups.md)과 사본에도 포함됩니다.
