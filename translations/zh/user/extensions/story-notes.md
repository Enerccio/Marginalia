# 故事笔记

这是侧边栏中为你的书准备的一个小型维基：用来记录你正在规划的情节、暂时还不打算用上的想法、魔法体系的规则，以及反派真正想要什么。这些内容是你自己的思考，用你自己的语言写成，页面之间可以用标签和链接相互关联。与[作者注释](authors-note.md)不同——后者是随每次生成一并发送的一段文字——笔记本身不会单独发送给模型。[情节向导](arc-outline.md#developing-the-plot-in-a-conversation)和智能体可以读取这些笔记，并且在你允许的情况下修改它们。

<a id="the-notes-tab"></a>

## 笔记标签页

[故事编辑器](../books/story-editor.md)左侧边栏在 *Outline* 旁边有一个 **Notes** 标签页。它会按标题顺序列出这本书的所有页面。列表上方有 **Add**（新建页面）按钮、按**标签**筛选的功能（页面有标签后才会显示），以及一个可搜索标题、标签和页面正文的搜索框。

每个页面都会显示其标题、正文的第一行以及标签。点击页面或铅笔图标即可打开；点击垃圾桶图标会在确认后删除该页面。标题旁可能出现两个小标记：一个划掉的眼睛（表示该页面[对助手隐藏](#what-assistants-can-see)），以及一根魔杖（表示最近一次修改来自命令，而不是你本人）。

![笔记标签页：一个对助手隐藏的页面（眼睛标记），以及一个情节向导添加过内容的页面（魔杖标记）](../../images/plugin-storynotes-tab.png)

<a id="a-page"></a>

## 页面

页面的对话框包含以下内容：

| | |
|---|---|
| **Title** | 必填，在同一本书中必须唯一（不区分大小写），不能包含方括号或竖线（`|`）。其他页面通过它来链接到此页。 |
| **Tags** | 用逗号分隔。用于筛选列表。 |
| **Text** | Markdown 格式。**Write** 和 **Preview** 用于在编辑文本与预览效果之间切换。正文中的 `[[Title]]` 会链接到标题为 Title 的页面；`[[Title|other words]]` 同样链接到该页面，但在预览中显示 *other words*（例如 `[[Language barrier|how they talk]]`）。 |
| **Visible to assistants** | 默认开启。详见下文。 |

在正文下方，对话框会列出本页正文**链接到的**页面：链接到已存在页面的，点击即可打开；链接到不存在页面的，会提供 **Create** 选项，用该标题新建一个页面。再往下是**链接到此页**的页面。重命名页面时，其他页面中指向它的 `[[链接]]` 会随之更新（链接显示的文字保持不变）。

![一个页面，显示它链接到的页面以及链接到它的页面](../../images/plugin-storynotes-page.png)

**Preview** 会将正文以 Markdown 形式呈现，每个 `[[链接]]` 都显示为可点击的链接：点击即可打开对应页面（链接到不存在的页面时，会以该标题新建一个页面）：

![同一页面的预览效果](../../images/plugin-storynotes-preview.png)

在点击 **Save** 之前，任何内容都不会被保存；如果关闭一个已修改的页面，系统会先询问是否放弃更改。如果你在编辑页面时该页面已被某条命令修改，系统会询问你是否要用自己的版本覆盖它。按 **Ctrl/Cmd+Enter** 可直接保存。页面与书籍一起存储，因此会包含在它的备份和副本中。

<a id="what-assistants-can-see"></a>

## 助手可以看到什么

“助手”指笔记功能提供的各类命令，智能体、宏以及情节向导都会使用这些命令。关闭了 **Visible to assistants** 的页面对它们而言等同于不存在：不会被列出、搜索到、读取或修改；当它们尝试创建一个只有该隐藏页面使用的标题时，也会被拒绝。请将只希望自己看到的内容设为隐藏。你关闭显示的页面仍会保留在备份中。

命令如下（用于命令栏和智能体；标题即页面的地址）：

| 命令 | |
|---|---|
| `/list-notes [<tag>]`、`/get-note <note>`、`/search-notes <query>` | 列出页面；查看某一页面的正文、链接以及链接到它的页面；或进行搜索。 |
| `/create-note <title> [<content> [<tags>]]` | 新建一个页面。 |
| `/append-to-note <note> <text>` | 在页面末尾添加一段文字。 |
| `/update-note <note> [<title> [<content> [<tags>]]]`、`/edit-note <note> <find> <replace> [<all>]` | 修改页面，或替换其中的一段文字：`find` 必须与页面中的内容完全一致（区分大小写），并且除非 `all` 为 `true`，否则只能恰好出现一次；当 `all` 为 `true` 时，所有匹配处都会被替换，适用于全文统一修改某个名称或术语。回复会说明替换了多少处。这些命令会改动已有文字，属于*破坏性*操作：若智能体设置为先询问，它会先征求你的同意。 |
| `/delete-note <note>` | 删除一个页面，删除前需要确认。 |
| `/note-text <note>` | 返回页面的正文，供宏使用：{%{`{{command::note-text::Magic}}`}%} 会将其放入模板中。若页面不存在或已隐藏，则返回空内容。 |

被命令修改过的页面会带有魔杖标记，直到你自己保存它为止。

<a id="with-the-plot-wizard"></a>

## 与情节向导配合使用

安装此扩展后，Arc Outline 中的[情节向导](arc-outline.md#developing-the-plot-in-a-conversation)会增加一个 **Send the notes** 选项（可选择发送标题及其首行、完整正文，或不发送），以及一组 **Notes** 工具：模型可以搜索并阅读页面、顺着链接查看，当你要求它记住某些内容时添加新页面或向已有页面追加内容，并修改页面中的文字。在 *Ask me before it changes or deletes something* 开启的情况下，修改页面正文前会先征求你的同意；情节向导无法删除页面。这一选项和工具组可在向导的表格中查看。

![带有笔记工具的情节向导：它读取了一个页面，并将未解决的问题添加到其中](../../images/plugin-storynotes-wizard.png)

<a id="other-extensions"></a>

## 其他扩展

该扩展为其他扩展提供两种文本来源：**Story notes (titles)** 和 **Story notes (all)**（[Side Query](side-query.md)可通过其插件按钮附加它们）。两者都会排除隐藏的页面。
