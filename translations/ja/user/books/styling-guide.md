# スタイルガイド：本を自分の本らしく見せる

**テキストスタイル**は、パートの文章の見た目を決めます。フォント、色、本文の段の幅、見出し、場面の間の区切り線などが含まれます。このガイドでは、最初の変更から仕上がった見た目までを順に説明し、最後に、すべてのオプションと独自の CSS を使ったホラー小説用のスタイルを完全な例としてダウンロードできるように紹介します。

スタイルが使われる場所は次のとおりです。

| 場所 | 何が起きるか |
|---|---|
| **ストーリーエディタ** | 本のスタイル（またはデフォルト）が、すべてのパートの見た目になります。[テキストスタイル](story-editor.md#text-styles)を参照してください。 |
| **リーダー** | [公開された本](publishing.md)は、読者が自分のスタイルから選んだもの（選ぶまでは本のスタイル）で読まれます。 |
| **エクスポート** | **For exports** を指定したスタイルは、[エクスポートダイアログ](export.md#print-styles)で選びます。HTML と EPUB はスタイルシートを使い、PDF と Word は数値を使います（[各エクスポートが使う要素](#what-the-exports-take)を参照してください）。 |

<a id="make-your-first-style"></a>

## 最初のスタイルを作る

1. **Settings → Styles** を開きます（[Styles タブ](../account.md#styles)）。
2. リストで **ブック** を選び、**複製** を押します。組み込みのスタイルは変更できないため、作業は必ず *ブック (copy)* という名前のコピーから始まります。名前を付けてください。
3. **オプション** タブでいくつかの項目を変更します。フォームの下の **プレビュー** には見本の文章（章のタイトル、強調、引用、場面の区切り、小さい見出し）が表示され、入力するたびに変更が反映されます。
4. 設定の **保存** を押します。それまでは何も保存されず、**変更を破棄** を押すと作業内容が捨てられます。
5. ストーリーエディタで設定メニュー（⚙）→ **表示** → **テキストのスタイルを変更** を開き、自分のスタイルにチェックを入れます。これは本に保存されます。すべての本で使いたい場合は、リストでそのスタイルを選び、**デフォルトにする** を押します。

![メニュー内のストーリーのスタイル](../../images/story-style-menu.png)

空欄の項目はアプリケーションの見た目のままになるため、スタイルには変えたいものだけを書けばよいことになります。すべての項目が空のスタイルは、素のままの見た目です。

<a id="the-options"></a>

## オプション

どの項目にも CSS の値を入力します。よく使う単位は次のとおりです。`rem`（ページの文字の大きさ。通常 1rem は 16px）、`em`（現在の文字の大きさ）、`px`、`%`。色は `#336699`、`rgb(51, 102, 153)`、または `ivory` のような名前で指定します。

<a id="text"></a>

### 文字

| オプション | 働き | 例 |
|---|---|---|
| **Font family** | 文字のフォントです。リストで指定します。コンピュータにある最初のフォントが使われ、最後には総称のファミリ（`serif`、`sans-serif`、`monospace`）を置くのがよいでしょう。 | `"Garamond", "Georgia", serif` |
| **Font size** | 文字の大きさです。 | `1.1rem` |
| **Line height** | 行と行の間隔です。単位のない数値は、フォントサイズの倍率になります。 | `1.7` |
| **Letter spacing**、**Word spacing** | 文字どうしの間隔、単語どうしの間隔を広げます。小さな値を使い、わずかな文字間隔を入れると、文章がゆったり見えます。 | `0.01em`、`0.05em` |
| **Text color** | 文字の色です。 | `#cfc6bb` |
| **Text align** | `left`、`right`、`center`、または `justify` です。 | `justify` |
| **Hyphenation** | 行末で長い単語を分割します。本の[言語](managing-books.md#the-about-tab)の辞書を使うため、先に言語を設定してください。*justify*（両端揃え）と併用するのが最適です。 | on |
| **Paragraph spacing** | 段落の下の余白です。本では通常ほとんど空けず、一行目の字下げを使う場合は特にそうします。 | `0.3em` |
| **First line indent** | 段落の一行目を字下げします。印刷された本と同じ形式です。ただし、見出しや場面の区切りの直後は字下げしません。 | `1.5em` |
| **Drop cap** | 見出しの後の最初の段落の、最初の文字を大きく表示します。 | on |

<a id="page"></a>

### ページ

| オプション | 働き | 例 |
|---|---|---|
| **Text width** | 指定した幅の段を中央に配置します。1行が 60 から 75 文字だと最も読みやすく、およそ `34em` から `40em` が目安です。 | `38em` |
| **Background color** | 文字の後ろの色です。テキストのブロックだけでなく、領域全体を塗ります。その上で読みやすい文字色を選んでください。 | `#0c0a0a` |

<a id="emphasis-links-and-code"></a>

### 強調、リンク、コード

| オプション | 働き |
|---|---|
| **Emphasis color** | *斜体* の文字の色です。 |
| **Strong color** | **太字** の文字の色です。 |
| **Link color** | リンクの色です。 |
| **Code font family** | `code` とコードブロックのフォントです。 |

<a id="quotes"></a>

### 引用

| オプション | 働き |
|---|---|
| **Quote color** | 引用文（`> a line`）の文字の色です。 |
| **Quote border color** | 引用の横に付く線の色です。 |

<a id="headings"></a>

### 見出し

| オプション | 働き |
|---|---|
| **Heading font family** | `#`、`##`、`###` 見出しのフォントです。 |
| **Heading size** | 第一レベルの大きさです。下のレベルは比率に応じて小さくなります。 |
| **Heading color** | 見出しの色です。 |
| **Heading align** | `left`、`center`、または `right` です。 |
| **Heading small caps** | 見出しをスモールキャピタル（小型大文字）で表示します。 |

<a id="scene-break"></a>

### 場面の区切り

本文に `---` と書かれた行は、場面の区切りになります。初期設定では三つの点です。**Scene break text** は代わりに表示される文字（`* * *`、`~`、`† † †`）で、**Scene break color** はその色です。

<a id="custom-css"></a>

## カスタム CSS

オプションで一般的なことは設定できます。それ以外の細かな指定には、**カスタム CSS** タブに自分の CSS を書きます。書いた内容は他のすべての設定の後に追加され、そのスタイルの中でだけ適用されます。書き方は二つあります。

- **単純な宣言** は、文章を含む領域全体に適用されます。

  ```css
  box-shadow: inset 0 0 120px rgba(0, 0, 0, 0.8);
  ```

- **セレクタ付きのルール**。セレクタの前に `&`（スタイルの領域）を付けるか、付けないかのどちらでも書けます。どちらの場合も、このスタイルの文章にだけ効きます。

  ```css
  & .chat-message-markdown h1 { text-shadow: 0 0 12px #8e1b17; }
  & .chat-message-markdown a:hover { color: #b3261e; }
  ```

パートの本文は、クラス `chat-message-markdown` を持つ要素の中にあるので、本文の中の何かを指定するセレクタはそこから始まります。CSS の入力欄の下にある **生成された CSS** フィールドには、オプションによって作られたスタイルシートが表示されます。そのセレクタをコピーすると、何を上書きできるかがわかります。

| 変更したいもの | セレクタ（`& .chat-message-markdown` の後に続けます） |
|---|---|
| 段落 | `p` |
| 見出し | `h1`、`h2`、`h3` |
| 斜体、太字 | `em`、`strong` |
| リンク | `a`、`a:hover` |
| 引用 | `blockquote` |
| リスト | `ul`、`ol`、`li` |
| コード | `code`（インライン）、`pre`（ブロック） |
| 場面の区切り | `hr`、`hr::after`（記号） |
| 段落の一行目 | `p::first-line` |
| 選択したテキスト | `::selection` |

知っておくとよいこと：

- **波かっこ `{ }` は対応している必要があります**。対応していない場合、保存時にそのスタイルは受け付けられません。コメント `/* ... */` は使えます。
- アプリケーションに必要なルールの一部は `!important` で定められています（文章が領域より広くならないこと、長い単語が折り返されること、段落の改行が保たれることなど）。CSS でこれらを上書きすることはできません。それ以外はすべて上書きできます。CSS は後から追加されるためです。
- CSS で変えられるのは見た目であって、文章の内容ではありません。文章の周りのツールバーやタブには届きません。
- カスタム CSS は、ストーリー、リーダー、HTML エクスポートで使われます。EPUB、PDF、Word では使われません。

<a id="what-the-exports-take"></a>

## エクスポートで使われるもの

エクスポート用のスタイルは、[エクスポートダイアログ](export.md#print-styles)で選びます。スタイルを **複製** して **For exports** にチェックを入れるか、アプリケーションに用意されている四つのスタイルのどれかから始めてください。アプリケーションのテーマに依存する色（ダークテーマの明るい文字など）は、エクスポートの際、白いページ向けの暗い色に変わります。

| | HTML | EPUB | PDF | Word |
|---|---|---|---|---|
| フォント、大きさ、行の高さ、間隔、配置、一行目の字下げ | ✓ | ✓ | ✓ | ✓ |
| 文字、強調、太字、引用、見出し、場面の区切りの色 | ✓ | ✓ | ✓ | ✓ |
| 背景色 | ✓ | ✓ | ✓ | ✓（ページの色） |
| 段の幅、ドロップキャップ、ハイフネーション、見出しのスモールキャピタル | ✓ | ✓ | | |
| カスタム CSS | ✓ | | | |

電子書籍リーダーは、スタイルシートの指定に関係なく、独自のフォント、大きさ、色を使うことがよくあります。PDF と Word は、その形式が持つフォントしか使えません。PDF は、書いたフォントの並びから明朝、ゴシック、等幅のいずれかを選びます。Word は、並びの最初のフォント名を指定し、コンピュータにそのフォントがなければ独自のフォントを表示します。
<a id="share-a-style-export-and-import"></a>

## スタイルの共有: エクスポートとインポート

スタイルの一覧の下にある **エクスポート** は、選択したスタイルをファイルとして保存します（`name.style.json`。組み込みのスタイルもエクスポートできます）。**インポート** は、そのようなファイルを読み込みます。
インポートしたスタイルは、自分のスタイルに新しいスタイルとして追加されます。**保存** を押すまでは保存されません。名前はそのまま引き継がれるため、似た名前のスタイルが既にある場合は名前を変更してください。

ファイルは JSON 形式です:

```json
{
  "format": "marginalia-text-style",
  "version": 1,
  "styles": [
    {
      "name": "My style",
      "forExport": false,
      "options": { "FONT_SIZE": "1.1rem", "TEXT_COLOR": "#222222" },
      "customCss": "& .chat-message-markdown h1 { letter-spacing: 0.1em; }"
    }
  ]
}
```

複数のスタイルをまとめて含めることもできますし、手で書くこともできます。オプションは大文字の名前で指定します（`FONT_SIZE`、`TEXT_COLOR`、`SCENE_BREAK_TEXT`...）。[ホラーの例](#an-example-a-horror-book)にはすべてのオプションが含まれています。このバージョンの Marginalia が知らないオプションは取り除かれます（その数が通知されます）。新しい形式バージョンのファイルは受け付けられず、カスタム CSS の波括弧が対応していないスタイルも同様に拒否されます。

<a id="an-example-a-horror-book"></a>

## 例: ホラーの本

[ホラースタイルをダウンロード](../../files/horror-book.style.json)（`horror-book.style.json`）し、*設定 → スタイル* でインポートして選択すると、プレビューで確認できます。このスタイルは**すべてのオプション**を設定し、オプションでは対応できない部分にはカスタム CSS を使っています。

| | |
|---|---|
| **ページ** | ほぼ黒の背景 `#0c0a0a`、`38em`の段組み、そして端に迫る暗いビネット（カスタム CSS）。 |
| **テキスト** | `1.12rem`のGaramond、行の高さ `1.8`、ハイフネーションを使った両端揃え、`1.6em`の字下げ、段落間はほとんど空けず、印刷された小説のように。テキストは古い紙のグレー `#cfc6bb`で、見出しの後にはドロップキャップが付きます。 |
| **強調** | ダスティローズ `#b99a94`の斜体、血のような赤 `#b3261e`の太字。 |
| **リンク** | ポインタを乗せると赤く波線になる、不健康な緑 `#8fa07e`（カスタム CSS）。 |
| **引用** | 暗い赤のバー `#5c1010`付きのグレーのテキストと、背後にうっすら赤い染み（カスタム CSS）。 |
| **見出し** | 小型大文字のPalatino、中央揃え、暗い赤 `#8e1b17`、うっすらとした光彩（カスタム CSS）。 |
| **場面転換** | 暗い赤の `† † †`。リストの点の代わりに十字が付きます（カスタム CSS）。 |
| **コード** | ほぼ黒の背景に Courier New。 |

![ホラースタイルの物語](../../images/story-style-horror.png)

実際の文章で試すには、ページ（またはプレビューが用意する類似のサンプル）に次を貼り付けてください:

```markdown
# Chapter One: The House on Harrow Lane

The rain had been falling for *three days* when Mara found the door. It was not on the plan of the house, and it was **warm** to the touch.

> Do not open it after dark. — scratched into the plaster, in a hand that was not hers

She counted the steps down. Thirteen. At the bottom there were:

- a lantern, still burning;
- a chair, turned to face the wall;
- her own name, written in the dust.

---

By morning the lantern was out, and the [house records](https://example.com) said nobody had lived there for forty years.
```

それから変更してみてください。たとえば背景を `#14100c` にしてろうそくの明かりのような茶色にする、**テキストの幅** を `32em` にしてページを細くする、またはカスタム CSS を削除してオプションだけの効果を確かめる、といった具合です。気に入る見た目になったら、**エクスポート** して、ファイルを本と一緒に保管してください。
