# 책 프롬프트

책의 **프롬프트** 탭에는 Marginalia가 프롬프트를 만들 때 사용하는 텍스트가 들어 있습니다. 두 개의 템플릿, 서사 설정, 요약 및 재작성 프롬프트가 그것입니다. 책의 어조를 정하는 것은 모델 설정보다 이 텍스트들이 훨씬 더 큰 역할을 합니다.

![프롬프트 탭](../../images/book-prompts.png)

<a id="defaults-and-book-values"></a>

## 기본값과 책 값

모든 필드는 선택 사항입니다. 비어 있는 필드는 값을 상속합니다. 책 위에 있는 가장 가까운 [폴더](folders.md)가 그 필드를 설정했다면 그 값을 쓰고, 그렇지 않으면 **설정 → 템플릿**([계정 및 설정](../account.md) 참고)의 기본값을 씁니다. 그마저 비어 있으면 내장 기본값을 사용하며, 이때 설정의 [프롬프트 언어](../account.md#prompt-language)를 따릅니다. 상속된 값은 빈 필드 안에 회색으로 표시됩니다.

따라서 모든 책이 공유하는 것은 *설정*에서, 시리즈가 공유하는 것은 해당 폴더에서, 이 책에만 특별한 것만 책의 *프롬프트* 탭에서 지정하세요. 변경 사항은 입력하는 대로 저장됩니다.

<a id="inherited-settings"></a>

### 상속된 설정

비어 있는 필드 아래의 한 줄은 그 값이 어디서 왔는지 알려 줍니다. 그래서 책이 왜 그런 방식으로 쓰이는지 분명히 알 수 있습니다.

- *폴더 "Sci-fi"에서 상속됨* - [폴더](folders.md#where-the-settings-of-a-book-come-from)가 이 값을 설정한 것입니다(책 위에서 가장 가까운 폴더 이름이 표시됩니다).
- *내 설정에서 상속됨* - *설정 → 템플릿*의 값입니다.
- *내장 기본값* - 아무것도 설정하지 않은 경우입니다.

![폴더 안 책의 프롬프트 탭](../../images/book-prompts-inherited.png)

폴더의 설정에도 같은 필드가 있고, 같은 줄이 표시됩니다. 빈 텍스트는 설정되지 않은 것으로 간주합니다. 조회는 프롬프트를 만들 때 이루어지므로, 책을 다른 폴더로 옮기거나 폴더를 바꾸면 다음에 생성하는 부분부터 달라집니다.

<a id="settings-of-extensions"></a>

### 확장 기능 설정

[확장 기능](../extensions/index.md)은 책과 폴더가 같은 방식으로 상속하는 설정을 추가할 수 있습니다(예를 들어 책에 관한 대화가 그 책을 어떤 매체로 다루는지 등). 이 설정은 프롬프트 아래의 **확장 기능 설정** 섹션에 있습니다. 책의 *프롬프트* 탭과 폴더의 설정에 있으며, 확장 기능마다 **접을 수 있는 패널 하나**씩 있습니다(모두 닫혀 있되, 값이 설정된 첫 번째 패널은 열려 있어 입력한 값이 가려지지 않습니다). 이들도 위의 필드와 같이 동작합니다. 빈 필드는 책 위의 폴더들에서 상속하고, 그다음 *설정 → 확장 기능 설정*의 해당 확장 기능 설정에서, 마지막으로 그 기본값에서 상속합니다. 필드 아래의 줄이 어디서 왔는지 알려 줍니다. [내보내기 형식](export.md#title-page-template)의 템플릿(표지, 앞부분, 저작자 표시문)도 같은 섹션에 있으며, 형식마다 패널 하나씩 있습니다. 확장 기능에 대해 설정한 값은, 그 확장 기능이 로드되지 않더라도 책이나 폴더에 그대로 남습니다.

각 필드에는 **기본 템플릿 삽입** 버튼이 있는 힌트 팝오버가 있습니다. 이 버튼은 기본 템플릿을 필드에 복사해 나만의 버전을 만들 때의 출발점으로 삼을 수 있게 해 줍니다. 템플릿 필드에는 **사용 가능한 템플릿 변수**와 **사용 가능한 매크로**도 나열되어 있습니다.

![템플릿 필드의 힌트 팝오버](../../images/template-hints.png)

## 필드

| 필드 | 사용 위치 | |
|---|---|---|
| **마스터 템플릿** | 시스템 메시지 | 프롬프트의 틀입니다. 모델의 역할과 설정, 서사 설정, 요약이 들어갈 자리를 정합니다. 템플릿입니다. |
| **시점(POV)** | 마스터 템플릿 | 서술의 목소리입니다. 예: *1인칭*, *3인칭 제한*. 일반 텍스트입니다. |
| **시제** | 마스터 템플릿 | 예: *과거형*, *현재형*. 일반 텍스트입니다. |
| **문체** | 마스터 템플릿 | 문장과 어조에 대한 문체 지침입니다. 일반 텍스트입니다. |
| **기본 사용자 프롬프트** | 마지막 메시지 | [턴 지시문](story-editor.md#writing-the-next-part)으로 만드는 다음 부분에 대한 요청입니다. 템플릿입니다. |
| **기본 요약 프롬프트** | 요약 | [요약](summaries.md)에 대한 요청입니다. 템플릿입니다. |
| **기본 메타 요약 프롬프트** | 메타 요약 | 요약들을 병합하는 [메타 요약](summaries.md#meta-summaries)에 대한 요청입니다. 템플릿입니다. |
| **재작성 시스템 프롬프트** | 재작성 | [재작성](story-editor.md#redrafting-a-part)의 시스템 메시지입니다. 지시, 서술, 요약을 담습니다. 템플릿입니다. |
| **재작성 프롬프트** | 재작성 | 재작성의 마지막 메시지이자 요청 자체입니다. 로어북이 지금 이 부분에 제공하는 로어(그래서 항목을 고치면 재작성에도 반영됩니다. 책에 로어북이 없을 때만 부분을 쓸 때의 로어를 씁니다), 부분 뒤의 이야기, 부분과 지시가 들어갑니다. 템플릿입니다. |
| **더 짧게 재작성 프롬프트**, **더 길게 재작성 프롬프트** | 재작성 | [재작성](story-editor.md#redrafting-a-part) 창이 **더 짧게** 또는 **더 길게**로 설정되었을 때, 지시문 뒤에 덧붙는 문장입니다. 일반 텍스트이며 템플릿이 아닙니다. 비워 두면 내장 텍스트를 씁니다. |
| **주석 시스템 프롬프트** | 주석 | 부분을 모델이 [주석 달기](annotations.md#letting-a-model-annotate)하도록 요청할 때의 시스템 메시지입니다. 템플릿입니다. |
| **주석 프롬프트** | 주석 | 주석 달기 요청의 마지막 메시지입니다. 템플릿입니다. |
| **주석 지침** (*살펴볼 내용*) | 주석 | 모델이 주석을 달 때 무엇을 찾을지(*연속성 오류 표시*, *약한 대사*), 주석 프롬프트의 `{%{{{annotateInstructions}}}%}` 텍스트입니다. 일반 텍스트입니다. 여기, 폴더 또는 *설정 → 템플릿*에서 설정하면 *AI로 주석 달기* 창이 이 내용으로 시작합니다. |
| **대필 프롬프트** | 지시문 초안 | 다음 턴의 [지시문을 초안으로 작성](story-editor.md#drafting-the-instructions)하도록 모델에 요청하는 프롬프트입니다. 당신을 대신해 작성합니다. 템플릿입니다. |

*시점*, *시제*, *문체*는 마스터 템플릿에 그대로 삽입되며, 이 안에서는 매크로가 동작하지 않습니다.

구문 오류가 있는 템플릿은 저장되지 않으며, 경고가 오류를 표시합니다.

<a id="templates"></a>

## 템플릿

템플릿은 이중 중괄호로 감싼 자리 표시자가 있는 텍스트입니다. 각 템플릿마다 고유한 변수가 있습니다.

| 템플릿 | 변수 |
|---|---|
| 마스터 템플릿 | `{%{{{backgroundLore}}}%}`(활성화된 로어북 항목), `{%{{{narrativePov}}}%}`, `{%{{{narrativeTense}}}%}`, `{%{{{style}}}%}`, `{%{{{summaries}}}%}`, `{%{{{annotations}}}%}`(모델에 준 메모) |
| 사용자 프롬프트 | `{%{{{sceneSetting}}}%}`, `{%{{{povCharacter}}}%}`, `{%{{{presentCharacters}}}%}`, `{%{{{instructions}}}%}` |
| 요약 프롬프트 | `{%{{{backgroundLore}}}%}`(로어북이 지금 이 부분에 제공하는 로어), `{%{{{text}}}%}`(요약할 부분들) |
| 메타 요약 프롬프트 | `{%{{{backgroundLore}}}%}`(위와 같음), `{%{{{summaryBlocks}}}%}`(병합할 요약들) |
| 재작성 시스템 프롬프트, 재작성 프롬프트 | `{%{{{text}}}%}`(부분), `{%{{{redraftInstructions}}}%}`(바꾸고 싶은 내용), `{%{{{previousStory}}}%}`, `{%{{{summaries}}}%}`, `{%{{{followingStory}}}%}`, `{%{{{backgroundLore}}}%}`, `{%{{{narrativePov}}}%}`, `{%{{{narrativeTense}}}%}`, `{%{{{style}}}%}`, 그리고 그 부분을 쓸 때 사용한 턴의 `{%{{{sceneSetting}}}%}`, `{%{{{povCharacter}}}%}`, `{%{{{presentCharacters}}}%}`, `{%{{{instructions}}}%}`, 그리고 `{%{{{annotations}}}%}`(부분에 대해 열린 메모. 재작성 창에서 요청하지 않으면 비어 있습니다). [선택 영역만 재작성](story-editor.md#redrafting-only-a-passage)의 경우에는 `{%{{{selection}}}%}`(선택한 텍스트. 부분 전체를 재작성할 때는 비어 있음), `{%{{{selectionBefore}}}%}`과 `{%{{{selectionAfter}}}%}`(그 주변의 부분 텍스트) |
| 대필 프롬프트 | `{%{{{impersonateInstructions}}}%}`(당신의 안내), `{%{{{outline}}}%}`(호출한 쪽이 넘기는 이야기의 계획. 예: 아크 개요의 현재 장), `{%{{{previousStory}}}%}`, `{%{{{summaries}}}%}`, `{%{{{backgroundLore}}}%}`(마지막 부분의 로어), `{%{{{instructionExamples}}}%}`(마지막 세 부분의 지시문. 오래된 것부터), `{%{{{narrativePov}}}%}`, `{%{{{narrativeTense}}}%}`, `{%{{{style}}}%}`, 그리고 지시문이 적용되는 턴의 `{%{{{sceneSetting}}}%}`, `{%{{{povCharacter}}}%}`, `{%{{{presentCharacters}}}%}` |
| 주석 시스템 프롬프트, 주석 프롬프트 | 재작성 프롬프트의 변수와 동일하며, `{%{{{redraftInstructions}}}%}` 대신 `{%{{{annotateInstructions}}}%}`(살펴볼 내용), 그리고 `{%{{{annotations}}}%}`(부분에 이미 있는 메모), `{%{{{facts}}}%}`(확장 기능이 그 부분 시점의 이야기에 대해 아는 내용. 예: 등장인물이 아는 것. 그런 확장 기능이 없으면 비어 있음), `{%{{{outputFormat}}}%}`(모델에게 어떤 형식으로 답하라고 할지)를 씀 |

섹션은 변수가 비어 있지 않을 때만 내용을 출력하므로, 프롬프트에 빈 제목이 생기지 않습니다.

{%{
```handlebars
{{#sceneSetting}}Current Location & Time: {{.}}{{/sceneSetting}}
```
}%}

섹션 안의 `{%{{{.}}}%}`는 그 변수의 값입니다. *장면 배경*이 비어 있으면 그 줄 전체가 빠집니다.

모든 템플릿은 SillyTavern 호환 **매크로**도 사용할 수 있습니다. 예를 들면 `{%{{{user}}}%}`(시점 인물), `{%{{{description}}}%}`(책의 설명), `{%{{{random::a::b}}}%}`, `{%{{{getvar::name}}}%}`, `{%{{{setvar::name::value}}}%}`가 있습니다. 전체 문법과 매크로 목록은 [템플릿과 매크로](../templates/index.md)를 참고하세요.

## 마스터 템플릿

마스터 템플릿은 프롬프트의 첫 메시지인 **시스템 메시지**가 됩니다. 내장 기본값에는 다음 블록이 있습니다.

1. **시스템 역할** - 모델은 이야기를 이어 쓰는 작가입니다.
2. **세계와 로어 맥락** - 활성화된 [로어북](../lorebooks/index.md) 항목(`backgroundLore`).
3. **문체와 서술 규칙** - 시점, 시제, 문체, 그리고 일반적인 산문 규칙.
4. **지금까지의 이야기 요약** - [요약](summaries.md).
5. **이야기에 대한 작가 메모** - [모델에 메모를 준](annotations.md#giving-a-note-to-the-model) 경우에만.

[추론 제공자](../inference-providers.md#general-settings)에서 탈옥 프롬프트를 켜 두었다면, 그 프롬프트는 마스터 템플릿 앞에 놓입니다.

<a id="user-prompt"></a>

## 사용자 프롬프트

사용자 프롬프트는 프롬프트의 **마지막 메시지**입니다. 즉 써야 할 부분에 대한 요청입니다. *새 턴 지시문*(또는 *다시 생성*과 *스와이프*의 경우 *턴 상세 정보*)으로 채워집니다. 내장 기본값은 시점 인물, 장소, 등장하는 인물, 플롯 지시와 함께 다음 섹션을 요청합니다. 그 뒤에는 규칙이 이어집니다. 요청하지 않는 한 새 인물을 만들지 말 것, 지시를 따를 것, 연속성을 유지할 것, 이야기 텍스트만 출력할 것입니다.

*앞 사용자 프롬프트 전* 삽입 모드의 로어북 항목은 바로 그 앞에 놓입니다. 자세한 내용은 [항목과 활성화](../lorebooks/entries.md)를 참고하세요.

## 재작성 프롬프트

[부분 재작성](story-editor.md#redrafting-a-part)은 두 개의 프롬프트로 이루어진 하나의 요청입니다. **재작성 시스템 프롬프트**는 시스템 메시지이고, 부분 앞의 이야기는 대화의 앞선 메시지로 따라옵니다(생성 요청이 보내는 것처럼 각 부분은 모델의 답변으로 전달됩니다). **재작성 프롬프트**는 사용자의 마지막 메시지입니다. 기본 제공 프롬프트는 모델에게 여러분의 지시를 적용하고, 바꾸라고 하지 않은 부분은 그대로 두며, 앞뒤 이야기와 일관성을 유지하고, 문체를 지키며, 재작성된 부분만 답하라고 지시합니다. 두 프롬프트는 같은 변수를 사용합니다. `{%{{{previousStory}}}%}`는 이야기가 메시지로 따라온다는 것을 알리는 메모일 뿐입니다. 재작성마다 같은 내용은 시스템 프롬프트에, 매번 달라지는 내용(설정집처럼 부분마다 다른 정보, 부분 뒤의 이야기, 부분 자체, 지시문)은 마지막 프롬프트에 두십시오. 그래야 읽은 프롬프트를 기억하는 서버가 대부분을 재사용할 수 있습니다. 직접 만든 마지막 프롬프트에는 필요한 변수를 남겨 두어야 합니다. `{%{{{text}}}%}`가 없으면 모델은 부분을 볼 수 없습니다. 각 프롬프트는 모든 프롬프트의 규칙을 따릅니다. 책의 설정란이 있으면 그것을, 없으면 *설정 → 템플릿*의 것을, 그것도 없으면 기본 제공 텍스트를 씁니다.

[선택한 문단만 재작성](story-editor.md#redrafting-only-a-passage)할 때도 같은 프롬프트가 쓰이며 `{%{{{selection}}}%}`가 채워집니다. 이때 기본 제공 프롬프트는 부분을 보여 주되 문단을 `[[PASSAGE TO REDRAFT]]`와 `[[/PASSAGE TO REDRAFT]]` 사이에 표시하고, 모델에게 문단을 대체할 텍스트만 답하라고 지시합니다. `{%{{{selection}}}%}`를 모르는 직접 만든 프롬프트는 모델이 부분 전체를 답하게 만들며, 그러면 그 답 전체가 선택 영역을 대신하게 됩니다. 이를 막으려면 `{%{{#selection}}%}...{%{{{/selection}}}%}` 블록(그리고 다른 경우를 위한 `{%{{{^selection}}}%}`)을 추가하십시오.

<a id="redraft-shorter-and-longer"></a>

## 더 짧게, 더 길게 재작성

[재작성](story-editor.md#redrafting-a-part) 창의 **길이** 선택지(**같은 길이**, **더 짧게**, **더 길게**)는 재작성 프롬프트 자체를 건드리지 않습니다. **더 짧게**를 고르면 **더 짧게 재작성 프롬프트**의 텍스트가(**더 길게**를 고르면 **더 길게 재작성 프롬프트**의 텍스트가) *재작성 지시문*에 쓴 내용 뒤에 덧붙고, 그 위치는 `{%{{{redraftInstructions}}}%}` 자리입니다. 그래서 직접 만든 재작성 프롬프트와도 함께 작동합니다. 지시문이 비어 있으면 이 텍스트가 유일한 지시가 됩니다. 두 텍스트도 모든 프롬프트의 규칙을 따릅니다. 책의 설정란이 있으면 그것을, 없으면 그 위 폴더 중 가장 가까이 설정된 것을, 없으면 *설정 → 템플릿*의 것을, 그것도 없으면 기본 제공 텍스트를 씁니다. 기본 제공 텍스트는 내용을 바꾸지 않고 대략 3분의 1에서 2분의 1 정도 짧게(더 길게는 절반 더, 즉 두 배 가까이 길게) 쓰도록 요청합니다.

## 주석 프롬프트

모델이 [부분에 주석을 달 때](annotations.md#letting-a-model-annotate) 재작성과 같은 종류의 요청을 받습니다. **주석 시스템 프롬프트**가 시스템 메시지이고, 부분 앞의 이야기가 앞선 메시지로 오며, **주석 프롬프트**가 마지막 메시지입니다. 기본 제공 프롬프트는 모델을 편집자로 설정합니다. 편집자는 여러분의 지시에 비추어 문제가 있는 문단을 찾아 각각을 한 글자도 바꾸지 않고 인용하며, 칭찬이나 군더더기 없이 짧은 메모를 씁니다. 부분에 이미 달린 메모를 되풀이하지도 않습니다. [확장 기능이 이야기에 관한 사실](annotations.md#letting-a-model-annotate)(인물이 무엇을 아는지를 기록하는 Knowledge Tracker)을 제공하면, 기본 프롬프트는 이를 *확립된 사실*로 보여 주고, 편집자는 그와 모순되는 부분을 표시합니다. 프롬프트에는 답하는 방식(JSON, 텍스트 블록, 자유 서술 중 여러분이 고른 답변 형식에 따라 달라짐)을 설명하는 자리에 `{%{{{outputFormat}}}%}` 변수가 있습니다. 직접 만든 프롬프트에도 이 변수를 남겨 두십시오. 그렇지 않으면 모델에게 어떻게 답해야 하는지 알려 주지 않게 됩니다. 두 주석 프롬프트 모두 모든 프롬프트의 규칙을 따릅니다. 책의 설정란이 있으면 그것을, 없으면 *설정 → 템플릿*의 것을, 그것도 없으면 기본 제공 프롬프트를 씁니다.

**살펴볼 내용**(*주석 지시문*)도 같은 규칙을 따르므로 한 번만 정해 두면 됩니다. 모든 책에 적용하려면 *설정 → 템플릿*에, 폴더 안의 책들에 적용하려면 해당 폴더에, 한 권의 책에만 적용하려면 *프롬프트* 탭에 두십시오. *AI로 주석 달기* 창은 현재 적용되는 내용을 입력란에 회색 글씨로 보여 주고, 그 출처도 알려 줍니다. 입력란을 비워 두면 그 내용이 쓰이고, 무언가를 입력하면 이번 실행에만 그것으로 바뀝니다. 또는 입력란의 정보 아이콘을 누르고 **기본값 채우기**를 선택하면 적용 중인 내용이 입력란에 복사되어, 이번 실행을 위해 고칠 수 있습니다. 어디에도 설정되지 않았다면 프롬프트의 기본 과제가 쓰입니다. 자동 주석과 `/generate-annotation` 명령도 같은 방식으로 작동합니다.

## 대필 프롬프트

모델이 다음 턴의 [지시문을 작성할](story-editor.md#drafting-the-instructions) 때는 재작성과 같이 단 하나의 메시지로 된 요청을 받습니다. 기본 제공 프롬프트는 모델에게 *지시문*에 여러분이 직접 입력했을 내용을 쓰라고 요청합니다. 다음 부분의 줄거리 명세(무슨 일이 일어나는지, 누가 무엇을 하는지, 부분이 어디서 끝나는지)로서, 여러분의 안내를 발전시키고, 계획을 따르며, 이야기가 끝난 곳에서 이어가고, 여러분이 이전에 쓴 지시문과 같은 방식으로 씁니다. 본문 산문 자체는 아닙니다. 안내가 없으면 이야기가 이끄는 방향으로 이어갑니다. 여러분의 안내는 프롬프트에서 `{%{{{impersonateInstructions}}}%}`가 들어가는 자리에 놓입니다. 직접 만든 프롬프트에도 이 변수를 남겨 두십시오. 대필 프롬프트는 모든 프롬프트의 규칙을 따릅니다. 책의 설정란이 있으면 그것을, 없으면 *설정 → 템플릿*의 *대필 프롬프트*를, 그것도 없으면 기본 제공 프롬프트를 씁니다.

<a id="how-the-prompt-is-put-together"></a>

## 프롬프트가 구성되는 방식

```
system     탈옥 프롬프트(사용 중인 경우) + 마스터 템플릿
user       [ Generate story. ]
assistant  부분 #1
user       [ Generate more story. ]
assistant  부분 #2
...        (들어갈 수 있는 만큼의 앞선 부분)
user       설정집의 "Before User Prompt" + 사용자 프롬프트
```

앞선 부분들은 모델 자신의 답변으로 보내지므로, 모델은 같은 목소리로 이야기를 이어갑니다. 이야기가 [컨텍스트 한도](../protocols.md#limits)보다 길면 가장 오래된 부분부터 빠집니다. [요약](summaries.md)은 빠진 부분을 압축된 형태로 이야기 안에 남겨 둡니다.

어떤 부분의 메뉴에 있는 **프롬프트 보기**는 그 부분이 쓰인 정확한 프롬프트를 보여 줍니다. **프롬프트 비교**는 그 프롬프트를 더 이른 부분의 프롬프트와 나란히 놓고 처음 달라지는 지점을 보여 주며, 그 지점이 서버의 [프롬프트 캐시](../prompt-cache.md#compare-prompt)가 끝나는 곳입니다.

<a id="tips"></a>

## 팁

- 모든 부분에 적용되는 규칙(새 인물 금지, 길이, 서식)은 사용자 프롬프트에 넣으십시오. 마지막 메시지이기 때문에 가장 강하게 작용합니다.
- 세계와 인물에 관한 지속적인 사실은 *문체*가 아니라 [설정집](../lorebooks/index.md)에 넣으십시오.
- 응답 한도는 텍스트를 중간에 잘라 버리므로 그에 기대기보다, 지시문에 길이를 적으십시오(예: "약 800단어").
- 템플릿을 바꾼 뒤에는 부분을 하나 생성하고 **프롬프트 보기**로 확인하십시오.
