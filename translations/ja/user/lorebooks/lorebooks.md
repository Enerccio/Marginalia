# ロアブックの作成

<a id="the-lorebook-editor"></a>

## ロアブックエディター

**Lorebooks** タブを開きます。エディターには一度に1つのロアブックが表示されます。上部の **Lorebook** フィールドで選択してください。
ロアブックはあなたのアカウントに属します。他のユーザーは、あなたが [共有](#sharing-a-lorebook) したものを除き、それらを見ることはできません。

ツールバーは2段になっており、画面が狭い場合は複数行に折り返されます。1段目はロアブック用（**Lorebook** から **Tag lorebooks** まで）、2段目は選択したロアブックのエントリ用（**Add Entry** から **Refresh** まで）です。

| ボタン | |
|---|---|
| **Lorebook** | 編集するロアブックを選択します。 |
| **Only root lorebooks** | 他のロアブックのサブロアブックではないロアブックだけを一覧に表示します（選択中のロアブックは一覧に残ります）。 |
| **Add Lorebook** | *New Lorebook* という名前の新しいロアブックを作成して選択します。 |
| Clone（2枚の紙のアイコン） | 選択したロアブックのコピーを作成します。名前を尋ねられ、元の名前に *(Copy)* が付いた名前が初期値になります。作成後、コピーが選択されます。コピーには、同じエントリ（設定、タグ、除外タグを含む）、タグ、説明、拡張機能のデータが含まれます。サブロアブックはコピーされず、コピーは同じものを使用します。元のロアブックは変更されません。 |
| **Delete Lorebook** | 選択したロアブックを削除します（確認後）。 |
| Import（ファイルのアイコン） | **Import Marginalia Lorebook**、**Import from SillyTavern**、**Import from archive**（`.md` ファイルを含む zip）、または **Import from other user**（他のユーザーが [共有](#sharing-a-lorebook) しているロアブック）。詳しくは [インポートとエクスポート](import-export.md) を参照してください。 |
| Export（ファイルのアイコン） | サブロアブックを含めてロアブックをダウンロードします。詳しくは [インポートとエクスポート](import-export.md#exporting) を参照してください。 |
| Tags（タグのアイコン） | **Tag lorebooks**：多くのロアブックに一度にタグを付けます。[下](#tagging-many-at-once) を参照してください。ブックで開かれているロアブックには表示されません。 |
| Description（行のアイコン、1段目の最後） | **Edit description**：ロアブックの内容を書くための窓を開きます。[下](#description) を参照してください。 |
| **Add Entry** | ロアブックにエントリを追加します。[エントリと発動](entries.md) を参照してください。 |
| **Full-screen editor** | ロアブックのエントリを、タブ付きの全画面の窓で開きます。[全画面での編集](#editing-in-full-screen) を参照してください。デスクトップのみ。 |
| **Search and replace** | ロアブックのエントリの名前、本文、コメントにある文字列を変更します。[検索と置換](entries.md#search-and-replace) を参照してください。 |
| **Mass edit** | ロアブックとそのサブロアブックのすべてのエントリを1つの表で開きます。[一括編集](#mass-edit) を参照してください。 |
| Tags（タグのアイコン、**Search and replace** の右、2段目） | **Tag entries**：選択したロアブックの多くのエントリに一度にタグを付けます。[下](#tagging-many-at-once) を参照してください。 |
| **Preview activation** | 入力したテキストでターンを行ったときに、どのエントリが使われるか、またその理由を表示します。[発動のプレビュー](entries.md#preview-activation) を参照してください。 |
| **Refresh** | エントリを再読み込みします。 |
| 検索ボックス | 指定した文字列を含むエントリだけを表示します。[多数のエントリの検索と削除](entries.md#searching-and-deleting-many-entries) を参照してください。 |
| **Delete selected** | 一覧でエントリが選択されているときに表示されます。確認後、それらを削除します。 |

ツールバーの下には、選択したロアブックの設定があります。

| フィールド | |
|---|---|
| **Name** | ロアブックの名前。ブックのロアブックとして、またはサブロアブックとして選択するときに表示されます。 |
| **Sub Lorebooks** | このロアブックに含まれるエントリを提供する他のロアブックです。[下](#sub-lorebooks) を参照してください。選択したサブロアブックの名前をクリックすると、それを開きます。 |
| **Tags** | ロアブック全体のタグです。各エントリのタグとしても扱われます。[タグ](entries.md#tags) を参照してください。 |
| **Scan depth** | `0` から `5` まで：使われたエントリの内容を、他のエントリのフィルターのために何回まで検索するかを指定します。[他のエントリによって取り込まれるエントリ](entries.md#entries-brought-in-by-other-entries) を参照してください。ブックが使用するロアブックのエントリと、そのサブロアブックのエントリに適用されます。ただし、サブロアブックに独自の深度がある場合（次の行）は除きます。 |
| **Scan depth as a sub lorebook** | 空、または `0` から `5` まで：ブックが使用するロアブックのサブロアブックとして、このロアブックのエントリに適用されるスキャン深度です。空の場合は、そのロアブックのスキャン深度を使います。`0` の場合は、他のエントリの内容によってこのロアブックのエントリが見つけられることはありません。 |
| **Enabled** | チェックを外すと、ロアブックは何も寄与しません（エントリもサブロアブックのエントリも含みません）。 |
| **Share with other users** | チェックすると、他のユーザーがロアブックを閲覧し、コピーをインポートできます。[下](#sharing-a-lorebook) を参照してください。新しいロアブックではオフです。 |

設定の下には、ロアブックの[説明](#description)があります（説明がある場合）。

エディターの残りの部分は、[エントリ](entries.md)の一覧です。すべての変更は、行うと同時に保存されます。

<a id="description"></a>

### 説明

説明は、ロアブックについての数語（または数行）の文章です。どの世界のものか、何のためのものか、どのブックが使うのかを書きます。ツールバーの1段目にある行のアイコンをクリックし、窓に書いてから確定してください。空のテキストにすると説明は削除されます。説明があるロアブックは、設定の下に1行で表示されます。収まらない部分は省略記号で切られます。全文を読むには、その行にマウスポインターを合わせてください。説明はロアブックと一緒にコピーされ（複製、エクスポート、インポート、バックアップ）、共有したときには、他のユーザーが名前の横に見るテキストになります。

![ロアブックの説明の窓](../../images/lorebook-description.png)

<a id="sharing-a-lorebook"></a>

### ロアブックの共有

**Share with other users** にチェックを入れると、このインストール環境の他のすべてのユーザーには、**Import from other user**（ツールバーの1段目にあるインポートボタン）にそのロアブックが、名前、作成者（あなたのフルネーム。フルネームがない場合はログイン名）、説明とともに表示されます。相手は行を開いてエントリ（およびサブロアブックのエントリ）を読み、コピーをインポートできます。チェックを外すと、そのロアブックは相手の一覧から消えます。すでに作られたコピーは、相手のものとして残ります。

* 共有は閲覧のみです。他の人があなたのロアブックを変更、削除、またはブックで使用することはできません。ロアブックはあなたのものであり、これまでと同じように表示されます。
* インポートすると、相手には**新しいロアブック**が作られます。それは、そのロアブックと、深さを問わず**共有されている**サブロアブックで、エントリ、タグ、説明を含み、あなたのものと同じようにリンクされたものです。コピーは非公開（共有されていない）です。その後あなたがロアブックに何をしても、コピーには反映されず、相手が変更したものもあなたのロアブックには反映されません。
* **共有されているサブロアブックだけが表示され、コピーされます。** 共有されていないサブロアブックは、その下にあるすべてのもの（その下にある共有済みのロアブックも含む）と一緒に除外されます。共有されていないサブロアブックを持つロアブックで **Share with other users** にチェックを入れると、それらも共有するかどうかを尋ねる質問が表示されます。**Yes** はロアブックとそれらすべて（深さを問わず）を共有します。**No** はロアブックだけを共有します。**Cancel** は何も共有せず、チェックボックスは外したままになります。後から追加したサブロアブックは、共有するまで共有されません。
* チェックボックスを外すと、そのロアブックの共有だけが止まります。そのサブロアブックは共有されたまま（他のユーザーの一覧にはそれぞれ単独で表示されます）で、それらのチェックも外すまで続きます。
* 削除されたロアブック、エージェントの作業用コピー、あなた自身のロアブックは一覧に表示されません。削除されたユーザーには何も表示されません。

設定の下には、ロアブックの有効なエントリのトークン数の見積もりが表示されます。その隣にあるリンク **Count with subbooks** をクリックすると、ロアブックの有効なエントリと、深さを問わずすべてのサブロアブックの有効なエントリのトークン数を合計し、その合計を隣に表示します。物語を書くときと同様に、無効なサブロアブックは、その下にあるロアブックとともに除外されます。また、複数の場所でサブロアブックになっているロアブックは、1回だけ数えられます。
合計は、クリックした時点の数です。エントリを変更すると表示は消えるので、もう一度クリックして数え直してください。

エージェントが作業しているブックのロアブックは読み取り専用で表示されます（[エージェント](../agents.md) を参照）。**Add Entry**、**Search and replace**、**Mass edit**、**Delete Lorebook** と設定は表示されません。**Add Lorebook**、インポート、エクスポート、**Refresh** は残るので、いつでも別のロアブックを始められます。
<a id="mass-edit"></a>

## マスエディット

**マスエディット**を開くと、選択したロアブックと**そのサブロアブック**（何階層深くても）のすべてのエントリが、1つの表にまとめて表示されます。並び順は、エントリの**順序**の順です（順序が同じ場合はロアブックごとにまとめ、その後に名前順）。大きなロアブックを整理するためのものです。

- エントリの *enabled* チェックボックス、**エントリ名**、**順序**、**タグ**、**フィルターモード**、**フィルタリング**、**挿入モード**、**ネガティブタグ**、**発動コンテキスト**とその**パート**、パートの範囲（**開始メッセージ**と**終了メッセージ**、空欄は制限なし）、**メモ**は、エディタと同じように表の中でその場で変更できます。エントリは1行ずつ表示され、表は下方向にスクロールします（ウィンドウが狭い場合は横方向にも）。順序を変更すると、その行は新しい位置へ移動します。表ではエントリの本文が短く省略されます。全文を読んだり編集したりするには、ロアブックでそのエントリを開いてください。
- 行の**ロアブック**欄には、そのエントリがどのロアブックに属しているかが表示されます。別のロアブック（そのロアブック自身、またはそのサブロアブックのいずれか）を選ぶと、エントリをそこへ移動できます。
- 複数のエントリを移動するには、それらにチェックを入れます（見出しのボックスを押すと全件にチェックが入ります）。下部で**ロアブックへ移動**を選び、**チェックしたものを移動**を押します。
- 複数のエントリを削除するには、チェックを入れて**チェックしたものを削除**を押します。確認は一度だけ行われ、エントリは[ごみ箱](../trash.md)へ移動します。
- エージェントが作業中のロアブックはロックされます。そのエントリはグレーになり、変更も移動もできず、そこへエントリを移動することもできません。これはロアブックごとに判定されるため、サブロアブックが別の作業（別のブックで使用中）でロックされていても、親のロアブックはロックされていない場合があります。**更新**を押すと、ウィンドウを読み直し、ロックが解除されたかどうかを確認できます。

変更後にウィンドウを閉じると、エディタ内のロアブックも更新されます。

## フルスクリーンでの編集

**全画面エディター**（ツールバーの2段目）は、選択したロアブックを画面いっぱいのウィンドウで開きます。長いエントリの編集に使います（エントリの行にある展開ボタンを押すと、そのエントリを開いた状態でウィンドウが開きます）。ブックのウィンドウの *Lorebook* タブにも同じボタンがあり、そこに表示されているロアブックを開きます。ウィンドウのタイトルはロアブックの名前になります。[ストーリーエディター](../books/story-editor.md)と同じようにタブの集まりになっており、タブをドラッグして別のタブの横や下に並べられ、タブ間の仕切りもドラッグで動かせます。

![フルスクリーンのロアブックエディター：エントリの一覧と、タブで開いた2つのエントリ](../../images/lorebook-fullscreen.png)

- **Entries** タブにはエントリの一覧が表示されます。ロアブックのページと同じ検索ボックスとタグ・状態のフィルターがあり、さらに **Add Entry**、**Mass edit**、**Tag entries**、**Preview activation**、**Refresh** があります（一括編集とタグの変更は、開いているタブにも反映されます）。**Include sub lorebooks** をオンにすると、[サブロアブック](#sub-lorebooks)のエントリも各エントリの所属するロアブック名付きで一覧に加わります。この場合 **Add Entry** は、一覧の横で選んだロアブックにエントリを追加し、そのエントリのタブにはロアブック名が表示されます。このタブは閉じられません。一覧の各行には3つのボタンがあります。
  - **Open**（ペンのアイコン。行をダブルクリックしても同じ）は、最後に使ったエントリのタブでエントリを表示します。そのようなタブがない場合は、一覧の右の列に新しく開きます。
  - **Open in new tab**（矢印のアイコン）は、最後に使ったエントリのタブの隣にそのエントリ用のタブを追加します。
  - **Delete**（ごみ箱のアイコン）は確認の後にエントリを削除し、そのタブも閉じます。

  エントリは1つのタブでしか開けません。すでに開いているエントリをもう一度開くと、そのタブが表示されます。
- **エントリのタブ**は上から順に、**Name**、**Order**、**Enabled** があります。続いて **Settings** があり、これは折りたためるパネルで、エントリの残りの設定（フィルターの方式とフィルター、挿入の方式、発動の文脈と部分、タグと除外タグ、部分の範囲、再帰のチェックボックスと条件）が入っています。詳しくは [エントリと発動](entries.md) を参照してください。その下が **content** で、Markdownエディターになっています（各タブは、テキストだけを表示するか、テキストとプレビューを並べるか、プレビューだけを表示するかを、ウィンドウを開き直したときも含めて覚えています）。**Show note** をオンにすると、その横に **note** が表示されます。目のアイコンを押すと、このエントリの[発動プレビュー](entries.md#preview-activation)が開きます。一番下の行には、内容の推定トークン数と、テンプレートの問題点が赤字で表示されます（問題があっても保存はされます）。タブを閉じるには **×** を押します。
- **エントリ内の画像。** 内容に画像を貼り付けるか、画像をドラッグして内容の上に置くか、ツールバーの画像ボタンで選択します（PNG、JPEG、GIF、WebP、10 MBまで）。画像はファイル（*Resources* タブ）に保存され、カーソルの位置に `![Map](resource:…)` のような行が入ります。プレビューには画像が表示され、かっこの中の文字はそのキャプションになります。画像をエントリから外すには、その行を削除します。モデルはこの行を除いてエントリを読みます。画像そのものが送られるのは、モデルの設定で *Send lore images* が有効になっている場合だけです（[推論プロバイダー](../inference-providers.md)を参照）。画像はロアブックに付いて移動します。複製、共有ロアブックのコピー、書き出したロアブックのファイル、ファイルを含むブックのバックアップには画像が含まれ、コピー先にはそれぞれ独自の画像が作られます。SillyTavern形式の書き出しとブックの書き出しには画像は含まれません。ストーリーの *Lorebook* タブでは、画像がエントリの本文の下に表示されます。画像は、まだトークン数の推定に含まれません。
- **エントリ間の移動。** 内容の中の別のエントリの名前やキーワードを、本文でもプレビューでも Ctrl+クリック（Macでは Cmd+クリック）すると、そのエントリが最後に使ったタブで開きます。Shift も押すと新しいタブで開きます。一番下の行には **Mentioned in:** の後に、このエントリの名前を内容で挙げているエントリも並びます。その一つをクリックすると開き、Shift+クリックで新しいタブに開きます。エントリは、その名前と、フィルターの語（各キーワード、*Text* フィルターの文章全体、正規表現にマッチする語句）によって指定されます。単語単位で、大文字・小文字は区別されません。これは[再帰](entries.md)がたどるものに近いものの、同じではありません。再帰は、長い単語の中に含まれるキーワードも見つけますし、*AND* フィルターではすべてのキーワードを必要とし、さらにタグと条件も確認します。
- Markdownエディターにはツールバーがあり（太字、斜体、取り消し線、線、見出し、引用、コード、コードブロック、表、3種類のリスト）、右側には *edit*、*edit with preview*（既定）、*preview* の表示切り替えがあります。一般的なキー操作（Ctrl+B、Ctrl+I など）が使えます。Tab はインデントではなく次の項目へ移動します。入力したものは、入力を少し止めたときと、エディターから離れたときに保存されます。
- ヘッダーには、有効なエントリの推定トークン数、**Count with subbooks**、**Search and replace** が表示されます。**Search and replace** は、開いているタブの中の置換結果にも反映されます。

すべての変更は行うたびに保存されるので、**Close** を押しても何も失われません。ウィンドウは、ロアブックごとに前回の状態を覚えています。次に開いたとき、同じエントリが同じタブで、同じ並びで表示されます（その後に削除されたエントリは除かれます）。ロアブックのページは、ウィンドウを閉じるとエントリを表示し直します。

**他の場所での変更。** タブでの変更は、そのときエントリに保存されている内容に対して保存されます。そのため、他の場所（ロアブックのページ、一括編集、別のウィンドウ）で変更されたエントリの *他の* 項目はそのまま残り、タブにもそれが表示されます。**content** か **note** が、タブに表示されてから他の場所で変更されていた場合は、あなたのテキストで上書きされることはありません。その旨が一番下の行に表示され、**Keep my text**（それでも自分のテキストを保存する）と **Load the saved text**（自分のテキストを捨てる）が選べます。他の場所で削除されたエントリは、そのタブを閉じます。

ウィンドウは開いている間に保存されたものにも追従します。エージェントや他のウィンドウ（別のブラウザータブ、ストーリーのロアブックタブ）がエントリを保存または削除すると、一覧が読み込み直され、そのエントリのタブは現在の内容を表示します（削除されたエントリのタブは閉じます）。**Keep my text** か **Load the saved text** の回答を待っているテキストのタブは、回答するまでそのままです。入力したのと同じ1秒の間に保存された変更は、まだ食い違う場合があります。その場合は、上記と同じように一番下の行で確認が表示されます。

**エージェント。** エージェントがそのロアブックを使うブックで作業している間は、このウィンドウは開けません。ウィンドウを開いている最中に実行が始まった場合、次に変更したとき、またはタブを切り替えたときに、ウィンドウは読み取り専用になります。バーにはエージェントの名前が表示され（最後の変更を保存できなかった場合はその旨も表示されます）。実行を一時停止するか停止してから **Check again** を押すと、エントリは実行が残した状態で読み込まれ、再び編集できます。

[Lore Generator](../extensions/lore-generator.md) と [Lorebook VCS](../extensions/lorebook-vcs.md) の拡張機能もここで使えます。魔法の杖のボタンは一覧の行とエントリタブの名前の行にあり、リビジョンのパネルは一覧の上に、エントリの リビジョンバーはそのタブにあります。

<a id="tagging-many-at-once"></a>

## 複数の項目へのタグの一括付与

ツールバーの2つのタグボタンは、同じウィンドウを開きます。このウィンドウでは、多くの項目にタグを付けたり外したりできます。**Tag lorebooks** は自分のロアブックの一覧を、**Tag entries** は選択したロアブックのエントリの一覧を表示します。**Tag**（または新しいタグを入力して Enter）でタグを選びます。一覧には、すべての項目とそのタグが表示されます。選んだタグを持つ項目が先頭に並び、そのタグが強調されます。各行の **+** と **-** のボタンは、その項目に対してタグを付けるか外します。複数の項目にチェックを入れ（ヘッダーのチェックボックスで全選択できます）、一番下の **Apply the tag to the checked** または **Remove the tag from the checked** を使うと、チェックしたすべての項目に一度に適用できます。エージェントが作業中の項目（実行中のエージェントがあるブックのロアブック、つまりそのすべてのエントリ）は灰色で表示され、実行が一時停止または停止されるまで変更できません。このウィンドウでは、[ブック](../books/managing-books.md#tagging-many-books-at-once)にもタグを付けられます。

エントリに付けられるタグは通常のタグです（[タグ](entries.md#tags)を参照）。除外タグは、エントリ自体に設定されます。

<a id="using-a-lorebook-in-a-book"></a>

## ブックでロアブックを使う

ブックを開き、その **Lorebook** タブで、**Lorebook** の欄からロアブックを選びます。その下のエディターにそのロアブックが表示されるので、執筆中にエントリを追加したり変更したりできます。欄を空にすると、ロアブックを使わずに執筆できます。

1つのブックが使えるロアブックは1つだけです。複数のロアブックを使いたい場合は、それらをサブロアブックとして含む新しいロアブックを作り、そのロアブックを使ってください。

同じロアブックは、いくつのブックから使ってもかまいません。ロアブックへの変更は、次に生成される部分から、そのロアブックを使うすべてのブックに反映されます。すでに書かれた部分は、書かれたときのロア設定のままです。
<a id="sub-lorebooks"></a>

## サブロアブック

**サブロアブック**では、他のロアブックのエントリーを、このロアブックに取り込むことができます。典型的な設定例は次のとおりです。

```
"Saga" (used by the books of the series)
 ├─ "World"       places, history, rules of magic
 ├─ "Characters"  the main cast
 └─ "Book 2 notes"
```

- サブロアブックにも、さらにサブロアブックを設定できます。すべての階層が取り込まれます。
- ロアブックは、複数のロアブックのサブロアブックになれます。何度経由されても、そのエントリーは一度だけ使われます。
- ロアブックは、直接でも他のロアブックを経由してでも、自分自身を取り込むことはできません。このような選択は拒否され、*サブロアブックを選択できません：循環が検出されました。* と表示されます。
- 無効にされたサブロアブックは、それが取り込んでいるものも含めて、すべて除外されます。

![サブロアブックを2つ持つロアブック：それらを含む場合と含まない場合のトークン](../../images/lorebook-sub-lorebooks.png)

取り込まれたすべてのロアブックのエントリーは、どのロアブックから来たものかに関係なく、まとめて[順序](entries.md#order-and-insertion)によって並べ替えられます。

<a id="disabling-and-deleting"></a>

## 無効化と削除

一時的にロアブックを off にしたい場合、たとえばそれなしで本がどう読めるかを確かめたいときは、**有効** のチェックを外してください。本はそのロアブックを使わなくなりますが、チェックを入れると再び機能します。

**ロアブックを削除** を実行すると、そのロアブックは一覧から取り除かれます。それを使っていた本は、そのエントリーを受け取らなくなり、それをサブロアブックとして取り込んでいたロアブックも、それを飛ばすようになります。データは、管理者が[クリーンアップ](../administration/cleanup.md)を実行するまでデータベースに残ります。それまでは[ごみ箱](../trash.md)からロアブックを復元できます。[本のバックアップ](../books/backups.md)やエクスポートされたファイルのコピーには影響しません。
