# 상태 추적기

등장인물의 현재 **상태**를 기록합니다. 무엇을 입고 있는지, 무엇을 들고 있는지, 손에 쥔 무기, 부상, 기분, 또는 여러분이 정의한 다른 무엇이든 추적할 수 있습니다. 모델은 두 장 전에 검이 사라졌다는 사실이나 망토가 젖어 있다는 사실을 쉽게 잊어버립니다. 상태 추적기를 사용하면 장면에 등장하는 추적 대상 인물 각각에 대해 지금 무엇이 사실인지가 프롬프트에 담깁니다.

!!!
누구를 추적할지, 그리고 그들에 대해 무엇을 추적할지는 여러분이 정합니다. 탭에 추가한 인물만 모델에 전달되며, 그 인물이 작성 중인 부분의 *등장인물*에 포함되어 있을 때에만 전달됩니다. 이 버전에서는 상태를 여러분이 직접 관리합니다(또는 아래 명령을 사용하는 에이전트가 관리합니다). 모델과 함께 이야기의 흐름을 따라가는 기능은 나중에 추가될 예정입니다.
!!!

<a id="categories"></a>

## 범주

**범주**는 인물에 대해 추적할 수 있는 한 가지 항목입니다. 각 범주에는 다음이 있습니다.

- **이름**: 프롬프트에서도 이 이름으로 표시됩니다(*Wearing*, *Weapon at hand*, *Carrying*).
- **종류**:
  - **단일 값**: 짧은 값 하나이며, 새 값이 이전 값을 대체합니다(손에 쥔 무기, 위치).
  - **목록**: 항목을 하나씩 추가하고 제거합니다(소지품, 부상).
  - **설명**: 하나의 글이며 전체가 통째로 다시 쓰입니다(옷차림, 기분).
- **모델을 위한 지침**: 범주에 무엇이 들어가고 무엇이 들어가지 않는지를 정합니다. 모델은 이야기를 따라갈 때 이 지침을 읽습니다.
- **텍스트에 적힌 내용만**: 켜져 있으면 값은 텍스트가 그렇다고 말할 때에만 바뀝니다. 꺼져 있으면 명백한 결과(수영 후 젖은 상태)에도 바뀝니다. 모델은 이야기를 따라갈 때 이 설정을 사용합니다.
- **비어 있으면 "none"이라고 말하기**: 인물에게 값이 없을 때(잃어버린 무기) 범주를 빼 버리지 않고 프롬프트에 *none*이라고 적습니다.

<a id="my-categories"></a>

### 나만의 범주

나만의 범주는 **설정 → 확장 설정 → State Tracker**에 있습니다. 책은 이 범주들을 복사해 가져갑니다. 직접 바꾸지 않으면 기본으로 제공되는 다섯 가지 범주가 있습니다: *Wearing*, *Weapon at hand*, *Carrying*, *Injuries*, *Mood*. 범주는 그 화면에서 추가, 수정, 삭제할 수 있으며, 설정 화면에서 **저장**을 누르면 적용됩니다. **기본 범주로 복원**을 누르면 기본으로 제공되는 다섯 가지가 돌아옵니다.

<a id="the-categories-of-a-book"></a>

### 책의 범주

책은 사용하는 모든 범주의 **자체 사본**을 가지고 있습니다. 그래서 책을 백업하거나 내보낼 때 필요한 것이 모두 함께 담기며, 나만의 범주를 삭제해도 책이 깨지지 않습니다. 상태 탭의 **이 책의 범주** 버튼을 누르면 이 책의 범주 목록이 나옵니다.

- **나만의 범주에서 추가**는 나만의 범주 하나를 책으로 복사합니다.
- **이 책을 위한 새 범주**는 이 책에서만 존재하는 범주를 만듭니다(배의 화물, 마법의 조율 등). 이런 범주에는 *이 책에서만*이라고 표시됩니다. **나만의 범주에 저장**을 누르면 나만의 범주에도 추가되어, 다른 책에서도 쓸 수 있습니다.
- 나만의 범주와 더 이상 같지 않은 사본에는 *나만의 범주와 다름*이라고 표시됩니다. **나만의 범주에서 업데이트**를 누르면 나만의 범주의 내용을 가져옵니다. 지침이 바뀌면 모델의 동작도 바뀌므로, 여러분이 직접 확인하지 않은 채로 아무것도 업데이트되지 않습니다.
- 범주를 수정하면 이 책에서만 바뀝니다. 인물이 해당 범주의 값을 가지고 있는 동안에는 범주의 종류를 바꿀 수 없습니다.
- 책에서 범주를 삭제하면 그 범주에 속한 모든 인물의 값이 함께 삭제됩니다.

<a id="the-state-tab"></a>

## 상태 탭

[이야기 편집기](../books/story-editor.md)의 왼쪽 사이드바에 **상태** 탭이 추가됩니다. 변경한 내용은 모두 바로 책에 저장됩니다.

**인물 추적 시작**을 누르면 **이름**, 선택 사항인 **별칭**(부분의 *등장인물* 칸에 쉼표로 구분되어 적히는 인물의 다른 이름들), 그리고 **추적할 범주**를 입력하라고 합니다. 목록에는 이 책의 범주와 나만의 범주가 나오며, 나만의 범주를 고르면 책으로 복사됩니다. 말은 *부상*만 추적하고, 여주인공은 모든 범주를 추적하게 할 수도 있습니다.

추적 중인 인물은 각 범주를 현재 값(또는 값들)과 함께 보여 줍니다.

- **+**는 단일 값 또는 설명 범주의 값을 설정합니다(현재 값은 기록으로 옮겨집니다). 목록 범주라면 항목을 추가합니다.
- 연필은 값을 수정하고, 가위표는 값을 **제거**합니다. 더 이상 사실이 아니므로 기록으로 옮겨지고 모델에는 전달되지 않습니다.
- 자물쇠는 값을 **잠금** 상태로 표시합니다(흉터, 가문의 검 등). 모델과 함께 나중에 제공될 정리 기능은 잠긴 값을 건드리지 않습니다.
- **기록**은 범주의 과거 값과 그 값이 끝난 이유(*대체됨* 또는 *제거됨*)를 보여 줍니다. **복원**은 과거 값을 다시 현재 값으로 만듭니다(단일 값 또는 설명 범주라면 현재 값이 그 자리를 대신해 기록으로 옮겨집니다). 삭제는 값을 영구히 지웁니다.

인물의 연필 아이콘은 이름, 별칭, 범주를 수정합니다. 범주의 선택을 해제하면 그 범주는 숨겨지지만 값은 남아 있으며, 다시 선택하면 값이 돌아옵니다. 휴지통 아이콘은 인물의 추적을 멈추고 그 인물의 상태 전체를 삭제합니다.

## 프롬프트에서

톱니바퀴 버튼에는 책의 설정이 들어 있습니다.

- **프롬프트에 넣기**를 켜면 장면에 등장하는 추적 인물의 상태가 모든 생성 요청의 프롬프트에 들어갑니다(켜져 있으면 톱니바퀴가 초록색으로 바뀝니다).
- **깊이**와 **역할**은 작가의 노트와 마찬가지로 상태가 들어갈 위치를 정합니다. *깊이*는 그 뒤에 오는 메시지의 개수입니다(0이면 그 턴의 지시문 뒤, 1이면 바로 앞).
- **이름 구분자**는 *등장인물* 칸을 어떻게 나눌지 정합니다(기본값은 `,` `;` `/` `|` 및 줄바꿈). 대괄호 안의 메모는 무시되므로 `Mara (asleep), Fiora`는 두 경우 모두를 찾습니다.

프롬프트에는 전달할 내용이 있는 장면의 인물만 들어갑니다.

```
The current state of the characters of this scene. Keep to it; it changes only when the story changes it:

Fiora:
- Wearing: torn green cloak, leather boots
- Weapon at hand: none
- Carrying: rope; lantern
```

같은 텍스트를 템플릿의 원하는 곳에 {%{`{{command::state-tracker-block::{{presentCharacters}}}}`}%} 매크로로 넣을 수도 있습니다(인수로는 어떤 이름 목록이든 쓸 수 있습니다). 이 매크로는 **프롬프트에 넣기**가 켜져 있든 꺼져 있든 상태를 출력하므로, 매크로를 쓸 때는 그 옵션을 끄세요. 그렇지 않으면 모델이 상태를 두 번 받게 됩니다.

<a id="commands"></a>

## 명령

명령 입력줄과 에이전트를 위한 명령입니다.

| 명령 | 기능 |
|---|---|
| `state-status` | 설정, 이 책의 범주, 그리고 이 책에 사본이 없는 나만의 범주를 보여 줍니다. |
| `list-state-characters` | 추적 중인 인물과 각 인물의 범주를 보여 줍니다. |
| `track-state-character` | 인물 추적을 시작합니다: 이름, 별칭, 이름으로 지정한 범주. |
| `stop-tracking-state-character` | 인물 추적을 멈추고 그 인물의 상태를 삭제합니다(먼저 확인을 묻습니다). |
| `list-character-state` | 인물의 값을 현재 값과 과거 값까지 번호와 함께 보여 줍니다. |
| `set-character-state` | 값을 설정합니다: 인물, 범주, 텍스트. |
| `remove-character-state` | 번호로 값을 제거합니다. 값은 기록으로 옮겨집니다. |
| `state-tracker-block` | 인물 목록에 대한 프롬프트 텍스트를 보여 줍니다(매크로). |
