# 提示词检查器

在生成的提示词发送给模型之前将其显示出来，并询问是否发送。

<a id="how-it-works"></a>

## 工作原理

该扩展会在[故事编辑器](../books/story-editor.md)的设置菜单（⚙）的 *Analysis* 分组中添加 **Inspect prompt before sending**（发送前检查提示词）。它是一个复选框项：选择它即可开启检查，再次选择则关闭。该选项是你的用户设置，适用于你的所有书籍。

开启后，一次生成（新的部分、替换版本或重新生成）会在请求发出之前停止，并打开一个对话框 **Send this prompt to the model?**（将此提示词发送给模型？）。文本即模型将收到的提示词，是在其他所有扩展都已对其作出修改之后的版本：每条消息按其角色列出——`[SYSTEM]`（模板、设定和摘要）、故事中较早的部分（作为 `[USER]` 和 `[ASSISTANT]` 消息），以及最后一轮的指令。随请求一起发送的图片会计入其所在消息的末尾。

![发送前的提示词](../../images/plugin-prompt-inspector.png)

- **Send**（发送）会发出请求，生成照常进行。
- **Cancel**（取消）会停止生成。为此生成而开始的部分会被移除（重新生成的部分会恢复为其旧文本），与生成在收到任何文本之前失败时的做法相同。

<a id="notes"></a>

## 注意事项

- 提示词会像任何生成一样先被构建，而你是在请求发出前的最后一步被询问的。如果某个摘要已失效，那么关于在没有它的情况下继续的常规询问会先于提示词的显示出现。在你作答之前，不会向模型发出任何请求。
- 只有从故事编辑器发起的生成会被拦下。[智能体](../agents.md)和命令没有可以显示提示词的页面，它们的生成会直接进行，不再询问。
- 对话框可以移动和调整大小，文本可以被选中和复制。该对话框必须作出回应：Esc 键和点击外部区域都不会关闭它。如果你在对话框打开时关闭了页面，则视为 *Cancel*：一旦服务器发现页面已不存在，生成即被停止，且不会发送任何内容（这可能需要一些时间）。
- 其他用户不会被询问，并且该开关在页面重新加载后仍会保留。
