# 통계

모든 사용자의 [집필 통계](../books/statistics.md)(단어 수, 작업 시간, 책마다의 크기를 날짜별로 기록한 것)는
데이터베이스에 보관됩니다. 통계에는 사용자가 언제 책을 작업했는지, 책의 이름과 폴더가 무엇인지가 기록되며, 삭제된 책의 기록도 포함됩니다.
관리자 페이지의 **통계** 탭에서 이를 제한할 수 있습니다. 사용자는 자신의 [설정](../account.md)에서 같은 것을 할 수 있으며,
통계 창에서 자신의 통계를 지울 수도 있습니다.

![관리자 페이지의 통계 탭](../../images/admin-statistics.png)

| | |
|---|---|
| **집필 통계 기록** | 끄면 사용자가 무엇을 선택했든 모든 사용자에 대한 기록이 멈춥니다. 이미 기록된 내용은 이 설정으로 삭제되지 않습니다. 통계 창에는 새로 집계되는 것이 없다고 표시됩니다. |
| **통계 보관 기간(개월)** | 이보다 오래된 날짜의 기록은 모든 사용자의 통계에서 영구적으로 삭제되며, 하루에 한 번(약 4:20, 그리고 시작 직후 잠시 후) 및 저장할 때 실행됩니다. 비워 두거나 0으로 두면 모든 기록을 보관합니다. 사용자는 자신에 대해 더 짧은 기간을 선택할 수 있지만, 더 긴 기간은 선택할 수 없습니다. |
| **사용자의 통계 지우기** | 선택한 사용자의 모든 통계를 확인 질문 후에 삭제합니다. 해당 사용자의 책은 변경되지 않습니다. |
| **모든 사용자의 통계 지우기** | 같은 작업을 모든 사용자에 대해 수행합니다. |

삭제된 통계는 [데이터베이스 백업](database-backups.md)에서만 복구할 수 있습니다. 통계는 데이터베이스의 일부이기 때문입니다(단일 책의 백업에는 통계가 포함되지 않습니다).

[정리](cleanup.md) 기능은 통계를 건드리지 않습니다. 통계는 삭제된 객체가 아니라 책을 id로 참조하며, 이는 의도적으로 책이 삭제된 뒤에도 남도록 설계된 것이기 때문입니다.
