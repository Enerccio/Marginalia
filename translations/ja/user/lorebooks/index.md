# ロアブック

!!!
[携帯電話レイアウト](../phone.md#lorebooks)にも同じエディタが一列で用意されています。ロアブックのボタンはメニューに、ロアブックの設定は開くセクションに、エントリーは開くフォームに入っています。デスクトップでしか使えない機能はごくわずかで、その一覧はそちらにあります。
!!!

ロアブックには、モデルが知っておくべき世界についての情報を収めます。キャラクター、場所、歴史、ルール、用語などです。それぞれの情報は**エントリー**として登録します。生成されるパートのたびに、Marginaliaはどのエントリーが関連するかを判断してプロンプトに入れます。そのため、モデルはキャプテン・ヴァローがシーンに入ってきたときに彼が誰なのかを知っていますが、すべてのエントリーがすべてのプロンプトの場所を占めることはありません。

![ロアブックエディタ](../../images/lorebook.png)

<a id="how-it-fits-together"></a>

## 全体の仕組み

```
Book ──uses──▶ Lorebook "Saga" ──sub lorebooks──▶ "Characters", "Places", "Magic"
                   │                                   │
                 entries                             entries
```

- **ブック**は1つのロアブックを使用します（*Lorebook*タブで設定します）。
- ロアブックは他のロアブックを**サブロアブック**として含めることができます。そのエントリーも使用されるため、複数のブックで使う共通の資料（複数のブックで使う世界観、登場人物の一覧など）を独立したロアブックに入れておき、必要な場所で含めることができます。
- 各**エントリー**には、プロンプトに入る本文と、いつ使われるかを決める条件があります。

<a id="when-an-entry-is-used"></a>

## エントリーが使われるタイミング

生成されるパートのたびに、次のすべてが満たされたとき、エントリーが**有効化**されます。

1. エントリーとそのロアブックが有効になっていること。
2. エントリーの**タグ**（ある場合）がブックのタグに合うこと。
3. エントリーの**フィルター**（ある場合）がそのパートの指示に合うこと。または、エントリーが物語を参照する設定の場合は、物語の最新のパートにも合うこと。

有効化されたエントリーは、その**順序**に従って挿入されます。システムプロンプトのロアブロックに入るか、パートのリクエストの直前に入ります。詳しくは[エントリーと有効化](entries.md)を参照してください。

タグもフィルターもないエントリーは、常に有効です。モデルに常に知っておいてほしい内容に使ってください。

<a id="lorebooks-and-other-features"></a>

## ロアブックと他の機能

- ロアブックのエントリーは[テンプレートとマクロ](../templates/index.md)を使えます。SillyTavernのワールド情報もそのまま使えます。
- [SillyTavernのワールド情報](import-export.md#importing-sillytavern-world-info)をインポートできます。
- [ブックのバックアップ](../books/backups.md)には、ブックのロアブックとそのサブロアブックが含まれます。
- [Lore Generator](../extensions/lore-generator.md)拡張機能は、既にあるロアをもとに、モデルを使ってエントリーの本文を書きます。
- [Lorebook VCS](../extensions/lorebook-vcs.md)拡張機能は、エントリーの改訂履歴を保存します。
