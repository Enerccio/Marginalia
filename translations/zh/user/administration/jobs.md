# 任务

应用程序向**外部 AI** 提出的所有请求都是一个*任务*：生成、摘要、批注、智能体运行、将章节转换为音频、图片。每个任务都会记录发起它的用户、开始和结束时间、结束方式，以及它向模型或语音、图像后端发出的每一次*调用*，每次调用同样有自己的开始和结束时间。管理员页面的**任务**标签页显示该记录；页面 `/jobs` 显示当前正在运行的内容。

只保存元数据：谁、何时、耗时多久、使用的是哪个 AI 或服务器（AI 的名称，或语音、图像服务器的主机名；绝不保存地址路径或查询参数）、模型、结束方式，以及失败时的简短错误信息。**不会保存任何提示词、回答或文本**。

<a id="what-is-one-job"></a>

## 一个任务是什么

- **没有被任何东西归并的请求**（生成、批注、重写、模拟、某一部分的摘要、向帮助助手提出的问题，或插件的请求，例如某一部分或某条设定条目的翻译）是独立的任务，只有一次调用。它的类型就是工作的类型（`generation`、`annotate`、`summary` 等）。
- **重写摘要**是一个任务（`summary`），每写一条摘要有一次调用。
- **智能体运行的一个工作阶段**是一个任务（`agent`），每轮智能体有一次调用；一次被暂停并恢复的运行，每个阶段各有一个任务，子智能体发出的请求也各自是独立的任务。
- **转换为音频**时，每一批章节是一个任务（`audiobook`），标注模型的请求以及每一段被朗读的内容都作为它的调用。
- **图像生成器**生成的图片是独立的任务（`image-generator`），带一次图像调用。

<a id="what-runs-now-jobs"></a>

## 正在运行的内容：`/jobs`

![正在进行生成的 /jobs 页面](../../images/jobs-live.png)

在你的 Marginalia 地址后面打开 `/jobs`（例如 `http://localhost:8080/jobs`；标签页上的 **Open the live view** 链接可以直接打开）。与其他页面一样，它需要登录，并且对非管理员用户不显示任何内容。列表每两秒刷新一次，对每个正在运行的任务显示：用户、类型、已运行时长、已完成的调用数量，以及当前正在进行的内容（AI 或服务器，以及调用等待了多久）。当服务器看起来很忙时，可以用它快速查看：如果大量调用都在等待同一个模型，就说明了一切都变慢的原因。

在任务列表下方，**Runs on the books** 列出当前正在处理某本书的运行，并防止其中的部分内容被删除或在运行期间被修改（参见[运行面板](../books/story-editor.md#the-panel-of-the-runs)，它为每个用户显示其自己书籍的相同信息）：包括用户、书籍、运行的操作、所处阶段（面板上的文字：*Waiting for the model*、*The model is thinking/writing...*、*Working*、*Waits for you*；对于生成，还有其阶段，例如写作该部分时的 *INFERENCE*；已打开的书籍窗口则不显示此项）、开始时间，以及它占用的对象数量（书籍、部分）。已打开书籍的窗口也算一次运行。**Stop** 会像其用户那样停止该运行。**End** 只在出现提问后可用，它会结束运行而不停止其工作：运行所占用的内容会立即释放。只在运行永远无法结束时使用它（其工作卡住，并一直占用该书，直到重启为止）；其工作在被唤醒时仍可能写入内容。

<a id="the-log-the-jobs-tab"></a>

## 记录：任务标签页

![管理员页面的任务标签页](../../images/admin-jobs.png)

| | |
|---|---|
| **User, Kind, Status** | 筛选器。*类型*是任务的种类（`generation`、`summary`、`annotate`、`agent`、`audiobook`、`image-generator` 等）；未指定工作类型的代码所发出的请求显示为 `untagged`。 |
| **Older than (days)** | 只显示在该天数或更早之前开始的任务。 |
| **Refresh** | 重新读取记录。 |
| **Delete these jobs** | 永久删除筛选器显示的任务及其调用，删除前会弹出一个询问数量的确认框。未设置任何筛选器时，会删除整个记录。 |
| **Open the live view** | 在新标签页中打开 `/jobs`。 |

点击某一行可查看该任务的调用：类型（语言模型、音频、图像）、AI 或服务器、模型、开始时间、结束时间、耗时、状态，以及失败调用的错误信息。显示为失败的任务，表示其中有一次调用失败，或者运行它的代码将其标记为失败；被取消的调用是你主动停止的调用（或任务结束时仍在运行的调用）。

![音频转换的调用](../../images/admin-jobs-calls.png)

失败的任务会显示是哪一次调用失败以及原因：

![语音调用出错导致转换失败](../../images/admin-jobs-failed.png)

**记录不会自动删除。** 每个请求都会让记录增长，因此要不时清理：设置 *Older than (days)*（例如 30），查看列出的内容，然后删除。[清理](cleanup.md)功能会在删除用户时一并删除该用户的任务。

![30 天前的任务，以及删除前的询问](../../images/admin-jobs-old.png)

![删除任务前的询问](../../images/admin-jobs-delete.png)

任务在结束时才写入记录；仍在运行的任务只出现在 `/jobs` 上。如果应用程序停止，正在运行的任务会丢失（它们从未完成）。一个无人结束、且半小时内不再发出任何调用的任务，会被标记为已完成。
