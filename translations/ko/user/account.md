# 계정 및 설정

Marginalia에서 만든 모든 것은 사용자 계정에 속합니다. 책, 로어북, 태그, 추론 제공자, 프로토콜과
설정이 여기에 포함됩니다. 다른 사용자는 이것들을 볼 수 없고(공개한 [책](books/publishing.md)은 예외입니다), 여러분도 다른 사용자의 것을 볼 수 없습니다.

<a id="your-account"></a>

## 내 계정

작업 공간 하단의 버튼들입니다:

| 버튼 | |
|---|---|
| **언어** | 사용자 인터페이스의 언어입니다. [언어](#language)를 참고하세요. |
| 해 / 달 버튼 | 언어 옆에 있으며, 어두운 테마와 밝은 테마를 전환합니다. [테마](#theme)를 참고하세요. |
| **비밀번호 변경** | 비밀번호, 사용자 이름, 이름을 변경합니다. 아래를 참고하세요. |
| **로그아웃** | 이 기기에서 로그아웃합니다. |
| **관리** | 관리자만 사용할 수 있습니다. [관리](administration/index.md)를 참고하세요. |

<a id="changing-the-password"></a>

### 비밀번호 변경

**비밀번호 변경**을 누르면 **사용자 이름**, **이름**, **현재 비밀번호**, **비밀번호**, **비밀번호 확인** 항목이 있는 대화상자가 열립니다:

- 변경할 때마다 **현재 비밀번호**를 입력하세요(계정에 비밀번호가 없다면 비워 두세요);
- 비밀번호를 바꾸려면 새 비밀번호를 두 비밀번호 칸에 모두 입력하세요;
- 이름만 바꾸고 비밀번호는 그대로 두려면 두 비밀번호 칸을 모두 비워 두세요;
- **다른 브라우저와 저장된 모든 로그인에서도 로그아웃** 옵션을 선택하면, 비밀번호를 바꾸지 않고 다른 모든 기기에서 계정이 로그아웃됩니다. 아래를 참고하세요;
- 사용자 이름은 다른 계정이 이미 사용 중이면 안 됩니다.

저장하려면 **확인**을 누르세요. 현재 비밀번호가 틀리면 아무것도 저장되지 않습니다.

비밀번호를 바꾸면 이 기기를 포함한 모든 기기에서 저장된 로그인(*로그인 유지*)이 끝납니다. 새 비밀번호로 다시 로그인해야 합니다. 지금 열려 있는 다른 세션(다른 기기의 브라우저에 작업 공간이 떠 있는 경우)도 함께 종료됩니다. 지금 작업 중인 세션만 유지됩니다. 기기를 잃어버렸거나 비밀번호가 유출되었다면, 비밀번호를 바꾸는 것만으로 그 기기에서 로그아웃됩니다.

**다른 곳에서 모두 로그아웃**은 새 비밀번호 없이 같은 작업을 합니다. 계정의 저장된 로그인이 모두 잊히고, 다른 열린 세션도 모두 종료됩니다. 본인 계정이 다른 기기, 예를 들어 내 것이 아닌 컴퓨터에 로그인된 채로 남아 있다면 이 기능을 사용하세요. 이 대화상자의 다른 변경과 마찬가지로 현재 비밀번호가 필요합니다. 지금 사용 중인 세션은 유지되지만, 그 세션의 저장된 로그인도 함께 잊히므로 이 브라우저도 다음번에 비밀번호를 물어봅니다.

<a id="language"></a>

### 언어

버튼 위에 있는 **언어** 선택기로 사용자 인터페이스의 언어를 다른 언어로 바꿀 수 있습니다. 선택 내용은 계정에 저장됩니다. 페이지가 새 언어로 다시 로드되며, 열어 둔 다른 페이지(다른 기기의 페이지 포함)도 같이 바뀌고, 다음에 로그인할 때도 그대로 사용됩니다. 로그인 화면 자체는 항상 기본 언어로 표시됩니다.

목록에는 설치된 언어만 나타납니다. 영어, 일본어, 프랑스어, 스페인어, 독일어, 한국어, 이탈리아어는 Marginalia에 기본으로 포함되어 있습니다. 관리자는 [확장 기능](extensions/index.md)을 불러와 언어를 더 추가할 수 있습니다. 예를 들어 [중국어 현지화](extensions/chinese-localization.md)가 있습니다. 해당 언어로 번역되지 않은 문구는 영어로 표시됩니다. 함께 제공되는 확장 기능은 일본어, 중국어, 프랑스어, 스페인어, 독일어, 한국어, 이탈리아어 문구를 자체적으로 포함합니다(중국어 문구는 중국어 현지화가 로드되었을 때 표시됩니다).
날짜는 해당 언어의 방식으로 표시됩니다. 책과 그 본문은 번역되지 않으며, 인터페이스만 번역됩니다.

<a id="theme"></a>

### 테마

**언어** 선택기 옆의 버튼은 사용자 인터페이스를 어두운 테마(기본값)와 밝은 테마 사이에서 전환합니다. 선택 내용은 계정에 저장되며, 다음에 어느 기기에서 로그인하든 그대로 사용됩니다. 다른 탭에 이미 열려 있는 페이지는 다시 로드할 때 바뀝니다. 차트와 관계도는 열릴 때 테마의 색을 따릅니다.

![밝은 테마의 작업 공간](../images/theme-light.png)

<a id="logging-in"></a>

### 로그인

로그인 화면의 **로그인 유지**를 선택하면 이 기기에서 30일 동안 로그인 상태가 유지됩니다(서버에서는 HTTPS가 필요합니다. [서버(Docker)](getting-started/docker-server.md#https-and-reverse-proxy)를 참고하세요). **로그아웃**을 누르면 로그인 상태가 끝납니다.

계정은 비밀번호를 비워 둘 수 있으며, 이 경우 사용자 이름만으로 로그인합니다. 관리자가 잊어버린 비밀번호를 지웠다면, 이 방법으로 로그인한 뒤 바로 **비밀번호 변경**에서 새 비밀번호를 설정하세요. 이 방식은 직접 쓰는 컴퓨터의 데스크톱 앱에서는 편리하지만, 다른 사람이 접근할 수 있는 서버에서는 절대 사용하지 마세요.

<a id="settings"></a>

## 설정

**설정** 탭에는 모든 책에 공통으로 적용되는 기본값이 있습니다.

![설정 탭](../images/settings-defaults.png)

맨 위에는 세 개의 버튼이 있습니다:

- **새 책으로 백업 가져오기** - 백업 파일로 책을 만듭니다. [책 백업](books/backups.md#importing-a-backup-as-a-new-book)을 참고하세요;
- **변경 사항 취소** - 저장하지 않은 변경 사항을 버리고 저장된 설정을 다시 불러옵니다;
- **저장** - 설정을 저장합니다.

!!!info 저장되지 않은 변경 사항
설정은 자동으로 저장되지 않습니다. 필드(확장 기능 설정 포함)를 하나라도 바꾸면 곧바로 상단에 *저장되지 않은 변경 사항*이 나타나고, 다른 탭, **관리**, **로그아웃**이 잠깁니다. **저장** 또는 **변경 사항 취소**를 눌러야 잠금이 풀립니다.
!!!

### 일반 설정

| 필드 | |
|---|---|
| **기본 모델** | 새 책이 처음 사용하는 [추론 제공자](inference-providers.md). |
| **기본 프로토콜** | 새 책이 처음 사용하는 [프로토콜](protocols.md). |
| **주석용 기본 모델**, **주석용 기본 프로토콜** | 실행할 때 다른 것을 고르지 않으면 [파트에 주석을 달 때](books/annotations.md#letting-a-model-annotate) 사용하는 모델. 비워 두면 책의 모델을 씁니다. |
| **백업 전략** | 자체 전략이 없는 책의 자동 [책 백업](books/backups.md#automatic-backups): *백업 없음*, *N개 메시지 후* 또는 *N분 후*. 옆의 숫자는 그 조건의 값입니다. |
| **파트별 보관 버전 수** | 모든 책에서 파트 본문의 이전 버전을 [기록](books/version-history.md#how-many-versions-are-kept)에 몇 개나 보관할지 정합니다. 폴더, 책 또는 관리자가 더 적게 제한하지 않는 한 적용됩니다. 비워 두면 여기서는 제한이 없고, **0**이면 기록을 보관하지 않습니다. |
| **이야기에서 한 번에 불러오는 파트 수** | [이야기](books/story-editor.md)와 [뷰어](books/publishing.md)가 메모리에 불러와 두는 책의 파트 수. 이야기는 마지막 파트들로 시작하고, 뷰어는 마지막으로 읽은 위치(또는 처음 파트)에서 시작합니다. 그 앞뒤의 파트는 스크롤에 따라 불러오며, 멀리 떨어진 파트는 다시 내립니다. 비워 두면 모든 파트를 한꺼번에 불러옵니다. |
| **일일 목표: 작성한 단어 수**, **일일 목표: 편집 시간(분)** | [집필 통계](books/statistics.md#the-daily-goal) 달력에 쓰는 하루 목표로, 모든 책에서 직접 쓴 단어 수와 편집한 시간(분)을 셉니다. 비워 두면 목표가 없습니다. |
| **집필 통계 기록**, **Keep statistics for (months)** | [집필 통계](books/statistics.md#privacy-clearing-not-recording-keeping-less)를 기록할지, 그리고 몇 개월 동안 보관할지 정합니다(비우거나 0이면 전부 보관). 관리자는 모든 사용자에 대해 기록을 끄거나 더 짧은 기간을 설정할 수 있습니다. |

*기본 모델*과 *기본 프로토콜*은 책을 만들 때만 사용합니다. 이 값을 바꾸어도 기존 책은 바뀌지 않습니다. [Lore Generator](extensions/lore-generator.md) 확장 기능은 책이 없으므로 이 값으로 생성합니다. 백업 전략은 *원고별 재정의*가 없는 모든 책에 적용되며, 다음에 생성되는 파트부터 반영됩니다.

### 템플릿

[책 프롬프트](books/prompts.md)의 기본값입니다.

| 필드 | |
|---|---|
| **프롬프트 언어** | 내장 프롬프트의 언어입니다. 영어(기본값), 일본어, 프랑스어, 스페인어, 독일어, 이탈리아어, 한국어, 그리고 [중국어 현지화](extensions/chinese-localization.md)가 로드된 경우 중국어 중에서 고릅니다. 아래 [프롬프트 언어](#prompt-language)를 참고하세요. |

| **문체** | 문체와 어조에 대한 지침입니다. |

| **주석 시스템 프롬프트**, **주석 프롬프트** | 모델에게 파트에 [주석을 달도록](books/annotations.md#letting-a-model-annotate) 요청할 때의 시스템 메시지와 마지막 메시지입니다. [주석 프롬프트](books/prompts.md#annotate-prompt)를 참고하세요. |

| **대필 프롬프트** | 모델이 당신을 대신해 다음 턴의 [지시문을 작성](books/story-editor.md#drafting-the-instructions)하도록 요청하는 문구입니다. [대필 프롬프트](books/prompts.md#impersonate-prompt)를 참고하세요. |
| **에이전트 압축 프롬프트** | [에이전트](agents.md)를 사용할 수 있는 사용자만 해당합니다. [`/compact`](agents.md#running-a-command-yourself)를 실행할 때 에이전트에게 요청하는 내용입니다. 에이전트 자체의 압축 프롬프트가 비어 있을 때 쓰이며, 여기서도 비워 두면 관리자가 설정한 값을 쓰고, 그것도 없으면 내장 값을 씁니다. |

| **에이전트 시스템 프롬프트** | [에이전트](agents.md)를 사용할 수 있는 사용자만 해당합니다. 에이전트 자체의 시스템 프롬프트가 비어 있을 때 에이전트에게 어떤 존재인지 알려 주는 내용입니다. 여기서도 비워 두면 관리자가 설정한 값을 쓰고, 그것도 없으면 내장 값을 씁니다. 일반 텍스트이며 템플릿이 아닙니다. |

에이전트를 사용할 수 있는 사용자에게는 아래쪽에 에이전트의 프롬프트도 나타납니다.

![템플릿 탭의 에이전트 프롬프트](../images/settings-templates-agents.png)

각 필드는 비어 있는 동안 내장 기본값을 회색으로 보여 주고, **기본 템플릿 삽입**과 사용 가능한 [변수와 매크로](templates/index.md)가 나오는 힌트 팝오버를 가지고 있습니다.

<a id="prompt-language"></a>

#### 프롬프트 언어

**프롬프트 언어**는 내장 프롬프트의 언어를 고릅니다. 비어 있는 필드가 무엇을 뜻하는지(다른 언어를 고르면 회색 글자가 바로 바뀝니다)를 정하며, 따라서 생성, 요약, 재작성, 주석, 대필에서 모델에 보내는 내용을 정합니다. 플러그인 중 자체 프롬프트를 가진 것들(Arc Outline, Beta Readers, Book Description Generator, Lore Generator, Manga Generator, SillyTavern Converter, Knowledge Tracker, Audiobook)과 에이전트의 프롬프트도 이 설정을 따릅니다. 이것은 인터페이스 언어와는 별개입니다. 애플리케이션은 영어로 쓰고 프롬프트는 일본어로 보낼 수도 있습니다. 모델은 이야기의 언어로 된 지시를 가장 잘 따르므로, 책을 쓰는 언어를 고르세요. 바뀌는 것은 내장 프롬프트뿐입니다. 여기서든 책이나 폴더에서든 직접 쓴 프롬프트는 그대로 유지됩니다. [에이전트](agents.md)는 이 설정이 아니라 에이전트 설정의 *언어*에 따라 프롬프트와 알림을 읽습니다.

이 기본값은 **자체 필드가 비어 있는 모든 책에** 즉시 적용되며, 새로 만든 책에만 적용되는 것이 아닙니다. *프롬프트* 탭에서 자체 값을 설정한 책은 그 값을 유지합니다. 따라서 다음과 같이 하세요.

- 모든 책이 공유하는 것은 여기에서 설정합니다.
- 한 책에만 해당하는 것은 그 책의 *프롬프트* 탭에서 설정합니다.
- 책의 필드를 비우면 *설정*의 기본값으로 되돌아갑니다.

### 스타일

책 텍스트 스타일: 이야기와 독자 화면에서 각 부분의 텍스트가 어떻게 보이는지를 정합니다. 이 탭에는 애플리케이션이 제공하고 바꿀 수 없는 **보통**과 **책** 스타일(*내장*으로 표시됨)과 직접 만든 스타일이 나열됩니다. 목록에서 스타일을 선택하면 오른쪽에서 편집할 수 있습니다. 목록 아래의 버튼은 다음과 같습니다.

- **복제** - 선택한 스타일을 바탕으로 직접 쓸 수 있는 스타일을 만듭니다(내장 스타일도 복제할 수 있으며, 이렇게 시작하면 됩니다). 이름은 *... (복사본)*으로 붙고, 이후 이름을 바꾸고 수정할 수 있습니다.
- **삭제** - 직접 만든 스타일을 삭제합니다. 내장 스타일은 삭제할 수 없습니다.
- **기본값으로 설정** - 이 스타일을 책이 기본으로 사용하는 스타일로 지정합니다. 단, 책의 설정 메뉴에서 [다른 스타일을 선택](books/story-editor.md#text-styles)한 경우에는 그 선택이 우선합니다. 기본 스타일은 목록에서 *기본값*으로 표시됩니다.
- **내보내기**와 **가져오기** - 선택한 스타일을 `.style.json` 파일로 저장하고, 그런 파일의 스타일을 직접 만든 스타일에 추가합니다(설정을 저장하기 전까지는 저장되지 않습니다). 자세한 내용은 [스타일 공유하기](books/styling-guide.md#share-a-style-export-and-import)를 참고하십시오.

[스타일 가이드](books/styling-guide.md)에서는 모든 옵션을 차례로 설명하며, 내려받을 수 있는 예제 스타일도 제공합니다.

![스타일 가이드의 호러 스타일이 선택된 스타일 탭](../images/settings-styles.png)

직접 만든 스타일의 경우 오른쪽 양식에는 **이름**, **내보내기용 (책에는 제공되지 않음)** 체크 상자, 두 개의 탭이 있습니다. 스타일은 책용이거나 내보내기용 중 하나입니다. 내보내기용 스타일은 [내보내기 대화상자](books/export.md#print-styles)에서 선택할 수 있으며(애플리케이션이 HTML, EPUB, PDF, Word 내보내기의 모양에 해당하는 네 가지를 기본으로 제공합니다), 책의 기본 스타일이 될 수 없습니다. 반대로 책용 스타일은 내보내기 대화상자에 나타나지 않습니다. 목록에서는 내보내기용 스타일에 *(내보내기)*라고 표시됩니다.

- **옵션** - 그룹별로 구성됩니다. *텍스트*(글꼴, 크기, 줄 높이, 글자 및 단어 간격, 색상, 정렬, 하이픈 처리, 문단 사이 간격, 문단의 **첫 줄 들여쓰기**, 제목 뒤의 **드롭캡**), *페이지*(본문 열의 너비, 가운데 정렬, 텍스트 뒤의 전체 영역을 채우는 **배경색**), *강조, 링크, 코드*(기울임꼴과 굵은 글씨, 링크의 색과 코드 글꼴), *인용문*, *제목*(글꼴, 첫 번째 수준의 크기, 색상, 정렬, 작은 대문자) 그리고 *장면 전환*(`---`)의 기호와 색상입니다. 각 상자에는 CSS 값을 아무거나 입력할 수 있습니다(`1.1rem`, `#336699`, `var(--lumo-body-text-color)` 등). 빈 상자는 애플리케이션의 기본 모양을 그대로 유지합니다. 글꼴 상자에는 흔히 쓰이는 글꼴 목록이 제공되며, 직접 입력할 수도 있습니다.
- **사용자 지정 CSS** - 직접 작성한 CSS로, 옵션 뒤에 추가되고 스타일 안에서 적용됩니다. 따라서 여기에 쓴 규칙은 이 스타일을 쓰는 텍스트에만 적용됩니다. 예를 들어 `.chat-message-markdown p { text-indent: 1.5em !important; }`는 문단을 들여씁니다. `font-size: 1.2rem;`처럼 선언만 쓰면 전체 텍스트에 적용됩니다. 그 아래의 **생성된 CSS**는 옵션이 만들어 내는 스타일시트를 보여 주며, 읽기 전용입니다. 중괄호 `{ }`의 짝이 맞지 않으면 스타일이 저장되지 않습니다.

![스타일의 사용자 지정 CSS 탭](../images/settings-styles-css.png)

양식 아래의 **미리 보기**에는 스타일이 적용된 샘플 텍스트가 나타나며, 입력할 때마다 변경 사항을 바로 반영합니다.

다른 탭과 마찬가지로 스타일 탭도 설정의 **저장**으로 함께 저장되며, **변경 사항 취소**를 누르면 이 탭의 변경 사항도 함께 버려집니다. 복제, 편집, 삭제, 기본값 설정은 작업 중인 사본만 바꾸며, 이런 작업을 하면 바로 *저장되지 않은 변경 사항* 표시(와 잠금)가 나타납니다. 이름이 없는 스타일이나 중괄호가 맞지 않는 사용자 지정 CSS는 저장할 때 거부됩니다.

<a id="exports"></a>

### 내보내기

각 파일 형식을 어떻게 내보낼지 정합니다. 이 탭에는 설정할 것이 있는 형식마다 구역이 있습니다(**일반 텍스트**, **마크다운**, **HTML**, **Word**, **PDF**, **EPUB**, **front matter가 있는 마크다운**, **옵시디언 보관함**). 구역을 열려면 그 이름을 클릭하십시오.

- **인쇄 스타일**(글꼴과 색이 있는 형식인 HTML, Word, PDF, EPUB) - [내보내기 대화상자](books/export.md)가 해당 형식에 미리 선택해 두는 스타일입니다. 처음에는 애플리케이션이 해당 형식에 제공하는 모양(**HTML 페이지**, **PDF 책** 등)으로 시작합니다. 목록에는 [내보내기용 스타일](#styles)이 나타나며, 내장 스타일과 직접 만든 스타일이 모두 포함됩니다. 다른 스타일을 고르면 한 번의 내보내기에서 대화상자의 선택을 바꾸기 전까지 그 형식은 항상 그 스타일로 내보내집니다.
- **front matter**(front matter가 있는 마크다운과 옵시디언 보관함) - 파일의 맨 앞에 오는 YAML 블록으로, `{{title}}`, `{{author}}`, `{{language}}`, `{{exportDate}}`를 쓸 수 있습니다. 비워 두면 기본 블록이 사용됩니다.
- **표제지**(다른 도구용 형식을 제외한 모든 형식. 옵시디언 보관함은 책의 노트에 표제지가 있습니다) - 표제지의 템플릿입니다. 마크다운을 작성하는 Handlebars 템플릿이며, `{{title}}`과 `{{author}}`를 사용할 수 있습니다(필드의 정보 아이콘에 목록이 나옵니다). 비워 두면 기본 표제지가 사용되며, 제목은 제목으로, 저자는 그 아래에 기울임꼴로 표시됩니다. 정보 팝오버의 **기본값으로 채우기**를 누르면 기본 템플릿으로 시작할 수 있습니다.
- **저작 표시**(SillyTavern 채팅을 제외한 모든 형식) - 내보내기의 확인란 **저작 표시 포함**을 선택하면 끝에 추가되는 문구입니다. 사용할 수 있는 항목은 `{{title}}`, `{{author}}`, `{{totalWords}}`, `{{writtenWords}}`, `{{generatedWords}}`, `{{writtenPercent}}`, `{{generatedPercent}}`, `{{models}}`입니다(`{{models}}`에는 사용된 모델이 쉼표로 구분되어 들어가며, 모델이 없으면 비어 있습니다). 비워 두면 기본 문구가 사용됩니다.

이것들은 사용자가 설정한 버전입니다. 책이나 폴더는 자체 설정을 가질 수 있으며, 자세한 내용은 [표제지 템플릿](books/export.md#title-page-template)을 참고하십시오. 이 탭은 설정의 **저장**으로 함께 저장되며, **변경 사항 취소**를 누르면 다른 탭과 마찬가지로 이 탭의 변경 사항도 버려집니다. 유효하지 않은 템플릿은 저장할 때 거부됩니다. 스타일 탭에서 만든 스타일은 저장한 뒤 이곳에서 선택할 수 있습니다.

![HTML 구역이 열린 내보내기 탭](../images/settings-exports.png)

### 태그

책, 로어북, 로어북 항목에 붙인 모든 태그의 표이며, 각 태그가 연결된 객체 수를 보여 줍니다. 열 머리글을 클릭하면 그 열 기준으로 정렬됩니다. 다른 탭과 달리 이 탭은 바로 적용되며, 저장되지 않은 변경 사항에 포함되지 않아 저장할 것이 없습니다.

![태그 탭](../images/settings-tags.png)

| 버튼 | |
|---|---|
| **이름 바꾸기** (연필) | 태그의 새 이름을 묻습니다. 연결된 모든 객체는 새 이름으로 태그를 유지합니다. |
| **삭제** (휴지통) | 확인을 묻고 나서 태그를 삭제하고, 그 태그를 가진 모든 객체에서 제거합니다. |

새 이름이 다른 태그의 이름과 같으면(이름은 대소문자를 구분하지 않고 비교합니다) 이름을 바꾸는 순간 두 태그가 같아지므로, 두 태그를 **병합**할지 묻습니다. 병합하면 이름이 바뀐 태그가 붙은 모든 것이 기존 태그로 옮겨지고 이름이 바뀐 태그는 삭제됩니다. 두 태그가 모두 붙은 객체는 기존 태그가 한 번만 붙습니다. 취소하면 아무것도 바뀌지 않고, 태그는 예전 이름을 유지합니다.

![두 태그를 병합할지 묻는 화면](../images/tag-merge.png)

### 키보드 단축키

[이야기 편집기 단축키](books/story-editor.md#keyboard-shortcuts)의 키입니다(컴퓨터에서 이야기 편집기에 적용되며, [휴대폰 레이아웃](phone.md)에는 단축키가 없습니다).
이 표는 [확장 기능](extensions/index.md)이 추가하는 항목을 포함해 모든 동작과 그 키를 나열하며, 책 목록의 [정리](books/folders.md#organise) 창 버튼의 키도 포함합니다. 이야기 설정 메뉴, 부분(part) 메뉴, 그리고 그 본문의 마우스 오른쪽 클릭 메뉴의 모든 항목은 여기서 동작으로 취급됩니다(대부분은 키를 지정하기 전까지 키가 없습니다). 메뉴에는 각 항목 옆에 키가 표시됩니다.

| 버튼 | |
|---|---|
| **기록** | 새 키 조합을 누릅니다(수정 키를 먼저 또는 함께 누릅니다. 예: `Ctrl+Shift+K`). 다른 곳을 클릭하면 취소됩니다. |
| **기본값으로 초기화** | 동작의 기본 키를 되돌립니다. |
| **지우기** | 동작에 키를 지정하지 않습니다. |

두 동작이 같은 키를 쓰면 빨간색 메모로 알려 줍니다. 브라우저가 자체적으로 사용하는 키(`Ctrl+N`, `Ctrl+T`, `Ctrl+W` 등, 페이지는 이 키를 받지 못합니다)와, 문자 키가 붙은 `Alt`(일부 키보드, 예를 들어 macOS에서는 문자를 입력합니다)도 마찬가지로 표시됩니다. `Ctrl`, `Alt`, `Meta` 없이 쓰는 키는 텍스트 입력란에 포커스가 없을 때만 동작합니다. 키는 다른 설정과 함께 **저장**으로 저장되며, 열려 있는 이야기에는 즉시 적용됩니다.

![설정, 키보드 단축키](../images/settings-shortcuts.png)

### 알림

모델 작업이 끝나면 브라우저의 데스크톱 알림을 보내므로, 모델이 작업하는 동안 다른 탭으로 이동해도 됩니다. 이 탭에는 **데스크톱 알림 사용** 체크박스, 아래의 버튼들, 그리고 알림이 발생하는 항목의 목록이 있습니다.

- **이야기 생성**, **AI로 주석 달기**, **AI로 주석 달기(자동)**, **재작성**, **재작성(자동)**, **지시문 초안 작성**, **요약**, **모든 요약 다시 요약**, **도움말 어시스턴트**, 그리고 [확장 기능](extensions/index.md)이 추가하는 항목들이며, 이들은 확장 기능 이름을 따릅니다(*Reviewer: generate a review*, *Lore Generator: generate lore*, *Image Generator: generate the image*, *Arc Outline: generate chapters*... 등). *Manga Generator* 항목 중 *(자동)*으로 표시된 것은 연속 모드입니다.
- *(자동)*으로 표시된 항목은 책이 스스로 시작하는 실행입니다. 즉 생성 후의 [자동 주석](books/story-editor.md)과 그에 이어지는 재작성입니다. 이 항목들은 사용자가 직접 여는 대화상자와 구분되어 선택됩니다. **AI로 주석 달기**는 체크되어 있고 **AI로 주석 달기(자동)**는 체크되어 있지 않으면 자동 주석은 조용히 실행됩니다. 자동 항목만 체크되어 있으면 자동 주석만 알림을 보냅니다.
- 오류로 끝나는 실행(*… failed*)도 알림을 보내지만, 사용자가 직접 중단한 실행은 알림을 보내지 않습니다.

체크박스를 켜면 계정에 대해 알림이 활성화되고, 두 버튼이 사용 가능해집니다. **이 브라우저 등록**을 누르면 브라우저에 권한을 요청하며, 이 클릭을 통해서만 요청할 수 있습니다. 버튼 아래의 줄에는 이 브라우저의 상태가 표시됩니다. 허용됨, 차단됨(브라우저의 사이트 설정에서 허용해야 합니다), 또는 아직 요청하지 않음 중 하나입니다. 이 권한은 계정이 아니라 브라우저에 속합니다. 알림을 받고 싶은 모든 브라우저나 기기는 한 번씩 등록해야 하며, 체크박스와 목록은 어디서나 동일합니다. **테스트 알림 보내기**를 누르면 페이지가 앞에 있어도 즉시 알림이 표시됩니다.

**필터** 입력란은 이름으로 목록을 좁혀 줍니다. **표시된 항목 선택**과 **표시된 항목 선택 해제**는 필터로 보이는 항목에만 적용되고, 나머지 항목은 그대로 둡니다. 알림은 사용자가 페이지를 보고 있지 않을 때(다른 탭에 있거나 창이 앞에 있지 않을 때)에만 표시되며, 알림을 클릭하면 페이지로 돌아옵니다.

알림에는 `https://` 주소나 `localhost`가 필요합니다. 내부 네트워크 서버의 일반 `http://` 주소에서는 브라우저가 알림을 제공하지 않으며, 이 경우 탭에 그렇다고 표시됩니다. 브라우저가 절전 상태로 둔 탭(보통 휴대폰에서)은 알림을 표시할 수 없습니다. 이 탭의 설정은 다른 설정과 마찬가지로 설정의 **저장**으로 저장됩니다.

### 확장 기능 설정

설치된 [확장 기능](extensions/index.md)의 설정으로, 확장 기능마다 한 구역씩 있습니다(예: *Reviewer Settings*, *SideQuery Settings*). 같은 **저장** 버튼으로 저장됩니다. 설정이 있는 확장 기능이 설치되어 있지 않으면 이 탭은 비어 있습니다.
