# 中国語のローカライズ

ユーザーインターフェースの言語に、簡体字中国語（中文（简体））を追加します。

<a id="using-it"></a>

## 使い方

管理者が拡張機能を読み込むと（[拡張機能の管理](../administration/extensions.md)）、*中文（简体）*が、ワークスペースの下部にある**言語**セレクターに、英語と日本語と並んで表示されます（[スマートフォン](../phone.md)では、メニューの中にあります）。これを選ぶとページが中国語で再読み込みされます。選択内容はアカウントに保存されるため、ログインするすべての端末で使われます。言語はユーザーごとに個別に選べます。

![中国語のストーリーエディター](../../images/plugin-chineselocalization.png)

インターフェースは翻訳されます。メニュー、ボタン、メッセージ、テンプレート変数とマクロの説明などが対象です。まだ中国語訳がない文章は英語のまま表示されます。

この拡張機能は、設定の**プロンプトの言語**（*設定 → テンプレート*、[プロンプトの言語](../account.md#prompt-language)を参照）にも中国語を追加します。これを選ぶと、アプリケーションとプラグインの組み込みプロンプトが中国語で送信されます。これはインターフェースの言語とは独立した、別の選択です。あなたの作品、ロアブック、ご自身で書いたプロンプトは変更されません。

<a id="removing-it"></a>

## 削除方法

拡張機能を読み込み解除すると、インターフェースとプロンプトの両方から中国語が取り除かれます。中国語を選んでいたユーザーは、別の言語を選び直すまで英語で表示され、英語で送信することになります。ただし選択内容は保持され、拡張機能を再び読み込むと再び適用されます。

<a id="for-developers"></a>

## 開発者向け

この拡張機能は、言語を追加する際の例になっています。詳しくは[サンプルプラグイン → 中国語のローカライズ](../../developer/plugins/example.md#walkthrough-chinese-localization)を参照してください。
