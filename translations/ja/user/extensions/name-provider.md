# 名前プロバイダー

モデルが名前を発明する代わりに、選べる実在の名前を提供します。多くの国で最もよく使われる名と姓です。[Name generator](name-generator.md)が、カテゴリに合う響きの新しい名前を作るのに対し、この拡張機能は実際に存在する名前を渡します。各名前には、ローマ字表記の隣に原綴りも添えられます：`Satō` と `佐藤`。

この拡張機能には独自の画面がなく、設定する項目もありません。他の拡張機能が、その機能をモデルに提供します。[Lore Generator](lore-generator.md#tools)と[Arc Outline](arc-outline.md)では、モデルが使ってよいリストを選べます。そのスイートは、[ツールウィンドウ](tools.md)にある*Name generator*スイートの隣の*Name provider*です。両方のリスト、片方のリスト、またはどちらのリストも使わない、を選べます。

<a id="what-the-model-can-do"></a>

## モデルにできること

| 関数 | 内容 |
|---|---|
| `list_real_name_lists` | 名前のリストを一覧表示します。`filter`を指定すると、名前に指定語を含むリストだけを表示します。 |
| `pick_real_names` | 1つのリストから、重複のない名前を最大100個ランダムに選びます。各名前は、ローマ字表記と原綴りのペアです。 |

要求された数より名前が少ないリストでは、すべての名前が返されます。モデルには（[ツールウィンドウ](tools.md#choosing-the-tools)の*Name provider*スイートのヒントを参照）、受け取った名前の中から選ぶこと、返されたとおりに書くこと、設定に合う場合は原綴りを隣に添えること、同じ国の名と姓を組み合わせてもよいことが伝えられます。

<a id="commands"></a>

## コマンド

同じ名前は、コマンドラインと[エージェント](../commands/index.md)向けの[コマンド](../agents.md)としても利用できます。エージェントは自分のプロンプトでこれらを使えます（例えば[Lore Generator](lore-generator.md)の`/generate-lore-entry`で）：

| コマンド | 内容 |
|---|---|
| `/list-real-name-lists [<filter>]` | リストをJSON配列として一覧表示します。filterを指定すると、名前にすべての指定語を含むもの（各語は単語の先頭で一致し、順不同で、大文字と小文字を区別しない）だけを表示します。 |
| `/pick-real-names list count` | リストから名前を最大100個ランダムに選び、ローマ字表記と原綴りのペアのJSON配列として返します。 |

どちらも読み取るだけです。

<a id="lists"></a>

## リスト

約180のリストがあり、名前は`<Country> - Surnames`と`<Country> - Forenames`の形式です。姓は75か国分、名は106か国分あります（`Japan - Surnames`、`Czechia - Forenames`、`Kosovo - Surnames`）。男女両方の名は1つのリストにまとめられています。1つのリストには、その国で最もよく使われる名が5個から約150個入っています。名前は新たに作られたものではありません。受け取る名前は、実際に人々が使っている名前です。

数十個の項目は、言語ごとの**グループ**です。`<Language> - Forenames`と`<Language> - Surnames`の形式で、スペイン語（18か国）、ポルトガル語、フランス語、ドイツ語、英語、アラビア語、西スラブ語、東スラブ語、南スラブ語、北ゲルマン語、北欧語、ウラル語、バルト語、テュルク語、ペルシア語、中国語、南アジア語、東南アジア語、コーカサス語、アルバニア語、ルーマニア語（該当するリストがある場合）があります。これらも他のリストと同様に一覧に表示され、[ツールウィンドウ](tools.md)では1つの項目です。グループの名前はすべて、そのグループ内のリストからランダムに選ばれます。各国は同じ確率で選ばれるため、20個の名前を要求すると複数の国の名前が得られ、同じ名前が2回出ることはありません。複数の言語が話されている国（ベルギー、ルクセンブルク、マルタ、アンドラ）は、どのグループにも含まれません。グループは`name-groups.json`の1行として定義されます。詳しくは[プラグインのREADME](https://github.com/Enerccio/Marginalia/blob/master/marginalia/plugins/name-provider/README.md#groups)を参照してください。

データは[国別人気名データセット](https://github.com/sigpwned/popular-names-by-country-dataset)（CC0）で、Wikipediaの最も一般的な姓と最も人気のある名のリストから取られたものです。非ラテン文字で書かれた名前（中国語、日本語、韓国語、アラビア語、キリル文字など）にはローマ字表記があります。これは元データのものか、機械翻訳によって作られたものです。そのため、正確さが重要な場合は綴りを確認してください。

<a id="usage"></a>

## 使い方

*Admin → Extensions*で拡張機能を読み込みます。読み込みは次の生成から適用されます。使用する拡張機能より後にインストールした場合や、一度アンロードして再インストールした場合も同様です。この拡張機能と他のスイートがなければ、*ツール*ボタンは表示されません。
