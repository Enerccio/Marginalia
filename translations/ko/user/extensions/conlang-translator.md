# 컨랑 번역기

이야기의 등장인물이 인공 언어(conlang)로 말하도록 해 줍니다. 여러분이 언어(규칙과 단어)를 설명하면, 모델이 그 언어를 쓰는 등장인물의 **직접 화법**을 그 언어로 작성하고, 이야기에는 그 뒤에 있는 영어가 남습니다.

!!!
이야기 본문에는 **컨랑**이 담깁니다. 모델에게 이야기를 읽히는 모든 것(다음 생성, 요약, 로어북 검색, 주석, 다른 확장 기능)은 그 말이 번역되어 나온 **영어**를 읽습니다. 그래서 모델은 이야기를 이어 가기 위해 여러분의 언어를 이해할 필요가 없습니다. 번역된 말을 클릭하면 영어가 표시됩니다.
!!!

!!!warning 작업 중
이 확장 기능은 여기서 설명하는 화면을 사용하는 사람과, [명령](#commands)을 통해 에이전트 모두에게 동작합니다. 휴대폰에서는 일부 기능만 사용할 수 있으니 자세한 내용은 [제한 사항](#limits)을 참고하세요.
!!!

<a id="the-idea"></a>

## 기본 개념

1. **언어**는 두 가지로 구성됩니다. **규칙**(모델을 위해 문법서처럼 작성한 본문)과 **어휘집**(단어들. 주로 모델이 작성하고 여러분이 판단합니다). 언어는 설정에 한 번 저장되며, 원하는 만큼 많은 책이 이 언어를 사용할 수 있습니다.
2. **책**(또는 책 폴더)이 사용할 언어를 고릅니다. 한 부분(part)은 메뉴에서 수동으로 번역하거나, 확정되었을 때 자동으로 번역하거나, 구간 단위로 번역할 수 있습니다.
3. 부분마다 모델에 요청 한 번을 보내 모든 직접 화법을 분류합니다. 즉 그 말이 해당 언어로 되어 있는지, 아니면 이 등장인물이 이야기의 공용어로 말한 것인지(청자가 이해하는 말인지)를 가려내고, 해당 언어로 된 말만 번역합니다. 언어에 없는 단어는 규칙에 따라 만들어지며, **이유와 함께 보고**되고, **새 항목**으로 어휘집에 추가됩니다. 여러분은 이를 수락하거나, 바꾸거나, 잠그거나, 버릴 수 있습니다.
4. 영어는 책의 데이터 안에 말의 *원문*(source)으로 보관되며, 모든 모델이 이를 읽습니다. 컨랑이 원본입니다. 여러분이 직접 고친 내용은 그대로 남고, 여러분이 편집한 부분은 여러분 모르게 덮어쓰이지 않습니다.
<a id="languages"></a>

## 언어

언어는 **설정 → 확장 기능 설정 → Conlang Translator**에서 편집합니다. 이 패널에 사용자의 언어 목록이 나타납니다.

![설정의 언어 목록](../../images/plugin-conlang-settings.png)

| 버튼 | |
|---|---|
| **New language** | 빈 언어를 만듭니다. |
| **Design a language** | 모델이 새 언어의 각 부분을 제안하면 사용자가 편집하고 수락하는 [마법사](#the-designer)입니다. |
| **편집** | 선택한 언어의 [편집기](#the-editor)를 엽니다. |
| **복제** | 새 이름과 단어를 포함한 독립적인 사본을 만듭니다. 변경을 시험해 볼 때 사용하세요. 사본은 *한 책만을 위한* 언어를 갖는 유일한 방법이기도 합니다. 언어를 선택한 책은 그 언어를 선택한 다른 모든 책과 공유하기 때문입니다. |
| **Compare** | 선택한 언어에 다른 언어의 변경 사항을 가져옵니다. [검토](#comparing-and-merging)를 거친 뒤 적용됩니다. |
| **내보내기**, **가져오기** | 언어를 문서(JSON)로 내보내거나 가져옵니다. 규칙과 어휘만 포함되며 책과의 연결은 포함되지 않습니다. 이미 있는 이름의 언어를 가져오면 차이점 검토 또는 새 언어 만들기를 선택할 수 있습니다. |
| **삭제** | 확인 질문 후 삭제됩니다. |

화면 위쪽에는 **디자이너의 모델과 프로토콜**이 있습니다. 목록 아래에는 책과 폴더가 사용자에게서 **상속**하는 설정이 있습니다. 언어, 각 부분을 따로 번역할지 여부, 번역의 모델과 프로토콜입니다. 책이나 폴더는 이를 직접 지정할 수 있습니다. 자세한 내용은 [책의 언어 선택](#choosing-the-language-of-a-book)을 참고하세요. 변경 사항을 유지하려면 설정 화면에서 **저장**을 누르세요. 그 사이에 번역이 추가한 단어는 사라지지 않습니다. 사용자가 건드리지 않은 언어는 설정 화면을 저장할 때 다시 읽힙니다.

<a id="the-editor"></a>

### 편집기

편집기는 다섯 개의 탭이 있는 창입니다. **저장**을 누르기 전까지는 사본에서 작업하며, 크기를 조절하거나 끌어서 옮기거나 최대화할 수 있습니다.

| 탭 | |
|---|---|
| **Overview** | 이름, 사용자를 위한 설명, 옵션 **하이픈은 단어의 일부이다**(끄면 `thal-orun`과 `thalorun`은 같은 단어이고, 켜면 하이픈이 형태에 속합니다), 그리고 디자이너가 읽는 **예시 책**과 **예시 로어북**을 설정합니다. |
| **Rules** | **섹션**으로 나뉜 규칙입니다(소리와 표기, 문법, 단어 형성 등). 각 섹션은 **누가 읽는지**를 밝힙니다. *번역자*(모든 요청에 전송됨), *디자이너만*(언어의 역사, 단어 만들기 메모), 또는 *아무도*(사용자 자신의 메모)입니다. 플러그인은 규칙을 구문 분석하지 않습니다. 모델을 위한 텍스트일 뿐입니다. |
| **Categories** | 단어 묶음입니다(*People & Social*, *Nature*, *Particles* 등). 어휘는 이 제목 아래에 표시되고 모델에 전송됩니다. **항상 전송**되는 범주(조사, 대명사, 숫자)는 어휘가 너무 커서 통째로 보낼 수 없을 때도 모든 요청에 포함됩니다. |
| **Registers** | 설명이 붙은 말투(*formal*, *soft*, *vulgar*, *archaic* 등)입니다. 하나의 개념은 말투마다 형태를 가질 수 있으며, 모델은 말하는 사람과 듣는 사람에 따라 고릅니다. |
| **Lexicon** | 단어입니다. 아래를 참고하세요. |

![언어의 규칙](../../images/plugin-conlang-rules.png)

<a id="the-lexicon"></a>

### 어휘

![언어의 어휘](../../images/plugin-conlang-lexicon.png)

표에는 **검색**(단어 또는 뜻으로), **범주**와 **상태**별 필터, 그리고 **Add**, **Edit**, **Accept**, **Lock**, **Retire**, **삭제**, **Accept all new** 작업이 있습니다. 단어에는 다음이 있습니다.

- **형태**(이야기에서 쓰는 방식), 선택적으로 **문자 체계**의 형태, **범주**, 그리고 **종류**(어근, 합성어, 조사, 이름, 숫자, 구)가 있습니다.
- 하나 이상의 **뜻**(동음이의어는 여러 뜻을 가지며, 각각 품사와 메모가 있습니다)과 **개념의 다른 형태**(같은 것을 가리키는 격식체, 부드러운 말, 비속어 단어로, 함께 표시되고 함께 전송됩니다).
- **근거**: 모델이 그 단어를 고른 이유(규칙이나 어근)입니다. 사용자는 이를 보고 단어를 판단하며, 이후 요청에 다시 전달되어 다음 만들기가 같은 논리를 따르게 합니다.
- **출처**: 사용자 자신이거나 모델입니다(모델의 경우 어떤 부분을 위해 만들었는지, 어떤 모델이며 언제 만들었는지 포함). 사용자가 편집한 모델의 단어는 사용자의 것이 됩니다.
- **상태**: **New**(모델이 만들었고 사용자가 아직 보지 않음), **Accepted**, **Locked**(모델이 쓸 수는 있지만 뜻을 바꿀 수는 없음), **Retired**(남겨 두지만 모델에 제시하지 않음. 대체된 단어용)입니다.

모델이 필요로 하지만 어휘에 없는 단어는 **새롭다는 이유로 버려지지 않습니다**. 즉시 추가되어 다음 부분이 같은 것을 같은 방식으로 말하게 하며, *New* 상태로 기다립니다. 어휘에 없는 단어를 쓰고 모델이 보고하지 **않은** 번역은 표시됩니다. 그 단어가 실수인지 아닌지 아무도 알 수 없기 때문입니다.

<a id="names-for-the-name-generator"></a>

### 이름 생성기용 이름

편집기의 **Names** 탭은 언어를 [이름 생성기](name-generator.md)에서 쓸 수 있게 합니다. 그러면 생성되는 이름이 그 언어처럼 들립니다. **이름 범주**(예: *Places* 또는 *People*)를 추가한 다음, 그것을 구성할 어휘의 단어에 체크하세요. **검색**과 **범주 필터**로 목록을 좁힐 수 있고, **Check all shown**과 **Uncheck all shown**은 표시된 단어에 작용합니다. **Preview names**는 저장하기 전에 지금 체크된 단어로 이름 20개를 만듭니다. 이름 생성기는 체크된 단어로 마르코프 연쇄를 학습하므로, 범주에는 몇 개의 단어가 필요합니다(열두 개 이상이면 더 나은 이름이 나옵니다).

유지되는 것은 단어가 아니라 사용자의 선택뿐입니다. 바꾼 단어는 지금 상태 그대로 읽히고, 삭제하거나 Retire한 단어는 이름을 만들 때 제외됩니다. 설정을 저장한 뒤에는 그 범주가 이름 생성기(lore 생성기와 arc 개요의 **Tools** 대화상자, `generate-names` 명령, 에이전트 실행)에서 *Conlang - 언어 - 범주*라는 이름으로 제공됩니다. 이 범주는 사용자 자신의 것이며, 설치본의 다른 사용자에게는 자신의 범주만 보입니다.

![Names 탭: 이름 범주, 그것을 이루는 단어, 그리고 그 단어로 만든 이름 스무 개](../../images/plugin-conlang-names.png)

<a id="the-designer"></a>

### 디자이너

편집기의 **Design with AI** 메뉴는 모델에 도움을 요청합니다. 항상 언어를 **현재 상태 그대로**(규칙, 말투, 범주, 어휘, 예시 로어북) 전달하며, 항상 **제안**으로만 작동합니다. 사용자가 검토하기 전에는 아무것도 기록되지 않습니다.

![디자이너 메뉴](../../images/plugin-conlang-designer-menu.png)

| 작업 | |
|---|---|
| **Generate words...** | 범주의 단어를 원하는 개수만큼 만듭니다. 메모("공성 야영지의 부엌")를 함께 줄 수 있습니다. |
| **Add a section with AI...** | 빠진 부분(숫자, 색, 공손어)과 그것에 필요한 단어를 위한 새 규칙 섹션을 만듭니다. |
| **Rewrite a section...** | 사용자가 요청한 대로 모델이 섹션을 다시 씁니다. 모델은 **섹션 전체**를 돌려주므로, 아주 긴 섹션은 느리고 비용이 많이 듭니다. 섹션은 짧게, 주제는 하나씩 유지하세요. |
| **Review the language** | 모순, 빈틈, 소리 체계를 깨뜨리는 단어의 목록입니다. 각 항목에는 섹션과 해결책이 붙습니다. 아무것도 바꾸지 않습니다. |
| **Ask the designer...** | 대화입니다. 단어나 섹션이 담긴 답변은 변경 사항으로 검토할 수 있습니다. |

패널의 **Design a language**는 일곱 단계로 이루어진 마법사입니다(개요, 소리, 표기, 문법, 단어 형성, 범주별 첫 단어, 문장으로 하는 시험). 각 단계는 모델이 제안하고 사용자가 편집하며, 메모로 다듬고 수락하는 섹션입니다. 언어는 **완료**를 누르기 전까지 창 안에만 존재합니다.

![언어를 설계하는 마법사](../../images/plugin-conlang-wizard.png)

<a id="comparing-and-merging"></a>

### 비교와 병합

**Compare**(그리고 이미 가지고 있는 언어의 가져오기)는 두 언어의 차이를 보여 주는 창을 엽니다. 각 항목은 체크 상자가 있는 한 줄이며, 언어의 필드, 규칙, 범주, 말투, 단어, 이름 범주 중에서 추가, 변경, 삭제 또는 이동된 것을 보여 줍니다. 양쪽이 서로 다르게 바꾼 항목은 **충돌**입니다. 선택할 때까지 사용자의 값이 유지되며, 상대의 값을 고르거나 직접 쓸 수 있습니다. 고른 내용은 화면의 언어에 기록되고, 설정 화면을 저장할 때 보존됩니다. 같은 창에는 디자이너가 제안한 내용도 표시됩니다.

![두 언어의 차이점 검토](../../images/plugin-conlang-review.png)

<a id="choosing-the-language-of-a-book"></a>

## 책의 언어 선택

책 창의 **Prompts** 탭, *확장 기능 설정* 아래에 이 확장 기능의 필드가 있으며, 폴더 창에도 같은 필드가 있습니다. 비워 두면 *상속*입니다. 즉, 위의 폴더 설정을 따르고, 그다음 사용자 설정을 따릅니다.

![책의 필드](../../images/plugin-conlang-book.png)

| 필드 | |
|---|---|
| **Language of the speech** | 책을 번역할 언어입니다. 비워 두면 책은 번역되지 않습니다. |
| **Translate a new part by itself** | 부분이 확정되면 번역됩니다. 생성 후, 책에 자동 주석과 다시 쓰기가 있다면 그 후에, 또는 [부분 뒤에 이어지는 작업](../books/story-editor.md#what-follows-a-generated-part)의 한 단계로 번역됩니다(실행 패널에 표시되며, **중지**로 멈출 수 있습니다). |
| **Model of the translation**, **Protocol of the translation** | 비워 두면 책의 모델과 프로토콜을 쓰고, 없으면 사용자의 기본값을 씁니다. |
| **Readers of the published book see** | [뷰어](#the-viewer)가 보여 주는 내용입니다. |
<a id="the-conlang-tab-of-the-book"></a>

## 컨랑어 탭 (책 단위)

이야기 창에는 이 책의 언어를 위한 **Conlang** 탭이 있습니다(챕터 및 로어북과 같은 도크에 있으며, 원하는 곳으로 끌어다 놓을 수 있습니다). 이 탭에는 네 개의 하위 탭이 있으며, 책의 창에서 언어를 바꾼 뒤에는 **새로 고침**으로 언어를 다시 읽어 옵니다. [언어가 두 개 이상인 책](#more-than-one-language-in-a-book)이라면 **새로 고침** 옆의 입력란에서 *단어*, *화자*, *빠른 번역* 탭이 다룰 언어를 고를 수 있습니다.

<a id="words"></a>

### 단어

책 언어의 어휘집으로, 검색, 필터, [편집기](#the-lexicon)의 동작을 통해 이야기를 쓰는 동안 단어를 찾아보고, 고치고, 모델이 만들어 낸 단어를 수락하고, 단어를 잠그거나 폐기할 수 있습니다. 변경 사항은 즉시 라이브러리에 저장됩니다(그사이 번역이 추가한 단어는 사라지지 않습니다).

<a id="speakers"></a>

### 화자

**이 책에서** 이 언어를 쓰는 사람들입니다. 화자는 언어가 아니라 책에 속합니다. 같은 언어를 다른 이야기에서는 다른 사람들이 쓰므로, 언어를 복제하거나 내보내거나 비교해도 등장인물은 함께 옮겨지지 않습니다.

기본적으로 **모든 사람이 이 언어를 쓰되, 목록에 있는 등장인물은 제외**합니다(또는 반대로, 목록에 있는 사람만 씁니다). 이것은 기본값일 뿐이며, 본문이 이를 덮어씁니다("그녀는 공용어로 말했다", "경비병은 한마디도 알아듣지 못했다"). 모델은 모든 대사마다 이를 판단합니다. 등장인물마다 **성별**(언어가 성별을 표시하는 경우, 본문이 "그녀"라고만 쓰면 잘못 처리되므로 이를 적어 두는 것이 좋습니다)과 **목소리**("격식 있고, 간결하며, 거침")를 적어 둘 수 있으며, 모델은 이를 언어의 말투와 맞춥니다. 변경 사항은 즉시 책에 저장됩니다.

각 등장인물에는 **이해 수준**도 지정할 수 있습니다: *전혀 알아듣지 못함*, *몇 단어만 앎*, *대부분 따라감*, *모두 따라감*. 비워 두거나 *모두 따라감*을 선택하면 모델에는 아무 정보도 전달되지 않습니다. 이 수준은 언어를 말하지는 못해도 듣기는 하는 사람들에게 씁니다: *Tomáš: 전혀 알아듣지 못함*, *다른 마을 사람들: 대부분 따라감*(이름은 그저 글자일 뿐이므로 집단도 가능합니다). 이 수준은 책 전체에 걸쳐 **고정**되며 정보로서 모델에 전달됩니다. 그 정보를 가지고 등장인물이 무엇을 할지는 모델에 달려 있고, 언제든지 지시문에 더 자세히 적을 수 있습니다("Tomáš는 그들이 하는 말을 알아듣지 못한다").

이 정보는 두 가지 방식으로 모델에 전달됩니다. **이야기 모델**은 이해 수준이 담긴 짧은 메시지를 받습니다(작가의 노트처럼 프롬프트에 삽입됩니다. 위 목록 위의 체크박스로 끌 수 있고, 숫자는 끝에서 몇 번째 메시지에 넣을지를 뜻합니다). **부분을 검토하는 모델**(*AI로 주석 달기*)은 이 수준을 사실 목록의 한 섹션으로 받으므로, 알아듣지 못하는 말에 반응하는 등장인물을 표시할 수 있습니다. 문구를 직접 배치하고 싶다면 삽입을 끄고, 템플릿에서 {%{`{{command::conlang-understanding}}`}%} [매크로](../templates/macros.md#commands)를 사용하세요. 이 매크로는 선택적으로 유지할 등장인물 목록을 받습니다.

![컨랑어 탭: 화자 목록과, 언어를 따라가지 못하는 두 등장인물](../../images/plugin-conlang-tab.png)

<a id="languages"></a>

### 언어

책의 다른 언어들로, **언어 (말)** 필드가 지정하는 첫 번째 언어 외의 것입니다. 자세한 내용은 [책 하나에 여러 언어](#more-than-one-language-in-a-book)를 참고하세요.

<a id="quick-translate"></a>

### 빠른 번역

영어로 된 텍스트(구절, 이름, 아직 쓰지 않은 대사 한 줄)를 쓰고, 선택적으로 누가 누구에게 말하는지 적은 뒤 **번역**을 누르면, 모델이 규칙, 말투, 어휘집, 그리고 텍스트에 언급된 등장인물의 메모를 따라 책의 언어로 번역합니다. 이야기에는 아무것도 쓰이지 않습니다. 결과는 번역문, 선택에 대한 메모, 그리고 어휘집에 없던 **번역에 필요했던 단어**들이며, 각 단어에는 뜻과 그 이유가 함께 나옵니다. 원하는 단어를 선택한 뒤 **선택한 단어 가져오기**를 누르면, 이 단어들은 번역된 부분의 단어와 마찬가지로 *새로운* 항목으로 어휘집에 들어갑니다. 번역문에 있으면서 어휘집에도 없고 보고되지도 않은 단어는 경고로 표시됩니다.

<a id="more-than-one-language-in-a-book"></a>

## 책 하나에 여러 언어

서사시에는 엘프의 말, 드워프의 말, 오크의 말이 각각 등장할 수 있습니다. 책은 **먼저 쓰는 언어 하나**를 지정하며(위의 필드인데, 폴더나 설정이 이를 대신 정할 수도 있습니다), **컨랑어** 탭의 **언어** 하위 탭에서 라이브러리의 **다른 언어**를 하나씩 추가하거나 제거할 수 있습니다.

- **언어마다 고유한 화자가 있습니다.** *화자* 탭은 맨 위의 필드가 고르는 언어에 대한 것입니다. 첫 번째 언어는 이전처럼 목록에 적힌 등장인물을 제외한 모든 사람이 씁니다. **추가한 언어는 "목록에 적힌 등장인물만 쓴다"로 시작하며 아무도 적혀 있지 않으므로**, 누가 쓰는지 적어 넣기 전까지는 아무것도 요청되지 않습니다. 등장인물의 말이 다른 언어에 속한다면 첫 번째 언어의 예외로 그 인물을 적어 두세요. 그렇지 않으면 첫 번째 언어도 그 인물의 말을 요청하게 됩니다(두 언어가 모두 주장하는 말은 먼저 요청되는 언어에 속합니다). 등장인물은 여러 언어를 쓸 수 있으며, 두 언어 모두에 적으면 됩니다(부분 본문이 어느 언어로 된 말인지는 모델에 알려 줍니다).
- **언어마다 한 번의 요청.** 요청 하나에는 한 언어의 규칙과 어휘집, 그리고 그 언어 화자들의 대사만 담깁니다. 두 언어의 대사가 있는 부분은 두 번의 요청을 차례로 거칩니다. 두 번째 요청은 첫 번째 요청의 대사를 영어 그대로 두고 번역된 채로 남겨 두며, 그 부분을 읽습니다. 시점 인물과 등장 인물이 모두 해당 언어의 화자가 아닌 부분은 그 언어에 대해 요청되지 않습니다(이름이 하나도 없는 부분은 화자가 있는 모든 언어에 대해 요청됩니다).
- **대사와 부분의 언어를 알고 있습니다.** 팝오버, 내보내기, 뷰어는 이전과 같이 동작합니다. **컨랑어 번역(대화)**을 한 언어에 대해 다시 실행하면 다른 언어의 대사는 그대로 남으며, **영어로 되돌리기**는 한 언어에 대해서도, 모든 언어에 대해서도 할 수 있습니다.
- **메뉴는 책에 언어가 둘 이상이면 어느 언어인지 묻습니다.** 부분의 메뉴(*컨랑어 번역(대화)*: 언어 중 하나 또는 *모든 언어*)와 선택한 문장의 우클릭(한 언어)이 그렇습니다. **컨랑어 부분 번역**에는 *언어* 필드가 있습니다(기본값은 모든 언어). *번역되지 않은 부분*은 "그 언어로 번역되지 않은"을 뜻합니다.
- **자동 실행**은 새 부분을, 그 부분에 화자가 있을 수 있는 모든 언어로 번역합니다.
<a id="translating"></a>

## 번역

- **직접:** 파트의 메뉴에는 **번역** 하위 메뉴가 있습니다(텍스트를 우클릭해도 같은 메뉴가 나옵니다). 그 안에 **번역 대화(컨랭)** 항목이 있습니다(이 항목과 **파트 번역**은 이 플러그인의 언어가 있는 책에서만 표시됩니다). 이미 번역된 파트는 **영어 원문에서** 다시 번역되므로, 규칙이나 어휘집을 바꾼 뒤 파트를 다시 번역할 때도 이 방법을 씁니다. 책에 언어가 둘 이상 있으면 먼저 [어느 언어인지](#more-than-one-language-in-a-book) 묻습니다.
- **자동으로:** **새 파트 자동 번역**을 켜 두면, 생성된 파트가 확정되는 즉시 번역됩니다. 파트를 *다시 생성*하면 새 영어 원문이 만들어지고 이전 번역은 제거됩니다.
- **모델이 놓친 대화:** 번역에서 대화 일부가 영어로 남는 경우가 있습니다. 파트의 메뉴에서 **번역 → 누락된 대화 번역(컨랭)**을 선택하면, 아직 영어로 남은 대화만 번역하고 이미 번역된 대화는 그대로 둡니다. 텍스트를 선택한 상태에서 우클릭 메뉴의 **번역 → 선택 영역의 누락된 대화 번역(컨랭)**을 쓰면, 선택 영역에 걸친 대화만 번역합니다. 모델에는 번역된 대화가 포함된 파트 전체가 그대로 전달되고, 영어로 남은 대화만 요청하므로 파트 전체를 번역하는 것보다 비용이 적게 듭니다. 이 기능은 대화만 씁니다. 모델이 대화로 보지 않는 문장은 번역하지 않으므로, 그런 경우에는 *선택한 텍스트 번역*을 사용하세요.
- **직접 쓴 문장:** 파트 텍스트에서 문장을 선택하고 우클릭한 뒤 **번역 → 선택한 텍스트 번역(컨랭)**을 고르세요. 모델은 선택한 텍스트(앞뒤 공백과 따옴표 한 쌍은 제외)를, 언어와 등장인물의 메모, 주변 이야기를 참고해 번역합니다. 텍스트는 번역문으로 바뀌고, 영어는 대화의 원문으로 남으므로 클릭하면 다른 번역 대화와 마찬가지로 영어가 보입니다. 모델이 새로 만들어야 했던 단어는 번역된 파트와 같이 *새로운* 항목으로 어휘집에 추가됩니다. 번역된 대화가 포함된 선택 영역은 거부됩니다(먼저 영어를 되돌리세요). 그 사이에 바뀐 파트에서 한 선택도 마찬가지로 거부됩니다.
- **범위:** 이야기의 도구 메뉴에 있는 **파트 번역(컨랭)**을 열면, 이야기 옆에 계속 열려 있는 창이 나타납니다.

  ![파트 번역](../../images/plugin-conlang-range.png)

  **시작 파트**와 **끝 파트**(텍스트가 있는 파트를 내보내기와 같이 1부터 셉니다)를 고르고, 무엇을 할지 선택하세요. *번역되지 않은 파트 번역*, *번역된 파트 다시 번역*(규칙이나 어휘집을 바꾼 뒤), 또는 확인을 거친 뒤 *영어로 되돌리기* 중 하나입니다. 창에는 범위에 파트가 몇 개 있는지, 그중 선택한 작업이 몇 개에 적용되는지가 표시되고, *m개 중 n번째 파트*가 나타납니다. **중지**를 누르면 현재 처리 중인 파트가 끝난 뒤 멈춥니다(이미 시작된 모델 요청은 되돌릴 수 없습니다). 실패한 파트는 집계되고 작업은 계속됩니다. 언어나 모델이 없으면 작업이 끝납니다. 작업이 끝나면 이야기를 다시 그립니다. 작업 중에 편집한 파트는 작업 전체가 아니라 그 파트만 실패하게 합니다.

번역은 다른 텍스트 변경과 마찬가지로 저장됩니다. 파트의 기록에 새 버전이 생기지만, 파트는 **편집됨으로 표시되지 않으며** 영어 원문도 유지됩니다. **직접 고친 대화는 파트를 다시 번역하거나 영어로 되돌릴 때 그대로 남습니다**. 그 대화에는 작성자의 단어가 담겨 있기 때문입니다.

!!!
번역에는 모델이 파트를 처리하는 시간만큼 걸립니다. 생각하는 로컬 모델에서는 몇 분이 걸릴 수 있습니다. 이 확장은 모델이 생각하도록 요청하므로(성별, 수, 말투의 번역 품질이 훨씬 좋아집니다), 모델의 출력 한도를 넉넉하게 주세요.
!!!

## 독자가 보는 것

<a id="in-the-story"></a>

### 이야기에서

번역된 대화에는 **점선**이 표시됩니다. 점선을 클릭하면 팝오버에 영어가 나타나고, 누가 말했는지와, 듣는 사람이 그 언어를 이해하지 못하는 경우 *(듣는 사람이 이해하지 못함)*이 표시됩니다. 번역 이후 컨랭 텍스트를 편집했다는 빨간 메모가 나타나면, 영어가 지금의 내용과 다를 수 있다는 뜻입니다.

**원문 편집**(팝오버의 버튼이며, 작성자 본인의 보기에서만 나타나고 게시된 책의 독자에게는 보이지 않습니다)을 누르면, 이야기에 저장된 번역과 모델이 읽는 영어가 함께 나오는 작은 창이 열립니다. 원어민이 번역을 직접 고쳤는데 영어가 다른 내용을 말하고 있거나, 모델이 영어를 잘못 옮겼을 때 사용하세요. 저장하면 대화에 새 영어가 주어지고, 그 영어가 현재 번역문에 대응하는 것으로 기록되며(빨간 메모가 사라집니다), 이후 모델은 기존 영어 대신 새 영어를 읽습니다. 파트의 텍스트는 바뀌지 않으며, **대화 번역(컨랭)**을 다시 실행하면 둘 다 새로 만들어집니다. `conlang-edit-source` 명령으로도 같은 작업을 할 수 있습니다.

![대화의 원문을 편집하는 창](../../images/plugin-conlang-source.png)

**원문에서 찾아 바꾸기**(컨랭 탭 맨 위의 화살표 버튼)를 누르면, 활성 분기에 있는 번역된 대화의 영어 원문에 대해 애플리케이션의 찾아 바꾸기 창이 열립니다(일반 텍스트 또는 정규식, 대소문자 구분 여부를 선택할 수 있습니다. 표에는 일치하는 대화가 파트와 대화 번호별로 나열됩니다). 영어에서 이름의 철자가 두 가지로 쓰인 경우에 사용하세요. 원문만 바뀌며, 번역문 자체의 단어를 바꾸려면 책의 찾아 바꾸기를 사용하세요. 검색 후에 원문이 바뀐 대화는 그대로 두며 집계됩니다.

![번역된 대화의 영어 원문에 대한 찾아 바꾸기](../../images/plugin-conlang-search-replace.png)

### 뷰어

[게시된 책](../books/publishing.md)의 뷰어는 **독자가 보는 게시된 책**(책 또는 폴더의 선택 항목)을 통해 책이 지정한 방식대로 번역된 대화를 보여 줍니다. 작성자 본인의 기본 설정은 독자에게 무엇이 보일지를 결정하지 않습니다.

| | |
|---|---|
| **컨랭, 클릭하면 영어** | 기본값입니다. 클릭(휴대폰에서는 탭)하면 영어가 있는 팝오버가 열립니다. |
| **컨랭만** | 영어는 독자의 브라우저로 전송되지 않습니다. |
| **영어만** | 번역이 없었던 것처럼 책이 보입니다. |

클릭 모드에서는 페이지에 컨랭만 담깁니다. 대화의 영어는 독자가 클릭할 때 서버에서 가져옵니다.

## 내보내기

책에 번역된 대화가 있으면, [내보내기](../books/export.md) 대화상자에 **번역된 대화** 항목이 나타납니다.

![내보내기 대화상자](../../images/plugin-conlang-export.png)

| | |
|---|---|
| **컨랭, 있는 그대로** | 기본값입니다. 저장된 그대로의 텍스트입니다. |
| **영어만** | 대화가 영어 원문으로 바뀝니다. |
| **컨랭, 영어는 각주로** | 번역된 모든 대화에 영어(와 화자)가 담긴 각주가 붙습니다. |
| **영어, 컨랭은 각주로** | 반대입니다. |

각주는 [내보내기의 각주](../books/export.md#footnotes)입니다. HTML과 EPUB에서는 연결된 주석, 일반 텍스트에서는 각 파트 뒤의 미주, Word와 PDF에서는 쪽 아래의 실제 각주로 나타납니다. 번역한 뒤에 편집한 대화는 그대로 남으며 각주가 붙지 않습니다. 내보내기는 책에 저장된 텍스트를 절대 바꾸지 않습니다.

## 명령

화면에서 하는 모든 작업은 명령으로도 실행할 수 있습니다. [명령줄](../commands/index.md)에서도, [에이전트](../agents.md)에서도 가능합니다. 에이전트는 사람이 대화상자 앞에 없어도 언어를 만들고, 키우고, 책을 번역하고, 결과를 확인할 수 있습니다. 언어는 **이름**(대소문자 구분 없음) 또는 id로 지정합니다. 규칙 절은 제목이나 `conlang-list-rules`에서 보이는 번호로, 범주는 이름이나 번호로 지정합니다. 단어는 형태로 지정하며, 동음이의어를 구별할 때에만 `conlang-list-words`의 id를 씁니다. 부분(part)은 애플리케이션의 다른 명령과 같이 핸들이나 활성 가지에서의 위치로 지정합니다(첫 부분은 1). 명령줄에서는 명령의 모든 인자를 입력할 수 있으며, 에이전트는 선택 인자를 생략해도 됩니다.

| 명령 | |
|---|---|
| `conlang-list`, `conlang-get`, `conlang-create`, `conlang-duplicate`, `conlang-update`, `conlang-delete`, `conlang-export`, `conlang-import`, `conlang-set-references` | 라이브러리. `conlang-delete`는 사용자에게 확인을 묻으며, 에이전트는 사용할 수 없습니다. |
| `conlang-list-name-categories`, `conlang-add-name-category`, `conlang-update-name-category`, `conlang-delete-name-category`, `conlang-preview-names` | [이름 생성기](name-generator.md)의 이름 범주(**Names** 탭). 추가와 수정에는 어휘집의 단어(`;`로 구분)나 어휘집의 범주 전체를 넣을 수 있습니다. 삭제는 사용자에게 확인을 묻고, 미리보기에는 이름 생성기가 필요합니다. 이름의 목록과 생성은 생성기 자체의 `list-name-categories`와 `generate-names`로 합니다. |

| `conlang-list-categories`, `conlang-add-category`, `conlang-update-category`, `conlang-move-category`, `conlang-delete-category` | 단어의 범주들. |

<a id="agent-runs"></a>

### 에이전트 실행

에이전트는 **책의 사본**에서 작업하며, 언어는 책의 일부가 아니므로 에이전트가 사용자 몰래 라이브러리를 바꿀 수는 없습니다. 실행이 처음으로 언어를 **변경**하면(단어, 규칙, 또는 번역이 새로 만든 단어), 그 언어는 복사된 원본 버전과 함께 책의 사본으로 복사됩니다. 그 뒤로 실행은 자신의 사본을 읽고 씁니다. 읽기만 하거나, 가지고 있는 단어로만 번역하는 실행은 아무것도 복사하지 않습니다. 이 사본은 책의 사본이 가는 곳을 따라갑니다. 즉 체크포인트와 그 복원, 실행의 검토, 그리고 삭제에도 함께 적용됩니다.

실행의 결과를 **적용**하면 언어는 책에 들어가며, **라이브러리에는 들어가지 않습니다**. 그러면 책의 **Conlang** 탭에 *An agent run changed the language ...* 메시지가 **Review**와 **Drop** 버튼과 함께 나타납니다. Review는 세 가지 버전을 비교합니다. 실행이 사본을 만들었을 때의 언어, 실행의 버전, 그리고 지금의 라이브러리 버전입니다. 따라서 실행 도중 라이브러리에서 바꾼 내용은 유지되고, 두 사람이 모두 바꾼 부분은 사용자가 결정할 충돌로 표시됩니다. 명령으로는 `conlang-pending-changes`가 변경을 번호로 나열하고, `conlang-take-pending-changes`가 그것을 가져옵니다(이때 사용자에게 확인을 묻습니다). 실행이 만든 언어는 사용자가 확인하면 통째로 추가됩니다.

실행은 언어를 처음 바꾸기 전까지는 라이브러리를 읽고, 그 뒤로는 자신의 사본을 읽습니다. 따라서 실행이 작업하는 동안 사용자가 언어에서 바꾼 내용은 실행이 보지 못하지만, 사라지지도 않습니다.

<a id="limits"></a>

## 제한 사항

- **품질은 모델의 몫입니다.** 확장 기능은 공짜로 할 수 있는 검사(인용된 대사가 부분에 있는지, 언어, 어휘집에 대한 단어, 합성어와 접사에 대한 규칙)를 하고 나머지는 보고합니다. 문법을 검사하지는 않습니다. 긴 실행을 하기 전에 몇 개의 부분에서 먼저 언어를 시험해 보고, 같은 실수가 반복되면 설계자의 **Review the language**를 사용하세요.
- **언어는 그 언어를 쓰는 책들이 공유합니다.** 사용자가 바꾼 단어나 번역이 추가한 단어는 같은 시리즈의 모든 책에서 바뀝니다. 이는 의도된 동작입니다(하나의 세계). 언어를 따로 유지하려면 **Duplicate**를 사용하세요.
- **에이전트가 바꾼 언어는 책에서 기다립니다.** 실행을 적용한 뒤 사용자가 라이브러리에 가져와야 합니다. 실행이 작업하는 동안 언어는 잠기지 않습니다.
- **명령은 이야기 속 단어를 바꾸지 않습니다.** 또한 다시 번역할 때 영어 원문이 바뀌지 않은 번역은 보존되지 않습니다(범위의 모든 부분을 다시 요청합니다).
- **휴대폰**에서는 패널, 편집기, 검토, 마법사를 쓸 수 있습니다. 다만 어휘집 표는 좌우로 스크롤됩니다. 뷰어에서 대사를 탭하는 동작은 작동합니다. 이야기 쪽(부분 메뉴, 범위 창, 이야기 안의 클릭)은 휴대폰에서 시험하지 않았습니다.
