# リソースファイル

[リソース](../resources.md)のファイル（ストーリーのパーツに添付された画像やアップロードされたファイル）は、各ユーザーのデータフォルダ内の `data/<login>/images` と `data/<login>/resources` に保存されます。リソースを削除したり、その内容を差し替えたりしても、変更されるのはデータベースだけです。ファイルはディスク上に残り、[クリーンアップ](cleanup.md)やその他の操作でも削除されません。**リソースファイル**は、もう使われていないファイルを見つけ、ダウンロードしたり、ディスクから削除して容量を取り戻したりできるようにする機能です。

<a id="cleaning-up-the-files"></a>

## ファイルのクリーンアップ

1. 管理ページの**リソースファイル**タブを開き、**ファイルをスキャン**をクリックします。読み込み中のフォルダが進捗バーで示されます。
   この時点では何も変更されません。
2. 表には、どのリソースからも参照されていないファイルが並びます。表示されるのは、パス（`<ユーザーフォルダ>/images/<ファイル>`）、サイズ、最終更新日時です。すべてのファイルにチェックが入っています。残したいファイルのチェックを外してください。**すべて選択**と**選択を解除**は全ファイルを一括で切り替えます。最初の列のヘッダーにある矢印も同じ操作をします。表の上の行には、未使用のファイルの数、その合計サイズ、チェックされている数が表示されます。
3. 必要に応じて**ZIPでダウンロード**をクリックすると、チェックされたファイルを1つのアーカイブにまとめて取得できます（エントリ名はパスになります）。行の矢印をクリックすると、1つのファイルだけを取得できます。削除する前に、これをバックアップとして保存しておくと安心です。
4. **選択したものを削除**をクリックすると、確認の後、チェックされたファイルがディスクから削除されます。**閉じる**をクリックすると、何も削除せずに表を空にします。

![スキャン後のリソースファイルタブ](../../images/admin-resource-files.png)

!!!warning
削除したファイルは元に戻せません。迷ったら、先にZIPでダウンロードしてください。
!!!

<a id="what-counts-as-used"></a>

## 「使用中」の判定

ファイルは、**いずれかのユーザーのどのリソースからでも参照されていれば**使用中とみなされます。削除済みのリソースも含まれます。[ゴミ箱](../trash.md)にあるリソースは復元できるので、その画像も再び正しく表示される必要があるからです。したがって、削除されたリソースのファイルは、[クリーンアップ](cleanup.md)がデータベースからそれらのリソースを取り除いた後にはじめて一覧に表示されます。置き換えられた内容の古いファイル（古いファイルは残ったままになります）や、アップロードに失敗して残ったファイルも同様です。

ファイルは名前（ランダムな識別子）で照合されます。照合の対象は全ユーザーのフォルダで、削除済みユーザーの `<login>-deleted` フォルダも含まれます。そのフォルダ内のファイルは、クリーンアップがそのユーザーとリソースを完全に消去するまで*使用中*のままです。

データフォルダ内のフォルダのうち、読み取られるのは `images` と `resources` フォルダだけです。それ以外（データベースのバックアップ、エージェントのワークスペースなど）には触れません。

スキャンの後にユーザーがアップロードしたファイルは削除されません。**選択したものを削除**を実行すると、データベースを読み直し、その時点でリソースから参照されているファイルは残します（残したファイル数がメッセージに表示されます）。

スキャンではデータフォルダ全体を読み込むため、ファイル数が多いと時間がかかることがあります。進捗バーの**停止**をクリックすると、スキャンを中止できます。
