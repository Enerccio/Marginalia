# モデルに渡すツール

一部の拡張機能は、モデルに**ツール**を与えます。これは、モデルが書いている途中で呼び出せる関数で、名前を得たり、実在する場所を調べたりするために使われます。モデルが勝手に作り出すのではなく、これらを使います。一つの拡張機能のツールの集まりが**ツール群**です。現在あるツール群は次のとおりです。

| ツール群 | 拡張機能 | モデルがこれで行えること |
|---|---|---|
| 名前ジェネレーター | [名前ジェネレーター](name-generator.md) | あるカテゴリ（地名、神名、国の姓など）に合う響きで作られた名前を得る。 |
| 名前プロバイダー | [名前プロバイダー](name-provider.md) | 実在する名前を、元の綴りのまま得る。 |
| 場所プロバイダー | [場所プロバイダー](place-provider.md) | 実在する場所、その周辺の様子、そして場所同士の距離を調べる。 |

ツールを使ってモデルを動かすダイアログには**ツール**ボタンがあります。対象は[ロアジェネレーター](lore-generator.md)と[アークアウトライン](arc-outline.md)の生成機能です（アークアウトラインの物語インポートは除きます。そこでの名前はすでに物語の中にあるためです）。このボタンは、ツール群が一つでも導入されている間だけ表示されます。何かを選んでいる場合は、いくつ有効かを表示します（例: **ツール (3)**）。

<a id="choosing-the-tools"></a>

## ツールを選ぶ

**ツール**を押すと、ウィンドウが開きます。ツール群ごとに一つずつセクションがあり、セクション名はツール群の名前で、その中でチェックされている項目の数が表示されます。何かがチェックされているセクションは、開いた状態で始まります。セクションの中身はツール群によって異なります。

- **項目**を持つツール群（名前ジェネレーターと名前プロバイダーには、カテゴリや名前リストごとに項目があります）では、各項目にチェックボックスが付いた表が表示されます。表の上には、そのための**フィルター欄**があります。名前の一部を入力すると、一致する項目だけが表示されます。チェックされている項目は、フィルターの内容にかかわらず表に残ります。**表示中を選択**を押すと、そのときに表に表示されている項目がすべてチェックされ、**表示中の選択を解除**を押すと、それらのチェックが外れます。下の行には、チェックされている数が表示されます。モデルが受け取るのはチェックされた項目だけです。モデルはそれらを一覧にしたり、その名前を使った名前を求めたりできますが、それ以外の項目は扱えません。
- **項目を持たない**ツール群（場所プロバイダー）は、オンかオフのどちらかです。**このツール群を使う**で切り替えます。

![「日本」で絞り込んだ名前ジェネレーターのカテゴリを表示しているツールのウィンドウ](../../images/tools-dialog.png)

どのセクションにも**モデル向けヒント**があります。これは、ツール群がモデルに渡されるときにプロンプトの末尾に加えられる短い文章で、ツールをいつ、どのように使うかをモデルに伝えます（名前の場合は、名前を勝手に作らずツールを呼び出すこと、返された名前から選ぶこと、実在の名前は返されたとおりに保つことなど）。組み込みの文章は欄にグレーで表示されます。自分で書いた文章で置き換えるには、そこに書き込みます。欄を空にすると、組み込みの文章が使われます。

![オンになっているツール群で、そのモデル向けヒントを開いた状態。残りの二つのセクションは閉じており、チェックされた項目の数が表示されている](../../images/tools-hint.png)

モデルが受け取るのは、何かがチェックされているツール群だけです。どのツール群でも何もチェックされていなければ、ツールは渡されません。この選択はアカウントごとに保存されるので、次回も同じ状態になります。ロアジェネレーターは、生成した各エントリにも選択を保存し、そのエントリを開くとその選択も一緒に復元されます。読み込みを解除されたツール群は読み飛ばされ、拡張機能がもう持っていないチェック済みの項目は無視されます。拡張機能は Marginalia の実行中に読み込んだり解除したりでき、ボタンはその状態に合わせて変わります。

二つのツール群が同じ名前の関数を持っていた場合、生成は開始されず、どの二つかが示されます。Marginalia に付属するツール群では、このようなことは起きません。

<a id="as-commands"></a>

## コマンドとして

ツール群は、[コマンドバー](../commands/index.md)と[エージェント](../agents.md)のコマンドにもなっています（`/pick-real-names`、`/generate-names`、`/search-places` など）。そのため、ここでモデルが受け取るものと、エージェントが呼び出せるものは、同じ名前の同じツール群です。

<a id="from-an-older-version"></a>

## 古いバージョンから

**名前ツール**ボタンは**ツール**になりました。以前チェックしていたカテゴリは、名前ジェネレーターと名前プロバイダーのツール群でチェックされた状態になっています。*設定 → 拡張機能の設定* に書いていたヒント（*名前ジェネレーターのヒント*、*名前プロバイダーのヒント*）は、このウィンドウでその二つのツール群のモデル向けヒントになりました。設定の欄はなくなっています。
